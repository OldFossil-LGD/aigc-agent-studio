## 一、先分清"僵硬"和"虚假"是两种病（根因不同，药也不同）

用户说"人物僵硬/虚假"时，**先分诊再下药**——两者的成因与修法完全不同：

| 症状 | 根因 | 修法（按此顺序） |
|---|---|---|
| **僵硬 / 面具脸** | ① 脸在画面里太小（表演根本读不到）② 只写了动作名、没写可见信号 ③ 匀速插值感 | ① **需要表情就给近景**（这条最优先，其余都白搭）② 补【人物表演】块 ③ 写"节奏不均匀"+ 呼吸有深浅起伏 + 眨眼间隔不等（不写固定秒数） |
| **虚假 / 出戏** | ① **人物知道自己在被看**（摆姿势）② **反应太满太快**（零延迟、零犹豫）③ 动作**太对**（每个动作都完成得干干净净）④ 情绪单向、无矛盾 | ① 写"没在看镜头"的具体形式 ② 加反应延迟与半途修正 ③ 允许动作**未完成**就转下一拍 ④ 补矛盾层（说的 vs 身体做的） |

**一句话判据**：**僵硬是"没信息"，虚假是"信息太整齐"。**

- 没信息 → 补信号（第二节）
- 太整齐 → 补**噪音**（第三节：延迟、半途修正、未完成、矛盾）

> ⚠️ **最常见的误诊**：把"虚假"当"细节不够"，于是加更多细节——结果更假。
> 虚假的解法不是**加**，是**破**：打破完整性。真人的动作是**没有完成的**。

## 二、内部驱动：写之前先答三句（答不出就是没想，不是不会写）

`character-depth.md` 第 8 节的三问是所有表演的**输入端**。"他此刻想要什么"决定了**每一个可见信号的幅度与方向**：

| 三问 | 它决定什么 | 例：一个人被叫住 |
|---|---|---|
| **他此刻想让人看见什么？** | 外在表演的**控制点** | 想让人看见"我没事" |
| **身体在哪里背叛他？** | 唯一允许泄漏的**一个通道**（只给一个，给多了就散） | 手——松开又攥上 |
| **他用哪里使劲克制？** | 张力**存哪个部位**（写"绷着的静"要指明位置） | 下颌 |

**表演的逻辑：目标是外在的，泄漏是一个通道的，克制是局部的。** 三者齐了，演员不需要"演"，观众自己会读。

**外加一句（补 character-depth 没有的）**：**给一个"当下不允许做的事"**。
人在克制的瞬间一定有个想动而没动的部位——写出来，观众就读到"他在忍"：
`他抬手想扶她，手抬到一半，改成插进兜里。`

## 二·补：五大支柱（目标 / 障碍 / 战术 / 节拍 / 潜台词）

上面三问是**输入端**（他要什么），这五条是**整场戏的骨架**——比单镜更上一层，写序列时会用到：

| 支柱 | 定义 | 最容易写错的写法 |
|---|---|---|
| **目标 Objective** | 他此刻、对**这个具体的人**、想要什么。**永远是瞄准搭档的动词** | ❌ 写成状态："他很愤怒""他很愧疚"（状态没法被直接演出）→ ✅ "他要让她承认是她干的" |
| **障碍与赌注** | 什么挡着他；**得不到会怎样**。赌注越高，戏越紧 | ❌ 只写障碍不写代价 → ✅ 每条障碍后面接一句"如果失败" |
| **战术 Tactics** | 此刻追求目标的**具体方法**（施压 / 讨好 / 羞辱 / 恳求 / 激将 / 拖延） | ❌ 整场一个战术（＝死表演）→ ✅ **战术失败就换**，活人会换 |
| **节拍 Beats** | 最小行动单位：想要一件事 + 用一种方式追求它的一小段 | ❌ 节拍变化看不见 → ✅ **每个节拍变化必须在行为上可见**（停一下 / 换姿态 / 变语速 / 视线移开） |
| **潜台词 Subtext** | 他真正想什么 vs 他说什么 | ❌ 把潜台词"演出来"→ ✅ **潜台词不是演出来的，是没藏住的** |

> **潜台词怎么自然漏出来**（五个标记，写台词时对照）：不是问题的提问 / 重复问同一件事（不信对方的回答）/ 突兀转话题 / 错时机的玩笑 / **过短的回答**（"挺好。""行。"——一扇关上的门）。

**一句话**：**目标是外在的，障碍是真的，战术是会失败的，节拍要看得见，潜台词不能演。**
（这条与三问互补：三问管**一个瞬间**怎么演，五支柱管**一整场**怎么搭。）

## 三、破"虚假"的四个工具（这一节是本文的核心增量）

真人的表演"不整齐"。下面四个工具专门制造**可控的不整齐**——不是加瑕疵，是加**人的痕迹**。

### 工具 1 · 反应延迟（最立竿见影的一条）

**AI 的默认是"零延迟"**：听到话立刻反应、看到东西立刻转头。真人不是——**听到→理解→决定→动**，中间有时间差。

| 写法 | 效果 |
|---|---|
| `被叫到名字后，他先没有反应，过了大半秒，才把视线抬起来` | 分出了"听见"和"应答"两件事 |
| `她听完，手里的事没有停，停下来的只是呼吸` | 反应发生在**非主要通道**上，更真 |

**延迟长度纪律**：**0.5–1 秒**是"迟疑"，**1.5 秒以上**是"走神/听不见"。别笼统写"愣一下"。

### 工具 2 · 半途修正（人做动作不是一次到位）

AI 倾向于把动作做成**一条平滑完成曲线**。真人会**过头再修正**、**中途改变主意**：

- `他把杯子端起来，举到嘴边停了一下，又放回去`
- `她点头，点到一半改成摇头`
- `他伸手去拿，指尖碰到了又收回来`

**这一条几乎单枪匹马解决"虚假"**：一个"未完成的动作"比十个"完成的动作"更像人。

### 工具 3 · 未完成与余势

- **动作不许都做完**：`话没说完，他人已经转身了`。
- **上一个动作的余势是下一个动作的起点**（与 `physical-feedback.md` 第 9 节同源，但这里用在表演上）：
  `借着转头的惯性顺势抬眼`。
- **情绪先起、动作后到**：`他脸上先有了反应，手才跟上`——**表情永远比动作快半拍**，反之就是机器人。

### 工具 4 · 矛盾（写一个通道的背叛）

`character-depth.md` 第 6 节给了矛盾的原理，这里给**可执行清单**——每一行都是"表面 + 一个部位的背叛"：

| 表面 | 一处背叛（只写一处） |
|---|---|
| 平静地说话 | 呼吸变浅、句子之间换气变短 |
| 笑着答应 | 笑停在嘴边，眼睛没有跟着弯 |
| 无所谓地耸肩 | 肩是耸了，手指还按在桌沿上没松 |
| 转身要走 | 脚动了，肩膀还朝着对方 |
| 专注看手机 | 拇指一直没有滑，屏幕停在那一页 |

> **纪律**：矛盾**只给一个通道**。同时写手抖 + 呼吸乱 + 眼神躲 = 演员在"演慌"，反而假。
> **一个通道泄漏，其余全部保持控制**——这才是克制的语法。

## 三·补：三个"结构性"破假手段（比加细节更根本）

上面的四工具是**时序层**的补丁。这一节是**结构层**的——不写这些，光加延迟也还是"两个人站在空房间里念台词"。

### 补 1 · 活计（Business）——给角色一件"正在做的事"

**AI 最典型的假，是两个人在干净的空气里站着说话。** 真人说话时几乎总在干点什么：擦杯子、修东西、数钱、系鞋带、喂猫。

- **活计的作用**：杀死舞台腔 / 制造场景节奏 / **生出潜台词**（他手上的事和他的话不一致时，戏就有了）。
- **最强的一个重音是"停下手里的活"**：`她一直低头叠衣服；说到那三个字，手停了，衣服还捏在手里。`
  这比任何表情描写都更有力——**中断动作＝最大的强调**。
- **无对白 / 独角戏更要给活计**：没有台词的时候，活计就是唯一的台词。

### 补 2 · 空间关系（Proxemics）——距离就是情绪

| 区域 | 距离 | 含义 | 怎么用 |
|---|---|---|---|
| **亲密区** | 0.5 米内 | 爱，或暴力 | 只有这两种事发生在这个距离 |
| **个人区** | 0.5–1.2 米 | 信任 | 朋友、家人 |
| **社交区** | 1.2–3.5 米 | 公事、戒备 | 同事、陌生人 |
| **公共区** | 3.5 米+ | 疏离 | 演讲、对峙 |

**距离改变 = 节拍改变。** 一个人越过了界限，或者退开一步，**本身就是一次节拍变化**——不用写任何表情，观众就懂了。
写对白戏时先问一句：**这两人现在应该在哪个区？他们有没有动过？**

### 补 3 · 地位（Status）——地位是"做"出来的，不是"是"出来的

- **高地位**：头不动、动作慢、注视长、回答前先停一下、**占地方**。
- **低地位**：忙乱、频繁自摸（摸脸 / 摸头发）、语速碎、身体缩小。
- **音量对比：最可怕的东西说得最轻。** 吼是弱者的货币；掌控局面的人压低音量。
- **"最危险的人动得最少"**——威胁不是由威胁者演出来的，是由**周围人的紧张**演出来的。
- **地位崩塌最好看**：老板有一秒露怯 / 下属突然不笑了 / 一直稳的人手抖了一下。**只给一秒，然后收回去。**

> ⚠️ **别把地位写成形容词**。不写"他很有气势"，写"他从头到尾没动过，回答之前先看了对方两秒"。

## 四、微表情的正确粒度（**一两帧**、不可控、一闪而过）

`character-depth.md` 第 5 节给了面部肌肉的具体动作表（眉/眼/嘴/颌）与**三档时长**（**"不到一秒"是错的量级——微表情只有一两帧，40–200 毫秒**）；这里补**三条它没有的**：

### 1. 三区必须同拍（这是成片验收的硬判据）

一个可信的表情，**嘴+下颌 / 颈喉 / 眼眉**是**同一个拍**上一起动的（→ `review-passes.md` Pass 3）：

- ❌ 只有嘴唇开合（= 贴图换嘴）
- ❌ 眼睛在做悲伤、嘴角还在上一拍的笑（= 分区动画）
- ✅ `眼眶先红起来，紧接着下颌绷住，喉结滚了一下——三处同一个拍`

> **★ 边界（2026-09-15 补）**：**三区同拍管"完整情绪表达"（释放 / 峰值）**；**被压住的泄漏允许只动一处、且是碎片的**（→ `character-depth.md` §五）。
> **看这一拍是在"演"还是在"漏"**——"演"要三区同拍，"漏"只给一个通道。两套规则不冲突，**混用的后果是"演得像漏"或"漏得像演"，两头都假**。

### 2. 准备 → 峰值 → 释放（不要整段绷着）

表情是**有弧线的**，不是有/无两态：

| 段 | 写什么 | 例（忍住不哭） |
|---|---|---|
| **准备** | 肌肉先收（观众预感到了） | 眉心先微微紧起来 |
| **峰值** | 最大形变，**只停 1–2 帧** | 眼睑下端绷紧、下唇内收咬住 |
| **释放** | 松掉，留一点残迹 | 松开了，但眼角还湿着 |

**纪律**：**峰值不许停留太久**。停留 = 摆拍；一闪而过 = 真实。写实向尤其如此。

### 3. 微表情要与"他表现出来的"有落差

微表情的价值**全在落差**里：`他脸上有什么东西闪了一下，随即被按平`。
**写法固定为两步**：先给一个**不由自主**的反应（一帧），再给一个**压回去**的动作（几帧）。
只写前者 = 情绪外放；只写后者 = 面具。**两者都要有才叫"克制"。**

### 4. 眼生命（Eye Life）——死眼是 AI 表演的头号破绽

**这条不可选。** 一条提示词里没写眼睛，模型就给你一双**盯着不动、亮得像玻璃珠**的眼睛——**这是全片最先被观众看出"是 AI"的地方**。六条规则与全部反例正例 → `performance-vocabulary.md` 第二节。

> **判据（交付前必过）**：随便挑一帧暂停——**他的眼睛像活人的吗？** 不像就回去补，别指望别的描写能救。

## 五、情绪表达的翻译纪律（写实 vs 风格化，两套幅度）

情绪词一律翻译成可见信号（原理与对照表在 `character-depth.md` 第 11 节）。本节只解决一个它没答的问题：**同一套方法，不同风格的幅度差多少。**

| | 写实向 | 风格化 / 美漫描边 |
|---|---|---|
| **延迟** | 保留（这个更真） | **缩短到几乎没有**（夸张风格里迟疑会显得拖） |
| **半途修正** | 保留（最有效） | 保留但**幅度放大**（改成大幅度的"回头"） |
| **微表情停留** | 1–2 帧 | **停留更久**（6–10 帧，要让观众一眼抓到） |
| **矛盾通道数** | **1 个** | **可到 2 个**（夸张风格容得下） |
| **预备与跟随** | 轻微 | **必须明显**（动画十二法则的 squeeze & stretch 与 follow-through，见 `physical-feedback.md` 第 3 节） |
| **眼睛** | 不改变形状 | **可变形**（瞳孔缩放、眼球放大） |

**共同点不变**：都是先问三句（第二节），再写可见信号——**风格只改幅度，不改方法**。

## 六、对手戏与多人：表演的"接球"纪律

单人表演是"给一个人写反应"；**对手戏是两个人之间的力**——AI 最常在这里崩成"两个人在轮流念台词"。

| 纪律 | 怎么做 |
|---|---|
| **一次只拍一个人的表演** | 需要两人都演 → **正反打分开做**（AI 对"同时两套表演"的容忍度极低） |
| **反应方比说话方更重要** | 说话的人在说的时候，**听的人在动**（手停了、视线移了、咽了一下）——这才是对手戏 |
| **不要把两人的动作写成对称** | 一个动、一个静；一个前倾、一个后撤。**对称＝排练感** |
| **"接球"要有延迟** | A 说完，B 不是立刻答——**先有一个接收的动作**（眨眼、吸气、手停半拍）再开口 |
| **配角错位** | 见 `character-depth.md` 第 12 节：主角在说话时，配角在干**别的事** |

**判据**：把这场戏静音看一遍——**你还能看出两人在交流吗？** 能，表演就成立了。

## 七、可执行的"训练要点"（怎么练到手上，不是怎么知道）

> 这一节**给你练**，不是给模型写。表演是**辨认能力**，不是知识量。

**训练 1 · 逐帧看真人（最有效，无替代）**——挑 3 个片段（**无对白最好**：独自做事 / 等人 / 听到坏消息）逐帧拖完，数三样：**从"听到"到"开始动"隔几帧**（真实值通常 8–20 帧）· **几个动作是没做完的**（你会惊讶）· **一处矛盾**（嘴上说的 vs 手在做的）。
> **纪律：只看身体，把声音关掉**——开着声音你会跟着台词走，看不见身体。

**训练 2 · 写一个动作的 5 秒拍序列（不许用情绪词）**
> ❌ `他焦急地等待` → ✅ `看一下表 → 视线没有落回原处 → 手指在桌沿上敲了半下停住 → 换了个坐姿 → 又看门`
**判据**：每一拍单独拿出来都看清是什么动作（同 `motion-control.md` 第 3 节）。练习量：**一个角色 × 五种情绪，每种 5 拍**。

**训练 3 · 延迟训练（拍自己）**——手机拍：**听到"喂"先不动，数 2 秒再抬头**。你会看到**面部先动、眼睛先动**——把观察写进提示词，就是"眼先于头"。

**训练 4 · 反例对照（AI 的假 vs 真人的真）**——各找一条同类型动作逐帧比，**只记三个差**：① 反应延迟各几帧 ② 动作完成度 ③ 同时有几个通道在动。
**这张差异表比任何模板值钱**——它直接给出下一版要改什么。

**训练 5 · 三秒测试（交付前的低成本动测）**——先跑一条 **3 秒、脸占画面 ≥1/4** 的测试（不等整镜）：静音看**他像个人吗？**（不像 → 回第二节）· 三区同拍吗？（→ 第四节 1）· 有延迟吗？（→ 第三节工具 1）。
> 替代不了完整动测（`review-passes.md`），但**成本极低，能拦掉大部分"方向就错了"的版本**。

## 八、速查：一张表走完整个流程

```
① 分诊   僵硬（没信息）还是虚假（太整齐）？       → 第一节
② 驱动   答三句（想看见什么 / 哪背叛 / 哪克制）    → 第二节
        + 五支柱（目标 / 障碍 / 战术 / 节拍 / 潜台词）→ 第二节·补
③ 信号   三区同拍 + 准备-峰值-释放 + 眼生命        → 第四节 / vocabulary
④ 破假   延迟 / 半途修正 / 未完成 / 一处矛盾       → 第三节
        + 结构性：活计 / 距离 / 地位               → 第三节·补
⑤ 对手   正反打分做 + 听的人要动 + 不对称          → 第六节
⑥ 验收   静音看 + 三区同拍 + 有延迟 + 量表 4+      → 第七节训练 5 / vocabulary
```

**量化验收（每镜交付前自评，详表见 `performance-vocabulary.md` 第五节）**：
**★ 本表是摘要，逐字与详表对齐；改详表必须回来同改**（2026-09-17 实测两处已漂移：`反应迟钝`↔`反应迟`、`目标与节拍在`↔`目标与节拍都在`）。

| 分 | 状态 | 判据 |
|---|---|---|
| **0** | 人偶 | 台词到了，行为缺席 |
| **1** | 朗诵者 | "有表现力"的念白、指示式情绪、图解手势 |
| **2** | 勤勉 | 能猜出目标，但单战术、反应迟、空停顿 |
| **3** | 工匠 | 目标与节拍都在、听搭档、身体合理 |
| **4** | **活着** | 连续行为、**战术会换**、潜台词背离台词、**反应先于台词** |
| **5** | 磁石 | 4 分全部 + **悖论**：角色同时是不兼容的两样东西（两真相同在） |

> **每个主角镜头瞄准 4+**。自评在 2 或以下 → **发前重写，不要修**。

## 九、三条最容易犯的错（写在最后，因为最容易忘）

1. **脸太小** —— 表演写在远景里，一个字都读不到。**需要表情就给近景**，这条排第一。
2. **要得太多** —— 一镜塞四种情绪五个动作。**每镜只写一到两个关键动作，写透幅度与节奏**。
3. **拿情绪词交差** —— "她悲伤地"、"他愤怒地"。**模型读不懂情绪词，只有形变可执行。**
   → 换词表在 `performance-vocabulary.md` 第一、三节（按情绪分类的肌肉 / 呼吸 / 眼神）。
