# 剧本诊断：十五类病灶，按层查、按序改

> **何时读**：剧本初稿写完（或写不下去）时。**读完回哪**：回 `script-craft.md` 改稿；回 `drama-structure-models.md` 换模型。
> **一句用法**：**先确诊，再开药**——不知道是哪一层的病就动手改，改的往往是症状不是病灶。

---

## §0 诊断顺序（**先大后小，不可跳层**）

```text
第 1 层 命题与容量  → 命题推不出反面 / 装不下（回去量容量）
第 2 层 骨架        → 缺拍 / 多拍 / 顺序错（换模型或折叠）
第 3 层 场          → 这一场没有功能 / 没有进出差
第 4 层 句          → 台词病灶（六种）
第 5 层 落地        → 概念写得进提示词（可写性三档）
```

**★ 跳层的代价**：第 1 层有病（命题站不住）却去改第 4 层（润色台词），**改十遍台词仍然是同一部烂片**——这是最常见的返工方式。

**改动纪律（与 `prompt-ops.md` 单变量法同源）**：**一次只改一个变量**，改完重读全片。**同时改三处，就永远不知道是哪一处起的作用。**

## §1 十五病总表

| # | 层 | 病 | 确诊判据（答"是"即确诊） | 处方 |
|---|---|---|---|---|
| **1** | 命题 | **命题推不出反面** | 把主旨句反过来，**也成立** | 降到更具体的一对对立（`direction-reasoning.md` §三 可反转测试） |
| **2** | 命题 | **主题被说出来** | 台词里有一句在讲道理 / 讲人生 | 删该句，改由高潮的动作支付（`drama-character-arc.md` §7） |
| **3** | 容量 | **装不下** | 一拍 <8 秒 / 出现第二个反转 / 一场两件事 | **换模型**，别删拍（`drama-scaling.md` §7） |
| **4** | 骨架 | **中段塌方** | 50% 处只有"事情变多了"，没有 stakes 换档 | 加中点：假胜利或假失败 |
| **5** | 骨架 | **被动主角** | 他是**被推进**二幕的，不是自己迈进去的 | 把转折点改成他的**主动且不可撤销**的选择 |
| **6** | 骨架 | **结局没支付** | 结尾的动作与命题没有关系 | 让高潮成为命题的结算（`drama-structure-models.md` §2） |
| **7** | 骨架 | **开场与终场不呼应** | 首尾两镜不是**同一构图 / 同一位置** | 重写终场为首帧的镜像 |
| **8** | 场 | **废场** | 整场删掉，后面的故事**仍然成立** | 删场；或给它一个不可替代的功能 |
| **9** | 场 | **没有进出差** | 人物进场与出场**状态相同** | 给他一个决定，或让局面变一次 |
| **10** | 场 | **静态冲突** | 两人来回嚷嚷，局面**不升级** | 给一次"台词动作翻转"（宣称→施压 / 试探→让步） |
| **11** | 场 | **没有主导问题** | 观众在场上**没有在等一个答案** | 立一个问题，且**把答案推到切点之后** |
| **12** | 句 | **说情绪** | 台词直接讲感受 | 换成可见的行为或一个具体细节 |
| **13** | 句 | **说明性对白** | 双方都知道的事互相讲一遍 | 改成质疑 / 从冲突里露出信息 |
| **14** | 句 | **旁白越界** | 旁白解释了画面已说清的东西，或替观众下结论 | 删；或改成与画面**矛盾**的关系（`drama-dialogue-craft.md` §10 三种主关系） |
| **15** | 落地 | **术语进了提示词** | 提示词里出现"弧光 / 潜台词 / 主题 / 反转 / 悬念" | 走 `drama-aigc-conversion.md` 翻译表 |

## §2 五个"看着像病、其实不是"（**误诊清单**）

**这五条是最容易被自己或他人误判为缺陷的手法**。**判定它们是不是病，只有一个标准：命题需不需要它。**

| 看着像 | 什么时候是病 | 什么时候不是 |
|---|---|---|
| **留白 / 不解答** | 主线也留白了（那就是没写完） | **主线闭合 + 只留一个被看见过的次要线索**（`script-craft.md` 留人三件套 ③） |
| **反高潮** | 前面承诺了"要打"，结尾不打（违约） | 命题本来就是"打不起来"（成长 / 社会寓言） |
| **被动主角** | 从头被动到尾，没有任何选择 | **平弧 C**：主角不变，与世界的关系在变（`drama-character-arc.md` §3） |
| **多义结局** | 观众读成"没交代清楚" | 两条解释**都有画面证据**，且**都能回扣命题** |
| **没有冲突** | 观众不知道自己在等什么 | **起承转合 / 序破急**：靠因果与视角翻转推进（`drama-structure-models.md` §7） |

> **判据一句话**：**观众不是因为没有冲突才走开，是因为不知道在等什么才走开。** 只要"在等什么"清楚，无冲突也站得住。

## §3 每一层展开：三个最常被漏的深层病灶

### 3.1 第 4 病"中段塌方"为什么反复出现

**成因**：`drama-structure-models.md` §4 的 15 拍把它点得很清楚——**Fun and Games（20–50%）是最舒服的一段，写起来最顺，于是被写长；中点被推后，stakes 换档延后，下半场就没有时间翻**。

**处方三步**：

1. 找到真正的中点句：**"从这一刻起，他要面对的问题变了。"** 写不出来 → 中点不存在。
2. 把 20–50% 里**与"前提的承诺"无关**的场删掉（它们通常是"好看的日常"）。
3. 让中点的形式是**假胜利或假失败**，而不是"又发生了一件事"。

### 3.2 第 8 病"废场"为什么自己看不出来

**成因**：创作者**知道这一场在干什么**，所以感觉它有用——这就是 `direction-reasoning.md` §九 第 4 问"陌生观众测试"要防的**信息补偿**。

**处方**：用**外部读者法**读一遍——**删掉这一场，问一个没看过的人："故事还接得上吗？"** 他说接得上 → 这场要么删，要么给它一个唯一功能（`script-craft.md` 接口行的 `叙事功能`）。

### 3.3 第 14 病"旁白越界"是本库最高发的一种

**成因**：写剧本时最容易的补丁就是"再加一句旁白解释"。**旁白每补一次，画面就被削弱一次**——最后变成"有声书的配图"。

**处方**：**先删旁白，再补画面**。删掉后如果故事断了，问题不在旁白，在**前面的镜头缺一个可读信号**（`direction-reasoning.md` §九：**首选补在前一镜的结尾**）。

## §4 诊断记录模板（**每部片一份，进工作稿不进交付物**）

```text
【诊断】第 __ 层
病名：____　确诊判据（引原文句/镜）：____
最小改动：____　（只改一处）
预计副作用（改完可能出现的新问题）：____
改后重读结论：____
```

> **"预计副作用"这一栏不许空**：任何结构改动都会把问题推去别处（把中点前移 → 建置变挤；把台词砍短 → 信息不足）。**写不出副作用，说明还没想清这个改动会连带什么。**

## 来源与署名

- **"删掉测试"· "进出差"· "主导问题与延迟答案"· "陌生观众测试"· 可反转测试**：本库既有方法论，**权威源在 `direction-reasoning.md`**（本文引用并转写成诊断判据，未重复定义）。
- **中点与中段塌方 · 主动选择进入二幕 · 终场画面与开场画面成镜像 · Fun and Games 占 20–50%**：Snyder 15 拍（2005）与其公开整理表述；**"观众无法想象另一个结尾"**与**被动主角毁掉观众纽带**：McKee《Story》通行表述。
- **静态冲突（来回嚷嚷而不升级）之禁 · 渐进改变**：Egri《The Art of Dramatic Writing》通行表述。
- **"观众原谅龙不原谅规则改动"** 类类型承诺判据：类型公开教学表述（见 `drama-genre-casebook.md` 来源）。
- **本库自建**：十五病的**分层归位与确诊判据** · §0 五层诊断顺序 · §2 **五项误诊清单**（"是不是病只看命题需不需要它"）· §3 三处深层成因分析 · §4 诊断记录模板（**"副作用"为必填**）。
- **不采用**：网传的"剧本打分表 / 100 分制自查"。理由：**分数掩盖归因**——同一个低分可能来自命题层也可能来自句层，而两层的改法相反。
