>
> **四份文件的分工（不要互相抄）**：
> - `style-library.md` = **选哪一种风格**（这是什么世界 / 哪种片子）
> - `camera-package-library.md` = **包本身是什么**（17 个主包的器材 / 痕迹 / 运动三行）· 三个档位 · 四个调制层；**选包速查（三问 / 反查表 / 成套句 / 纪律）→ `camera-package-quickref.md`**

## §0 四条铁律（在上述适用范围内使用）

1. **一片一包**：选定后整片不改（含资产图与每一镜）——**中途换包＝观众读到的不是"风格变化"而是"穿帮"**。**唯一例外是"跨世界"条目**（G01 选集式多风格 · G15 混合画幅 · G02 · G03 · G08 · D20）——**那不是"中途换包"，是每一段／每一画幅各自成片**；准入条件见 `stylized-look.md` §二·补2 的四条件。
2. **资产与镜头同包**：角色/场景/道具的资产图**必须与本片方案包同一套器材与痕迹**，否则人像会像贴上去的（→ `quality-layer.md` §三 适配表）。
3. **只有写实系需要包**：**描边系（美漫 / 赛璐璐 / 卡通渲染）与第三系（定格 / 像素 / 油画 / 水彩…）不用任何包**——它们要的是"渲染方式句"，写器材反而会把模型拽回写实（→ `style-library.md` §二）。**★ G 卷（混合媒介）与 D20 不能整条判**：它们**按"层"判**——有实拍层就有包（→ §1 族⑭）。
4. **★ 越"高级"的类型越该用低端包**：**干净的现代影像本身就是 AI 味最重的观感**。恐怖、纪实、回忆、犯罪这几族**主动选"有缺陷"的包**（手机 / 监控 / 家用 DV / 老玻璃），比选最漂亮的大画幅更真（→ `key-decisions.md` C27）。

## §2 五条最容易配错的（反直觉）

| # | 常见的错配 | 为什么错 | 应该改成 |
|---|---|---|---|
| 1 | **恐怖片配 P13 大画幅数字** | 干净的画面里"脏"显得是加上的；恐怖要靠**载体自带的脏** | **P04 监控 / P10 黑白**——缺陷本身是恐惧来源 |
| 2 | **年代回忆配 P08 35mm** | 35mm 是"当年的电影"，**不是"当年的家庭影像"** | **P11 Super 8 / P02 MiniDV**（记忆是家用的，不是放映的） |
| 3 | **西部片配 P13 干净数字** | 西部的可信度来自**尘土、皮革、胶片的颗粒** | **P08 + 白色漫射层**，或 **P14 变形宽银幕**（大远景） |
| 4 | **当代都市配 P09 65mm** | 体量越大，人越小，都市的拥挤感消失 | **P01 手机 / P07 手持 / P14** |
| 5 | **纪录片配"电影感"包** | 越精致越像摆拍 | **P05 转播 / P01 手机 / P06**（自带不需要被相信的理由） |

## §3 调制层：四个叠加层与风格族的搭配

**调制层不单独成包**，叠在已选的包上（→ `camera-package-library.md` §四）。

| 调制层 | 怎么写 | 配哪一族 |
|---|---|---|
| **漫射滤镜（白）** | `有光的地方柔和化开、黑位微抬、整体发一点乳白` | **④ 年代回忆 · ⑧ 类型片（西部 / 公路）· 温情向剧情** |
| **漫射滤镜（黑）** | `只在有光处发光、黑位不抬` | **⑥ 犯罪黑色 · ⑨ 太空 · 写实夜戏** |
| **漂白层** | `高对比、整体去饱和，只有皮肤保留一点暖色` | **⑦ 战争 / 极端处境 / 冷酷题材** |
| **颗粒档** | **不要另写"加颗粒"**——选了包就定了（65mm 极细 · 35mm 细 · 16mm 中 · Super 8 极粗） | 全部写实系 |
| **升降格** | `把这一秒拉成四秒`（**必须写帧率意图**） | 只在叙事需要时叠（爆点 / 神圣化瞬间） |

## §4 三步落地（可复制的工作流）

```
① 定族   → 这个风格"靠什么让人相信"？（§1 左列的判据）
② 取包   → 按 §1 取首选包；把该包的「器材 / 痕迹 / 运动」三行逐字粘进统一提质层
③ 叠层   → 按 §3 叠一到两个调制层；然后才去写资产与镜头
```
**判据（写完自检）**：把提示词读一遍，问 **"这是谁拍的、拿什么拍的、在什么条件下拍的"**——**能答出唯一一个答案**才合格（→ `quality-layer.md` 六问之一）。

## §5 五条纪律与失败模式

1. **不许同一片混包**：`手机随手拍` + `影棚级人像光` = 一个画面讲了两个拍摄故事（→ `quality-layer.md` 第 2 条）。**"干净也行"的题材也别偷懒用默认包——在干净的包里换一个（P13 与 P14 都干净，但一个是平面、一个是变形）。** **例外同上（§0 铁律 1）：G01／G15／G02／G03／G08／D20 的"换"不是混包，是分层——判据是"这一段／这一画幅／这一层自己的拍摄故事讲圆了没有"。**
2. **资产与镜头不同包 = 人物像贴上去**：这是最高频的返工原因。**资产阶段就把包写进提示词，并在全片逐字复用。**
3. **包定了不改，要改整片改**：中途换包只能重出全部资产（→ `key-decisions.md` E22）。
4. **禁忌包的判据是"机制不符"不是"不好看"**：P13 不是差包，是**在恐怖片里它会消掉"载体自带的不洁"**。
5. **拿不准时**：**不要挑默认包**——回 `equipment-selection.md` §六，**六轴各取一个最保守值**；或按族取"可换"列里的第二个。
