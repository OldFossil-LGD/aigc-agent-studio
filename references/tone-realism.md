# 写实缺陷层：影调体系与去 AI 味

> **何时读**：写光影段与质感段（写实向）时。**读完回哪**：回到 `shot-craft.md` 的八层模板。

## 为什么

"暖橙主光 + 青蓝辅光对撞、高反差低调夜景"这类写法是**标准答案**，模型会把它执行成精修概念图：布光完美对称、色彩像拉了 LUT、材质 PBR 塑料化、画面干净得没有生活——这就是 AI 味。
> **为什么"青橙"这个实拍技巧在 AI 里会变成 AI 味？完整因果链见 `color-science.md` §八。**

**新原则：写光的缺陷，不写光的完美。** 模型默认输出"漂亮"，提示词的影调层职责是把"漂亮"拽回"真实"。

## 写实六层物理（自然实拍的完整构成 · 追求极致写实时必读）

写实感的本质：**真实照片是物理世界经过真实光源、真实镜头、真实传感器后的结果**。
AI 味 = 物理的缺失 + 过度完美。六层物理逐层写进提示词，每层给"可执行句式"。

### 第一层 · 光的物理

| 物理事实 | AI 默认做错的 | 可执行句式 |
|---|---|---|
| 真实光源都是面积光 → 阴影有半影渐变带 | 阴影要么硬边要么均匀虚化 | "阴影边缘是一条从亮到暗的渐变带，不是清晰的分界线" |
| 平方反比衰减：远一倍距离暗两档 | 光均匀铺满场景 | "紧挨灯罩的纸页接近过曝，一尺外的桌面已经沉入半暗" |
| 间接光染色：暗部被反弹光照亮并染色 | 暗部纯黑或均匀灰 | "暗部不是纯黑：地板和旧墙面把一点脏暖灰反弹进阴影里，外套的轮廓在黑里仍可辨" |
| 多光源色温混色 → 交界有脏过渡带 | 冷暖分区干净像调色 | "屏幕冷光与台灯暖光在他脸上交界的地方，有一条发灰绿的混色脏带" |

### 第二层 · 皮肤与面孔

| 物理事实 | AI 默认做错的 | 可执行句式 |
|---|---|---|
| 皮肤三层：表面薄反射 / 真皮次表面散射 / 暗部偏暖 | 一层均匀镜面涂层（油脂感/蜡像） | "皮肤哑光打底，逆光时耳朵边缘和鼻翼透出一点红——光透进皮肤又散出来的感觉" |
| 高光是碎的：被毛孔纹理打断的小片 | 大面积光滑镜面高光 | "额头和鼻尖几粒碎高光，高光里能看到毛孔" |
| 真脸靠不对称识别 | 平均脸：对称、标准、无瑕疵 | "右眼比左眼略小，右眉尾一道浅疤，下颌两侧宽度不一，笑的时候只有左边嘴角先动" |
| 瑕疵分布随机且具体 | 无瑕疵或均匀撒点 | "鼻翼两侧泛红脱皮，左颧骨两粒深色小斑，下巴胡茬长短不一其中几根是白的" |
| 头发有碎发飞丝，发缝见头皮 | 头发像一顶整体的头套 | "头顶翘着几缕碎发，发缝处可见头皮，发丝边缘被屏幕光照出细碎的毛边" |
| **皮肤只给一个主导物理状态** | 一次生成里油亮与干燥混着，或根本没给状态 | 六选一：自然半哑光 / 运动后发热 / 潮湿天气 / 灰尘与擦伤 / 冷空气泛红 / 海水浸湿。**状态是"条件"不是"装饰"**，一镜一个，按剧情走 |

**细节预算随景别缩放（写多细，由景别决定）**

| 景别 | 这一档只给这些细节 |
|---|---|
| 全景 / 远景 | 整体肤色与冷暖、暴露在外的皮肤、姿态、轮廓、服装反光——**不写毛孔** |
| 中景 | 手部与衣物的质地、发丝边缘、面部大结构 |
| 近景 / 特写 | 毛孔、绒毛、眼下与唇纹、眉根、局部碎高光、不均匀的肤色 |

**在远景里写毛孔级细节＝无效指令**，还会把模型拽向"假特写"的构图（人物被推得过大）。

### 第三层 · 材质的物理（光落到东西上之后怎么了）

> **与 `physical-feedback.md` 的分工**：那份管**力学**（多重、力从哪来、摩擦、惯性、形变）；这一层管**光学**（光撞上不同材质被怎么处理）。**两套词汇不可互替**——力全写对了，水照样可能像颜料、布照样像纸板。

| 物理事实 | AI 默认做错的 | 可执行句式 |
|---|---|---|
| **菲涅尔反射**：水与玻璃的反射率随视角变——俯视多半透明，视角压到近乎平齐时变成镜子 | 要么一律半透明、要么一律反光 | "俯看水面能看到池底瓷砖；视线压到近乎平齐的那一片水面变成镜子，映出对岸的灯" |
| **焦散**：光穿过水或玻璃后，在下一层表面上留下移动的亮斑 | 光直直穿过，毫无水感 | "水波把光折到池底，浅色瓷砖上浮动着一层晃动的亮网" |
| **表面张力**：液体边缘是上凸的圆角，不是刀切的直边 | 水像画上去的色块，边缘发硬 | "杯口的水面微微上凸成弯月面，贴着杯壁往上爬了一点；每颗水珠各带一粒小高光" |
| **织物各向异性**：丝缎沿经纬反光不同、棉麻带毛羽、皮革沿受力线起细褶 | 布像纸板、像贴在身上的色块 | 按下方材质词表挑一种写 |
| **接触处的颜色溢出**：两个相贴的表面互相染上对方的颜色 | 接触处只有一条生硬的黑边 | "红漆桌面把一层淡红反到白瓷杯底；他按在玻璃上的手指留下一枚指纹和一小片雾" |

**材质词表（一条只挑该镜真正出现的那一种，不铺开列表）**：

| 材质 | 关键词 |
|---|---|
| 丝 / 缎 | 各向异性反光、软垂坠、光泽随角度变化、能看见经纬 |
| 牛仔 | 斜纹织法、边缘磨白、靛蓝染料、垂坠硬挺 |
| 棉 / 亚麻 | 哑光、表面细毛羽、软褶、透气感 |
| 皮革 | 天然纹路、微弱高光、沿受力线的细褶、包浆 |
| 羊毛 | 粗颗粒感、可见纤维尖、边缘一圈柔和毛边 |
| 金属 | 氧化发乌、拉丝方向一致、接触点高光变化 |
| 玻璃 / 陶瓷 | 有厚度、边缘透光、釉面高光聚成一小条 |

**剂量纪律**：材质光学细节**一到两处就够**，写出三处以上，画面就从"真实"翻成"材质渲染演示"（与"不完美只给一到两处"是同一条纪律）。

### 第四层 · 镜头的物理

| 物理事实 | AI 默认做错的 | 可执行句式 |
|---|---|---|
| 胶片高光渐进滚降 + **halation**（高光向周围渗出橙红晕）——胶片感最大来源 | 高光硬截断、锐利刺眼 | "灯丝和屏幕的高光向周围渗出轻微的橙红色光晕（halation），像老胶片的过曝" |
| 暗角与边缘色差 | 全画面均匀清晰 | "画面四角有轻微的暗角，高反差边缘带一点紫边" |
| 180° 快门：动作带方向性动态模糊 | 动作帧帧清晰如定格 | "打字的手带一点与运动方向一致的动态模糊" |
| 对焦呼吸 | 对焦无声无息 | "焦点偶尔呼吸一次再拉回" |

### 第五层 · 运动的物理

| 物理事实 | AI 默认做错的 | 可执行句式 |
|---|---|---|
| 惯性：起停有加减速，没有匀速 | 匀速机械运动 | "打字节奏不均匀：快几秒、停半秒、再快——真实打字者的节奏" |
| 重量：动作前重心预移，落手有质量 | 轻飘无重量 | "手掌落下时带出肩膀的一点点下沉" |
| 禁表面滑动：物体转动时纹理必须跟着转 | 纹理不动只有轮廓动 | （发现滑动即判废片，重生成） |
| 布料与头发有跟随延迟（drag） | 布料头发焊在身上 | "他转头时外套的领口慢半拍才跟着转" |

### 第六层 · 参考锚点（写实的根，比"写实"二字有效十倍）

"写实"不可执行，**真实存在的摄影传统才可执行**。按场景类型选锚：

> **一条反直觉的前提**：对"真实感"而言，**过于干净、过于工整本身就是破绽**——"电影式完美构图 + 设计过的运镜"是最容易被一眼认出是 AI 的长相。所以下表里"手持""直播"两档不是"降级"，它们是**专门用来拆掉工整感的**；想要"活的真实"时优先选它们，而不是选最漂亮的电影感。<br>
> 同理：**完全静止的机位与大幅度的电影式运镜都不写实**——前者把观众的注意力全推到背景微动与人脸瑕疵上，后者是 AI 最擅长的"表演型运镜"、最容易露馅。写实向的常态是**小幅、不完美、理由充分的机位存在感**。

| 场景 | 锚点句 |
|---|---|
| 夜戏通用 | "像用柯达 Vision3 500T 电影胶片拍的：高光有橙红色光晕，暗部颗粒粗活" |
| 手持/纪实行进 | "像独立纪录片的单手持机摄影师在拍，画面有呼吸和轻微的寻找感" |
| **直播 / 现场转播**（"太工整"的解药） | "像一台固定广播机位拍下的现场素材：构图略偏、摄像师一直在微调着把主体拉回画面中间、画面带轻微压缩伪影与隔行颗粒——**没有一处是设计过的电影式运镜**" |
| 面孔写实 | "像纪实摄影里抓拍的真实路人，不是广告模特，不是精修人像" |
| 中国县城/老楼质感 | "像中国县城老写字楼里手机随手拍下又经过胶片调色的素材" |
| 办公室夜戏 | "像《铁西区》式的工业纪实光影，只是换了办公室" |

**完整参数库与"电影质感 vs AI 漫剧"判定标准 → `cinematic-look.md`**（胶片 / 摄影机 / 镜头型号可查，颗粒与高光的正确台词，减法提示原则，机械呼吸感，漫剧黑名单）。本节锚点句只做速用，写重要镜头时从参数库取精确项。

**量级统一纪律（重要）**：**全片只定一套量级**，来自 `quality-layer.md` 第二节的逐字复用块——`[本片方案包：把选定包的「器材」行逐字粘在这里]`。**摄影与印片那两行没有固定值**（先按 `equipment-selection.md` 选包，见 `camera-package-library.md`），**禁再写死 ALEXA 35 + Cooke S4/i + 2383**。上面这些锚点句是"这一部是哪种气质的电影"的候选（写实向 / 年代回忆 / 工业纪实），**选定一个就全片沿用，不逐镜自选**；同一条提示词里更不许出现两套以上体系（16毫米 + VISION3 500T + 变形宽银幕 = 模型色彩混成一锅，出来必是 AI 感）。

## 人物光影与皮肤（去油脂感 · 最高优先级）

实测反馈的三大人物缺陷，比环境问题更毁真实感。每镜提示词在场景影调段之后，**必须**追加"人物光影块"：

| 问题 | 成因 | 修法 |
|---|---|---|
| 油脂感 | 模型把"电影感人像"执行成商业精修：皮肤整体油亮、磨皮、蜡像 | 明确写哑光皮肤：毛孔/细纹/胡茬/泛红/色斑可见，高光被纹理打断 |
| 高光不对 | 高光面积过大、位置错、锐利如塑料镜面 | 高光只许在鼻尖/眉骨/颧骨顶各一小片，面积不超过指甲盖；眼睛只留一粒眼神光 |
| 人物光影不对（光不接） | 脸被"默认美颜光"照亮，与场景光源脱节，像贴上去的 | 人物的光**只能来自画面内的光源**：方向/色温/强度与场景一致；暗面沉入与背景相同的黑；影子方向随光源 |

> **★ 这一节只管"该写什么"。另外三层在别处——写皮肤前先知道去哪**（2026-09-16 补 · 全面审计查出**写作路径够不到那两份深册**）：
> · **症状 → 根因 → 改哪句**（油亮 / 蜡像 / 高光成片 / 褶皱乱走 / 磨皮感 / 疤痕看不见…）→ **`skin-realism.md`**（含**判据 S1–S6** 与处方表）
> · **皮沟（肌理）的解剖与区域差异 · 肌理的年龄曲线 · 疤痕的光学差异 · ★ 肌理的三档可达成边界** → **`skin-light-physics.md` §五–§七**
> · **一条最省钱的判据**：**"肌理"在提示词里只能写成"区域与分布"，不能写成"结构"**——**写成结构的词模型接不住**（1K 级 VAE 压缩下高频道根本没被存，解码器只会"重建"不会"生成"）；**换光位 / 换景别 / 上分辨率，比换形容词有效。**

### 人物光影块模板（每镜必带，按光源替换方位与色温）

```
人物光影必须与场景光源完全一致：
他脸上的光只来自画面里那盏台灯——右前方、低角度、暖橙、近而硬，
亮面在右脸和鼻梁，左脸和后颈沉入与背景相同的黑，暗部细节靠噪点若隐若现；
他的影子落在桌面上，方向与台灯位置一致；
皮肤是哑光的，毛孔、细纹、胡茬和泛红清晰可见，高光被这些纹理打断；
高光只是小点：鼻尖、眉骨、颧骨顶各一小片，面积不超过指甲盖，不是光滑的镜面反光；
眼睛里只有一粒来自台灯的眼神光；
禁止：蜡像般均匀油亮的皮肤，大面积镜面高光，磨皮质感，
无来由的正面补光，人物比环境亮两挡以上，脸和身体的光不统一。
```

| 禁用写法 | 替代 |
|---|---|
| "皮肤细腻有光泽" | "皮肤哑光，毛孔细纹胡茬可见，高光被纹理打断" |

## 七条铁律（环境级）

1. **接近单色的昏暗优先**：整场戏色彩收敛到近乎单色，冷暖只渗一点点；不做轮廓光、不做辉光、不做双色对撞。
2. **光池小而脏**：只照亮必要一小圈；光衰减不均匀；大片死黑 + 雛星漏光斑 + 灯罩边缘漏光。
3. **逐件写脏**：金属氧化发乌带绿锈 / 木头磨白与色斑 / 纸张黄一块白一块卷边 / 皮肤不均匀油光、松弛褶皱、老年斑 / 布料磨白补丁石墨灰。
4. **生活痕迹强制**：杯渍圈、散乱纸片、灰尘、歪斜物件、笔筒杂笔、胶布缠过的破损。
5. **摄影不完美**：暗部是有机银盐颗粒簇（暗部粗、中间调细）而非均匀数码噪点 / 高光轻微过载但仍保留暖色而不裁成纯白 / 写字的手带一点快门运动模糊 / 画格边缘轻微彗差 / 轻微机械片门晃动与镜头呼吸 / 稳定器跟随但保留人体呼吸浮动。
6. **明确禁止**：完美对称布光 / 概念图或海报式构图 / CG 渲染塑料感 / 均匀漆面 / 三视图摆拍 / 倒影里的人。
7. **首帧同规**：首帧静帧按同一影调出，首帧不对味后面全废。

## 影调段模板（每镜末尾追加，按环境替换）

### A. 室内·单台灯夜戏（信号站/值班室/老屋）

```
这是一场接近单色的昏暗夜戏，画面里只有一处暖光，来自右前方那盏老台灯：
光池很小，边缘发脏，只够照亮桌面一圈和主角的手，
光往墙上衰减得很不均匀，墙上大片区域是照不到的死黑色，剩下的部分有零星杂乱的反光斑和漏光；
灯罩边缘漏出一缕散射光，灯下的浮尘让光柱发灰发闷；
雪夜冷光只从窗缝渗入一点点，给窗框和霜花一点青灰，不给人物打轮廓光，不要渲染用的辉光。
色彩不一致：铜件氧化发乌带绿锈，桌面有深浅不一的磨白和一圈圈杯渍，
纸张黄一块白一块边角卷曲；皮肤有不均匀的油光、松弛褶皱和老年斑。
暗部是有机银盐颗粒簇（暗部粗、中间调细），高光平滑滚降、轻微过载处仍带暖色不裁成纯白，
手部动作带一点点快门运动模糊，画格边缘有轻微彗差和镜头呼吸，画面带轻微的机械片门晃动。
构图不对称，桌面留有生活痕迹：歪着的杯渍圈、散乱旧纸片、灰尘、胶布缠过的破损。
```

### B. 雪夜·窗边

```
冷光从结霜的木窗渗入，色温高但强度极弱，只够勾出物体朝窗一侧的边缘；
霜花从窗框向中心生长，玻璃上有旧裂痕和指印；
窗外雪景模糊发灰，失去锐利细节；
室内其余区域沉入死黑，只有暖光源所在的小范围可辨；
冷光与暖光在地面交界处有一条模糊脏乱的过渡带，不是干净的明暗分界。
```

### C. 夜街·霓虹

```
霓虹只照亮湿路面的一小片水洼，反光碎裂不均匀；
主光来自招牌但多数灯箱半坏闪烁，明暗节奏不规律；
墙面有涂鸦、水渍、空调外机滴水锈痕；
人脸上霓虹反光只打在一侧，另一侧沉入街道的杂光里（车灯、橱窗、远处路灯混色不纯）；
空气有雾感，远处光源发晕。
```

### D. 白昼·外景

```
日光硬而偏斜，影子短且方向不一致（多云导致）；
地面反光脏：尘土、水洼、脚印打破干净反光；
皮肤高光有汗感，阴影里不是纯黑而是环境反光的脏青灰；
风持续作用于衣物和植物，让它们一直摆动；
远景有热浪扰动或灰霾，空气浑浊。
```
