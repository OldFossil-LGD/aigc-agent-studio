# 剪辑节奏与轴线：**把"剪得顺不顺"变成可量的东西**

> **何时读**：排镜表出来之后、成片拼起来之后；**"这条片看着累 / 看着平"但说不出哪里不对**时。
> **读完回哪**：回 `post-production.md`（处理与包装）· `transition-library.md`（转场类型）· `cross-shot-interface.md`（拼接点）。
> **★ 本册是剪辑节奏的权威源**：`post-production.md` §六 原有的量化基准**已迁入本册**，那边只留指针。
> **★ 为什么单列**：`节奏点` / `ASL` / `节奏密度` / `切点密度` / `节奏诊断` / `30 度原则` / `180 度` **全库此前各 0 命中**——
> **"节奏"在本库一直是个形容词，不是个可量的东西。**

---

## §1 ★ 两个可量的词（先有度量，才谈节奏）

| 词 | 定义 | 怎么用 |
|---|---|---|
| **ASL**（平均镜头长度） | 总时长 ÷ 镜头数 | **它是这条片的"底色"**——先看 ASL，再看它怎么起伏 |
| **节奏密度** | **每 10 秒的切点数** | **看它是不是一条直线**——**恒定＝大脑脱敏＝平** |

**★ 基准（迁自 `post-production.md` §六，原口径不变）**：
- **短视频平均镜头时长 1.8–2.2 秒**；**AI 短片单镜 2–3 秒为黄金**；
  **核心镜 3s · 过渡镜 1.5–2s · 空镜 1s**。
- **★ 变化本身制造吸引力**（大脑对恒定脱敏）——**这条比任何一个具体数字都重要**。

**★ 怎么客观地数「切了几刀」（2026-09-20 实测可用）**：`ffmpeg -i <片> -filter:v "select='gt(scene,0.30)',showinfo" -f null -` → 输出一串 `pts_time`，**每一处就是一次真硬切**。
判读要点：**段内换画面若走连续式（变焦 / 推拉）不会触发** → 所以「检测到 N 处」＝**硬切数**，正好用来核段落版的「恰好 N−1 个切换点」；再抽关键帧确认景别弧线。**比人眼数镜可复现**（阈值 0.30 起步；光大幅变化会误报，须抽帧复核）。

## §2 ★ 情绪 → 公式 → ASL（**照填表**）

| 这一段的情绪 | 用哪套公式 | ASL 落在哪 | 注意 |
|---|---|---|---|
| 建立 / 日常 / 铺垫 | **① 呼吸式**（快 3 短 + 1 长） | 2–3s | 通用款，最不容易出错 |
| 悬疑 / 追问 | **② 心跳式**（均匀 → 加速） | 由 2.5s 压到 1.2s | **加速要有终点**（不然只是累） |
| 情感 / MV / 回忆 | **③ 海浪式**（渐强 → 平静） | 由 3s 拉到 5s+ | 靠**长镜本身**给情绪留位置 |
| 高潮 / 爆点 | **④ 子弹时间**（慢动作 → 爆发） | 慢 2s + 爆 0.5s | **快慢对比越大越有效** |
| 预告 / 蒙太奇 | **⑤ 脉冲式**（越切越快 → 定格） | 逐段递减到 0.5s | **最后必须定格**，否则像没剪完 |
| 恐怖 / 惊悚 | **⑥ 静默锤击**（长静 → 重击） | 长 6s+ 然后 0.3s | **静默段不许有切**，否则不成立 |

> **★ 六套公式逐字迁自 `post-production.md` §六**（权威源现在在本册）。

## §3 ★ 节奏诊断四问（**成片后跑，能答"哪一段平"**）

```text
① 这条片的节奏密度曲线，是一条直线还是起伏？（直线＝平）
② 最长的那个镜头，是"有意留白"还是"没素材补"？
③ 最短的那个镜头，是"冲击"还是"闪一下看不清"？（<0.5s 通常读不出来）
④ 有没有连续 3 个镜头时长几乎相同？（有＝这段会读作"机械"）
```
**★ 判据一句话**：**"把每个镜头的时长画成一条折线——它好看吗？"**
**★ 最快的修法**：**把某两个相邻镜头的时长对调**（不动内容，只动长短）——**常比重新剪一遍有效**。

## §4 ★ J-cut / L-cut：**声音与画面不同时进出**（库里各只 3 册，太薄）

| 名字 | 做法 | 用来干什么 |
|---|---|---|
| **J-cut**（**声音先入**） | **下一镜的声音先响**，画面还停在本镜 | **预告**（观众先听见，再看见）· 让转场"有机" |
| **L-cut**（**画面先出**） | **画面已经切到下一镜，上一镜的声音还在** | **留连**（人走了话还在）· 情绪延续 |

**★ 两个都是"跨拼接点"的操作**——**写在 `【声音】` 与 `【进入下一镜的过渡压力】` 里**（`cross-shot-interface.md` §2 的听觉接口）。
**★ 一句判据**：**"这一段的声画是不是同时进出的？如果一直是，试试错开半秒。"**

## §5 节拍对位：**"切在拍上"的判据**

**做法**：把选定的音乐铺在时间线上，**在每一个剪辑点上检查"是否有一拍落在该时间戳 100 ms 内"**；
**落上了 → 不要再叠额外的旋律标记**（会打架）；**没落上 → 这一刀要么挪到拍上，要么故意反拍**。

**★ 三种选择（没有一种天然更好）**：
- **切在拍上**：顺、稳、观众不察觉（**默认**）；
- **切在反拍**：紧、不安（**悬疑/动作**）；
- **故意不踩拍**：让画面"挣脱"音乐（**情绪爆发**时用，**一场最多一次**）。

**★ 与平台的接口**：Seedance 的 **beat-sync（卡点）** 是平台原生能力（`platform-matrix.md` §八）——
**平台原生能做时优先用平台**；不行才手动对位。

## §6 ★ 三种衔接（`匹配剪辑` 4 册，但**没拆成这三种**）

| 衔接 | 接什么 | 例 |
|---|---|---|
| **动作衔接** | 同一动作跨镜继续 | 上一镜抬手 → 下一镜手已经落下 |
| **视线衔接** | 上一镜"看" → 下一镜"被看的东西" | 他抬眼 → 切线到门外 |
| **形状 / 颜色衔接** | 两个画面里有相似的形或色 | 圆形表盘 → 圆形灯 |

**★ 用法纪律**：**三种里选一种，不要同时接三种**（同时接＝炫技，观众出戏）。

## §7 ★★ 两条轴线硬规则（**全库此前 0 命中，本册补**）

### 7.1 **180 度线**（轴线规则）

**定义**：一场戏里，**机位必须待在"关系线"的同一侧**——线的一侧是"他在左、她在右"，越过线就变成"她在左、他在右"，观众会瞬间失去方位感。

**可写进提示词的判据**：**"这一场所有镜头的机位都在这条关系线的同一侧"**（`staging-craft.md` 的关系方位那一栏就是这条线的落点）。
**★ 什么时候可以**破**：**要的就是"错位感/失序感"时，且**破一次就够**（连破两次＝乱）。

### 7.2 **30 度原则**

**定义**：**同一主体、同一景别下，两个相邻机位的夹角应当 ≥30°**（否则两个画面太像，剪起来像"跳帧"）。
**★ 它和"景别落差"是两条不同的规则**：
- **景别落差**管"大小变没变"（`sequence-craft.md` 九级景别）；
- **30 度原则**管"角度变没变"。
**→ 两条都要满足**：**同景别时必须换角度 ≥30°；同角度时必须换景别。**

**★ 一段可直接用的自查**：
```text
相邻两镜：景别变了没有？角度变了没有？
两个都没变 → 这一刀必跳（观众读作"卡了一下"）
```

## §8 失败模式（**照这个改**）

| 症状 | 根因 | 改法 |
|---|---|---|
| **看着累** | 节奏密度是直线且偏高 | 插一个长镜（呼吸） |
| **看着平** | ASL 全程一致 | 用 §2 挑一套公式**重排**时长 |
| **像卡了一下** | 违反 30 度原则（同景别同角度） | 换角度 ≥30°，或换景别 |
| **方位乱了** | 越了 180 度线 | 把机位挪回同一侧（或**正式破线**并给理由） |
| **剪得"机械"** | 连续 3 个镜头时长几乎相同 | 对调其中两个的时长 |
| **情绪没起来** | 高潮段没用快慢对比 | 慢镜 2s + 爆发 0.5s（子弹时间） |
