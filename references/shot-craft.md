## 五段式提示词协议（通用 · 适用于镜头/场景/道具/角色一切类型）

从优秀实拍系提示词中提炼的**通用协议**——不管写镜头、场景、道具还是角色，都走同一条五段结构，区别只在各段填什么：

| 段 | 镜头版 | 场景版 | 道具版 | 角色版 |
|---|---|---|---|---|
| **① 置景** | 画面内主体+环境+画外触发 | 空间布局+全部陈设+边界与出入口 | 道具本体：年代/材质/尺寸/逐处磨损 | 人物+服装+随身物+标记 |
| **② 调性** | 类型/时代/时段天气/内外景 | 同左 | 同左（道具的年代与来历） | 同左 |
| **③ 镜头** | 画幅/格式/焦段/光圈/机位视角/构图法/引导线/前中后景层次 | 景别与机位/构图法/引导线 | 多视角组合/微距/比例锁定 | 设定板分区/姿势/视角 |
| **④ 光影** | 光现象列表+主辅光源+人物光影块 | 场景光源逻辑+光池衰减+混色脏带 | 摄影棚暗调布光+接触阴影 | 中性光（资产）或场景光（首帧）+人物光影块 |
| **⑤ 后期** | 特效清单（体积雾/光穿透/高光处理）+调色方向+颗粒+渲染质感参考 | 大气透视+体积雾+调色 | 轻微（静物质感即可） | 轻微（颗粒即可） |

**提炼出的通用规律**（这是协议的魂，不是格式）：

1. **元素罗列法**：把画面里"能看见的每一样东西"罗列出来，每样具体到材质/状态/位置——"废弃神庙与金字塔式石塔、仰望飞船的人群、山脉天际线、残垣断壁与藤蔓"。模糊的"废墟场景"不可执行，罗列可执行。
2. **调性四元组**：`类型 / 时代 / 时段与天气 / 内外景`——四个词定调，先于一切描述（"科幻史诗 / 近未来与古代文明遗迹并建 / 黄昏 / 外景"）。
3. **镜头参数化**：画幅比、焦段、光圈、机位视角、构图法、引导线、前中后景层次——每一项都是明确参数，不留"电影感"这种空词。
4. **色彩对照法**：色板写"3-4 个色系 + 对照关系"（"低饱和灰、烟紫、灰褐与雾粉色，辅以冷青色光源"），并写明主光/辅光/光源逻辑。
5. **后期清单化**：特效按元素罗列（体积雾、烟尘、光线穿透、高光增强），最后给渲染质感参考（胶片/物理渲染/数字合成）。
6. **禁止项收尾**：与写实缺陷层负向清单合并。

**与写实六层物理的关系**：五段式是**结构协议**（骨架），写实六层物理是**内容标准**（第四段光影与质感段的填充物）。两者叠加使用：结构照五段填，光影与质感段按六层物理写。

## 单镜整合脚本模板（**单机位模式** · 骨架 · 项序固定，不可倒置）

> **这是"一条一个机位"的模板。**
> 想**一条里就换景别 / 机位**（15 秒 3 个景别那种），用 `references/segmented-shot.md` 的分段镜模板——
> 本模板的【运镜】块**显式排除了同族运镜**（无拉出、无摇、无环绕），
> **拿它去写多景别，出来必然是缓推**。这是"只会缓推"的直接原因。
> 走分段镜时，**每一镜的内部仍按本模板的镜内纪律写**（一镜一个运动、镜内锁景别、镜内排除同族）。

项序固定，`[ ]` 为替换变量：

> **★ 板块分两区，顺序不可倒置**：**先写「全片通用」三块（标着"每一镜逐字复用、不改字"），再写「本镜专属」九块**。　**★ 每块的功能 / 目标 / 输入 / 输出 / 依赖 / 边界 / 约束 → `references/block-spec.md`（12 块接口规格）**　**★ 第 7、9 块各带一条"真实性下限"（不许省）**：**第 7 块**带**个体化三点里的面部那一处**（**只许一处**，相对量写法）与**静息微动的体态句**；**第 9 块**带**生理活性**（瞳孔 / 眨眼 / 呼吸至少两样，且**不是恒定节律**）→ `references/character-realism.md`
> **为什么前置**：这三块是**全片级**的（它们一改，全片观感就断），写在最前 = **每次复制粘贴时不会忘改**；
> 而本镜专属的九块**每镜都不同**，跟在全片块后面，读的人一眼能分清"哪几句要改、哪几句不许动"。
> **代价**：全片块会把【人物与环境】【光位与影调】推后，**位置权重下降** ——
> 所以**全片三块要写紧凑**（去掉解释，只留可执行项），**别把它们写成最长的部分**。

> **★ 2026-09-14 口径改动：镜头按顺序写，不按秒数写。**
> **秒数不写进提示词**——**按「段落 / 组合」写（段落A / 段落B / 段落C），⛔不写「镜几」**，时间由模型自己分配（写死秒数＝把它的节奏钉死，且一改就要全文重算）。
> **唯一保留的秒数是首行总时长**（那是平台硬约束）。**排镜表仍要时长列**（节奏数学靠它）——**秒数只活在排镜表，不活在提示词**。

> **★ 模板使用契约（写之前先看这四条）**
> ① **块内只许提示词本身**——无注释、无"（改成你的…）"、无元说明、无 markdown 强调与装饰符号（`**` / `★` / `①` / `✅`）；**不写秒数**（唯一保留的是首行总时长）。
> ② **块不许删**——本镜不适用时写 `本块不适用：N.A.（原因 + 替代）`；**空块也要把该块的必需元素写全**（例：【声音】N.A.＝"本条静音，无配乐、无环境音"）。
> ③ **冲突时的优先级**：全片通用三块 ＞ 本镜专属九块；同一块内 **安全与禁止 ＞ 物理 ＞ 风格 ＞ 偏好**。
> ④ **粒度**：每块 1–3 句；整条建议 ≤ 8000 字符（超了先删形容词，不删约束）。

### ★ 器材要译成效果（**别只丢型号给模型**）

**问题**：`Kodak VISION3 500T`、`柯达 2383 印片`、`ARRI 435` 这些是**行业术语**——**模型不一定知道它拍出来什么样**，很可能只当普通词读过去。

**规则**：**器材行里的每个型号后面，用括号补一句"它拍出来什么样"**；
**判据一句话**：**把型号全部划掉，剩下的那句还能不能说清"这部片看着像什么"？** 说不出 → 效果句没写。
⚠️ **括号里放的是"效果"，不是编号**——`Kodak VISION3 200T（5213）` 是反例（`cinematic-look.md` §三 开头已写明）。

```
❌ 括号放编号：Kodak VISION3 500T（5219）—— 模型不认识，等于没写。
✅ 型号 + 效果：摄影与印片：35mm 摄影机（ARRI 435）· 定焦 · Kodak VISION3 500T

```

**型号 → 效果从哪里取**：`cinematic-look.md` §三 的四张表（胶片 / 数字摄影机 / 镜头 / 印片）**每张都有"特性"列，那一列就是效果句的来源**——
**不用另建对照表**（细节集中一处，其余改指针）。

### ★ 焦段也要译成结果（**同一条规则，2026-09-17 补齐**）

**问题（自查发现的真实缺陷）**：上面那条规则只管**器材**，于是稿子里出现**只写"35 毫米"就当写完了**的写法——
而**焦段是这一段里唯一直接决定"空间关系长什么样"的参数**，写个数字等于没写。

**规则**：**写了焦段，就要补它带来的看得见的后果**——取景关系、透视/压缩、前后景比例、移动时的视差。
**判据一句话**：**把那个毫米数划掉，剩下的字还能不能说出"这一镜看上去空间是什么样"？** 说不出 → 只写了标签，没写结果。

```
❌ 只写标签：35毫米，光圈 f2.0。
✅ 标签 + 结果：约 35 毫米（中等广角：人物与房间的关系保留，近处桌角有轻微透视放大，
   背景仍可辨认，他走动时前后景有自然视差），光圈 f2.0。
```

**⚠️ 别拿"景深"顶替**——`中等偏浅景深` / `f2.0 浅景深` 是**光圈**的后果（虚化程度），**不是焦段的后果**。
两者都要有：**焦段给空间关系，光圈给虚实分层**。
**⚠️ 反差最大的两处**：**广角端**（约 28 毫米及以下）要写**边缘拉伸与前后景比例夸大**；
**长焦端**（约 85 毫米及以上）要写**压缩感与人物从背景里被"拔出来"**。
> **来源与判据归属**：本条**不是外部发明**——它是本册上一条「器材要译成效果」**同一条规则在焦段上的补齐**（自查发现规则只管器材、漏了焦段）。
> 外部材料（Higgsfield 开源项目《Hell Grind》的 CINEDANCE 技能）给了一句同义表述："**焦段也要写出结果——只写'35mm 电影镜头'，模型得到的信息很少**"，**与我们的判据同向，故并入**。
> 机检：`audit_prompt.py blocks` 对「【镜头规格】有毫米数、却没有焦段专属结果词」报 WARN。

### ★ 度打头，毫米放括号（**2026-09-17 外部学习后补 · 一手引用**，证据评级见节末）

**问题**：毫米数是**行业内部语言**，模型对它的读法是"**建议**"；而**视场角（度）是它能"咬住"的锚值**。
外部一手源原话（`cinema-director-v3` · Higgsfield 站上公开技能）：
> **"The model latches onto degrees as a snap value; millimetres read as suggestion. Write the degree first, mm in parentheses."**

**规则**：**【镜头规格】里焦段写成「视场角（毫米）」，度在前、毫米在括号里**——`84°（22mm）`，不是 `22mm`。
**配 §十档对照表**（带"观感"与"用来干什么"，**这两列才是"译成结果"的取词处**）：

| 视场角 | 毫米 | 观感 | 用来干什么 |
|---|---|---|---|
| 180° | 鱼眼 | 球面鼓胀 | 主观视角 / 梦 / 幻觉 |
| 107° | 14–16mm | 建筑级超广 | 巨大室内尺度 / 史诗建立镜 |
| **84°** | 20–24mm | 经典广角 | 全身走位 / 沉浸动作 / 环境建立 |
| 63° | 28–35mm | 报道式广角 | 观察、并肩走、纪录片感 |
| **47°** | 40–50mm | 眼平中性 | 万能中景 / 双人 / 腰以上 |
| 34° | 60–70mm | 短焦长焦 | 压缩的人群 / 层叠的深度面 |
| 29° | 75–85mm | 肖像压缩 | 孤立胸像 / 手部细节 / 紧覆盖 |
| 18° | 100–135mm | 肖像紧 | **保身份的close-up** / 情绪停住的一拍 |
| 12° | 180–200mm | 长焦细节 | 手部插入 / 物件 / 首饰 / 质感 |
| 8° | 300–400mm | 极长焦 | 远处锚定观察 / 瞭望塔 |

**★ 非常规视场角要带"防御组"**：长焦若不明文声明它不是什么，**会被平均回正常镜头**——
写长焦时带上：`强压缩、透视压扁、背景被拉近并糊掉、同时只有一到三张脸是清晰的、裁切紧`
+ `不是广角、不是大画幅覆盖、不是鱼眼、没有边缘畸变、不是深焦、不是全景覆盖`。**超广角反向同理。**
> **来源**：`cinema-director-v3`（站点公开技能 · 一手，原件见 `outputs/higgsfield_skills_原件/`）。
> **★ 证据强度 = 多源（2026-09-17 全量验证）**：273 份有正文的社区技能里，**31 份**用了"用视场角/degrees 描述镜头"的同类写法 → **真实存在但不是主流**，属**少数高质量件共有的做法**（`governance-law.md` L6：记为「拟订」，可改）。
> **机检**：`audit_prompt.py blocks` 对「【镜头规格】有毫米数、却没有度数」报 WARN。

### ★ 写多少的**分配与上限**（2026-09-17 地毯式搜索后补）

**为什么这条重要**：本库一直在给"**下限**"（逐处写脏 ≥2 处、每项必带、皮肤要毛孔……），
**从来没有给过"上限"**——于是很容易写成"面面俱到"，而**面面俱到＝没有重点**。

#### ① 分辨率感知三问（决定"这个细节该不该写"）

写任何可见细节之前，先问三句，**有一句为否就删掉**：

| # | 问 | 例（200 英尺外、120 迈的车） |
|---|---|---|
| 1 | **在这个距离，真实的电影镜头分得清这个细节吗？** | 否 → 侧贴纸 / 挡风文字 / 轮毂幅数**全部删掉**，只写"剪影 + 色块 + 头灯 + 运动拖影" |
| 2 | **在这个运动模糊程度下，这个细节读得出来吗？** | 否 → 同上 |
| 3 | **在这个布光档位下，这个细节看得见吗？** | 夜里只有一盏实用光时 → **毛孔、绒毛、微表情全部不可见**，只写"脸型 + 眼神光 + 被光扫到的关键衣物" |

**★ 判据一句话**：**细节是靠"相机距离 / 焦段 / 静止度 / 光强"挣来的，不是靠"它真实存在"挣来的。**
（同一辆车停在 20 英尺的静止特写里 → 贴纸、文字、轮毂**都可以写**。距离变了，可写的就变了。）

#### ② 密度分配（决定"哪里细、哪里粗"）

| 必须**细**（写到位） | 必须**粗**（少写） |
|---|---|
| 身份锚点 · 空间阻挡 · **第一帧** · 视线 · 地标邻近 · **手的状态** · 道具状态 · 定时动作 · 光学 · 灯光锁定 · 物理 · 对白 | 泛化美感描述 · 非关键服装细节 · 背景群演 · 非活动道具 · **参考图里已经明显的东西** |

**★ 一句话**：**"不要用装饰性形容词把提示词变长——改进来自更强的信号，不是更多的膨胀。"**
**★ 与"单点变量"的关系**：改稿时**只改一个变量**；而**定稿时**按上表分配密度——**该细的细到底，该粗的一句带过**。

> **证据强度（`governance-law.md` L4·补2）**：**单源**（① `3/273`，② `1/273`）。
> **走「机制可独立论证」门槛**：① 是**光学分辨率的物理事实**（距离/焦段/运动模糊决定可分辨性），不依赖来源；
> ② 是本库既有**"注意力稀释 / 关键信息放首尾"**规则的直接推论。**两条按 L6 均记「拟订」**。
> **来源**：`banana-pro-director-3-0`（RESOLUTION-AWARE DETAIL RULE）· `seedance-prompt-director`（CINEDANCE V4 · Prompt density control）。

### ★★★ 写完之后过一道「拆镜开关」（**分镜版（＝单机位镜）** · 这一镜装得下吗？）

**一镜 = 一次独立生成 = 一条一个机位。** 写完一镜的【时间线】，**回读一遍，问四个问题**：

| 问 | 命中就拆 |
|---|---|
| ① **画框换过没有？** | 景别出现 **≥2 级**的变化（例：超大远景 → 特写）→ **拆** |
| ② **轴线 / 机位换过没有？** | 主体关系变了（两人同框 → 只剩一人 / 换到另一侧 / 越轴）→ **拆** |
| ③ **动作数超过一个没有？** | 把动作名说出来是**两个动词**（不是一条动作的两个阶段）→ **拆** |
| ④ **时长超过单镜上限没有？** | 内容要 2–3 秒以上才说得清 → **拆** |

**★ 一句话判据**：**画框换过？轴线换过？动作超过一个？——三个都没有，留；有一个有，拆。**
**反过来不用拆的**：同机位、同轴线、同一件事；景别只做 ≤1 级微调（「收近一档」）；一条连续动作的推演（他先抬手，随后停住）；只是状态在变（呼吸、眼神、尘落）。
**★ 拆出来的新镜头 = 另一次独立生成** → **通用 3 块照抄、专属 9 块重写**，不许只改时间线。**★ 拆 ≠ 写得更细**：拆是「多生成一次」。
⛔ **不许用「他先…；随后…；最后…」把装不下的内容压进同一个镜**——那是**段落版（＝分段镜）**的做法（一次生成里多画面）。**分镜版超载只有一个出路：拆。**

## 六条硬规则（从主流模型官方与一线实践提炼 · 逐条查）

| # | 规则 | 怎么写 | 为什么 |
|---|---|---|---|
| 1 | **开场先给风格标签行** | 3–6 个标签用 `\|` 分隔，放在最前（单镜模板可并入首行风格槽，见 §模板首行）：`粗粝硬科幻 \| 雨中码头 \| 战损美学 \| 后末日实拍` | 一段散文风格描述会被稀释，标签串是密集的锚点，且**位置最靠前** |
| 2 | **摄影机三行写全** | ① 单机位还是分段镜（`一镜到底 / 不剪辑` 或 `N 段、段间 N−1 次硬切，并列明段内断切与全片切点总数`）② 景别 + 机位角度 + 运动方向 ③ 呼吸感 | 少了任一行，模型就自己发挥 |
| 3 | **呼吸感要写全限定词** | `手持，全片保持极轻微、如呼吸般的机位浮动`——**"极轻微"和"如呼吸般"两个词都必须有** | 只写"手持"会被理解成剧烈摇晃 |
| 4 | **声音行必带** | `无配乐，只保留现场音`；并**显式列出**关键环境音（雨、继电器、远处金属刮擦） | 不写，模型会自己配乐 |
| 5 | **瑕疵数量要够** | 角色 / 装备 / 服装**各至少两处**具体瑕疵 | 完美＝假；且这些瑕疵同时充当**跨镜一致性锚点** |
| 6 | **结尾留白** | 结尾不要堆对白、爆炸、强光、胜利姿势；模板：`无对白、无爆发、无强光——只有[主体][动作]，[环境细节]` | 满的结尾最假；空位承载情绪 |

**另两条通用纪律**：**一镜**只指定一种运镜（推拉摇移同写＝不稳；**分段镜里这条只约束每一镜内部**）；
**优先低缓连续的小动作**，狂奔与大跳是模型长尾。

## 构图指令层（人物位置写成指令，不靠感觉）

| 指令 | 写法 | 作用 |
|---|---|---|
| 主体位置 | `[主体]置于画面[左/右]三分之一` | 三分法参数化 |
| 双主体对峙 | `[A]占左三分之一，[B]占右三分之二` | 真人vs倒影、人物vs门缝这类对峙构图 |
| 引导线 | `[桌沿/走廊/海平线]形成水平引导线，把视线从[A]引向[B]` | 视线动线 |
| 留白 | `[方向]留出[暗部/虚化]负空间，给[元素]呼吸` | 张力与呼吸 |
| 前景遮挡 | `[隔壁椅背/门框/柱子]以虚焦状态入画一角` | 纵深与"偷拍感"，破贴图感 |
| 主体占比 | `[主体]占画面高度约[比例]` | 防景别漂移 |
| 水平线 | `[地平线/桌沿]保持在画面[上/下]三分之一处且水平` | 防歪斜 |

**★★ 景别行必须点名画框边界**（2026-09-14 补）：景别**由"画框装了什么"决定，不由"这件事多重要"决定**。
❌`中近景——手停在枪套上`（只写动作，等于把景别交给模型猜）→
✅`中近景——帽檐横切过面部上三分之一，画面下缘收进枪套的下半截`。
**判据：把画框当剪刀——剪下去后，框里还剩几张脸、几个物件？** 同一件动作（"手停在枪套上"）
在特写＝"手比人诚实"，在中近景＝"他在忍"，**是两个意思**。换景别只有三条正当理由：
**信息密度变了 / 距离关系变了 / 叙事职能变了**——"这件事很重要"**不是**理由。（→ `sequence-craft.md` §8.1b）
