# 第一次用？照这个顺序做（傻瓜式操作手册）

> **何时读**：第一次用这个 skill，或者隔了一阵子忘了怎么用。**读完回哪**：`SKILL.md`（那是完整规则手册，这份是操作手册）。
>
> **这一份只讲"你怎么操作"**——你该说哪句话、看到什么、什么时候继续往下走。规则细节一律不在这里展开，需要时按链接进。

---

## ⚡ 30 秒速览（只记这个也够用）

| 次序 | 你说 | 你会拿到 | 你做什么 |
|---|---|---|---|
| **1** | **"我想做一支 AI 短片：主题…，35 秒，抖音竖屏，风格你挑"** ／ 或**点名一个**（如 `B10 王家卫式`） | 可行性判断 → 一页 brief（**含风格编号**）→ **剧本** | 读一遍，不满意就说"改一下"，满意就说 **"继续"** |
| **2** | **"继续"** | **资产清单 + 出图提示词** | 按 **场景→光源→道具→角色→照片** 顺序出图（**照片 = 成片定调照**，见下面 3.2） → **跑一组测试（跨角度/景别/真实光/同框，各 5 条）** → **把图贴回来说"出好了"** |
| **3** | **"继续"** | **分镜脚本**（每镜：黑白故事板 + 视频提示词） | 逐镜：复制板块一出构图 → 复制板块二出视频 → 过了就下一镜 |
| 崩了 | **"第 N 镜 XX 崩了"** | 责任层判断 + 改法 | **贴回来说，别自己重抽** |
| 人假 | **"像打蜡 / 油光 / 高光成片 / 皱纹不对"** ／ **"五官都没毛病，但一眼看得出不是真人 / 站着像雕塑 / 说不上哪里怪"** | 前一种：皮肤成因诊断 + **光位改法**（多半不是改词）；后一种：**人物真实性三层分诊**（平均脸 / 静息态 / 恐怖谷）→ `character-realism.md` | 贴图 + 说现象，**别自己加"不要油光"**，也**别自己再加细节** |

**另有一件你看不见、但它一定会先做的事**：它会先答一遍**「六问推导」**（这片子到底在说什么 · 人物要什么怕什么靠什么撑着 · 这场戏为什么非存在不可 · 冲突什么形状 · 能量怎么走）——**这是"为什么不空心"的地基**，不写进交付物，但决定后面所有选择。想知道它推了什么，直接问：**"你的命题是什么？"**

**三条铁律**：① 三步顺序**不能跳**（跳过第 2 步＝人物每镜换脸）· ② 出完图**必须贴回来** · ③ 崩了**先问再抽**。

---

## 零、先搞清一件事：这 skill 是在帮你做什么

你只需要**说人话**——提供**想法**就行，不需要懂提示词、不需要懂运镜、不需要懂调色。全程三步，顺序不能换：

```
第 1 步  说想法  →  拿到【剧本】
第 2 步  说"继续" →  拿到【资产图提示词】→ 去出图 → 把图贴回来
第 3 步  说"继续" →  拿到【分镜脚本】→ 一镜两块，逐镜出片
```

**别做的事**：不要自己写提示词、不要自己拆镜头、不要跳过第 2 步直接要分镜。**跳过第 2 步 = 人物每镜换一张脸**，这是最常见的翻车。

---

## 一、开新话题时，复制这句话（就这一句）

```
我想做一支 AI 短片。主题是【用一句话说】，大概【多少】秒，发在【抖音竖屏 / B站横屏】，
风格想要【写实电影感 / 美漫描边 / 其他】，整体感觉像【说一个你熟悉的作品或感觉，可选】。
```

**填不出的项可以不填**——你没说的，它会问。

**举个填好的例子**：

```
我想做一支 AI 短片。主题是一个拾荒少女把修了三个月的破机器人推进"自动维修站"，
投币后发现保修已过期三十年。大概 35 秒，发在抖音竖屏，风格想要美漫描边，整体感觉像废土喜剧。
```

发出去之后，**它会先给你三样东西**（这是它的固定动作，你不用要）：

| 它会先给你 | 是什么 | 你要做什么 |
|---|---|---|
| **① 可行性判断** | 你这个想法里有哪些镜头是 AI 做不好的 | **看它写的"改法"**，认了就说"可以" |
| **② 一页 brief** | 时长画幅 / 一句话主旨 / 交付物清单 / 难点预判 | 看一眼，**有不对的直接说"第 3 条改成…"** |
| **③ 然后才开始写剧本** | —— | —— |

> ⚠️ **如果它说"你这个题材里有 4 个高危镜头，建议改结构"——请认真看改法再决定**。
> 它不是在推脱。手、走路、多人、口型、打斗这些，实测失败率 60–70%，**在第 1 步改，比在第 3 步发现拍不出来便宜一百倍**。

---

## 二、第 1 步：拿剧本（你只需要读，不需要改）

**你会拿到什么**：一份文档，七件装订在一起，不拆——主旨与 Logline / 梗概 / 人物 / 节拍表（精确到秒）/ 无对白版 / 分场剧本 / 台词清单。

**你只做一件事：读一遍，看有没有"这不是我想说的"。**

| 你觉得 | 你就说 |
|---|---|
| 挺好 | **"可以，继续"** |
| 人设不对 | "阿拾不该是 17 岁，改成 12 岁" |
| 结尾差点意思 | "结尾我想要更狠一点，机器人最后不理她" |
| 太长了 | "压到 25 秒" |

**它会自己重出一版。** 改到你满意为止，**不用客气，这一步改是免费的**（后面改才贵）。

**✅ 你可以进下一步的信号**：你读完剧本，**点头了**，并且说"继续"。

---

## 三、第 2 步：拿资产图提示词（这一步要你动手，最重要）

**这一步是全流程唯一需要你亲自动手的地方，也是最值得花时间的地方。**

**3.0 先确认风格（它在库里有 247 个可挑）**：你会收到一个**风格编号**（如 `B10 王家卫式`／`E03 敦煌壁画`／`D10 定格动画`／`G02 2D 角色+3D 环境`）+ **属于哪套量级**（写实／描边／第三系工艺渲染／混合）+ 全片不许变的三条一致性锚点。
**风格决定了后面所有图的量级与材质——所以必须在出图之前定。** 不满意就直接说"换一个偏 XX 的"（如"换个更冷的""换个更民间的"），它会从库里的氛围反查表重挑。
**3.0b 同时会给你一个「拍摄方案包」编号**（主库 `P01`–`P17`，另有 `P18`–`P34` 补充包）：写实类的片子里器材**不再是一套用到底**——纪实给你 S16 手持、年代戏给 35mm 胶片、恐怖给你监控、当代给你手机。**同一个包里，资产图与镜头图的"痕迹"必须一致**，否则人像会像贴上去的。想要别的观感直接说（"我要像手机拍的""要胶片的颗粒"）。
→ 想看全部 247 个风格与挑选逻辑：`style-library.md`；想看全部 34 个器材包：`camera-package-library.md` + `package-extended.md`（**你都不用读，说人话就行**）

### 3.1 先看它给的清单

它会先给你一张**资产清单**，长这样：

| 资产 | 是什么 | 为什么要 |
|---|---|---|
| 场景 A · 废土路边 | 一张场景图 | 全片都在这 |
| 光源 · 落日 | 一张参考 | 定全片的光，**最先出** |
| 道具 · 投币口 | 一件一张 | 有特写 |
| 角色 · 阿拾 | 一张设定板 | 主角 |
| 角色 · 阿拾（湿透版） | 单独一版 | 剧情里会变 |

**你检查一件事：剧本里会出现的东西，清单里是不是都有？** 缺了就说"少了一个 XX"。

### 3.2 然后去出图（**按顺序出**）

它会给你【批量任务】格式的提示词，**直接整段复制，粘到你用的出图工具里**（Updream / 即梦 / SeeDream 都行）。**想自己改批量任务怎么写，格式见 `updream-workflow.md` 第一节**。

**⚠️ 出图顺序不能乱**：

```
1 场景  →  2 光源  →  3 道具  →  4 角色  →  5 照片
```

**为什么**：**光源要早出（排在道具 / 角色 / 照片之前），因为排在它后面所有图的"光"都要跟它一致**。先出角色后出光源 = 角色和场景的光对不上，人物像贴上去的。

**第 5 步「照片」= 成片定调照**：前四项都锁定后，把它们放进同一张图（已定场景 + 已定光源 + 道具 + 角色，机位取第一镜）。
用处有二：① **验证**前四项搭在一起成不成立；② 作后面所有分镜的**风格参考图**（对应 `asset-consistency.md` 九类枚举里的「**风格**」类）。**判据**：给没看过剧本的人看，他说得出这片子什么气质吗？说不出 → 重出。

> **出图时怎么复制**：它给的提示词块是**整段**的，**整段全选复制**，不要只复制某一行。
> 一次出不完就分批，**每批它会给不超过 6 条**。

### 3.3 出完图，**把图贴回来说"出好了"**

这一步**不能省**。你就把图发给它，说：

```
图出好了，贴给你。场景图我觉得够了，角色图第三张脸崩了，你看怎么调。
```

**为什么必须贴回来**：它要用你**实际出的图**去写分镜——**用文字描述人物长相，每写一镜漂一次**（这是硬道理，见 `asset-consistency.md`）。你不贴图，它只能靠文字猜，后面脸会一直变。

### 3.4 它会做的最后一道检查：动测（**这一步决定资产能不能用**）

贴完图，它会让你**跑一组测试**（不是一个）——**判据：三条勾选项 + 四类测试 + 5 条重复性，见 `asset-consistency.md` 第八节**。

**为什么是一组**：**一条测试镜过得去可能是运气。** 角色要跑四类——**跨角度**（正/3-4 侧/侧）· **跨景别**（近景+中远景）· **真实光**（**用这场戏实际的光**，不是资产中性光）· **同框**（和**每个会同框的角色**各一条二人镜）。**同类连跑 5 条全成立才算过，不许"4 条好就锁"。**
**同框这类最容易漏**——资产是**一个人一个人出的**，出场顺序上看不见"两人同时在场"；多角色同框的片要主动提醒它跑。

**别跳过**：这是**全片最省钱的一步**——图再好，一动起来崩了，到第 3 步才发现就晚了。**过不了就回上一步改资产**，不是"多抽几次"。
**另一个工具**：两个主体的**大小关系**关键时（人和巨物、大人和孩子），它会做一张**尺寸参照图**当"尺子"——**比例用数字写，不用形容词**（→ `production-ledger.md` 第五节）。

**✅ 你可以进下一步的信号**：① 主要资产图**都出好了**（不需完美，够用即可）② **图已贴回给它** ③ **动测跑过、没崩**（或崩了但已调好）。三条都满足，说**"继续"**。
