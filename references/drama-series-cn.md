# 国产剧体系：写、改、算、送（**中文剧集专用**）

> **何时读**：写或评判**国产剧**（上星长剧 / 网络剧）· 小说 IP 改剧 · 写策划文档（**故事大纲 / 分集梗概 / 人物小传**）· 算集数与字数 · 查内容红线与送审链。
> **读完回哪**：引擎与季形 → `drama-series.md`；单集幕与出幕 → `drama-episode-structure.md`；格式 → `script-format.md`；交付 → `script-module.md`。
> **适用**：剧本 / AIGC 写作。**NOT for** 技术文档 · 论文 · 新闻 · 公文（→ `writing-methods.md` §0）。
> **⚠️ 时效**：本册的政策、机构名、费率、平台格局均按来源书年份（**2014 / 2015 / 2016**）标注——**引用前必须核对现行文件**。

## §0 国产 vs 美式：差异表（**本册的脊梁，先看这张**）

**为什么要有它**：`drama-series.md` 与 `drama-episode-structure.md` 来自美式体系，**直接套到国产项目上会犯结构性错误**。下表左边的每一条，都是"中式与美式**真的不一样**"的地方。

| 议题 | 国产 | 美式正统 | 用哪个 |
|---|---|---|---|
| **结构单位** | **集 / 段 / 场**（"戏剧需要分场分幕，电影需要分镜头分场景，**电视剧需要分场分段分集**"） | 幕 + act out | 给中国平台的文件用**集-段-场**；向外方提案时另做幕表 |
| **每集收口的谱系** | **李渔"收煞"**（"略收锣鼓，**令人揣摩下文，不知此事如何结果**"）+ 评书"且听下回分解" + 周刊连载 | act out 出自广播—电视广告制 | 解释"**为什么必须收口**"用中式谱系；算页码锚点用美式 |
| **重复** | **长篇中"重复上升为一种具有本质性的技巧"**（模式 / 情节 / 细节 / 首尾四种都被鼓励） | 信息经济：重复 = 浪费篇幅 | 30 集以上日播长剧用前者；10–13 集短剧用后者 |
| **主角能动性** | **允许被动主角**："总是在被动中**保持一份欲望**"（忍耐、辩解、恐慌都算反动作） | 被动主角 = 结构缺陷 | 苦难成长型 / 家庭伦理可用，**但必须给她"每集被动中的一个主动动作"** |
| **季形** | **闭合长篇**：全剧拍完、一次性播完 →"故事更完整，结构更严谨" | 开放引擎 + 季终钩子，为无限续订设计 | **判据先看交付侧：首播在上星 → 一律闭合（优先级最高）；网络剧或已规划续集才可留开放结尾** |
| **瓶子集** | **否决**（"出场只有两人、且都不是主角……**一看就很不专业**"）；国产改用"**同一景多集套拍**"压成本 | 省钱又深刻的正当手段 | — |
| **主角缺席集** | **禁止**："**主人公必须在每一集都出场**，并有足够戏份" | 群像轮转集合法 | 例外：缺席期间**仍在施加意志**、且这一集**关于他的缺席** |
| **对白密度** | **适度冗余是工业要求**（观众有伴随性活动，离开电视机也不该丢主信息）；对白占 50% 以上、每集 1.6–1.8 万字 | 对白经济；动作大于语言 | **拆成两半看**：**体量是硬约束，但只对 45 分钟上星长剧成立**；"动作从属于语言"是日播语境下的结论，**投视频平台（可回看）时不必照办** |
| **主题的稳态性** | **"审核的最高标准并非国家机器，而是观众"**；主题须配齐**启悟者 + 奖罚机制 + 不跑题的主人公** | 主题可反讽、悬置、道德模糊 | 面向最广泛观众的上星剧用前者 |
| **"晚进早出"** | **同名反义**：姚版"晚进" = **先铺垫渲染气氛、让观众熟悉场景并积累期待，再点燃导火线** | enter late = 跳过铺垫直接进冲突 | 每集 25–35 场的长剧用姚版；美式集用美版。**裁决**：姚版的"铺垫"**必须由正在发生的动作承担，不得由交代承担**——可以慢慢进，不可以先讲来历 |
| **开场** | **禁止追根溯源**："**往往一开口就是刮着的风、下着的雨：事件正在发生**……所有必要的解释说明，须在事件发展中见缝插针" | pilot 要建立世界与人物 | 国产第 1 集两者都要做，靠"事件中见缝插针"完成建立 |
| **未收尾的线索** | **合法**：网状结构中"许多线索时断时续，**有头无尾**"也发挥作用 | 每条线必须 payoff | — |
| **集尾** | **每集末尾必须再卖一个大关子**，收口即开新扣 | 末幕只做兑付、不引入新信息 | **直接冲突，按媒介选**：国产单集一律按国产办；美式那条只用在**季终集** |
| **总纲** | **"电影是为经典而写作，电视剧是为'收视率'而写作"** | showrunner 作者论 | 这是国产"通俗性 / 娱乐性 / 时尚性 / 覆盖面最大化"的依据 |

**补三条**：**虚假 cliffhanger**——中式坦率承认"**虚晃一枪要比没有好**，因为毕竟有了悬念"（美式视为欺骗，**不要每集都虚晃**）· **连续剧 vs 系列剧的技术界线**——用"**场面是否有明显结尾**"划分（有明显结尾 → 产生不了下一波风浪）· **现成素材库**——中式教材**直接给**"三十六种境遇 / 三十六个喜剧情势"并说"还可以借用"（美式忌套路）。**两条都要知道，选边由项目定。**

## §1 中文的"页"怎么折算 + 体量硬数据

**中文剧本没有页数标准，只有字数标准**，而甲方、平台与写作指南都在用"页"说话。**统一用这条链折算，用时必须声明"这是折算页"**：

```text
① 美式一页 ≈ 一分钟（来自美式版面，不是中文的）→ 所以"N 页"先读成"N 分钟的戏"
② 中文每分钟字数：长剧 300–370 字/分钟；对白为主约 400；动作与反应多的 270–330
③ 取值：对白为主的长剧 370–400；单机位喜剧 / 悬疑 / 动作取 300–330
④ **上线前按平台成片时长校准（2026-09-30 补）**：折算出的字数 / "页"数在交稿前按目标平台**实际成片时长**再核一遍——上星正片与流媒体正片的分钟数不同，靶子跟着平台走
```
**★ 按时长折算，不要按集数套用长剧数字**：28 分钟的半小时剧按 330 字/分钟 ≈ **9,200 字/集**，不是 1.6–1.8 万字；12 分钟短剧 ≈ 4,000 字。**写"约 N 页"时把折算依据一并写出**，否则同一份稿会被两种"页"读出两倍的差。

| 项 | 数值（附前件） |
|---|---|
| **集数** | **20–60 集**（**前件：这是"上星日播"的市场区间**——每天两集连播、按集计酬、广告排期共同撑出来的数）；**流媒体短剧集（12/16/24 集）不适用**，集数改按**引擎失压论**论证（见 `drama-series.md` §2） |
| **单集时长** | **全长 45 分钟；正片不低于 41 分 30 秒**；片头 60–90 秒，片尾 120–150 秒 → **按 41.5 分钟写一集**。**前件：上星技术交付标准**；流媒体不留下集预告位、正片由平台定 → 41.5 只当**写作靶子** |
| **字数** | **30 集剧本至少 40 万字**；对白占全部容量 **50% 以上**（**前件：45 分钟上星日播**——见 §0 差异表"对白密度"行，投流媒体不必照办） → 所以"改编不是把小说分场拍摄，而是**一次全新的再创作**" |
| **集数可变** | 合同常写"集数以批复为准"，**加集 = 按比例追加投资** → **这是"注水"的经济结构所在** |

## §2 文档链：三套并存，动笔前必须问清用哪套

**★ 甲方的格式要求优先于本册的一切体例。** 下面是**默认值**；对方给了模板就按对方的，本册只用来填空白。典型冲突：对方要"每集一段 100 字"，而本册体例要"**戏眼 + 事件 + 结尾状态**"三件——**压缩三件、不超字数**，展开版另存给自己用。

| 链 | 顺序 | 关键点 |
|---|---|---|
| **A 学院 / 策划口径** | 情节概要 → 人物设计 → 主要场景 → 创意说明 → 情节流程 → **样本剧本** | 策划文件六件套；**该口径不用"分集大纲 / 分场大纲"** |
| **B 制片方评审口径** | **故事大纲** → **分集梗概** → **分集剧本** → 分镜头本 | "故事大纲完全可以判断有没有**别致的闪光点**"；分集梗概"可以看出全剧篇章结构、矛盾起承转合、以及**每一集戏的'戏眼'**"；分集剧本"可据此**编制拍摄预算**" |
| **C 合同交付序列** | 剧本创意 → **总纲和人物小传** → 分集梗概 → **分批初稿（分批验收）** → 整体定稿 | 另一版本：故事大纲 → 分集提纲 → 初稿 → 二稿 → **开机前定稿**，对应六段付款 |

**★ 两个中国特有词**：
- **"戏眼"**——**中国分集梗概评审的核心词：每集必须有一个能被一句话指认的戏眼。**
- **分镜头本**——"目前中国的电视剧制作，**很少有导演做正式的分镜头本**"（工期紧、情节量大）。**"分场大纲"不是国产标准交付物**（它是对美式 outline 的中译）；国产对应物是**分场景表**（定稿后由场记做的制片文件）。

## §3 单集骨架：3 分钟 + 15 分钟 + 集尾（**国产剧的硬骨架**）

```text
开场 3 分钟必须抓住观众 → 每 15 分钟来一个小扣子 → 集尾再卖一个大关子
```
**关键理解**：15 分钟节点**在无广告时代被保留并重新解释**——"过去是为了插广告……现在是考虑剧集中的分段，以 15 分钟为一个情节点，构建所谓的**片断戏剧结构**"。**硬规定**："每 15 分钟为一个时段，这种片断与每集的 45 分钟基本上固定不变"。（**★ 同词两义澄清（2026-09-30）**：此处"情节点"＝**时段段界单位**（每集 3 个）；与 §10 自查①"每集约 13 个情节点"的"情节点"（**细分节拍**）**不是同一个单位**——用时先分清指哪个。）
**制作现实**："有时根据导演的爱好任意扩张或减缩情节……**一旦这样做，会破坏片段的悬念和集尾的悬念，影响收视效果。严格的制片人一般不会同意。**"

**★ 段界校验（划完段必须再跑一遍）**：**15 分钟只给位置，不给理由。** 每处段界必须落在**一次信息或权力的转移**上——用隐形幕三重判据复核（① 剧情日是否换 ② 地点或交通工具是否切换 ③ 核心问题是否转向），**三条全不中就是"掐着表切的假段界"**，把段界挪到最近的一次转移上。**流媒体无广告位时，这一步取代秒表。**

**四级悬念（中式独有的一套分层）**
| 级 | 是什么 | 要点 |
|---|---|---|
| **1 全剧总悬念** | 若干小悬念环环相扣构成总悬念，其揭开有赖于小悬念的逐个解决 | 两种提法：**先提总悬念再延伸到枝节**；或**把尚未出现的主要悬念提到前面，再回头叙述如何造成这种局面**。系列剧的总悬念 = "**两性之间没完没了的吸引与拒斥**"（"作者一直阻断着观众对他俩终成眷属的期待"） |
| **2 集尾悬念** | 机制是**"空白"**——集与集之间那段"物理空档" | **⚠️ 一次性放出时那段空白在物理上不存在**：仍要留开放结尾，但依据换成"**留一笔要兑付的账**"（见 `drama-series.md` §5 记账式单元）。**平台与卫视同播时两个理由都要给**——判据：先问首播在哪一侧 |
| **3 时段悬念** | 每 15 分钟一个"**局部的生动点**"（"不时地收紧放飞的风筝"） | 可同时跑 5–6 条线，但仍守"**一个问题**"：**解决了一个问题才能引出一个新问题** |
| **4 开场悬念** | 职责与舞台剧/电影相反 | 比喻："**迅速地截流**，将观众的注意力从现实生活或其他电视信息流中间引向电视剧，**就如报纸杂志的标题作用**" |

**悬念设置四条**：① **以人物为基础**——"人物必须赢得观众的感情……舞台剧和电影不一定要有惹人喜爱与讨人厌烦的人物，**但电视剧十分重视**"；② **跟随情境同行**——**诊断句："有的戏抓不住观众，不在于没有整体悬念，而往往是缺乏一个循序渐进的小悬念系列"**；③ **用平行蒙太奇制造"终极界限"**——每解决一个悬念立刻补一个带硬时限的新悬念，并把限制**物化为一个可见的计量器**；④ **"一个问题"格局**（尽早出场 / 减少头绪 / 具体明确 / 强而有力 / 一个刚结束就即时提出新的）。**反面案例**：一部 30 集剧**九个并发谜团 + 四条婚恋副线**，"到最后三四集才大抖包袱，把观众绕得直叫唤"。

## §4 延宕五技巧（"狗熊掰棒子"的反面）

**初学者典型失误**："常常是**狗熊掰棒子，拿一个，丢一个**。"

| # | 技巧 | 要点 |
|---|---|---|
| 1 | **在人的头顶聚集乌云，灾难越来越大** | "越解决问题问题越乱"，而最后时限已紧逼 |
| 2 | **在紧张时刻突然中断，按下不表** | "**如果间隔时间过长，要适时地重提。虽然叙述中断，但情势不能减弱**" |
| 3 | **把一个完整的大动作分成多节拍的细碎动作，每节设一个小悬念** | "赴约一定遇上大灾难 → 在他出门、下楼、路上设置种种小问题，**只有解决了这些小问题，他才能与最后的大问题见面**" |
| 4 | **增加故事情节** | 向社会广度与心理深度扩张；冲突卷入新人物，新人物带来新事件 |
| 5 | **节奏调节，一张一弛** | 放在"**强弱（力度）· 快慢（速度）· 大小（幅度）· 虚实**"的对比里 |

**节奏口诀**（对《24 小时》某集的总结，可直接背）："**安静的时候，像一棵树；行动的时候，像闪电雷霆；感情用事的时候，流水一样散漫；事件讲述的时候，像军事上实施进攻一样集中优势兵力。**"

## §5 开篇前三集（**中式与美式在此高度一致，但理由不同**）

**做法**："**尽早建制全剧情境、尽早制造核心冲突、抛出全剧总悬念、尽早让主角出场**"。
**观念纠正**："传统观念里，中国人的审美往往强调**将好的东西留在后头**。但是现在，这样的观念显然已经落伍了。"
**★ 送审驱动的版本（中式特有）**："审片人每天有大量片子需要观看……一定会**将重点放在前几集**……所以即便从审查这个角度考虑，改编者也应尽量将**故事最精彩的部分**放在开篇，**特别是前三集**。"
**配套**：**后半段才发力的核心人物必须在第 1 集露脸**（把某人的出场从"婚礼时"提前到第 1 集）。

## §6 情境两步法：中式版的"引擎"（可替代美式 franchise）

**长剧的推进机制**："开场时**设置情境**，构成全剧的推动力量……促使人物心理活动凝结成具体动机，并导致具体行动。由此，主要人物的行动牵动其他人物的行动，引起新的冲突，构成新的事件，导致**局部情境变化**……层层递进，通向高潮。"

**★ 两步法（中式最实用的一句）**：
> **第一步，想方设法设置一个情境；第二步，让人物在这个情境里跌爬滚打，始终保持着一种动作的状态。**

**情境规定的动作必须重复**：复仇情境 → "仇不能轻易解开，复仇要一而再、再而三"；磨合情境 → "既要保持独立又要融合的长期过程"；误会情境 → "一旦造成，就必须**越解释越说不清楚**"。
**★ 复合原则（长剧专用）**：**给主角同时挂 4–5 个不同类型的情境**（如：世仇 / 家族财产 / 顽劣的儿子 / 同行竞争 / 老字号存续），**并规定其中至少一个在中途转型**（"复仇"变成"追逐"，"磨合"变成"竞争"，"恋爱"有时反成"复仇"）。

**突转 = 国产剧替代 act out 的装置**："电视剧注重各条动作线的交替出现、注重在每集中每条线上造成小高潮，**所以更多运用突转技巧**……**电视剧的'突转'几乎分散在各集各片断之中**。"倒推法：**向负面转折就先把正面文章做足，反之亦然。**

## §7 结构类型：一处**必须保留的分歧**

| 立场 | 主张 |
|---|---|
| **学院派** | **戏剧式 / 散文式 / 心理式 / 引戏员式**四型并列，后三者**不以冲突为骨架**；线索分单线 / 复线 / 网状（"**网就有纲**……总有一条主线起支配作用，虽然它有时并不明显"） |
| **实务派** | "在电视剧当中，**几乎不可能存在散文式结构**，更别谈心理结构、诗结构了。市场上所有电视剧，几乎都清一色隶属戏剧式结构" |
| **制片方** | 四种骨架：① 一个或几个**家庭的命运演变**（宅门剧）② 一组或几组**人物关系的变化**（家庭情感剧）③ **任务的发出与完成**（警匪 / 谍战）④ **人物的成长**（武侠 / 青春偶像）——"以上几种可能在一部剧里综合使用" |

**★ 什么情况用哪个**：献礼剧、平台命题、30 集以上上星剧 → 按实务派（戏剧式 + 时空顺序式）；单本剧、纪实剧、作者性项目、网络短剧 → 可用学院派的散文式 / 心理式 / 引戏员式，**但必须承担"结构松散、吸引力不强"的风险**。

## §8 "一案 N 集"是一条光谱，不是判断题

**中式教材的警告**（"场面有明显结尾 → 产生不了下一波风浪 → 把连续剧变成系列剧"）**是在警告一个代价，不是禁止一种做法**。国产长剧实际落在这条光谱的任意一点：

| 一案占几集 | 形态 | 换来什么 | 代价 | 适合 |
|---|---|---|---|---|
| **1 集** | 单元剧 | 任意集进入、重播二轮友好、剪条好切 | 人物不积累，**约第 12 集观众开始觉得重复** | 情景喜剧、行业单元剧、日播 |
| **2–3 集** | 单元连续剧（**主流国产长剧**） | 每 2–3 集一次完整满足，同时留得住人物变化 | 24 集只装得下约十个案子 | 职业剧、刑侦、年代单元 |
| **4–6 集** | 板块式（一块一件大事） | 每块能写到底，情绪容量大 | **前两集慢**（平台最怕"前三集留不住人"正在这里） | 家庭剧、群像、改编长篇 |
| **全季一案** | 纯连续剧 | 张力最满 | **任何一集单看都不成立**，重播与二轮吃亏 | 迷你剧、短剧集 |

**选点三判据**：① 平台要二轮与重播 → 靠 1–3 集；② **题材的纠纷/案件来源有限**（算一下最多几类）→ 来源少就往 4–6 集靠，否则约第 8 集就露底（**以实际排播与集数为准**）；③ 主角的变化需要多少篇幅——**变化慢的人物不要放进 1 集一案**。
**两种合法的混合法**：**记账式**（单元照旧闭合，但每个单元留一笔由后面指定某集兑付的账——**正好绕开"有明显结尾=不产生下一波风浪"的代价**）· **三轨制**（A 案本集收 / B 案跨 3–6 集 / C 线贯穿全季；代价是每集要同时伺候三种节奏，分集大纲必须逐集标明三轨各走到哪）。
**★ 不要做的事**：**在方案里不表态**——光谱上不选点，写出来的 24 集就会一半像单元剧一半像连续剧，第一轮审读就会问"这到底是什么剧"。

## §9 改编与制片链（要点）

**改编（扩写方向）**：**五源类型学**（小说 / 电影 / 传记 / 戏剧 / 外国剧本土化）· **卖点迁移**（原著受众专属卖点全换、**关键词保留做门面**）· **主题坐标系** · **人物三位一体 + 逐段【复制 / 删除 / 改编】表** · **扩容四法** · **IP 评估**（"三基础 + 两判断"）。
**片段改编（压缩方向，与扩写相反）**：成片 → **8–20 分钟、3–8 人的舞台片段**；**四条法则**（场景设置合理化 / 选材否决门 / 一个核心事件与切点 / 完整性）。

**制片链与审查（**2014–2016 口径，引用前须核对现行文件**）**：
- **八项行政制度** + **两道审查**（内容审查 + 技术审查）→ 取得发行许可证方可发行；**重大革命 / 重大历史 / 重大理论文献题材走双审通道**。
- **内容红线**：**十大类**（含"反面角色不得作为主要表现对象"、"不得暴露侦查手段与侦破细节"、"善恶界限要清楚"、"婚外恋/一夜情/非正常性关系"的处理、不得为已有定论的历史人物翻案、不得对革命历史作游戏式表现、不得宣扬转世轮回/巫术等）。
- **必聘专家把关三类**：涉军队 / 武警 / 国安 / 公安 / 司法 / 医生 / 律师；少数民族语言文字；革命先驱、特定标识、特定历史时期的服化道。
- **合同门禁**：**每阶段拿到制片人与导演双签的书面认可**；**审核期限与默认条款**；**重大改动限制**（创作意图 / 主要人物 / 主要事件 / 样式）；**权利回转**、翻拍许可、版税三档、署名救济。
- **排期意识**（写剧本时就要有）：景名全稿一致 · 相似地点区分 · 同一景的日夜戏成组 · 写一批"**演员少、无特殊地点、不受天气影响**"的小场次供机动 · 避免昂贵的毁道具、群演与夜戏。
- **加集的经济结构**：**按集计酬 + 加集按比例追加投资 = 注水的激励**。**对抗它的唯一办法是在策划阶段就把集数论证清楚**（见 §8 与 `drama-series.md` §2）。

## §10 诊断清单（国产稿专用，逐条自问）

```text
① 一集按 41.5 分钟算的吗？25–35 个场面、其中 4–5 个精彩主要场面？每集约 13 个情节点？
   30 集到 40 万字、对白到 50% 了吗？（拿分场表的场号数直接比区间，不要先换算）
② 单集骨架：开场 3 分钟有抓人的事？每 15 分钟一个"局部的生动点"？集尾大关子是真关子还是虚晃一枪？
③ 段界校验：每处 15 分钟段界都落在一次信息或权力转移上了吗（三条判据至少中一条）？
④ 开场第一句写的是"正在发生的事"还是在追根溯源？解释是"在事件中见缝插针"给出的吗？
⑤ 前三集：情境、核心冲突、总悬念、主角四件事都交完了吗？后半段发力的核心人物第 1 集露脸了吗？
⑥ 每集主角在场且有足够戏份吗？（缺席例外：他仍在施加意志、且这一集是关于他的缺席）
⑦ 悬念：总悬念是"一个问题"还是九个谜团？有循序渐进的小悬念系列吗？时限被物化成可见的计量器了吗？
⑧ 延宕五技巧用了哪几条？按下不表后、间隔过长时重提了吗？有没有"狗熊掰棒子"？
⑨ 情境：主角同时挂了几个？有一个在中途转型吗？情境规定的动作重复够次数了吗？
⑩ 线：事业线与私生活线各有目标/障碍/高潮、且互为因果？并行线超 5–6 条了吗？
⑪ 重复：模式/细节/首尾三种重复用了哪些？**每次重复的内涵有变化吗**（否则是机械重复）？
⑫ 结构类型选点表态了吗（戏剧式 or 散文式；一案 N 集定位在哪一档）？还是含糊其辞？
⑬ 主题：有启悟者吗（且不是主角）？违背主题的受罚、顺从的受赏了吗？主人公动机跑题了吗？
⑭ 改编：一句话概括过原著？数出它给了几个主角几条线、够不够填目标集数？做过逐段【复制/删除/改编】表？
⑮ 格式：四种格式选定一种并全稿统一了吗？修改用 19A/19B 与删除标记吗？
⑯ 排期：景名一致 / 相似景区分 / 同景日夜成组 / 有一批机动小场次吗？
⑰ 审查：逐项过了红线十大类吗？涉专业人员与特定群体的戏留了专家审读时间吗？
⑱ 交付：确认对方用哪套文档链了吗？每阶段拿到双签了吗？合同里审核期限与改动限制争到了吗？
```

## §11 工作流程（十二步）与训练（六个）

**工作流程**
```text
① 选题四原则：真有意义 · 极有兴趣且力所能及 · 能掌握丰富第一手素材 · 从大量现象中有了新发现
   （并做市场定位与目标设定，对"一年之后观众要什么"作判断——制作到播出至少一年以上）
② 若是改编：IP 评估 → 确认改编权 → 一句话概括原著并数主角数与线数
   → 逐段【复制/删除/改编】表 → 定主题坐标系 → 做卖点迁移清单
③ 定类型与体量：主打类型一个（可复合，但立项文件只写一个）· 集数 · 单集 41.5 分钟 · 预估全剧字数
④ 写策划文件：情节概要（或 200–400 字分段梗概，每段一个时间锚点、每段结尾一个不可逆改变）
   + 人物设计（主角三个创新点）+ 主要场景（已考虑景地集中）+ 创意说明
⑤ 报备案/立项（或并行）：确认是否属重大题材（双审通道）· 涉民族宗教另走对应部门
⑥ 故事大纲 → 分集梗概：每集写一句【戏眼】· 排前三集 · 排四级悬念
   · 标每 3–5 集一个高潮、全剧至少两次突转 · 给主角挂 4–5 个情境并安排一次情境转型 · 铺事业线+私生活线
   ——【拿到制片人与导演双签后再往下写】
⑦ 人物小传与总纲：心理与精神层面的内容写在小传里，不写进分集剧本
⑧ 样本剧本（第 1 集或前两集）：按职责清单自查 · 选定格式并全稿统一 · 每集 25–35 个场面
⑨ 分批初稿 → 二稿 → 开机前定稿：每阶段按合同闸门推进 · 加付写进合同 · 过论证会 · 过专家审读
⑩ 定稿后：场记拆成分场景表与排序表 → 套拍排期；修改用 19A/19B 与删除标记
⑪ 送审：内容审查 + 技术审查，改到通过为止，取发行许可证方可发行
⑫ 出海（可选）："从生产制作环节就要融入国际化元素"；长剧出海的标准改法是
   "将长篇连续剧改编成一部或两部 100 分钟左右的电视电影版本"
```

**六个训练**：① **抄格式**（把同一场 3 页的戏用四种格式各写一遍，体会哪一种导演最快看懂）② **41.5 分钟校准**（找一集已播国产剧掐表，列出场面表 25–35 场，标开场钩子/每 15 分钟扣子/集尾关子，数情节点是否接近 13 个）③ **情境两步法**（给一个主角挂五个不同类型情境，为每个写出"必须反复做的那个动作"，指定其中一个第几集转型）④ **卖点迁移**（选一本畅销小说，列三个卖点与受众画像，逐条判断对电视剧观众是否有效并给替换方案）⑤ **四级悬念表**（为 30 集剧做表：总悬念一句 / 30 个集尾悬念各一句 / 三集的三个 15 分钟节点 / 第 1 集用哪种开场范式）⑥ **反向练习**（把你自己某集最强的一场戏改成 10 分钟、4 人、单一主场景的舞台片段，对比它靠什么成立）
