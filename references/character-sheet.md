# 人物小传（角色档案）：怎么推 · 怎么写 · 怎么落进提示词

> **何时读**：**第一步写剧本的「人物」那一件之前**（先推后写）；**第二步出角色资产之前**（档案是身份锚的上游）。**读完回哪**：`asset-consistency.md` 出图 · `block-playbook-asset.md` 写角色提示词。
>
> **分工（三份别互相抄）**：
> - **本文 = "这个人是谁、从哪来"**（字段 · 推导法 · 句架 · 痕迹词表 · 到提示词的映射）
> - `character-depth.md` = **"这个人怎么被看见"**（外观 / 体态 / 行为 / 矛盾四层 · 肌肉表 · 表情下限）
> - `character-realism.md` = **"怎么才不像 AI"**（个体化三点 · 生理活性 · 静息微动 · 恐怖谷）
> - `performance-craft.md` = **"这一镜怎么演"**（内部驱动 / 破假 / 对手戏）
>
> **★ 一句话定性**：**小传是推导工具，不是交付物。** 它是**给你自己用的**——用来推出提示词里那一行行**可执行的可见信号**。
> **把整段小传抄进提示词＝把"给作者的"当成"给模型的"**（→ `lexicon-map.md` §0 三类语料）。
> **★ 依据（用户长期要求）**：写任何角色/人物设定，**不写形容词、写可执行的具名信号**；**数字只作对表、不进提示词**。

---

## §0 先分清：小传的三层，与"只交付第三层"的纪律

| 层 | 内容 | 给谁 | 交付吗 |
|---|---|---|---|
| **① 底层（内在）** | 欲望 / 恐惧 / 缺陷 / 前史 / 赌注 | **只给你自己** | ❌ **不交付** |
| **② 中层（行为规则）** | 习惯动作 · 体态 · 语速 · 面对压力的反应 | 给**导演与演员**（你） | ⚠️ 折成"可见信号"后交付 |
| **③ 表层（可见物）** | 痕迹 · 服装状态 · 随身物 · 姿态 · 一句身份锚 | **给模型** | ✅ **只交付这一层** |

**判据一句话**：**把①原样写进提示词，模型会当噪音；把③丢了，人物就变成"34岁男性"这种道具清单。**

## §1 字段表（最小集 8 项 · 每项都要能被"看见"或"被问到"）

| # | 字段 | 写什么 | 不合格 | 合格（示例，非模板） |
|---|---|---|---|---|
| 1 | **外在目标** | 他**此刻、对某个具体的人**要什么。**必须是动词** | 状态词（"他很愧疚"） | `他要让她承认是她干的` |
| 2 | **内在需求** | 他真正缺的东西（往往与外在目标相反） | 抽象名词（"需要爱"） | `他要的是有人不问他为什么` |
| 3 | **致命缺陷** | 让他反复失败的**一个行为习惯** | 性格形容词（"他很固执"） | `他凡事都要先自己解决一遍，才肯开口求人` |
| 4 | **赌注 / 代价** | 得不到会怎样。**写具体的损失** | "他会很痛苦" | `错过今晚，她就搬走，地址不会留` |
| 5 | **前史（只管一行）** | **能解释他身上某处痕迹的那件事** | 完整生平、时间线 | `十七岁那年冬天在货场睡过两个月` |
| 6 | **职业与手上的活** | 他靠什么吃饭 + **手每天在做什么** | "他是个工人" | `他修表：右手拇指有一块被镊子磨出的硬皮` |
| 7 | **空间习惯** | 他**怎么占空间**（→ `character-depth.md` §三） | "他坐下了" | `坐的时候把身体收得很小，一只手压在另一只上面` |
| 8 | **一句身份锚**（40–70 字） | 逐字复用，全片不改（→ `asset-consistency.md` §三） | 形容词堆砌 | 见 §4 |

> **纪律**：**①–④项一个字都不进提示词**，但**必须写**——**不写，⑤–⑧就全是随手的想象**。

## §2 推导法：四步，每步都从"上游"往下推

**顺序不能倒**：**命题 → 欲望 → 经历 → 痕迹**。从痕迹倒推欲望＝在编，不是在设计。

### 第 1 步 · 从命题推"他非得是这种人"

**命题**＝这部片在说什么（→ `direction-reasoning.md`）。**人物是命题的载体**——换命题，同一个"外卖员"是完全不同的人。

> **问句**：**如果命题成立，这个人身上必须有哪一样东西是坏的？**

### 第 2 步 · 从欲望推"他会做什么、不会做什么"

**外在目标 + 内在需求的错位**，决定他每一次选择。

> **问句**：**为了这个目标，他最不愿意做的那件事是什么？**——**那件事就是这一场戏的动作。**

### 第 3 步 · 从经历推痕迹（**这一步产出可交付的部分**）

**每处痕迹都要能答"这是什么事留下的"**（→ `character-depth.md` §二）。**痕迹不是装饰，是履历的可见面。**

| 经历类 | 可写的痕迹 |
|---|---|
| **长期劳作的职业** | 老茧的**位置**（不是"有老茧"）· 指关节粗大 · 指甲边缘的缺口 · 虎口的硬皮 · 前臂的旧烫伤 · 皮肤被某种油污长期浸出的暗色 |
| **户外 / 日晒** | 晒痕的**分界线**（衣领、袖口、表带处）· 颈后与前臂色差 · 眼周的细纹比同龄人多 |
| **旧伤** | 疤的**位置与走向**（能反推是什么伤）· 惯用手的关节变形 · 走路时一侧承重更多 |
| **长期单侧习惯** | 一侧咬肌更厚 · 一侧肩更低（惯用侧背包）· 一侧眉尾因常皱眉而更浅 |
| **穷 / 局促** | 磨白的肘部与膝部 · 袖口卷起的**固定折痕** · 缺一颗扣子（位置固定）· 口袋鼓出的轮廓 · 缝过的针脚 |
| **当下的（今天才有的）** | 袖口的水渍 · 鞋上的泥 · 被风吹乱的头发 · 一张折过的纸 · 手上的灰 |
| **随身物** | 柄上换过三次、颜色一层深一层的胶布 · 磨圆的边角 · 贴纸的残留 · 用旧的拉链头 |

**纪律**：**一处写透 > 十处各写一句**（→ `character-depth.md` 下限条）；**面部结构类的偏离，全片只许一处**（→ `character-realism.md` §一）。

### 第 4 步 · 从矛盾推表演（→ 本文只列一行，方法在别处）

`他想让人看见什么 / 身体在哪背叛他 / 用哪里使劲克制` 三问 → `character-depth.md` §八；**破假的四工具** → `performance-craft.md` §三。

## §3 句架库（**可直接套的骨架 · 把①折成③**）

**用法**：左边是档案里的写法，右边是**唯一可以进提示词的那一层**。

| 档案里（不进提示词） | 提示词里（可写句式） |
|---|---|
| 外在目标：要让她承认 | `他的视线始终没有离开她的脸，每当她移开眼睛，他会微微前倾一点` |
| 内在需求：要有人不问他为什么 | `她开口时他先别过脸，然后才转回来，像在等一个不会被问到的问题` |
| 致命缺陷：凡事自己先解决一遍 | `他伸手想去接，中途改成了插回兜里`（**未完成的动作**＝缺陷的可见形式） |
| 赌注：她会搬走 | `他看了一眼墙上的挂历，指腹在今天的日期上按了一下` |
| 前史：在货场睡过两个月 | `他睡着的时候是蜷着的，一只手压在另一只手腕上` |
| 职业：修表 | `他的拇指常无意识地搓食指侧面那块硬皮` |
| 空间习惯：把身体收小 | `他坐着的时候肩膀向前扣，膝盖并拢，一只手压在另一只上面` |

**三条句架纪律**：

1. **每句只承载一个档案项**——一句话里想同时表达目标、缺陷、前史，模型一个都执行不了。
2. **句子里必须有物理落点**（手、眼、肩、呼吸、物件）——**没有物理落点的句子会被当形容词处理**。
3. **不许写"因为…所以…"**——原因不进提示词，**只写结果**（"因为他在货场睡过，所以他蜷着睡"→ 只留后半句）。

## §4 从档案到提示词：映射表（哪一行落到哪个板块）

| 档案字段 | 落到哪个板块 | 具体落成什么 |
|---|---|---|
| ① 外在目标 / ② 内在需求 | 第 4 块【本镜目的】 | **只写职能**：`这一镜推进的是"她第一次开始怀疑"` |
| ③ 致命缺陷 | 第 9 块【时间线】 | **未完成的动作** / 半途改主意 / 反复的同一个习惯 |
| ④ 赌注 | 第 4 块 + 第 12 块【过渡压力】 | 结果的压力从哪来、留给下一镜什么 |
| ⑤ 前史 → **痕迹** | 第 7 块【人物与环境】 | **一处写透**（位置 + 形态 + 与周遭材料的对比） |
| ⑥ 职业与手上的活 | 第 7 块 + 第 9 块 | 习惯动作（**带触发条件**）；**手始终有明确接触面** |
| ⑦ 空间习惯 | 第 7 块 | 重心 / 肩 / 朝向 / 手放在哪（→ `character-realism.md` §四） |
| ⑧ 身份锚（40–70 字） | 第 7 块**逐字复用** · 资产阶段作冻结块 | 每个角色在**每一镜**里逐字出现，**连标点都不改** |

**身份锚示例（照格式写，非模板）**：
```
脸型偏窄、颧骨明显；眼距略宽、双眼皮很浅；黑色短发向后梳，
左眉尾有一道旧疤；身形偏瘦、肩窄，锁骨突出。
```
**★ 加一条（2026-09-15 起）**：身份锚里**必须含"个体化三点"里的面部那一处**（**只许一处**，相对量写法；→ `character-realism.md` §一）。

## §5 长度纪律：三种角色，三种预算

| 角色 | 档案预算 | 必须有 | 可以没有 |
|---|---|---|---|
| **主角** | **8 项全写**，其中前史一行、痕迹一处写透 | ② 内在需求 · ③ 缺陷 · ④ 赌注 | 完整时间线 |
| **有台词的配角** | **只写 3 项**：他要什么（对主角）· 他的赌注 · 一处可见差异 | ③ 一个只属于他的动作 | 前史、职业细节 |
| **一次性（≤1 镜、<3 秒）** | **不建档案**，只给**一处差异** | 与主角的**动作不同类**（→ `character-depth.md` §12） | 其他全部 |

> **判据**：**把小传遮住，只看提示词，能推出"这个人大概经历过什么"吗？**——**能，档案写对了；不能，说明只写了①没写③。**

## §6 反例图鉴：一看就是"AI 写的人物"（10 条）

| # | 症状 | 修法 |
|---|---|---|
| 1 | **全是形容词**（"坚毅的、沉默的、内心柔软的中年男人"） | 换成**一处痕迹 + 一个习惯 + 一个未完成的动作** |
| 2 | **简历式**（"生于X年，X年毕业于…"） | 前史**只留一行**，且必须是**解释了某处痕迹**的那一行 |
| 3 | **标签堆叠**（"警察、离婚、爱喝酒、有女儿"） | 每个标签都要**落到一个可见物**上；落不到就删 |
| 4 | **把①原样进了提示词**（"他心里其实很自卑"） | **只写结果**：`他说话时下巴会先收一下` |
| 5 | **痕迹没有位置**（"手上有很多老茧"） | 写**哪只手、哪一节、什么形状** |
| 6 | **完美的人**（没有弱点、没有旧伤、没有穷的痕迹） | 补**一处**（→ `character-realism.md` §一，**面部只许一处**） |
| 7 | **所有人说话一个腔调** | 每人写**一个只属于他的句尾习惯**或**语速** |
| 8 | **配角只是递东西的人**（→ `character-depth.md` §12） | 给他一行**私账** + 一个**与主角错位**的动作 |
| 9 | **档案前后不一致**（这一镜小三岁、下一镜多道疤） | 全部差异**进造型状态表**（→ `character-continuity.md` §三） |
| 10 | **档案里写了摄影、颜色、运镜** | **档案只驱动"人"**——摄影与色彩去 `shot-craft.md` / `color-science.md` |

## §7 自检七问（写完档案，问一遍；交付前再问一遍）

1. ①–④ 有没有**一个字都没进提示词**？
2. 前史**只有一行**吗？那一行**解释了某处痕迹**吗？
3. 痕迹写的是**位置与形态**，还是只写了"有"？
4. 缺陷是**一个行为习惯**，还是一个性格形容词？
5. 身份锚**40–70 字**、含**一处面部结构偏离**（只一处）、且**全片逐字复用**吗？
6. **遮住小传**，只看提示词，能推出这个人经历过什么吗？
7. 配角有**自己的赌注**吗？一次性角色**有没有被过度设计**？

## 来源与口径

**本文件为 2026-09-15 本库自建**，动机（**E20 核对结论**）：全库关键词扫描显示——`人物小传` / `小传` / `生平` / `履历` / `人物卡` / `角色卡` / `句架` / `固定句` **全部零命中**；
`外在目标` / `内在需求` / `致命缺陷` **只在三处作为名词清单出现**（`studio-workflow.md` 第一步 · `script-craft.md` 验收清单 · 本库体例），**没有任何一处说明这三项怎么推出来、怎么落进提示词**。→ **属真缺口。**
**方法来源**：① **三层结构（内在 / 行为规则 / 可见物）与"只交付第三层"**：本库自建，依据是 `lexicon-map.md` §0 的三类语料分法（**给作者的判断进判断，不进提示词**）；② **外在目标 / 内在需求 / 致命缺陷**：本库既有字段（`studio-workflow.md` 第一步），本文补**推导与落点**；③ **痕迹与履历的对应关系**：与 `character-depth.md` §二（细节携带信息）同源，本文**只补可查的痕迹词表**；④ **句架纪律（每句一个档案项 / 必须有物理落点 / 不写因果）**：本库自建，与 `prompt-ops.md` 的空话词纪律同向；⑤ **反例图鉴 10 条**：由本库既有失败记录（`pitfalls.md` · `character-depth.md` §九 陈词滥调清单 · `key-decisions.md` C34）归纳。
**与外部资源的关系**：本轮检索的同类仓库（`LingyiChen-AI/image-prompts` 的 `image-prompt.md` 角色公式、`khanof89/awesome-video-prompts` 的角色样例）**均未采用**——前者**未声明 LICENSE**，后者的角色段落是**提示词样例而非档案方法**；本文**只保留其"角色要分层写"的启发，未使用任何词条或句式**。
