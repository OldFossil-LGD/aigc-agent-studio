## R2 · 分镜与故事板（12 问）

**1）景别序列**：**原序列跳跃过密**（前 5 镜塞 5 个景别、方向来回摆＝zigzag，观众会晕）。
- **两条线选一条**：**递进** 或 **往返**，不要 zigzag。
- **★ 它的改法**：**全(1) → 中(2) → 中近(3) → 特(4) → 近(5) → 特(6) → 全(7) → 中(8) → 近(9) → 全(10)**。
- **硬规则**：**相邻两镜不要跳两级以上**（如全景直接切特写），**除非那一刀就是本片唯一一次冲击点**。
- 特写/近景占比偏高（10 镜里 5 个）→ 可以，但**每镜特写必须有新信息**。

**2）每镜时长**：3–4 秒＝"短镜档"，稳定但**要求每镜动作极简（一个动作、一个变化）**。
生成模型**单镜 4–8 秒最稳**（动作完整不崩），**3 秒以下容易"没展开就结束"**；情绪镜给 **5–6 秒**，从纯过渡镜里扣。

**3）正对中轴会单调**——但**对称不是问题，"完全无变化"才是**。不破坏对称的变量六项：**焦段/景别 · 机位高度（平视→略俯→略仰，仍在轴上）· 主体前后位移（不左右偏）· 光比与色温 · 前景遮挡（仍居中）· 时长节奏**。

**4）"锁死只变焦"更稳 ✓**（运镜会让模型每帧重推空间 → 漂移/崩）。**例外三种**：转折点用**极慢 push_in/pull_out**（幅度小、速度恒定）· "时间流逝"用极慢 pedestal 或极轻横移 · 首尾呼应各用一次同向慢推。
**→ 原则：全片运镜镜头 ≤ 2 个，且都是慢速单向；其余锁死。**

**5）构图纪律**：**部分读得懂，执行是概率性的，不是硬约束**。提高命中：**用相对位置＋比例**（"主体占画面高度约 1/3、居中"）· **一条 prompt 里构图约束不超 2 条**（多了互相打架）· **关键构图靠首帧图锁定**（比文字可靠得多）。

**6）硬切要额外做三件事**：① 切点两侧画面连续性（景别/机位/主体位置不要跳变过大）② **动作匹配**（切点前后动作方向、手部位置、物件状态接得上）③ **声音连续**（环境音在切点处不断）。若某处硬切突兀 → **用"同景别同构图、只换内容"过渡，而不是加转场**。

**7）ASL**：**3.4 秒偏快**（写实无对白常见 **4–6 秒**）。**→ 纠正：建议 ASL 提到 4–5 秒，即 34 秒用 7–9 镜**，把省下的镜数换成每镜更完整的动作。

**8）故事板**：**一镜一张＝对每分镜各调一次 `generate_image_v3`，`tag=keyframe`**；灰度写进 prompt（"黑白灰阶、无彩色、素描/线稿质感"）；**不要用拼版模板**（`continuous_storyboard_grid_25` / `story_beat_grid_4` / `multi_camera_grid_9`）。单格可用 **`storyboard_panel`**；**灰度不要靠模板，靠 prompt 描述更可控**。

**9）故事板能否当首帧**：**写实灰度、构图准确 → 可直接作 `start_frame_image_node`**；**线稿/示意风 → 只能当参考**（否则把线稿风带进成片）。
**★ 最稳做法**：**故事板定构图 → 另出一张"写实彩色首帧" → 用写实首帧做 `start_frame`。**

**10）★ 平台不理解"全片唯一一次"这类全局计数约束**（它只看单条 prompt）。
→ **不要写"全片唯一一次"**，**写具体画面**："主体位于画面右侧三分之一处，画面左侧留空"；
→ **并在其余 9 镜主动写"主体居中、对称构图"**，**用正约束把对称焊死**，这样破对称那镜才不会被平均化；关键镜可用首帧图强锁。

**11）不要写"切点在第几帧"**：各镜独立生成、帧级对齐无意义，**只写时长（秒）**；精确节奏在合成阶段用 `start_position`/`end_position` 微调。

**12）4 个拉回镜会显重复** → 四招：**① 变化维度**（焦段/起点景别/拉回幅度/速度各不相同）**② 信息增量**（每次多露一点新东西：多一个物件、多一片空间、光变一次）**③ 间隔**（不连续两镜都拉回，中间插锁死镜或推近镜）**④ 最后一次拉回归落点镜，幅度最大、速度最慢，形成收束**。

**⚠️ 纠正本片《钥匙》**：① **景别序列 zigzag** → 改成它给的递进序列；② **ASL 3.4 偏快 → 34 秒应用 7–9 镜**；③ **4 个拉回镜要有四维变化**；④ **"全片唯一破对称"必须改写**（写具体画面 + 其余镜用正约束焊死）。

## R3 · 角色与场景资产提示词（12 问）

**1）主锚点用单张正面定妆图**（信息单一，模型不纠结"锁哪张脸"）；**三视图适合理解结构（发型/体型/服装），当参考而非唯一锚点**。可一起用：**三视图作 `reference_nodes` 辅助，正面定妆图作主锚点/首帧**——**但不要让三视图单独承担"锁脸"职责**。

**2）三视图会污染下游**（模型随机选一张脸/一个角度 → 跨镜脸漂移）。规避：主锚点用单张正面；若必须用，prompt 明确"**以正面视图为准**"；下游优先引用正面定妆图。

**3）★ `tag` 枚举只有四个**：**`character` / `scene` / `prop` / `keyframe`**（分镜首帧、故事板单格用 `keyframe`）。**没有更多枚举，不要自造 tag。**

**4）`quality` / `ratio` 最省**：
- **★ `ratio`：按成片画幅定，一次定死（如 9:16 或 16:9），全片资产统一，避免下游重缩放**；
- **★ "不要为资产图单独设不同画幅，否则引用时会被重新裁剪"** ← **【逐字过账补录：此条我首轮漏了，且已犯】**
- **`quality`：资产图用"中等质量"即可**（锚点主要提供身份/结构，不需要极致清晰），省积分；**成片首帧再用高质量**。

**5）★ "三处偏离平均的点"：特征数量 ≤ 3，且都要"大尺度可见"**——**★ 更正（逐字过账）：原文给的正面例子就是"左眼略窄""鬓角有白发""右食指有一道旧疤"** ——
→ **它接受"左眼略窄"，只反对"窄两毫米"这种亚像素描述**。
→ **正确改法：保留"左眼略窄"，删掉"约两毫米"**（**我首轮把"左眼略窄"整个删掉＝过度修正，已更正**）。
→ **关键身份特征优先靠参考图锁定，而非纯文字。**

**6）★★ 场景 3/4 图与"全片正对中轴"不匹配！**——3/4 图给的是"两面墙"信息，而镜头全正对中轴，**模型可能把 3/4 透视带进成片，破坏对称**。
→ **主场景锚点必须用"正对中轴的正面场景图（单点透视）"，与成片机位一致**；需要空间信息时**另出一张 3/4 图仅作 `reference_nodes` 参考，不作主锚点**。

**7）小道具值得单独建锚点**（叙事核心物件 → 保证跨镜一致：位置/形状/反光/磨损）。**若只出现 1 镜且不重复 → 可不建**，写进镜头 prompt 即可。

**8）"中性灰底+柔光无影"不会自动传到下游**（资产布光是资产自身属性），**但引用时模型可能带入"平光"倾向**。加回硬光：**镜头 prompt 明确写光**（"硬质侧光从画面左侧打入，主体右半脸落在阴影中，桌面有明显投影"）+ **明确写"背景为室内实景，非灰底"** + 关键镜用首帧图锁光位。

**9）写脏"部分继承、不可靠"**：**若是身份特征 → 每次镜头 prompt 都要重写**；只是氛围 → 可不重写。**最稳：写进主锚点图 ＋ 每镜 prompt 复述一次关键词。**

**10）换装/换姿势是否建派生锚点**：**换姿势不必建**（改镜头 prompt 的动作描述，身份靠原锚点）；**换装：跨多镜且服装是身份一部分才建派生锚点**（引用父锚点、只改服装），**单镜一次性 → 改 prompt 即可**。
**→ 原则：变化跨多镜且需一致 → 派生锚点；单镜一次性 → prompt。**

**11）重抽会改 `node_key` 吗**：**同一节点重新生成通常保持 `node_key` 不变，引用不断**；**但新建节点替换旧节点 → key 变、旧引用指向废弃节点**。**规范：替换后必须更新锚点清单与分镜表，在原位置写新 key、保持排序不变。**

**12）★ 资产库（主体库）API 侧用法**：**`save_asset`** 把节点存入资产库，指定 **`asset_type`（1 角色 / 2 场景 / 3 道具 / 4 风格 / 5 音效）** 与 `folder_name`。
**跨项目复用**：**`search_asset`** 按名称模糊检索 → 拿 **`asset_uuid` / `url`** → **`create_resource_node`** 把它放回画布（node_type + url）→ 再作参考引用。
**注意：`search_asset` 只检索、不上画布；上画布必须走 `create_resource_node`，不要用生成工具重建。**

**⚠️ 纠正本片《钥匙》**：① **场景锚点必须换成"正对中轴的正面场景图"**（我原建的是 3/4）；② **个体化三点删掉"窄两毫米"这类亚像素描述**，换成大尺度可见；③ **无换装 → 不需要派生锚点**（原计划的派生锚点可省）。

## R4 · 器材与镜头（11 问）

**1）器材词强弱分明**：**`65mm 大画幅` / `柯达 VISION3 250D 日光片` 有意义**（对质感/颗粒/宽容度/色彩倾向有弱到中等影响）；**"2393 印片"基本是装饰词，可删**。
**→ 器材词总量控制在 1–2 个，堆多了互相稀释。**

**2）焦段写法＝"景别 ＋ 焦段 ＋ 透视效果"三件套**，且**一镜只写一个焦段**：
- 例："全景，40mm 广角，空间纵深明显，前景桌沿接近画面下缘"
- 例："特写，85mm 长焦，背景被压缩、虚化，主体占画面 2/3"
- **焦段与景别必须自洽**（广角配全景、长焦配特写），别反着写。

**3）光圈可写，但要补"背景可读性"**：写"T2.8 浅景深，背景虚化但保留轮廓与光斑，仍可辨认窗与墙"。
→ **叙事镜保环境（T4–T5.6 或直接不写光圈）；情绪镜可浅景深。不要全片一个光圈。**

**4）滤镜**：**柔焦可写**（效果明显，但削弱"写实锐利"，慎用）；**偏振镜基本无效**（模型不理解"去反光"物理机制）→ **删**。

**5）★ 稳定方式要写成"静态属性"**：写 **"固定机位，三脚架，画面完全静止"**（不是"架在三脚架上缓缓移动"）；**"机位锁死"优于"稳定拍摄"**；**避免"轨道""手持"这类词**（模型会理解成有运动）。若确实要轨道运动，**必须同时写清方向与速度**（"轨道，极慢向右横移"）。

**6）快门角**："180° 快门角"是**装饰词**；**写"轻微运动模糊，物体边缘有拖影"更有效**；**静态镜无需写**。

**7）★★ "机位锁死只变焦"与"轨道慢而稳"矛盾！**——变焦＝焦段变化、机位不动；轨道＝机位移动、焦段不变。**平台不会调和，会随机二选一或混着做，结果不可控。**
→ **一镜只写一种运动**：要么"机位锁死、焦段不变"，要么"轨道缓慢横移、焦段固定"。**全片若要两种，分配给不同镜头，不要写在同一镜。**

**8）长焦压缩空间**：室内单场景会显"平、闷"；适合特写/情绪镜/背景虚化；**不适合交代空间的全景/中景**。
→ **建议：室内单场景以 40–50mm 中焦为主**（接近人眼、保留纵深），**长焦只用于特写，广角只用于 1–2 个全景**。

**9）器材描述放"中前部"**，结构：**`[景别+焦段+构图] → [器材/胶片质感] → [光线] → [动作/内容] → [负向约束]`**；太靠后会被动作描述淹没。

**10）视频侧没有"器材模板"**；`style_display_board` / `cinematic_lighting_correction` / `portrait_texture_adjustment` 都是**图像模板**。**风格锚点可用 `style_display_board` 出一张风格板。**

**11）一镜换焦段**：平台不拒绝，但**当变焦处理且执行不可控** → **不要变焦就一镜只写一个焦段**；要变焦就写清起止焦段与速度。**变焦与推轨（dolly in）不同，别混写。**

**⚠️ 纠正本片《钥匙》**：① **删掉"2393 印片"**；② **"机位在轨道上慢而稳，只做焦段变化"是矛盾句 → 改成一镜一种运动**；③ **焦段分配要改**（室内以 40–50mm 为主，长焦只特写，广角只用 1–2 个全景）；④ **光圈不要全片一个**（叙事镜用 T4–5.6 或不写）。

## R5 · 胶片与色彩（11 问）

**1）250D / 500T 弱区分**（模型只有模糊倾向，不可靠）→ **要准确控色温就直接写色温**："**3200K 钨丝暖光**" / "**5600K 日光冷白**"，**比胶片型号有效**。

**2）"2393 印片"不该写**——无效装饰词，删。

**3）★ 颗粒写法（只写"极细"不够，会被当数字噪点）**：
- "**细腻胶片颗粒，均匀分布，不结块、不彩噪**"
- "**颗粒仅在暗部可见，高光区干净**"
- 明确排除："**非数字噪点、无彩色噪点**"

**4）★ 三色板要"每镜都写"**——**色彩不会自动跨镜传递**（除非用色彩锚点图）。每镜复述三色关键词；**更稳：出一张"色彩锚点图"（含三色板），每镜作 `reference_nodes` 引用**。**三色板是固定值，每镜必写、不可省。**

**5）★ 色板与"调色族"会冲突**（具体颜色 vs 整体倾向，模型随机取舍）→ **二选一：用具体色板（推荐，可控）或用调色族（省事但不可控）**。若都要，**调色族只能写在色板之后作"整体倾向"补充，且不能与色板矛盾**。

**6）★★ 冷白硬光 + 暖色物件（橙红地面/塑料牌）＝天然青橙对比，极易滑向青橙调！**
→ 明确写"**暗部为中性冷灰蓝，非青绿**""**高光为中性冷白，非暖黄**"；或**压低暖色物件饱和度**（"橙红地面为低饱和暗砖红"）。
→ **关键：暗部青蓝要"灰"，不要"青"。**

**7）肤色线要写，写成排除句**："冷光环境下肤色保持中性偏暖，**不偏青、不偏绿、不灰化**"；"面部高光为中性白，阴影为暖灰，非青蓝"。

**8）高光要写成可拍描述**："高光点小而集中，边缘锐利，无大面积过曝"；"窗光在桌面形成一条窄亮带，边缘清晰"。

**9）资产图色彩会污染镜头** → 中性灰底减少污染 + **镜头 prompt 重新明确写色彩覆盖资产图倾向** + 主场景锚点带强色彩时每镜复述目标色彩。

**10）★★ 色彩统一的正路（纠正本库）**：**`composite_video` 不做调色，只做拼接与音轨混合**；**`edit_video_v4` 支持调色（colour grading）——这才是统一色彩的正路**。
→ **所以"导出不支持调色"的结论要修正为：合成不支持，但后处理 `edit_video_v4` 支持**。
→ 若完全不做后期：**在生成阶段就把色彩写死（每镜同色板、同光色），靠 prompt 保证一致。**

**11）平台没有自动色彩检查**；机检需我方自实现：**色板区域 RGB 均值比对** · 直方图（色相分布）· 关键色 HSL 跨镜比对。

**⚠️ 纠正本片《钥匙》**：① **"待定的调色族"取消——改用具体三色板**（二者会冲突）；② **三色板每镜必写**；③ **必须写"暗部中性冷灰蓝、非青绿"+"肤色不偏青"**（否则必滑青橙）；④ **色彩统一改走 `edit_video_v4` 或生成期写死**。
