# 12 · 创作工艺路由（人物 · 动作 · 灯光 · 风格 · 声音）

任务：统一基准重构 · B 路
日期：2026-10-07

> **本文回答**：哪些内容属于创作工艺、**不应被三作样本删除**；每一条工艺在哪个阶段加载、进哪个提示词块、**用什么验收**。
>
> **判定口径（任务单 §1）**：平台事实看接口和回读；**创作工艺看多来源工艺共识、原库经验与三作案例** —— **不因为三作没写某条微表情就删掉它**。

---

## 0. 为什么工艺要单独路由

三作蒸馏拿到的是**三份生产选择**，不是三条通用规则（跨作品裁决台账 §0 已写明「这张表不是优劣表」）。工艺知识与它们的关系是：

~~~text
平台事实    ← 接口与回读决定
跨作规律    ← 至少两作独立成立
创作工艺    ← 多来源共识 + 原库经验 + 三作案例；三作没写 ≠ 无效
样例        ← 只作参考，抄结构不抄数字
~~~

**最容易犯的错**：把【例子】当【库规】。三作里「某一次的做法」不能升级成规格；反过来，工艺册里长期成立的 prior 也不能因为三作样本没覆盖就被删。

## 1. 六族与加载阶段

工艺按**加载阶段**挂载，不按文件目录挂载。阶段的划分与 `run-sheet.md` 站序一致。

| 阶段 | 说明 | 本阶段主要加载的族 |
|---|---|---|
| S1 接活与 brief | 时长 / 题材 / 交付物 | 叙事（可行性、容量、结构） |
| S2 风格定档 | 写任何提示词之前 | 风格与器材 · 色彩 |
| S3 剧本 | 定稿剧本 | 叙事 · 声音（对白与旁白规划） |
| S4 资产 | 出资产图 | 人物 · 灯光（材质受光） |
| S5 分镜与故事板 | 排镜与故事板 | 动作与运镜 |
| S6 镜头提示词 | 落笔写提示词 | 全部六族 |
| S7 声音 | 音轨 | 声音 |
| S8 合成与交付 | 后期 | 色彩 · 声音（混音） |

**跨阶段生效的两条**（`thinking-pipeline.md` §12）：

1. **一致性锚点**：锚点三条在 S2 定、账本登记、各板块原句复用；改锚点 = 全链同步；
2. **门禁扩张警告**：**审美类判断不追求机检** —— 方案包配得好不好、表演到位否，只能人检。

**三条不许省的真实性下限**（`shot-craft.md` 第 7、9 块）：

1. 面部**只许一处**个体化特征（相对量写法）；
2. **静息微动**的体态句（呼吸起伏很浅但不停 / 重心换过一次 / 手指松了一下又收回）；
3. **生理活性**（瞳孔 / 眨眼 / 呼吸至少两样，且不是恒定节律）。

> **机位可以锁死，人不能锁死** —— 写「他站在门口等她，一动不动」是反例。

**本族最重要的一条反直觉规则**：**换光位比改形容词有效得多** —— 皱纹是微立体结构，沟影在正面平光下不成立。**不许写纹名**（一提名字，模型就调用「深沟」的统计印象）。

**皮肤出问题的处置顺序**：先分数（哑光 / 毛孔 / SSS 证据句），再换光位，最后才改形容词。

## 9. 工艺进视频提示词的通道（自动化的关键一段）

工艺知识要**自动进入**提示词，必须走这三条通道之一，否则就变成「无人使用的文章」。

| 通道 | 从哪来 | 怎么进 | 例子 |
|---|---|---|---|
| **块映射** | 工艺册 → 12 块中的唯一归属块 | 归属表（`block-spec.md` §三·补）决定写进哪一块 | 皮肤句只准进【光位与影调】；动作链只准进【时间线】 |
| **下限注入** | 真实性下限（不许省的三条） | 每个含人物块的视频包强制注入 | 面部一处个体化 + 静息微动 + 生理活性 ≥2 |
| **锚点复用** | 身份锚点句 / 禁止项清单 | 进 `locked_text[]`，逐字复用 | `铁锈红外套` 不许写成 `深橙色外套` |

**归属表里最常犯的两处**（机检会报）：

1. 【人物与环境】里写了**皮肤句**（哑光 / 毛孔）→ 皮肤归【光位与影调】；
2. 【人物与环境】里出现**动作过程**（入画 / 走过来 / 提起身）→ 动作链归【时间线】。

## 10. 只能人检、不能机检的工艺（诚实清单）

`thinking-pipeline.md` §12.10：**审美类判断不追求机检**；「扫到了＝好」是错的，`rc=3`「没扫到 ≠ 过」同样适用。

| 判断 | 为什么机检不了 | 谁判 |
|---|---|---|
| 方案包配得好不好 | 审美 | 人 / 平台侧 agent 只取维度 |
| 表演到位否 | 审美 + 上下文 | 看片 |
| 微表情「像不像」 | 需要看片抽帧 | 看片 |
| 光位「对不对」 | 需要看片 | 看片 |
| 风格像不像 | 需要参照物比对 | `style-cards-*` 校准卡 |
| 三帧风格化归模型还是后期 | **未裁决**（W1 两处写法并存） | 需成片抽帧 |

## 11. 证据标签与未决项

标签：**【已验证】**＝实测或一手源 · **【库规】**＝skill 内成文规则 · **【例子】**＝参考做法 · **【已撤回】**＝被后续证据推翻 · **【不可判定】**＝证据不足。

**本文的未决项**：

- 三作对「工艺」的覆盖是**样本覆盖**，不是**有效性判定**：三作没写微表情不等于微表情无效，三作都写了某做法也不等于它是平台规则；
- 工艺册里凡标【例子】的数值（如单一景别占比、资产图角度）**不当规格**，当前项目合理就照做，不合理就写明理由豁免；
