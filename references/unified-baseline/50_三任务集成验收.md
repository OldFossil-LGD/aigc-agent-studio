## 5. Gate 名空间裁决

【库规】统一允许：

```text
<domain>.<check>
```

保留 C 路现有名称，不强制改字符串：

```text
graph_plan.structure
graph_plan.reference
graph_plan.media
graph_plan.cost

three_work.structure
three_work.reference
three_work.media
three_work.cost
```

新增域使用自己的前缀，例如 `prompt.*`、`script.*`、`delivery.*`。同一域内 `check` 必须稳定，不能为了美化结果改名。

## 6. `new_regression` 语义裁决

【库规】`new_regression=true` 只表示：

```text
1. 本任务新产出的 artifact 检出失败；或
2. 冻结基线之后发生了可归因于本批改动的真实回归。
```

预检阶段计划本身不合法，属于新 artifact 失败，可以记 `new_regression=true`。

以下情况不得记 `new_regression=true`：

```text
rc=3 证据缺失                 -> debt_class=not_verified
rc=5 平台不适用或缺单价        -> debt_class=not_applicable
开工前已经存在的索引、撞号债务 -> debt_class=existing, new_regression=false
只读证据回答不了的平台归因      -> 不可判定，不进入强制通过
```

`debt_class=new_regression` 必须同时满足 `new_regression=true`；`existing`、`not_verified`、`not_applicable` 必须为 `false`。
