## 0. 三个输入档位

用户给的东西只有三种形态，编译器对每种只需要问最少的问题。

| 档位 | 用户给了什么 | 例子 | 编译器要做的 |
|---|---|---|---|
| **I 一句话目标** | 一句自然语言 | 「做一个 15 秒的悬疑短片」 | 补全全部缺项（本文 §2 的默认值表），**只把真正需要人裁决的 1–3 项标成待确认** |
| **II brief** | 一段带约束的描述 | 时长 / 画幅 / 题材 / 交付物 / 难点 | 把 brief 逐项映射成计划字段，缺项走默认值 |
| **III 已有剧本** | 现成剧本文档 | 一份分场剧本 | 只做**校验与编译**，不重写剧本；剧本是上游定稿 |

**判据（来自 `thinking-pipeline.md` §1 与 Step 0 廉价闸门）**：交付终点（提示词还是成片）与验收人是谁 —— **这两项含糊时唯一合法动作是问人**，其余一律走默认值。

## 1. 计划对象：字段与来源

计划产物对齐 `production_record.schema.json` 的核心字段。每个字段都要能回答"它从哪来"。

| 字段 | 含义 | 从哪来 |
|---|---|---|
| `project_id` | 一个制作目标一个 id | 用户目标 / 自动生成 |
| `script_id` | 剧本定稿版本 | 档位 III 直接取；档位 I/II 由编译器生成 v1 |
| `scene_id` | 场次 | 从剧本的场次切分 |
| `shot_id` | 镜头 | 从排镜表 |
| `asset_ids[]` | 本镜引用的资产锚点 | 从资产清单 × 排镜表交叉 |
| `duration_sec` | 本镜时长 | **平台档位**决定（见 §5），不是文学节奏决定 |
| `dialogue_lock` | 台词是否锁定 | 有对白镜锁定；无对白镜为 null |
| `world_state_delta` | 本镜结束时世界状态改变了什么 | 每镜必写「什么变了」，写不出就删镜 |
| `prompt_package_id` | 本镜对应的提示词包 | 见 `11_提示词包与五类模板.md` |
| `gate_results[]` | 门禁结果 | 见 `13_提示词门禁与失败诊断.md` |

**单一事实源（R51 账本纪律，`libtv-quality-delivery-content.md` §5.3）**：

~~~text
账本的「引用锚点」字段 = 生成引用的正本
画布节点              = 人工可读镜像
每次生成只收到本次 prompt 与显式引用 → 不能假设模型记得上一镜
~~~

所以：**改引用先改账本，再改画布**；反过来做，画布与账本必然对不上。

## 2. 缺项补全：默认值表

档位 I / II 的缺项一律按此表补，**不把缺项抛回用户**。

| 缺什么 | 默认值 | 依据 |
|---|---|---|
| 时长 | 15 秒（短片）/ 用户没给就按 15 秒起步 | `drama-scaling.md` 容量换算入口 |
| 画幅 | 2.39:1（写 21:9 落地） | `platform-matrix.md` §7.4 |
| 风格 | **未声明即写实系**（系一），必须显式写出 | `style-library.md` §二 |
| 结构模型 | 30–60 秒只有四个能直给；更短用钩子 + 一个转折 | `drama-structure-models.md` §9 |
| 单镜时长 | 平台下限 4 秒；默认 5 秒，上限 15 秒 | `sequence-craft.md` §8.3 |
| 声线 | 有台词即需声线母档；无对白片声音 = 底噪 + 点状两层 | `sound-craft.md` §一 |
| 对白 | 无对白版必须能独立成立 | `script-craft.md` |
| 参考图 | 人物参考 = 干净正面 + 全身两张独立文件 | `asset-consistency.md` §3.0 |
| 字幕 | 显式声明无字幕 | `sound-craft.md` §二·补 |

**必须标成「待确认」而不许默认的三类**（因为改起来会毁掉上游）：

1. **交付终点**（提示词 / 成片）与验收人；
2. **题材是否踩可行性红线**（手 / 全身走 / 口型 / 多人 / 剧烈动作 / 画面文字）→ `feasibility.md`；
3. **时长与平台档位的冲突**（用户要 20 秒单镜，但平台单次上限 15 秒）。

## 3. 编译七步

每一步都有可判的出口，走不完不许进下一步。

| # | 步 | 出口（可判） |
|---|---|---|
| 1 | **量容量** | 总时长 → 段数 / 镜数上限（§5 表） |
| 2 | **定结构** | 选出结构模型 + 节拍表秒数总和 = 总时长 ±0 |
| 3 | **定风格档** | 风格编号 + 量级系 + 方案包 + 三条一致性锚点，写进账本 |
| 4 | **定资产清单** | 每个 ≥2 镜出现的实体一行；三档必要性（必出 / 条件出 / 点名才出）标注 |
| 5 | **排镜** | 排镜表含时长列与「引用锚点」列；镜头数与 §5 档位一致 |
| 6 | **选路线** | 单镜版还是段落版（判路表见 `segmented-shot.md` §一）；试错成本算术决定默认走哪边 |
| 7 | **出包** | 五类提示词包（见 11 号册）逐镜落地，过 `13` 号册的门禁 |

**顺序不可倒置的两处**：

- **风格必须早于资产**（风格决定资产的量级，定晚了资产全部要重出，`style-library.md` 何时读）；
- **`block-playbook-asset.md` 五段式协议早于 `shot-craft.md` 12 块** —— 资产是靶子，靶子歪了下游每条都歪。

## 4. 规模档位（消费 A 路档位，不另起定义）

> **所有权声明**：规模预算的**档位与公式归 A 路**（`03_规模预算与题材时长档位.md`，B 路只读）。
> 本节**不重复它的数字表**，只写 B 路需要的那两件事：**段数算术**与**包级切分**。
> 本节第一版曾自行列了一张与 A 路冲突的镜数表（5 分钟 40–60 镜 / 120 分钟 960–1440 镜），**已删除** —— 同一事实两个定义违反单一权威源。

**A 路档位（B 路只引用，不修改）**：

~~~text
T0  15–60 秒    镜头带宽   2–6     典型组数   4–8
T1  1–5 分钟    镜头带宽   6–40    典型组数   8–16
T2  5–30 分钟   镜头带宽  40–240   典型组数  16–40
T3  30–120 分钟 镜头带宽 240–800   典型组数  40–100
~~~

**档位只是启动带宽，不是目标数量**；按口型对白 / 多人同框 / 强动作 / 跨场景 / 状态连续 / 多语言 / 多平台 / 高一致性资产上调复杂度系数 `C`（A 路 §1、§4）。

### 4.1 已验证锚点

| 项 | 值 | 标签 |
|---|---|---|
| 平台单次生成下限 | 2.0 = `[4,15]` 秒；2.5 = `[4,30]` 秒；1.5 Pro = `[4,12]` 秒 | 【库规】`sequence-craft.md` §8.3 |
| 单个动作镜定型下限 | 2–3 秒 | 【库规】同上 |
| 15 秒 / 3 镜写实片节点数 | 23（公式与实际一致） | 【已验证】`libtv-quality-delivery-content.md` §5.4 |
| 段数档位（5 / 8–10 / 15 / 30 秒） | 2 / 3–4 / 3（上限 5）/ 5–8（节点 ≤8） | 【已验证】`segmented-shot.md` §四 |

### 4.2 B 路需要的三个包级常数

| 常数 | 值 | 来源 |
|---|---|---|
| 一个视频包 = 一次投喂 | **≤15 秒**（平台单次生成上限） | `sequence-craft.md` §8.3 |
| 一个合成单元 | **≤25 镜**，超则拆子合成树 | `libtv-quality-delivery-content.md` §5.4 |
| 一个生成单元的定型下限 | **2–3 秒** | `sequence-craft.md` §8.3 · `segmented-shot.md` §四 |

节点量级公式（引用，不修改）——`libtv-quality-delivery-content.md` §5.4：

~~~text
节点总数 = 3（剧本 + 总表 + 合成）+ 4N（分镜条目 + 故事板 + 首帧 + 镜头）
           + (C + L + P)（内容锚点：角色 / 场景 / 道具）+ D（派生锚点）+ A（声音轨条数）
不随 N 增长：剧本 1 · 总表 1 · 合成（≤25 镜 1 个，超则 ceil(N/25)+1）
随 N 线性：分镜条目 / 故事板 / 首帧 / 镜头（各 N）
~~~

### 4.3 三档降级（预算不够时砍什么）

| 档 | 内容 | 砍掉的 |
|---|---|---|
| 最小版 | 母锚点 + Sn + Fn(首帧) + Vn + 单一 X1 | 派生锚点 / 尾帧 / 长镜拆段 / 子合成 |
| 标准版 | 母锚点 + 少量派生 + Sn + Fn + Vn + AU(M) + 单一 X1 | —— |
| 完整版 | 全套派生 + 一镜多关键帧 + 长镜拆段续写 + 声音细分 + 子合成树 + 色彩 / 字幕 / 章节卡 | —— |

## 5. 档位计算：先算每段几秒，再定段数

**唯一算式（`segmented-shot.md` §四）**：

~~~text
每段秒数 = 总时长 ÷ 段数
每段 < 2 秒 → 减段数 / 加总时长 / 拆多次生成（三选一）
~~~

**为什么这条是硬门**：5 秒写 5 段 = 每段 1 秒，低于定型下限 → 每段只演半口气，接起来是五段糊片。**不是提示词不详细，是每段预算不够。**

**按内容类型分档比平均分更准**（PenShot `neopen/story-shot-agent`，MIT）：快动作 1.5–2.5 秒 · 对话与表情反应 2.5–4 秒 · 环境交代 3–5 秒 · 情感高潮 4–6 秒。标【例子】，可改。

**官方原句（Seedance 2.5 指南，2026-09 核）**：`Leave roughly 2–3 seconds for a visible action.` —— 5 秒片 2–3 个节拍 · 8–10 秒片 3–5 个节拍 · 15 秒 3–5 镜最佳。

## 6. 三个工作样例：一句输入 → 一份计划

### 6.1 「做一个 15 秒的悬疑短片」

| 步 | 结果 |
|---|---|
| 量容量 | 15 秒 → 3 段（最稳），每段 5 秒 |
| 定结构 | 钩子 + 一个转折（30–60 秒以下只有四个结构能直给） |
| 定风格 | 未声明 → 写实系，写一句技法名词句而不是「电影感」 |
| 定资产 | 主角 1 人（≥2 镜必出）；场景 1 个；道具 1 件（点名才出） |
| 排镜 | 3 镜 × 5 秒；排镜表带时长列与引用锚点列 |
| 选路线 | 单镜版（三段各自成镜）或段落版（一条含 2 个切换点） |
| 出包 | 3 个视频包 + 1 个资产包 + 1 个故事板包 + 1 个声音包 + 1 个合成包 |
| 待确认 | 交付终点（提示词 / 成片）；是否出对白（有对白要锁口型与声线） |

### 6.2 「做一个 5 分钟的城市纪录片，要有旁白」

| 步 | 结果 |
|---|---|
| 量容量 | 300 秒 → 落 T1/T2 边界（40 镜量级），再按复杂度修正；段数每镜 1–3 |
| 定结构 | 场次制（12 场量级）；每场一个包组 |
| 定风格 | 写实系 + 纪录片向方案包（`camera-package-quickref.md` 反查） |
| 定资产 | 场景锚点为主、人物锚点少（纪录片不锁单一主角） |
| 排镜 | 约 40 镜；子合成 2 个 + 总合成 1 个 |
| 选路线 | `(V.O.)` 旁白 —— 本库最划算的写法，**不吃口型** |
| 出包 | 约 40 个视频包 + 锚点包 + 故事板包 + 3 层声音包 + 合成包 |
| 待确认 | 旁白语言与是否要字幕轨（→ `14_语言口型字幕与本地化.md`）；素材授权 |

### 6.3 「做一个 30 分钟的科幻短剧，两集」

| 步 | 结果 |
|---|---|
| 量容量 | 1800 秒 → 落 T3（240–800 镜带宽）；按集拆（每集 15 分钟） |
| 定结构 | 剧集层：单集幕结构 + 卡点（`drama-episode-structure.md`） |
| 定风格 | 风格编号必须在库内存在（自编编号会被门禁判引用优先律违规） |
| 定资产 | 母锚点（角色 / 场景 / 道具）跨集复用；状态变化单独一版 |
| 排镜 | 每集 120–180 镜；子合成 10–15 个 |
| 选路线 | 段落版为主；长镜拆段续写 |
| 出包 | 按集分包；跨集共享锚点包 |
| 待确认 | 集数与平台档位（单集超 45 分钟要换结构模型）；多语言分发 |
