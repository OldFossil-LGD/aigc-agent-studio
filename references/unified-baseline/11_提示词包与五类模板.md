# 11 · 提示词包与五类模板

任务：统一基准重构 · B 路
日期：2026-10-07

> **本文回答**

## 0. 包是什么：统一字段

一个**提示词包**＝一次投喂的最小单元。字段与 A 路冻结的 `prompt_package.schema.json` **逐字对齐**（本文引用字段名，不改 schema）：

| 字段 | schema 类型 | 含义 | 谁填 |
|---|---|---|---|
| `prompt_id` | string | 包 id | 编译器 |
| `target_type` | enum: `asset` / `storyboard` / `video` / `audio` / `composite` | 三类静态 + 两类动态 | 五选一 |
| `source_record_id` | string | 上游记录（production_record 的 shot_id 等） | 编译七步第 5 步 |
| `reference_nodes[]` | array of `{node_id, purpose, deny[], order}` | 本包引用的资产 / 帧 / 上游段；**`order` 即参考位序** | 账本「引用锚点」字段 |
| `blocks[]` | array of `{name, text, visible?, source?}` | 结构化的块；`source` = `script` / `craft_prior` / `platform_contract` / `user_lock` / `inference` | 见各类模板 |
| `locked_text[]` | array of `{kind, text, language?}`；`kind` = `dialogue` / `world_voice` / `title` / `subtitle` / `other` | 逐字复用、不许改写的文本 | 台词 / 旁白 / 标题 / 字幕 |
| `duration` | `{seconds, mode?}`；`mode` = `single_shot` / `segmented` / `timeline` / `not_applicable` | 时长；静态包走 `not_applicable` | 平台档位 |
| `model_route` | `{model, mode, settings?, cost_class?}` | 模型与 modeType | C 路（模型路由） |
| `gates[]` | array of string | 本包要过的门禁名 | 见 13 号册 |
| `language_profile` | string \| null | 语言档（本地化用） | 见 14 号册 |
| `version` | integer ≥1 | 版本号 | 改口径即升版 |

**★ 一处必须说清的归属**：`reference_nodes[].purpose` 是**枚举**（`identity` / `scene` / `prop` / `style` / `composition` / `start_frame` / `end_frame` / `voice` / `reference_video` / `other`），**不是自由文本**；「不许它供什么」写在 `deny[]` 里。
**身份锚点句属 `blocks[]`**（`source: user_lock`）或 `locked_text[]` 的 `kind: other` —— 它不是 `reference_nodes` 的字段。

**三条打包纪律**：

1. **一个包一个目标**：一张参考图只承担一个任务（`asset-consistency.md`）；
2. **`locked_text` 原句复用**：身份锚点句改一个词就是换人；
3. **包内只有提示词本身**——无注释、无「（改成…）」、无 markdown 强调与装饰符号（`**` / `★` / 圈号）。

## 1. 五类包总表

| 类 | target_type | 时间轴 | 组织方式 | 必需门禁 | 样例 |
|---|---|---|---|---|---|
| 资产 | `asset` | 无（静帧） | **九块协议** + 五段式骨架 | `audit_prompt.py blocks --asset` | `samples/B1_资产_角色设定板.md` |
| 故事板 | `storyboard` | 无（静帧） | 结构 / 景别 / 画框 / 明暗块 | `audit_prompt.py blocks --storyboard` | `samples/B2_故事板_黑白三路径.md` |
| 视频 | `video` | 有 | **12 块思考层 → 输出层** | `audit_prompt.py blocks` | `samples/B3` `B4` `B5` |
| 声音 | `audio` | 有 | 按层分条（环境床 / 点状事件 / 对白） | `sound_lint.py` | 见 §5 |
| 合成 | `composite` | 有 | 时间线 / 混音 / 转场 / 字幕 | `export_readiness` 预检 | 见 §6 |

**为什么分两类查门禁**：静帧没有时间轴，不该有声音行与结尾留白。用镜头规则去查资产图，每块恒定吐 2 条无意义 WARN —— WARN 里混进固定噪声，人就会开始忽略 WARN。

## 2. 资产包（九块协议）

**九块 = 写法层**（`block-playbook-asset.md`，唯一权威源）；**五段式协议 = 骨架**（`updream-workflow.md`）；**三类差异 / 字段下游归属 / 从剧本哪一行派生**（`asset-prompt-spec.md`）。

| # | 块 | 必需元素 | 最容易写歪 |
|---|---|---|---|
| 1 | 板式行 | 比例写成数字 + 分区数 + 分隔方式 | 只写「超宽横版」不带比例 → 比例随机 |
| 2 | 身份锚点冻结块 | 40–70 字可判物理事实 | 写成气质词（「历经沧桑」）→ 得到通用沧桑脸 |
| 3 | 分区 / 视角清单 | 每格编号 + 视角 + 一个变量 + 「其余不变」 | 漏「其余五官与发型完全不变」→ 每格换一张脸 |
| 4 | 美学调性行 | 类型 / 年代 / 材质 | 写「质感十足」这类空话 |
| 5 | 材质与脏 | **逐处写脏 ≥2 处**，每处位置 + 形态 + 尺寸 | 只写「有些旧了」→ 出来是全新塑料 |
| 6 | 尺度关系 | 有可比参照物 | 整块漏掉（最常漏的一块） |
| 7 | 色板 | 3–4 个色系 + 对照关系 | 角色设定板专属，别漏 |
| 8 | 布光 | **中性的、可继承的** | 写戏剧光 → 被下游每一镜继承 |
| 9 | 统一提质层（资产版）+ 禁止项 | 材质受光响应 + 禁止出现清单 | 道具类漏材质受光 → 抹成同一种塑料面 |

### 2.1 资产侧必须写、镜头侧不写

身份锚点冻结块 · 分区 / 视角清单 · 尺度关系 · 色板 · 参考范围声明。

### 2.2 资产侧不许出现

时间线 · 人物表演 · 物理反馈 · 摄影机运动 · 过渡压力 · 声音 · 结尾留白。

**为什么**：资产没有时间轴。塞进时间线与动作句，模型会开始编动作，把「靶子」拍成「片子的一帧」——而这一帧还要被下游每一镜继承。

### 2.3 一条跨量级系的硬边界

**人物多视图设定板只作设计稿、不作参考素材**（会被识别成多个主体、加剧 ID 漂移）；出片参考要另出**一张干净大头照 + 一张全身照，两个独立文件**。**这条禁令与量级系无关** —— 它禁的是「一张图里出现两张有效脸」。

## 3. 故事板包

| 项 | 要求 |
|---|---|
| 管什么 | 结构、景别、画框边界、明暗块 |
| 不管什么 | 色温、材质、皮肤、后期 |
| 必需元素 | 黑白声明 + 画幅 + 起始景别 + 画框边界 + 明暗结构 |
| 三条路径 | 见 `storyboard-frame.md`（含失败处方） |
| 平台规格 | `storyboard-platforms.md`；故事板表不支持分组 |
| 门禁 | `audit_prompt.py blocks --storyboard` |

**为什么故事板只锁结构不写色温**：故事板是给下游选构图与景别的，写色温会让它变成一张「美术稿」，下游反而要推翻它重画。

## 4. 视频包

### 4.1 两层结构（本库的核心设计）

~~~text
思考层：12 块一块不漏地想过（用户铁律，不许跳块）
输出层：落到 prompt 的字面按平台权重收敛（格式见下）
~~~

**思考层 12 块**（`block-spec.md`）：全片通用 3 块（后期特效 / 统一提质层 / 风险移除 + 禁止出现）+ 本镜专属 9 块（本镜目的 / 镜头规格 / 构图 / 人物与环境 / 光位与影调 / 时间线 / 运镜 / 声音 / 过渡压力）。

**15 块思考清单**（`block-playbook.md`）是**思考清单的编号，不是写作顺序**——两者数字不同是设计，不是不一致。落笔时并进 12 块。

**资产 9 块**与视频 12 块**不是同一套**：资产走五段式，视频走 12 块层序。

### 4.2 输出层两种形态

| 形态 | 首行 | 块名 | 何时用 |
|---|---|---|---|
| **单镜版** | `分镜头脚本，单人单镜，时长N秒，画幅…` | `【本镜目的】`…`【进入下一镜的过渡压力】` | 一条一个机位 |
| **段落版** | `单条多镜（含 N 个镜头切换），时长N秒，画幅…` | `【本段目的】`…`【全局约束】` | 一条里换景别 / 机位 |

**单镜版的时间线四相**：`起始 / 主动作 / 反应与呼吸 / 定格`（**单镜契约**，段落版没有它）。

**段落版的时间线三相位**：`先：… / 随后：… / 最后：…`。⛔ 段内**不许用** `起始 / 触发 / 主动作 / 反应` —— 那是段间词汇，模型会读成「这是三个镜头」。

### 4.3 段落版必须写死的三件

1. **恰好 N 个段落、N-1 个切换点**（不写死，模型自己决定切几次）；
2. **每段内部跨 ≥2 级景别**（整条一个景别＝不合格）；
3. **段内不写秒数**（用相位组织；秒只活在首行总时长与排镜表）。

### 4.4 平台口径（v2 审计版 5 块主干）

LibTV 侧的输出层按平台权重可收敛到 **5 块主干 + 附属短句**：① 【人物与环境】（含锚点引用）② 【动作时序】③ 【景别 + 构图】④ 【运镜】⑤ 【光位与影调】，再加质感一行、对白随动作、尾帧随运镜、禁止项一行。

**但思考层铁律不变**：**「想全 12 块」≠「写全 12 块」**。收敛的是输出字数（建议 150–350 字，上限约 500），不是思考的块数。

> **口径澄清（`libtv-prompt-structure.md` §八）**：平台**不会「认块名」**，它把整个字符串交给生成模型。12 块是**我方 QA 规范，不是平台解析 schema**；缺块 FAIL 只说明「我方 linter 与块名表不匹配」。

### 4.5 引用语法：统一中间格式 + 三作保留

三作的引用语法**零重叠**（跨作品 07 号实测）：

| 作 | 载体 | 引用语法 | 实测 |
|---|---|---|---|
| W1 弥寿计划 | 节点内单层 | `{{Node <id>}}` 插桩；首行身份锚点序列 | `@ImageN` 0%；813 次 `{{Node}}`；54 个首行族 |
| W2 抵达之前 | 节点内单层 | `<标签1>…<标签3>` 参考标签块 | `@ImageN` 0%；末尾阶段算式 = `settings.duration` |
| W3 THE TURN | text 母本 → video 编译 | `@ImageN` 98% + `{{Node}}` + `ACTIVE` + `OUTPUT CONTRACT` | 92 个 text 母本 |

**统一中间格式 = `reference_nodes[]`**（A 路已冻结），每条四件：

~~~text
order       引用位（1-indexed，顺序即参考位序）      ← schema 字段
node_id     画布节点 / 资产锚点                      ← schema 字段
purpose     它供什么（十个枚举之一，不是自由文本）    ← schema 字段
deny[]      不许它供什么（明文排除，不可省）          ← schema 字段
~~~

**编译到具体平台时**才把 `order` 渲染成该平台的语法（`{{Mixed N}}` / `@ImageN` / `<标签N>`）。**中间格式保留语义，不保留某一作的语法**——这样三作各自的写法都能落到同一套计划上，又不互相抄错。

**两条铁律（三作共通，出自实测）**：

1. **插桩 + 有边 + 文字声明** 三者要一致；**插桩但没有边 = 真错误**（W1 实测）；
2. **N 必须等于该 key 在列表里的 1-indexed 位置** —— 回读确认，**绝不靠「上次是几号」推算**；加一条参考 → 后续序号整体 +1。

## 5. 声音包

**按层分条，不按事件个数**（模型 `seed-audio-1.0`，`nodeType=audio` 必带显式 `scene`）。

| 层 | 内容 | 什么时候有 |
|---|---|---|
| 环境床 | 底噪 / 空间声 | 几乎每片都有 |
| 点状事件层 | 脚步 / 关门 / 一记闷响 | 有可见事件时 |
| 对白 / 旁白 | 台词 / `(V.O.)` | 有对白时；`(V.O.)` 不吃口型 |
| BGM | 配乐 | 需要时；必须写它与对白的关系（让路） |

**声音行的四条判据（机检可查）**：

1. 有台词就必须写声线（脸与物都锁成逐字复用的固定文本）；
2. 有配乐就必须写它与对白的关系；
3. 有离散事件声就必须有环境或空间词（否则声场是死的）；
4. 环境层在前、事件声在后。

**闭包纪律**：声音总时长与成片时长对表；各层起止列时间线；AU 先生效再点合成。

**可门禁样例**：`samples/B6_声音_三层声音表.md` —— 六字段表 + `总时长` 声明，`sound_lint.py` rc=0（实测「字段齐备、时间码合法、优先级有效、无空话词、有环境层」）。

## 6. 合成包

| 项 | 内容 |
|---|---|
| 时间线 | `left` 即时间线顺序，必须与放映顺序一致 |
| 混音 | 三层电平；`video_volume=0` 避免视频原声叠进来 |
| 转场 | 取自转场库；组接点四查 |
| 字幕 | 后期字幕规范见 14 号册 |
| 门禁 | `export_readiness` 预检 → `export_video` → `export_status` 收件 |

**子合成树**：≤25 镜 = 1 个 X1；更多按场次拆 `X_sub`，父合成引子合成。

**可门禁样例**：`samples/B7_合成_时间线与字幕.md` —— 时间线表 + 拼接顺序 + 混音 + 转场 + 字幕，`audit_prompt.py timeline` rc=0（实测「覆盖区间 0.0 → 15.0 秒，无空档、无重叠、首镜从 0 起」）。
**该样例的实测教训**：时间列必须写秒不写 `MM:SS` —— 脚本声称支持时间码，但纯数字区间模式排第一顺位，会把 `00:05–00:10` 解析成 `05–00`（见回执 §5.C4）。

## 8. 长片怎么拆

~~~text
场次：一个场景一个包组（锚点集可整组切换）
镜头包：一镜一个视频包（平台单次上限 15 秒，超出必拆）
长镜拆段：同包内多段，段内用先 / 随后 / 最后
合成：子合成 ≤25 镜，超则拆子合成树
声音：按层不按事件，与镜数解耦
~~~

**长片必须显式声明的三件事**：

1. **时间码体系**：全片绝对时间码还是段内相对 —— 跨节点算时长前必须确认；
2. **锚点逐字复述**：身份锚点句每包原句搬过去，禁止近义词替换；
3. **代际退化防线**：每 3 段插一次超分，链式续写的断点落在可直接衔接的帧上。

**来自实产写法的三条可选增强**（`libtv-prompt-anatomy-distilled*.md`，【例子】，不是硬门禁）：

- 用**独立「整体空间锁定」块**一次性写死方位（越轴的唯一治法：方位不交给每一镜重新发明）；
- 先给**机位序列总览**（箭头链），正文 `相机 / 焦段` 与它逐项对应；
- 尾部加**执行锁定**清单，锁的是因果必然性，不是逐镜重复。

## 9. 未决项

- **五块主干 vs 12 块输出**：库内两种输出层口径并存（`libtv-prompt-structure.md` §六 vs `shot-craft.md` 12 块）。本册的处理是「思考层 12 块必须想全；输出层按平台权重收敛」——**这是一条裁定，不是实测**，标【库规】。
- **长镜「阶段分组」的阈值**（>15 镜用阶段分组的建议）来自单作实产（W1），**标【例子】**，不当跨作规则。
- **`prompt_template` 官方模板两条路径已实测全拒**；三视图要用自由文本 + 同一主体多视角并置声明。
