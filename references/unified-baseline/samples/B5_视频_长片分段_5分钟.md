# B5 · 视频提示词样例：长片分段（5 分钟 · 镜头包 + 分包清单）

用途：B 路「视频包」样例之一，演示**长片如何拆成可管理的提示词包**。
门禁：`python3 scripts/audit_prompt.py blocks <本文件>` 期望退出码 0。
分包公式与档位见 `10_输入到计划编译器规范.md` §5 与 `11_提示词包与五类模板.md` §8。

## 一、单个镜头包（示例子包：S03-V07）

```
分镜头脚本，单人单镜，时长15秒，画幅2.39:1（21:9 落地）。

【全片通用 · 后期特效】 每一镜逐字复用，不改字
大气透视：随距离对比度与饱和度逐步损失，越远越灰；
体积感：走廊尽头有薄雾，灯下有浮尘；
高光处理：平滑滚降、渐进出白不裁纯白，过曝处仍带暖色；
调色方向：低饱和，阴影推向青绿，肤色保留暖棕；
颗粒：暗部有机银盐颗粒簇，暗部粗、中间调细。

【全片通用 · 统一提质层】 每一镜逐字复用，不改字
摄影与印片：35mm 胶片，日光型彩色负片拍出来肤色偏暖、阴影不发青、高光有厚度，柯达 2383 印片收尾带来扎实对比与带青蓝的厚实暗部，画幅 2.39:1。
光有出处：一个走廊顶灯从画面上方进入，光先落在磨亮的地面上，曝光优先保脸，另一侧不补光。
运动：机位几乎不动，只保留手持的轻微呼吸浮动。
禁用（只管成像层）：漫剧感，概念图，全画面过锐，硬截断高光，高光裁成纯白。

【全片通用 · 风险移除 + 禁止出现】 每一镜逐字复用，只改方括号里的本镜专属项
他的手始终落在行李箱拉杆上，动作简单、不做手势；
画面里的门牌字迹很小很糊、不可读，需要真字时后期贴。
禁止出现：第二个人，倒影里的人影，背景路人，字幕，水印，文字伪影，现代物品，均匀明亮布光，镜头抖动，随机变焦，同时叠加两个以上的运镜，口型开合，说话，音乐，人声。

【本镜目的】实质推进动作：他从站在门口变成把行李箱推过门槛，这一下把这一场从前厅推进走廊。

【镜头规格】起始景别全景（框到全身与门框）；63°（35mm，中等广角：他与走廊的关系保留，前景箱体有轻微透视放大，走廊纵深仍可辨认），光圈 f2.8，机位高度平视，观察视角斜后方四十五度。

【构图】主体位于画面左侧三分之一，右侧留白给走廊纵深；地面上被踩亮的一条线把视线引向走廊尽头；前景允许一角虚焦的门框入画，增加纵深。

【人物与环境】老周，46岁男性，长脸，下颌线清楚，灰黑色短发、两鬓泛白，左手虎口一道约2厘米的浅色旧疤，深灰色旧呢外套、下摆磨白，随身一只深棕色旧皮箱；他站在门槛外，双手落在拉杆上；呼吸起伏一次，眨了一次眼，重心在两脚之间换过一次；眉内端先压下去、随后下唇往里咬住。
画面里只有他一个人，走廊门玻璃倒影里没有人。
走廊两三件物件：两扇旧木门、一个门牌、墙角一只缺口的花盆。

【光位与影调】光源是头顶的走廊灯，从画面上方进入，影子落在脚下偏右；皮肤哑光，毛孔细纹与胡茬可见，高光只是鼻尖与颧骨顶的小点，眼睛一粒眼神光；眼下略凹、颈部有浅纹，年龄由结构承载。

【时间线】起始：他已经在往前迈了，一只手已经压到拉杆上、重心已经偏到右脚，呼吸起伏很浅但不停，视线落在走廊尽头；主动作：他把行李箱推过门槛，视线从门牌移到走廊尽头；反应与呼吸：手臂的力松开一次，呼吸加深一次，眉先松开、然后口角回落、最后下睑才放松，不要同时回落；定格：他保持站姿，呼吸仍在，视线停在走廊尽头。

【运镜】起始观察点：斜后方四十五度；主运动：极缓跟移约0.5米；全程锁死：构图关系与轴线；全程排除同族运镜：无侧移、无拉出、无变焦、无摇、无环绕；稳定方式：手持，保留轻微人体呼吸浮动；结尾落点：镜头停下时画面停在走廊尽头与他箱子的后轮。

【声音】NO BGM（no background music），只保留现场音：走廊里顶灯的电流嗡鸣、远处车流、箱子后轮在地砖上滚过的两下轻响。

【进入下一镜的过渡压力】下一镜切到走廊尽头同一扇门：动作匹配点是他推箱后轮的最后一推，景别落差从全景跳到中景。

【结尾留白】他不动，目光停在走廊尽头，呼吸仍在。
```

## 二、分包清单（5 分钟长片怎么拆）

| 层级 | 拆分单位 | 本样例取值 | 理由 |
|---|---|---|---|
| 场次 | 一个场景一个包组 | 12 场 | 场与场之间必换空间，锚点集可整组切换 |
| 镜头包 | 一镜一个视频包 | 约 60 镜 | 平台单次生成上限 15 秒，超出必拆 |
| 长镜拆段 | 一镜多段（同包内） | 3 段 / 条 | 段落版，段内用先/随后/最后组织 |
| 合成 | 子合成 ≤25 镜 | 3 个子合成 + 1 总合成 | 超过 25 镜拆子合成树 |
| 声音 | 按层不按事件 | 环境床 + 点状事件 + 对白 3 层 | 与镜数解耦 |

推导（对齐 `libtv-quality-delivery-content.md` §5.4 扩展公式）：

~~~text
节点总数 = 3（剧本 + 总表 + 合成）+ 4N（分镜条目 + 故事板 + 首帧 + 镜头）
           + (C + L + P)（内容锚点）+ D（派生锚点）+ A（声音轨条数）
N = 60 时：3 + 240 + 锚点与派生 + 声音轨
~~~

> 非提示词的代码片段一律用 `~~~` 围栏——`audit_prompt.py` 只把 ``` 围栏当提示词块，
> 用 ``` 装公式会被误当成一个提示词块扫（本文件第一版就踩了这条）。

## 三、长片必须显式声明的三件事

1. **时间码体系**：全片绝对时间码还是段内相对 —— 跨节点算时长前必须确认（`libtv-prompt-anatomy-distilled-part3.md` §19）。
2. **锚点逐字复述**：身份锚点句每包原句搬过去，**禁止近义词替换**（`segmented-shot.md` §五）。
3. **代际退化防线**：每 3 段插一次超分，链式续写的断点要落在可直接衔接的帧上。
