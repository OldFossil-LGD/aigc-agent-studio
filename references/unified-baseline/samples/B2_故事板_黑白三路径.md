# B2 · 故事板提示词样例（黑白静帧）

用途：B 路「故事板包」样例。目标类型 storyboard，静帧类，无时间轴。
门禁：`python3 scripts/audit_prompt.py blocks --storyboard <本文件>` 期望退出码 0。
配套：三路径与失败处方见 `storyboard-frame.md`，平台规格见 `storyboard-platforms.md`。

```
单镜黑白故事板，铅笔速写，纯黑白灰，无任何颜色。
超宽横幅构图，21:9。
起始景别中景，人物偏画面右侧三分之一，面朝画面左侧。
画框下沿停在腰带位置，头顶留出约一头高的空位。
明暗结构：硬光从画面左上方下来，背景接近全白，人物是深灰剪影。
画面里只有他一个人，镜面与窗玻璃里没有人影。
画面里的票据字迹很小很糊、不可读。
```

## 与镜头提示词的分工

| 项 | 故事板 | 镜头提示词 |
|---|---|---|
| 管什么 | 结构、景别、画框边界、明暗块 | 时间线、表演、运镜、声音 |
| 不管什么 | 色温、材质、皮肤、后期 | —— |
| 门禁 | `blocks --storyboard`（跳过声音行与结尾留白） | `blocks`（要 12 块 + 声音行 + 结尾留白） |
