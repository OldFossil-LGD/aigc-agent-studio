# B3 · 视频提示词样例：短片单镜（15 秒）

用途：B 路「视频包」样例之一。目标类型 video，单机位模式，12 块齐。
门禁：`python3 scripts/audit_prompt.py blocks <本文件>` 期望退出码 0；`python3 scripts/ai_smell_check.py <本文件>` 期望退出码 0。
长片/中片的段落版样例见 `B4`、`B5`。

```
分镜头脚本，单人单镜，时长15秒，画幅2.39:1（21:9 落地）。

【全片通用 · 后期特效】 每一镜逐字复用，不改字
大气透视：随距离对比度与饱和度逐步损失，越远越灰；
体积感：窗光柱里有浮尘，地面有薄薄一层冷气；
高光处理：平滑滚降、渐进出白不裁纯白，过曝处仍带暖色；
调色方向：低饱和，阴影推向青绿，肤色保留暖棕；
颗粒：暗部有机银盐颗粒簇，暗部粗、中间调细。

【全片通用 · 统一提质层】 每一镜逐字复用，不改字
摄影与印片：35mm 胶片，日光型彩色负片拍出来肤色偏暖、阴影不发青、高光有厚度，柯达 2383 印片收尾带来扎实对比与带青蓝的厚实暗部，画幅 2.39:1。
光有出处：一个窗光从画面左上方进入，光先落在桌面上，曝光优先保脸，另一侧不补光。
运动：机位几乎不动，只保留手持的轻微呼吸浮动。
禁用（只管成像层）：漫剧感，概念图，全画面过锐，硬截断高光，高光裁成纯白。

【全片通用 · 风险移除 + 禁止出现】 每一镜逐字复用，只改方括号里的本镜专属项
他的手始终落在桌沿上，动作简单、不做手势；
画面里的票据字迹很小很糊、不可读，需要真字时后期贴。
禁止出现：第二个人，倒影里的人影，背景路人，字幕，水印，文字伪影，现代物品，均匀明亮布光，镜头抖动，随机变焦，同时叠加两个以上的运镜，口型开合，说话，音乐，人声。

【本镜目的】施加戏剧压力：他从低头核对变成抬起头，这一下是他在这一场里第一次停手。

【镜头规格】起始景别中景（框到腰部以上）；63°（35mm，中等广角：人物与桌面的关系保留，前景桌角有轻微透视放大，背景仍可辨认），光圈 f2.0，机位高度平视，观察视角肩后四十五度。

【构图】主体位于画面左侧三分之一，右侧留白；桌沿横线把视线引向他的手腕；前景允许一角虚焦的椅背入画，增加纵深。

【人物与环境】老陈，42岁男性，方下颌，黑色短发、发际线在额角略后退，左眉中段一道约3厘米的浅白色旧疤，藏青色旧式邮电工作服、袖口磨白，随身一串铜钥匙；他坐在凳子上，双手放在桌沿；呼吸起伏一次，眨了一次眼，重心在两脚之间换过一次；眉内端先压下去、随后下唇往里咬住。
画面里只有他一个人，窗玻璃倒影里没有人。
桌上两三件物件：一盏旧台灯、一叠票据、一只有磕碰的搪瓷杯。

【光位与影调】光源是窗光，从画面左上方进入，影子落在桌面右侧；皮肤哑光，毛孔细纹与胡茬可见，高光只是鼻尖与颧骨顶的小点，眼睛一粒眼神光；鬓角有少量白发，发际线在额角略后退，眼下略凹，年龄由结构承载。

【时间线】起始：他已经在往前倾了，一只手已经压到桌沿、重心已经偏到右脚，呼吸起伏很浅但不停，视线落在票据第三行；主动作：他抬起头，视线从桌面移到门口；反应与呼吸：呼吸加深一次，眉先松开、然后口角回落、最后下睑才放松，不要同时回落；定格：他保持坐姿，呼吸仍在，视线停在门口。

【运镜】起始观察点：肩后；主运动：极缓推近约0.3米；全程锁死：构图关系与轴线；全程排除同族运镜：无侧移、无拉出、无变焦、无摇、无环绕；稳定方式：三脚架，保留轻微人体呼吸浮动；结尾落点：镜头停下时画面停在桌面与他的手腕。

【声音】NO BGM（no background music），只保留现场音：房间里的旧台灯电流嗡鸣、窗外远处的车流、纸张翻动的一下摩擦声。

【进入下一镜的过渡压力】下一镜切到他抬头的视线落点：门口。

【结尾留白】他不动，目光停在门口，呼吸仍在。
```
