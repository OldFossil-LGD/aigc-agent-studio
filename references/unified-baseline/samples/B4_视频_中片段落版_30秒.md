# B4 · 视频提示词样例：中片段落版（30 秒 · 3 段落）

用途：B 路「视频包」样例之一。目标类型 video，段落版（一条里换景别）。
门禁：`python3 scripts/audit_prompt.py blocks <本文件>` 期望退出码 0。
动笔前先算档位：`每段秒数 = 总时长 ÷ 段数`；30 秒 → 5–8 段，每段 6–3.7 秒，**段数按动作可读性定**。

```
单条多镜（含 2 个镜头切换），时长30秒，画幅2.39:1（21:9 落地），日式日常静观：高调过曝、低对比、几乎单色偏暖白，机位几乎不动。

【全片通用 · 后期特效】 每一段逐字复用，不改字
大气透视：随距离对比度与饱和度逐步损失，越远越灰；
体积感：窗光柱里有浮尘，地面有薄薄一层冷气；
高光处理：平滑滚降、渐进出白不裁纯白，过曝处仍带暖色；
调色方向：低饱和，阴影推向青绿，肤色保留暖棕；
颗粒：暗部有机银盐颗粒簇，暗部粗、中间调细。

【全片通用 · 统一提质层】 每一段逐字复用，不改字
摄影与印片：35mm 胶片，日光型彩色负片拍出来肤色偏暖、阴影不发青、高光有厚度，柯达 2383 印片收尾带来扎实对比与带青蓝的厚实暗部，画幅 2.39:1。
光有出处：一个窗光从画面左上方进入，光先落在木地板上，曝光优先保脸，另一侧不补光。
运动：机位几乎不动，只保留手持的轻微呼吸浮动。
禁用（只管成像层）：漫剧感，概念图，全画面过锐，硬截断高光，高光裁成纯白。

【全片通用 · 风险移除 + 禁止出现】 每一段逐字复用，只改方括号里的本段专属项
她的手始终落在桌沿上，动作简单、不做手势；
画面里的信纸字迹很小很糊、不可读，需要真字时后期贴。
禁止出现：第二个人，倒影里的人影，背景路人，字幕，水印，文字伪影，现代物品，均匀明亮布光，镜头抖动，随机变焦，同时叠加两个以上的运镜，口型开合，说话，音乐，人声。

【全局约束】恰好 3 个段落、2 个切换点。段落 A 中景跨到近景，跨 ≥2 级；段落 B 近景跨到中景，跨 ≥2 级；段落 C 中景跨到全景，跨 ≥2 级。全片一个机位家族，段内不换机位高度。画面里始终只有她一个人。

【本段目的】改变人物情绪：她先从端坐等消息变成把信纸按回桌面，代价是她的手离开了信纸。

【本段共用 · 镜头规格】球面镜头，起始景别中景（框到腰部以上），47°（45mm，眼平中性：她与桌面的距离关系保留，前景信纸有轻微透视放大，背景房间仍可辨认），光圈 f2.8，起始机位高度平视，起始观察视角斜后方四十五度，起始机位距主体约1.2米。

【本段共用 · 光位与影调】光只有一个来源：窗，从画面左上方下来，软、过渡宽；光先落在木地板上，人只是接受它的一部分；曝光优先保住面部；另一侧不补光，直接沉进浅灰。人物光影块：脸上的光只来自窗光；皮肤哑光，毛孔细纹可见，高光只是鼻尖与颧骨顶的小点；眼下略凹、鬓角少量白发，年龄由结构承载。

【本段共用 · 声音】无配乐，只保留现场音：室内旧木地板的轻微吱响、窗外远处的车流、纸张落下的一记轻响。

【本段共用 · 人物与环境】阿岚，34岁女性，圆脸，颧骨不高，黑色中长发、发尾平齐，右手腕内侧一道约2厘米的浅色旧疤，米白色棉布衬衫、袖口卷起，随身一只旧银镯；她坐在木桌前，双手放在桌沿；呼吸起伏一次，眨了一次眼，重心在椅面前后换过一次；眉内端先上抬、随后下唇往里咬住。
画面里只有她一个人，窗玻璃倒影里没有人。
桌上两三件物件：一叠信纸、一只白瓷杯、一盏旧台灯；台灯灯罩边缘掉漆，杯口有一处缺口，桌面一角磨白。

【时间线 · 段内变化】
先：她已经在读第二页了，一只手已经压在信纸下缘、重心已经偏到椅子前沿，视线落在信纸末行，呼吸起伏很浅但不停；
随后：她读完最后一行，视线从信纸移到窗外，眉先松开、然后口角回落、最后下睑才放松，不要同时回落；
最后：她把信纸按回桌面，手离开纸面，呼吸加深一次，视线停在窗外。

【运镜】起始观察点：斜后方四十五度；主运动：极缓推近约0.3米，段内不改机位方向；全程锁死：构图关系与轴线；全程排除同族运镜：无侧移、无拉出、无变焦、无摇、无环绕；稳定方式：三脚架，保留轻微人体呼吸浮动；结尾落点：镜头停下时画面停在桌面与她的手。

【进入下一镜的过渡压力】下一段从她视线的落点接：窗外同一扇玻璃，景别落差从她脸部跳到窗外街景，声音桥是那记纸张轻响。

【结尾留白】信纸留在桌面上，她不动，目光停在窗外，呼吸仍在。
```
