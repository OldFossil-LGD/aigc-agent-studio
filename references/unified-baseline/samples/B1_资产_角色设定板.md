# B1 · 资产提示词样例：角色设定板（九块协议）

用途：B 路「资产包」样例。目标类型 asset，静帧类，无时间轴。
门禁：`python3 scripts/audit_prompt.py blocks --asset <本文件>` 期望退出码 0。
说明：本文件放在 `outputs/` 下，不是 `references/`，因此**不会被规格文档守卫跳过**，是真会被查的样例。

```
一张完整的角色设定板，超宽横版 16比9 排布九个编号分区，分区之间用细白线分隔，浅灰白背景。
调性行：1970年代中国北方小城，阴天午后，室内；材质以棉布、搪瓷与黄铜为主。

分区1 身份锚点冻结块：他42岁男性，方下颌，颧骨不高，黑色短发、发际线在额角略后退，左眉中段一道约3厘米的浅白色旧疤，右手背一道横向旧伤，藏青色旧式邮电工作服、袖口磨白，随身一串铜钥匙。这一段逐字复用、永不改写。

分区2 全身三视图：并排站立，正面、左侧、背面，全身入画，双手自然下垂，穿完整服装，其余五官与发型完全不变。

分区3 面部特写：正面，眼神平视前方，眉毛、眼型、鼻形与分区1完全一致，其余五官不动。

分区4 色板：六列两行网格色块，即全片调色基准。

分区5 服装细节：藏青色旧式邮电工作服，领口起皮，右肘磨出底色，第二颗扣子褪色。

分区6 随身物：一串铜钥匙，三把，钥匙柄掉漆露出黄铜色，钥匙环里积灰。

分区7 手部特写：右手背一道横向旧伤，指节皮肤粗糙，指甲边缘有磨损。

分区8 尺度参照：他与一扇标准门框并立，头顶距门框上沿约一头高。

分区9 材质与受光：布料哑光、不反光，纤维可见；皮肤哑光、毛孔可见；接触阴影落在领口与钥匙环下缘。
```

## 逐块自检（对照 `block-playbook-asset.md` 板块 1–9）

| 块 | 断言 | 本样例 |
|---|---|---|
| 1 板式行 | 比例写成数字 + 分区数 + 分隔方式 | 16比9 / 九个编号分区 / 细白线 |
| 2 身份锚点 | 40–70 字可判物理事实，不写气质 | 年龄写死 42，疤写位置+长度+颜色 |
| 3 分区清单 | 每格编号 + 视角 + 一个变量 | 每分区只变一个变量，其余写明不变 |
| 4 美学调性 | 类型/材料/年代可判 | 调性行（年代 + 时段 + 内景 + 材质） |
| 5 材质与脏 | 逐处写脏、位置+形态+尺寸 | 起皮 / 磨出底色 / 褪色 / 掉漆 / 积灰 / 磨损 |
| 6 尺度关系 | 有可比参照物 | 与标准门框并立 |
| 7 色板 | 调色基准 | 分区4 六列两行 |
| 8 布光 | 中性可继承，不写戏剧光 | 分区9 只写材质受光响应，不写光位方向 |
| 9 统一提质层 + 禁止项 | 资产版提质 + 禁止项 | 见下 |

## 本样例未放的内容（有意为之）

- 不放时间线、表演、物理反馈、摄影机运动、过渡压力、声音、结尾留白——**资产没有时间轴**，塞进去模型会开始编动作。
- 不写戏剧光、浅景深、暗角、光晕——那些是镜头阶段的活，写进资产图会被下游每一镜继承。
- 人物多视图设定板只作设计稿，不作参考素材；出片参考要另出干净大头照 + 全身照两个独立文件（`asset-consistency.md` §3.0）。
