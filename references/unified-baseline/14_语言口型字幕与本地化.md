# 14 · 语言 · 口型 · 字幕与本地化

任务：统一基准重构 · B 路
日期：2026-10-07

> **本文回答**：中文 / 英文 / 口型 / 字幕 / 配音 / 本地化的边界在哪，什么时候该绕开，什么时候该换结构。
>
> **一句话边界**：**口型不是「能不能做」，是「用什么景别、几句台词、配不配乐」的组合问题**；字幕不是「加不加」，是**后期工序 + 画面内文字的污染源**。

---

## 1. 四层语言，别混成一层

一个 AI 视频项目里同时存在四种「语言」，改一层不影响另一层：

| 层 | 是什么 | 谁管 |
|---|---|---|
| **提示词正文语言** | 写给模型的描述 | 中文为主；术语按需补英文 |
| **台词语言** | 角色嘴里说的 | 剧本；逐字锁定 |
| **音轨语言** | 实际发出的声音 | 声音包（TTS / 克隆音色 / 后期对口型） |
| **画面内文字** | 招牌 / 信件 / 字幕 / 屏幕 | **默认要压掉**，需要时后期贴 |

**高频错误**：把「台词语言」当成「音轨语言」—— 写了台词不等于模型会有人声；`enableSound=off` 时声音不写进 V 层执行口径。

## 2. 口型：两条路线

| 路线 | 工具 | 什么时候用 |
|---|---|---|
| **生成时带口型** | 即梦 / Seedance、可灵、Runway、Sora | 台词短、正脸、单人、场景可控 —— 一次成片省管线 |
| **先生成画面再后期对口型** | 可灵对口型、Sync.so、Hedra、LatentSync | 已有画面要换台词、**多语配音**、台词较长 |

**判定口径（`feasibility.md` §2026-09-13 复核）**：口型已从「黑名单」**降级为「有条件可用」**。

### 2.1 可用条件（五件齐）

~~~text
景别：中景 / 中近景（不要特写）
人数：单个说话者
台词：一句短台词
音频：写「无配乐」
文字：显式声明无字幕
~~~

**★ 景别是口型的第一调节旋钮**：**特写对口型时机压力最大，中景 / 中近景更宽容**。这是「改结构」的第一手段 —— 不是把口型整类删掉。

**降级路径**：换景别 → 缩短台词 → 拆镜。**不要把整类能力删掉**。

### 2.2 中文口型的失败根因（不是模型笨）

~~~text
闭唇音 b / p / m
卷舌 zh / ch / sh / r
儿化与轻声
~~~

这三类超出默认模型的对齐精度。**修法（外部对口型工具，本平台生成节点不暴露这些参数）**：

~~~text
开音素级对齐
口型延迟补偿 −60 ~ −90 ms
唇动幅度 0.65–0.78
强制闭口帧插值
~~~

### 2.3 生成时带口型的写法

**必须写语速停顿标注**：`低声哽咽+缓慢："……"`。

> **只写台词不标语速停顿，口型必翻车。**

**英文侧可借用的短语**（多源一致，作为术语锚）：`mouth movement matches the words without exaggerated expression`。

**顺手写一句「无字幕 / no subtitles」** —— 无害，且能压画面内文字。

> **不采的说法**：某来源称「绝对禁止引号，引号会触发视觉文字渲染导致字幕」。本库只采「显式写无字幕」这条低成本做法。

## 3. 配音与声线母档

### 3.1 声线母档（防「每场戏嗓音都不一样」）

**后果是实测过的**：同一个角色每场戏的嗓音都不同 —— 同一条声线描述，模型每次给出的音色都在飘。

**规则**：**每个说话的角色一份声线母档，写一次，之后每次他开口就逐字粘进【声音】块，永不重写。**

~~~text
[音色；音域范围（耳语—满声）]。
~~~

走平台 TTS 时：**声线母档 + 当句台词一并写入 TTS 节点 prompt**（平台要求逐字台词与音色 / 语气同写）。

**三条写法纪律**：

1. 音色先定，情绪后加；
2. **别只写情绪标签** —— `愤怒地说` 只给了情绪，没给音色；
3. 换角色 = 换母档，不是改一句话。

### 3.2 音色克隆（LibTV 实操）

| 项 | 内容 |
|---|---|
| 入口 | 新建音频节点 → 模型选 **Minimax Speech** → 高级设置 → 切换音色 → 我的音色 |
| 克隆 | 右下角切换音色 → 我的音色 → 克隆新音色 |
| 朗读建议 | **安静环境、清晰、语速适中，尽量读 115 秒以上**；**朗读时带入情绪，克隆出的音色会带该情绪** |
| 试听检查 | 与原音色相似度 · 清晰无杂音糊音爆音 · 语速稳定 · 听感自然 · 情绪表达到位 |
| **硬约束** | **创建音色后 7 天内未使用会被 MiniMax 官方 API 清除** → **创建完立刻使用一次，即可永久保存** |

**★ 描述不只作备注**：音频节点的「名称 / 音色 / 描述」里，**描述会被系统自动拼接到提示词中参与生成**。

### 3.3 合规（不可省）

~~~text
AI 生成内容须显式 + 隐式标识
只用自有或已授权音色，并打标
克隆未授权 / 未加 AI 标识 = 合规风险
~~~

**商用片随交付附授权清单**（参考帧 / 音乐 / 字体的授权状态 → `sources-and-credits.md`）。

## 4. 字幕

### 4.1 生成阶段：字幕是要「压掉」的污染源

| 做法 | 说明 |
|---|---|
| 显式写「无字幕 / no subtitles」 | 低成本、无害 |
| 画面里的字迹写「很小很糊、不可读」 | 需要真字时**后期贴** |
| 参考素材里的文字**先清掉** | 画面里冒出字幕多数来自参考素材 |
| 风险排序 | 横屏比竖屏概率低 |

**机器判据**：视频包的【风险移除】块必须写「字幕、水印、文字伪影」。

### 4.2 后期字幕规范（`post-production.md` §七）

| 项 | 规范 | 标签 |
|---|---|---|
| 字体 | 黑体为主；**楷体限旁白 / 书信等特殊语体**（避免宋体细横画） | 【库规】中文规范，编号与数值**待核标准原文** |
| 颜色 | 对白字幕白色 | 同上 |
| 行长 | ≤15 字 / 行 | 【库规】 |
| 高度 | 约 5% 画面高度 | 【库规】 |
| 安全区 | 字幕区不超出画面 80% 对称区域；走安全框 | 【库规】 |
| 片头片尾 | 4K 片名字幕 ≥80 像素；片尾滚动不闪烁 | 【库规】 |

> **来源标注**：中文规范引 NRTA GY/T 357-2024；**编号与数值待核标准原文** —— 这条按【库规】用，不当平台事实。

## 5. 本地化：四件一起做，不是逐件补

触发条件（`thinking-pipeline.md` §12.9，Step 0 识别）：**多语言 / 本地化 / 多平台分发 / 观众试映**。

~~~text
1 口型重配（配音换语言 → 走「后期对口型」路线，不是重生成）
2 字幕轨（按目标语言的字幕规范，与 4.2 同表）
3 画面内文字多语（招牌 / 信件 / 屏幕 → 一定要后期贴，不要让模型画）
4 文化禁忌与文化符号核对
~~~

**多平台分发的一条硬纪律**：**在排镜阶段就做安全框与构图双版本，不是导出时裁画幅。**

**为什么**：导出时裁画幅 = 裁掉构图里已经写进提示词的主体位置（「主体位于画面左侧三分之一」被裁掉左侧三分之一）—— 那不是适配，那是毁片。

### 5.1 旁白是最划算的本地化路径

**`(V.O.)` 是本库最划算的写法 —— 不吃口型**（`script-format.md` §213）。

配套：`(O.S.)` 是「声场」（人在画面外但同一空间），`(V.O.)` 是「旁白音轨」。**本地化时只换音轨，画面一字不改。**

## 6. 双语提示词的边界

**中文提示词里可以出现英文，但只有两种情形**：

| 情形 | 例子 | 判据 |
|---|---|---|
| **术语锚**（中文动作词有多种视觉解读时） | `Sliding Tackle`（美式橄榄球式低身滑行，不是摔倒）· `Whip Pan Split` · `Barrel Roll Free-fall` | **一个中文动作词有多种视觉解读时补一个英文专业术语把它钉死** —— 比写三行中文更省字数 |
| 平台字段 / 精确术语 | `NO BGM` · `no music` · `enableSound=off` | 是接口字段或平台已认的写法 |

**同族术语**（写作时可查）：`Jetpack Burst`（暗示有推进器，不是纯弹跳）· `Knee Slide` · `Flesh Knitting` · `Optical Distortion` · `Rigid Body Destruction`。

> **英文术语的定位（诚实标注）**：中英双写是**某位 owner 的习惯，不是平台门禁**；建议**只在中英歧义确实存在处使用**。标【例子】，可改。

**机器会报的反例**：**中文短语后面硬跟一个英文括注**（`电影感（cinematic feel）` 这类）——`ai_smell_check.py` 判为「双语并列」，属 AI 味特征。

## 7. LibTV 声音节点落地（与语言相关的部分）

| 项 | 约束 |
|---|---|
| 节点类型 | `nodeType=audio` **必带显式 `scene`** |
| 模型 | `seed-audio-1.0` |
| 分条 | 按「连续层 / 点状事件层」分 2 条 |
| 接线 | **只接合成，不接镜头**（V 层 `enableSound=off`，声音在合成端叠加） |
| 顺序 | 点火顺序约束：AU 先生效再点合成 |
| 冲突 | **V 层 prompt 详写声音与 `enableSound=off` 打架**（R50 实抓）—— V 层不写声音执行口径 |

**参考音色 / 声线的两条路**：有素材优先用素材锁（上传声线）；没有素材就用文生音色描述 + 声线母档。

## 8. 边界与未决项

**边界（一句话）**：

- **口型**：中景 / 中近景 + 单说话者 + 一句短台词 + 无配乐 + 无字幕 —— 五件齐才做特写硬碰；
- **字幕**：生成阶段压掉，后期阶段按规范贴；
- **本地化**：改音轨与字幕，画面不改；要改画面内文字，一律后期。

**未决项（标【不可判定】，不进强制门禁）**：

- 后期对口型的四个参数（延迟补偿 / 唇动幅度 / 闭口帧插值 / 音素对齐）**只在外部工具适用**，本平台生成节点不暴露 —— 没有本平台的实测值；
- 中文字幕规范引 NRTA GY/T 357-2024 的**编号与数值待核标准原文**；
- 「朗读 115 秒以上」是课程建议值，**不是平台校验规则**（标【库规·来自 LibTV 官方课程】）；
- 多语版本的口型重配对白时长的影响，**未测**。
