# 人物描写深度（通用方法，不是填空模板）

> **何时读**：写人物描写与表演之前。**读完回哪**：回到 `motion-control.md` 或 `shot-craft.md` 写动作层。
>
> **分工**：本文管"**这个人物是谁**"（外观 / 体态 / 习惯 / 矛盾 / 中间态）。
> **这一镜怎么演、怎么破掉"虚假"、对手戏怎么接、表演怎么练 → `performance-craft.md`**（本文不重复那部分）。
> **情绪词换不出形变、要查按情绪的微节拍词表 / 眼生命 / 表演主档案模板 → `performance-vocabulary.md`**。
> **人物"够细了但就是不像人"（好看但记不住 / 对称过头 / 静息像雕塑 / 说不出的瘆人）→ `character-realism.md`**（个体化配额 · 生理活性 · 静息微动 · 恐怖谷三步诊断）。
> **"这个人是谁、从哪来"（角色档案 / 小传的字段、推导与句架）→ `character-sheet.md`**（**小传只给你自己用，交付的只有"可见物"那一层**）。

> 为什么单列这一份：只写"32岁、短发、旧卫衣"——那是**道具清单**，不是人物。
> 人物要能被看见，靠的是**三层**：长什么样（外观）→ 怎么占空间（体态）→ 怎么动、怎么反应（行为）。
> 这份文件教**怎么想**，不提供逐字模板；落地句式随角色与情境自己写。

## 一、三层：从"像什么"到"是谁"

| 层 | 回答的问题 | 浅的写法 | 深的写法 |
|---|---|---|---|
| **外观层** | 他长什么样 | 32岁东亚男性，短发，旧卫衣 | 每一处特征都**指向一段经历**：发际线后缩但两侧翘着碎发（自己剪的）；右眉尾浅疤（谁在哪一年留下的）；右手食指第一节横向压痕（常年握某种东西） |
| **体态层** | 他怎么占这块空间 | 他坐着 | 他坐的时候**把身体收得很小**：肩膀向前扣，膝盖并着，一只手压在另一只手上面——像在公共场合不想被注意到 |
| **行为层** | 他怎么动、怎么反应 | 他抬头看她 | 他先**不动**，只有喉结滚了一下；然后视线从桌面移到她的鞋，再到脸——每一段都有停顿 |

**判断标准**：把名字换掉之后，这段描写还能安在别人身上吗？能，就是太浅。

## ★★★ 表情动作的下限（每镜 / 每画面必过，2026-09-15 立）

本库此前只有**上限**——「每镜只写一到两个关键动作，**深度不等于数量**」。**没有下限的后果不是写多，是写空**：
一句"他面无表情"也能过关。所以补这一条，**它管的是深度，不是数量**。

**下限＝至少把「一处」写透四层**（**只写一处，但要写透**）：

| 层 | 问自己 |
|---|---|
| ① **外观** | 这一处痕迹是什么？它指向哪一段经历？ |
| ② **体态** | 他怎么占空间——重心在哪、肩怎么挂、手放在哪、脚怎么站？ |
| ③ **行为** | 他怎么动——起点、过程、落点各是什么？ |
| ④ **矛盾** | 他想让人看见什么？身体在哪背叛他？ |

**外加两项，每镜必写**（2 秒级过场配角镜按 §十二 的 ≥3 秒门槛分流，不必写全）：
- **眼的落点**——看哪里、什么时候移开（本库既有「眼不可选」，此处给出它该写什么）
- **呼吸**——在哪一拍屏住、在哪一拍松开

**★ 与上限的关系（两句一起用）**：**写透一处 > 罗列十处**。一处写满四层，胜过十处各写一句。
**★ 这三样各落在哪**：第 7 块【人物与环境】写 ①②；第 9 块【时间线】的「主动作 / 反应与呼吸」写 ③④ 与眼、呼吸。
（分段镜的段落版同一套：① ② 写进【本段共用 · 人物与环境】，③④ 写进【★ 时间线】的每个画面。）
**★ 面部（五官）要写"哪块肌肉、往哪个方向"，不许写情绪词**（2026-09-16 补 · 解剖底在 **`expression-anatomy.md`**（**情绪 → AU 组合总表**＋**情绪 × AI 崩坏对照表**））：
情绪词（悲伤 / 忍住 / 难过）**换不出形变**——面部这一层必须落到**具体的肌肉位移**：
- **眉内端上抬（额肌内侧束 / AU1）是"悲伤"与"愤怒"的分界**：**只皱眉无眉内端上抬＝愤怒；两者同时有＝悲伤**。**模型最常漏的就是眉内端那一下**——漏了就成"她在生气"。
- **写"忍"要写下巴**（颏肌：上提并皱缩下颏皮肤，**比嘴角更早动**）；**嘴角下弯是"斜向下"**（降口角肌），不是垂直下拉。
- **眼泪不许一步到位**（写"泪流满面"＝省掉了蓄与盈）→ **眼泪四阶段**与**压抑型四档**（日式文艺 / 内敛路数专用）见 **`expression-rhythm.md` §4 · §4.4**；按压情绪的微节拍与眼生命 → `performance-vocabulary.md`。
**★ 不适用**：**没有人物的空镜**（纯环境 / 纯道具）——这时把这份预算花在**环境自己的"表演"**上（草木怎么动、水面怎么皱、尘怎么落）。
**★ 与"过载"的边界**：写到四层是**深度**，不是让你**堆事件**。若一镜里出现**两个各自完整的动作**，
那不是"再写细点"，是**该拆镜**（→ `shot-craft.md` 的「拆镜开关」）。

## 二、外观层：让细节携带信息

写外观时，每一笔问一句"**这道痕迹是什么事留下的**"。没有信息量的细节就是噪音。

- **骨相与体态**：脸型/骨架决定剪影（方下颌=硬，圆肩=软）。
- **岁月与职业痕迹**：老茧的位置、晒痕的分界线、指关节的粗大、牙齿的缺口、指甲的整洁程度。
- **一次性的痕迹**：今天才有的——袖口的水渍、鞋上的泥、被风吹乱的头发。
- **服装的状态而非款式**：*穿什么牌子*没意义；*卷起的袖口、磨白的肘部、缺的一颗扣子、口袋鼓出来的轮廓*才有意义。

**随身物的用法**：不是"他带着一把扳手"，而是"**扳手柄上缠的胶布已经换过三次，颜色一层深一层**"——物件自己会讲故事。

## 三、体态层：姿态比脸诚实

> 写作共识：**姿态往往比面部表情更诚实，因为我们对自己身体的控制没那么自觉。**

写姿态的四个维度：

| 维度 | 两极 | 写法 |
|---|---|---|
| **占据空间** | 舒展（自信/放松）↔ 收缩（防御/疲惫） | 他把椅子往后推了半掌，让膝盖有地方放 / 他把脚收进椅子下面 |
| **朝向** | 正对（开放）↔ 侧转（回避） | 他身体朝着门的方向，只有头转过来 |
| **高度与重心** | 挺、沉、前倾、后撤 | 重心压在左脚，右脚虚点着地——随时准备起身 |
| **静止的质量** | 松垮的静 ↔ 绷住的静 | 他不动，但下颌的线条一直紧着（**这是"克制"的写法**） |

**姿态要会变**：一个镜头里姿态的**位移**就是情绪弧线——从松到紧、从挺到塌，比任何表情描写都直观。

## 四、习惯层：一两个"签名动作"，长在职业与前史上

- 习惯动作要**能从他的经历解释出来**：老收音员会先拍两下机器再拧旋钮；常年握笔的人用拇指蹭食指的压痕。
- 数量克制：**一个角色一到两个**就够，重复出现才成为"签名"。
- **关键技巧**：同一个习惯，**情绪不同时形态不同**——
  - 平静时：慢慢蹭；
  - 紧张时：蹭得更快、更频繁；
  - 压不住时：改成用力掐（"习惯变形"＝情绪升级）。

这一条比写十个表情都有效：观众会通过"这个动作变了"读到情绪。

### 四·补 ★ 表演母档：把上面三层固定成**一份可复用的文档**（2026-09-17 外部学习补）

**为什么要有母档**：**模型没有记忆**（本库既有前提）——所以"这个角色怎么演"**必须是一份固定文本**，
每个镜头**整段粘进去**，而不是凭手感每次重写。**母档 = 表演层的身份锚点句。**

**★ 模板（固定顺序，照这个填）**：

```
【角色名】的表演母档。
[年龄 / 体型 / 体态 —— 身体即传记：重心在哪、站法、肩线]
[内驱力：一句能解释他身体的话]
声线：[音色 + 音域范围 + 语速与说话方式 + 紧绷时哪里会破]
身体习惯：[用逗号列 2–4 个签名动作；每个都要带触发]
眼生命：[视线行为 / 眨眼节律 / 他"读懂"的那一下长什么样]
织体：[压力击穿伪装时，什么先变 —— 这一条是"破绽的指针"]
弧光制造器：[压力下他会做的那件很小的事]
```

**★ 三条纪律**：
1. **只写摄像机看得见的东西**——不许写"他很紧张"，写"呼吸停半拍、指节发白"。
2. **每个习惯都要有触发**——**没有原因的行为是装饰，不是习惯**。
3. **母档里不写服装、不写机位、不写调色**（那是别的块的事）。
**篇幅**：**一到两段、90–200 字**。

**★ 母档 ≠ 每镜照抄**：进到具体场景要**按当下的身体条件与目标改写一份"场景表演稿"**，
但**母档里的特征要保留**——**动作可以换，认得出的那股劲要在**
（例子：一个走路爱敲手指的人坐到沙发上没法踱步，**手指的敲击、身体的轻晃、略显僵硬的转身还可以留下**）。
> **证据强度（`governance-law.md` L4·补2）**：**单源**（273 份语料里 2 份含 `master (acting) profile`）。
> **走「机制可独立论证」门槛采纳**：**"模型没有记忆 → 固定文本 + 逐字复用"是本库既有铁律**（身份锚点句、统一提质层都靠它），
> 母档只是**把同一条铁律用到表演层**。**状态按 L6 记为「拟订」**。
> **来源**：`acting-skill`（站点公开技能 · 一手，原件见 `outputs/higgsfield_skills_原件/`）。

## 五、微表情层：写"一闪而过"，不写情绪词

微表情是**不受控制的真实情绪泄漏**。它和"他表现出来的样子"之间的落差，就是深度。

### 5.0 先定时长（**写"不到一秒"是错的量级**）

**微表情是一两帧的事，不是"半秒的可见表情"。** 三档对照（**24fps 下 1 帧 ≈ 42 毫秒**）：

| 类 | 时长 | 折算 | 可控性 |
|---|---|---|---|
| **微表情**（压抑中的泄漏） | **40–200 毫秒**（经典定义 1/25–1/5 秒） | **约 1–5 帧** | 不可控 |
| **普通表情**（社交信号） | **0.5–4 秒** | 12–96 帧 | 可控 |
| **两者的边界** | **200 毫秒**（识别率拐点：短于此随时长上升，长于此不再上升） | 约 5 帧 | —— |

> **`key-decisions.md` C10「峰值停留 1–2 帧」取本区间（1–5 帧）的短端＝写实峰值档**——写实向把峰值当"一两帧"处理，不是"演半秒"。
> **依据**（逐条 → `sources-and-credits.md`）：Ekman & Friesen 1974（1/25–1/5 秒为经典定义；Ekman 本人另用过 <1/4 秒、<1/3 秒）· Yan 等实证（下限约 170、上限约 500 毫秒）· Shen 等识别侧（**200 毫秒为拐点**）· 普通表情 0.5–4 秒为通行对照口径。

**★ 两条边界（别把微表情用错）**：

- **只限六种基本情绪**：微表情只出现在**高兴 / 悲伤 / 愤怒 / 厌恶 / 恐惧 / 惊讶**六类之内（至今未发现超出基本情绪的）。**"释然的惆怅"这类复杂情绪不许用微表情写**——它要靠行为与物件（→ `character-realism.md`）。
- **允许"只动一处"**：**完整情绪表达（释放 / 峰值）要三区同拍**（→ `performance-craft.md` §四 1）；**被压住的泄漏可以只动一处**——真实微表情**既可能整脸，也可能是某几块肌肉**，且呈**碎片化**。**两套规则不冲突：看这一拍是在"演"还是在"漏"。**

### 5.1 三样写法 + 肌肉动作表

- **复合表情**（同时有两种相反的肌肉状态）：嘴角在笑，眼眶是干的；眉头是松的，眼睑却在跳。
- **一闪而过**：情绪先露一下、再被压回去——`他脸上有什么东西闪了一下，随即被按平`。
- **转折句**：`笑到一半僵住` / `刚要开口又抿住` / `点头点到一半停住`——**转折永远比单一状态好看**。
- **面部肌肉的具体动作**（替代"皱眉/微笑"）：
  - 眉：向内收（困惑/不忍）· 中段上提（悲伤/恳求）· 一高一低（怀疑）· 完全抬进发际（震惊）
  - 眼：瞳孔放大定住（惊愕）· 视线游移不敢停（心虚）· 眼睛发平发干（情绪关闭）· 眼睑下端绷紧（强忍）
  - 嘴：抿成一条线（压制）· 单侧上扬（不屑/自嘲）· 下唇内收咬住（忍）· 嘴角抽动一下（快绷不住）
  - 颌：牙齿咬紧但嘴不动（怒/忍）· 下巴微微前伸（倔）· 下颌松开下垂（放弃）

## 六、矛盾：深度的捷径

> **最动人的身体语言永远在"说的话"和"身体做的事"之间打架。**

身体比语言诚实，所以写**矛盾**：

| 表面 | 身体背叛 |
|---|---|
| "没事。" | 手在抖 / 指节发白 / 把杯子攥得太紧 |
| 他很平静 | 呼吸变浅了；下颌一直在紧 |
| 她笑着说好 | 笑停在嘴边，眼睛没跟上 |
| 他转身要走 | 脚动了，肩膀还朝着她 |

**一条通用公式**：`他表面上[想让人看见的]，但[身体其中一处]出卖了他。`

## 七、呼吸与静默：静止时的诚实

- **呼吸**：急促浅（紧张）· 长长的一口（放下）· **停住**（最有效的"震惊"）· 刻意压着（强忍）。
- **静的时候也要写微动**：一次眨眼、喉结的一次滚动、指头在膝盖上敲半下又停。
- **写"不动"时要写清是哪种不动**：放松的塌 vs 绷紧的僵——两种完全不同的表演。

## 八、写之前的三个问题（照这个问自己）

1. 他此刻**想让人看见什么**？（外在表演）
2. 他的身体**在哪里背叛了他**？（矛盾）
3. 他在**用哪里使劲克制**？（克制点＝张力位置）

答完这三个，描写自然就深了——不需要任何模板。

## 九、陈词滥调清单（写风格化片尤其要避开）

`咬嘴唇 · 皱眉 · 耸肩 · 握拳 · 揉太阳穴 · 叹气 · 双手抱胸 · 翻白眼 · 手指敲桌 · 移开视线`

这些都**太通用**，读完看不见这个人。替换方法：**把它改成只有这个角色才会做的版本**——
厨子焦虑时用拇指刮刀刃的背；修机器的人焦虑时反复拧同一颗已经拧紧的螺丝；
老收音员焦虑时把耳机摘下来又戴回去。

## 十、按风格调幅（同一套方法，两种力度）

| | 写实向 | 卡通 / 美漫描边 |
|---|---|---|
| 幅度 | 克制：一口气、一次眨眼、半度的转头 | **夸大**：眉抬得更高、眼睛可变形、嘴形夸张、动作有预备与跟随 |
| 微表情 | 一闪而过，靠观众自己读出来 | 停留更久、幅度更大，要让人一眼抓到 |
| 习惯动作 | 细微、偶尔 | 更明显，每镜都可以带 |

**共同点不变**：都是先问那三个问题，再用可见痕迹写——风格只改幅度，不改方法。

## 十一、情绪外化：抽象词一律翻译成身体细节

**模型对情绪词的读法分辨率粗、不可控、易给"公共脸"**（基本情绪词能响应，复合与细腻的情绪词才崩）。"很悲伤""非常愤怒""终于轻松了"——这些都是给读者看的，不是给模型执行的。

| 抽象情绪 | 可执行的身体细节 |
|---|---|
| 悲伤 | 低头、肩膀微微颤抖、眼眶泛红、手指无意识攥紧衣角、泪在眼眶里打转却始终没落下 |
| 喜悦 | 嘴角压不住地上扬、眉眼舒展、脚步变轻快、忍不住原地转半圈 |
| 紧张焦虑 | 频繁看表、手部高频自我安抚小动作（按 §九 具名到"只有这个人这样做"的版本）、呼吸变浅、眼神闪躲 |
| 愤怒 | 双拳握紧、下颌线绷住、胸口起伏变快、从牙缝里挤出话 |
| 释然 | 长长舒一口气、绷着的肩膀整个垮下来、浮起很淡的笑、抬头望向远处 |
| 恐惧 | 瞳孔放大、向后退半步、手不自觉抓住身边的东西、屏住呼吸、嘴唇发抖 |
| 疲惫 | 手部自我安抚动作（按 §九 具名化）、靠到墙上、眼皮下沉、长呼气、动作整体变慢 |
| 专注 | 眉头微皱、视线锁死一点、嘴唇抿紧、身体前倾、手保持不动 |
| 犹豫 | 张嘴又闭上、视线游移、手悬在半空不敢落下、脚下小步挪 |
| 惊喜 | 眼睛瞬间睁大、嘴巴张成 O 形、双手捂嘴、向前一步、笑容慢慢绽开 |

> ⚠️ **上表只是"通用起点"，不是可以照抄的答案。** 表里的"低头、肩膀颤抖、攥紧衣角"本身就是一份**公共库存**——
> 直接抄就是把第 9 节那份陈词滥调清单换了个说法。**落地时必须改写成"只有这个角色才会做的版本"**：
> 拾荒少女的悲伤是"把扳手在手里转了一圈又一圈"；老值夜员的疲惫是"反复检查同一颗已经拧紧的螺丝"。
> 路径是：**先用表找到情绪落在哪个身体部位，再把它换成这个人物专属的动作。**

**三条使用纪律**：

1. **每镜只写一到两个关键动作**——写四五个反而把焦点稀释没了，观众一个都记不住。**深度不等于数量**：与其写十个动作，不如把一两个写透（写到具体的幅度与节奏）。
2. **情绪要能"变速"**：同一个情绪在不同强度下形态不同——紧张可以从"敲桌子"升级到"手抖到握不住东西"。
3. **可对照**：❌ `她很难过。` → ✅ `她低着头，肩膀在抖，手指把衣角攥出褶子，眼眶红着，但眼泪没落下来。`

## 十二、配角也要有自己的赌注（2026-09-11 补）

**问题**：主角有欲望与代价，配角却只是"递东西的人""站在旁边的人"。配角一旦没有自己的赌注，观众就只看见两个道具在说话，**整个场景变成说明文**。

**做法**：给每个**有台词或占画面 ≥3 秒**的配角写一行私账——不用写进提示词，写上自己心里有个数，再**把它变成一两个可见行为**：

| 配角 | 他的赌注 | 落地成什么可见行为 |
|---|---|---|
| 催账的房东 | 怕收不回钱，也怕撕破脸 | 说话时手一直搭在门框上（随时准备走），眼睛却盯着桌上的东西 |
| 递工具的学徒 | 想被认可 | 递出去后手不收回，等一句回应；被无视时嘴角落下去 |
| 路过的同事 | 心里有事 | 走过时不看主角的眼睛，脚步比平时快 |

**三条纪律**：

1. **配角的行为必须与主角的动作"错位"**——主角说话时，配角在干**别的事**，这才像真人。
2. **配角不抢焦点**——幅度小于主角，且**动作不同类**（主角握拳，配角就别握拳）。
3. **只在 ≥3 秒的镜头里给**——一闪而过的背景人物不需要私账，写了反而乱。

**自查**：把某一个配角的全部动作划掉，场景还成立吗？成立 → 这个配角是道具，补一行赌注；不成立 → 说明他已经在承担叙事。

## 十三、角色「中间态」设定图（2026-09-11 补）

**问题**：角色资产通常是"干净、完整、标准状态"（新工装、干衣服、头发整齐），但成片里角色**中途会变**（湿透、破损、蓬头垢面、受伤）。**用干净资产生成湿透状态 → 模型会把脸也一起改掉**。

**做法**：凡剧情里角色**有明显状态变化**，就**先单独出这一版的设定图**（作为独立资产），不要指望现场用文字改出来：

| 中间态 | 单独出一版时锁什么 |
|---|---|
| 湿透 | 头发成绺贴在额头、衣服贴在身上显出水痕与褶皱、脸上有水光但**五官位置与干发版逐点一致** |
| 破损 | 衣服破口位置固定、脏污分布固定（哪块蹭了土）、**脸不动** |
| 受伤 | 伤口在**固定位置**、血量与颜色固定、表情仍是同一个人 |
| 时间流逝（胡茬 / 疲惫） | 胡茬长度与分布、眼下的阴影深浅——**骨相与比例不变** |

**纪律**：中间态资产**必须与基础资产同底**（同色温、同光位、同背景规格），否则脸会漂。出好后**必须跑动测**：**同一条件连跑 5 条、5/5 全成立**才允许锁——**一条过得去可能是运气，不许只跑一条**（→ `asset-consistency-part2.md` §八 工作流第 5 步 + §「★ 动测的加强版：跑"一组"而不是"一条"」）。**5/5 不成立的处置**：回第 1 步查变量（多数是身份块被改词或参考素材被混用，→ `asset-consistency-part2.md` §八 末条），修变量后二轮再测；仍不过按 `production-ledger.md` §四 换实现路径，不是继续抽。
