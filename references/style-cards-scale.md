# 风格校准 · 定标与容差（所有校准卡共用的一把尺；**容差为单样本初始值，待分层校准**）

> **何时读**：拿到风格编号、翻 `style-cards-*.md` 之前。**读完回哪**：回校准卡填「参照 / 生成」四个数。
>
> **校准卡上写的是"低 / 中 / 高"这类定性词**——它告诉你**方向**，但**没法判"偏了多少"**。
> 本页给两样东西：**① 怎么量**（用同一把尺量参考帧与你的生成帧）· **② 差多少算偏**（容差表）。

---

## §0 一条铁律（先记住，这条推翻了"绝对目标值"的写法）

**目标不是一组绝对数字，是你自己那张参考图的四个数。**

所以每张校准卡上写的是 ``参照 __/__/__/__ ｜ 生成 __/__/__/__``：
**先量参考帧（`style-sources-*.md` 告诉你去哪取、挑哪类帧）→ 再量自己出的图 → 看差值。**

**为什么不预填绝对数段**：本库的红线是不存影片画面（→ `sources-and-credits.md`），
**我无法核验任何一条的"真实数值"**——预填一套数段等于**假权威**（违反 `governance-law.md` L4）。
**参考图是你手上唯一可信的标尺。**

---

## §1 怎么量（口径：两边必须同尺）

1. **参考帧取 ≥3 张**（取图册每条都写了"挑哪一类帧"，按那个挑）；**生成帧取 ≥3 张**（不同时间点，别只截一张）。
2. **同一工具、同一口径**量两组。**单帧读数会抖 → 取中位数**，不要取首帧。
3. 四个量的定义（照这个口径量，**不要混用别的工具的默认口径**）：

| 量 | 范围 | 怎么读 |
|---|---|---|
| **色相 H** | 0–360° | **只统计有色像素**（饱和度高于阈值），对它们做**圆平均**（不能直接算术平均 350° 与 10°）；画面近无色时色相无意义，写 `—` |
| **饱和 S** | 该工具量程 | **逐像素 S 的平均**（不是"平均色的 S"——平均会把饱和度压平） |
| **明度 V** | 同上 | **逐像素 V 的平均** |
| **对比** | 同上 | **V 的标准差**（不是最大最小之差） |

> **★ 尺度不重要，"两边同尺"才重要**：容差用的是**相对值**，
> 所以 S / V / 对比 用 0–100 还是 0–255 **都成立**——**只要参考帧与生成帧是同一把尺量的**。

**可直接跑的量法**（把参考帧与生成帧分别放进两个目录，各取 ≥3 张）：

```
python -c "
import sys,glob,os
import numpy as np
try: import cv2
except ImportError: sys.exit('需要 opencv: pip install opencv-python numpy')
for tag,d in [('参考',sys.argv[1]),('生成',sys.argv[2])]:
    H,S,V,STD=[],[],[],[]
    for f in sorted(glob.glob(os.path.join(d,'*')))[:6]:
        im=cv2.imdecode(np.fromfile(f,dtype=np.uint8),1)
        if im is None: continue
        hsv=cv2.cvtColor(im,cv2.COLOR_BGR2HSV).astype(float)
        h,s,v=hsv[...,0]*2,hsv[...,1],hsv[...,2]          # H 归到 0-360
        m=s>60                                            # 只算有色像素
        if m.sum()>500:                                   # 圆平均
            a=np.deg2rad(h[m]); H.append(np.rad2deg(np.arctan2(np.sin(a).mean(),np.cos(a).mean()))%360)
        S.append(s.mean()); V.append(v.mean()); STD.append(v.std())
    if not H: print(tag,'近无色，色相记 —')
    print('%s 色相%.0f 饱和%.0f 明度%.0f 对比%.0f'%(tag,np.median(H) if H else -1,np.median(S),np.median(V),np.median(STD)))
" 参考图目录 生成帧目录
```

> **注**：上面这段是**可复现的最小实现**；如果你用取色器手读，**只要两组是同一方法、同一工具读的**就同样成立（点样本与全像素统计对象不同，不可混用）。
> **口径变了要重量另一组**——不同口径的数不可比。
> **脚本边界（2026-09-30 补）**：`[:6]` 取前 6 张是**示例简化**——正式使用应遍历全目录并断言 ≥3 张有效帧；带黑边 / 字幕条的帧**先裁安全区再量**。`s>60` 阈值对**低饱和题材**（黑白 / 雪景）会把大半像素挡在门外，色相记 `—` 是预期行为不是错；换量程工具先做归一换算。

## §2 容差表（差多少算偏）

| 量 | 容差 | 超了说明什么 |
|---|---|---|
| **色相** | **±12°** | **整片的色彩方向错了**——最严重，优先修 |
| **饱和** | **参考值的 ±25%** | 偏艳（AI 默认）或偏灰 |
| **明度** | **参考值的 ±15%** | 偏亮（AI 默认拉高）或偏暗 |
| **对比** | **参考值的 ±15%** | 平了（AI 默认洗平）或硬了 |

> **多帧同向规则（2026-09-30 补）**：**≥3 帧同向越界才算系统性偏差**——单帧越界可能是抽帧抖动；参考值过低（S·V < 10）的指标不用百分比容差，改用**绝对地板**（差 ≥10 判偏）。

**为什么是这几个数**：用 2026-09-15 那次《情书》实测**反推**出来的——
这一组值**刚好抓住当时那四项偏差，又没有把正常帧误判**（逐帧验算见 §4）。
**它们是"能用的初始值"，不是定律**；用得多了，按实拍经验收窄或放宽，**改了要写在这里**。

## §3 判出偏差之后改哪（三级，按幅度递增）

| 偏差程度 | 改哪一环 |
|---|---|
| **只超 1 项、幅度小** | 改**提示词里的色彩句**（风格层那几行），**不动风格编号** |
| **超 2 项以上** | 改**风格层**：先核 §二 的归系有没有判错 → 再核**胶片档与调制层**（`film-stock-matching.md` §3 十四族推荐档） |
| **色相超 ±20°** | **停下别改了**：这通常**不是调色问题**，是**风格选错或方案包配错** → 回 `style-library.md` §二 重判量级系，再回 `style-package-matching.md` 重取包 |

> **判据**：**色相错 = 方向错，其余错 = 程度错。** 方向错的时候调程度是白费功夫。
> **12–20° 区间的处理（2026-09-30 补）**：按**第二级**改风格层后复量；**连续两批仍落此区间**则升级第三级重判量级系。

## §4 实证：C62 日式文艺那一次（本表的来源）

参考帧＝《情书》雪后街景；生成＝同一段 4 个时点。**按 §1 口径量（H 0–360 / S·V 0–255）**：

| 帧 | 色相（±12°） | 饱和（±9） | 明度（±19） | 对比（±11） |
|---|---|---|---|---|
| 参考 | **183** | **37** | **129** | **72** |
| 帧1 | 104 **偏 −79** | 59 **偏 +22** | 143 ok | 69 ok |
| 帧2 | 114 **偏 −69** | 43 ok | 168 **偏 +39** | 56 **偏 −16** |
| 帧3 | 90 **偏 −93** | 72 **偏 +35** | 134 ok | 68 ok |
| 帧4 | 112 **偏 −71** | 66 **偏 +29** | 136 ok | 72 ok |

**读出来的结论（当时靠"感觉差异很大"是读不出来的）**：
① **色相 4/4 全偏，且都偏 −70° 以上 → 青变成了黄绿，这是方向错，属于 §3 第三级"停下重判"**；
② **饱和 3/4 偏艳**、明度与对比各在帧2 偏——**都是"AI 默认审美"（拉亮、加艳、洗平对比）的指纹**；
③ 帧1/3/4 的明度对比是 **ok** 的 → **说明不是全盘崩，是色相与饱和两处系统性偏差**。

> **这正是校准卡该干的事**：把"风格差异很大"变成"**色相偏了 78 度、饱和超了 22**"。
> 有了这句话，下一版改哪里、改多少就是确定的。

## §5 两类风格不用这四个数

| 哪一类 | 用什么 |
|---|---|
| **G 卷 15 条（工艺渲染系）** | 用**工艺判据**——`每秒张数` / `格边框可见吗` / `模型尺度看得出来吗` / `画幅变化对应什么`（已写在各条卡上） |
| **C71–C75 摄影向** | 按**产品与纪实口径**量：高光有没有裁掉、皮肤/材质的高光位置、畸变与透视 |

**判据**：**能量出"工艺错没错"的，就不要用色彩四指标去量它**——工艺系的偏差通常不在色彩上。（**澄清（2026-09-30）**：G 卷工艺判据（每秒张数 / 画幅变化等）属**视频 / 时序层**，单帧校准卡不量它们——单帧卡只锁静态特征。）

---

## §6 定性词怎么用（明确：不要用它判偏）

校准卡上的"低 / 中 / 高"**只用来挑参照图与对齐口径**，**不作数值判据**。
**例子**：C62 写"饱和 低"，而参考图实测 **37**、生成 **59**——**两个都能被不同的人说成"低"**。
**靠定性词永远判不出这 22 的差**。所以卡上给定性词是给你**找方向**，判偏**必须回本页量数**。
**结构零值的语义（2026-09-30 补）**：`—` / `无` / `N/A` 表示**该通道不存在**（近无色、默片字卡类整卡无色彩通道），与"低"是两回事——**零值不参与判偏**，也不算合格或不合格。
