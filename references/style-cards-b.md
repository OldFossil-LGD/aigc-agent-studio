# 风格参照卡 · B 卷（电影 20 条）· **可自测、无版权、可核验**

> **何时读**：选定风格编号之后、进资产阶段之前——**用它把"像不像"从感觉变成可核对的东西**。**读完回哪**：`quality-layer.md` 写统一提质层。
> **★ 定标与容差 → `style-cards-scale.md`**：卡上给"低 / 中 / 高"是**方向**，**判偏要回那一页量数**——先量参考帧、再量你出的图，按容差表（色相 ±12° · 饱和 ±25% · 明度与对比 ±15%）看差多少。
>
> **★ 先说清一件事（用户要求"逐条搜集真实电影截图"，本库的做法不同，理由如下）**：
> ① **本库的红线是不存储影片画面**（→ `quality-layer.md` 第 4 条 · `sources-and-credits.md` 许可红线：本库自建立起"**未使用任何影片画面、剧照或角色**"）——**建截图库等于把整库的版权立场推翻**；
> ② **我也无法核验"这张图真的来自那部片"**（图搜结果大量是粉丝拼图、错标、AI 生成图）——**一个没核验过的截图库比没有更糟**，它会变成错误来源（违反 `governance-law.md` L4）；
> ③ **真正要的其实不是图，是"可核对"**。所以本文把每一条风格做成一张**参照卡**：
> **方向性指标（色相/饱和/明度/对比）+ 光位光质 + 景深焦段 + 构图语法 + 质感清单 + 该截哪 3 帧 + 允许包与禁忌包 + **参照 / 生成两个测量位**。
>
> **★ 取帧规程（截图由你截、存你本地，不上库）**：
> 1. 用**你自己的正版片源**截 3 帧（下面每条的「参照帧」写明了截哪三种画面）；
> 2. 存到本地一个目录，命名 `B04_ref1.jpg` / `_ref2` / `_ref3`（**只在本机，不进 skill、不随库分发**）；
> 3. 用同一工具读四个数（口径见 `style-cards-scale.md`），**先量参考帧、再量你出的图，填进该条的「参照 / 生成」**——**两组数都填了，这张卡才算"测过"**；
> 4. 卡上原有的指标是**方向性推导**（依据公开影史与摄影通识，**不是实测值**），**与你实测有出入时，以你的实测为准并覆盖它**。
>
> **判据**：**这张卡上桌后，你能答出"我这一版哪里不对"**——答得出就是可用；只能说"感觉不对"就是还没用上它。

## 三、这批卡的用法与"器材联动"的口径

**用法**：① 拿卡上的**方向性指标**对你已生成的画面（或对提示词）→ **先看色相与饱和度两项**，多数"风格不对"都在这两项；② 按「参照帧」截三帧并量四个数（`style-cards-scale.md` 给口径与容差），**连同你出的图一起填进「参照 / 生成」** → 卡从此是实测卡；③ 按「允许包 / 档」写统一提质层，**若你的选择不在允许集里，要能说出理由**。

**★ 关于"风格 ↔ 器材包 一一对应"（**这一条与库内纪律冲突，说明如下**）**：
`camera-package-quickref.md` §一 明令 **"不做'编号→包'的对照表——绑死会害了你"**（同一个 B04 黑色电影：P08 拍是经典黑白、P14 拍是现代 neo-noir，**都成立**）。
所以本卡给的是 **「允许集 + 禁忌集 + 判据」**：
- **允许集**＝首选 + 可换（通常 2–3 个）——**在这几个里选哪一个，由"年代 + 光源色温 + 明暗调性"决定**（→ `film-stock-matching.md` §0）；
- **禁忌集**＝**机制冲突**的那几个（如恐怖片配 P13 的分辨率、Dogme 配任何"电影感"包）；
- **判据一句话**：**允许集内任选都成立；出了允许集必须说得出理由。**
**这比"一一对应"更严**：一一对应只排除错配，**允许集会同时告诉你"还有哪两个也对"**。

**★ 当某个风格在现有 34 个包里找不到合适的**：**按"机制不同才成包"的判据补包**（→ `camera-package-library.md` / `package-extended.md` 的写法：器材 / 痕迹 / 运动三行 + 适用 + 一句"拍摄故事"）。**B 卷 20 条经核对，现有包够用，本批未新增包。**
