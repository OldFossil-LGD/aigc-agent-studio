# 剧集结构工程：单集与季（**多集专用 · 引擎层的下半场**）

> **何时读**：破一集的结构 / 排幕 / 放出幕 / 配 A-B-C 线 / 拆一集的诊断 / 排一整季。
> **读完回哪**：引擎与人物网 → `drama-series.md`；单集交付 → `script-module.md`（每集一套 M1–M12）；卡点落到镜头 → `transition-library.md`；**剧本定稿后进 AIGC 生产（提示词翻译 / 资产派生）→ `drama-aigc-conversion.md`**。
> **适用**：剧本 / AIGC 写作。**NOT for** 技术文档 · 论文 · 新闻 · 公文（判据 → `writing-methods.md` §0）。
> **口径**：`drama-series.md` 管**"凭什么每周都还有故事"**（引擎）；**本册管"这一集与这一季该怎么切、怎么断、怎么收"**（结构工程）。

---

## §0 两条地基（先记这两条，别的都是从它们推出来的）

**① 幕是交付格式，三幕是设计工具。**
"幕"的本源是戏剧换蜡烛、电影换胶片卷、电视插广告——**它是物流**（决定"几根香肠、多长"），**不是戏剧原理**。
→ **设计时用三幕**（一个主动作/演化的**之前 / 之中 / 之后**），**交付时再按平台切成四/五/六幕并放广告位**。两者可叠用：**切幕当工作单元，三幕当设计工具。**

**② 页码锚点只在它的原产地有效——不可换算。**
| 体系 | 切幕依据 | 锚点是否可用 |
|---|---|---|
| **美式一小时**（48–63 页） | **页数与广告位** | ✅ 本节页码只对它有效 |
| **半小时喜剧** | 另一套幕长与场数 | ❌ 不要把一小时的数字缩放过去 |
| **国产 45 分钟集** | **时段与片断**（正片约 40–43 分钟，随中插广告政策浮动；开场 3 分钟钩子＋每 15 分钟一个小扣子＋集尾大关子） | ❌ **绝不可按比例换算**（详见 §8） |

**③ 一条随手可用的计数规则**（避免"场数"三个字各说各话）：
- **主角或目标变 → 一个新的戏剧场**（dramatic scene）
- **地点或时间变 → 一个新的物流场**（logistical scene）
- **结构文档按"戏剧场"计数**；一个戏剧节拍可以含多个场景标题。

## §1 单集容器：功能链与三条通用律

**四幕功能链**（不受幕数变化影响，五幕六幕都是从它拆出来的）：

| 幕 | 这一幕必须完成的事 |
|---|---|
| **1** | 介绍人物、**冲突与赌注** |
| **2** | 幕尾把故事推向**全新且意外的方向**（不是"更危险"，是**性质变了**） |
| **3** | 幕尾是"**主角以为控住了，却发现错了**"——"他们都要死了，没有希望" |
| **4** | 想出办法、达成目标 |

**★ 三条通用律**（三条都是**可判定的**）：
1. **一幕结尾不是最大危机，而是"主角被推进一个没有退路的处境"**。
2. **二幕的转折点必须改变故事的性质**，而不只是提高危险等级。
3. **三幕结尾必须让主角的胜利变成新的失败。**

**场数参考**（三个体系差两三倍，按"拍法＋时长"选，**不要缩放**）：美式一小时——每幕 5–7 场、全集 **20（五六幕）～30（四幕）**；半小时喜剧——多机 15–20 / 单机 40–50；**国产 45 分钟——25–35 个场面**。

**Teaser / 冷开场**：
- **它不是必需品**：只有服务戏剧目的才要；强连续剧可用"短第一幕 + 晚打片名"替代。
- **硬规则**：**用故事开场，不要用信息开场**——"用重大主题或抽象哲理开场，其实是看到戏剧弧线的挑战而畏缩"。
- **闪回类 teaser 的禁忌**：可以从动作的中段甚至末段起叙，**但绝不能在 teaser 里回答本集的戏剧问题**；取材自结尾就选高潮**之前或之中**，不要之后。
- **cold open ≠ teaser**：不影响主线、只启动本集主题的那个开场，属于 cold open（此时本集的切入点落在第一幕）。

## §2 出幕（act out）：八种形式 + 一条判准

**八种出幕形式**（按可迁移性排序，**每集至少换三种，不许四幕全用台词**）：

| # | 形式 | 备注 |
|---|---|---|
| 1 | **悬念提问** | 最常用，也最容易被滥用 |
| 2 | **反转台词** | 一个词就能完成反转 |
| 3 | **情感揭示** | 揭的不是事，是态度 |
| 4 | **无对白动作** | **★ 至少留一幕给它**——但**必须先教会观众这套语法** |
| 5 | **道具定格** | 摄影机留在物上 |
| 6 | **重复台词的语义反转** | 同一句第二遍变了意思 |
| 7 | **被剪断的 setup** | 话没说完就切 |
| 8 | **伏笔兑现的手势** | 前面铺过，这里只做动作 |

**两条排布纪律**：**每一幕的出幕交给不同的线**（不要连着四幕都压在 A 线上）；**幕末悬念不一定在 A 线**——B 线的转折点也可以是硬出幕。

**★ 出幕的判准（本册最重要的一条）**：
> **必须长自人物的 jeopardy / risk / fear。**"**在每一个幕末强行安一个 cliffhanger 是致命的**"——现代的做法是**让幕断落在一个从人物里长出来的转折点上，而不是从情节里挤出来的转折点上**。
> **"surprise"型出幕也必须（隐约地）铺过**，让观众有"**本该看出来，但没有**"的感觉。

**cliffhanger 的十种**（选型用）：人物陷入危险 · 倒计时炸弹 · 感情悬空 · 反转/恍然大悟 · 某人物死亡 · 发现秘密 · 重大人生事件 · 缺乏闭合 · 迷你悬念（场级）· 喜剧型悬念。
**两种最可迁移的做法**：**用一个词完成反转**；**不要在笑点上出幕**（喜剧型另有语法）。
**反面教材（schmuck bait）**：心电图拉平、护士喊"抢救"——插广告——"有脉搏了"。**为震惊值而震惊，不是悬念。**
**位置与时限**：一小时剧把高潮型 cliffhanger 留到集末；多机情景喜剧通常在集中点出幕（结尾要回到常态）；**可以延后揭示全部真相，但必须在本季结束前揭示**。

## §3 信息管理与赌注（三件工具，直接进 M12 自检）

**信息管理四工具**：**戏剧反讽**（观众知道、角色不知道 → 揪心）· **惊奇**（突然揭出）· **谜**（角色/观众都不知道 → 好奇）· **悬念**（知道有危险、不知何时 → 不安）。
**缝合句**：**"不只问谁在何时做了什么，还要问谁在何时知道了什么。"**

**四条红线**：
1. **不要让主角长期比观众知道得更多**——**尤其是理解他动机所必需的前史**（这是最常见的观众流失原因）。
2. 做 cliffhanger 优先用**信息炸弹**（揭一件事），而不是物理绝境。
3. 分清**封闭谜团**（结局必须揭）与**开放谜团**（可以有，但要控制数量）。
4. **"反派是什么"可以有谜，"危险是否真实存在"不可以有谜。"**

**★ 赌注检验（一句话就能判）**：
> **问自己：对这个人物来说，"面对危机什么都不做"是不是一个可行选项？**
> **是 → 赌注不足。**

**极化模型**：在每一集、每一场、每一幕标出正负电荷（+/−）；**幕断的方向可正可负**——"**有些幕就是以'赢'收尾的**"。

**速度检查**：**"第四幕结尾那个最酷的事，能不能挪到 teaser 末尾？"** 能挪 → 这一集前面太慢。

## §4 A/B/C 与 runner：配比与两条替代路线

**定义**：A＝引擎线（贯穿每一幕）· B＝与 A 咬合的私人线（常承载主题）· C/runners＝短促的插入线（幽默、怪癖、小麻烦）。

**六条硬规则**：
1. **A 线贯穿每一幕**；B 与 runner 按需插入。
2. 每幕一般 **4–5 个节拍**，**理想情况收在 A 线、落在主角的困境上**。
3. **极少在 C 线收幕**——"**如果这条线值得一个幕断，它多半不是 C，而是 A 或 B。**"
4. **但幕末悬念不一定在 A 线**（可以是 B 线的转折）。
5. **不必棋盘式交替，要跟随"兴趣线"**——某一场在剧情顺序上可以省，但对"观众的兴趣线"至关重要。
6. **没有一场戏是专为交代而写的**——"如果你需要传递事实，就把事实放进一个充满情感的语境里。"

**两条替代路线（都要与 A/B/C 并列保存，不是替代品）**：
| 路线 | 做法 | 代价 |
|---|---|---|
| **按角色 break** | 白板上每个角色各有开头/中间/结尾，**不按幕 break、按角色 break**，先破主角线，最后 weave | 需要更强的整体感 |
| **拒绝 A/B/C** | 改问 **"这一集是关于什么的？"**，让每个人物在那个更大的故事里各就各位 | **次要人物可能永远只是次要人物**（提出者自己点明） |

**多线不等于主题驱动**：若各线角色**共享同一个外部问题与同一个目标**，那它其实是**同一主线的多主角**，不是主题驱动。
**线的交叉在有主题链接时最有效**；家庭关系是最强的链接；**runner 可以长大成主线**。

## §5 场结构五件套（**单场级别的硬规格**）

```text
want（他这一场要什么）→ obstacle（什么挡着）→ escalations（≥3 次升级）
→ decision（场的高潮）→ resolution（决定的结果，并把人带进下一场）
```
**六条**：
1. **want 与 obstacle 在开场之前就已确定**；**第一次升级就开场**。
2. **decision 是场的高潮**；**resolution 是它的结果**，并把人物推进下一场。
3. **至少三次升级，越多越好**——"升级越多，这一场越有时间建立与呼吸"。
4. **优先用动作做升级**："**如果你所有的升级都是口头的，你的剧就变成广播剧了。**"
5. **一场只有一个主角，但主角可以换人**；**一人场**的对手来自世界或环境。
6. **"没有 character want 的 moment 不是一场戏，只是一个 moment、一个画面。"**

**两条场级附加规格**：电视**一场的目标长度约 2 页**（**美式剧本页，约 1 分钟成片**——页码不可换算到中文剧本，见 §8 中式接口；"一开始就用 4 页写一次会面，等于挂红旗"）；**舞台指示可以承担结构任务**（用道具与走位标记权力与关系变化）。

## §6 流媒体无幕标记时的"隐形幕"：三重判据

付费平台常不标幕、不分页——**但他们仍然在写幕，只是把幕伪装成日程**。反推幕位用三条：
```text
① 剧情日 / 时间块标记 —— 换日就是换幕
② 地点与交通工具的切换
③ 核心问题转向的那一刻
```
**判定标准**：**每一幕末尾必须有一次信息或权力的转移**（不必有悬念钩）。
**配套规律**：长篇里**多数集会把全集压进一个"带固定程序的容器"**（一场晚宴、一次董事会、一趟行程）——**程序节点替代 act break**。

## §7 季形（这一季怎么排）

| 装置 | 要点 |
|---|---|
| **帐篷柱（tentpoles）** | teaser / 各幕断点 / 尾场（tag）合称；**先定柱子，再排集**（顺序别倒） |
| **瓶子集** | **成因是预算**（无客串、无外景、无新布景、无群众）；**把四条限制逆用成选择**：单夜、单建筑、趁机说出季弧里一直没敢说的秘密、**并把线数从 4 加到 5**（瓶子集 ≠ 单线） |
| **容器集** | "所有人被关进一栋楼 + 通讯受限"；**压力舱**本身就是节拍表 |
| **仪式集** | 一个有日程表的日子（婚礼、葬礼、颁奖、董事会议）；**白送一张节拍表**——每个既定环节塞一次冲突；常安排**主角缺席** |
| **两集连播** | 上半做"铺开与升级"，下半做"兑现与代价"；两集各自仍要有完整形状 |
| **六集季形（模板）** | ①铺开 ②欲望 ③露底 ④**瓶子集** ⑤伪胜利 ⑥**封闭社交场合一次结清** |
| **季终** | **让季初那个数字/物件/台词，在季终用同一个东西完成掉头**；**每条线的落子必须同时生成下一季的债务**；末幕只做兑付、不引入新信息 |

**季层纪律**：**给自己和主角一个 deadline**（它同时能帮你写完 pilot）；**集数检查——"你是不是开始得太早了？"**（减一集常常就能提速）。

## §8 ★ 中式接口：三处**不可换算**（**写国产剧之前必读**）

> **★ 完整的中式层已独立成册 → `drama-series-cn.md`**（国产 vs 美式差异表 · 单集骨架 3 分钟 + 15 分钟 + 集尾 · 四级悬念 · 延宕五技巧 · 情境两步法 · 一案 N 集光谱 · 制片链与红线）。本节只留**跨体系时最容易出错的三处**。

| # | 美式做法 | 中式现实 | 处置 |
|---|---|---|---|
| **1** | 页码锚点按 48–63 页切幕 | 国产按**时段与片断**切：**正片约 40–43 分钟**（随中插广告浮动）；**开场 3 分钟钩子 + 每 15 分钟一个小扣子 + 集尾大关子** | **页码一律不换算**；改用"时段 + 场面数（25–35）" |
| **2** | **末幕只做兑付、不引入新信息** | **国产要求每集末尾再卖一个大关子** | 本条**只对季终集适用**；单集集尾按中式的集尾悬念办 |
| **3** | 场数 20–30（一小时） | 国产 45 分钟 **25–35 个场面** | 按场面数排，不按页数 |

**仍然可直用的部分（跨体系有效）**：**出幕八型与其判准** · 一幕尾是"被推进没有退路的处境" · **二幕转折改变故事性质** · **三幕末让胜利变成新失败** · 场结构五件套 · 赌注检验 · **信息管理四工具** · 隐形幕三重判据 · 帐篷柱与瓶子集。

## §9 分歧保留表（十争点逐条取边）

| 争点 | A | B | **本库用法** |
|---|---|---|---|
| 幕是结构还是格式 | 幕是骨架，页码可检验 | **幕只是物流**（"香肠的尺寸"），设计用三幕 | **A 当工作单元，B 当设计工具**——可叠用 |
| 页面上写不写 ACT | 按幕断点破故事，定稿删标注 | 很多剧集主管要看标注（作为结构掌握的证据） | **看目标市场**：投流媒体可删，投有广告的平台必留 |
| 中点有没有意义 | 中点是二幕断点，必须扭转主线并带倒计时 | **中点可以忽略**，替代品是"幕中高潮" | 主线目标能覆盖整幕 → 用中点；**目标中途更换 → 用幕中高潮** |
| 中点是假胜利还是必须成功 | 假胜利或假失败二选一 | **"必须是主角几乎成功——不是失败！"** | 写悲剧／反英雄时用变体：**挤压翻正、高潮翻负** |
| "最坏情况"的位置 | 四分之三处 / 五分之四处 | **"剧是靠别的成功，不是靠这些公式化拐杖"** | 第一次写剧集 → 用锚点自检；已有扎实段落设计 → 不必摆 |
| A/B/C 还是别的破法 | A/B/C + runner，字母按戏份排 | **拒绝 A/B/C**，改问"这一集是关于什么的" | 群像且每集要"一个完整故事" → B；单主角连续剧 → A |
| 每幕是否必须放悬念 | 每幕（理想每场）都要让人想翻页；六幕剧"一集五六个悬念" | **"在每个幕末强行安 cliffhanger 是致命的"** | 有广告位的六幕 → 配额；无广告或强作者剧 → 松。**判准不变：必须长自人物的危境/风险/恐惧** |
| 主题统一多线 vs 主题是涌现物 | 主题是把几条线黏起来的胶水 | **"我们不做主题"**——强写实优先，替代品是"本集的操作性问题" | 群像多线 → A；强写实/惊悚 → B |
| 要不要大纲 | **"没有大纲就没有稿费"** | **"我不用大纲"**（替以两三页故事文档 + 每拍两三个词） | 在别人的剧组写集 → 必须大纲；自己是主创且能边写边守结构 → 可省 |
| Teaser 是否必需 | teaser 是抓人的第一道关 | 只有服务戏剧目的才要，否则"毫无意义" | 有广告、观众拿遥控器 → 必有；强连续剧/刷剧平台 → 可用"短第一幕 + 晚打片名" |

## §10 诊断清单（写完一集逐条自问）

```text
① 这一集的核心问题能用一句话说出来吗？
② A 线贯穿每一幕吗？有没有一幕收在 C 线上（有 → 那条线可能其实是 A 或 B）？
③ 每幕 4–5 个节拍、每幕 5–7 场吗？全集场数在本体系区间内吗（**按拍法与时长选，不缩放**）？
④ 有没有一场超过 3 页却不是完整节拍？（四页的会面戏是红旗）
⑤ 有没有专为交代而写的场？有没有"没有 want 的 moment"被当场用？
⑥ 每场都有五件套吗？升级≥3 次吗？**动作型升级占多少**（全是口头 → 变成广播剧）？
⑦ 每个出幕都能说清是什么事件吗？它从人物的危境/风险/恐惧里长出来了吗？
⑧ 八种出幕形式用了几种？**至少一幕是无对白或道具出幕吗**（且它的语法前面教过吗）？
⑨ 二幕转折改变的是**故事性质**，还是只提高了危险？三幕末是否把胜利变成了新的失败？
⑩ 赌注检验：对这个人来说"什么都不做"是可行选项吗？每幕的正负极性标了吗？有几幕是以"赢"收尾的？
⑪ 四个信息工具各用在哪里？主角有没有**长期比观众知道得更多**（尤其是动机所需前史）？本季的大谜会在季末揭吗？
⑫ teaser 是故事还是讯息？用了闪回的话，它有没有回答本集的戏剧问题？
⑬ 末幕是否只做兑付？（**中式单集不适用**——中式要求集尾再卖关子；本条只对季终集用）
⑭ 无幕标记的稿：删掉 ACT 后，隐形幕还能用三重判据划出来吗？每个幕末有信息或权力转移吗？
⑮ 季形：这一集在季里的位置对吗？季终与季初有对称掉头吗？**每条线的落子生成下一季的债务了吗？**
⑯ 提速：四幕末那个最酷的事能不能挪到 teaser？这一集有"第二天人人都在谈的那一场"吗？
⑰ 制作：内外景与日夜配比算过吗？**只写了 DAY / NIGHT 吗？** 有没有把限制逆用成瓶子集？
```

## §11 工作流程（十步）与训练（八个）

**工作流程**
```text
① 定三件事再动笔：系列类型 / 故事类型 / 格式（集长与大类）——任一含糊就别写大纲
② 选"结构对照剧"：找一部语调类型受众相近的成功剧当模板，问清四件事——
   有没有 teaser？几个幕断？每幕几场？有没有尾场？
③ 拆对照剧的两三集填格子：命名 A/B/C，每条线一句挂在主角上的 log line，逐格填字母
④ 定本集的核心问题 + 每条线的入口场与出口场（群戏线数上限 8–12，其中 1–2 条与主危机无关）
⑤ 倒序制造：先在格子里填"开场 / 四分之三处的最坏情况 / 结尾"，只做 A 或 A+B，给 C 留余地
⑥ 每条线单独做地标（分开写，先不编织）
⑦ 压成一页 grid：每幕一列、一卡一场、卡上写场景标题 + 人物 want
   一眼检查：地标是否落位、幕断是否够硬、主角是否主动、本集是否合乎季
⑧ 排出幕：每幕交给不同的线；八型里选三种以上；至少一幕无对白或道具出幕
⑨ 写大纲/节拍表（**剧集大纲必须写出幕断**）；到大纲这一步再编织各线
⑩ 交付前对格式做一次决定：标 ACT 还是删；跑 §10 的诊断清单
```

**八个训练**：① 拆一集填格子（命名 A/B/C＋每幕悬念属哪条线）② 出幕计数（五个出幕各属哪型，指出哪一个像"为震惊而震惊"）③ 信息管理改写（把同一个幕断写成"惊奇 / 戏剧反讽 / 谜"三版，判断哪版更想让人看下一集）④ 隐形幕反推（取一集无幕标记的剧，用三重判据划幕位）⑤ 幕数换算（把四幕大纲改五幕、六幕、无幕各一遍，每次都要为新幕断找一个站得住的事件）⑥ 提速练习（把末幕最酷的事挪到 teaser 末尾，重写全集）⑦ 预算倒逼（下四条禁令写一集瓶子集，并把线数从 4 加到 5）⑧ 对称练习（给第一集找一个数字/物件/台词，让季终用同一个东西完成掉头）
