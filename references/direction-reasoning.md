# 导演推理：从"这部片在说什么"推到每一个镜头

**何时读**：拿到（或刚写完）剧本之后、排第一镜之前。**读完回哪**：回 `studio-workflow.md` 第三步，把推导结果填进每镜。

> **一句话**：镜头语言不是选出来的，是**推出来的**。
> 每一个参数都必须能回答"**因为这个，所以这个**"；答不出因果，那就是在照抄风格。

**★ 本文件与各"库"的关系（先说清，否则一定打架）**：

| | 是什么 | 例子 |
|---|---|---|
| **风格库 / 运镜库 / 转场库 / 镜头组接** | **词汇表** | 有哪些词、每个词长什么样 |
| **本文件** | **造句法** | 这部片该用哪些词、为什么 |

**先有本文件的判断，再去库里挑词。** 反过来——拿着剧本去查"这场属于哪一类、该用哪套配方"——
出来的一定是"正确但空心"的东西。**配方表的唯一正确用法是推导完之后拿它校验有没有漏，不是拿它当起点。**

---

## 一、为什么不能从"这是什么类型的戏"开始

**类型是结果，不是原因。** 同样一场"两个人在厨房争执"：

| 命题 | 拍法 |
|---|---|
| "一个人用体面换来了彻底的孤独" | 两人**几乎不同框**；大量单人镜；中间永远隔着灶台或门框 |
| "亲密关系里没有胜利者" | 两人**必须同框**；对称构图；谁说话都一样大；最后一起出画 |

同一句台词、同一个场景，**命题一变，拍法完全相反**。
所以第一问永远是"**这部片在说什么**"，不是"这场戏属于哪一类"。

## 二、六问推导链（骨架）

| # | 问什么 | 答不出来的后果 | 它决定后面的什么 |
|---|---|---|---|
| **1** | 这部片在说什么（**命题**） | 全片没有主轴，每场都拍得不错但拼不成一部片 | 视觉母题、全片基调 |
| **2** | 人物要什么、怕什么、靠什么撑着 | 表演无动机，镜头无处安放 | 认同谁、机位与景别 |
| **3** | 这场戏为什么非存在不可 | 出现"好看但没用"的段落 | 剪辑点、信息释放 |
| **4** | 冲突以什么形状进行 | 只有吵，没有结构 | 构图与空间关系 |
| **5** | 能量怎么走 | 节奏平，观众疲劳 | 镜头长度、光色渐变、下一场怎么开 |
| **6** | 落到参数 | — | 景别 / 构图 / 机位 / 运动 / 光 / 色 / 声 / 切点 |

**纪律**：**六问自上而下，不许跳。** 回答第 6 问时脑子里没有第 1 问的答案，就是在套模板。

## 三、第一问：这部片在说什么（命题）

**★ 可反转测试**（区分题材与命题）：

> 把你的那句话**反过来**，看它是不是也成立。
> "一个人失业后重新振作" ↔ "一个人失业后彻底垮掉" —— 两个都成立 → 这只是**题材**。
> "他以为失去的是工作，其实失去的是他唯一会扮演的角色" —— 反过来不成立 → **这才是命题**。

**命题 → 核心矛盾 → 视觉母题**：命题里一定藏着**一对对立**（体面／真实、控制／失控、记得／忘记）。
把这对对立翻译成**一个看得见的对立**，让它贯穿全片：

| 命题里的对立 | 视觉母题（全片可复用的对照） |
|---|---|
| 体面 / 真实 | 对称构图、冷色、收边的动作 ↔ 失衡构图、暖色、衣服的褶皱与污渍 |
| 控制 / 失控 | 框中框、门框与窗棂 ↔ 溢出画框、人物被切掉一部分 |
| 记得 / 忘记 | 反复出现的同一个物件 ↔ 逐渐空掉的空间 |

> **判据**：把全片的镜头打乱顺序看，还能认出是同一部片吗？认不出 → 视觉母题没立起来。
> **★ 聚焦与成本控制**：短时长、单主线且没有多意象要求时，优先让一个视觉母题贯穿。用户明确要求并列或对照意象时，分别说明其功能与关系，以可读性和制作负担检查取舍，不按意象数量判错。

## 四、第二问：人物要什么、怕什么、靠什么撑着

**三个必答**：

1. **表面目标**（他以为自己要什么）与**真实需求**（他其实需要什么）——**两者的落差就是人物弧线**。
2. **他怕什么**：不行动的代价是什么。怕的人才会动，不写"怕"，人物就是木的。
3. **他靠什么撑着**：说谎、沉默、攻击、讨好、讲道理——**这是他维持体面的手段**，
   也是**表演最值钱的地方**：他说话的内容 vs 他身体在做的事，两者打架才好看。

**这一问决定两件事**：

**① 认同谁，镜头就架在谁的肩上。**
过肩镜从谁背后看出去，观众就在替谁想。**认同感是可以在一场戏里转移的**——
转移的那一刻（比如观众开始同情那个一直讨厌的人），过肩镜的落点要跟着换。

**② 接近真相就收紧，想逃就给空间。**
景别的本质不是"看得多清楚"，是**心理距离**：
- 人物**快要碰到真相**了 → 收紧（推近＝无处可躲）
- 人物**在逃避、在撒谎、在拖** → 给空间（拉远＝让他有地方站、有地方躲）

> 反过用也可以，但**必须是有意的**：给一个正在撒谎的人一个大特写，是在逼观众看穿他。

## 五、第三问：这场戏为什么非存在不可（戏剧任务）

**★ 删掉测试**：

> 把这场戏整场删掉，后面的故事还成立吗？
> 删除后若叙事因果、观众信息、情绪体验和节奏都无变化，可列为冗余候选。承担等待、空间建立、持续张力或形式重复作用的段落，先检查这些体验功能，再决定保留、压缩或删除。

**用“进出差”检查承担情节转折的场景**：人物进入和离开时的状态如何变化？持续等待或形式重复段落可以保持人物状态；此时说明观众获得了什么信息、情绪或时间体验，再判断这场是否完成任务。

**★ 主导问题**：这场戏观众在心里等一个答案（"他会说吗？""她知道了吗？"）。
**剪辑点的作用是把答案往后推**，不是把答案给出来。

> 具体做法：切点落在**答案将出的前一刻**——切到另一个人的反应、切到一个物件、
> 切到别处。**观众被多吊一秒，答案落地时就重一分。**
> 反过来，**急着给答案**是新手最常见的错：一问完立刻切到回答，张力全泄。

## 六、第四问：冲突以什么形状进行

不要只问"有没有冲突"，要问**形状**：

| 形状 | 说明 | 落到画面 |
|---|---|---|
| **进攻 / 防守** | 谁在推进、谁在退 | 进攻方景别更大、占据画面中心；防守方被压到画框边缘、被前景遮挡 |
| **战场在哪** | 抢的是语言、空间、还是某件东西 | 战场如果是**空间**——谁站在门边（随时可走）、谁被围在里侧 |
| **表面 / 底下** | 说的是一套，要的是另一套 | 表面用中景（两人都体面），底下用特写（谁的手在抖） |

**★ 同框还是分开，是这一问最重要的决定**：
- **同框**＝关系还在（哪怕在吵）
- **分开的单人镜**＝关系已经断了（哪怕在说爱）
- 一场戏里**从同框切到分开**，就是在告诉观众"他们完了"——**不用一句台词**。

## 七、第五问：能量怎么走（情绪曲线）

**不是起承转合，是能量值。** 给每场戏标一个 1–10 的能量数，然后看三件事：

**① ★ 按任务检查能量是否推进。**
需要转折、释放或对照的段落，检查场间落差是否有表达作用。持续等待、循环、仪式或极简任务可保持相近能量；用微变化、信息积累或有意重复说明体验如何推进。
**相近能量不自动等于冗余。** 先按命题和用户锁定的节奏判断，再选择下一场的开法，不机械套用固定能量差。

**② ★ 镜头长度由"观众这一刻需要多少时间"决定——不是风格偏好。**
这里有两种信息，**规则相反**，混在一起就会得出"结尾信息最少却该最长"这种自相矛盾的结论：

| 哪一种信息 | 密度 / 重要性 | 镜头 | 为什么 |
|---|---|---|---|
| **叙事信息**（发生了什么） | **高**（动作、混乱、多方同时） | 短 | 观众需要多次重新定位，一镜里塞不下 |
| **叙事信息** | **低**（独处、等待） | 长 | 需要**时间本身**产生压力，切碎了就没了 |
| **情绪信息**（这件事有多重） | **越重要** | **越长** | 与信息量无关——观众要的是**消化的时间**，不是**看的时间** |

> **两条打架时听情绪的。** 最常打起来的地方就是**结尾**：那里叙事信息最少、情绪最重——所以结尾往往最长，尽管"什么都没发生"。
> 所以"快切"不是风格，是**叙事信息密度高时的必然结果**；**在叙事密度低的场里快切，只会让观众觉得莫名其妙地赶。**

**③ 光与色随人物弧线走**，不是随场景走。
同一间屋子，人物状态不同，光就该不同（**量级不变，光的性质在变**——见第十节）。

## 八、第六问：落到参数（映射规则）

每一项都要能说"**因为这个，所以这个**"。下面只列**因果**，术语与写法去各自的库。

| 参数 | 推导依据（来自第几问） | 因果句式 |
|---|---|---|
| **景别** | 第 2 问 + 第 5 问①② | 他在逼近真相 → 收紧；他在拖 → 给空间；信息密度高 → 短而碎 |
| **构图** | 第 4 问 + 第 1 问的视觉母题 | 关系还活着 → 同框；关系断了 → 分开；谁掌权 → 谁占中心 |
| **机位** | 第 2 问① | 认同谁 → 架在谁肩上；谁被压迫 → 谁被俯视或压到边缘 |
| **运动** | 第 2、3、5 问 | 从观察点、信息揭示、动作、情绪或空间体验推导运动目的；有目的再选路径，不只按有无事件变化判定 |
| **光** | 第 5 问③ + 视觉母题 | 随人物状态变，不随场景变 |
| **色** | 第 3 问的视觉母题 | 全片一个对立，一场里只用其中一边 |
| **声音** | 第 5 问 + 第 2 问③ | **画内声＝他在现场；画外声＝他在回忆或被侵入**；他要讲道理时给安静 |
| **切点** | 第 3 问的主导问题 | 落在答案将出的**前一刻**；变化正在发生的那一帧 |

> **★ 一条总判据**：把这一镜的八个参数挨个问"为什么"，
> **只要有一个答不出因果，就说明你在抄，不是在导。**

## 九、★ 自我批判（每场戏出完必做）

**三问，写在方案后面，不许省**：

1. **这一版最可能在哪儿失败？** —— 具体到某一镜、某一句。
2. **如果只能改一个变量，改哪个？** —— 逼自己排序，不许说"都再调调"。
3. **我有没有在偷懒？** —— 具体表现为：
   - 用"电影感""高级感"这类词代替判断
   - 因为"这类场景都这么拍"而选了某个参数
   - 八项参数里有答不出因果的
4. **★ 陌生观众测试（逐镜过一遍，见下）** —— 这条查的不是"我写了什么"，是"**观众此刻知道什么**"。

### ★ 第 4 问：陌生观众测试（2026-09-13 新加）

**为什么单独列一条**：创作者对自己故事的信息补偿是**自动的、无意识的**——你太熟了，看文本时会自己把缺的补上，**所以你根本看不出缺什么**（《莽古斯》导演 KK 原话："我太熟自己的故事了，看文本时会自动脑补，但第一次看的观众看不懂"）。
**这条查的是与前 3 问完全不同的维度**：前 3 问查"判断对不对"，**这条查"信息够不够"**。

**做法**：把分镜按顺序读一遍，每读到第 N 镜，问一句——

> **"一个只看过前 N−1 镜的观众，此刻是否知道：① 这是谁 ② 在哪 ③ 上一镜发生了什么 ④ 他为什么这样做？"**

**任一问答不出 → 这一镜缺信息。修法有优先级：**

| 修法 | 说明 | 评价 |
|---|---|---|
| **① 补在前一镜的结尾** | 在上一镜末尾留一个可读的信号（一个物件、一个眼神、一个动作） | **★ 首选** |
| ② 在本镜里加一个可读信号 | 用画面内的东西交代（墙上照片、手上的戒指） | 次选 |
| ③ 用台词/字幕解释 | 直接说出来 | ❌ 最差——AI 短片台词与画面文字都是高危，且会把戏讲死 |

> **为什么首选"补在前面"**：创作者的本能是在当前镜里塞解释，但**当前镜一塞就信息过载**（这一镜本来要交代动作，又加解释，模型会顾此失彼）；
> 而**补在前一镜的结尾等于改一个"钩子"**——观众带着问题进入下一镜，本身就是更好的叙事。

**注意与"删掉测试"的分工**：删掉测试查的是"这一场/这一镜**该不该存在**"（冗余）；
陌生观众测试查的是"这一镜**能不能被看懂**"（缺失）。**两者都可能同时命中同一镜——先删冗余，再补缺失。**

**与 `steelman-protocol.md` 的分工**：
> 那个管**提示词会不会执行失败**（模型会不会做砸），
> 本文件管**这个判断对不对**（做成了是不是也是错的）。**两道都要过，顺序是先本文件、后那个。**

**每场戏填一份，填完才许排镜**（第 1 问只在开新片时填一次，其余每场重填）：

```
【导演推理】第 [N] 场

1 命题：这部片在说的是 ______
  核心矛盾：____ ↔ ____　视觉母题：____
2 人物：他要 ____，其实需要 ____；他怕 ____；他靠 ____ 撑着
  认同谁：____　这场里认同会不会转移：____
3 这场为什么非存在不可：删掉它，后面 ______
  进：____　出：____　主导问题（观众在等什么答案）：____
4 冲突形状：谁进攻 ____ ／谁防守 ____ ／战场是 ____
  同框还是分开：____
5 能量：进场 ____，出场 ____（1–10）；上一场是 ____，落差或有意延续如何服务命题 ____
  叙事信息密度：高／低　·　情绪重要性：高／低　→ 镜头长度：____（打架时听情绪）
6 参数与因果（每项必须填得出"因为"）：
  景别 ____ 因为 ____
  机位 ____ 因为 ____
  运动 ____ 因为 ____
  光 ____ 因为 ____
  声音 ____ 因为 ____
  切点 ____ 因为 ____

自我批判：最可能失败在 ____；只改一个变量就改 ____；有没有在偷懒 ____
```

> **这份记录是内部工作稿，不进交付物**——与 `sequence-craft.md` 的布局地图同性质。
> 但它**值得存档**：同一部片的场与场之间要互相校验（尤其是第 5 问的能量推进或有意延续）。

### 审已有方案时的最小交付

任务是审阅已有文字分镜时，保留既定命题和锁定项；按“原文证据 → 陌生观众可能知道/误解什么 → 相对表达目标的缺口 → 最小可见修改”判断。观众已知只按分镜明确呈现的信息判断，剧情目标中未呈现的背景仍列未解。先列出现有角色、道具及信息断点；能用现有元素解决，就写出获准修改那一镜中的连续可见动作及结果。一镜可包含动作过程，不能把“只改一镜”误当只能更换静态末态；现有元素确实不足时，说明剩余缺口，并将必要新增元素单列待确认及理由。已存在或用户明确允许的元素照常使用。复核修改是否仍满足镜数、声音与改动范围。只准改一镜而无法同时解决全部缺口时，写明未解，不把改法宣称为已完成的效果。

未解收口：依当前验收目标和采用后的整段文字，按三类交付；状态与证据定义见 governance-law.md L6。

1. 当前文字结论与必要修法：把原文连续动作与前后持有状态合起来，对照目标核对发起者、回应及结果。主动让渡核对让渡者发起；自行取走保留接收者发起。动作与状态已共同支持目标时，必要修法写无；“松手/手空”不是独立必备词，最终持有状态已清楚时不为补词强加动作。仅增强可读性的安排归第三类。确有缺口时，只在获准范围补目标所需的发起、接收与结果。有效原话、当前替换稿、已选镜头分工和表达手段归入依据；文字条件已能推出的成立或不可达结论直接写明，不重新当成未知。
2. 真正需要确认的问题：每项写“还缺的具体信息或决策 → 会改变哪个当前验收判断”。只保留会改变本次文字判定的缺口；关键物件身份缺失时，列明审阅所缺依据和目前无法判定的目标，保留原文角色事实与已成立的动作；缺的是物件与目标的对应关系，就确认该关系，不把“角色是否知道内容”换成判据或新增认知缺口。必须改变锁定空间/机位才可能完成动作时，写清需改变哪项决定；若用户已明确不许改变，当前直接判条件下不可达，不再追问能否改锁定项，突破范围的选项只列后续另行确认。没有就明确“当前文字无待确认项”，不把局部审阅扩成完整创作六问补写。
3. 后续实现与媒体验证：分列“待设计或拟订选项”和“效果待验证”。不影响当前文字判断的未定机位、景别、空间摆位归待设计，不要求用户先补答；实际表演、接触和观众可读性归效果待验证，写清所缺的媒体证据。不能由文字成立推成实际效果通过，媒体效果边界见下段。

概念判断、文字分镜和实际媒体分开报告。没有媒体时只评文字可读性和因果，不写已看见表演或动态已通过；完整创作仍按六问推导，不为填写模板重做用户未要求改变的全片。

## 十、★ 当推导结果与既有偏好冲突时

**习惯与默认值的存在是为了省时间，不是为了免于思考。**
推导结果（第一至五问）**优先于**下面的默认值；若两者冲突，按推导走，并把理由写出来。

| 既有偏好 | 什么时候它会错 | 怎么处理 |
|---|---|---|
| **"开场 3 秒钩子"** | 命题要求观众**先进入人物的日常**时（缓慢、冥想、生活流的片），强行加钩子会毁掉调性 | 钩子**不能与第一问的答案矛盾**；这类片改用"一个反常的细节"而不是"一个强事件" |
| **"结尾留白"** | 类型要求**最后一击**（惊悚 / 恐怖）或要求交代人物去向时 | 留白是**默认**，不是铁律；推导要求"击中"就击中，要求"补完"就用蒙太奇 |
| **"动作镜景别快速切换"** | 该段落**信息密度低**、需要沉浸时 | 快切只在信息密度高时成立（第 7 问②）；密度低时快切＝莫名其妙地赶 |
| **"全片统一光度量级"** | 人物弧线要求光随状态变化时 | 精确化：**量级（机器 / 镜头 / 印片）统一，光的性质可以变**。两者不是一回事——统一的是"谁拍的"，不是"每一场都同一个光" |
| **"人物一致性五条线"** | 人物**该变化**时 | **变的必须是状态与情绪，不变的必须是身份与造型**。一致性是防止漂，不是防止变；用它锁死弧线就是误用 |
| **"一镜一张黑白故事板"** | 不冲突，但**顺序常被做反** | 先答完前五问再画构图；**先画构图再想戏剧任务，是这条纪律最常见的失效方式** |
