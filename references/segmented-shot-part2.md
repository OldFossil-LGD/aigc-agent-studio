## 九、可复制模板（两版）

### 简化版（默认 · 一张首帧 + 段落文字）

只出**第一段**的彩色首帧当图生视频输入，后两段靠文字。**代价说清楚**：后段的几何与身份只有文字兜底，漂移风险高于稳版。
**★★ 首帧与多画面的冲突**：**首帧 / 首尾帧 / 全模态参考三选一、互斥，不能同时给**——只给第一段首帧时，**段内后续画面只有文字兜底、容易被首帧的构图锁住**；要段内真的换画面，**优先走稳版**（先派生机位图，或改用首尾帧）。
**适合**：同一光区、主体 1 人、动作简单、不是非过不可的段。

**⚠️ 板块照写**：分段镜**同样用【】分节**（与 `shot-craft.md` 单镜模板**同一套 12 块、同一顺序**——
先"全片通用"三块标"每一段逐字复用、不改字"，再"本段专属"九块）。　**★ 每块的接口规格 → `references/block-spec.md`**
**唯一差别是【时间线】按段落分条、并把段内的景别变化写进时间线。**
**不要把板块压成散文**：散文会让"光""器材""动作"糊在一起，模型容易把**光**读成**动作**。
**★ 动笔前先回 §4.1 算「总时长 ÷ 段数」——这道门过了再写板块。**
> ⛔ **首行的 `[风格槽]` 不许留「写实电影」这种笼统词**（`写实电影风格`＝把"电影感"换个词塞回去）——**模型会按训练数据里最"电影"的那套给：高饱和 + 浅景深 + 青橙 + 均匀布光**（→ `color-narrative.md`：**听到"电影感"就给青橙**）；**而且它会跟后文打架**（日式文艺要**高调过曝、低对比、几乎单色**，牛仔要**天空过曝成浅黄而不是饱和蓝**）。**写成技法名词句**：`日式日常静观：高调过曝、低对比、几乎单色偏暖白，机位几乎不动` · `美式经典西部的荒原：土黄与赭石、天空过曝成浅黄，地平线压到画面下缘`（→ `prompt-ops.md` 空话词表·**风格槽**一条）。

### 稳版 = 简化版 + 每段机位锚定（**不另抄一遍，只列差异**）

1. 先出**段落A** 的彩色首帧；**用图像编辑从它派生出其余机位图**（改机位、不改材质与光）——**不要分别重新生成**（新生成会让磨损与反射对不上）；
2. **每段末尾加一句机位锚定**，写在【时间线】同一行里：`…[一个动作]；[机位参考图片1]`；其余板块与简化版逐字相同（**同一套 12 块**：全片通用 3 + 本段专属 9）。

> 两版都要接 `quality-layer.md` 第二节的**统一提质层逐字块**——分段镜最容易在段间漂的就是质感与颗粒，这一段是唯一能同时管住整条的。

## 十、失败模式与止损

| 症状 | 根因 | 修法 |
|---|---|---|
| **★★ 整条看不懂，每段都糊**（**最高频**） | **总时长 ÷ 段数 < 2 秒**——每段预算不够演完一件事 | **减段数**（回 §4.1 重算）或加总时长或拆成多次生成。**不要在提示词里加内容** |
| **★★ 整条只出一个镜头，段内景别没切** | 段内**画面数没有下限**；或用了**剪辑词**（`切到` / `转到` / `镜头N`），被读成"要另起一次生成" | 每段**至少 2 个画面**、**全片画面数 ≥ 段数 + 1**；换画面**只用换景词**（§七） |
| **说切了但没切**，三段糊成一段 | 段名写进了散文里；或每段塞了多个动作 | 段名**另起一行**；每段只留一个动作，**一个画面只留一个运镜** |
| **切了，但人换了一张脸** | 锚点没逐字复述，或用了近义词 | 锚点句**整句复制**到每段；清掉全部近义替换 |
| **段首景别没变** | 段首没显式写景别词 | **每段第一个词就是景别** |
| **★★ 一段里塞了整条动作弧** | 借了**段间词汇**（准备/接触/落定、起始/触发） | 段内推进写**「他先…；随后…；最后…」**（§三）· 跑检查 0c |
| **段首景别与后文打架** | 景别标签只描述起始帧，段内又变了却没写 | 段内景别变化**必须在时间线里写出来**（§三） |
| **★★ 景别标成中近景，出来像特写** | 收尾句**只写动作、没写画框还剩什么**（"手停在枪套上"） | 景别行**点名画框边界**（"画面下缘收进枪套下半截"）；收尾分开写画框与动作（→ `sequence-craft.md` §8.1b） |
| **模型自己加了镜头** | 没写死段数与切换数 | 全局约束分别写段落数、段间切点、段内断切及全片切点总数（口径见 `segmented-shot.md` §七） |
| **最后一段很仓促** | 段排满、末段没有落定空间 | 末段的**动作相位**在落定处收住（**不要靠留秒数**） |
| **背景每段都在变** / **转场很花但叙事没动** | 每段重新描述了场景；或用了炫技转场 | 陈设也只复述不新写；同场景换机位**一律硬切** |
| **一段之内又推又摇 / 动作变形** | **画面内**没排除同族；或本就不该进分段镜（手、走路） | 照 `shot-craft.md` 写同族排除；变形动作拆出去（`motion-control.md`） |

**止损顺序**：① **先算每段秒数**（`总时长 ÷ 段数`，< 2 秒直接砍段数）；② 再减每段信息（动作砍到一个）；③ 再换硬切；④ 还不行就**退到拆段**——分段镜是省事路径，不是唯一路径。
