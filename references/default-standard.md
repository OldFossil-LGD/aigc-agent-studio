# 默认标准（十站出口门 · 不许随机 · 不许偷懒）

> **何时读**：接到任何"做片 / 写镜头 / 改片"任务的第一分钟；每站准备说"下一步"之前。
> **读完回哪**：各站的规则仍在原册（本册只做**绑定与出口**，不重复规则）；工具 → `stage_gate.py`。
> **★ 地位**：本册是**执行纪律册**。与各册细则冲突时，**细则以各册为准，出口以本册为准**。

---

## §0 三条原则

本册适用于交付终点已确定的制作流程。只检查该任务进入的制作站，文本审阅与终点之后的站记为不适用。完整制作工程才用 `--all`；不适用站无需虚构用户豁免，仍保留适用站的出口要求。

1. **默认值是写死的，不是"看情况"**——没有用户明确指令时，按 §2 执行，不现场发明。
2. **每站有出口门**：文件在不在、必填段有没有、清单过没过、参考是否生效——**机器能判的必须机检**。
3. **跳过只有一种合法方式**：**用户明说** + 写进 `waivers.json`（含原话）。agent 自己"觉得不需要"＝FAIL。

## §1 十站出口（`stage_gate.py` 逐站判）

| 站 | 必产（缺一即 FAIL） | 出口判据 |
|---|---|---|
| **S1 命题** | 01_命题.md | 七段齐：命题 / 核心矛盾 / 视觉母题 / 人物三问 / 进出差 / 主导问题 / **可反转** |
| **S2 可行性+brief** | 02_brief.md | 六项齐：时长 / 画幅 / 主旨 / 交付物 / 难点 / 风格 |
| **S3 风格+方案包** | 03_style.md | 风格编号 / 量级系 / 方案包；一片一包 |
| **S4 剧本** | 04_script.md ＋ 10_breakdown.json | 七件齐；节拍秒数合计＝总时长；无空档重叠；**拆解单存在** |
| **S5 资产** | `assets/asset_manifest.json` | `ok=true` 且 `counts.fail=0`；七件齐 / 每镜≤1 张脸 |
| **S5.5 参考闭环** | `refs/resolved.json` | 每镜有 `node_key` 且 `effective=true`；**空引用不许生成** |
| **S6 分镜** | 06_shotlist.md ＋ 16_production_ir.json ＋ 15_Canonical_Prompt.md | 镜号/景别/时长三列；`shotlist_lint` 无 FAIL；**IR 无 BLOCK**；12 块视图存在 |
| **S6.5 生成** | `gen/tasks.jsonl` | 每行有 `task_id`、非空 `refs`、状态不是 failed/cancelled |
| **S6.6 合成** | `out/final.mp4` + `qc/container.json` | 成片非空；容器信息有据（时长/分辨率/fps/音轨） |
| **S6.7 交付** | `delivery/evidence.json` | 四件：`task_id` / `params` / `result_path` / `criteria` |
| **S7 返工** | `rework/decision.md` | 责任层 + 回退站；不许"再抽最后一次" |

```bash
python scripts/stage_gate.py --dir projects/P1 --all
python scripts/stage_gate.py --dir projects/P1 --stage S5
```

**退出码**：`0` 全过（含合法豁免）｜`1` 有站不过｜`2` 用法错误｜`3` 没扫到（≠通过）。

## §2 全局默认值（用户没说时照此执行）

| 项 | 默认 |
|---|---|
| 画幅 | **16:9**；竖屏 9:16 仅用户指定 |
| 单镜时长 | **5s**；生成单元下限 **2.0s**（低于必崩） |
| 声音 | 平台侧 **`enableSound=off`**，声音本地做 |
| 每镜参考 | **中位 4–5**；75%/63% 的成片镜头 ≥4 张（THE TURN / 抵达之前全量统计）；同一身份 **≤1 张脸**；**顺序＝空间/首帧 → 人物 → 道具**；超过 4 张逐张声明用途 |
| 人物 | 每造型 **7 件**（脸 + 前/后/左/右/俯 + 无头身体） |
| 场景 | **平面图 1 + 每个机位 1 张**；同机位多镜只出 1 张 |
| 道具 | **主图 1**；多面 3；**上限 5**；物证加近距版 |
| 命名 | `资产_{主体}_{角色}[_{状态}]`；`镜头_{id}` |
| 目录 | `assets/ refs/ gen/ out/ qc/ delivery/` |
| 模型 | 由**方案包**决定，不临场挑；默认 `Seedance 2.0 VIP` |
| 幂等 | 每次付费调用带 `idempotencyKey` |
| 重试 | 每阶段 **2 次**；同一产物 **≤3 次**；超限改结构 |

**资产类默认**：先建立 L1 脸部特写，其余六件 L2 以它为 `parent` 生成（`modeType=image2image`）；机位视图以平面图为 `parent`；每镜按朝向取件，**不把七件一起挂**。

## §3 反偷懒判据（机检已覆盖，人工也照此看）

| 症状 | 判据 | 处置 |
|---|---|---|
| **空话** | 电影感 / 氛围感 / 高级感 / 质感拉满 / 大片感 | 换成可判的物理描述 |
| **占位** | `TODO`、`待补`、`（待定）`、`[ ]` | 补完或标未解，不许交付 |
| **看着像** | 交付说明里出现"看着像 / 差不多 / 应该可以" | 必须给帧级或像素级判据 |
| **未过门就说完成** | 没跑 `stage_gate` / 相关 lint 就报"完成" | 视为未完成 |
| **静默裁剪** | 少一件资产 / 少一镜 / 少一段声音，没有豁免记录 | FAIL |
| **自证** | 用自己刚写的样例证明自己写对了 | 换人或换数据复验 |
| **模板脸** | 冻结块里出现"沧桑 / 坚毅 / 有年代感" | 换物理事实 |

## §4 豁免协议（唯一的"跳过"通道）

`projects/<id>/waivers.json`：

```json
{
  "S5.5": {"user_quote": "先别建画布，我只想看提示词", "reason": "用户只要 prompt_only", "date": "2026-10-31"}
}
```

- **必须有 `user_quote`**（用户原话）；没有原话＝不是豁免，是偷懒。
- 豁免只免除**该站的出口**，不免除已产出的质量；下一站仍按自己的门判。
- 豁免记录进交付证据；**交付时要能说出哪几站被豁免、为什么**。

## 来源与署名

- **本册为本库自建**：把 run-sheet 的十站、asset-standard 的数量裁决、asset-pipeline 的引用与 QC，收敛成**一套默认值 + 出口门 + 豁免协议**。
- **不新增创作规则**；只把已有的"建议"升级为"默认 + 可判"。
- **★ 分档**：默认值来自本库既有实测与平台口径；`stage_gate` 判的是**结构与证据**，不判画面好坏——画面仍要人看。
