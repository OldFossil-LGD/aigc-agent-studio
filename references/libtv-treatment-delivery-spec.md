# 提案类交付物的视觉与实现规范（命题·页面·分层·抽帧）

> **来源**：官方插件 `libtv-to-treatment/SKILL.md` §5–§7（**一手 · 2026-10-15 读**）。
> **为什么单列**：本库有交付**内容**层（`libtv-quality-delivery-content.md`）与验收清单，但**"交付物长什么样"的量化规范此前几乎空白**（`4.5:1` / `CSS 变量` / `--accent` / `镜头网格` / `object-fit` 全库 **0 命中**）。本册只收**可跨项目迁移**的规则，不收该格式专属的美学偏好。
> **读完回哪**：`libtv-quality-delivery-content.md` · `acceptance-check.md`。

---

## 一、画布、安全区与语言

- **1920×1080 逻辑设计画布**；每页**严格 16:9**，在不同窗口**等比缩放**——**不拉伸、不改成长网页**。
- **安全边距通常为页宽 4%–6%**；**导航放在内容安全区之外或独立控制层，不得压住图文**。
- **语言分工**：正文 / 小标题 / 图注 / 表头 / 页码提示 / 目录 / 播放按钮用**中文**；英文只用于**每页大标题、专名与固定页脚**；**歌词原文不受中文正文规则限制**。

## 二、字号阶梯（逻辑画布 px，可直接当门禁）

| 用途 | 字号 |
|---|---|
| 内容页大标题 | **64–100**（封面/少字海报页可 **120–180**） |
| 正文 | **28–36** |
| 图注与表格 | **不低于 22** |
| 歌词单页 | 24–28 |

**★ 一条硬纪律**：**空间不足时先精简、重排或拆页，不要持续缩小文字。**

## 三、从资产推导色卡（官方六步法）

1. 从封面候选、主要场景、人物与高潮画面里选 **6–12 张**代表素材（不足就用现有素材）；
2. 归纳 **3–5 个有依据的候选色**，区分"场景主色 / 背景中性色 / 局部识别色"；**人物肤色不因面积大就自动成为强调色**；
3. 从主色或识别色的**同色相及相近色相**中取**较高饱和度**作强调色，**不随机加入与资产无关的荧光色**；
4. 定下 **1 个主强调色 +（可选）1 个相近辅助色 + 背景色 + 正文色 + 弱化文字色**，并**记录成 CSS 变量**（如 `--accent` / `--accent-alt` / `--bg` / `--text` / `--muted`）；
5. **高饱和色面占比**：内容页通常 **5%–15%**（少字海报页可 **25%–40%**）——**这只是控制视觉重量的参考，不要求机械测量**；**高饱和体现在设计层，不默认提高原始照片/视频的饱和度**；
6. **对比度**：普通文字与其背景 **≥ 4.5:1**，大号粗体 **≥ 3:1**；叠图文字按**实际落字区域**检查，必要时调整色值/加局部遮罩/加底板。**不要为了"高饱和"牺牲可读性。**
**纯黑白资产没有可靠色相来源时**：沿用已知品牌色；没有就自提一个统一强调色，**并在内部方案注明这是设计选择**。

## 四、九种版式家族与节奏

**满版海报** · **横向镜头带** · **居中主画面** · **居中概念页** · **非对称双栏** · **主图加拼贴** · **镜头网格** · **局部强调色面** · **音乐结构版**。

- **全篇选 3–5 类贯穿使用**，不要求每页换风格；默认以"居中 / 上下关系 / 横向镜头带"为主构图；
- **左右图文双栏页不超过内容页的 1/3，且不得连续超过两页**；**交换左右位置仍算同一版式**；
- **镜头网格：默认 4 列 × 2 行 = 8 镜，每页最多 8 镜，超出新增页面**（末页允许真实余数）；
- 让"大图少字页 / 叙述页 / 高密度网格页"交替；**不为版式变化增加空洞章节页**；
- 图文并置时**主图占明显优势**；**分镜表为保证比较与顺序可以等大**。
- **每页中文说明通常 80–180 字**（歌词与表格不套用此范围）。

## 五、图片与分层的实现纪律

- **图片不拉伸**；影调/故事线/分镜用**原生 16:9 或原始比例**；**尺寸随图片比例计算，不用"不匹配的固定高度 + `object-fit: contain` + 色底"制造黑边/白边**。
- 源文件自带黑边先确认边界；**仅在用户授权裁切时**移除纯边缘，**不裁关键画面**；氛围图可裁切但**保留人物脸部、关键动作与道具**；分镜与服化道参考**优先完整显示**。
- 分镜可用**统一约 3–4px 描边 + 左上角 `CUT1` 式编号标签**（底色与描边同色、直角、干净排版）；**避免做成仪表盘卡片**。
- **层序固定**：底色/渐变底层 → 低透明度背景图 → 局部渐变遮罩 → **清晰前景图与文字** → 导航。**不要给整个页面或公共父容器设模糊与低透明度。**
- **背景图透明度** 0.15–0.30 起步（按实图在 **0.12–0.40** 内调）；遮罩把文字区与边缘压暗或柔化，另一侧保留少量色彩。
- **低清截图当背景**：`filter: blur(12px)` 起步（常用 **8–24px**）＋低透明度＋渐变；**背景层放大约 1.04–1.08 并裁切溢出**，避免模糊边缘露缝。高清且不干扰阅读的背景可不模糊。
- **★ 模糊是"主动弱化细节"，不是超分辨率或清晰度恢复——不得宣称修复了源图。**
- **背景与前景不得是两个同等抢眼的重复主体**；重复同图时背景要弱到主要只剩色块。

## 六、抽帧选帧（与视频侧共用）

- **先在同镜头内比较多个相邻候选**；避开**转场、严重运动模糊、编码破损、闭眼尴尬帧**；
- **静态资产清晰且符合内容时优先用静态资产**；
- **按实际显示尺寸检查**——**分辨率数值合格 ≠ 画面清晰**；
- **低清图不得直接充当"需要看清人物细节"的满版主视觉**：可缩小置于前景、另用柔化副本铺底，仍不可用就换来源；**前景图必须始终清晰展示**。
- **CSS 处理不需要改原图**；**打印与预览两种介质都要检查**模糊与透明度效果。

## 七、交付包结构（**官方 §6.1**）

```text
treatment/
  index.html
  assets/{images,video,audio}/
```

- **只创建实际用到的素材目录**；另交付 **`treatment.zip`**，**ZIP 根目录直接含 `index.html` 与 `assets/`**（不是再套一层目录）；
- **内部资产清单、完整对话、调试日志、源凭据一律不进交付包**；
- 用户要"本地 HTML 素材包"即**包含"下载所选画布相关媒体"的任务范围**：按 LibTV 媒体下载路线存到**明确本地目录**；**保留源文件、网页压缩副本另存**；**不扫描无关本地文件**。

## 八、实现约束（**官方 §6.2 · 13 条**）

1. **优先静态 HTML + 内联 CSS/JS**；**页面内容直接写进文档**——**不依赖本地 `fetch` 读 JSON、不依赖构建工具、不依赖后端服务、不依赖在线 CDN**，确保**解压后可直接打开**；
2. 媒体用**相对路径**，避免工作机绝对路径与登录态 URL；字体用**合适的系统中文字体回退**，特殊字体**可合法随包提供**；
3. **固定逻辑画布 + 整体等比缩放**（或等效方案），并**验证内部排版也随页面缩放**——**不能只给外框写 `aspect-ratio` 却让内容高度失控**；
4. 导航必备：**上一页 / 下一页 / 当前页-总页数 / 中文目录 / 全屏入口**；键盘支持 **左右方向键 / Home / End**；**聚焦输入框或媒体控件时不抢占按键**；按钮有**可理解标签与可见焦点**；
5. 视频提供**对应封面 + 原生控件 + `playsinline`**；**音视频均不自动播放**；**离开页面暂停其媒体**（避免多路声音叠加）；**全屏不可用时仍能正常翻页**；
6. 图片加**有意义的替代文本**；媒体加载失败**显示中文提示**（必要时保留已验证原始链接）；**不能因一个媒体失败导致整份提案翻不了页**；
7. 用户文本写入 HTML 时**正确转义**；媒体链接只用**可信来源与适当协议**；**不把画布原始 HTML / 脚本 / 事件属性直接插进页面**；
8. 素材下载失败**先试受支持的恢复方式**；仍失败**可交付带明确在线依赖的版本，但不得称为"离线完整包"**；**只有缩略图就如实标明**；
9. 用户要**单文件 HTML** 时可内嵌适量素材——**先评估大型音视频体积**，**不许悄悄改成外链却称"完全独立文件"**；
10. **不因生成本地提案就自动发布网站**；用户另行要求托管时才走发布流程。

## 九、打印样式（**官方 §6.3**）

- 加 **`@media print`**：**所有幻灯片顺序显示、每张一页、16:9 自定义纸张、零页边距**；
- **取消屏幕缩放、隐藏导航、设置分页、保留背景色**；
- **打印时视频显示封面、音频显示文字说明**；
- **不能只打印当前激活页**；
- **★ 浏览器打印设置仍可能影响输出——实际检查过之后才能声称"打印效果已验证"**。

## 十、验收：必须**打开真实 HTML 逐页看**（**官方 §7**）

**★ 总纲**：完成后**打开真实生成的 HTML 逐页检查，而不只检查代码能否解析**；优先用浏览器预览/截图；按结果修正并**复查受影响页**。

**内容侧**：项目与版本正确 · 重要图片与人物**没有错配** · 分镜顺序与来源一致 · **缺项/建议/估算没有伪装成既定成果** · 视频独立页在尾页前且 Scene 用场景图 · 中文规则正确、署名有依据、**歌词与时间码没有凭空补全** · **对客页不含完整 Agent 对话 / 技术日志 / 临时签名 / 资产统计 / 核验过程 / 制作自述**（重要限制只留在交付说明）。

**视觉侧**：每页 16:9 且**同时检查标准桌面尺寸与较小窗口** · **无文字溢出 / 元素重叠 / 裁掉关键主体 / 空白图片 / 难读表格** · 字重字号边距色彩一致且有章节变化 · **逐页核对大标题水平居中与内容页纵向坐标一致、不因内容多少上下跳** · 封面尾页无冗余角标 · 上下无装饰横线 · 左下页脚 `Director Treatment` · **缩略看整册**确认标题/强调色/网格成系统 · **核对左右图文双栏占比与连续页数**（不是只交换图文左右）· 无排版添加的黑白补边 · 图注与图片左边缘对齐 · 服化道图片等高无厚底板 · **背景柔化不能作用到前景** · **实际查看抽帧质量、不把模糊截图放大成清晰主图** · 分镜**每页最多八个有效镜头**、超出续页、不为凑数造镜头 · **原图未被擅自整体调色** · 中文细宋体 + 英文 Baskerville 且字号不变、**验证字体回退**。

**功能与交付侧**：**实测翻页 / 目录 / 键盘 / 全屏 / 离页暂停**（全屏受环境限制时**注明未验证**）· **验证本地媒体真的加载，至少实际播一次交付中的音视频** · **检查所有相对资源存在、ZIP 解压结构正确，并在解压目录打开 HTML 验证可移交性** · 检查打印预览含全部页面、保持比例、无意外空白页 · **未导出 PDF 就不宣称提供了 PDF** · **没有浏览器/播放能力时，做能做的结构与文件检查并明确列出未验证项——不能用"生成成功"代替视觉验收**。

**交付回复**：简要给出 **HTML 与 ZIP 链接、总页数**，以及**影响使用的缺项或在线依赖**；用可用的预览能力展示 HTML；**除非用户要求，不在回复里粘贴整份 HTML 代码**。

## 十一、交付类技能自身的维护纪律（**官方 §8**）

- **技能正文（含 YAML、空白、标点的 Unicode 字符数）严格 < 20,000**，建议**留至少 2,000 余量**；**改完要重新计数并校验 frontmatter 与命名**；
- 该上限**只针对技能文本，不限生成的 HTML 或提案页数**；**不许用"拆分重复说明"来规避上限**；
- **工具能力与认证方式一律用当前的 LibTV 基础技能与实时 schema**；**不在此固化私有端点、临时资源地址或特定账号信息**。

**→ 对本库的映射**：这三条与本库 `governance-law.md` 的"单一权威源 + 指针"和"实时 schema 优先"同向；其中**"不许靠拆分重复说明规避上限"**是一条新的负面约束——**拆册必须是"移动 + 指针"，不是"复制一遍"**。
