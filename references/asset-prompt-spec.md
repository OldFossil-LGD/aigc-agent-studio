# 资产提示词规格：三类资产的差异化 + 继承接口 + 从剧本派生

> **何时读**：**写资产提示词之前**（人物 / 道具 / 场景三类）；资产出完**准备放行**时；发现"下游接不上"时。
> **读完回哪**：**九块的写法** → `block-playbook-asset.md`（**唯一权威源，本册不重复**）；参考图纪律 → `asset-consistency.md`；五段式骨架 → `updream-workflow.md`；人物一致性 → `character-continuity.md`。
> **本册管三件它没管的事**：**① 三类资产各自的重点不同**（同一块在人物/道具/场景里要求不一样）· **② 每个字段被下游哪一块继承**（接口表）· **③ 资产从剧本的哪一行派生**（把剧作层接通）。
> **一句话定位**：`block-playbook-asset.md` 管"**九块怎么写**"；**本册管"写哪一类、写到什么程度、写完谁用"**。

---

## §0 为什么需要这一册（三个实测症状）

| 症状 | 病根 | 本册的处方 |
|---|---|---|
| 场景出了图，**排镜时发现没地方放机位** | 场景资产只按"好看"出，**没写空间结构** | §2 场景四字段 |
| 远景镜里**认不出是同一个人** | 人物资产只锁了"近景可判"的特征 | §3 景别可判区 |
| 道具**多出一堆、关键的一件却没出** | 资产清单**不是从剧本派生**的，是拍的 | §6 派生规则 |

**★ 一条总判据**：**每一件资产的每一句，都要能回答"下游哪一步用它"。** 答不出 → 这一句是装饰，删掉。

## §1 ★ 三类资产 · 九块重点对照表（**本册核心表**）

同一块，三类的重点**不同**。下表只标差异；**没有列到的格子按 `block-playbook-asset.md` 的通用写法办**。

| 块 | **人物** | **道具** | **场景** |
|---|---|---|---|
| **1 板式行** | **七张单图**（脸/前/后/左/右/俯/无头），不拼板、每张独立文件（`asset-standard.md` §3.1） | 主图 1 张；多面才 3 视角（**4–5 是上限，不是默认**） | 平面图为主锚点，机位视图由它派生（`asset-standard.md` §5）；**★ 图中不许出现人** |
| **2 身份锚点** | **40–70 字物理事实，逐字冻结**（命门） | 等价物＝**材质 + 年代 + 磨损指纹**（没有"脸"，所以锚在工艺上） | 等价物＝**空间指纹**——一处**唯一可辨**的建筑小特征（例：`窗框刷过很多遍漆，右下角漆皮卷起一小片`） |
| **3 分区清单** | 逐格编号，**格与格只变一个变量** | 按"画面上实际要展示什么"给（一个背包 3/4 + 正视两张就够） | **★ 机位清单**（见 §2.3）——不是"视角数"，是"**这个空间能给出哪几个机位**" |
| **4 美学调性** | 全片唯一一行，逐字复用 | 加**年代与来历**一句话 | 同人物行，另加**该空间的时段**（它决定室内光） |
| **5 材质与脏** | 服装分层 + 皮肤哑光句 | **≥3 处逐处写脏**（位置+形态+尺寸） | **陈设逐样写脏** + **磨损分布**（哪里被踩亮、哪里积灰、哪里被手摸出油亮） |
| **6 尺度关系** | 身高 / 体型（与服装比例） | **与人体部位对照**（"高约90厘米，到成年人的腰"） | **★ 空间尺度**（见 §2.1） |
| **7 色板** | 分区 4，**即全片调色基准** | — | — |
| **8 布光** | 中性可继承光 | 摄影棚暗调（静物） | 该空间光源逻辑（**可带光池与死黑**） |
| **9 提质层** | 无运动句；皮肤哑光句 | 无运动句；高光颗粒句 | 无运动句；**注意：场景的"真实"允许花在空间材质上，仍不许花在戏剧光上** |

**★ 三类共用的一条**：**量级句逐字粘本片方案包**（资产与镜头**必须同包**）。

## §2 ★ 场景资产：本册新增的四个字段（**此前全库没有**）

**为什么单列**：场景资产要同时承担两件事——**① 给人看（像不像那个地方）② 给排镜用（够不够放机位）**。现有写法只覆盖了 ①。

### 2.1 空间结构（写之前先量）
```text
面积约[X]平米；层高约[X]米；进深约[X]米；
[X]个门（位置：左墙中段 / 右墙靠后）；[X]扇窗（位置与朝向）；
主力墙面材质：[ ]；地面材质：[ ]。
```
**判据**：**说出"最远的一个机位大概在哪"**——说不出来，说明空间没量清。

### 2.2 空间可拍性（三条自检）
```text
① 这个空间能不能做出 ≥3 个机位（正 / 反打 / 侧或俯）？
② 有没有一面"干净的墙"能给到人物（否则每个背景都杂乱）？
③ 门与通道的动线清楚吗（人物从哪进、往哪走、在哪停）？
```
**★ 一处硬要求**：**场景资产必须能见两面墙**（`asset-consistency.md` 一·补 第 ③ 条）——**只有一面墙的场景，反打就没了**。

### 2.3 ★ 机位清单（**本册新增的字段，直接给排镜用**）
在分区清单里把"视角"写成**机位**，并写清这个机位**能拍到什么**：
```text
分区1 主视角：3/4 俯角，能看见桌、窗与左墙门（建立空间）
分区2 反打：从窗口方向回看，能看见桌的另一侧与右墙（对话用）
分区3 侧位：从门内往里，能看见整张桌的侧面（物件特写底座）
```
**判据**：**列不出 ≥3 个，就不要急着出图**——先改场景（加一扇窗、挪一件家具），否则后面每条镜头都在同一个机位里打转。

### 2.4 继承要素清单（**防"空间断裂"**）
**写下 3–5 样"每一镜都必须在场"的东西**（例：`搪瓷杯 · 钥匙串 · 那面小镜子`），并在图里给它们**明确的位置关系**。
**作用**：下游每一条镜头验收时对照它——**少了一样，这个空间在剪辑上就断了**。

### 2.5 状态版本（与道具状态机同规则）
**同一场景的日夜 / 灯态 / 天气，各出一版**，命名清楚（`S1-夜` / `S1-夜-灯亮半`），**不许在同一张图里画状态变化**。

## §3 ★ 人物资产：本册新增的两个字段

### 3.1 景别可判区（**决定"远景要不要另出资产"**）
把身份特征分两栏写：
| 栏 | 内容 | 用途 |
|---|---|---|
| **远景可判** | 体型 · 发型轮廓 · 服装主色与剪裁 · **随身物** | 全景/远景镜头靠这几件认人 |
| **近景可判** | 疤 · 痣 · 眼褶 · 皮肤质感 | 近景/特写靠这几件认人 |

**判据**：**你的片子里有没有"远景镜"？有 → 远景可判栏必须写满**（否则远景里那个人等于没锁）。
**推论**：若一部片**只有近景**，远景栏可以省；**但只要有一场全景，它就不能省**（这条据 `drama-scaling.md` 的场数预算推得——场景图数决定景别跨度）。

### 3.2 造型状态版本：**只写 delta**（**格式，照抄**）
```text
状态 A（基准）＝身份锚点冻结块逐字（不改一个词）
状态 B：[同一冻结块逐字]；差异：左袖自肘部起撕开约 15 厘米，右手背新增一道约 3 厘米的浅红划痕。
状态 C：[同一冻结块逐字]；差异：外衣脱去，内穿浅灰高领；头发被雨打湿，贴向右侧。
```
**★ 三条纪律**：① **冻结块逐字搬，一个字都不许改**（改一个词＝换人，`asset-consistency-part2.md` §七 第 5 条）；② **差异句要可判**（位置 + 长度/颜色/形态）；③ **每个状态单独一版图**，命名带版本号。
**上游**：状态来自 `character-continuity.md` 的造型状态表与 `script-module.md` 的 M11——**剧本里出现几个造型状态，就要出几版**。

### 3.3 / 3.4 → 见续册 `asset-prompt-spec-part2.md`

**★ 资产板的背景与布光（18% 中性灰 + 完全平光）** 与 **三视图的像素预算与跨面板一致性**——
**已移入续册 `asset-prompt-spec-part2.md`**（本册到 300 行上限，故拆）。
**一句话记住**：**板子是"参考"不是"成片"——灰底降对比、平光不带任何布光信息；格数只影响设计板的可读性，不改变投喂规格（投喂见 `asset-standard.md` §3）。**

## §4 ★ 道具的三类分法（**此前全库没有**）

**为什么分**：三类道具**在镜头里的处境不同**，出图规格就不同。

| 类 | 是什么 | 出图规格（**关键差异**） |
|---|---|---|
| **手持道具** | 会被握住、拿起、递出（杯 / 耳机 / 手机 / 钥匙） | 必须给 **① 握持面**（哪一面朝手、手指落在哪）**② 尺度对照**（部位对照或数字）；**接触面单独说明**（`ai-artifact-control.md` 的接触面） |
| **陈设道具** | 摆着不动、但在画面里（搪瓷杯、遗像、桌） | 必须给 **位置关系**——它与桌/墙/其他物的**相对位置**（"靠桌左前，距桌沿约10厘米"），**位置一旦定下就进冻结块**（换位置＝场景漂移） |
| **环境道具** | **成组**出现（一排灯 / 一堆纸 / 一片椅子） | **给"组"不给"个"**：数量区间 + 排列逻辑 + 单个与整体的尺度关系；**不要逐个数**（数多了模型必错） |

**★ 一条补充（与失败项咬合）**：**关键剧情物证（信/照片/工单/药瓶）要单独出一版"近距版"**——本库明列**手与物的接触是高失败项**，物证镜头必须靠**独立资产 + 少接触**来解决，不能指望远景里"顺便看清"。

## §5 ★ 字段 → 下游继承映射（**接口表**）

**这张表回答"这句写完谁用"**——资产是靶子，靶子的每一句都要有下游。

| 资产字段 | 下游谁继承 | 继承方式 |
|---|---|---|
| **身份锚点冻结块** | 每一条镜头的**第 7 块（人物与环境）** | **逐字复用**，不改一个词 |
| **色板** | 镜头端的**色彩陈述** | 与它**同族**（`color-science.md` §八） |
| **尺度关系** | 构图块（**同框占比**） | 写死，不用"适中" |
| **继承要素清单** | 每镜的"环境在场证明" | 逐镜对照 |
| **机位清单** | **排镜表**（`shot-orchestration.md`） | 机位从这里取，不从零编 |
| **布光（中性光）** | **下游不许继承** | 场景光由**镜头端**给；资产图的光**只是当次拍摄条件** |
| **逐处写脏** | 道具的任何出现镜 | 磨损形态在每镜一致（防止"越拍越新"） |
| **`hard_facts`（M11）** | 道具出现在**哪几镜** | 由剧本决定，不由美术决定 |

**★ 三条最容易被违反的**：**① 布光被下游继承**（人景光影不接）· **② 机位从零编**（场景白出了）· **③ 位置关系没写死**（同一件道具每镜换地方）。

## §6 ★ 从剧本派生资产（**把剧作层接通**）

**规则**：资产清单**不是拍的，是派生的**——每一件都要能回指剧本的某一行。

| 剧本（`script-module.md` 的 M11 / M7） | 派生出 | 判据 |
|---|---|---|
| **每个不同的场景标题（内外景+地点+时间）** | **一个场景资产**（含状态版本） | **地点名不一致会直接造出多余资产** |
| **`hard_facts` 的"恰好人数"** | **场景图不许出现人的规格**；人物资产的数量 | 数不上 → 场景出了人才发现 |
| **`hard_facts` 的"唯一道具"** | **必须出的道具资产**（+ 若为物证，加"近距版"） | 漏一件 → 下游某一镜没东西可拍 |
| **`hard_facts` 的"禁止出现的东西"** | 每张资产的**禁止项**（写进第 9 块） | —— |
| **角色表** | 人物资产；**造型状态数 = 剧本里的状态数** | 状态少一版 → 该镜的造型凭空编 |
| **`open_state` / `close_state` 里的物件** | 道具**状态版本**（开/合、亮/灭、满/空） | 状态少一版 → 同一件东西前后不一 |

**★ 两条硬判据**：
1. **清单里每一件资产都能指回 M11 或 M7 的某一行**——指不回去的，是多余（删掉，或说明它为什么必须存在）。
2. **M11 里有、清单里没有的**——是漏。
**这两条一正一反，用一次就能把资产清单从"美术的品味"变成"剧本的结算"。**

## §7 三类各自的常见失败（各三条）

| 类 | 失败 | 表现 | 修法 |
|---|---|---|---|
| **人物** | 身份锚点写成判断词 | 每张脸都像，**但不是同一个人** | 换成物理事实（位置+尺寸+颜色） |
| | 把表情当身份 | 下游每镜都是同一个表情 | 表情属镜头层，资产只给**中性** |
| | 只锁近景特征 | **远景镜里认不出** | 补 §3.1 远景可判栏 |
| **道具** | 写"有些旧了" | 出来是**全新塑料** | 逐处写脏 ≥3（位置+形态+尺寸） |
| | 尺度用形容词 | 同一道具**每镜忽大忽小** | 部位对照或数字 |
| | 关键物证没出近距版 | 物证镜全靠远景"顺便看清" | 单出近距版 + 少接触 |
| **场景** | 图中出现人 | 人景光影不接 | 场景与人物**分开锁** |
| | 只有一面墙 | **反打没了**，全片一个机位 | 场景必须能见两面墙 |
| | 没写空间结构 | 排镜时**没地方放机位** | 补 §2.1–2.3 |

## §8 交付前自查（三组，各六条）

```text
【人物】
① 身份锚点逐字复用冻结块了吗（没改一个词）？
② 冻结块里还有判断词（沧桑/坚毅/有年代感）吗？
③ 有远景镜吗？有 → 远景可判栏写满了吗？
④ 有几个造型状态？**每版都是"冻结块逐字 + 差异句"**吗？
⑤ 表情是中性吗（不是某一镜的表情）？
⑥ 布光是可继承的中性光吗？

【道具】
① 逐处写脏 ≥3 处吗（位置 + 形态 + 尺寸）？
② 尺度写死了吗（部位对照或数字）？
③ 它属于手持 / 陈设 / 环境哪一类？**该类的差异项写了吗**（握持面 / 位置关系 / 组而非个）？
④ 有状态变化吗？**每个状态单独一版**了吗？
⑤ 关键物证出"近距版"了吗？接触面说明了吗？
⑥ 它出现在哪几镜——是从 M11 派生的吗？

【场景】
① 空间结构四个数写了吗（面积/层高/进深/门窗）？
② 机位清单列得出 ≥3 个吗？**能见两面墙吗**？
③ 继承要素 3–5 样写了吗？位置关系明确吗？
④ 图中没有出现人吗？
⑤ 日夜/灯态状态版本齐吗（凡是剧本里出现的）？
⑥ 陈设逐样写脏了吗？磨损分布写了吗？
```

## §10 ★ 跨平台参考机制：**"参考图"不是一套机制，是四套**（2026-09-17 外部学习后补）

**写资产提示词前先答一句**：**我这张参考图是"引脸 / 引整个主体 / 引风格 / 引构图"里的哪一种？** 说不清 → 模型会替你决定，而且它常常决定错。

| 机制（行业通名） | 引什么 | 权重参数 | **适用范围（关键）** |
|---|---|---|---|
| **角色参考** | **一个人**——发色 / 衣服 / 面部 | 有强度参数，端点 0 与 100 | **只在中生代版本上支持**；新版本官方标注**不支持** |
| **主体参考** | **整个主体**——人物 / 物体 / 载具 / 非人生物 | 0–1000 | **只有某一代支持**；更新的版本上**任务会静默回退到上一代重跑** |
| **风格参考** | **只引风格**（色彩 / 介质 / 纹理 / 光），**不引主体** | 0–1000 | 覆盖较广 |
| **图像提示** | 内容与构图 | 0–3（各版本不同） | 较广 |

**★ 三条硬结论**：
1. **道具 / 载具 / 生物类资产要引"整个主体"**，不是引脸——**本库"道具用多角度拼图当参考"在机制层面对应的正是这一类**。
2. **版本陷阱是真实存在的**：同一参数在不同版本上可能"支持 / 不支持 / **静默回退**"三态。**因此所有提示词模板必须标注"适用哪个模型版本"；跨版本教程一律降档使用。**
3. **权重数值不要背**：官方只给范围，**"多少最好"是个人手感（不可追溯的经验值）**——**只能当起点，且必须自己在本版本上复核**。

> **★ 证据档位（本库口径）**：本节两条机制的版本兼容关系来自**读官方文档核对的第三方整理**（**B 档**，标注了核对日期），**不是官方直发**；**权重甜点值一律 C 档，未采用**。

## §11 ★ 参考图的"角色分工"（八种角色，每种都要写"不许它供什么"）

**一张参考图 = 一个任务。** 八种角色（**每张只给一个角色**）：

| 参考图角色 | 借什么 | **必须写清"不许它供什么"** |
|---|---|---|
| **身份** | 脸 / 发 / 年龄 / 可辨特征 | **不许供姿态与背景** |
| **产品 / 道具** | 形状 / 比例 / 标识位置 | **不许重新设计** |
| **服装** | 款式 / 颜色 / 材质 | **不许供模特的脸** |
| **姿态** | 身体位置与机位角度 | **不许供身份与服装** |
| **风格** | 色板 / 颗粒 / 渲染方式 | **不许供主体与构图** |
| **构图** | 位置 / 取景 / 留白 | 原物可换 |
| **光照** | 方向 / 软硬 / 对比 | **不许供场景内容** |
| **批注** | 箭头 / 框选 / 涂改标记 | **只在标记处生效** |

**★ 三条用法**：
1. **点名编号**：`图1 只供脸；图2 只供配色——不要抄图2、图3 的物体与文字`。**这就是本库"参考范围与不继承项"那句话的展开版**。
2. **不要堆图**：参考图越多，**互相冲突的脸 / 材质 / 视角**越多——**用"能说清需求的最少张数"**。
3. **一致性靠单变量迭代**：**每批只改一个维度**（角度 → 背景 → 时段 → 小道具），出成网格后挑**身份稳定的**那些。
**上游**：`asset-consistency.md` §二（位置权重）· §三（视角数与一致性）· `updream-workflow.md`（多图参考的落法）。
