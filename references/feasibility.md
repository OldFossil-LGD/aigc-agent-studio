# 可行性边界与题材选择（写剧本前的第一道门）

> **何时读**：**动笔写剧本之前**——它决定这部片做不做得出来。**读完回哪**：回到 `studio-workflow.md` 第一步。
>
> 一句话：**AI 短片的成败，在选题那一刻就基本决定了。** 2024–2026 所有获奖 AI 短片，
> **没有一部是"提示词一键成片"**——都是图生视频 + 大量人工剪辑后期；AI 占比越高，题材越集中在**抽象 / 无对白**。

## 一、先看数据（这是排期与预期的基础）

| 事实 | 数据 | 来源类型 |
|---|---|---|
| 真实可用率 | 生成 3–5 秒的片段，**去掉瑕疵后有效通常只有 1–2 秒**（约 30–40%） | 《鬼饮食》制作方自述 |
| 商业广告实测 | 40 条生成**只有 3 条可直接用、2 条裁切可用**（约 12%） | 品牌实测 |
| 高难镜头 | 有快动作 / 多人 / 对白时，降到 **1/20** | 同上 |
| 手部 | 失败率约 **60–70%** | 多来源 |
| **★ 单镜抽卡（公开实测）** | **一个普通片段平均生成 6–8 次**，镜头调度越复杂越多 | 《鲸鱼之歌》团队测算（百花奖最佳技术作品，2026-08 华尔街见闻） |
| 单镜预算（乐观值） | 每镜按 **2–4 次**；**但这只在前置准备充分时成立**（见下） | 行业通例 |
| **★ 全片生成成本（公开实测）** | 7 分钟短片，**AI 生成成本约 3000 元**（**仅生成，不含人力时间**） | 同上 |
| **★ 成本区间（两个独立来源）** | **¥200–450 / 分钟成片**（仅生成）：《鲸鱼之歌》≈**¥429/分**（3000 ÷ 7）·《山》≈**¥212/分**（20000 ÷ 94.5） | 百花奖团队 + B站《山》创作者自述 |
| **★ 工期区间（两个独立来源）** | **全职约 2 天 / 分钟成片**；业余口径 **≈5.7 天/分**（《山》：18 个月 ÷ 94.5 分，业余） | 同上 |
| 前期/制作耗时比 | 4 个月周期里，**剧本+人物+分镜 ≥ 40%**（剧本 1 个多月，制作约 2 个月） | 同上 |
| 后期占比 | 成片的 **60–70% 工作量在后期**（音效/配乐/配音/调色/抠像/文字/超分） | 案例汇总 |

> **★ 关键：抽卡次数不是模型能力的函数，是前置准备质量的函数。**
> 《鲸鱼之歌》原话："**前期准备得越完善，进入视频生成阶段后的'抽卡'次数也就越少**……图片越接近最终需要的构图、人物和质感，进入视频模型之后需要反复生成的次数就越少。"
> **所以"2–4 次"与"6–8 次"不矛盾**：前者是**准备充分后的乐观值**，后者是**公开实测的普通值**。
> **对外报预算时报 6–8 次、并说明"前置准备能把它压下来"**——**这正是一个可量化的、劝用户认真做前期的理由。**

> **推论**：如果剧本要求 30 个"人物演技镜头"，你需要的不是 30 次生成，而是 **180–240 次生成 + 大量后期**。

> **★ 可行性门的复核日期：2026-09-13**。
> 依据：Seedance 2.0 官方博客（2026-02-12）**自己承认**"多人口型匹配 / 多主体一致性 / 文字还原精度"仍是短板——**与本节表格完全吻合**。
> ⚠️ **但厂商在逐条修**（Seedance 2.5，2026-07-31，已加局部编辑、复杂指令控制、白模/绿幕参考）。
> **纪律：本节每条"做不好"，在使用前先想一次"这半年厂商修了没有"**。**拿着过期的约束自我限制，与误报同样是错**（会让用户觉得规则不可信）。

> **★ 一之一、长周期项目会被技术迭代"甩开"——无解，只能预防（2026-09-13 新加）**
>
> 上面讲的是"模型能力会变"。**还有一个更棘手的方向：你的项目周期本身会跨过技术代际。**
>
> 《山》（刘慈欣原著改编，单人 18 个月 / 94 分钟，B站 295 万播放）创作者原话：
> > "这18个月还经历了数轮AI视频技术的大升级，影片里现在还残留少部分**上上上上个时代AI技术残留，实在改不过来了**，整体不影响食用。"
>
> **含义**：技术升级**不是纯好事**——升级会改变模型的"手感"（光照、材质、人物脸型的默认倾向）。**同一部片前后用两代模型生成，断层无法通过重跑修复**（重跑 94 分钟的成本不现实）。
>
> **判据**：**项目周期 > 6 个月 → 必须做"风格冻结档"**：
> 1. 开工时把**锚点提示词 + 参考图 + 模型版本号**整份存档，命名带日期；
> 2. 排片时**按"代际"分批**——同一场戏尽量在同一代模型里做完，不要跨代切；
> 3. 对外沟通时**提前说明可能存在的代际断层**（它大概率不影响叙事，但观众看得出来）。
>
> **反例警告**：不要因为"新模型更好"就中途换模型重制前半段——**《山》的教训是"改不过来"，不是"不值得改"**，而是**成本上不可能改**。

## 一之二、★ 两层可行性门（2026-09-13 新加）

**上面整节讲的是"技术层"的门（手/走路/多人/口型/文字）。还有一层更致命、且绕不开的门——"类型层"。**

**问一句**：**我这个故事，是"爽点驱动"还是"表演驱动"？**

| | 爽点驱动 | 表演驱动 |
|---|---|---|
| 观众要的 | 悬念、反转、奇观、节奏 | 看这个人的内心怎么变化 |
| 例子 | 短剧、类型片、恐怖、动作 | 文艺片、人物片、情绪片 |
| AI 当前状态 | **已跨过**（2026-04 红果 AI 短剧首次登顶真人短剧热度榜） | **未跨过**（DiDi_OK："AI 生成的真人表演都只是'预制菜'"） |
| 处理 | 大胆做 | **要么改结构，要么用"身体事实"替代表演**（见 `character-depth.md` / `physical-feedback.md`） |

> **★ 为什么这一层比技术层更致命**：**技术层的坑能绕**（少拍手、切在动作峰值前）；
> **类型层的坑绕不过**——你没法用别的方式讲一个"必须靠表演才成立"的故事。
>
> **★ 与技术层的分工**：技术层管"**怎么拍**"，类型层管"**写什么**"。
> **判据**：**如果为了通过可行性门而需要改变人物动机或事件因果，说明你改错了东西**——那已经不是绕技术，是在换故事。

## 二、能做好 vs 做不好

| ✅ 反复验证能做好 | ❌ 反复证明做不好（必须绕开） |
|---|---|
| 自然风景、天气、微距 | **手与手指**（多指、融合、帧间数量变化） |
| 抽象 / 流体 / 粒子 / 墨 / 烟 | **全身走路 / 奔跑**（顺拐、重心错） |
| 科幻概念、宇宙、产品展示 | **口型**——**2026-09 起移出本列，降级为"有条件可用"（条件见下表）**；历史症状：p/b/m 不闭唇、快语速不同步 |
| 二次元 / 风格化动画 | **多人交互**（遮挡后重生成、手指错乱） |
| 固定机位、慢推、缓慢横移 / 环绕、航拍 | **剧烈动作 / 打斗 / 法术特效** |
| 单主体、单动作、慢速、无交互 | **液体与布料**（倒流、水下飘） |
| 纪录片式旁白 | **画面内文字 / Logo**（拼写漂移） |
| 静物、空镜、氛围镜头 | **快速运镜**（揭示区域被幻觉重建、背景扭曲） |

**绕开手段**：切掉手（构图 / 手插兜 / 背后）、避免全身行走（改坐 / 站 / 局部，或走决策树）、
用旁白替代对白、单主体 + 正反打分开生成、切在动作峰值前、文字全部后期覆盖、锁机位把动感交给剪辑。

### ★ 2026-09-13 复核：**口型已从"黑名单"降级为"有条件可用"**

**依据（平台能力已变）**：**Veo 3 / 3.1 的原生音频与口型是官方主推能力**；**可灵 3.0 Omni 的角色主体可绑定音色**（官方称 "the same face **and voice** across different works"）；**Seedance 2.0 / 2.5 支持生成有声视频**，官方示例**直接写台词与音效**。
→ **继续把它整类列进"必须绕开"，是拿旧能力当前提。**

**但它是"预算"问题，不是"能不能"问题**：

| 约束 | 数值（多源） |
|---|---|
| 单镜时长 | **4–8 秒** |
| **一句台词长度** | **8 秒以内 ≤15–20 词**（英文 ≈130–150 词/分钟；中文用本库算法：字数 ÷ 5 ≤ 镜时长） |
| 说话人数 | **一镜一个说话者**；对话**拆镜**（正反打） |
| **景别** | **特写对口型时机压力最大；中景 / 中近景更宽容** ← **这是"改结构"的第一手段** |
| 音频卫生 | 优先口型时**必须写"无配乐"** |

- **✅ 可做**：中景 / 中近景 · 单个说话者 · **一句短台词** · 写"无配乐" · 显式声明无字幕
- **❌ 高风险**：特写长台词 · 多人对话 · 一镜多句 · 台词超出时长预算
- **止损线**：高风险条目命中停手规则（→ `qa-failure-codes.md` 第三节：连续两批同一错误无改善即停）→ 退回旁白 / 拆正反打

> **与本节原则一致**：可行性门的本意是"**改结构，不是删动作**"（🔴 三条禁令第 2 条）。
> **口型同样应"换景别 → 缩短台词 → 拆镜"，而不是把它整类删掉。**
> 写法（四条配套指令 / 对白公式）见 `sound-craft.md` §一 §二。

### 2.1 ★ 兜不住时：把模型缺陷写成剧情（"失败即内容"）

当手 / 走路 / 细节**绕不开**时，不要让它"正常地"做——**把它写成角色的一部分**：

| 缺陷 | 写成 |
|---|---|
| 手抖、手部结构不稳 | **颤抖的手** / 戴手套 / 握拳 / 手插口袋 / 被前景遮挡 |
| 拿不住东西 | 东西**滑落** / 掉落 |
| 按不准 | **连按三次没按到** |
| 走路不稳 | 踉跄 / 扶墙走 / 只给上半身 |

> **原则**：不要让角色"正常地"做模型做不好的事——**让它做不好本身成为内容**。
> 这类镜头往往是全片最出彩的地方，比一味规避多一条路。

**★ 三级升格（2026-09-13 新加，来自 B站《时差》）**：上表停在**身体缺陷**层（手/腿）。还有两层更高的：

| 级 | 缺陷类型 | 操作 | 例 |
|---|---|---|---|
| 一 | **身体部件** | 把缺陷写成动作特征（上表） | 手抖 → 颤抖的手 |
| 二 | **运动/物理** | 把缺陷写成**剧情事实** | 走路不稳 → 他是病人在康复 |
| 三 | **★ 介质/信号** | 把缺陷写成**母题本身**，让它承载情感 | 视频**掉帧** → **"亲人正在掉帧"＝告别** |

《时差》（B站 AI 创作大赛，137 万播放，题材"亲人影像开始掉帧"）走的是第三级：
**"掉帧"本是视频生成的典型故障，创作者把它升格为叙事核心——亲人的影像逐渐掉帧，就是死亡的视觉隐喻。**

> **判据**：走到第三级的标志是——**把"这个技术缺陷"从提示词里删掉，故事就不成立了**。
> 如果删掉缺陷故事还在 → 你只是"绕开"了它，没"化"它。
> ⚠️ **第三级可遇不可求，不要硬追**：它要求缺陷与命题天然同构（掉帧↔消失）。**硬凑会变成"技术炫技盖过叙事"**——那正是 `## 三、"AI 短片感"` 要查的头号病。

### 2.2 ★ 人群 / 规模的分层写法（绕不开多人时）

**不要写"一千人"。** 写**分层**：

```
前景：1 个清晰主体（唯一有细节的人）
中段：密集阵型（一片有节奏的暗影）
远景：雾中溶解的剪影（无细节，逐渐消融）
```

**人群出现克隆体时的正解不是加禁令，是加参考**：给两个**剪影类别**参考（如"重甲 / 轻斥候"），让模型有两个不同的模板可分配，而不是复制同一个。

### 2.3 ★ 主角不是人：无人脸题材的改造法

写剧本前多问一句：**这个故事能不能把叙事主体换掉？**

**可替换的主体**：地方 / 物件 / 自然现象 / 事件。

人若必须出现，按**降级序列**往下退（越往下越安全）：

```
痕迹（一杯没喝完的茶）→ 剪影 → 背影 → 局部（手 / 脚 / 后颈）
→ 无口型的正面 → 手部局部 → ❌ 正脸说话（最危险）
```

**8 类替代镜头**（用来填满没有人的画面）：
① 空镜与环境；② 物件的状态变化；③ 手部局部动作；④ 剪影与背影；
⑤ 反光 / 影子 / 倒影；⑥ 屏摄与监控画面；⑦ 数据 / 文字 / 图示；⑧ 纯氛围镜头。

> 三个真实选题（维苏威、威尼斯地基、吉萨）**全都不是人物驱动**——这是绕开口型与多人交互最彻底的解法。

### 2.4 ★ 打斗 / 剧烈动作绕不开时：受控迭代路径

**默认口径不变**：打斗是最后才碰的题材（见第四节⑥）。

**但若剧情必须打斗**，不要裸写上——走这条受控路径：

```
① 资产板：场景给正反两个机位（→ asset-consistency.md 3.2）
② 测量化分镜：规模与变形写"起点→路径→定时→终点"，不写程度副词（→ physical-feedback.md 九·补）
③ 每镜一个信息职能：静音读机位计划，信息重复就是装饰镜头（→ `sequence-craft.md` 五）
④ 按层诊断：先比姿态 → 再看接触点间距 → 最后查加速时刻与断裂材料
⑤ 按锁修改：只改出问题的那一把锁，不重写整条
```

**预算重算**：难镜按**每镜 3–5 次 × 3 倍素材量（合计 9–15 次生成/镜）**，不要按乐观值 2–4 次估；3 倍素材量指**有效素材比**（可用率 30–40% → 素材量 = 镜头数 × 3），已含在上式乘积内，不另乘。

## 二之三、★★ "你靠什么赢"决定策略：攻坚 vs 避短（2026-09-13 新加）

**两部同期获奖、方法完全相反的片子**，说明策略必须由"你的强项在哪"决定，而不是照搬别人的流程：

| | **DiDi_OK《牌子》** | **邵凡（惊悚/悬疑向）** |
|---|---|---|
| **靠什么赢** | **奇观 / 视觉密度** | **叙事结构 / 类型张力** |
| **策略** | **攻坚**——死磕那些 AI 做不好的画面，抽卡上千次换那 10% | **避短**——选一个"AI 的短板恰好是加分项"的类型 |
| **自述** | "他想做的特效和美术风格，**有 90% 都是 AI 实现不了的**"，曾对朋友说"我这辈子都不想动 AI 了" | 选惊悚片，让 AI 特有的"非人感 / 不稳定感"变成氛围的一部分 |
| **代价** | 极高抽卡量、极高挫败感、不可复制 | 需要真的懂类型片的叙事结构 |

**★ 判据（三步）**：
1. **这部片靠什么赢？** 一句话说清（奇观 / 叙事 / 情绪 / 概念 / 表演）
2. **AI 在这件事上是强项还是弱项？**
   - 强项 → **顺势做**（不折腾）
   - 弱项，但"赢了就值" → **攻坚**（预算按 ≥10 倍重算，且要接受可能失败）
   - 弱项，且绕得开 → **避短**（换类型 / 换讲法）
   - **弱项，绕不开，又攻不动 → 换故事**（回到"类型层可行性门"）
3. **两条路混着走是最差的**——既想避短又想要奇观，结果是两头不到岸

> **★ 反例警告**：看到《牌子》拿 100 万就去学"抽卡 1000 次"，是**归因错误**——
> **它的成功来自"他知道自己要什么"，而不是"他抽得多"。** 抽卡只是手段，**先有判断，抽卡才有意义**。
> 同理，看到邵凡"不画分镜"就跟着不画，也是**漏掉了前提**（他脑内有等价的心智模型）。

## 三、"AI 短片感"到底是什么（出片后逐条查）

观众骂"AI 味"时，实际骂的是这 9 件具体的事：

1. **手部变形帧**——最经典的标记。
2. **跨剪辑背景不连续**：每镜独立生成，云 / 影 / 光的位置跳变。
3. **"多云下午"式打光**：所有场景同一种柔光，没有硬影。
4. **过度饱和**：红 / 青 / 黄偏高，像游戏调色。
5. **过度平滑、没有微抖**：运镜像飞行模拟器，缺手持微颤。
6. **口型不同步**；眨眼机械规律（每 3–4 秒一次）。
7. **镜面 / 倒影错误**；画面里的文字变成乱码。
8. **时序"微停顿"**：分段生成导致动作像"重启"。
9. **一集一张脸**、微表情缺失、配音机械。

→ 这 9 条就是**验收清单**：成片后逐条对照，命中任何一条都要修。

## 四、题材选择的优先序（从最稳到最险）

```
① 抽象 / 自然 / 概念 + 强旁白      ← 最稳，获奖片集中在这里
② 风格化动画（二次元 / 美漫）      ← 风格遮蔽了写实的失败
③ 单主体情境（一个人在空间里做一件事，慢动作，锁机位）
④ 产品 / 静物 / 食物              ← 商业最成熟
⑤ 对白戏（单人、正脸、短句）
⑥ 多人交互 / 动作戏 / 长镜头调度    ← 最后才碰；需要参考视频 + 后期兜底
```

**写剧本前的可行性三问**：

1. 这个故事里**有多少镜头必须出现"手 / 走路 / 多人 / 剧烈动作 / 画面文字"**？超过 3 个，就要改结构。
2. 这个题材**能不能用旁白承担叙事**？（能 → 风险立刻下降一个量级）
3. 预算（生成次数）够不够支撑 **3 倍素材量 + 60% 后期**？

---

## 五、结构策略：为 AI 而写的剧本

- **强旁白 + 意象蒙太奇**：叙事交给声音，画面只做氛围与隐喻。这是《Total Pixel Space》《I Pray for Love》这类获奖片的共同打法。
- **回避"演技戏"**：把情绪放在**物件、环境、光与声音**上，而不是脸与身体。
- **单主体优先**：需要两个角色时，用**正反打分开生成**，不要同框。
- **镜头短**：真实有效素材只有 1–2 秒，剧本要**按短镜头写**，节奏靠剪辑而不是靠长镜头。
- **把"绕不过去"的镜头提前标出来**：走路 / 手 / 多人，标了就预留参考视频与重抽预算。

## 六、真实案例（工具链 + 人机分界）

| 作品 | 工具链 | AI 做什么 / 人工补什么 |
|---|---|---|
| **Dreams of Violets**（75 分钟，$2000，首部进大影展官方单元的纯 AI 长片） | Kling + Gemini + Nano Banana | AI：全部画面与人脸；**人工：剧本、调度、终剪、声音、配乐** |
| **Total Pixel Space**（Runway AIFF 2025 大奖） | Midjourney + Runway Gen-3 + ElevenLabs + Resolve | AI：图与动画；**人工：剧本、剪辑**（混合型，非纯 AI） |
| **Get Me Out**（AIFF 金奖） | Luma + Runway V2V + ComfyUI | **真人实拍为主**，AI 做环境重建与转绘 |
| **鬼饮食**（242 个 AI 镜头，3 个月） | Midjourney + 可灵 + Pika + PixVerse | AI 只出画面；**剧本/剪辑/音效全人工**；有效镜头仅 1–2 秒 |
| **致亲爱的自己**（威尼斯 AI 短片节第一） | ComfyUI + ControlNet + AnimateDiff + LoRA + C4D/AE + 手绘 | AI 训 LoRA + 转绘；**2D/3D 与手绘打底** |
| **Croquette Crew**（戛纳 AI Film Awards 最佳 MV） | ElevenLabs + Suno + Runway + Kaiber + Pika + Firefly | 宣称全 AI 流程，评论两极 |

**共同点**：**没有一部是"输入提示词 → 输出成片"**。人始终在剧本、调度、剪辑、声音这四件事上占据主导。

## 七、电影节与平台的 AI 规则（要用 AI 片子投递就要知道；核实于 2026-09-13）

- **奥斯卡（98/99 届；第 98 届规则核实于 2026-09-13，第 99 届适用性待核）**：生成式 AI "既不助也不害"提名，核心看**人类创作的比重**；硬限制——**剧本须人类创作、表演须真人且同意**。
- **戛纳（2026-04 起）**：**剧本、主体画面或主要表演以生成式 AI 为基础者，不得进入官方竞赛 / 金棕榈**（电影市场另有自愿性三级披露标准：无 AI / 辅助 / 生成式）。
- **圣丹斯**：申请表新增**可选**的生成式 AI 披露项，不作为筛选器。
- **AI 专属电影节**（如 Runway AIFF）：只看"是否含 AI 视频"，**无占比门槛**，评分同时看创意与叙事。
- **平台标注**：抖音 / B站 / 快手 / TikTok / YouTube / Meta 均已推行 AI 生成内容披露或自动标注，中国已施行《人工智能生成合成内容标识办法》（2025-09-01 施行）。**交付时就要准备标识。**

## 八、一句话总结

**当前能稳定拿奖 / 过审的 AI 短片 = 抽象或强旁白题材 + 图生视频 + 大量人工剪辑后期。**
凡是"多人、对话、行走、剧烈动作、画面文字"密集的剧本，都是在跟模型的统计缺陷硬刚——
不是不能做，是**要按 3 倍素材量、60% 后期、逐镜重抽来报价**。
