# 跨片段接口：**一条片是拼出来的**（拼接点 · 首尾帧 · 动作匹配 · 音频桥）

> **何时读**：一镜一镜生成完之后，**要把它们拼成一条片时**；或**写多镜之前就要预留接口时**。
> **读完回哪**：回 `shot-craft-part2.md`（第 12 块【过渡压力】）· `transition-library.md`（转场类型）· `post-production.md`（拼接与重编码）。
> **★ 本册补的是全库真空**：2026-09-19 全库扫描——`跨片段` / `片段拼接` / `接口规范` **各 0 命中**，`拼接点` 仅 1 册。
> **为什么必须有这一册**：**AIGC 的一条片不是拍出来的，是十几段生成件拼出来的**——
> **每段单独看都合格，拼起来却"跳"**，是这一层最常见的失败；而**它只能在写提示词时预留，事后补不了**。

---

## §1 ★ 一句话地基

> **每一镜的结尾，都是下一镜的入场券。**
> **镜与镜之间要有三样东西对得上：画面（视觉接口）· 动作（动势接口）· 声音（听觉接口）。**
> **三样里只对两样，拼接点就会"跳"。**

**★ 判据一句话**：**"把这两段直接接上，观众会不会觉得'刚才发生了什么？'"**——会，就是接口没留。

---

## §2 ★ 三个接口，各写在哪一块

| 接口 | 写在哪一块 | 要写什么 |
|---|---|---|
| **视觉接口** | `【进入下一镜的过渡压力】` | **切法与匹配点**（相似转场 / 动作转场 / 声音转场） |
| **动势接口** | `【时间线】` 的**定格相** | **结尾停在"势能未尽"的位置**，不是停稳（停稳＝下一镜没法接） |
| **听觉接口** | `【声音】` | **哪一层声音跨过拼接点继续**（＝音频桥，见 `sound-prompt-craft.md` §5） |

**★ 一条纪律**：**这四处是与下一镜共用的**（本镜的出口＝下一镜的入口）——
**定稿前要"两两对读"**：把镜 N 的结尾与镜 N+1 的开头放在一起读一遍。

---

## §3 ★ 定格相：**停在"势能"上，不停在"结果"上**（最容易被忽略的一条）

| 停在结果上（✗） | 停在势能上（✓） |
|---|---|
| 他坐下了 | 他**正在坐下、还没落到底** |
| 门关上了 | 门**正在合、还差一道缝** |
| 他转身走了 | 他**刚转过去半身** |
| 杯放稳了 | 杯**刚触到桌面、还在晃** |

**★ 为什么**：**"结果"是终点，"势能"是接口**。下一镜要接的是**动作的后续**，不是**动作的墓碑**。
**★ 唯一的例外**：**这一镜就是全片结尾**——那才允许"停稳"（且要留白，见 `block-spec.md`）。

---

## §4 ★ 拼接点的四查（**逐点过，不要跳**）

拼之前，对**每一个**拼接点问四句：

```text
① 画幅与色彩：两段的分辨率 / 画幅 / 调色方向 / 响度是否同值？
② 动作：上一段的"势能"与下一段的"起始"，是同一个动作的延续吗？
③ 声音：跨过这一点的那一层（环境 / 音乐）有没有断？
④ 空间：轴线没跳？景别落差是"有意的"还是"没想过"的？
```

**★ 判据**：**四句里任何一句答"不知道" → 回到写稿阶段补那一句**（事后补不了）。

---

## §5 ★ 重编码：**直接拼会翻车**（工程坑，实测）

```bash
# ✗ 直接流拷贝拼接：常出现绿屏 / 冻结 / 时基错乱（不同次生成的时间基不一致）
ffmpeg -f concat -i list.txt -c copy out.mp4

# ✓ 统一重编码（稳，代价是时间）
ffmpeg -f concat -safe 0 -i list.txt -vf "fps=24,format=yuv420p" \
  -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k out.mp4
```
**★ 三条纪律**：
1. **统一帧率与像素格式**（`fps=24` / `yuv420p`）——不同模型出的片段帧率与色度采样会不一样；
2. **统一画幅**（有 `21:9` 与 `2.39:1` 混用时，**先裁到同一个**，不要留黑边凑）；
3. **统一响度**在拼接**之后**做（`mix-loudness.md` §1）——**逐段做会让段落间响度起伏**。

---

## §6 ★ 多段共用块的复用纪律（与"锚点逐字"同一条）

**同一部片里，三块全片通用（`【后期特效】`/`【统一提质层】`/`【风险移除】`）必须逐字复用**——
**这不是省事，是接口**：**两块之间只要有任何一个词不同，模型就会给出两套成像**（`asset-consistency-part2.md` §七 同规）。

**★ 声音层同理**：**环境签名逐字复制**（`sound-prompt-craft.md` §4）——**它是"这两段在同一个世界"的唯一证据**。

---

## §7 ★ 分段镜是特例：**段内切换不是"跨片段"**

**`segmented-shot.md` 的分段镜**是**一条生成里的段内切换**——**段的接口写在段与段之间**（`【全局约束】` 写死"恰好 N 段 N-1 切换点"），
**它不走本册的四个接口**（没有跨生成、没有重编码、没有响度统一）。
**★ 判据**：**"这两段是不是两次生成的？"** 是 → 走本册；不是 → 走 `segmented-shot.md`。
