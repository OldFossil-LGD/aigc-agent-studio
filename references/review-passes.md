# 生成结果的验收：七遍审片法

> **何时读**：生成结果出来了、要判断这一条能不能用时。**读完回哪**：过了 → 进下一镜；没过 → 回 `shot-craft.md` 改提示词重出。

**这份只管一件事：单条生成结果怎么结构化过一遍，判断它能不能用。**

**验收必须分三层**：结构/参数复刻可机器对账；像素技术指标只证明解码、帧、尺寸、时长等技术层；动作、身份、表演、空间与整体审美必须人工或多模态判定，技术通过不等于质量通过。
多条候选之间怎么挑 → `post-production.md` 第一节（选片三桶 + 量化指标）。两者是不同轴，都要走。

来源：Higgsfield Academy《How to evaluate AI filmmaking demos》（2026-09-11 学完 16 门课时精读）。

---

## 一、总流程（不可跳步）

```
第 1 遍   不停，整条看完（裸看）
第 2 遍起 一次只带一个问题重看（一次只审一类证据）
每一条笔记  "我看见 ___，所以我会 ___"（前半证据 / 后半决定）
```

**一次只审一类证据。合计＝七遍：1 遍裸看 + 6 个专项 pass——标题的「七遍」就是这个算式，pass 数仍是 6。** 相机、脸、身体、光、分辨率一起看 = 每一类都看不深。

**笔记格式是硬性的**：

| 不合格 | 合格 |
|---|---|
| 相机很棒 / 舞蹈很假 / 画面很软 | 怪物在切点之间保持了它的疤痕 |
| 不够电影感 | 环绕保持了一条连续的相机路径 |
| 有点怪 | 两条手臂在快拍上穿模了 |

形容词不给下一个环节任何信息。**"我看见 ___，所以我会 ___"**——前半是证据，后半是决定（重抽 / 改提示词 / 拆镜 / 后期修 / 止损）。

> 查失败码之前，先写下这两半。→ `qa-failure-codes.md`；**查到码后写进同一条笔记的第三段：证据 → 决定 → 失败码**——码用于回 `shot-craft.md` 时定位改法，不回写笔记就无法聚类统计反复出现的问题。

## 二、六个 pass（选一个，不要一次全审）

| Pass | 审什么 |
|---|---|
| **1 相机轨迹** | 位置、尺度、方向，穿过**最难的那段运动** |
| **2 剪辑连续性** | 跟住**一个**表演者 / **一个**服装细节 / **一个**道具，穿过每一个切点 |
| **3 面部表演** | 嘴、下颌、眼、喉、时序是否**一起**动 |
| **4 身体编舞** | 四肢、姿态、重心、反射，穿过**重复的**动作 |
| **5 世界连贯** | 地标、透视、光、背景运动是否逻辑连通 |
| **6 交付约束** | 在**目标**分辨率、裁切、屏幕、时长下判断 |

### Pass 1 · 相机轨迹

- 用**物理动词**描述：推 / 升 / 降 / 环绕 / 甩 / 落定。
  > 如果最好的描述是"镜头变了"，回去重看那个切点。
- **同时**跟踪两个细节：主体上一个（疤痕、袖子）+ 场景上一个（地平线、一个光源）。两者应随视点**一致地**移动。
- **每个切点暂停**问：相机或主体接下来必须做什么？切点常常藏住问题。
  > 一个切点证明不了什么；**重复出现的模式**才有意义。
- ⚠️ **长镜头不自动更好**。问题在于这条片是**展示了**运动，还是**让剪辑去暗示**运动。

### Pass 2 · 剪辑连续性

- 选**一个**特征（墨镜 / 衬衫 / 脸 / 一个重复手势），看它是否穿过换场地、换造型、换构图存活。
- **真镜头 vs 滤镜**：
  - ✅ 真：脸、手、布景**按距镜头远近不同程度地畸变**（深度响应）；
  - ❌ 假：只有一圈弯曲边框，主体仍然比较平。
- 查时序：嘴型、手臂、高光、切点是否属于**同一个拍**。

### Pass 3 · 面部表演（本 pass 先静音看一遍）

> **写之前的表演方法（延迟 / 半途修正 / 三区同拍 / 对手戏）→ `performance-craft.md`。** 这一节只管**怎么验**。两册分工：craft＝怎么演，`performance-vocabulary.md`＝怎么打分 / 判活气（两册并存，入口不同）。
> **交付前另有两个低成本判据**：① 暂停任意一帧问**"他的眼睛像活人的吗？"**（→ `performance-vocabulary.md` 第二节）；② 用表演量表 0–5 自评，**主角镜头必须 ≥4**（→ 同文件第五节）。

可信的表情在**整张脸和颈部**，不只是嘴。三个检查点：

1. **嘴与下颌** —— 下半脸作为结构整体在动，不是只有嘴唇动；
2. **颈与喉** —— 可见的紧张支撑了表情暗示的用力；
3. **眼与眉** —— 上半脸投入同一个拍，不是一张中性面具。

再看**进出表情的运动**：准备 → 峰值用力 → 释放。整段绷着一张脸，不如随节拍变化来得可信。

> ⚠️ **脸太小看不清时，标记为"不可判定"，不许判过也不许判挂。**

### Pass 4 · 身体编舞

一个动作查三个时刻：

- **Entry 入手**：是否从合理的平衡与关节位置起手？
- **Contact 接触**：最快的交叠处，四肢是否保持分离（不穿模）？
- **Recovery 收势**：身体是自然继续，还是**重置**了？

**同时查地板反射**——它是动作的第二次渲染，身体与反射不一致是有用的证据。
切点若正好落在 contact 上，**重播前后各一拍**——那里最可能藏着重置。

### Pass 5 · 世界连贯

- 保持一张粗略地图，看层与层是否逻辑连通。
- 高速下看纵深：**不要按背景物体数量判断**，查近 / 中 / 远三层是否按一个相机能产生的方式改变尺度。
- 冻结**最忙的那一帧**，问普通问题：还是同一个人吗？地平面在哪？运动往哪个方向？什么照亮了脸？
  > 一个超现实的前提**不能**豁免这条镜头回答基本空间问题的义务。
- ★ **复杂世界用简单锚点：一个人、一个物体、一个运动、一个光源。**
- **状态/因果连贯也归这一遍审**：setup → 变化 → 场景损伤 → 回归，四段连通、**后果必须保留**（打碎的玻璃下一镜复原＝挂）——先列"保持不变的东西"。

### Pass 6 · 交付约束

在**目标**分辨率、裁切、屏幕、时长下判断，不是在生成尺寸下判断。这一遍单独跑，不与其他 pass 混。

## 三、判据表（过 / 不过 / 备注）

| 维度 | 过 | 不过 | 备注 |
|---|---|---|---|
| 相机轨迹 | 能用物理动词说出完整路径；主体与场景细节同步移动 | 最好的描述是"镜头变了"；切点反复落在难点上 | 长镜头 ≠ 更好 |
| 剪辑连续性 | 一个细节穿过所有切点不变 | 切点后细节变了或消失 | 跟**一个**，不跟全部 |
| 面部表演 | 嘴+下颌+颈喉+眼眉在同一拍上一起动；有准备→峰值→释放 | 只有嘴唇动；面具脸；整段绷着不变 | 先静音；脸太小 → 不可判定 |
| 编舞 | Entry 合理 / Contact 不穿模 / Recovery 不重置；反射与身体一致；接触帧能解释位置与重量 | 穿模、姿态重置、切点落在 contact；接触帧失去物理关系 | 重播 contact 前后各一拍；**从接触帧开始看** |
| 世界连贯 | 地标/透视/光/背景运动连通；复杂世界有四个简单锚点 | 人、地平面、运动方向、光源不能同时回答 | 冻结最忙的一帧 |
| 状态转换（挂 Pass 5 审） | setup → 变化 → 场景损伤 → 回归四段连通；后果保留 | 状态之间不连通，后果被抹掉 | 先列"保持不变的东西" |
| 交付约束 | 在目标分辨率、裁切、屏幕、时长下成立 | 只在生成尺寸下成立 | 单独一个 pass |

---

## 四、两条纪律

1. **证据不足 = 不可判定，不得判过。** 脸太小、接触点被遮、运动被切点跳过 → 标记 inconclusive。默认倾向"看着还行就过"是漏检的主因。
2. **不许在 pass 里混入别的问题。** 审手持相机时同时纠结口型 → 口型**另记**，这一 pass 只问一件事。

## 五、与静态判据的分工

`studio-workflow.md` 第三步的 done 判据分两类，**动态类不能省**：

- **静态**：构图、身份、几何、时间戳累加、声音行 —— 一次看画面就能查；
- **动态**：相机轨迹能否用物理动词说出、接触点是否解释位置与重量、编舞 Entry/Contact/Recovery、脸部三区是否同拍 —— 必须按上面的 pass 跑一遍。

> 反复出现的失败模式是"**照片过关，视频测试淘汰**"：静态都好看，一动就崩。所以静态判据过了不等于能交付。
