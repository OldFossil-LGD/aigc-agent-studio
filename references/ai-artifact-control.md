# AI 视频退化控制（三条第一性原理 + 修复阶梯）

> **何时读**：开写前规划脆弱元素、生成崩坏时查原理。**读完回哪**：出片不合格时转 `qa-failure-codes.md`。

> 来源：Hailuo/MiniMax 官方《Faces melting mid-clip? Here's the fix ladder》《Prompting for Photometric Film Emulation》、Scenario 官方故障排查文档、Versely 退化机制分析、ReelMind 时域不稳定研究。提炼为通用对策。

## 一、三条第一性原理（决定一切）

现代视频模型是**去噪**生成：从随机噪声开始，逐步细化到符合提示词的视频——工作对象不是像素，而是视频的压缩数学摘要（latent），靠"注意力"跨时空保持帧间一致。三条推论：

| 原理 | 推论 | 后果 |
|---|---|---|
| **1 细节是从压缩里"重建"的，不是保留的** | 小的东西被近似 | 手指、文字、logo、小道具必崩 → **把脆弱的东西拍大** |
| **2 帧间一致性是学出来的注意力，不是追踪对象** | 模型不"知道"杯子还是那个杯子 | 脸/物随时间漂移；遮挡后重现的物体会被重新发明 |
| **3 运动是统计模式，不是物理模拟** | 常见动作合理，长尾动作必错 | 漂浮物、不可能的液体、复杂交互会崩 |

**所有退化都是这三条的变装。**

## 二、退化 → 原因 → 对策表

| 症状 | 原因 | 对策 |
|---|---|---|
| 手指/肢体畸形、缠绕 | 手小、结构复杂、训练数据多样 | 拉宽景别减少手部特写；减少手物交互；每轮批量多出候选 |
| 文字/logo 乱码 | 小字处在压缩的粗糙区 | **让字在画面里足够大**；或后期覆盖真文字（我们一贯做法：中文字迹不要求 AI 生成） |
| 脸/身份漂移 | 时域注意力随时长衰减，脸每帧被重新生成 | 更短的片段；图生视频锚定；加身份句（见第四节） |
| 物体出现/消失/融合 | 遮挡破坏连续性，重现时被重新发明 | 简化场景；避免交叉重叠的元素；不要让物体进出画面 |
| 闪烁与纹理"沸腾" | 去噪每帧对细纹理的解析略有不同 | 提示稳定的简单表面；后期升频/时域平滑。**⚠️ 先分两类**（→ `carrier-artifacts.md` §三·★）：**细纹理沸腾**（位置漂移、结构变形）→ 修；**颗粒帧间重排**（原地抖、不漂移）**必须留**——它是"这是拍的"的第一眼证据 |
| 运镜时背景扭曲 | 模型实时幻觉画外新露出的区域 | **慢而简单的运镜**；重要内容锁死机位 |
| 物理失败（漂浮/液体错） | 学到的规律，不是模拟 | 只提示常见交互；在崩坏前切 |
| 调色/亮度跳变 | 帧间白平衡或曝光漂移 | 色彩稳定滤镜；统一色温描述；颗粒覆盖统一纹理 |

## 三、五级修复阶梯（从最便宜到最强 · 脸部融化专用）

```
1 安抚运动
   删掉所有速度词。"狂舞、快速旋转、甩头"是融化配方；
   "轻摆、点头、微笑"不是。每 6 秒只安排一个主体动作。
   开头写 [Static shot]——别让摄影机额外加运动。
2 从照片开始，不从文字开始
   改用图生视频，干净的人像做首帧。
   这是单次提升最大的一步：脸变成模型持续回归的像素，
   而不是每帧从文字重新想象。
3 让脸大且在画面内
   腰部以上或更近；绝不让脸离开画面——
   出去再回来会变成"表亲"。需要全转身就切开分镜。
4 在文字里钉住身份
   加一句"他的脸全程保持完全相同的特征"；
   跨镜角色用统一的角色参考图。
5 重 roll 是工作流的一部分
   生成是抽样，不是打印。前四步做完仍然漂，重抽就是正确动作。
```

## 四、四条铁律（比任何技巧都重要）

1. **一镜一主体一动作。** 复杂度是敌人——"厨师颠三个锅同时浇汁"几乎必然失败；"厨师在摆盘，俯拍"稳过。
2. **把脆弱的东西拍大。** 脸、产品、文字占据画面大比例——这是 AI 视频里最可靠的单条规则（大细节能熬过压缩，小细节被近似）。
3. **安抚摄影机。** 快摇、快环绕迫使模型实时发明画外内容 → 背景扭曲。慢推或锁死，动感留给剪辑。
4. **画面瑕疵不要写否定句。** "不要多余的手指"往往反而把手指注进引导 —— 改为**移除风险**：`手插在口袋里`、`双手捧着杯子`、`让手离开画面`。
   ⚠️ **但这条只管瑕疵**——**同族动作相反，必须写排除**（写了推镜就排除拉/摇/移/环绕/变焦）；**内容类别否定**（"不要像游戏"）两条路都走不通，只能改写成"该拍什么"。**三类方向各异**，见 `quality-layer.md` 第四节 1a / 1b / 1c。

## 五、超出能力的镜头怎么拍（设计绕过）

专业做法是像实拍片一样躲开限制：

- 快速动作 → 用剪影、背影、模糊
- 转身/剧烈动作 → 切到反应镜（别人看着他转）
- 手部精细动作 → 只拍手的影子或动作结果
- 复杂物理 → 在崩坏发生前切走
- 大场面混乱 → 拆成多个简单的单主体镜头

**这不是妥协，这是分镜思维——实拍片也在这么做。**

### 五·补 手的"退路写法"分层（2026-09-11 补）

手是失败率最高的部位（60–70%）。绕开是**首选**，但剧情确实要求手出镜（拿、握、递、写）时，按**四级退路**从上到下退，**一级能成就不要退到下一级**：

| 级 | 做法 | 提示词怎么写 | 代价 |
|---|---|---|---|
| **① 给手一个明确任务 + 固定接触面** | 手**始终碰着**一个东西（杯柄 / 门把 / 绳头），接触点清楚 | "右手握住杯柄，四指环住杯身、拇指压在上沿；手不离开杯柄" | 最低——成功率显著提高 |
| **② 把手指藏起来** | 手出现但**不露五指**——握拳、插袋、戴手套、被袖子遮、手里被东西占满 | "双手插在工装口袋里""戴着手套扶着栏杆" | 低 |
| **③ 用角度避让** | 手在**侧面 / 背面 / 画外**，只露出手腕与手背轮廓 | "手的动作发生在画面右侧画外，观众只看见小臂" | 中——损失一点表演 |
| **④ 只给影子或结果** | 拍**手的影子**投在墙上，或**只拍动作结果**（东西已经放好了） | "墙上晃过一只手放东西的影子""桌上多了一杯茶" | 高——放弃手的表演 |

**为什么"解剖参考式细写"不放在①之前**：写"四指环住杯身、拇指压在上沿"这类**解剖级句子**确实能提高成功率，但它属于**①的内部写法**，不是独立一级——**没有接触面的纯解剖描写仍然会崩**。所以顺序是：**先给接触面 → 再补解剖细节**。

**三条纪律**：

1. **一镜只给手一个动作**（拿 OR 放 OR 递，不能又拿又转又放下）。
2. **接触面必须是名词**（杯柄、绳头、门把），不能写"手在空气中比划"。
3. **连续两批手部仍崩 → 直接退到②或③**，不要在①上继续加字（加字是在喂更多出错机会）。

## 五·补 成片前的 AI 味自检（九条 · 检测清单反过来用）

> 这九条本来是"**怎么辨认一段视频是不是 AI 做的**"的检测清单。**反过来用，它就是"必须写进去的东西"**——
> 每一条都是观众在无意识里用来判真假的依据。**辨别得越准的点，越是我们必须写明的点。**
> 与 `tone-realism.md` 的六层物理是两套口径：那份讲"物理怎么发生"，这份讲"破绽会在哪里被看见"。

| # | 破绽点 | 观众凭什么看出来 | 提示词里怎么写 |
|---|---|---|---|
| **1** | **眨眼节律** | 真人每 **2–10 秒**自发性眨眼一次，且**眨眼时眼周肌肉联动**（眼角收紧、眉毛微动）；AI 的眨眼是"眼皮单独动" | `他眨眼间隔不规律，大约三到八秒一次，思考停顿时更久；眨的时候眼角的皮肤一起收紧`（**不写固定节律**——钟表式眨眼本身就是 AI 味） |
| **2** | **单根细结构** | 真人的头发**一根一根各自被吹动、各自反光**；AI 的头发是一整块在动，或者干脆不动 | `有几缕碎发各自被风吹起，一根一根反着光` |
| **3** | **光源个数与阴影方向** | 数一下画面里的光源个数，与阴影方向的个数**对不上**就是假的。**这条后期补不回来** | 按 `lighting-philosophy.md` 第五节清点：`画面里只有[一处]光源，所有影子朝[同一方向]倒` |
| **4** | **世界自洽（30 秒检查）** | 季节 / 天气 / 服装 / 建筑 / 背景活动要互相印证——"夏天的游行里全是枯树"就露了 | `深冬，所有人都穿着厚外套，树上没有叶子，呼出的气是白的` |
| **5** | **音画同步阈值** | 人耳能察觉 **100 毫秒**以上的不同步（24fps 下约 2.5 帧） | 对口型镜头逐帧验，容差见 `sound-craft.md` 第二节的 ±2 帧 |
| **6** | **呼吸的位置** | 真人的吸气出现在**短语之间**；AI 常把呼吸塞在词的中间 | 生成对白时把吸气单独切出来、放在标点处（`sound-craft.md` 第八节第 3 步） |
| **7** | **室外声音的干净度** | 室外的人声必须带环境底噪与距离感；"录音棚般干净"反而不像真的 | 见 `sound-craft.md` 第七节第 2、4 条 |
| **8** | **"太干净"本身** | 真实相机有像差、真实素材有噪声。一个本该在混乱现场的人却像杂志封面，就是红旗 | 走 `camera-package-library.md` 的低端档 **+ 调制层**——**"它最干净、最现代"不构成选它的理由** |
| **9** | **AI 的审美倾向** | 高饱和 + 贴上去的镜头眩光 + 太均匀的照明 + 像图库照片活过来的脸——这四样是模型的默认偏好 | 这四条由本册收尾清单「四禁」与运动质量禁令在拦，**逐条确认没踩** |

**两条配套纪律**：

- **第 1–4 条必须在提示词里写出来，不能指望后期**——尤其是第 3 条（光源与阴影的一致性），后期无法修正。
- **第 5–7 条属于声音层**，在分镜阶段就要规划，交付前用耳机逐句听一遍。

## 五·补二 · **脏点专项**（四种机制 · 分诊表 · 分层对策 · 可验证判据）

> **来自用户实际反馈**：**"AI 模型有脏点问题——不仅是视频模型，图片模型也一样。"**
> **★ 先说最要紧的一句**：**"脏"不是一种病，是四种。混着治＝用错药。**
> （"脏点 / 污点 / 网格纹 / 重复纹理"在全库此前**零命中**——本节是补这个缺口。）

### 1. 四种机制（**先分诊，再动手**）

| 型 | 现象（放大看） | 根因 | **该在哪一层治** |
|---|---|---|---|
| **① 采样型** | 平滑渐变里出现**可见台阶**（天空一条条蓝）、**彩色噪点**、纯色区发花 | **引导强度过高**把色彩推向极值、**步数过低**残留随机噪点、**精度不足的中间转换环节** | **参数层**（降引导强度、加步数——**仅外部工具可调**；本平台侧对策＝换更高分辨率档 / 换模型 / 重 roll / 纯色区改写为有信息材质）——**写多少提示词都没用** |
| **② 分辨率型** | **重复与平铺**（人脸/砖/链条成排复制）、多头多手、镜像构图 | **在远高于模型原生分辨率的尺寸上生成 → 模型开始"平铺"它学过的图案** | **生成层**（**在原生分辨率附近生成，再放大**；提示词里**写明数量**：`一个人` 而不是 `人`） |
| **③ 信息不足型** | **纯色区 / 背景 / 大面材质**上出现**斑驳的块与颗粒**（墙面、皮肤、布料上莫名的脏） | **模型在"它不确定"的地方按训练数据里的统计纹理自己编**——**信息越少，编得越多**；再加**元素冗余**（背景细节太多）会分散它的算力 | **提示词层**（★ 见 §3） |
| **④ 风格外溢型** | 整幅都带一层**"笔触式"的脏**（本该干净的地方也有画味） | **风格词被过度应用到不该应用的元素上**（风格外溢） | **提示词层**（把风格**限定到该在的地方**） |

**★ 判据一句话**：**① 与 ② 是"机器的事"，③ 与 ④ 才是"提示词的事"。**
**所以"画面脏"先问一句：这是"工具参数/分辨率"的问题，还是"我没告诉它那处是什么"的问题？**——**问错层，改一百遍也不干净。**

### 2. 一条反直觉的铁律（**"脏"与"颗粒"不是一回事**）

**胶片本身就是有颗粒的**——**颗粒不是脏；"该有颗粒的地方有颗粒、该平滑的地方平滑"才是对。**
**所以对策不是"去噪"（把颗粒一起去掉 → 画面变塑料），而是把颗粒"关进它该在的地方"**：
`颗粒只在暗部成簇、中间调细、亮部几乎看不到`（→ `carrier-artifacts.md`）
**★ 这句同时解决了两个反向的病**：**该净处脏（杂点）** 与 **该有质感处塑料（磨皮）**。

### 3. ★ 提示词层能做的四件事（③④ 型专用）

| 做 | 怎么写 | 为什么有效 |
|---|---|---|
| **给那一处"足够的信息"** | 不写"一面墙"，写 `墙面是被反复涂刷过的厚漆、边角磕掉一块、有一道旧的胶带痕` | **信息足了，模型不用自己编**——**这是治"信息不足型"的正法** |
| **降低那一处的需求** | 把背景**简化 / 遮挡 / 移出画外**（前景挡一下、景深压一下、干脆不入画） | **元素冗余会分走算力**；**不给它机会编**比"编完再修"省事 |
| **给"合理介质"框住它** | 颗粒 / 雾 / 尘 **写明位置与量级**：`只有暗部有颗粒` · `远处被雪雾糊成一片灰白` | **把"偶然的斑"变成"设计的介质"**——**同一堆像素，换个说法就从"脏"变成"质感"** |
| **限定风格的作用域** | `只有信纸是暖的，其余全是冷灰` · `木地板有被擦亮的区域` | **风格外溢靠"划范围"解决**，不靠加形容词 |

### 4. 可验证判据（**看哪里**，不靠感觉）

| 型 | 判据 |
|---|---|
| **① 采样型** | **放大到 200% 看一片天空/一面白墙**——出现**等距的色阶台阶**＝采样型；出现**彩色的随机点**＝步数/精度 |
| **② 分辨率型** | **在整幅里找"镜子"**：有没有两处一模一样的图案（砖、窗、人群里的脸）——有＝平铺；**数一遍手和头** |
| **③ 信息不足型** | **看"最平的那一块地方"**（纯色墙、背景虚化区、衣服的大面）——**那一块最脏**，就是这一型 |
| **④ 风格外溢型** | **看"不该有风格的那一小块"**（金属、水面、字牌）——**它也有画味**＝外溢 |

### 5. 处置顺序（**从便宜到贵**，别一上来就重做）

```
① 先判型（上面的四看）→ ② 采样型/分辨率型 → 回参数与尺寸，改完重跑
③ 信息不足型 → 改提示词（给信息 或 降需求 或 给介质框住），只改这一处
④ 风格外溢型 → 给风格划范围（"只有…是…的，其余全是…"）
⑤ 都试过 → 才动后期（局部重绘 / 加噪破台阶 / 局部降饱和）
```
**★ 一句忠告（来自公开实操经验）**：**"脏"靠后期简单修图治标不治本**——**先从"参数 / 尺寸 / 提示词"三个源头上调**，后期只做收尾。

## 六、后期补救清单


| 问题 | 后期手段 |
|---|---|
| 细节软/糊 | 升频器（AI upscaler）+ 轻锐化 |
| 闪烁/抖动 | 时域平滑、帧混合、光流插帧——**⚠️ 只对"漂移变形"类生效；颗粒的帧间重排不属于抖动，不许抹**（→ `carrier-artifacts.md` §三·★） |
| 纹理不统一 | **叠加胶片颗粒**（既统一纹理，又让颗粒落在它该落的地方——暗部粗、中间调细） |
| 色偏/曝光跳 | 色彩稳定、匹配颜色工具 |
| 长序列漂移 | 首尾帧控制（First-Last Frame），给模型两个固定端点 |
| 脸部细节崩 | 面部修复类工具；或裁切/用真实特写替代 |

## 七、与提示词体系的对接

- 每镜的**时间线**必须满足"一镜一主体一动作"；超了先拆镜，再考虑降复杂度。
- **脆弱元素清单**（脸/文字/手/小道具）在分镜阶段就标注，安排景别让它们占大比例。
- 运镜段优先慢推或锁死，动感靠剪辑（与 `shot-craft.md` 的"运动节制"一致）。
- 禁止项改写为**风险移除句**（"手插在口袋里"），而不是"不要多手指"。
- 连续两批同一错误无改善 → 停：拆镜 / 降复杂度 / 转后期（与 `tone-realism.md` 的停止条件一致）。

## ★ 收尾清单：渲染观感四禁 + 运动质量禁令（2026-09-17 · 自 `cinematic-look.md` 移入）

这两组是**提示词收尾时统一带的"观感过滤器"**——前者把"这一镜是拍出来的"钉死，后者把"帧是干净的"钉死。

### 四禁：抵住"AI 渲染感"（写清"它不是什么"）

```
NOT a 3D render · NOT a game engine · NOT a game-cutscene aesthetic · NOT a cartoon.
（做风格化时再加 NOT anime cel-shading）
```
**★ 为什么必须写"它不是什么"**：模型对**否定式风格边界**的响应，比对"要真实"这种正面形容词**强得多**——`cinema-director-v3` 把它叫 **render quad（渲染四禁）**，且**强制四项齐写、不许挑**；`CINEDANCE V4` 的负面清单里同样保留了 `No CG gloss` / `No game-engine look`。
> **证据强度**：**弱多源**（273 份语料里 6 份，`2%`）。
> **走「机制可独立论证」门槛**：**本库"未声明风格即走写实系"是用户 2026-09-17 定的铁律**——这四禁只是把那条铁律展开成**可执行、可逐条核对的清单**，不依赖来源权威。**按 L6 记为「拟订」。**

### 运动质量禁令：抵住"帧不干净"

```
sharp clarity, natural colors, stable picture,
no blur, no ghosting, no flickering.
```
**★ 它管的是"帧与帧之间"的缺陷**，与 §十 的静态质感缺陷（油腻/镜面/塑料）**不是一回事**：
- **重影 / 双像（ghosting / double-imaging）**——运动里拖出一个"残影"；
- **闪帧（flickering）**——相邻帧亮度或细节跳；
- **帧插值/帧混合（interpolation / frame blending）**——出现"中间帧"的糊；
- **形变 / 抖动（warping / morphing）**——脸或物体在帧间轻微扭。

**★ 用法纪律**：**它是收尾的兜底，不是替代**——`CINEDANCE V4` 原话：
> **"Do not use it as a substitute for real camera, lighting, or physics control."**
（**别拿一句"清晰稳定"去顶替真正的机位、布光与物理控制**——先写对因果，再补这道兜底。）
> **证据强度**：**多源收敛**（273 份语料里 **17 份，6%**）——**本轮新候选中证据最强的一条**，走 L4·补2 的"多源收敛"门槛，无需借机制论证。**按 L6 仍记「拟订」。**
