## 交付与改库纪律（**从 `SKILL.md` 按职责迁入 · 2026-10-16**）

> **为什么在这里**：这一节回答的是"**交付前必须做什么**"与"**改这个库时必须做什么**"，
> **与"怎么写一部片子"是两件事**——**入口文件只留生产流程，纪律层放治理册**。
> **正文逐字迁入，未改一字。**


- 推演留痕但成品干净；不足与不确定**明确说出来**，不藏。
- **交付前过一遍 10 项自查**（`steelman-protocol.md` 第 5 步）——**未全过 = 不交付**。
- **全中文**；提示词一律代码块，块内纯净（无注释、无"（改成你的…）"、无元说明）。
- **不分类型，一律带统一提质层**（→ `quality-layer.md`）；资产类省略运动句。
- 剧本一个文档（**版式按 `references/script-format.md`**：好莱坞标准 + 中文适配档；**中文档时长用秒 + 字数双轴，不许用页数估片长**）；资产按类给；**分镜每镜两个板块**，两块分开给、各自可复制；批量出图给【批量任务】文本。
- **三步顺序固定**；上游没定稿不动下游。
- 写之前先一句话确认：片名 / 时长 / 平台（竖屏横屏）/ 类型——缺关键项就问，不缺就直接写。
- **交付时要带预期管理**：素材量按 2–3 倍、后期按 60–70% 工作量说明；画面内文字一律约定后期覆盖。
- **交付时要带预算折算**：每个难点镜头给出**预估生成次数 → 折算成 credits / 钱**（→ `platform-matrix.md` 四·补）。**不写预算 = 把风险全留给用户**，用户无法主动砍镜头。
- **交付前做一次外部盲评**（或隔夜重读）：把成品给没看过的人，只问三句（→ `steelman-protocol.md` 四·补）。

**改动纪律与收尾自检（每次改动或交付的固定动作，不可省）**：

0. **★ 改动前核对（先于下面五条）**：加装任何内容之前，**先 grep 全库**确认"这个概念是否已有唯一定义、在哪份文件哪一节"——**凭记忆或摘要判断"这是缺口"一律不合格**；若已有且新来的并不更结构化，**不加**。（两次误判实例 → `key-decisions.md` E20）
1. **索引与实际文件一一对应**——`references/` 里每个文件都在索引里被提到过（**无孤立文件**），索引里每个文件都真实存在（**无幻影**）。
2. **同一概念全库只有一处定义**——量级句只在 `quality-layer.md`；写实缺陷层与人物光影块只在 `tone-realism.md`；皮肤**成因与判据**只在 `skin-realism.md`、皮肤光学**物理参数（分层/穿透/SSS/高光双层）**只在 `skin-light-physics.md`、**光位角度 / 半影 / 开尔文标度**只在 `light-physics.md`；器材参数与漫剧黑名单只在 `cinematic-look.md`；10 项自查只在 `steelman-protocol.md`。其他文件只引用、不复述。
3. **无前后矛盾**——同一件事在不同文件里说法一致（历史上出过：一处写"多视图走批量"、另一处写"不要多视图"）。
**★ 0.（推荐先跑这一条）`python3 scripts/lib_doctor.py`** —— **一条命令，库里库外一起查**：**九项库体检**（无工位册 / 超长册 / 悬空指针 / 未挂索引 / 八脚本自检 + claims / 跨册重复 / 路由自检 / **环境体检·ffmpeg**），**一行一条结论，有问题的直接给「→ 改法」**；对交付件加 `--deliver <文件…>`（内含**跨块矛盾四查**：首行画幅 · 光学族 · 焦段出包 · 固定光圈却写 f 值）；**要查某站该读哪几册用 `--route 站6`**（把 `run-sheet-part2.md` 的路由表变成机打）；**交付前判"及格/不及格"用 `--grade <文件…>`**（阈值表在 `acceptance-check.md` §五·补）；**算节奏用 `--rhythm <排镜表>`**（ASL 与节奏密度，`editing-rhythm.md`）；**查衔接用 `--linkage <分镜表>`**（景别序列 / 切点写全 / 情绪曲线，`shot-linkage.md`）；**查"直白"用 `--design <分镜表>`**（装置有无与种类 / 连续默认款 / 落点制造器 / 母题复现，`shot-design.md`）。**人不查表、不记规矩——只看结论。**
4. **结构断言自检**：跑 `scripts/audit_prompt.py`（时间戳累加 / 否定式动作句 / 声音行 / 结尾留白 / 块内杂质 / **空话词变体**）；**静帧类加开关** `blocks --asset`（资产图）/ `blocks --storyboard`（故事板）——**静帧没有时间轴**，不该有声音行与结尾留白（否则每块恒定 2 条无意义 WARN，久了没人看 WARN）。**★ 故事板另跑专用门禁** `scripts/storyboard_lint.py <故事板文件>`（查输出模式声明 / **张数 ≤ 平台上限** / 五段骨架 / 纯灰度 / 拼版 / 参数块与回写位）；**剧本另跑** `scripts/script_lint.py <剧本文件>`（**十二模块齐备与顺序** / 场景标题四要素 / 中文档加粗 / 括号与语速 / **交接契约逐场四键** / 诊断含副作用栏；单发正文加 `--mode body`）。**★ 改布局 / 拆卷 / 增删册 / 改行号之后另跑** `scripts/lib_health.py`（悬空指针 · 孤立知识 · 行数分布 · 跨册重复长句 · **行号引用越界 `refs`**——**超界即 FAIL**；拆卷最容易在这里静默腐烂）。
5. **AI 味自检**（交付前）：跑 `scripts/ai_smell_check.py <你的交付文件>`——查空话形容词与变体 / 文件腔 / **块内思考残留** / 双语并列。**FAIL 级（元说明）必须清零**；WARN 级人工定性。**维护风格库时加 `--inline`**（连「可写句式」那类行内代码句一起扫——它们是用户会直接复制的句子，但不是围栏块，默认模式看不到）。

> **⚠️ 读退出码，不要只看有没有输出。** 共用一套码：`0` 全过 ｜ `1` 有 FAIL ｜ `2` 用法错 ｜ **`3` 没扫到（≠ 通过）** ｜ `4` 只有 WARN ｜ **`5` 判据不适用（≠ 通过，也≠ 违规）**。**`3`/`5` 与 `0` 的区别是这套把关的关键**——历史上出过"贴错文件、扫不到块、照样报 PASS"的假绿；看到 `3` 要当作"**没验到**"，先确认文件贴对了。**改了脚本之后**先跑 `--self-test`（`audit_prompt.py` **78 条**（**含 `claims --refs` 两条**：默认只报 INFO 不误报 · strict 能进退出码） / `ai_smell_check.py` **29 条** / `shotlist_lint.py` **14 条** / `storyboard_lint.py` **17 条** / `script_lint.py` **23 条** / `sound_lint.py` **10 条** / **`lib_doctor.py` **11 条** / **`workrally_bridge.py` **14 条** / `mutation_check.py` **6 条**（**验证验证器**：给源码打一个已知坏改动、看门禁红不红；**只动临时文件，不碰本库脚本**）（站 6.5 投喂桥；**它 import `shotlist_lint`，改了载体词必须连带重跑它**）· **`libtv_orchestrate.py` **142 条**（**全链编排器**：`compliance` **内容合规层 R1–R16**（含**审核高危组合预检**）（把库里写死的 craft 规则编码成判据：资产三硬规格 · 每类资产齐备 · 像素值一致对应 · 分镜阶段 No BGM · 参考位序 · 图本面层齐备）——**结构对 ≠ 内容对**（六道结构门禁全绿却把明文规则做错的那次直接长出来的）；：`pipeline` **一条命令编译全链 + 六闸口 G1 上游门禁（**排镜表/故事板/声音表三载体分开入口**）/G2 资产锁定/G3 预算上限（**模型敏感**：含相对乘数）/G4 契约闸/G5 内容合规/G6 引用可生效** · `propagate` **错误作用传播**（键点重生成 → 沿引用链找到所有派生镜头与合成） · `classify` **错误可重试性分类 + 退避表**（K24） · `compile` 编译调用计划＋卡接口契约 K0–K24＋止损阶梯 · `ingest` 回填台账 · `resume` 断点续跑 · **`preflight` **开工第一条命令**（只读体检插件注册/缓存/凭据/网络四层，**不改配置、不读凭据、不发网络请求**；建节点前不跑它，就等于主动忽略可能已掉线）· `verify` 出站 6.7 证据包（容器/拼接点/色板 RGB 均值，ffmpeg 缺失时降 WARN）**；**它自己不发起 MCP 调用**——执行者是 agent））——它们是**唯一会自动运行的把关**，改坏了没有别的机制会发现。
