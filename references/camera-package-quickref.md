## 一、三问定档定包（带着风格编号来的，先走这里）

> **★ 先读 `style-package-matching.md`**（风格族 → 哪类包 + 哪些包是禁忌 + 叠哪个调制层）**与 `film-stock-matching.md`**（选定包之后取哪一档：片 / 印片 / 调制层）——**那两份给的是族级判据、档位与理由；§二 的表只是「氛围词 → 常见搭配」的速查。**

> **★ 带着风格编号来的，先走这三问**（在 `style-library.md` 选完编号后接这里）。
> 全库**写实系共 157 条**（B 卷 60 + C 卷 78 + E 卷 5 + A 卷 13 + G 卷 1）——其中 **C71–C75 五条不选包**（改选影棚灯具，→ `style-package-matching.md` §1 族⑪）· **G13 按方案包选机身后另加曝光层**（→ `camera-package-library.md` §四 调制层），
> 不做"编号→包"的对照表——**绑死会害了你**（同一个 B04 黑色电影，P08 拍是经典黑白、P14 拍是现代 neo-noir，都成立）。给的是**判据**：
>
> | 问 | 怎么取答案 | 答 → 落到 |
> |---|---|---|
> | **① 故事设定在哪个年代？** | 剧本的调性四元组（`shot-craft.md` 第二节） | 当代 / 近二十年 → **低端档**（P01–P06）或**数字档**（P13–P17）· 1950–2000 → **胶片档**（P07–P12）· 更远或年代不明确 → 跳过，看 ② |
> | **② 画面里的光是什么性质？** | **读两处**：风格条目的「色彩光影」一行 ＋ **内核册 `style-cores-*.md` 同编号条的「视觉语言」**（内核由真实参考帧逐图反推、剥掉题材仍成立，判光质比条目行更准），不用自己判断 | 暗调硬光、对比强烈 → **P08 / P10 / P04** · 自然光、像有人在现场拍的 → **P07 / P01** · 夜景霓虹、点光源多 → **P14 / P13** · 梦境、私密、怀旧 → **P15 / P11** |
> | **③ 机器是"被人拿着"还是"架在那"？** | 看叙事视角：目击 / 偷拍 / 不安 vs 凝视 / 正式 / 观察 | 有人拿着 → 档内选手持款 + 写不稳 · 架在那 → 档内选固定款 + 写稳定 |
>
> **三问答完仍拿不准 → 不要挑默认包**——回 `equipment-selection.md` §六 第一步问"真实感由谁承担"，再按六轴组合。（很需要保守起点时，按 §六 给**六轴各取一个最保守值**，而不是挑某个包顶上。）
> **这三问给的是起点，不是答案**：换档允许，**但要说得出理由**（换了年代设定，或换了光的性质）。
> **已经有明确氛围词的，不必走三问，直接查 §二 的表更快**——那张表是"氛围词 → 包"的直查。
> ⚠️ **读法**：它是"氛围词 → **常见搭配**"，**不是"场景类型 → 唯一器材"**——同一个厨房可以有五种记录方式（`equipment-selection.md` §五 原则 1）。

## 三、三个可直接复制的成套句

### 1. 低端档示范（P01 手机）

```
器材：现代手机主摄拍摄，等效26mm固定光圈，机内直出，不套任何胶片模拟；画幅4:3。
痕迹：景深很大，前后都清楚；画面边缘有轻微的桶形畸变；暗部可见彩色噪声；
高光直接硬裁成白、没有过渡；皮肤被算法处理过、纹理被抹平了一部分但没完全平整。
运动：手持不稳，走路时画面上下颠；变焦是一跳一跳的数码变焦。
```

### 2. 胶片档示范（P07 Super 16 手持纪实）

```
器材：用Super 16mm摄影机配定焦镜头拍摄，Kodak VISION3 7219（500T）负片；画幅1.66:1。
痕迹：颗粒明显、且随曝光变化——暗部颗粒粗、中间调细；宽容度高，亮暗两端都保得住；
景深较大，背景不容易虚；画面有轻微的片门晃动，偶尔闪过一道划痕或一粒灰尘。
运动：肩扛手持，机器有重量，呼吸感明显，从不完全静止。
```

### 3. 数字档示范（P14 变形宽银幕）

```
器材：用ARRI Alexa Mini LF配变形宽银幕镜头拍摄（40mm），数字底；
按柯达2383印片模拟收尾——对比扎实、暗部带一点青蓝、高光偏暖；画幅2.39:1。
痕迹：焦外是水平椭圆的；逆光时出现横向拉长的蓝紫眩光；高反差边缘有极轻的横向色散；
景深很浅，人物身后两三米就开始化开；画面有极轻的桶形畸变。
运动：缓慢横移，机身稳定但有极轻的呼吸浮动。
```

## 四、选包纪律（五条）与失败模式

1. **一片一包** —— 中途换包，观众读到的不是"器材"而是"不连贯"。**唯一例外是"跨世界"条目**（G01 选集式多风格 · G15 混合画幅 · G02 · G03 · G08 · D20）——**那不是"中途换包"，是每一段／每一画幅各自成片**；准入条件见 `stylized-look.md` §二·补2 的四条件。
2. **资产与镜头必须同包** —— 角色 / 道具 / 场景设定图要用同一包的痕迹参数；否则合成时人物像贴上去的。
3. **风格化系不用方案包** —— 描边系与工艺渲染系（见 `style-library.md` §二）是**画出来 / 造出来**的，不"拍"，器材句整段停用。
4. **低端档要敢用** —— 它是真实感最快的一档；只写"手机拍的"却不写手机的痕迹，等于没选包。
5. **痕迹至少写三项** —— 只写机身不写痕迹，模型会用它的默认观感覆盖掉你的机身。

| 症状 | 真正的原因 | 修法 |
|---|---|---|
| 所有片子观感都一样 | 每次都落回同一个包（往往是 P13 那一套） | 按 §二 反查表换包，或按 `equipment-selection.md` §三 跨包组合（**换包＝动手前重新选包**——如发现选错了档；**不是同一部片里混用两个包**，与纪律 1「一片一包」不冲突） |
| 写了"手机拍的"却出来很光鲜 | 只写了载体，没写该载体的痕迹 | 把该包「痕迹」行整行抄进去 |
| 资产与镜头不像同一次拍摄 | 两处用了不同的包 | 统一到同一包，痕迹参数逐字一致 |
| 太干净、一眼假 | 选了数字档却没上调制层 | 加**黑**色漫射滤镜 / 颗粒档 / 漂白层 |
| 年代戏没有年代 | 包对了，但色彩工程没锁 | 补该包的印片与色偏 |
