## 五、10 轮深度追问 · R1 剧本（2026-09-21 · 用户搬运）

> **对账结论**：**11 条里 3 条与本库一致、6 条新增、2 条直接纠正了《钥匙》清单**（三拍→四拍、声音参数）。

### 5.1 题材取舍（★ 新增）
**"单一动作 ＋ 单一物件"**：一个可被镜头拍到的物理动作贯穿全片（拿/放/开/关/等），**物件承担全部叙事压力**。
- **场景固定、光线固定**：一室一光源（窗光/台灯）→ 跨镜环境漂移最小，**一致性成本最低**。
- **时间跨度压在"一次等待"内**：不跨天、不跨地、不闪回。
- **情绪走"身体可见"路线**：呼吸、手指、站起又坐下、视线方向——**只写拍得到的**。
- **避开**：多人对话 · 复杂手部精细操作 · 镜面/文字/屏幕内容 · 快速运动 · 需真实人脸识别的题材。

### 5.2 时长与镜数配比（★ 新增 · 具体数字）
- **写实 + 无对白 + 靠物件叙事：2.5–4.5 秒/镜最稳，10 镜是舒适值**（34÷10＝3.4 ✓）。
- 若含 **1 个长镜（5–8 秒）**承载情绪停留，则其余压到 **2–3 秒**，总镜数 **9–11** 均可。
- **34 秒不建议 <7 镜**（镜头拖沓、单镜内动作易崩）**，不建议 >13 镜**（切碎后信息量不足、转场接不上）。
- 每镜时长之和要贴近总时长，**别靠删情节凑数**。

### 5.3 ★★ 四拍骨架 > 三拍（**直接纠正《钥匙》**）
**更稳的通用骨架是四拍**：
1. **建立**（她 + 钥匙 + 空间，交代"在等"）
2. **加压**（外部信号 / 时间推移，等待被拉长）
3. **转折**（伸手 / 起身，做出"拒"的动作）
4. **落点**（空镜 / 静止，留白）

**→ "四拍比三拍多一个『加压』，能让 34 秒的中段不塌；三拍在 ≤20 秒更合适。"**
**→ 对我的《钥匙》：三拍（等/拒/空）＝四拍的 1+3+4 合并，34 秒必须把"加压"单独拆出来。**

### 5.4 ★ 弧光的最少转折点＝2（★ 新增）
- **转折 A（约 40–50%）**：从"被动等"转为"主动面对"（注意到物件 / 起身 / 伸手）。
- **转折 B（约 70%）**：从"要拿"转为"不拿"（手收回 / 转身 / 放下）。
- **只有 1 个转折点会变成"事件"，而不是"弧光"**；2 个是下限，3 个更饱满但非必须。
- **转折 B 放 70% 合适**，但**前提是转折 A 已在前段（第 3–5 镜）埋好**，否则突兀无因。

### 5.5 ★ 弧光不进分镜行（★ 新增·口径）
**分镜行只放"可拍内容"**；**弧光属"意图层"**：
- 放在**我方文件**（剧本/设定）里，作为镜头描述的生成依据；
- 在分镜里**只体现为可见行为**（"她伸手，指尖距钥匙约 10cm 停住，收回"），
- **不写**"她内心挣扎""完成弧光"这类抽象词。**→ 弧光不进字段，只转化为镜头描述里的动作。**

### 5.6 ★★ 声音参数：**不要用"静音"代替"无 BGM"**（**直接纠正《钥匙》**）
- **无对白不影响生成**，平台不会因缺台词拒绝。
- **★ 关键**：**"生成时若不需要人声，别把 sound 关成 `off`——那会连环境音一起丢掉"**；
  **只要求无配乐时用 `need_bgm=false`，不要用静音代替。**
- 无对白意味着叙事全靠画面 → **分镜的镜头描述必须写足动作与物件状态**，否则生成结果会"空"。

### 5.7 ★ 静物冲突怎么增强（★ 新增 · 五法）
1. **给物件"状态变化"**：位置 / 朝向 / 被光扫过 / 被手指触碰后的位移——**状态差就是冲突**；
2. **给人物"接近—远离"的物理距离变化**：手与物件的距离从远到近再到远，**作为可量化的张力曲线**；
3. **用光线 / 景别当"压力计"**：越接近转折，**越靠近特写、光越硬**；
4. **加一个"外部信号"**（门响 / 光移）作**加压触发器**，让"等"有理由；
5. **避免依赖物件上的文字/图案识别**。

### 5.8 ★ 留白要写成"具体可见状态"（★ 新增）
**平台不会主动补剧情**；风险来自"提示词含糊时模型自行发挥"——末镜若只写"空镜"，**模型可能随机加入人物/动作**。
**规避**：末镜明确写「**画面中无人**」「**钥匙仍在原处未被移动**」「**镜头静止**」——**把留白写成具体可见状态，而不是让模型填空**。

### 5.9 命题不写进生成提示词 ✓（与本库一致）
命题属**文学层**，写进去违反"只写可见" → 留在我方剧本文件；要做片尾字卡则**当后期字幕处理**。

### 5.10 ★★ 进分镜行 vs 只留文件（★ 新增 · 分界）
| **进分镜行（可拍层）** | **只留我方文件（意图层）** |
|---|---|
| **视频内容片段**（逐条、完整、顺序一致，含动作 / 物件状态 / 声音）· **引用锚点列表** · **镜头描述（运镜 / 机位 / 景别 / 角度 / 构图 / 剪辑节奏）** · 时长 · 分镜编号 · **`node_key`** · **游标 index** | 命题 / 主题 / 情绪基调 / **人物弧光说明** / 创作动机 · 角色心理、前史、象征含义 · 台词清单 · 配乐设计意图 · 改编依据 |

**★ 一句话**：**"能拍到的进分镜，拍不到的留文件；两者之间用『镜头描述』做唯一转换通道。"**
