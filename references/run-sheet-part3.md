## 五、最小可用模板（写不动完整模板时用这一版）

> 完整版在 `shot-craft.md`（12 块）与 `segmented-shot.md`（分段镜）。这一版**只保留不能省的**——够用，但不豪华。

```
分镜头脚本，[单人单镜/多人单镜]，时长[N]秒，画幅[16:9 或 21:9]，[风格槽——**写具体技法与器材，不留泛化质感形容词**]（画幅写 `2.39:1` 也正确，落地取最接近的 `21:9`；**有首帧就留 `adaptive`**）。
[风格标签 3–6 个，用 | 分隔]

[人物与环境——身份锚点句逐字复用 + 场景物件两三件 + "画面里只有他一个人" + 瑕疵各≥2 处]

[光位与影调——只有 1–2 个有动机的光源，写明方向；曝光保护脸，另一侧不补光直接沉黑；光比写明]

时间线：起始 [起始姿态与动作]；主动作 [动作过程与落点]；反应与呼吸 [呼吸与余韵]；定格 [静止锁定]
        （⛔ 单镜只留上面四相；准备/接触/落定/触发 是**段落与段落之间**的切镜词，段内与单镜内禁写，段内推进写「他先…；随后…；最后…」）
        （**只写动作相位，不写秒数——AI 自己会分配时间**）

摄影机：[起始观察点]，[一个运动][方向]约[距离]；锁死[构图关系]；
        排除同族运镜[写了推就排除拉/摇/移/环绕/变焦]；[手持/稳定器]但保留**极轻微、如呼吸般**的浮动；
        镜内景别与焦距不变；**结尾落点**：[停下时画面停在哪]

[声音——无配乐，只保留现场音：列出 2–3 个关键环境音]

[统一提质层——把站 3 选定包的「器材」行 + 「痕迹」行逐字粘上；再接 `quality-layer.md` / `quality-layer-part2.md` 的高光颗粒句与禁用清单]

[风险移除——瑕疵类写肯定状态句，不写"不要…"]

[结尾——无对白、无爆发、无强光；用空位收]
```

**填不动就回头找站 3 的包和站 1 的命题**——模板填不动的根本原因，通常是上游没定。

## 六、三条禁令（跳过站点的直接后果）

| # | 不许 | 后果（实测） |
|---|---|---|
| 1 | **不许跳站 1（命题）** | 输出来"正确但空心"：技术参数全对，但**人物没有存在的理由**——观众第一反应是"谁会在那儿做那件事" |
| 2 | **不许把"规避风险"当目的** | 每步都更安全，累积起来**把题材删掉**。可行性门的本意是**改结构**，不是删动作。低风险方案里**必须仍保留题材的核心动作** |
| 3 | **不许用第三方体系（别人的 skill / 别的平台语法）冒充本库** | 外壳像了，内核没走——**流程跳步 + 术语错配**。本库的流程与文件是一体的，换外壳必丢内核 |

**一句话**：**成品可以傻瓜化，但复杂度必须由你吞掉。**
