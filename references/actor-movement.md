# 演员动作与走位：让主体真的动起来

> **何时读**：**做出来的片子"人不动"时**；分镜里需要人物位移时；给一场戏排动作时；剪出来发现像PPT时。
> **★ 一个动作怎样才能"像活的"（预备 / 缓入缓出 / 弧线 / 跟随 / 次要动作 / 时机）→ `motion-principles.md`**（动画十二法则经"能不能被模型执行"筛选后的七条可写原理）。
> **读完回哪**：动作控制工具与决策树 → `motion-control.md`（**本文与它同一层，但分工不同**）· 物理反馈 → `physical-feedback.md` · 可行性门 → `feasibility.md` · 站位与主陪关系 → `staging-craft.md` · 时间线块写法 → `block-playbook.md`。
> **分工（**别串**）**：`feasibility.md` 管**"哪些动作是门槛"**（要不要绕）· `motion-control.md` 管**"用什么工具控制它"**（参考视频 / 首尾帧 / 白模）· **本册管"在剧本与分镜层怎么写这个位移与动作"**——即**从"写什么"到"能不能动"的中间那一层**。

## §0 ★ 先诊断：为什么你的测试片里人不走（四个根因，按出现频率排）

| # | 根因 | 症状 | 处方 |
|---|---|---|---|
| **1** | **写的是"静帧式提示词"** | 景、光、材质、风格写得极细，**唯独没有"动作句"这一栏** | 每镜**强制加一行动作句**（见 §4） |
| **2** | **怕崩，故意不写动作** | 全片都是"他站着 / 她坐着"，安全但像PPT | 用 §2 的**可生成分级**挑A/B级动作填进去 |
| **3** | **镜头太短** | 单段 2 秒还要装一个位移 | 动作需要时间：**一步约 0.5 秒**（见 §5 换算） |
| **4** | **只写了"人在哪"，没写"人往哪"** | 有站位（`staging-craft.md`）没有**位移矢量**（起点→终点） | 补"**从哪 → 到哪 → 用几步**" |

**★ 一句话判据**：**把这一镜的动作句删掉，画面还能成立吗？** 能 → 这一镜本来就是静帧，**你要么承认它该静止（用运动镜头代替），要么给它一个动作。**

## §1 动作分级：先分清"两级动作"（与 `motion-control.md` 同级口径）

| 级 | 定义 | 例 | 特征 |
|---|---|---|---|
| **微动作** | **不改变身体位置**，只改变姿态与表情 | 呼吸起伏、眨眼、手指收拢、肩线下沉、转头 | **几乎必成**，且它是"活着"的最低成本 |
| **位移动作** | **改变身体位置** | 走、跑、坐下、起身、进门、转身 | **周期动作是能力边界**（见 §2） |

**★ 一条最容易被忽略的换算**：**没有微动作的"静止人"看起来是死的；有微动作的静止人看起来是"忍住不动"**——两者在成片里完全不同。**你测试片里可能不是"缺走位"，是"缺微动作"。**（先补微动作，再补位移——**这是性价比顺序**。）

---

## §2 ★ 动作的可生成性分级表（**正向清单 · 库里此前只有负向清单**）

> **口径**：本表按"**单主体 · 无接触 · 镜内可见**"的前提给分级；**成功率是经验值（C 档），必须在你自己的平台上用 §8 的实测清单复核**。

| 级 | 动作 | 说明与写法要点 |
|---|---|---|
| **A 几乎必成** | **呼吸 · 眨眼 · 手指/手腕微动 · 肩线起伏 · 头部轻微转动（<15°）· 衣角被风带动 · 头发丝动** | 只写"一个"动作；加"**幅度小、速度慢**" |
| **A** | **原地重心转移**（左脚换右脚）· **上半身转向**（<45°） | **这是"站着但不安分"的正确写法** |
| **B 多数能成** | **单步**（迈一步就停）· **起身 / 坐下** · **转身（<90°，慢）** · **递/接物（不发生接触）** · **开门（手在画外）** | 单步必须给**三个量**（见 §4） |
| **C 要参考视频** | **连续走路（≥3 步）· 上下楼 · 进出画面 · 多人交叉走位 · 跑** | 走 `motion-control.md` 的路径①（参考视频）或路径②（首尾帧） |
| **D 别做** | **奔跑中变向 · 打斗 · 舞蹈 · 人群中穿行 · 边说话边走 · 边哭边走** | **拆**：拆成两个镜，或用 §3 的跨镜位移 |

**★ 三条读表规则**：
1. **升级一条，成本翻一档**：A→B 只是换写法，**B→C 要加素材（参考视频/白模）**，C→D 就别碰。
2. **同一镜里不许跨两级**：写了A级微动作，就别同时让他走三步。
3. **一条镜里只有一个"动作单元"**（一个可判的起止：抬手→放下；起身→站定）。**两个动作单元=两个镜。**

## §3 ★ 位移的四种写法（**本册核心 · 从省到贵排序**）

**同一个"他从门口走到桌边"，有四种实现方式，成本差三倍。**

| 优先 | 写法 | 怎么做 | 成本 | 什么时候用 |
|---|---|---|---|---|
| **① 最省** | **跨镜位移** | **切**：镜头A他站在门口（或只给脚/背影），镜头B**他已经在桌边**——中间的过程**根本不拍** | **零** | **默认方案**。观众自动补全过程 |
| **② 次省** | **机位代走** | **人不动，摄影机动**：横移 / 跟移 / 推过去 / 绕过去 | 低（只吃运镜能力） | 要"空间在移动"的感觉，人物不必真走 |
| **③ 中** | **首尾帧位移** | **起点帧 = 预备姿，终点帧 = 落定位**，中间交给模型（`motion-control.md` 路径②） | 中（要出两张图） | **单步 / 单次改变**（从坐到站、转身、迈一步） |
| **④ 最贵** | **镜内连续位移** | 一镜里从 A 走到 B（≥3 步） | **高**（要参考视频或白模） | **只有"位移本身就是戏"时**（他一步步逼近、他退到墙角） |

**★ 决策顺序：①→②→③→④**（同 `staging-craft.md` §6 的降级逻辑：**先做结构性省力的**）。
**★ 一条硬判据**：**"这段位移本身在讲故事吗？"** 是 → 用④；**不是**（只是从这到那）→ **用①，省下的预算留给别处**。
**★ 最常犯的错**：把每一次"人物换位置"都写成镜内位移——**于是全片每一镜都在跟模型的弱项硬刚**，出片自然全是"原地不动"的妥协版。

## §4 ★ 动作句怎么写（**位置 · 语法 · 三个必补量**）

### 4.1 位置：动作句放哪
- **单机位镜**：写进**时间线块**（`block-playbook.md` 的【时间线】四相：起始 / 主动作 / 反应与呼吸 / 定格）。
- **段落版**：写"**他先…；随后…；最后…**"（**段内不许借切镜词**，见 `segmented-shot.md`）。
- **每镜强制一行"动作行"**——**这一行是"人不静止"的唯一保险**。

### 4.2 语法：**写约束，不写步骤**（承接 `motion-control.md` 的实测结论）
```text
✅ 两条腿一步一步交替迈出，每迈一步都看得见脚从后向前的摆幅；一步大约半秒
✅ 每走一步，骨盆与胸口在两条腿之间左右转移一次、身体随之下沉起伏一次
❌ 右脚跟先落地 → 脚掌压平 → 左腿在后蹬离 → 下一步整个反过来（会变成一张分解图）
```
### 4.3 **三个必补量**（缺任何一个，出来都是"原地摇摆"）
| 量 | 写法 | 为什么 |
|---|---|---|
| **步频** | `一步大约半秒` | 不给频率，模型给匀速滑行 |
| **摆幅** | `脚从后向前的可见摆幅` | 不给摆幅，脚不见移动 |
| **重心转移** | `骨盆与胸口左右各换一次、每步下沉一次` | 不给重心，腿像贴纸 |

### 4.4 本册补的第四条：**给"起点与终点"一个可判的空间标记**
```text
✅ 他从画面左后方的门内走出，走到桌前停住，与桌沿相距约一步
❌ 他在房间里走动
```
**★ 判据**：**起点与终点必须各有一个可看见的参照物**（门 / 桌 / 窗 / 台阶 / 另一个人）。**没有参照物的位移，在成片里看起来就是"没走"。**

## §5 走位的换算（**可写死的数字，标为经验值**）

```text
一步 ≈ 0.5 秒      （成年人正常步速）
一步 ≈ 0.6–0.75 米 （步幅）
→ 3 秒 ≈ 6 步 ≈ 4 米
→ 1 秒 ≈ 2 步 ≈ 1.3 米
```
**四条由此推出来的纪律**：
1. **单段 2–3 秒**（`motion-control.md` 的时间纪律）→ **镜内最多交代 3–5 步**；想要更多 → 拆镜或上参考视频。
2. **镜内位移超过约 2 米 → 考虑拆**（要么跨镜，要么机位代走）。
3. **"一步 0.5 秒"是你写"步频"的依据**——写"大约半秒"比写"慢慢地"可判。
4. **起身/坐下约 1–1.5 秒**，**转身 90° 约 1 秒**——**这两个动作单独占时间**，不要和走路挤在一段里。

## §6 症状 → 修法（八条，逐条对照）

| 症状 | 根因 | 修法 |
|---|---|---|
| **原地摇摆**（腿不交替） | 用文字分解了步态 / 跟拍诱导了"人不动背景动" | 改成**约束写法 + 三个必补量**；或改机位（不同速跟拍） |
| **滑步**（脚不动身子平移） | 没写摆幅与重心转移 | 补"脚从后向前的摆幅" |
| **走到一半停住** | 单段时长不够，或起点终点没给参照物 | 加时长 / 补参照物 / 拆镜 |
| **人物比例越走越小/越大** | 位移方向与机位关系没写 | 写 `横向移动，与摄影机的距离保持不变` |
| **背景跟着晃** | 写成了"跟拍"但主体没动 | 改成机位代走，或明确 `摄影机不动` |
| **转身崩**（脸变形） | 转身角度过大 + 正面入画 | 转身 **<90° 且慢**；或**转身交给剪辑**（跨镜位移的变体） |
| **穿模 / 与家具错位** | 镜内穿越调度 | **镜内不做穿越调度**——交给剪辑（`staging-craft.md` §6） |
| **一镜里两个动作互相抵消** | 一镜写了两个动作单元 | 拆成两镜：一镜一个动作单元 |

**★ 兜底三选**（关系复杂或纯走位时）：**背影 / 剪影 / 不给脚**——`feasibility.md` 的"把缺陷写成剧情事实"在这里的用法：**不给脚不是藏，是改题**（他坐在桌后 / 他只入画上半身）。

## §7 陪体也要动，怎么办（承接主陪关系）

**规则**：**主体动 → 陪体静；陪体动 → 主体静**（`staging-craft.md` §6）。**两个都动 = 崩**（且观众不知道看谁）。

**要让陪体也有生命感的三种做法**（都不破规则）：
1. **给陪体微动作而非位移**（A 级：呼吸、擦杯子、扶着栏杆的手轻轻动）——**成本最低，效果最好**。
2. **拆镜**：这一镜给主体走，下一镜切过去给陪体走。
3. **让陪体"被带动"**：主体走过时，陪体的衣角/头发/手里的纸被带动——**这是被动物理，不是陪体自己在动**（`physical-feedback.md`）。

## §8 ★ 平台实测清单（**先测平台，再写片子**·约 3 分钟可跑完）

**做法**：把下面 6 个测试各生成 4 次（同一提示词），统计"能用"的比例，填成表。

```text
① 微动作：人物静坐，只有呼吸与眨眼              期望成功率 ≥80%
② 原地重心转移：他站着，左右脚换重三次          期望 ≥60%
③ 单步：他迈一步就停                            期望 ≥50%
④ 起身：他从椅子站起                            期望 ≥50%
⑤ 转身 60°：他慢慢转头看向侧后                  期望 ≥40%
⑥ 连续三步：他从门口走三步到桌前                期望 ≥25%（低于此 → 走参考视频路径）
```
**★ 记录什么**：成功率 · 失败症状（按 §6 表归类）· **一次成功的提示词原样贴进台账**（`production-ledger.md`）。
**★ 判据**：**③④⑤ 任一低于 40%** → **本片的结构里，位移镜不能超过总镜数的 1/5**（回到 `feasibility.md` 的"超过 3 个就要改结构"）。
**★ 为什么必须先测**：**"走路能不能做"是平台差异最大的一项**——别人的"能"不代表你的能；**实测数据才是你自己的可行性门。**

## §9 交付前自检（十二条）

```text
① 每镜都有"动作行"吗？（没有动作行的镜 = 静帧）
② 每一镜的静止人物，有没有给"微动作"？
③ 动作属 A/B/C/D 哪一级？同镜里跨级了吗？
④ 每一镜只有一个"动作单元"吗？
⑤ 位移用了四种写法里的哪一种？**按①→②→③→④的顺序想过一遍吗？**
⑥ "这段位移本身在讲故事吗？"（不是 → 为什么不用跨镜）
⑦ 动作句写的是"约束"还是"步骤"？（步骤 → 改）
⑧ 三个必补量（步频 / 摆幅 / 重心转移）齐了吗？
⑨ 起点与终点各有一个可见参照物吗？
⑩ 步数与时长的换算对得上吗（一步≈0.5秒）？
⑪ 主体动的时候，陪体是静的吗？
⑫ 镜内有没有穿越调度？（有 → 交给剪辑）
```

## §10 常见误区

| # | 误区 | 后果 | 修法 |
|---|---|---|---|
| 1 | **以为"人不走"是模型不行** | 全片妥协成PPT | 先查 §0 四个根因——**多数是"没写动作句"** |
| 2 | **把每次换位置都写成镜内位移** | 每镜都在跟弱项硬刚 | ①跨镜 ②机位代走 优先 |
| 3 | **用文字分解动作** | 变成"分解图"，原地摇摆 | 写约束 + 三个必补量 |
| 4 | **一次性要多个动作** | 互相抵消 | 一镜一个动作单元 |
| 5 | **静帧式提示词**（只写景光材质风格） | 人不动 | 每镜强制动作行 |
| 6 | **不给参照物** | 走了像没走 | 起点终点各一参照物 |
| 7 | **主体陪体同时动** | 崩 + 不知道看谁 | 一动一静 |
| 8 | **没测平台就写片子** | 结构做完才发现位移做不了 | 先跑 §8 的六项实测 |
