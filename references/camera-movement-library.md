## 一、先分清三件事（不分清，选了也写不对）

**① 位移 vs 光学——判据是视差（parallax）。**
摄影机**真的移动** → 近处物体掠过画面边缘，远近层**速度不同**，有视差；
只**改焦距** → 主体大小变，而背景与主体的相对比例不变，**无视差**。
**这一条决定模型会把"推"执行成推还是变焦**——不写清，十次里约有四次给你光学变焦（经验估计，未留存样本）。

**② 旋转 / 高度 / 环绕是三条不同的轴。**
摇、俯仰、翻滚是**原地转**；升降是**垂直平移**；环绕是**绕圈平移**。
三者混写成一个词 → 模型自选 → 出来不像任何一样。

**③ 作用域：单机位 vs 分段镜。**
摄影机段与"景别不变"，在**单机位镜里全文生效**；在**分段镜里只在镜内生效**，
**镜与镜之间就是要换机位**（见 `segmented-shot.md` 第四节）。

## 二、运镜五要素（缺一不可，缺哪条模型就补哪条错的）

| # | 要素 | 写法 |
|---|---|---|
| 1 | **起始观察点** | 开拍时摄影机相对主体的位置：`从[角色]肩后与视线齐平`、`略高于桌面`、`门外` |
| 2 | **运动轨迹** | 方向 + 方式 + 距离：`向前推近约[1.5]米`、`绕主体顺时针弧形环绕约[120]度` |
| 3 | **速度与缓动** | **先给量纲，再给缓动**：`前移约1.5米、用时2秒`；`起步极缓、中段匀、收尾再缓`——**减速收尾是默认**，匀速到底要另写 |
| 4 | **锁死项 + 同族排除** | 明写"什么全程不变"+ **按族**排除（位移族 / 光学族 / 旋转族，不是全堆） |
| 5 | **停止结果** | 停在谁身上、什么景别、落在什么构图：`停在[角色]眼部，位于画面右侧三分线` |

**速度尺**——**把形容词换成数字**。"缓慢"是相对的：同样一句"缓慢"，在 1 米的距离上是挪，在 10 米的距离上是敷衍。

| 档 | 速度 | 画面读起来 |
|---|---|---|
| 凝滞 | < 0.2 m/s | 几乎静止，用来"屏住" |
| 缓推 / 慢摇 | 0.3–0.8 m/s | 注意力沉降、情绪下沉 |
| 常速跟随 | 1.2–1.5 m/s | 与人步行同速，最自然 |
| 快推 / 快跟 | 2–4 m/s | 压迫、追迫、急转 |
| 甩 | > 6 m/s | 只剩运动模糊（见 §4.2） |

**两条配套**：① 写"**距离 + 用时**"比只写 m/s 更稳（`前移约1.5米、用时2秒`，模型能直接换算该走多远）；② **复合运镜必须写速度差**（`升起慢、环绕快`），同速会糊成一坨。

> **"写了运动但五要素不全"＝无效运镜**，模型会自己补一个最省事的——**通常是缓推**。

## 三、六族全谱（查表用）（表内"时长下限"＝运动完整执行所需的生成侧时长，成片可截取）

### 3.1 位移族（摄影机真的动）

| 术语 | 它到底做什么 | 画面里什么在变 / 什么不变 | 时长下限 |
|---|---|---|---|
| **推进** dolly in / push in | 物理前移，**不是变焦** | 近景物体掠过画框边缘、**强视差**；主体变大 | ≥1s |
| **拉出** dolly out / pull back | 物理后移 | 环境层层进入，**地平线上升** | ≥3s（要读出"揭示"） |
| **横移** truck / lateral dolly | 平行于主体侧向平移 | 前中后**三层速度差**；主体在框内横向漂 | ≥1s |
| **跟随** tracking / follow | 与主体同速位移 | 主体**画面位置恒定**，背景在流 | ≥1s |
| **升降** pedestal | 垂直平移，**不转轴** | 视线高度变，地平线不倾斜 | ≥1s |
| **侧跟** profile track | 沿主体侧面平行推进 | 侧面轮廓保持，背景滚动 | ≥1s |

### 3.2 光学族（摄影机不动，画面变）

| 术语 | 它到底做什么 | 画面里什么在变 / 什么不变 | 时长下限 |
|---|---|---|---|
| **变焦** zoom | **只改焦距** | 主体大小变，**背景与主体比例不变（无视差）** | ≥1s |
| **急推变焦** snap / crash zoom | 极快变焦到某点 | 速度本身就是信息（惊） | ≥0.3s（相位，非生成时长） |
| **跟焦** rack focus | 焦点在**同一画面内**转移 | 清晰区从前景滑到背景，**构图不动** | ≥1s |
| **推变焦** dolly zoom | 后退 + 焦距推近同时进行 | **主体大小纹丝不动，背景胀或缩** → 失衡 | ≥2s |

### 3.3 旋转族（原地转）

| 术语 | 它到底做什么 | 画面里什么在变 / 什么不变 | 时长下限 |
|---|---|---|---|
| **摇** pan | 原地水平转 | 画面横向流；**旋转中心是摄影机，不是主体** | ≥1s |
| **俯仰** tilt | 原地垂直转 | 由下往上揭示高度或体量 | ≥1s |
| **翻滚** roll | 绕光轴转 | **地平线倾斜**（与荷兰角同源） | ≥1s |
| **甩镜** whip pan | 极快水平转，全程运动模糊 | **糊掉的那几帧就是转场** | ≥0.3s（相位，非生成时长）→ 见 §4.2 |

### 3.4 环绕族（绕圈平移）

| 术语 | 它到底做什么 | 画面里什么在变 / 什么不变 | 时长下限 |
|---|---|---|---|
| **弧轨** arc | 绕主体走**一段**弧 | 主体轮廓换面，背景连续替换 | ≥3s |
| **环绕** orbit | 绕行角度更大（90° / 180° / 360°） | 背景**整圈替换**，主体始终居中 | ≥3s（180°）、≥4s（360°） |
| **转盘** lazy susan | 主体自转的等价效果 | 主体转、环境不动 | ≥3s |

### 3.5 高度族（揭示规模）

| 术语 | 它到底做什么 | 画面里什么在变 / 什么不变 | 时长下限 |
|---|---|---|---|
| **升降摇臂** crane / boom | 整体升起或落下（可带弧） | **地平线稳定上升**，空间关系随之揭示 | ≥3s |
| **低位升起** rise | 从脚到手、从物到人的顺序揭示 | 信息按顺序给出 | ≥3s |
| **航拍** aerial | 高位平移或下降 | 尺度感；**人变小＝孤独** | ≥3s |
| **俯冲** nosedive / drone dive | 高位快速下冲 | 多轴同时动，冲击 | ≥1s |

### 3.6 复合族（两个分量以上 → 见 §4.3 的三条规则）

| 组合 | 效果 | 时长下限 |
|---|---|---|
| **推 + 环绕** | 强度最高，常用于主角时刻 | ≥3s |
| **升降 + 摇** | 开场 / 收尾 | ≥3s |
| **环绕 + 变焦** | 英雄式揭示 | ≥3s |
| **跟 + 手持** | 追逐、慌乱 | ≥1s |
| **翻滚 + 推进** | 失控、眩晕 | ≥2s |

## 四、三个难点专项（这三样最容易崩）

### 4.1 环绕运镜

**为什么它最容易崩**：① 模型把"环绕"理解成**主体自转**，结果环境绕过去了、人没动；
② 狭窄空间转不开，出现空间撕裂；③ 转到背面那几帧脸崩。

**四条写法（同时给，少一条就崩）**：

1. **写本质定义句**：`是摄影机在绕主体移动，主体自身不转动`
2. **写方向 + 角度**：`顺时针绕[120]度`（不给角度＝模型自己决定，通常给太少）
3. **写高度恒定**：`始终保持与[角色]眼睛齐平`
4. **写背景替换而主体居中**：`主体始终位于画面中央，背景连续替换`

**角度档**：`90°` 换一个面 ｜ `180°` 露出对面（对峙变同框）｜ `360°` 完整审视（≥4s）。

**⛔ 狭窄空间禁用**（走廊 / 车内 / 堂屋 / 电梯）——地形不够，转起来必撕裂。
改用**侧跟**或**横移**，同样能得到"绕行感"而没有空间穿帮。

### 4.2 甩镜头（whip pan）

想用"甩"把 A 和 B 接在一镜里，**两条硬规则必须同时满足**：

1. **以什么景别开始，就以什么景别落地**——中景甩中景、近景甩近景。
   **中途换景别＝藏在 pan 里的剪接，读起来是故障帧。**
2. **必须写动作相位预算**，把"稳定 / 拖影 / 落定"三个相位分开（**不写秒数**）：

```
甩镜：中景起，中景落，全程景别不变。
起始：主体A停在画面左侧，摄影机稳定无晃动；
甩动：摄影机向左急速甩动，全画面运动模糊；
落定：画面在新主体上停稳，主体B位于画面右侧，模糊消失，重新合焦。
```

> **两个主体分别命名**（主体A / 主体B），不要写"一个人""另一个人"。
> **验收**：甩得越快越要看**落定那两帧是否干净**——糊着落定＝废镜。

> 上面这段是**摄影机段片段**（不是完整提示词）——声音行与结尾留白由 `shot-craft.md` 的完整模板统一提供。

### 4.3 复杂运镜（复合）的三条规则

**规则 1：最多 2–3 个运动分量。** 超过三个，模型会糊成一团或只执行其中一个。

**规则 2：用顺序词写清先后，不要并列堆词。**
✅ `摄影机先缓慢升起，然后绕主体向右弧形环绕约90度`
❌ `升摇环绕推`（并列堆词 → 模型随便挑一个或全糊在一起）

**规则 3：锁死项只写一次总账**，不要每个分量各写一遍——
`全程保持不变：[主体]在画面中的相对位置、景别、焦平面、光线方向`。

**三条避坑**：
- **不写互相抵消的组合**（推 + 拉同写、左移 + 右移同写）→ 模型在中间来回抖。
- **分量越多，时长必须越长**——两个分量 ≥3s，三个分量 ≥5s（此为**生成层**时长）。本条只适用于**三分量复合运镜**；`shot-orchestration.md` 第七节的「单镜守在 2–3 秒」指**成片有效长度**（该册 §七已分层收口），两者分属两层、不冲突。【2026-09-30 复核：原「待确认项」（不可同时满足、原数值暂不改）撤销。】
- **需要三个以上分量 → 别硬写在一条里**，改**分段镜**：按段落把每个分量分给一段（见 `segmented-shot.md`）。**这是"复杂运镜"最稳的实现方式。**

## 五、选型两查（先问感受，再问情境）

### 5.1 意图表（每镜只选一个主导意图）

| 你要观众感到什么 | 首选运镜 | 辅助 |
|---|---|---|
| 领悟 / 压迫 / 决意 | **推进** | — |
| 恐惧 / 失衡 / 世界变了 | **推变焦** | — |
| 揭示规模 / 孤独 / 收尾 | **拉出** | 俯仰 |
| 转变 / 敬畏 / **身份不稳定** | **环绕** | 变焦 |
| 追逐 / 动势 / 空间连续 | **横移跟随** | 手持 |
| 仪式 / 威慑 / 画面化的权力 | **锁死** | 略低机位 |
| 压迫 / 失去控制 / 被困住 | **荷兰角 + 主体顶死在画框边缘** | 手持 |
| 揭晓高度 / 体量 / 由小到大 | **俯仰 / 升降** | 拉出 |
| 登场 / 由物到人 | **低位升起** | — |
| 能量转换 / 场景硬接 | **甩镜** | — |
| 紧张 / 不安 / 纪实 | **手持** | 跟随 |
| 失控 / 眩晕 | **翻滚** | 推进 |

**三条配套纪律**：

1. **每镜只选一个主导意图**——推与环绕同写＝不稳（与"一镜只指定一种运镜"同一条）。
2. **主体运动与摄影机运动分开写**——混在一句里，模型分不清是谁在动。
3. **若主体朝镜头来，必须写明摄影机是补偿、不动、还是后退**——不写，模型自己猜，十次里错六次（经验估计，未留存样本）。

### 5.2 情境表（问"这场戏在发生什么"）

| 情境 | 推荐运镜 |
|---|---|
| 情绪压力升级 / 点破真相 | 慢推（≥3s） |
| 破门 / 冲撞 / 惊变 | 急推（低角度更有冲击） |
| 人物冲入报信 | 跟随 |
| 进门落座 / 连续移动 | 横移跟随 |
| 视线转向新人物或证据 | 摇 |
| 新角色登场，由物到人 | 低位升起 |
| 一场结束，抽离 | 拉出 |
| 对峙问答 / 读屏幕 | 锁死 |

### 5.3 运镜主轴（每场登记一次，全场共享）

选 **1 种主运镜 + 0–2 种辅助**，写进序列契约，避免每镜各来一套：

| 主轴 | 适用 | 主 | 辅助 |
|---|---|---|---|
| 稳定观察 | 对话、信息交代 | 锁死 | 推进 |
| 逐渐逼近 | 压迫升级、真相揭示 | 推进 | 摇 |
| 逐渐疏离 | 收尾、孤独 | 拉出 | 锁死 |
| 跟随行动 | 追逐、报信、移动 | 跟随 / 横移 | 摇 |
| 空间揭示 | 建立场景、登场 | 升起 / 摇 | 横移 |
| 群像压迫 | 多人对峙、包围感 | 环绕 / 横移 | 推进 |

## 六、四型句式（**片段**：只替换 `shot-craft.md` 模板里的**摄影机段**）

> 下面四条**不是完整提示词**，是**摄影机段**本身（所以不带声音行与结尾留白——
> 那两项由 `shot-craft.md` 的完整模板统一提供）。`[ ]` 换成本镜内容。

**① 固定机位**（＝§五 意图表 / 情境表之「锁死」）——必须有可读性任务（读取 / 微反应 / 对峙压制），不是默认值。

```
[景别]，[机位角度]的固定机位；[主体锚点句]位于画面[位置]；
[主体]的[一个动作]，固定构图持续显示[关系的什么变化]。
```

**② 推进型**（五要素齐全的样板）

```
[景别]，摄影机从[主体A]肩后与[主体B]视线齐平的观察点向前推近约[1.5]米，
镜头停在[主体B]眼部，[主体B]始终位于画面右侧三分线；
全程保持不变：[主体B]在画面中的相对大小变化仅来自推进、构图关系不重排、光源方向与色温不变；
无横移、无拉出、无摇、无环绕、无变焦、无俯仰；
起步极缓、中段匀、收尾再缓；焦点始终锁定[主体B]面部。
```

**③ 环绕型**

```
[景别]，摄影机以[主体]为圆心顺时针弧形环绕约[120]度，
是摄影机在绕主体移动，主体自身不转动；始终保持与[主体]眼睛齐平；
主体始终位于画面中央，背景连续替换；
全程保持不变：景别、焦平面、光源方向与色温；
无推进、无拉出、无变焦、无俯仰。
```

**④ 复合型**

```
[景别]，摄影机先[分量1：缓慢升起约0.6米]，然后[分量2：绕主体向右弧形环绕约90度]；
两个分量速度不同：[升起慢、环绕略快]，不要同速；
全程保持不变：[主体]在画面中的相对位置、景别、焦平面、光线方向；
无[排除与这两个分量同族的其他运动]；
起步极缓、中段匀、收尾再缓。
```

## 七、失败模式（出片先来这里对）

| 症状 | 原因 | 修法 |
|---|---|---|
| **写推，出来是变焦** | 没写"摄影机物理前移"，也没写视差 | 补本质定义句 + `近景物体掠过画框边缘，远景保持较小` |
| **写环绕，人在原地转** | 没写"是摄影机在绕" | 补 `主体自身不转动` |
| **环绕空间撕裂** | 狭窄空间硬做环绕 | 改侧跟或横移 |
| **复合运镜只执行一半** | 分量超过 3 个，或用了并列堆词 | 砍到 2 个分量，改用"先…然后…" |
| **镜头在中间来回抖** | 写了互相抵消的组合 | 删掉方向相反的那一个 |
| **运动过程中构图被重排** | 锁死项没写 | 补 `全程保持不变：[构图关系 / 轴线 / 相对位置]` |
| **景别中途漂掉** | 没写景别锁定 | 补 `全程景别与焦距不变`（分段镜写在镜内） |
| **匀速到底，收尾很硬** | 没写缓动 | 补 `起步极缓、中段匀、收尾再缓` |
| **运镜说不清是快是慢** | 只给了形容词，没给距离与用时 | 补 `推近约1.5米、用时2秒`（见 §二 速度尺） |
