# 风格校准卡 · A 卷 ／ A 卷续（美术史 40 条）

> **这一册答的是**：**"我这一版偏了哪一项"**——每张卡给**四项色彩指标 + 光位 + 构图 + 质感**，**末行留「参照 / 生成」两组数、由你取帧后填**。
> **与取图册的分工**：`style-sources-a.md` 回答"**去哪找参照**"，本册回答"**怎么核像不像**"。
> **★ 用法**：取一张参照（画作）→ 用取色工具读四个数 → 与卡上的**方向**比。**先看色相与饱和**——多数"风格不对"就栽在这两项。
> **★ 定标与容差 → `style-cards-scale.md`**：卡上给"低 / 中 / 高"是**方向**，**判偏要回那一页量数**——先量参考帧、再量你出的图，按容差表（色相 ±12° · 饱和 ±25% · 明度与对比 ±15%）看差多少。
> **★ 卡上的指标是方向性推导**（依据美术史与绘画技术通识），**不是实测值**；**你填的实测优先于卡**。
> **★ 绘画类没有"光位/景深"这两个摄影概念**——卡上给的是**光的方向与软硬 + 画面的空间处理**（装饰性平面 / 空气透视 / 透视纵深）。
