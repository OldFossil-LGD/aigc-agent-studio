# 器材包扩展集（P18–P34 · 17 个补充包）

> **何时读**：`camera-package-library.md` 的 17 包里找不到合适的载体时；用户点名"航拍""监控感""像录像带""梦里的画面"这类**非标准摄影机**的需求时。
> **读完回哪**：回 `equipment-selection.md`（把新包**当六轴的取值**用，不是当整包用）。
> 单品细节仍查 `cinematic-look.md`；痕迹机理查 `carrier-artifacts.md`。

---

## ★ 总声明：以下全部是**可选项**，不是固定配置

**这一条比包本身重要，请先读：**

1. **包不是"一个场景配一个包"。** 下面每个包都**可以拆、可以组合、可以只取一行**——`equipment-selection.md` §三 的六轴跨包组合规则对它们同样适用。
2. **"适用"不是命令，是提示。** 它说"这类需求常这么配"，**不代表别的配法不成立**。同一个场景用 P18 无人机拍和用 P01 手机拍，是**两个不同的故事**，都成立——取决于你想讲哪个。
3. **每个包都带「取舍」一栏，它比「适用」更有用**：适用说"什么时候用"，**取舍说"什么时候别用"**。**先读取舍，再决定用不用。**
4. **不要为了用它而用它。** 新器材（航拍、FPV、红外、热成像）有强烈的"哇"效应——**第一次出现有效，用多了会廉价**（这条对 P19 FPV 尤其成立）。
5. **P32 / P33 不是"器材"**：它们没有摄影机。**用它们等于改变了全片的世界观**，读它们的「取舍」时会看到后果。

## 一、这份扩展补的是"维度"，不是"型号"

原 17 包（P01–P17）覆盖的是**常规摄影机在常规位置上的不同介质与光学**。缺的是**维度**：

| 维度 | 原 17 包覆盖 | 缺口 → 本次补 |
|---|---|---|
| **距离** | 人眼附近的常规焦段 | 超近（P22 微距/显微）· 超远（P21 长焦 · P30 卫星） |
| **位置** | 地面、手持或架着 | 空中（P18 航拍 · P19 FPV）· 身上（P20 穿戴）· 缝隙里（P31 内窥） |
| **光谱** | 可见光 | 红外（P26）· 热（P27）· 微光增强（P28） |
| **画框来源** | 摄影机的取景框 | **屏幕**（P29 录屏）· **无取景框**（P32 CGI · P33 AI 原生） |
| **时间** | 实时 | 压缩（P34 延时） |
| **空间感** | 常规透视 | 球面畸变（P23 鱼眼）· 微缩感（P24 移轴） |

**一句话**：**原 17 包回答"用什么机器"，这一份回答"从哪看、看什么波段、要不要机器"。**

## 二、17 个补充包

### 组一 · 特殊位置

#### P18 · 无人机航拍
- **拍摄故事**：一台无人机悬在空中，往下看。
- **器材**：四轴无人机 · 广角定焦（等效 24mm）· 电子增稳 · 16:9
- **痕迹**：**没有参照物时画面"过于平稳"——这本身是破绽** · 桨叶阴影偶尔入画 · 高空有大气透视（越远越灰）· 快速下降时有果冻效应 · 广角边缘畸变
- **运动**：悬停 / 缓慢平移 / 垂直升降
- **适用**：开场建立 · 地理交代 · 渺小与孤独 · 追踪移动主体
- **取舍**：**要人的表情就绝不能用**（这个距离上脸读不到）· **要私密感也别用**（俯视＝疏离，观众站在上帝的位置）

#### P19 · FPV 穿越机
- **拍摄故事**：一台竞速无人机以极高速度一头扎进去。
- **器材**：FPV 穿越机 · 超广角（等效 14–16mm）· 大幅电子增稳 · 16:9
- **痕迹**：**极强广角畸变（直线弯成弧）** · 高速运动模糊 · 剧烈颠簸与滚转 · 桨叶入画
- **运动**：极速穿越 / 俯冲 / 环绕 / 翻滚
- **适用**：动作 · 惊险 · 沉浸第一人称 · 空间穿越（一镜跨几个空间）
- **取舍**：**晕眩风险高**——超过 3 秒观众开始不适 · **不能承载对白与表演** · ★ **首次出现最有效，全片用两次以上就廉价了**

#### P20 · 运动相机 / 穿戴式
- **拍摄故事**：一个人把相机戴在身上，拍自己正在做的事。
- **器材**：运动相机 · 超广角 · 强增稳 · 4:3 或 16:9
- **痕迹**：广角畸变（边缘最重）· 水下有色偏与浮游物 · 强光下高光硬裁成白 · 关掉增稳时剧烈晃动
- **运动**：跟随身体（头 / 胸 / 手腕）
- **适用**：极限运动 · POV 沉浸 · 现场感 · "这是真的发生"
- **取舍**：**不能承载"被观察"的叙事**——穿戴＝自己就是主体 · **脸靠太近会变形**（广角）

### 组二 · 特殊光学

#### P21 · 超长焦监视
- **拍摄故事**：一个人站在很远的地方，用长焦看着另一个人。
- **器材**：超长焦定焦（等效 300–600mm）· 大光圈 · 三脚架
- **痕迹**：**空间被压缩（前后景挤在一起）** · 极浅景深 · 空气扰动（热浪、雾）· 极轻微的抖动
- **运动**：固定 / 极缓慢跟随
- **适用**：偷窥 · 监视 · 疏离 · 无法接近的关系 · 野生动物
- **取舍**：**压缩会抹平空间关系**——想表现"距离感"时反而不要用它（它让远的东西看起来近）· 空气扰动是双刃：真实感加分，清晰度减分

#### P22 · 微距 / 显微
- **拍摄故事**：镜头贴着东西在看，近到能看见结构。
- **器材**：微距镜头（1:1 或更高）· 显微（如需）· 环形补光或侧光
- **痕迹**：**极浅景深（只有一条线是清楚的）** · 环形光在金属与水面留下环形高光 · 高倍率下光衍射导致整体发软
- **运动**：极缓慢移动 / 固定
- **适用**：产品细节 · 自然微观 · 皮肤/眼睛/伤口 · **隐喻（把小事拍大）**
- **取舍**：**不能承载人物表演**（脸不在这个距离的叙事逻辑里）· 环形高光在某些材质上会显"廉价"（换成侧光）

#### P23 · 鱼眼 / 全景
- **拍摄故事**：一台装鱼眼镜头的机器，把整个空间塞进一个圆里。
- **器材**：鱼眼镜头（8–15mm）· 16:9 或 1:1
- **痕迹**：**所有直线弯成弧** · 四角与上下被拉长 · 边缘失光严重 · 近距离时人脸中央凸出
- **运动**：固定 / 缓慢旋转
- **适用**：VR · 幻觉 · 药物体验 · 极端空间 · 喜剧夸张
- **取舍**：**畸变是它全部的价值，也最容易被滥用**——写实题材慎用；**只在"空间本身不正常"时才对**

#### P24 · 移轴
- **拍摄故事**：一台架着的机器，把清晰范围压成一条窄带。
- **器材**：移轴镜头（或后期模拟）· 16:9
- **痕迹**：**只有一条横向窄带清晰，上下极速化开** · 高机位俯拍时产生"微缩模型"感
- **运动**：固定 / 极缓慢（保持那条带的位置）
- **适用**：微缩景观感 · 记忆（像在看一个模型）· 孤独的城市 · 时间流逝
- **取舍**：**微缩感与"真实"直接冲突**——想让人相信"这是真的"就别用

### 组三 · 特殊光谱

#### P25 · 即时成像（宝丽来）
- **拍摄故事**：一张刚拍出来的、还在显影的相纸。
- **器材**：即时成像相机 · 定焦 · 内置闪光 · 方画幅（1:1 或 4:3）
- **痕迹**：**低对比、灰雾** · 颜色偏移且不稳定（偏黄或偏青）· 四角暗角 · 边缘有药液不匀的痕 · **闪光灯是硬直闪（正面平光、红眼）**
- **运动**：固定
- **适用**：私密 · 纪念 · 瞬时 · 亲密关系 · **"拍下来"这件事本身作为叙事**
- **取舍**：**它的硬直闪会毁掉你精心设计的光位**——想控制光就别用 · **画质上限很低**，不能承载细节

#### P26 · 红外摄影
- **拍摄故事**：一台改造过的机器，看得见肉眼看不见的部分。
- **器材**：红外改造机身 · 红外滤镜（720nm 等）· 定焦
- **痕迹**：**植被变白或变粉** · **皮肤瑕疵淡化、静脉隐约**（近红外实况；**生成端易给随机红斑而非解剖可信血管，出现即弃**）· 天空变暗 · 白平衡完全失真 · 高光容易过
- **运动**：看叙事
- **适用**：异世界 · 恐怖 · 艺术 · 身体 · **另一种"真实"**
- **取舍**：**肤色被彻底改写**——要保留人物身份感就不用 · **颜色逻辑与写实冲突** → 必须**整场或整片统一**，不能局部用

#### P27 · 热成像
- **拍摄故事**：镜头只看得到温度。
- **器材**：热成像仪 · 定焦 · 伪彩（黑白热 / 铁红 / 彩虹）
- **痕迹**：**只有热信号，没有纹理** · 人体是亮块 · 玻璃会反射热辐射（"看穿"或"看错"）· 分辨率极低、边缘发虚
- **运动**：固定 / 缓慢
- **适用**：军事 · 搜救 · 恐怖（看不见脸的东西）· **机器视角**
- **取舍**：**它无法承载任何表演**（没有脸、没有表情）——只能用于"被机器观察"的叙事

#### P28 · 夜视仪
- **拍摄故事**：一个守夜的人透过夜视仪在看。
- **器材**：微光增强夜视仪 · 定焦 · 单目或双目
- **痕迹**：**整体绿色（单色）** · 强噪点（暗处最重）· 光源周围有 blooming 光环与拖影 · **视野被圆形遮罩** · 中心清晰、边缘模糊
- **运动**：跟随头部（有轻微摆动）
- **适用**：军事 · 恐怖 · 夜间追逐 · 主观视角
- **取舍**：**圆形遮罩是强特征**（一眼认出来）· **与"全知视角"冲突**——夜视＝有限的、被困住的视野

### 组四 · 非人持机（屏幕 / 机器之眼 / 合成来源）

> 组名注：本组统一特征是**没有"人持摄影机"这个动作**——P29/P32/P33 连摄影机都没有；P30/P31 有摄影机，但那是卫星与内窥镜这类机器之眼，不归人控制取景。

#### P29 · 屏幕捕获 / 录屏
- **拍摄故事**：**没有摄影机**——这些是从屏幕上截下来的。
- **器材**：无（屏幕录制 / UI 捕获）
- **痕迹**：**UI 元素、光标、分辨率与帧率的跳变** · 打字时逐字出现 · 窗口切换是硬切 · 像素级锐利（完全没有介质痕迹）
- **运动**：无（或 UI 的滚动与缩放）
- **适用**：当代 · 科技 · 界面叙事 · 消息对话 · 后台监控
- **取舍**：**它没有"摄影"的任何属性**——一旦用它，整片要接受"非摄影"的世界观 · ★ **画面内文字必须真实可读**，这与"AI 生成文字必崩"正面冲突 → **要真可读文字就走真录屏 + 后期合成，不要生成**

#### P30 · 卫星 / 地图俯视
- **拍摄故事**：一台在太空里的机器，垂直往下看。
- **器材**：卫星 / 高空平台 · 超长焦 · 正射（无透视）
- **痕迹**：**绝对垂直（没有透视收敛）** · 阴影方向暴露拍摄时间 · 分辨率到不了人 · 大气带来色偏
- **运动**：极缓慢横移 / 缩放
- **适用**：宏观 · 地理 · 冷眼旁观 · 战争 · 渺小
- **取舍**：**人在这个尺度上不是人**（个体被抹掉）· **想讲"具体的人"就绝不能用它**

#### P31 · 内窥 / 窥视
- **拍摄故事**：一台极小的机器，从缝隙里往里看。
- **器材**：内窥镜 / 管道摄像头 · 超广角 · 自带光源 · 圆形遮罩
- **痕迹**：**自带光源造成"手电筒"式中心亮、边缘黑** · 画面圆形 · 广角畸变 · 高噪点 · 前进时有规律的前后晃动
- **运动**：缓慢前进 / 旋转
- **适用**：身体内部 · 管道 · 通风口 · 偷窥 · 潜入
- **取舍**：**它天然带着"侵入"的含义**——用在非侵入场景会怪 · 圆形遮罩是强特征

#### P32 · 纯数字渲染（CGI）
- **拍摄故事**：**没有"拍摄"**——整幅画面是算出来的。
- **器材**：无（数位渲染）；可选"模拟某支镜头"作为第二层
- **痕迹**：**光滑、完美、无介质噪声（这是最大破绽）** · 需要**主动注入**不完美（模拟像差 / 噪点 / 颗粒）
- **运动**：不受物理限制——**但这本身会假**
- **适用**：科幻 · 不可能实拍的环境 · 抽象 · 概念演示
- **取舍**：★ **"太干净"是 CGI 的默认病**——必须主动叠缺陷层 · **与"人物真实"直接冲突**（只用于环境，不要用于人脸）
- **★ 与风格库的分工**（2026-09-17 补）：**P32 是"六轴取值"**（怎么把这一层弄得不完美）；**"整片由引擎实时渲染"是另一件事，属风格条目 `style-library-anthology.md` G06（第三系 · 工艺渲染）**——**两者常同时出现但不可互相代替**：选 G06 不等于自动获得 P32 的缺陷层，选 P32 也不等于片子就成了"引擎渲染风"。

#### P33 · AI 原生 / 无物理对应
- **拍摄故事**：**没有镜头**——这是梦、记忆、濒死、幻觉。
- **器材**：无（说不清是谁拍的）
- **痕迹**：**物理规则被有意违反**：透视不自洽 · 物体边界在融化 · 光线没有来源 · 空间在流动 · 时间非线性
- **运动**：**不受摄影机物理约束**（穿过墙、瞬间位移、多重曝光）
- **适用**：梦 · 记忆 · 濒死 · 精神错乱 · 意识流
- **取舍**：★ **它一旦出现，全片的"规则"就被打破了**——所以**只能用在"它本身就是内容"的时刻** · **绝不能让它进入写实场景**，那会毁掉整片的可信度

### 组五 · 特殊时间

#### P34 · 延时 / 时间压缩
- **拍摄故事**：一台机器架在那里，把几小时压成几秒。
- **器材**：三脚架固定 · 间隔拍摄 · 宽画幅
- **痕迹**：**云与影子高速流动** · 人群变成湍流 · **帧间跳动（不是连续运动）** · 光线连续变化（日落到大夜）
- **运动**：固定 / 极缓慢（滑动延时）
- **适用**：时间流逝 · 城市 · 建造 · **把"等待"拍成有意义的** · 建立场景的"常"与"变"
- **取舍**：**它跳过了"过程"**（只能表现趋势与结果）· **不能承载表演**（人的动作会被抽成碎影）

## 三、怎么用：三条取舍思路（不是"按场景查表"）

### 思路 1 · 先问"缺哪个维度"，再找包

**不要问**"我这个场景该用哪个包"（那会退化成查表）。
**要问**"这一镜缺的是什么"：

| 我缺的是 | 去哪个包 |
|---|---|
| **尺度感**（这东西有多大） | P18 航拍 · P30 卫星 · P22 微距（另一端） |
| **速度感** | P19 FPV · P34 延时（时间的另一端） |
| **沉浸感**（观众进到里面） | P20 穿戴 · P19 FPV · P23 鱼眼 |
| **疏离感**（观众被推远） | P21 长焦 · P30 卫星 · P18 航拍 |
| **"无法接近"的感觉** | P21 长焦 · P31 内窥 |
| **非人的视角**（机器在看） | P27 热成像 · P28 夜视 · P29 录屏 · P30 卫星 |
| **身体感 / 侵入感** | P22 微距 · P31 内窥 · P26 红外（静脉隐约） |
| **时间感** | P34 延时 · P24 移轴（像看模型＝时间被抽离） |
| **规则被打破** | P33 AI 原生 · P23 鱼眼 · P26 红外 |

### 思路 2 · 包可以只取一行

**跨包组合的合法用法**（`equipment-selection.md` §三）：

```
载体：P18 无人机的相机（广角 + 电子增稳）
光学：P22 的微距（贴近拍一个物体）
稳定度：完全固定
→ "一台悬停的机器，贴着拍一个东西" —— 三行来自三个包，仍然成立
```

**只要组合后讲的是同一个"拍摄故事"，就合法。**

### 思路 3 · 必查「取舍」栏，尤其是这三种情况

| 情况 | 为什么必须查取舍 |
|---|---|
| **你要承载表演或对白** | P22/P27/P30/P34 全都做不到——它们的尺度或光谱里没有"脸" |
| **你要观众相信"这是真的"** | P24 移轴（微缩感）· P32 CGI（太干净）· P33 AI 原生（违反物理）都会毁掉可信度 |
| **你要控制光** | P25 宝丽来（硬直闪）· P27 热成像（自发光）· P28 夜视（自带绿）——它们的光由器材决定，不由你决定 |

## 四、与既有体系的关系

| 项 | 说明 |
|---|---|
| **六轴定位** | 新包同样是"六轴的一组取值"，**不是新的轴**（`equipment-selection.md` §二） |
| **"一片一包"还成立吗** | 成立——但"包"可以是**跨包组合出来的那一组取值**，不必是 P01–P34 里的某一个整数编号 |
