## 运镜提示词的七段骨架（出自 Higgsfield Academy Prompt Bank，可直接套）

官方 Prompt Bank 的**每一条**运镜提示词都按这七段写，顺序固定。**这是"一条运镜为什么能锁得住"的答案**：

| # | 段 | 内容 | 为什么必须有 |
|---|---|---|---|
| 1 | **动作定义** | 一个动词（zoom in / dolly left / sweep pan…） | 只给一个动作，多给＝不稳 |
| 2 | **参数** | 方括号里的幅度、距离、速度 | 幅度不写，模型随机取值 |
| 3 | ★ **锁死了什么** | 明确写出"哪些东西在移动过程中**保持不动**" | **这是最容易被漏掉、也最关键的一段**——不写，模型在运动过程中把构图也一起改了 |
| 4 | **速度缓动** | 起步 / 中段 / 收尾的节奏 | 匀速＝机械感 |
| 5 | **构图变化** | 运动带来主体在画面里的比例或位置怎么变 | 不写，运动没有"结果" |
| 6 | ★ **结尾落点** | 镜头停下时画面停在什么状态 | 尾帧是下一镜的输入（LibTV 上先提取为 image 节点再作下镜首帧）；不写结尾＝尾帧不可用 |
| 7 | ★ **排除同族** | 列出同族的其他动作并逐一排除 | 不排除，模型在族内乱挑或混用两个动作 |

**设计原则（官方原话）**：**"运镜与场景分离，所以换掉画面，这条提示词依然有效。"**
→ 含义：**运镜句应该可以整体搬去别的镜头**。如果你的运镜句里写了具体的人物或场景，说明它没有分离成功。

**第 3、6、7 段是这份骨架的精华**，我们的模板已按此补齐（见单镜模板的【运镜】块；**板块规格与四相对应 → `block-camera.md` §2**）。

## 光比 → 读感（写光比之前先查这一行）

| 光比 | 读感 |
|---|---|
| **1:1 – 2:1** | 柔和 · 开阔 · 平静 · 商业 · **讨好** |
| **4:1** | **戏剧但仍可读**（写实剧情的安全区） |
| **8:1 及以上** | 严酷 · 阴郁 · 不祥 · 压抑 |

**只写四样**（写多的部分模型基本忽略）：① 光的方向 ② 阴影的密度 ③ **实用光源的动机** ④ **大气介质**（雾 / 烟 / 尘 / 雨 / 霾）。

**相邻镜的光比逻辑要保持**，除非剧情节拍有意改情绪。**三种连续性失败要在提示词里拦掉**：① 无解释地从硬逆光切到平正面光；② 色调无叙事原因地偏移；③ 同一段落里眼神光 / 剪影逻辑不一致。

## 后期特效层（独立成层，生成氛围的最后一步）

| 特效 | 写法 | 用在哪 |
|---|---|---|
| 大气透视 | `随距离增加对比度与饱和度逐步损失，越远越灰越暗` | 一切有纵深的场景 |
| 体积光雾 | `光柱中的浮尘清晰可见 / 地面上一层空调冷气的薄雾感` | 夜内景、有光源的场景 |
| 光线穿透 | `窗外城市光穿过雾气形成淡淡的光束（god rays）` | 有窗与雾的夜戏 |
| 高光处理 | `高光平滑滚降、渐进出白不裁纯白，过曝处仍带暖色；高反差边缘极轻的橙红光晕` | 一切发光体 |
| 调色方向 | `低饱和夜戏调色，阴影推向青绿，肤色保留暖棕` | 全片统一一次 |
| 颗粒 | `暗部有机银盐颗粒簇，暗部粗、中间调细`（**不写"加颗粒"**） | 全片统一 |

**纪律**：后期层只做氛围加法，不改变物理与叙事；与写实缺陷层冲突时以缺陷层为准（例：缺陷层要求死黑，后期就不加提亮雾）。

**填充来源**：光影段的用词从 `cinematic-look.md` 第四节的"光度三段式"取；质感段的颗粒与高光台词用第五节（`organic grain clusters in the shadows` / `gentle specular roll-off`，**禁写 "film grain"、"bright lights"**）；调色与颗粒方向从第三节的胶片参数库取（VISION3 500T 的暗部偏暖与红 halation / ETERNA 的低饱和平色调）。禁止项并入 `cinematic-look.md` **第十节**的 AI 漫剧黑名单（动漫/卡通/二次元/CG 动画/概念图/全画面过锐/硬截断高光/均匀数码噪点/云台般稳定/大平光/磨皮/8K 堆砌）。**本模板的公共层（量级 / 光有出处 / 高光颗粒 / 风险移除）逐字取自 `quality-layer.md`，与角色/道具/场景/批量任务五类共用同一套。**

## 用 Higgsfield 出片时（要点）

- 控制靠设置不靠句子：Genre / 灯光预设 / 运动预设 / 镜头 / 焦段光圈五项一次锁定跨镜不复述。
- 运动块与场景块分离；一条片段最多两个预设。
- 身份修改走图像编辑通道，只改"谁"不掺环境，否则整帧重生成导致闪烁。
- 成本纪律：720p 先测运动，确认再 1080p；每轮只隔离一个变量。
