# 电影打光理念（motivated light · 结果句可直接写进提示词）

> **何时读**：写光影段需要专业深度、想知道光该怎么设计时。**读完回哪**：回到 `tone-realism.md` 落地成句。

> 来源：Roger Deakins 五支柱（Occupy Cinematography / FilmLocal / eatsip365 / ReelMind 访谈整理）、ShotForge 提示词实践、Skyfall / Blade Runner 2049 / Sicario / Prisoners / No Country for Old Men 拉片分析。提炼为通用规则。

## 一、一句话内核

**他不给人物打光，他给环境打光，让环境照亮人物。**
（He lights environments, and lets the environment light the people.）
（**环境主语句怎么写（2026-09-30 补）**：把主语从"人"换成"房间"——`光先落在墙面与桌面上，人是被这层环境光顺带照亮的，脸上只有一小块最亮`；具体造法与五种柔光见 `light-quality-construction.md` §一。）

写提示词时，这句话等于：**先写光从哪来、怎么落在环境上，人物只是接受它的一部分。**

## 二、Deakins 五支柱（每条都能直接变提示词）

| 支柱 | 原文要义 | 提示词落地 |
|---|---|---|
| **1 有动机的光源优先** | 每一束光都必须属于场景世界（台灯、窗、火、屏幕、街灯）；无动机的光会把观众拉出画面 | 每个镜头必须能回答"光从哪来"。写具体：`画面里唯一的光是桌上那盏低垂的钨丝台灯`，而不是 `warm lighting` |
| **2 简单优先于复杂** | 用最少的灯完成；一个位置正确的光源胜过十二个互相争抢的 | 提示词里**只写 1–2 个光源**，其余全交给衰减与暗部 |
| **3 为脸曝光，不为测光表** | 读肤色，不读入射读数；脸曝光错了情绪就丢了 | `曝光优先保护面部：脸上有细节，背景可以掉进黑` |
| **4 先减光，再加光** | 用旗板、黑布、负补光加深阴影、控制溢出、制造分离 | `暗部不做补光`、`用负补光把脸的一侧压进暗部`（模型听不懂"负补光"就写"脸的另一侧完全没有光，沉进黑里"。**★ 2026-09-30 分级：保留暗部浓度、纹理看得清＝默认档；沉进黑里＝强分离档**——两种光比都对，按场次的分离需要选，写明即可，与 `light-quality-construction.md` 统一口径） |
| **5 不与场地对抗** | 找到场地已经给你的光，增强它而不是覆盖它 | `顺着这扇窗本来就有的光来拍，只做最小干预` |

## 三、四个签名词汇（可直接套的提示词片段）

**1. 明暗色温分离（chiaroscuro separation）**
暖色实用光源 vs 冷色环境光，脸坐在两个对立色温之间——《银翼杀手 2049》《边境杀手》的标志。
```
暖橙色的实用光源与冷蓝的环境光形成强烈分离，他的脸坐在两个对立的色温之间：
右脸是台灯的暖橙，左脸的暗部沉进窗外的冷蓝
```

**2. 单光源斜掠（single-source rake）**
孤独光源从低位 45 度斜掠，在带纹理的表面上拖出长影。
```
唯一的光从画面左下方约45度斜掠上来，在带纹理的墙面上拖出一道长而锐的影子
```

**3. 有机胶片质感**
暗场用 VISION3 500T，日戏用 250D（见 `cinematic-look.md` 参数库）。

**4. 空镜负空间（empty frame）**
孤独的小主体 + 大片空白，情感重量来自空。
```
他占据画面右下三分之一，左侧是整片暗下去的负空间
```

## 四、光的质量与方向（可执行参数）

| 维度 | 参数 | 写法 |
|---|---|---|
| 软硬 | 光源相对尺寸决定：大而近＝软（包裹、缓过渡）；小或远＝硬（锐影、明确方向） | `光很软，几乎没有影子，像阴天的大窗` / `光是硬的，影子边缘清晰` |
| 方向 | 侧逆勾轮廓、低角度拖长影、顶光压眼窝、正面平光最假 | `光从侧后方来，只勾出他的轮廓线，正面沉在暗里` |
| 高度 | 略低于视线＝不安；平视＝客观；高于视线＝压小 | `机位与光都略低于他的视线` |
| 光比 | 光比控情绪；低对比不等于没方向 | `低对比但方向明确：只有一侧被照亮，另一侧是深灰不是黑` |
| 负补光 | 先减后加 | `脸的另一侧不放任何补光，直接沉进背景的黑暗里` |

**关键纪律（摄影指导共识）**：`flat doesn't mean formless`——阴天可以低对比，但**必须保持单一清晰的主光方向**。

## 五、光源清单法（写每一镜前先过一遍）

能被写进提示词的光源类型（全部有动机）：
窗光（时刻与天气）· 台灯/落地灯（钨丝 2700-3000K【待核】此数值回一手源前不要当唯一答案——家用灯泡实测偏暖；工业标称 3200K 两口径并存，→ `light-quality-construction.md` §三）· 屏幕光（冷青，方向由屏幕位置决定）·
火（烛/炉，跳动）· 街灯与霓虹（外部，彩色）· 月光（冷，极弱）· 汽车灯（移动，扫过）·
安全出口指示牌（绿）· 电器指示灯（小点）

**每镜只允许 1–2 个主光源 + 1 个极弱环境光**，其余全部是衰减后的暗部。

## 六、六种最常见的"假光"（禁止项）

1. 无来源的补光（脸亮着，画面里找不到对应的灯）
2. 大平光（处处均匀明亮，无方向）
3. 处处补光（画面里没有黑）
4. 多光源同权（没有主次，光互相打架）
5. 光源方向与阴影方向不一致（光从左来，影子往左倒）
6. 人物比环境亮两挡以上（像贴上去的）【待核】此数值回一手源前不要当唯一答案

## 七、可复制句式（中英对照）

| 用途 | 中文 | 英文 |
|---|---|---|
| 单光源 | 画面里唯一的光是桌上那盏低垂的钨丝台灯 | the only light in frame is a single low-hanging tungsten desk lamp |
| 冷暗分离 | 暖橙实用光与冷蓝环境光形成强烈分离 | warm amber practicals against cold blue ambient |
| 斜掠 | 光从左下 45 度斜掠，拖出长影 | a single source raking low across the surface, long shadows |
| 无补光 | 脸的另一侧完全没有光，沉进黑里 | no fill on the other side, the face falls into black |
| 顺场地的光 | 顺着这扇窗本来有的光，只做最小干预 | working with the existing window light, minimal intervention |
| 曝光优先级 | 曝光优先保护脸，背景可以掉黑 | expose for the face, let the background fall to black |

## 八、与五段式协议的对接

光影段按此顺序写：**光源是什么（动机）→ 方向与高度 → 软硬与光比 → 人物受光面/暗面 → 环境衰减与暗部**。
写完自检一句：**这镜的光，能在画面里找到出处吗？**
