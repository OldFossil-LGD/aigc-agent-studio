# 图片反推提示词方法书（全库统一标准）

> **何时读**：拿到任何一张参考图、要把它反推成可复用提示词时。**读完回哪**：把结果写进对应风格的「三图反推卡」，再走《三图比对与内核提炼》那一步。
>
> **本册只给"怎么反推"，不给"该写什么"**——后者在各风格条目与 `shot-craft.md` / `block-playbook.md`。
>
> **★ 与本库既有纪律的关系**：本册的**证据分级**（Observed / Inferred / Unknown）与**双模型交叉**，
> 与库内 `governance-law.md` L4「凡数字必回一手源，核不到就标未证实或弃用」**是同一条纪律的两个面**。
> **"凭想象编"在这里是硬红线**——这正是《牌子 SIGN》逐镜拉片报告开头写明的：**没有一镜是凭想象编的**。

## §0 一条总原则：**反推不是写图说**

**"这张图里有什么"是图说；"这张图为什么长这样"才是反推。**

> 图说：`一个女人站在雨夜的街上`
> 反推：`中近景，机位齐胸略仰；主体在画面右三分之一，左侧留大片空；主光是右上方一块招牌（暖橙），
> 左后方有一道冷青边光把轮廓从背景里挑出来；湿地面把招牌反射成一条条被雨打散的竖亮带；
> 暗部偏暖褐不是灰；雨是斜向的白色短线，方向一致`

**判据**：**把反推结果里的所有形容词划掉，剩下的是不是还能指认"这是怎么拍/怎么画的"？**
不能 → 你写的是图说。

## §1 ★ 证据分级（**先分级，再动笔**）

**每一条观察都必须先归到三档之一**，不许夹带：

| 档 | 含义 | 例 | 处置 |
|---|---|---|---|
| **Observed 观察到** | **像素里直接可见** | `光从画面右上来` · `暗部偏暖褐` · `地面有竖向的亮反射` | 可直接写进提示词 |
| **Inferred 推断** | 合理但**不能从像素确认** | `用了柔光箱` · `85mm 拍的` · `调色参考了某部片` | **要写就标注为推断**；**落入提示词时改成可见效果** |
| **Unknown 未知** | **从这张图无法判定** | 具体机型 / 具体灯位功率 / 是否后期加了贴图 | **写「未知」，不许猜** |

**两条硬规则**：
1. **"推断"不许冒充"观察到"**——最常见的滑坡是：`用了某种柔光`（推断）→ 写成 `柔和的光线`（看起来像观察）。
   **修法：把推断翻译成它造成的可见效果**（`光线没有硬边，明暗交界是一条比较宽的过渡带`）。
2. **一条观察若三个来源对不上 → 标「存疑」，不要挑一个当真**（《牌子 SIGN》拉片报告的做法）。

### ★ 双模型交叉（**性价比最高的一步**）

**同一张图、跑两个不同的视觉模型、diff 两份输出**：
- **两者一致** → **可靠信号**
- **两者不一致** → **这一项本身就是模糊的**，由你（人）裁定，不许自动采信任一方

> 来源实测提示：**视觉语言模型擅长 mood / 色板 / 镜头感 / 风格**，
> **弱于精确几何与测量**——所以**光位方向与构图边界一定要用眼再验一遍**，不能只听模型说。

## §2 七层反推表（**逐层填，不许跳**）

| 层 | 问什么 | 反例（不合格） |
|---|---|---|
| **1 构图与画框** | **画幅比** · 主体落在哪条三分线 · 地平线/消失点在哪 · 前景/中景/背景各是什么 · 留白在哪、多大 · 主导的视觉方向 | 只写"构图好" |
| **2 主体** | 类型 · 剪影 · 姿态 · 表情（如有人） · **可复现的辨识特征** · 占画面多大 | 写具体的人名/角色名（→ `quality-layer.md` 第 4 条：IP 名不进提示词） |
| **3 环境与场景状态** | **地点** vs **状态**要分开——`城市街道`是地点，`雨后的城市街道、蓝调时刻、人少、招牌反光、薄雾`是状态 | 只写地点 |
| **4 光** | **主光方向** · 软硬 · 补光/负补光 · 轮廓光 · 光比 · 色温 · **画面里有动机的光源是什么** | 写"戏剧性的光" |
| **5 镜头与光学** | 广角/标准/长焦**的观感** · 机位高度 · 视角 · 景深 · 焦点落在哪 · 透视压缩 · 有无运动模糊 | 假装知道具体焦段（→ 标推断；写观感而不是数值） |
| **6 材质与质感** | 列出**表面**与它**对光的反应**：拉丝金属 / 哑光布 / 釉面陶瓷 / 皮肤 / 颗粒 / 灰尘 / 水汽 / 划痕 | 只写"有质感" |
| **7 排除项与失控点** | **这一张图特别容易漂走的是什么**（多了人 / 出现文字 / 换了光向 / 皮肤被磨平 / 构图被居中） | 堆一串通用负向词 |

### ★ 第 4 层是杠杆最大的一层

> **"光在做什么？"是反推里产出最高的一问。**
> 多数自动反推工具会说 `夜晚、街灯` 就停了；
> **但"暖冷两路光的混合"往往正是这张图之所以成立的一半**——
> 只有刻意追问"光在做什么"才抓得到。

**写法纪律**：光要写成**关系**，不写成形容词。
❌ `戏剧性的光` → ✅ `硬的冷青轮廓光从背后打来，柔和的暖橙主光在相机左侧，暗部补得很轻`

## §3 提示词堆叠顺序（**固定，便于改错**）

```
① 格式与构图  →  ② 主体  →  ③ 动作或姿态  →  ④ 环境  →  ⑤ 光  →
⑥ 镜头与焦点  →  ⑦ 材质与质感  →  ⑧ 情绪与收尾  →  ⑨ 排除项
```

**为什么固定顺序**：**出了问题时改对应的那一块就够了**，不必整条重写。
构图错了 → 改 ①；油亮 → 改 ⑤⑦；跑题 → 改 ②④。

## §5 ★ 一条反直觉的提醒：**反推工具只当草稿**

## §6 ★ 三图比对与内核提炼（**第 4 步的执行框架**）

**三张图各自反推完，才能进入这一步。顺序不能反**——先逐图（§2 七层），再横向（本节）。

### 6.1 三张图怎么挑（**第 3 步的判据**）

**目标是"三张之间差异尽量大，但都最能反映该风格的本质"**——这是一对张力，判据是：

| 要拉开的三条轴 | 每张各占一端 |
|---|---|
| **景别** | 极特写 / 中景 / 远景（**三张尽量不重复景别**） |
| **场景与题材** | 室内 vs 室外 · 人 vs 物 vs 空景 · 日 vs 夜 |
| **色调** | 暖 / 冷 / 中性（**至少两极**） |
| **人物** | 有脸 / 无脸（背影·剪影）/ 无人 |

**合并规则**：**只要三张里找得到"同一件东西"，那个东西就是内核的候选**；
**如果三张的差异大到看不出共同点，那是选图失败（不是风格没有内核）**。

### 6.1b ★ 三轴的例外：**当风格本身是单色时，改由"光"承担差异**（2026-09-16 实测补）

**实测（`C01 赛博朋克`）**：该族**本身就是单色化的**——整幅被青绿染进去，暖色只留给肤色。
**于是"色调拉开"在这一条根本做不到**（三条候选帧全是绿的），**而"景别拉开"也不够**（中近/极特写/中景）。

**修法**：**差异改由"光位与光比"承担** ——
`① 均匀环境光` · `② 浅景深自然光（焦外）` · `③ 单侧硬光 + 极暗大面积纯黑`。
**判据一句话：色调拉不开就拉光——"均匀 / 侧硬 / 逆"这三种光在任何风格里都能凑齐三档。**

### 6.1c ★ 取图质量：**`backdrops` 里混着宣传剧照**（2026-09-16 实测）

从 TMDB `images/backdrops` 拿到的图，**并不全是正片帧**——里面混有**宣传剧照（publicity still）**，
**打光比正片均匀、背景更干净**。

**处置（用 §1 的证据分级）**：
- 见到"**打光过匀、没有环境光痕迹、背景被刻意留空**"的 → **登记为「推断：疑似宣传照」**，
  **不作为内核证据**，只作构图参考。
- **正片帧的识别特征**：有**环境光的痕迹**（实景光比、色温不统一）、有**焦外或运动模糊**、
  皮肤/材质**不被修饰**。
- **首选正片帧**；三帧里**至少两张是正片帧**，内核才立得住。

### 6.1d ★★ 取图前必做：**核对"命中的是不是这部片"**（2026-09-16 实测踩到）

**实测**：按中文片名从 TMDB 取图时，**搜索会返回错片**——
`C81《浩劫》（Shoah，1985 拉兹曼）` 命中的却是一部**海上钻井平台火灾**片，8 张图**全部无关**。
下载器只取搜索结果的第一条，**没有任何校验**。

**三条处置**：
1. **读图者就是错片校验者**（**这是最有效的一条**）：写反推的人**在反推之前先判断"这 8 张像不像那部片"**。
   不像就在【存疑】里标 `[推断：疑似错片，请核对目录]`，**并停止该条的内核提炼**。
   → 反推提示词里必须带这一问，**不能省**。
2. **中文名不安全，优先用"英文原名 + 年份"**：`C35 指环王 → The Lord of the Rings 2001`、`C60 刺客聂隐娘 → The Assassin 2015`。
3. **★ 别指望自动核验**：本库试过用脚本比对"命中标题与年份"，**失败**——
   TMDB 搜索页的结果结构用正则抓不稳（那一次返回大量"年缺失"，等于没验）。
   **结论：错片校验交给"读图的人"，不要交给正则。**（真正的核验是"图里有没有那部片"。）

> **判据一句话**：**图不像那部片，就当这条没做过。**

### 6.1e ★ 非电影参照物（画作 / 文物 / 纹样 / 设计）：**要"本体平扫描"，不要"展厅照"**（2026-09-16 实测）

**取图链路**（实测可用，A/E/F/G 四卷共 85 条走这条）：
- **维基共享 Commons**（MediaWiki API，无需 key，覆盖最广）→ **主源**
- **芝加哥艺术博物馆 AIC Open API**（有 `is_public_domain` + IIIF）→ 补源
- **大都会 Met Open API**：接口稳，但**近现代作品多标非公有领域、不给图**（实测莫奈 36 命中、`primaryImage` 全空）→ 不作主源

**★★ 三条实测的坑**：
1. **中文检索词在 Commons 命中率极差**（`莫奈 日出·印象` → 6 条无关结果：汉字特征、百科辞典）；
   **英文检索词命中 81 条、首条即原作**。→ **A/E/F/G 一律用英文检索词。**
2. **Commons 的 `thumburl` 结尾带查询串**（`...jpg?utm_source=...`）→ **判扩展名不能用 `$` 锚定行尾**，
   否则全部被过滤、误报"无结果"（**实测踩到，白跑一轮**）。
3. **★ 拿到的常是"博物馆装裱照"**：带**画框、展墙、射灯反光**，甚至隔着玻璃。
   **做风格分析要的是"画作本体的平扫描"，不是展厅照**——这是非电影版的"宣传剧照"问题。

**处置（与 §6.1c 同一把尺）**：
- **展厅照的识别特征**：**可见画框或展墙**、**画面边缘是墙或玻璃**、**有射灯/窗的高光反光**、**透视是斜拍的**（不是正视平扫描）。
- 见到 → 标 `[推断：展厅照，非本体]`，**不作内核证据**；三帧里**至少两张是本体平扫描**，内核才立得住。
- **提纯办法**：优先取标题含 `Google Art Project` / 馆藏高清项目的文件，或**改用 AIC 的 IIIF 图**（其图是干净复制件）。

### 6.1f ★ 取图的前一站：**平台自带的"拉片 / 视频解析"**（2026-09-20 补）

- **是什么**：有的创作平台（**LibTV**）带"**一键拉片 / 视频解析**"——**贴一个视频链接，自动拆出故事板**【拟订 · 第三方教程口径，未实测。**★ 2026-09-28 补充：`analyze_video` 不在我方 MCP 的 48 工具表内（属平台 Agent 侧工具）；**我方侧最接近的是 `inspect_media`（媒体理解与分析），**是否为等价替代尚未实测**——故本条维持"未实测"，不升级为已核事实】。
- **接在哪**：它替掉的是 §6.1c–§6.1e 里的**人工截帧**那一半；**产物仍要过 §6.1d 的"命中的是不是这部片"核对**——**自动解析同样会混进宣传照与错片**。
- **一条纪律不变**：**自动化只解决"拿到帧"，不解决"帧够不够格"**——三轴规格、双模型交叉、覆盖率矩阵照走。
- **未核**：产物是否带时间码、能否按景别指定（**未实测，不许当结论**）。

### 6.2 剥离题材的三步（**这一节是第 4 步的核心动作**）

1. **列出三张各自的"题材层"**（谁、在哪、在做什么）→ **整列划掉**
2. **列出三张各自剩下的"语言层"**（构图关系 / 光的关系 / 色彩关系 / 材质反应 / 运动处理）→ **求交集**
3. **交集里若只剩抽象形容词（"高级""压抑"）→ 没提炼出来**；**必须是可执行的关系句**

### 6.3 内核三分栏（**统一输出格式**）

| 栏 | 写什么 | 判据 |
|---|---|---|
| **视觉语言** | 构图语法 · 光位逻辑 · 色彩结构 · 材质与痕迹 · 镜头与画幅（**全是关系句**） | 换一个题材，这套语言照样成立 |
| **叙事气质** | 它靠什么让人相信 · 与观众的距离（介入/不介入）· 幽默或残酷的方式 | 能说出"它为什么这么拍" |
| **情绪基调** | 情绪的上限与下限（**它从不做什么**，比"它做什么"更有信息） | 比如"从不激昂""从不给正面特写" |

### 6.4 一个真跑过的示范（《牌子 SIGN》三帧 · 2026-09-16）

**选图**（三张来自同一部片的不同段，景别/场景/色调全拉开）：极特写标牌 · 中近景戴帽禁示牌（有虚焦前景）· 室内外分割的中景（暖橙人物 vs 冷蓝街区）。

**题材层（划掉）**：一块黄色标牌 / 一个人抱着狗看窗外 / 一个禁烟符号。

**语言层（求交集）**：
- **色彩**：**黄 × 深蓝（青）的互补对撞**；**黄永远只出现在"被注意的那一个东西"上，且面积很小**；环境是低饱和的灰蓝、褐灰
- **明暗**：**高对比**；环境压暗，黄色块是全画面唯一的高亮区
- **构图**：**框内框**（标志的形状 · 窗框 · 圆形）＋ **前景或背景有虚焦遮挡**
- **材质**：**没有一处干净的表面**——划痕、污渍、垃圾、旧墙；做旧是全局的
- **光**：**色温不统一**（暖室内 vs 冷室外、街灯 vs 天光）——**"两路色温打架"是它的常态**
- **景深**：浅到中，总有一层被虚掉

**内核（三分栏）**：
| 栏 | 内容 |
|---|---|
| **视觉语言** | 高对比双色（黄 / 深蓝）＋低饱和环境；黄只在小面积上、且总落在"规则/标识"那件东西上；全局做旧不留干净面；框内框 + 一层虚焦遮挡；光允许两路色温同时存在 |
| **叙事气质** | 用"规则与标识"和"失序"对撞来产生冷幽默；摄影机**不介入**——它旁观，不做评判 |
| **情绪基调** | 上限是荒诞，**下限是"从不激昂"**；不给正面特写、不给情绪爆发 |

> **这个示范证明了什么**：**三张题材完全不同的图，剥掉题材后确实收敛到了同一套可执行的语言**——
> 而且这套语言**换一个题材照样成立**（把标牌换成一份文件、把窗框换成车门，语言不变）。
> **这就是"内核"的判据：换掉题材它还在。**

## §7 统一重写结构（**第 5 步的模板 + 达标判据**）

**每个风格重写后，按这个顺序落盘**（与风格库现行的十一字段对接，新增前两块）：

```
### <编号> · <风格名>
**参考片**：<片名>（**全库不重复**）｜ **选它的理由**：<一句话，说它为什么最契合>
- **三图反推**：① <景别>：<该帧的可复用提示词> ② … ③ …（各自 ≤3 行，格式符合 §3 的堆叠顺序）
- **内核三分栏**：视觉语言 / 叙事气质 / 情绪基调（§6.3 的三栏，**关系句**）
- 识别 / 核心视觉 / 色彩光影 / 构图材质 / 参考作品 / 适用场景 / 叙事氛围 / 可写句式
- ★ 质感与痕迹 / ★ 最容易被写歪成什么
```

### 7.1 ★ 达标判据（**任一不过 → 退回重做，不许带病往下走**）

| # | 判据 |
|---|---|
| 1 | **参考片在全库唯一**（跑一遍全库去重脚本，不凭记忆） |
| 2 | **三张图景别不重复**，且覆盖 ≥2 种色调、≥2 种场景类型（**单色风格豁免**：色调拉不开时按 §6.1b 改由光位与光比承担差异） |
| 3 | **每张图的反推七层齐全**（缺"光"或缺"构图"→ 退回） |
| 4 | **内核是关系句，不是形容词**——把形容词划掉后仍能指认"这是怎么拍的" |
| 5 | **内核经得起"换题材测试"**：换一个题材，这套语言照样成立 |
| 6 | **没有 IP 名进提示词**（片名只在"参考片"那一行，不进可写句式） |
| 7 | **改完跑门禁**：`audit_prompt.py index` · `ai_smell_check.py --inline` · **文件 ≤300 行** |

### 7.2 ★ 动笔前必须先做的一件事（**否则写到一半必然返工**）

**247 条全量重写会把 15 卷全部顶穿**（**库里已有多份接近或顶到 300 行**——**这个数每改一次就会变，故不写死：要实测就跑 `audit_prompt.py index --headroom`**）。
**必须先按拆卷规程定"拆成几份、按什么切"，再动笔**——
拆的是**结构性内容**（卷首规范、索引、认卡），**不按编号切条目**（→ `pitfalls.md` §三 的拆卷先例）。
