# 板块写作手册（每个板块：该想什么 · 怎么落笔 · 模型读不读得懂）

> **何时读**：**写镜头提示词之前**（配合 `shot-craft.md` 的层序使用）。⚠️ **本文只覆盖镜头**——**资产提示词（角色 / 道具 / 场景 / 批量）的板块结构完全不同，看 `block-playbook-asset.md`（9 块）**。
> **分工**：`shot-craft.md` = **格式与规范**（层序 / 五段协议 / 模板 / 六条硬规则 / 参数表）；**本文 = 每个板块的"思考 + 落地"**（该想什么、写哪一句、模型能不能懂）。**本文不重复深度内容**，每块末尾给出源头文件。
>
> **★★ 这里的「15 个板块」是思考清单的编号，不是写作顺序——两者数字不同是设计，不是不一致。**　**★ 12 块的接口规格（功能 / 目标 / 输入 / 输出 / 依赖 / 边界 / 约束）不在本文件 → `references/block-spec.md`**
> **写作顺序与块数只以 `shot-craft.md` 模板为准（全片通用 3 块 + 本镜专属 9 块 = 12 块）**。
> **为什么故意不合并**：把【人物表演】【物理反馈】拆成独立块，是为了**逼你把这两件事想过一遍**；落笔时它们要**并进【人物与环境】与【时间线】**（否则提示词会碎）。**想的时候拆开、写的时候并拢。**

---

## 怎么用这份文件（三步）

```
① 逐块答"写之前的思考" —— 答不出的块，就是上游没想清（回 direction-reasoning.md）
② 照"可抄句式"落笔 —— [ ] 换成这一镜的内容，句子结构不动
③ 过"模型读不读得懂" —— 有 ❌ 就改，改完再审下一块
```

**为什么逐块做**：**一块写歪，后面全歪。**（最常歪的三块：**光位**（写成了摄影棚动作）· **时间线**（一个相位塞了三件事）· **风险移除**（写成了否定句））

## ★ 两种多镜整合方式（**选一个，别混**）

| | **A · 全局 + 分段镜**（默认） | **B · 逐镜全板块** |
|---|---|---|
| 结构 | 全片块写一次 + 每镜**只写【时间线】【摄影机】等镜级块** | **全片三块写一次**（标"每一镜逐字复用"）**+ 每镜各带完整的本镜九块** |
| 长度 | 短 | **约为 A 的 2–3 倍** |
| 自足 | 镜不自足（改一镜要看全局） | **每镜的本镜部分自足**（只依赖写在上面的全片块） |
| 适合 | 一次投喂整条、镜间差异小 | **一条投喂，但每镜都要写全**（镜间差异大时用） |
| 风险 | 镜间易串味 | 长度增加；**全片块若每镜各抄一遍（＝没整合）就会稀释注意力** |
**判据一句话：这一镜与别镜的差异大不大？** 差异小 → **A**（只在镜级块上写不同）；**差异大、每镜都得写全 → B**。
**⚠️ 无论 A 还是 B，全片三块都只写一次**——**"分成几条来写"是交付形态问题，不是把全片块抄 5 遍**（库里铁律：交付一律整合式，一段可直接粘贴的提示词，绝不拆碎片）。
**只有"片一投 / 要能单独返工某一镜"时**，才把每镜做成**独立文件**、各自带全片块（此时互不干扰，重复也不是问题）。
**A / B 都是"一条整合提示词"**，区别只在每镜写多写少。
**B 的两条硬约束**：① **只有最后一镜写【结尾落点】**，中间镜写【过渡压力】（接口状态）；② **单镜只装一个连续动作**（**秒数不写进提示词**，由模型自己分配）——**动作相位越少越稳**（1.5–2.5 秒后连贯性开始衰减，所以一个相位装不下两件事）。

> **B 的真正用法是"片一投"**：若 5 片是**一次性投喂**的，"每片自足"这个好处根本用不上——用 B 就要走 **N 次独立任务**（各自带首帧；首帧/首尾帧/全模态参考**三选一互斥**）。**实测样本**：牛仔对决 5 秒 / 5 片（工作区 `验证_video/牛仔对决_5秒_逐秒14板块.md`，**旧版按秒写，已废除**）。
> **★ 写作顺序以 `shot-craft.md` 模板为准**（见本页开头的「15 块＝思考清单」说明）：**先写「全片通用」三块**（【后期特效】【统一提质层】【风险移除 + 禁止出现】），**再写「本镜专属」九块**（本镜目的 → 过渡压力）。
> 理由：全片块**一改就全片断**，写在最前＝**每次复制时不会忘改**；本镜块每镜都不同，跟在后面一眼能分清"哪几句要改"。
> **代价**：全片块会把【人物与环境】【光位与影调】推后、**位置权重下降** → 所以**全片三块要写紧凑**（去解释，只留可执行项），**别让它们成为最长的部分**。

## 一、通用纪律（对每一块都成立）

| 纪律 | 说明 |
|---|---|
| **具体名词覆盖空洞词** | 无"电影感 / 震撼 / 精致 / 高级感"——全部换成具体器材、动作、材质 |
| **"去做"还是"去画"** | ★ 判断每一句：**这个动作只有人剧组能做 → 删；这个结果模型画得出 → 留**。（`light-quality-construction.md` 卷首对照表） |
| **块内纯净** | 提示词块里**只放提示词**——注释、`（改成你的…）`、`*可选*` 一律不许（**块内一切都会被当提示词执行**） |
| **数字必须写出来** | 幅度、秒数、距离、光比、比例——**不写就是让模型随机取值** |
| **每块只说一件事** | 一块里并列两件事，模型会只做其中一件（且通常是错的那件） |

## 二、15 个板块逐个过

### 板块 1 · 风格标签行 + 时长画幅

- **回答什么**：这一条是什么规模、什么调性
- **写之前的思考**：① 时长多少（**与节拍表秒数一致吗**）② 画幅（由方案包定，还是由命题定）③ 3–6 个标签是什么
- **必需元素**：**3–6 个标签（用 `|` 分隔）+ 时长 + 画幅** —— 缺标签，风格会被稀释
- **可抄句式**：
  ```
  分镜头脚本，[单人单镜/多人单镜]，时长[N]秒，画幅[16:9 / 21:9（写 2.39:1 也正确——落地取最接近的 21:9）]，[风格槽——**写技法名词句，不留「写实电影/电影感」**]。
  [标签1] | [标签2] | [标签3] | 无配乐
  ```
- **模型读得懂**：✅ 标签串务必**放在最前**（位置最靠前 = 权重最高）；❌ 用一段散文描述风格（会被稀释）
- **源头**：`shot-craft.md` 六硬规则第 1 条 · `style-library.md`（挑编号）

### 板块 2 · 本镜目的

- **回答什么**：这一镜为什么存在
- **写之前的思考**：**三选一以上**——改变人物情绪 / 实质推进动作 / 施加戏剧压力。**三项都答不出 → 这镜应当删掉**，不要靠"好看"留着
- **必需元素**：一句话 + 一个动词
- **可抄句式**：`【本镜目的】[改变人物情绪 / 实质推进动作 / 施加戏剧压力]：[具体情况]`
- **模型读得懂**：这一块**主要是给创作者自己校准用的**（模型用得少）——**但它决定了后面所有板块的取值**，所以不能省
- **源头**：`shot-craft.md` 模板 · `shot-orchestration.md`（唯一信息）

### 板块 3 · 镜头规格

- **回答什么**：什么机器、什么镜头、什么景别
- **写之前的思考**：① 焦段（**广角=环境 / 标准=客观 / 长焦=压缩隔离**）② 光圈（**浅景深=私密主观 / 深景深=环境交代**）③ 机位高度（**略低=压迫 / 平视=客观 / 略高=弱小**）④ 观察视角
- **必需元素**：**焦段 + 光圈 + 机位高度 + 视角 —— 每一项都要能说出"因为…所以…"**（说不出就是在套模板）
- **可抄句式**：
  ```
  【镜头规格】[变形宽银幕/球面]镜头，等效约[N]毫米，光圈f/[N]（[景深效果]），
  机位高度[平视/略低/略高]，观察视角[斜后方45度/正面/肩后]，机位距[主体]约[N]米。
  ```
- **模型读得懂**：✅ **毫米数模型认识**，但要**补一句视觉效果**（"空间被夸张 / 自然 / 被压缩"）——**只写毫米数，模型可能只取其一**
- **源头**：`shot-craft.md` 镜头规格参数表 · `equipment-selection.md`（包定画幅与痕迹）

### 板块 4 · 构图

- **回答什么**：东西摆在画面哪里
- **写之前的思考**：① 主体在哪个三分之一 ② 引导线是什么、引向哪 ③ 哪边留负空间 ④ 前景遮挡是什么 ⑤ 主体占比 ⑥ 水平线在哪
- **必需元素**：**把位置写成指令，不靠感觉**（"画面很美"不可执行）
- **可抄句式**：
  ```
  【构图】[主体]占画面[左/右]三分之一；[桌沿/走廊/窗框]形成一条[水平/垂直]引导线，
  把视线引向[哪里]；[方向]留出[暗部/虚化]负空间，给[元素]呼吸；
  前景[右下/左下]角允许[物件]以虚焦状态入画一角；
  [主体]占画面高度约[比例]；[水平线]保持在画面[上/下]三分之一处且水平。
  ```
- **模型读得懂**：✅ **全是参数**——这一块是最好写的一块，**照抄结构即可**
- **源头**：`shot-craft.md` 构图指令层 · `storyboard-frame.md`（板块一与它必须一致）

### 板块 5 · 人物与环境

- **回答什么**：谁、在哪、有哪些东西
- **写之前的思考**：① **身份锚点句**（跨镜**逐字复用**，永不改写）② 场景物件两三件，**每件具体到材质与状态** ③ 容斥句 ④ **瑕疵各 ≥2 处**
- **必需元素**：锚点句 + 具体物件 + 容斥句（"画面里只有他一个人"）+ 瑕疵
- **可抄句式**：
  ```
  [身份锚点句——年龄/脸型/发型/疤痣标记/服装/随身物]。
  他[位置与姿态]，[关键道具与接触关系：谁的手、握在哪、接触面]。
  画面里只有他一个人，[镜面/窗玻璃]倒影里没有人。
  [场景：两三件具体物件 + 生活痕迹]
  ```
- **模型读得懂**：✅ **物件要具体到材质与状态**——"废弃场景"❌ /"剥漆的窗框、地上一层灰、墙角一只翻倒的塑料凳"✓
- **源头**：`character-depth.md`（三层+矛盾）· `character-continuity.md`（五条线）· `asset-consistency.md`（参考图纪律）

### 板块 6 · 光位与影调 ★（最容易写歪的一块）

- **回答什么**：光从哪来、什么性质、亮暗怎么分
- **写之前的思考**：① 光源**几个、各自出处**（动机）② 光位（角度——**结果**，可直接写）③ **光比**（情绪：4:1 戏剧但可读 / 8:1 严酷不祥）④ **曝光保护谁** ⑤ **哪面不补光** ⑥ 有没有介质（雾/烟/尘/雨）
- **必需元素**：**1–2 个有动机的光源 + 方向 + 光比 + 曝光保护对象 + 不补光的一侧**
- **可抄句式**：
  ```
  【光位与影调】画面里只有[一处/两处]光源：[光源1]，[冷暖][色温]，从[方向]来；
  [光源2]…。光比约[N]比1；曝光优先保护[部位]；[哪侧]直接沉进暗部，不放补光。
  [介质：随距离对比度与饱和度逐步损失 / 光柱里的浮尘清晰可见]
  ```
- **模型读得懂** —— **这一块的判据只有一句**：
  - ✅ **写"结果"**：`光位 45°` · `逆光` · `半张脸` · `墙上只有一条影子` · `暗侧完全没有补光但纹理照样清楚`
  - ❌ **写"动作"**：`把灯挪到 45°` · `加柔光纸` · `关掉一路` · `把 fill 开大`——**模型做不到，只会随机给你一张图**
- **★ 还有一条**：**光位决定"看得见什么"**——毛孔要斜射、绒毛与次表面散射要逆光、高光要斜角；**这四样在正面平光下全隐形**（→ `skin-realism.md` §1.4）
- **源头**：`tone-realism.md`（写实缺陷层 + 人物光影块）· `skin-realism.md` §1.4 · `light-physics.md`（色温标度）· `light-quality-construction.md`（柔光五造法）

### 板块 7 · 时间线

- **回答什么**：这一镜里发生什么（**按动作相位写，不写秒数**）
- **写之前的思考**：① **分几个动作相位**（起始 / 触发 / 主动作 / 反应与呼吸 / 定格）② **每个相位只有一个动作** ③ 画外声触发点在哪 ④ **相位顺序连贯，不跳、不重**
- **必需元素**：动作相位 + 每相位一个动作 + 画外声触发 + 落定状态
- **可抄句式**：
  ```
  时间线：起始：[起始姿态与动作]；触发：[画外触发事件]（声音后期加入），[可见反应 + 精确幅度]；
  主动作：[准备→接触→落定]三个阶段按顺序写全；反应与呼吸：[落定状态]；定格：[静止锁定]。
  ```
- **模型读得懂**：
  - ✅ **秒数由模型自己分配**——**写死秒数等于把它的节奏钉死**，且一改就要全文重算（返工最贵的那类改动）
  - ❌ **秒数写进提示词**（本库已定：**只写动作相位**；总时长写在首行，那是平台硬约束）
  - ❌ **"又抬头又转身又说话"——排不出来**（一个相位只写一件事）
  - ❌ **写"他开始打"的过程**——模型拍"**是何**"，不拍"**成为何**"：要写角色**已在**动作中（半空中的拳、已经开口骂到一半）
- **源头**：`shot-craft.md` · `motion-control.md`（动作五段链 / 拍序列）· `physical-feedback.md`（因果顺序）

### 板块 8 · 人物表演

- **回答什么**：他的脸、眼、呼吸在做什么
- **写之前的思考** —— **三问 + 一补**：① 他此刻**想让人看见什么** ② **身体在哪背叛他**（**只给一个通道**）③ 他**用哪里使劲克制** ④ 补：**当下不允许做的事**（`他抬手想扶她，手抬到一半，改成插进兜里`）
- **必需元素**：**四个可见通道（眉 / 眼 / 嘴与下颌 / 呼吸与重心）+ 微动节奏不均匀 + 每两秒一次眨眼 + ★ 眼睛必须单独写**
- **可抄句式**：
  ```
  眉——[舒展/皱起/一高一低]；眼——[眼睑开合 + 视线看向哪 + 何时移动]；
  嘴与下颌——[嘴角方向/嘴唇开合/下颌是否收紧]；呼吸与重心——[快慢深浅 + 重心往哪偏]。
  微动节奏不均匀：快一下、停一下、再动；每两秒有一次自然的眨眼；视线有一次小的游移再回到目标。
  ```
- **模型读得懂**：
  - ✅ **肌肉动作**：`下颚线绷了一下` · `眼睑下端绷紧`
  - ❌ **情绪词**：`他很紧张` · `她愣住了`——**模型读不懂情绪词，只有形变可执行**
  - ★ **死眼是 AI 表演的头号破绽**：没写眼睛 = 一双盯着不动、亮得像玻璃珠的眼睛（`performance-vocabulary.md` 第二节，**不可选**）
- **源头**：`performance-craft.md`（分诊 / 破假四工具 / 三区同拍）· `performance-vocabulary.md`（眼生命六条 / 微节拍词表）· `character-depth.md`（三层+矛盾）
