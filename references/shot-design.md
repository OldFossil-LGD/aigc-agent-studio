# 分镜的「设计感」：**调度装置 · 视觉母题 · 怎么不直白**

> **何时读**：**排完镜、觉得"单镜都对但很直白/像 PPT/没有设计感"时** · 定全片视觉语法之前 · 同一场戏抽卡多次都"摆拍感"时。
> **读完回哪**：回 `shot-linkage.md`（镜与镜之间：覆盖/切点/呼应）· `staging-craft.md`（镜内人物调度）· `shot-craft.md`（12 块怎么写）。
> **★ 本册补的是一条真空**：全库扫描——`三角调度` / `Z轴` / `视线引导` / `视觉主题` / `母题系统` **各 0 命中**；`视觉母题` 仅 6 册、`重复构图` 3 册（薄）。**"镜内怎么摆人"有了（`staging-craft.md`），"镜间怎么接"有了（`shot-linkage.md`），但"这一镜有没有设计"没有词。**

## §1 ★★★ 地基：**平均注视约 280 毫秒**

**硬数据**：人看一张新画面，**先要花约 0.28–0.3 秒**（初始扫视延迟约 285 ms）**才能把注视点落到"该看的地方"**；
视线**平均每次停留约 280 ms** 然后跳向下一点。

**→ 三条推论（本册全部内容的根）**：
1. **★ "设计感"不是审美，是功能**——构图的任务是**在不到 0.3 秒内把视线交到故事关键点上**。
   **观众不是在欣赏，是在找**；找不到，他自己在画面里乱逛（＝"看不懂""注意力散了"）。
2. **★ 一镜只能有一个落点**——**两个落点 = 0 个落点**（视线来回跳，那 0.3 秒就白花了）。
3. **★ 落点靠"对比"造，不靠"位置"造**——**把东西放在哪儿不重要，让它在哪儿"跟别的不一样"才重要**。

**落点制造器（强度从高到低，照这个挑一个）**：

| 制造器 | 做法 | 强度 |
|---|---|---|
| **人脸优先级** | 画面里有人脸 → 视线**几乎自动**先到脸 | **最高（近乎无条件的生理倾向）** |
| **运动** | 唯一在动的东西 | **极高** |
| **亮度对比** | 最亮处（或唯一的高光点） | 高 |
| **清晰度对比** | 唯一在焦平面上的 | 高 |
| **色彩孤立** | 唯一暖色 / 唯一高饱和（见 `color-narrative.md`） | 中 |
| **位置**（三分点 / 中心） | 传统构图法 | **最低——它是默认款，不是设计** |

> **★ 最常犯的错**：**全场都靠"三分点"造落点**——**那是最弱的一个**，而且**每镜都用它，就等于是没有落点**。
> **★ 反过来用**：**想让观众去看"没有脸"的地方，就必须把脸压暗 / 移出焦 / 挡住**（脸的优先级会抢走一切）。

## §2 ★★ 十个设计装置（**这就是"设计感"的词表**）

**用法**：**排镜时每镜问一句"这一镜用哪个装置"**——**答"没有，就是主体在三分点"＝这一镜是默认款**，可以留，但**不能每镜都是**。

| # | 装置 | 做法 | 它在说什么 | 提示词句法（关系词，非坐标） |
|---|---|---|---|---|
| 1 | **三角调度** | 三人成三角，**顶点＝这一镜最重要的人**；**只需旋转三角（机位不动）就换主导权** | 关系与主导权 | 「三人成三角：A 在顶点，B 与 C 在底边两侧各距约两步；B 侧身朝 A」 |
| 2 | **Z 轴调度** | 让人**沿纵深走**（后景→中景→前景，或反之） | **靠近＝支配/侵入；退后＝退缩/退出** | 「他从后景沿纵深走到中景停住，全程面向镜头侧前方」 |
| 3 | **负空间调度** | 主体压到画面一侧，**另一侧留大片空**；空的那侧**朝向"他想要或害怕的东西"** | 缺失、孤立、**指向画外** | 「她位于画面最右侧，左侧三分之二为空；她看向左侧的空处」 |
| 4 | **不对称配对** | 两人**永不"对称同姿态"**：一坐一站 / 一前一后 / 一实一虚 / 一入画一半 | 不对等的关系 | 「她坐着，他在她身后一步站着，只入画半个身子」 |
| 5 | **框中框** | 用**门 / 窗 / 镜 / 廊柱 / 拱门**把人框住 | **三种读法**：被限制（框比人小）· 被观察（从外往里）· 将过渡（门＝要走了） | 「隔着半开的门看他：门框占画面两侧，他在中景深处」 |
| 6 | **方向性装置** | 用场景自带的线（**长桌 / 楼梯 / 走廊 / 队列 / 铁轨**）排出**等级与进程** | 等级、顺序、旅途 | 「长桌沿画面对角线延伸，她坐在最远端」 |
| 7 | **象征性放置** | 同一件物件**"放在桌上" vs "收进抽屉"**——**位置本身是台词** | 权力的在场与退场 | 「他把钥匙放在两人之间的桌面上，手收回到身侧」 |
| 8 | **三区构图** | 前景 / 中景 / 后景**各放一个信息**，三层不同清晰度 | 一镜说三件事 | 「前景虚焦的肩、中景的他、后景走过的人」 |
| 9 | **焦点当调度** | **不切镜头，用移焦把"谁是主体"换掉** | 主陪互换、注意力转移 | 「焦平面由前景的杯子移到后景她的脸」 |
| 10 | **尺度对比** | 人在巨大物前 / 极小物在人手边——**用占比说处境** | 权力、渺小、被吞没 | 「他站在门洞里，门洞高度约占画面九成」 |

**★ 两条纪律**：
1. **一场戏装置别超过 2–3 个**——**装置一多，每一个都不被看见**（与 §4"一景一个想法"同一条）。
2. **装置必须带关系**——**只写装置不写"谁在看谁/谁占上风"，出来就是摆拍**（装置是形式，关系是内容）。

> **★ 已有出处，本册不复述**：
> **前景遮挡** → `staging-craft.md` §3.2-2（本册只把它当"§2-8 三区"的一层用）；
> **重复走位（调度层的母题）** → `staging-craft.md` §2 三条配套。
> **★ 本册补的正是这两个之外的那 10 个——库里此前没有名字**。

## §3 ★★★ 从"直白"到"有设计"：**四条改法**

> **这一节是给"已知这一拍要讲什么、但写出来很平"的镜用的。**
> **★ 通用诊断**：**把画框遮住，只读你写的文字描述——能读出"有事在发生"吗？**
> 读出来只有"谁在哪、在做什么" → **还是直白。**

### 改法一 · 把「人在哪」改成「人之间的关系」
```text
直白：男人坐在桌前，女人站在旁边。
有设计：她坐着不动，他从她身后绕到桌对面才坐下——两人各占长桌一端，桌面中间空出一大段。
```
**动了什么**：多了**过程**（绕过去）与**距离**（长桌两端＝对质）。**空间自己把关系说完了。**

### 改法二 · 加「画家里的一层」（框中框 / 前景层 / 反射 / 隔着什么）
```text
直白：他站在空荡的走廊里。
有设计：隔着半开的门缝看他——门框占画面两侧，他在中景深处，前景门缝边缘虚焦。
```
**动了什么**：**从"看一个人"变成"被允许看一个人"**（observer 位置）。**且一镜多了两层清晰度。**

### 改法三 · 把情绪从「脸上」移到「位置与物件上」
```text
直白：她悲伤地低下头。
有设计：她低头看着他留在桌上的钥匙，手从桌边慢慢收回到膝上；镜头不动。
```
**动了什么**：**用库里肖夫工作**（`shot-linkage.md` §1）——**给物件，不给形容词**。
**★ 理由**：脸的情绪靠模型演（不可靠）；**位置与物件的含义靠观众造（百分百成立）**。

### 改法四 · 给这一场定一个「基调构图」，然后**只破一次**
```text
直白：全场都用三分法构图。
有设计：全场都是"人物贴画框左右边缘、中间空着"；唯一一次把他放到画面正中——
        正是他做决定的那一镜。
```
**动了什么**：**建立基线 → 一次破格 → 破格自带重量**（见 §4 纪律 1）。
**★ 这是"设计感"最省的来源**——它不花钱、不靠道具、只在排镜时定一个规律。

> **★ 四条改法的共同点**：**都增加了"第二次读"**——**第一次读看到画面，第二次读看到含义。**
> **直白 ＝ 只有第一次读。**

## §4 ★★ 全片级：**视觉母题系统**

### 4.1 一句话地基
**母题 ＝ 一个视觉念头在全片反复出现**（一件物 / 一种运动 / 一个构图 / 一种光 / 一块颜色）。
**★ 它的力量不来自"重复"，来自"重复 + 变奏"**——**第一次建立基线，第二次邀请对比，第三次揭示转变。**

### 4.2 五类母题（**选 1–2 类，不许五类都选**）

| 类 | 做法 | 例（结构示意） |
|---|---|---|
| **物体母题** | 一件东西反复出现，**每次含义变一点** | 《寄生虫》那块石头：先是财运 → 后是凶器 → 最后回到水里 |
| **构图母题** | 同一构图在别处重演，**只改一项** | 同一张餐桌：人一次比一次少 |
| **运镜母题** | 同一种运动反复出现，**绑定一个情绪/状态** | 每次他说谎，镜头就缓缓绕到他背后 |
| **光位母题** | 同一种光反复出现，**绑定一种处境** | 凡"他在装"的场，全是顶光（见 `light-physics.md`） |
| **色彩母题** | 同一块颜色跟着一个主题走 | → **正文在 `color-narrative.md`**，本册只挂名 |

### 4.3 ★★ 三拍结构（**照这个排**）
```text
第一拍 · 起（要不起眼）—— 第一次出现必须"顺手带过"；观众不该记住它
第二拍 · 变（要可辨认）—— 形态变一点（多了 / 少了 / 换了人 / 换了位置）；观众"好像见过"
第三拍 · 揭（要能落地）—— 它被明确点名，或被打破；观众回头把前两次串起来
```
**★ 判据**：**把"第三拍"那一镜单独拿给没看过全片的人看，他会以为那只是个普通镜头吗？**
**会 → 前两拍埋得太浅或太深，重排。**

### 4.4 ★ 两条硬纪律
1. **★ 故意的破格＝叙事信号**——**当一套视觉规则被"唯一一次"打破，那一次就是全片最响的一句台词**。
   → **所以规则必须先立得住**（**全场随便变 ＝ 没有规则 ＝ 破格无意义**）。
   **代价要知道**：定了基调就会有"这一镜不够好看"的冲动——**忍住；好看的那一镜留给破格用。**
2. **★ 一景一个想法**——**一场戏只承担一个视觉设计念头**。
   **想塞三个 → 结果是三个都没被看见**（观众的 280 ms 只够读一个）。

### 4.5 ★ 与 `shot-linkage.md` §7 的区别（**别混**）
| | `shot-linkage.md` §7 | 本册 §4 |
|---|---|---|
| 尺度 | **点到点**（镜 3 ↔ 镜 17） | **面到面**（全片一套语法） |
| 最低要求 | **可以单点埋**（埋 2–4 处就够） | **必须先有基线，才有变奏** |
| 内容 | 重复构图 / 母题复现 / 图形匹配 / 色光呼应 | **五类母题 + 三拍 + 破格** |
**★ 两者可以并存**：**母题是骨架，呼应是在骨架上钉的钉子。**

## §5 案例五则（**抄规则，别抄画面**）

| 片 | 视觉语法（规则） | 用哪条装置 |
|---|---|---|
| **《闪灵》** | **空间的形状＝主题**（树篱迷宫：复杂、走不出去）；**全片对称稳定 → 唯一一次失衡＝崩溃** | 方向性装置 · 破格 |
| **《教父》** | **婚礼一场用"谁离维托多近"画权力半径**——他几乎不移动，是别人在绕他 | 三角调度 · 尺度对比 |
| **《寄生虫》** | **两处空间互为反义**（半地下室 vs 豪宅）；**同一场雨在两处是两种灾难** | 方向性装置 · 物体母题 |
| **《银翼杀手 2049》** | **反复的巨型投影/广告**——人在影像面前永远很小 | 尺度对比 · 三区 |
| **《遗传厄运》** | **构图持续不居中、不对称**——观众从头到尾"哪里不对" | 不对称配对 · 负空间 |

> **★ 用法**：**"这部片用 X 装置反复说了 Y"** ——**把它翻译成你自己的 X 和 Y，不是照搬画面**。
> **★ 别做的事**：**把五则案例的美术混在一起**（＝没有语法，只有拼贴）。

## §6 ★ 写进哪一块（**归属是硬约束**）

| 设计元素 | 落进哪一块 | 备注 |
|---|---|---|
| **落点**（最亮/最清/唯一暖色/唯一在动） | **【构图】** | 落点必须写"用什么造的"，不只写"在哪" |
| **框中框 / 负空间 / 不对称配对 / 方向性装置** | **【构图】** | 位置写成关系词（`staging-craft.md` §6.1） |
| **三区构图** | **【构图】** + **【光位与影调】**（清晰度差靠光与焦） | 两块各写一半 |
| **Z 轴移动 / 焦点转移** | **【时间线】**（动作相位）**+【运镜】**(若镜头也动) | **归时间线的那一半不写进运镜** |
| **象征性放置**（物件位置变化） | **【人物与环境】**（物件）**+【时间线】**（什么时候变的） | 只写功能，不重述外观 |
| **母题复现** | **【统一提质层】**（一致性锚点）+ 全片条目 | 锚点句逐字复述（`asset-consistency.md`） |
| **破格那一镜** | **【本镜目的】必须写明**「这是全片唯一一次……」 | **不写 → 破格会被当成失误** |

**★ 注意**：`block-spec.md` §三·补 14 条——**一个信息只在一个块里"定义"**，别处只许引用。
**★ 本表与 `block-spec.md` §三·补 14 条同源，本册不新增归属规则，只把它指向设计层。**

## §7 自检（**能机检的都机检**）

```text
① 每镜只有一个落点，且写了"用什么造的"（亮度/清晰度/运动/色彩/人脸）
② 本病至少有一个装置不是"主体在三分点"——默认款不算设计（§2）
③ 相邻镜的构图描述不雷同——连续三镜同款即单调（§2 纪律 1）
④ 全片选了 1–2 类母题，且写出"起 / 变 / 揭"三个位置（§4.3）
⑤ 全片至多一次破格，且那一镜【本镜目的】写明了（§4.4-1）
⑥ 机检：python3 scripts/lib_doctor.py --design <分镜表>
```

**★ 人只判两件（机器判不了）**：**"这一镜有没有设计感"** · **"这一套视觉语法配不配这个故事"**。

## §8 失败模式（**照这个改**）

| 症状 | 根因 | 改法 |
|---|---|---|
| **"每镜都好看，连起来像 PPT"** | **没有母题 / 没有基线**——每镜各自为战 | 补 §4.3 三拍；先立基线 |
| **"很直白"** | **只有"人在哪"，没有装置** | 走 §3 四条改法；每镜点一个装置 |
| **"说不出在讲什么"** | **一镜多个落点** | 删到一个（§1 推论 2） |
| **"看着累"** | **每镜都是默认款，反而没有节奏** | 交替用不同装置；一场 2–3 个 |
| **"炫技 / 花"** | **破格太多次 / 装置太多** | 破格全片一次；装置一场 2–3 个 |
| **"出来是摆拍"** | **只写了装置，没写关系** | 装置必须带"谁在看谁 / 谁占上风"（§2 纪律 2） |
| **"观众看不到重点"** | **落点用的是最弱的"位置"** | 换成亮度 / 清晰度 / 运动 / 人脸（§1 表） |

## §9 实例：一份"直白"分镜表怎么改

**场景**：她在医院走廊等手术结果（6 镜 · 约 17 秒）。

### 9.1 改造前（**每一镜都"没错"，但每一镜都只有"人在哪"**）
```text
| 镜 | 构图                 | 景别 | 时长 |
| 1  | 三分法，人物在左三分之一 | 全景 | 3s  |
| 2  | 三分法，人物在右三分之一 | 中景 | 3s  |
| 3  | 三分法，人物居中         | 近景 | 2s  |
| 4  | 三分法，人物在左三分之一 | 特写 | 2s  |
| 5  | 三分法，人物在右三分之一 | 中景 | 3s  |
| 6  | 三分法，人物居中         | 全景 | 4s  |
```
**机检**：`lib_doctor.py --design` → **抓到"整场没点任何设计装置" + "连续默认款" + "没有一条写落点制造器"**。

### 9.2 改造后（历史示例，含构图与情节变化）

第 5 镜新增了陪伴者到场，超出原表已写内容，属于情节变化。用于仅优化构图的任务时，须保留原有出场人物与动作，再重排装置。

| 镜 | 【构图】写什么 | 装置 | **这一拍在说什么** |
|---|---|---|---|
| 1 | 走廊尽头，她位于画面**极右**，**左侧三分之二为空**；空的那侧正对手术室的红灯（**全画面唯一的高饱和色**） | 负空间 + 落点（色彩孤立） | 等待＝**被那片空处压住** |
| 2 | **前景虚焦的售货机边角框住她**；她在中景坐着，手里那杯水没动 | 三区构图 | **世界照常运转，她停住了** |
| 3 | 隔着**半开的门框**看她，门框占画面两侧，她在中景深处 | 框中框（被限制） | **她被关在这件事里** |
| 4 | **焦点由前景的水杯移焦到她握杯的手指** | 焦点当调度 | **不给脸，给手**（脸靠模型演不可靠） |
| 5 | 他**坐到她旁边——不是对面，是并排**；两人各占长椅一端，**中间空着** | 不对称配对 + 方向性装置 | **陪伴，但还没靠近** |
| 6 | **与镜 1 完全相同的机位与构图**：椅子空着，手术室的红灯灭了 | **母题复现（第二拍·变）** | **不用演，观众自己填** |

**机检**：`--design` → **码 0**，装置 **5 种**（三区 / 方向性装置 / 框中框 / 焦点当调度 / 负空间），提示 **"写明复用：镜 6"**（即母题的"起"与"变"）。
> **★ 这张表是拿真门禁跑过的**：第一版它报了两条——一条是**我自己的词表太窄**（本册写「唯一**的**高饱和色」，而词表里只有「唯一高饱和」，中间插一个「的」就永远匹配不上），另一条是**逐字比对抓不到"与镜 1 同机位"这种指针式复用**。
> **两条都已修（词表加宽 + 复用写法另走一条正则）。** 所以这一节既是**门禁的用例**，也是**"写词表别写太长、判据要覆盖两种写法"的实例**。

### 9.3 ★ 两个版本并排读，差在哪
**改造前每一镜读出来是**："她在这里，她在这里，她在这里……"
**改造后每一镜多了一句**：**"它在说什么"**。

**★ 这就是"设计感"的全部定义**——**不是加了装饰，是让每一个画框都承担一句话。**
本例沿用原表的六个镜号，改造表未列出时长。新增陪伴者、景别描述与时长安排仍需与原方案对账。结构检查的码 0 只说明所检查的文本项，实际成本、叙事一致性与成片效果分别验证。

> **★ 一条纪律**：**改造后要回头确认"设计有没有挤掉信息"**——第 5 镜如果为了让两人不对称而看不清"他坐下了"，那就是设计盖过了叙事。
> **判据：把这一镜的装置划掉，剩下的字还说不说得清这一拍要讲的事？**
