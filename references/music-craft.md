# 音乐工艺：**给导演与编剧用的音乐理论**（不是给作曲家的）

> **何时读**：要决定"这场该不该有音乐 / 该是什么音乐"、给音乐工具写描述、或要把剪辑点对到音乐上时。
> **读完回哪**：回 `sound-craft.md`（结构与工作流的权威在那边）；音效层见 `sound-design-craft.md`；混音与响度见 `mix-loudness.md`。
> **★ 本册的定位**：**你不用会作曲，但要懂音乐的语言**——因为它决定的是**节奏、情绪与剪辑**，
> 而这三件事是导演与编剧的活。**本册只收"能翻译成一句可执行指令"的乐理**，不收和声学。

---

## §1 ★ 六个要素 ↔ 情绪（**本册核心表**）

**来源**：彭吉象《艺术概论》第七讲「表情艺术」（**权威中文教材级**，非自媒体）。六要素是音乐的"表情语言"，**每条都能直接译成一句给音乐工具/作曲家的话**。

| 要素 | 典型形态 | 对应的情绪 | **译成指令**（可直接写进描述） |
|---|---|---|---|
| **旋律** | 上行 | 昂扬、振奋 | "旋律整体上行" |
| | 下行 | 悲伤、深沉 | "旋律下行收束" |
| | 平稳 | 宁静、舒缓 | "旋律以级进为主，少跳进" |
| | 跳跃 | 活泼、欢快 | "旋律多跳进、断奏" |
| **节奏** | 快 | 紧张、激动、欢快 | "快速节奏" |
| | 慢 | 平静、深沉、悲伤 | "缓慢节奏" |
| | 稳定 | 坚定、庄重 | "节奏方正稳定" |
| | 变化 | 冲突、转折、波动 | "节奏不规则、含切分" |
| **和声** | 协和 | 和谐、稳定、温暖 | "协和和声" |
| | 不协和 | 紧张、冲突、不安 | "不协和和声、悬而未决" |
| | **和声进行** | **推动情绪发展与叙事性** | "和声进行持续向前推" |
| **音色** | 弦乐 | 柔美抒情、细腻 | "弦乐为主" |
| | 铜管 | 明亮辉煌、庄严激昂 | "铜管号角" |
| | 木管 | 空灵个性、自然灵动 | "木管独奏" |
| | 人声 | **最富表现力** | "无词人声衬底" |
| **曲式** | （结构形式） | **对应情感的发展、冲突与解决** | "三段式：陈述—展开—解决" |
| **调式调性** | 大调 | 明亮、开阔、积极 | "大调" |
| | 小调 | 深沉、柔和、忧郁 | "小调" |
| | **转调** | **情绪转折、场景变化、冲突升级** | "在中段转调" |

**★ 权威教材给导演的三条直接对应**（原文提炼）：
1. **旋律 ↔ 人物主题**：用主题旋律塑造人物——**英雄人物主题昂扬向上，悲剧人物主题深沉下行**；
2. **节奏 ↔ 剪辑节奏**：**"好的导演是用音乐的节奏来控制整部电影的呼吸"**→ 动作片快、文艺片缓、悬疑片紧；
3. **和声 ↔ 情绪张力**：**冲突场景用不协和和声制造紧张，情感高潮用协和和声带来释放**。

> **★ 一句话记法**：**要什么情绪，就临场先拧四个旋钮到那一档**（旋律走向 / 节奏快慢 / 和声协和度 / 音色编制）——
> **曲式是整首的骨架（§4）、调式是颜色（§2），编曲前先定**，**再决定要不要"转调"**——**转调是最高效的"局面变了"**。

## §2 ★ 七个调式的性格表（**选"颜色"用**）

**来源**：影视配乐实战手册（自媒体，**单源**）+ 调式理论通行知识（多源）。**用法：先选调式＝先选"这场戏的颜色"。**

| 调式 | 情绪 | 特征音 | 心理机制 | 配哪类场 |
|---|---|---|---|---|
| **Ionian 伊奥尼亚**（＝自然大调） | 纯净、光明、积极 | 主音 | 稳定和谐，安全感与希望 | 田园、胜利时刻 |
| **Dorian 多利亚** | 忧郁、内省、怀旧 | 6 度音 | 略带忧伤的旋律，引发追忆 | 雨中独行、回忆 |
| **Phrygian 弗里吉亚** | 紧张、神秘、异域 | 2 度音 | 不安与悬疑，暗示危险 | 进入遗迹、诡异气氛 |
| **Lydian 利底亚** | 梦幻、空灵、飘渺 | **#4 音** | **悬浮感与不确定性** | 梦境、超现实 |
| **Mixolydian 混合利底亚** | 蓝调、自由、奔放 | 7 度音 | 略不协和，轻松随意 | 酒吧、放松 |
| **Aeolian 爱奥利亚**（＝自然小调） | 悲伤、忧郁、绝望 | 7 度音 | 压抑与痛苦 | 黑暗中挣扎 |
| **Locrian 洛克里亚** | 恐怖、不稳定、混乱 | **♭5（减五度）** | **极度不协和** | 遭遇邪恶、绝望 |

**★ 判据一句话**：**"这一场的颜色是暖的还是凉的？"** 暖 → 大调家族（Ionian / Mixolydian）；
凉 → 小调家族（Aeolian / Dorian）；**要"异域 / 危险" → Phrygian / Locrian；要"悬浮 / 超现实" → Lydian**。
> **证据强度**：**调式↔情绪**为通行乐理（多源）；**"特征音 + 心理机制"那一层**为**单源**（自媒体手册）。
> 按 `governance-law.md` L4·补2 记「拟订」——**可当取词表用，不当定律**。

## §3 ★ 场面类型 → 音乐参数（**三类示范；其余场面按六要素自行组合**）

**来源**：Eduqas GCSE Music「Film Music」考纲（**教育机构教材级**，多源共识）。**它把"情绪"拆成了可勾选的参数**。

| 场面 | 速度 | 织体 | 力度 | 连断 | 和声 | 旋律 |
|---|---|---|---|---|---|---|
| **悲伤 / 反思** | 慢 | 主调（单声部为主） | 弱 | **连奏 legato**、长延音 | 协和 / 小调 | **级进 conjunct** |
| **惊险追车** | 快 | 复调、繁忙 | 强 | 断奏、**切分节奏** | **不协和** | **跳进 disjunct**、短 riff |
| **英雄救场** | 中—快 | 齐奏 | 强 | 重音 | 大调、**四度与五度** | **铜管号角 fanfare** |

**★ 音程也有性格**：**上行纯四度＝"英雄感"**；**半音＝"威胁感"**。
**★ 编配术语（写描述时可直接用）**：`pizzicato` 拨弦 · `tremolo` 颤弓（"颤抖"效果，同音或两音快速交替）· `glissando` 滑音 · `vibrato` 揉弦 · `muted` 加弱音器 · `ostinato / riff` 短句反复 · `pedal note` 长持续低音 · `fanfare` 号角短句。

**★ 五个必须认识的词**（它们决定了"这段音乐有没有叙事功能"）：
- **Theme** 主旋律；
- **Motif** 短动机（旋律或节奏的短想法）；
- **★ Leitmotif 主导动机**——**反复出现、绑定某个角色/物件/地点的音乐想法**（例：星战里达斯·维达的动机）。**这是"音乐承担叙事"的基本单位，也是我们做人物主题时的落点。**
- **Underscoring** 对白下的衬底音乐；
- **Minimalism** 用短句反复、逐渐变化（**最适合"不抢戏又有推力"**）。

## §4 ★ 曲式与能量曲线（**写"音乐节拍表"用**）

### 4.1 四种常用曲式（挑一个，或自创）

```text
ABABCB  Verse / Chorus / Verse / Chorus / Bridge / Chorus   （流行、摇滚最多）
AABA    主歌 / 主歌 / 桥段 / 主歌再现（主题回归，非副歌）         （爵士标准曲、叙事歌）
ABAB    主歌 / 副歌 交替                                      （简单直接）
AAA     主歌 / 主歌 / 主歌（分节式，无副歌）                    （民谣、说唱叙事）
```

**六个构件**：`Intro 引子（定调、抓人）· Verse 主歌（故事、细节、世界）· Pre-Chorus 预副歌（张力爬升，可选）· Chorus 副歌（情绪核心、被记住的部分）· Bridge 桥段（岔开、换视角或换调）· Outro 尾（告别，可回响或反转）`。
**它们不是必须都有**——**结构服务情绪，不是反过来**。

### 4.2 能量曲线（10 分制，写"音乐节拍表"时照填）

```text
Intro 2–3 ｜ Verse 5–6 ｜ Pre-Chorus 7 ｜ Chorus 8–9 ｜ Bridge 视情况 ｜ 末次副歌 9–10
```

**★ 最强的一条动态技巧：对比。**
- **在嘶吼之前先耳语**——比全程嘶吼狠得多；
- **疏 before 密、慢 before 快、低 before 高**；
- **"drop（炸点）之所以成立，是因为前面的铺垫"**；
- **静默是一件乐器**（`sound-lexicon.md` §6 有专门一节）。

**★ 一句可复用的写法**：**"耳语 → 咆哮 → 再回到耳语"**——**起于私密、推到全力、剥回脆弱**。
三种体裁通吃：叙事歌、史诗、颂歌。

> **★ 与 `sound-craft.md` §3.2「全片能量曲线」的关系**：**那边是"整片的声音能量"，这边是"一首音乐内部"**——
> 两者要**同向**（音乐的内部峰值应落在片子的情绪峰值上），**不许一个在升一个在降**。

## §5 音乐与剧作/剪辑的四个接口

| 接口 | 规则 | 判据（自问） |
|---|---|---|
| **人物主题** | 主要人物**一个主导动机**；**同一动机变奏**表现人物变化（不用换一首新曲） | "把他的动机放慢一半、换成小调，还认得出是他吗？" |
| **剪辑节奏** | **剪切点落在拍上**（`@Audio1 drives the pacing; cuts land on its beats`） | "把这条音乐铺在时间线上，剪切点对得上吗？" |
| **情绪张力** | **冲突用不协和、高潮用协和**；**转调＝局面变了** | "这一场的和声是"悬着"还是"落了"？" |
| **何时不写音乐** | **写实纪实 / 对白驱动 / 社会议题 / 恐怖悬念（靠环境音与静默）/ 日常切片 → 全片无配乐** | 见 `sound-craft.md` §四 |

**★ 一条容易忘的**：**预期违背——靠调外音（chromatic harmony）制造**——**在调内突然塞进不属于它的音**，是最省力的"不对劲"。
`drama-tropes.md` 里的"转折"在声音层可以只靠一个音完成。

## §6 写音乐描述时的两条通道（**工具不同，规矩不同**）

| | **给生成式工具（Suno 类）** | **给视频模型的原生音频（Veo 3.1 类）** |
|---|---|---|
| 描述什么 | **风格 + 情绪 + 年代 + 配器 + 人声 + 制作 + 动态** | **情绪基调 + 配器**（**不写流派**——单源经验） |
| 例 | "电影感管弦、冷战时期 60 年代、烟嗓女声、大乐队爵士、铜管与法国号、弦乐铺展、小调、模拟温暖" | "sparse piano melody, slow and melancholic" / "building string section, rising tension" |
| 要不要写 BPM/调 | **要**（有偏好就写） | 不必 |
| 商业名 | **禁**（不写艺人名/曲名，描述声音："60 年代冷战谍战铜管"，不写"007 风格"） | 同 |
| **共同铁律** | **描述"过程"而不只是"风格"**：`起于… 逐渐铺进… 副歌全奏… 尾段剥回一架孤独的钢琴` | **"音频弧线"**：`string quartet rising slowly from quiet to present` |

> **来源**：`songwriting-and-ai-music`（站点社区技能 · 一手）· `higgsfield-veo-3-audio-director`（站点社区技能 · 一手）。
> **证据强度**：**两来源相互印证"要描述动态进程"**，且与 §4.2 的能量曲线同构 → 记「拟订」。
> **完整工具矩阵与授权风险**见 `audio-tools.md`。
>
> **★ 平台落地注记（AI 工作流）**：**右列（视频模型原生音频）实测以对白、环境声、音效为主——需要完整、可控、可独立使用的配乐时，优先走左列（独立音乐生成工具）**；左列给歌词可出**带唱词的完整歌曲**，右列仅用于音乐与画面必须一次性共生的镜头。Suno / Veo 3.1 为通道类型代号，按实际可用的同类工具对应。
