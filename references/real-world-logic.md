# 现实逻辑：跨层自洽与九轴自查

> 何时读：写完一镜提示词之后（交付前必跑）；看片发现"哪里不对但说不清"时；写动作、光位、道具位置之前。
> 读完回哪：光学细节 → `light-physics.md` / `light-quality-construction.md`；动作反馈 → `physical-feedback.md`；可行性与门槛 → `feasibility.md`；动作控制 → `motion-control.md`；调度与空间 → `staging-craft.md`；皮肤光学 → `skin-light-physics.md`。
> 本册管什么：上面那些册各自管一层，本册管**它们之间有没有打架**——即"跨层自洽"。本册不重复它们的规则，只给自查与判据。

---

## §0 一句话地基

现实逻辑不是"加一句真实感"，而是**同一镜里各处描述能互相推得出来**。

判据一句话：把这个镜头里所有可见的事实列出来，问一句"它们能同时成立吗"。不能，就是现实逻辑出问题。

---

## §1 九条轴与自查问句

九条轴按"最容易出错"排序。每条给一个能直接回答的问句。

### 轴一：光与影（同一束光推得出三件事）

一束光同时决定三件事：亮面在哪、暗面在哪、影子朝哪。三者必须同向。

- 光从左上打来：脸左上亮、右下暗、影子落在右下方
- 光从下方打来（显示器、桌面灯）：下颌与鼻底亮、额顶暗、影子往上或投到身后的墙与天花板
- 光从背后打来（逆光）：轮廓亮、脸是暗的、影子朝镜头方向延伸

自查问句：这一镜的亮面、暗面、影子方向，能不能从同一个光源位置推出来？

另两条同轴纪律：

- 光源数量：动机光源一到两个。写到四个以上，等于没布光（模型会均质化成大平光）
- 时段与光源一致：写"夜"就不要出现只有白天才有的光（日光的硬度、方向、色温都不是夜里能给的）

### 轴二：人体力学（重心、支撑面、可达范围）

- 重心在哪只脚上，那只脚就是支撑面；重心在两脚之间时人是"待变"状态
- 手臂的可达范围约等于臂展的一半；身前一步以内的东西不用移动身体就能拿到
- 转身要处理支点（以哪只脚为轴）；起立要处理重心（先前倾再起）

自查问句：他做这个动作时，重心压在哪个支撑面上？那个东西他够得到吗？

### 轴三：空间地理（门、窗、家具与人的动线）

同一场戏里，空间事实必须前后一致：

- 他从哪个门进、朝哪个方向走、看哪一边，三者要能画在一张俯视图上
- 窗在左侧，光就从左侧进来；桌靠墙，人就不能从那一侧走过
- 摄影机的位置要能真的拍到所写的构图（不要写一个物理上拍不到的角度）

自查问句：把这一镜画成一张俯视图，人物、门、窗、家具、机位能同时放在合理位置吗？

### 轴四：因果链（每个结果必须有因，链条不超过两环）

- 被带翻的椅子，是被起身的动作带翻的；扬起的灰，是被掌风带起的
- 二级动作必须有因：写"椅子被带翻"就要写"起身的动量把椅子带翻"
- 链条不超过两环：A 导致 B 可以，A 导致 B 导致 C 就显得编造

自查问句：这一镜里每一个"动了的东西"，是被什么弄动的？

### 轴五：时间与动作量（算术要对得上）

- 一步约零点五秒，一步约零点六到零点七五米；三秒约六步约四米
- 起身或坐下约一到一点五秒；转身九十度约一秒
- 一个动作单元占满整个时长；两个动作单元塞进一镜就互相抵消

自查问句：这一镜里的动作总量，用上面的数除一除，装得进这个时长吗？

### 轴六：材质与守恒（体积、重量、惯性）

- 体积守恒：落地压短就变宽、弹起拉长就变窄
- 轻重对比：重的东西起步慢、要蓄力、停下还多冲一点；轻的东西反应快、幅度大、滞后明显
- 惯性：主体停下后，附属物（衣摆、头发、手里的纸）还会继续动一小段

自查问句：把画面里最重与最轻的东西各指一个，它们动起来是一样轻快吗？一样的话，重量没写出来。

### 轴七：生理常识（身体的反应要合情境）

- 剧烈动作之后呼吸不匀；静止久了会有一个无意识的吞咽或换重心
- 低照度下瞳孔放大，强光扫过来才收缩，而且慢半拍
- 冷、热、湿、疼都会改变身体姿态（缩肩、抱臂、倚靠）

自查问句：他刚做完那件事，身体该有什么反应？写了吗？

### 轴八：道具与身体的接触

- 接触点必须有支撑：手按在桌上，桌要能承住（人不能悬空按）
- 拿在手里的东西要有握持面；写"握住"就要给手指一个落点
- 接触事件越少越真：六秒内两处以内，其余写成持续状态（"已经握住"而不是反复抓握）

自查问句：这一镜里的每次接触，接触面在哪、由什么支撑？

### 轴九：声音与画面的因果

- 每一个声音都要来自画面内的一个具体东西或动作
- 声音与动作要绑在同一刻：落脚声落在落地的瞬间，不是"大约在走路的时候"
- 画面里没有的东西，不要给它声音（画外音要有画外来源）

自查问句：这一镜的每个声音，是画面里哪个东西发出的、在哪一刻发的？

## §2 高频矛盾对照表

| 错误写法 | 为什么错 | 正确写法 |
|---|---|---|
| 显示器从下方打上来，影子向下投射 | 光在下、影不可能朝下 | 影子落在白板上、朝右上方向拉长，鼻底与下颌最暗 |
| 夜里室内，光却是硬日光 | 时段与光源矛盾 | 夜戏用实用光：台灯、显示器、应急灯，光软、色温偏低 |
| 他一手按住纸、另一手同时拉开抽屉并拿起杯子 | 一双手装三件事 | 减到两件，或把第三件写成"已经拿在手里"的持续状态 |
| 六秒内从门口走到桌边还转身坐下再拿起东西 | 时间算术装不下 | 拆成两镜，或把位移交给剪辑（跨镜位移） |
| 椅子自己翻了 | 二级动作没有因 | 起身的动量把椅子带翻，椅子在地上又转了四分之一圈 |
| 他停在原地，衣摆却大幅飘动 | 因果与重量矛盾 | 要么有风（写风的来源），要么只写衣摆小幅落定 |
| 熄了灯的房间，脸上还有清晰的正面光 | 光源消失后光没跟着消失 | 只剩窗外街灯或应急灯的窄光，脸的暗面扩大 |
| 他跑过走廊呼吸平稳 | 生理常识不符 | 跑完呼吸不匀、胸口起伏快，或干脆不跑 |
| 手指捏住杯口边缘提起满杯 | 握持面不成立 | 手握杯身或杯柄，接触面朝内 |
| 声音写"远处传来音乐"，画面里没有声源 | 画外音没有画外来源 | 写明画外来源（隔壁、走廊尽头、楼下店铺） |

## §3 机器口径（已落成与可落成）

已落成（`scripts/audit_prompt.py blocks`）：

1. 影子方向与光源位置反向矛盾 → WARN（轴一）
2. 二级动作缺因（出现"被带翻/震出/晃了一下"却没有"被/因/借着/惯性"）→ 可判（轴四）
3. 时间线与时长算术：一步约半秒的换算与镜内位移上限 → 可判（轴五）
4. 一双手的动作数超限（时间线内四处以上）与接触事件过密（四处以上）→ WARN（轴二与轴八）
5. 光源数量超过三个 → WARN（轴一）

机器判不了，只能靠看片（如实划界）：

- 动作在画面上是否真的自然（写得对不等于做得到）
- 表演是否可信
- 道具的实际可达性与景深内的空间关系

## §4 自查流程（交付前跑一遍）

```
第一遍 单轴自检：九条轴逐条问，答不出的记下来
第二遍 跨轴对撞：把三组最容易打架的放一起看
        光与影 × 空间地理（窗在哪、光从哪来）
        人体力学 × 道具接触（重心在哪、东西够不够得到）
        时间与动作量 × 因果链（几秒内做完这些、每个结果有没有因）
第三遍 画一张俯视图：人、门、窗、家具、机位
第四遍 机器过闸：python3 scripts/audit_prompt.py blocks <文件>
```

## 来源与署名

- 本册为库内整合与自建：九条轴、自查问句、高频矛盾对照表、自查流程，均为本库自建（动因是用户 2026-09-17 要求"现实逻辑自查，或通过学习建立现实逻辑的规则"）。
- 归纳自库内既有资产：`light-physics.md`（光位与软硬光）· `light-quality-construction.md`（双影与六维）· `physical-feedback.md`（因果顺序、轻重对比、跟随与重叠、二级动作必须有因）· `motion-control.md`（时间纪律与三个必补量）· `motion-parameters.md`（速度与时长换算、每四秒运镜数）· `actor-movement.md`（一步约半秒、起身与转身的耗时）· `staging-craft.md`（空间与主陪）· `character-realism.md`（生理活性与静息微动）· `ai-artifact-control.md`（太干净与退化）· `skin-light-physics.md`（皮肤受光）。
- 通用物理常识（光与影同源、体积守恒、惯性、人体重心与支撑面）属通识，未逐字引用任何来源；带数值的换算（一步约半秒、起身约一秒到一点五秒）沿用库内既有口径，属经验值。
- 与既有册的关系：本册不重复任何一册的规则，只做"层与层之间的自洽检查"，并已把其中五条落成机检（见 §3）。
