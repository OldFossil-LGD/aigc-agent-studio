# 资产板块手册（每个板块：该想什么 · 怎么落笔 · 模型读不读得懂）

> **何时读**：写**资产提示词**之前（角色设定板 / 道具设定图 / 场景设定图 / 批量任务文本 / 首帧版 / 参考照片）。
> **分工**：`updream-workflow.md` = **五段式协议的骨架与五类模板**（照抄用）；`asset-consistency.md` = **参考图纪律与一致性机制**（漂移怎么防）；**本文 = 每个板块的"思考 + 落地"**（该想什么、写哪一句、模型能不能懂）。
> **★ 三类资产的重点差异 · 字段的下游归属 · 资产从剧本哪一行派生 → `asset-prompt-spec.md`**（本文管"九块怎么写"，它管"写哪一类、写到什么程度、写完谁用"）。
> **镜头提示词不看本文** → `block-playbook.md`（15 块，含时间线 / 表演 / 摄影机 / 声音）。
> **本文不重复骨架**，只讲"为什么这么填、写错了模型会怎样"。

## 怎么用这份文件（三步）

```
① 逐块答"写之前的思考" —— 答不出的块，就是上游没想清
② 照"可抄句式"落笔 —— [ ] 换成这一份资产的内容，句子结构不动
③ 过"模型读得懂" —— 有 ❌ 就改，改完再审下一块
```

**为什么逐块做**：资产是**靶子**——**一块写歪，下游每一条镜头都跟着歪**。（最常歪的三块：**布光**（写成了场景光）· **材质与脏**（写成"有些旧了"）· **身份锚点**（写成气质词））

## 零、先看清：资产与镜头的板块不是同一套

| | 镜头提示词 | 资产提示词 |
|---|---|---|
| 组织方式 | **12 块层序**（`shot-craft.md`） | **五段式协议**：置景 / 美学调性 / 镜头 / 光影 / 质感与后期　**★ 12 块的接口规格（本文件只覆盖资产侧 9 块）→ `references/block-spec.md`** |
| 里面的人 | 在表演、在动 | **静止**——没有时间，只有一个状态 |
| 目的 | 讲清"这 5 秒发生了什么" | 讲清"**这是谁 / 这是什么样**"，供下游每一条继承 |
| 光 | 场景动机光（有出处） | **中性的、可继承的**（中性光 / 摄影棚暗调 / 空间光源逻辑） |
| 首要矛盾 | 时间线一股脑塞太多 | **板式太杂 → 下游继承到杂物** |

**一句话判据**：**资产图是"靶子"，不是"作品"。** 好不好看排第二，**能不能被下游继承**排第一。
（依据：`asset-consistency.md` 一·补——光不对的图"再像也没用，它会污染下游每一条"。）

**★ 推论：「真实」在资产阶段指材质，不指光影。** 这是本手册最反直觉、也最容易写错的一处——
**资产图上越"有光影味道"，下游越接不上**（那张图的光会被每一镜继承）。
所以资产阶段的"真实自然"只该花在**材质与使用痕迹**上（毛孔 / 胡茬 / 磨损 / 纤维 / 指纹 / 接触阴影），
**不花在戏剧光、浅景深、暗角、光晕上**——那些是镜头阶段的活。
**按量级系分**：**写实系**要材质真实；**描边系 / 第三系连材质真实也不能要**——"真实毛孔""柔和高光滚降"是这两系的**禁用词**，
写进去就会掉回写实，**风格化的第一个翻车点就在这里**。

**资产侧必须写、镜头侧不写**：身份锚点冻结块 · 分区或视角清单 · 尺度关系 · 色板 · 参考范围声明。
**资产侧不许出现**：时间线 · 人物表演 · 物理反馈 · 摄影机运动 · 过渡压力 · 声音 · 结尾留白。
> **为什么**：**资产没有时间轴**。塞进时间线与动作句，模型会开始编动作，把"靶子"拍成"片子的一帧"——而这一帧还要被下游每一镜继承。

### 板块 1 · 板式行（这张图下游怎么用）

- **回答什么**：这张图是**板**还是**单张**，里面装几个分区／几个视角
- **写之前的思考**：① 下游拿它做什么（锁身份 / 锁空间 / 锁物件 / 只是设计稿）② 装多了会不会**引入第二个主体** ③ 几个分区才够下游用（不够＝下游再抽卡，多了＝注意力被分摊）
- **必需元素**：**画幅比例（写成数字）** + **分区数或视角数** + **分区之间的分隔方式**
- **可抄句式**：
  ```
  一张完整的[角色设定板 / 道具资产设定图 / 场景设定图]，[超宽横版 / 16比9]排布[十 / 五 / 四]个编号分区，
  分区之间用细白线分隔，[浅灰白 / 深灰褐渐变]背景。
  ```
- **模型读得懂**：✅ `超宽横版，十个编号分区，细白线分隔`——版式词模型学过；❌ `超宽横版` 不带比例数字 → 比例随机，**要写 `16比9` / `21比9`**；❌ `做成一张酷炫的角色大全` → 开始拼贴，人物比例互不一致
- **★ 硬边界**（`asset-consistency.md` §3.0 · 2026-10-31 改）：**人物七件（脸部特写＋五视角＋无头身体）全部作为资产被引用**，但**每镜只挂一张带脸图**（`asset-standard.md` §3.2）；**四合一拼板仍是设计稿**；**按脸数合并**（前+后 / 左+俯）允许，一张图里 ≤1 张脸。**无生命道具**的多角度拼图**可直接当参考图**（无面部身份风险）。**★ 这条禁令与量级系无关**——它禁的是"一张图里出现两张有效脸"，与画法无关；**描边系片与第三系片同样适用**，不因为"想展示画风 / 多给几个姿态"而放宽
- **源头**：`updream-workflow.md` 角色/道具/场景三节 · `asset-consistency.md` §3.0 §3.1

### 板块 2 · 身份锚点冻结块 ★（资产侧的"命门"）

- **回答什么**：这个人（或这件东西）**不可变、且每镜都看得见**的特征是什么
- **写之前的思考**：① 哪些特征**每一镜都看得见**（脸型 / 眼距 / 发型发色 / 疤痣 / 随身物）② 哪些只是**这一张图碰巧有**（表情 / 光照下的肤色 / 当前姿态）③ 有没有**形容词型描述**混进来（"坚毅""沧桑"是判断，不是特征）
- **必需元素**：**40–70 字，逐字复用、永不改写**；全部写成**可判的物理事实**，不写气质
- **可抄句式**：
  ```
  [年龄][族裔/地域]男性，[脸型]，[颧骨或下颌特征]，[发型发色]，[发际线特征]，
  [疤：位置+长度+颜色]，[痣：位置+大小]，[手部或身体标记：位置+形状]，
  [服装：颜色+款式+磨损处]，[随身物]。
  ```
- **模型读得懂**：✅ `左眉中段一道约3厘米的浅白色旧疤`（位置 + 长度 + 颜色，三项可判）；✅ `右手食指第一节一道横向压痕`；❌ `眼神里有一种历经沧桑的感觉` → 只会得到一张**通用沧桑脸**（等于没写）；❌ `服装有年代感` → 必须写具体：`藏青色旧式邮电工作服，袖口磨白`；❌ `大约四十多岁` → **写死**：`43岁`
- **★ 铁律**（`asset-consistency-part2.md` §七 第 5 条）：**冻结块里改一个词就是换人**——`钴蓝色波波头` 改成 `蓝黑色短发`，模型当成新角色；**词汇表也要冻结**（进 `production-ledger.md` 记账）
- **★ 位置**：身份锚点句放**人物段的最前**（位置权重最高，见 `asset-consistency.md` §二）
- **源头**：`character-continuity.md`（逐字复用与造型状态表）· `production-ledger.md`（冻结块记账）

### 板块 3 · 分区 / 视角清单 ★

- **回答什么**：这张板上**每一格分别解决下游哪个需求**
- **写之前的思考**：逐格问"**下游哪一步会用到它**"——答不出的格子**删掉**；格与格之间**只变一个变量**（视角 / 材质 / 情绪），其余全部锁定
- **必需元素**：每格**编号 + 视角或内容 + 一个变量**；跨格一致性锚定句
- **可抄句式**：
  ```
  分区2 全身三视图：并排站立——正面、左侧、背面，全身入画，双手自然下垂，穿完整服装。
  分区8 表情表：一行四个头像——[四个情绪，取自人物弧线]，其余五官与发型完全不变。
  ```
- **模型读得懂**：✅ `其余五官与发型完全不变`——**这句必须写**，否则每格换一张脸；✅ 方向写全（`正面、左侧、背面`）；❌ `各种角度` / `多来几个表情` → 数量与方向都随机
- **★ 数量纪律**：视角**够用即止**（道具按"画面上实际要展示什么"给——一个背包给 3/4 + 正视两张就够承载帆布纹理、刺绣贴与抽绳）；**视角越多一致性越差**（实测 2–3 最好，6–8 开始降，9+ 崩，见 `asset-consistency.md` §三）
- **★ 缺机位的正解不是"加视角"**，而是**从已锁定的一张派生新机位**（`asset-consistency.md` §3.1：Angles 类工具，或"复用提示词只改机位一个变量"）
- **源头**：`updream-workflow.md` 角色设定版十分区 · `asset-consistency.md` §三 §3.1

### 板块 4 · 美学调性行

- **回答什么**：这份资产属于**哪一部电影**（而不是"哪种好看"）
- **写之前的思考**：① 类型 ② 年代 ③ 全片时段——**三个都写**；它是所有资产共享的一行，**全片只有一个答案**
- **必需元素**：类型 / 年代 / 时段 / "角色（道具、场景）资产图"
- **可抄句式**：
  ```
  美学调性：[类型] / [时代] / [全片时段] / 角色资产图。
  美学调性：[道具的年代与来历，一句话]。
  ```
- **模型读得懂**：✅ `当代都市 / 2010年代 / 冬夜 / 角色资产图`（三项齐全）；❌ `美学调性：电影感` → 等于没写，模型给训练数据里最"电影"的那张（高饱和 + 浅景深 + 干净）；❌ 每张资产写不同年代或时段 → 同一部片里出现两套世界
- **源头**：`shot-craft.md` 调性四元组 · `style-library.md`（风格编号的"色彩光影"行）

### 板块 5 · 材质与脏 ★（无生命资产的"身份"就是磨损）

- **回答什么**：这件东西**被用过多久、怎么被用的**
- **写之前的思考**：① 至少 3 处具体磨损（位置 + 形态，带尺寸更好）② **材质受光响应**（金属哑光带划痕 / 布料吸光 / 塑料留指印）③ 有没有"状态变化"需要单独一版
- **必需元素**：**逐处写脏 ≥3 处** + 材质受光响应 + **接触阴影**
- **可抄句式**：
  ```
  逐处写脏：[磨损1：位置+形态]、[磨损2]、[磨损3]；
  [材质受光响应：金属哑光带划痕 / 布料吸光 / 塑料留指印]；道具底部有柔和的接触阴影。
  ```
- **模型读得懂**：✅ `台灯底座边缘一圈掉漆，露出底下黄铜色，直径约2厘米`；✅ `桌面被反复摩擦出一块浅色哑光区，位于杯子左侧`；❌ `有些旧了` / `有使用痕迹` → 出来是**全新塑料**（实测最常见的失败）；❌ **无磨损描述 = 模型默认全新**——`逐处写脏是硬要求`（`updream-workflow.md` 道具节）

**★★ 两条实测修正（2026-09-20 · Z Image Turbo 1K · 两次实生成，各 1 张）**
- **① "哑光 / 不反光"是弱约束**：写"桌面哑光、不反光"，**桌面照样出镜面反光**（两次都被违背）——**否定型材质词 ≈ 没写**。改写成**可见的正面状态**：`桌面漆面完全哑光：光落在桌面上只是整体明度抬高一层，没有形状可辨的亮斑，也没有任何倒影`。（这是 `quality-layer.md` §四·1a「瑕疵不写否定句」在**材质**上的同一回事——此前库里只举过瑕疵与动作的例子）
- **② 写了「位置＋形态＋尺寸」仍会漏**：道具 **2/3 落地**（漏掉"杯身左侧三厘米掉瓷线"）、场景 **3/4 落地**（起泡剥落也做了）→ **资产图必须逐条复核写脏项**，**关键破损点建议单独占一处、必要时再抽一次**。

**★★★ 三条通则（2026-09-20 · 工作流第二步三张资产实测：角色三视图 / 场景多角度板 / 单镜故事板）**
- **① 小于画面约 2% 的细节标记，默认会被省**：三张图、三个不同对象、同一种失败——"三厘米掉瓷线"漏、"鬓角白发与半厘米疤"不可见、"两指宽的踢白"不可辨。**修法：把它放大成"整块变化"，或单独占一处并接受重抽。**
- **② 整体性基调必须前置到首行**：色板（灰绿墙 → 出成奶白、深橙红地面 → 出成浅米）与构图纪律（单点透视、中轴对称）**写在提示词中后段＝权重被稀释，全丢**。**修法：色板 / 透视 / 对称这类"整片基调"，首行就写死。**
- **③ 板式类约束执行率最高，可直接依赖**：三视图并排、多角度板并排、单格故事板、纯中性灰底柔光无影、纯黑白灰、无文字——**全部达标**。**资产的"硬格式"不用反复试，把精力放在上面两条。**
- **★ 状态有变化的道具**（铅笔变短、灯色变红）：**每个状态单独一版**，版本号命名，**不在同一张图里画状态变化**
- **★ 与人交互的物件**（门把 / 开关 / 杯柄 / 笔）：**必须单独出资产**——它同时是 `ai-artifact-control.md` 的"接触面"
- **源头**：`updream-workflow.md` 道具节 · `ai-artifact-control.md`（接触面）· `carrier-artifacts.md`（介质痕迹机理）

### 板块 6 · 尺度关系 ★（最容易整块漏掉）

- **回答什么**：这件东西**相对人有多大**
- **写之前的思考**：① 它会和人物同框吗 ② 同框时占画面多少 ③ 出资产时有没有给**参照物**
- **必需元素**：与**人体某部位**的比例（部位对照或数字），不写形容词
- **可抄句式**：
  ```
  [道具]高约[数字]厘米，大约到成年人的[膝盖 / 腰 / 胸口]；
  与[角色]同框时占画面[比例]。
  ```
- **模型读得懂**：✅ `高约90厘米，大约到成年人的腰`（部位对照，模型能算）；✅ 出资产时**放一个参照物**（一只手 / 一枚硬币 / 人物剪影）；❌ `尺寸适中` / `比例协调` → **每镜比例都会变**，剪辑时道具忽大忽小
- **★ 为什么单列成块**：道具**豁免表演类动测**，**唯一要验的就是"与角色的尺度关系"**（`asset-consistency-part2.md` §八）——所以它必须在提示词里被写死
- **★ 一旦定下就进冻结块**，与身份锚同等待遇（`production-ledger.md` 尺寸参照资产）：`两倍` 改成 `大约两倍` 就是漂移源
- **源头**：`production-ledger.md`（尺寸参照资产）· `asset-consistency-part2.md` §八（道具豁免动测）

### 板块 7 · 色板 ★（人读副本；基准写在脸部特写第 7 块）

- **回答什么**：这部片**用哪几个颜色**
- **写之前的思考**：① 主色从**服装与场景**里取（不是从色环里选）② 6–12 个，**列成网格** ③ 它一旦定下，**后续所有镜头的色彩都对齐它**
- **必需元素**：六列两行或近似网格 + 色块 + 每块一个名字 / hex + **"即人读副本（基准见脸部特写）"**
- **可抄句式**：
  ```
  分区4 色板：六列两行网格色块——[本片主要色 6-12 个，每个附名称与 hex，即人读副本（基准见脸部特写）]。
  ```
- **模型读得懂**：✅ 把**色名或 hex** 直接写进色板分区（hex 是锚点，见 `color-science.md` §八）；❌ `柔和的色调` → 模型按**它的默认审美**给（高饱和青橙那一套）；❌ 色板与正文写的配色不一致 → 模型二选一，通常**选色板**（它是视觉锚）
- **★ 与镜头端的接口**：色板落定后，镜头提示词里的色彩陈述要与它**同族**（`color-science.md` §八 · 色彩弧线在 `color-narrative.md`）。**资产色板是"基准"，不是"参考"**
- **源头**：`color-science.md` §八（色彩 → 提示词的转化）· `color-narrative.md`（色彩弧线）

### 板块 8 · 布光（三种资产，三种光，不许混）

- **回答什么**：这张图的光**能不能被下游继承**
- **写之前的思考**：先选**这一张属于哪一类**——① 角色 / 道具设定图 → **可继承的中性光** ② 道具静物 → **摄影棚暗调** ③ 场景 → **该空间的光源逻辑**。**选错＝污染下游每一条**
- **必需元素**：
  - 角色 / 道具：**柔和顶中性光 + 一点暖色边缘光**、**几乎不产生投影**、**头发无高光斑**、**眼里有眼神光**
  - 道具静物：**单一顶光 + 一侧柔光** + 背景渐变 + 底部接触阴影
  - 场景：该空间光源逻辑 + **光池衰减** + **混色脏带** + **死黑比例**
- **可抄句式**：
  ```
  全板统一光照：柔和的顶部中性光加一点暖色边缘光。
  统一摄影棚暗调布光：单一顶光加一侧柔光，背景深灰褐渐变，道具底部有柔和的接触阴影。
  ```
- **模型读得懂**：✅ `柔和均匀的光、几乎不产生投影`（"不产生投影"可判）；❌ `打光高级一点` → 给**大面积锐利高光 + 均匀油光**（教科书式 AI 味）；❌ **用场景动机光出角色资产图** → 这张图的光会被下游每一镜继承，**人景光影永远接不上**（"人像贴上去"的根源）
- **★ 筛查顺序**（`asset-consistency.md` 一·补）：**先看光，再看像不像**——光不对的图**直接淘汰**，不要因为它"长得像"就留下
- **★ 例外**：**首帧版**角色资产**才用场景光**（它的任务就是当某一镜的首帧）——同一角色的**资产版与首帧版是两个文件**，不许混
- **源头**：`asset-consistency.md` 一·补（三条硬规格）· `light-quality-construction.md`（柔光造法）· `updream-workflow.md` 场景节（光池与死黑）。**⚠️ 这里三档全是写实系**——描边系用"纯色 / 渐变底 + 平光"，第三系按工艺（见「★ 分系替换表」）

### 板块 9 · 统一提质层（资产版）+ 禁止项

- **回答什么**：这张图的**观感与全片其他图是不是同一次拍摄**
- **写之前的思考**：① 本片方案包的**器材行 + 痕迹行逐字粘**（一片一包；**资产与镜头必须同包**）② 资产用**中性光**（不用场景光）③ **省略运动句** ④ 禁止项按 `quality-layer.md` §四 的三类分诊写
- **必需元素**：量级句（逐字粘包）+ 高光颗粒句 + **皮肤哑光句**（人物类身份段末尾）+ 禁止项 + **无文字 / 无配乐 / 无字幕 / 无水印**
- **可抄句式**：
  ```
  [本片方案包·器材行逐字]；[本片方案包·痕迹行逐字，至少三项]；
  高光平滑滚降、渐进出白不裁纯白，过曝处仍带暖色；
  暗部是有机银盐颗粒簇、暗部粗中间调细，不是均匀数码噪点；
  皮肤始终哑光，毛孔与胡茬清晰可见，高光只是额头与鼻尖的小点，禁止磨皮与蜡像油光。
  ```
- **模型读得懂**：✅ `皮肤哑光，高光只是额头与鼻尖的小点`（连高光**位置**都写了，可判）；❌ `皮肤质感真实` → 给**磨皮 + 油光**（它认为那才"真实"）；❌ 在资产里写 `摄影机缓慢横移` → **资产没有时间轴**，模型会理解成"拍成一条片"，构图随之被破坏
- **★ 油脂感必须在资产阶段掐掉**（`updream-workflow.md` 一·补）：等镜头阶段再修已经晚了，因为下游每一镜都继承这张图
- **★ 参考范围与不继承项**（资产必须写、镜头侧不写）：`仅参考图片1的面部特征，不继承其服装、背景、构图与光线`——**最需精准的参考图放最前**（位置权重最高）。用法与常见映射见 `asset-consistency.md` §二
- **源头**：`quality-layer.md` §二（逐字块）§三（适配表）§四（禁止项三类分诊）· `skin-realism.md`（哑光句的成因）。**⚠️ 本块是写实系版**——描边系 / 第三系**整块替换**（见「★ 分系替换表」），**上面三句真实感台词在另两系是禁用词**

## ★ 分系替换表（写实 / 描边 / 第三系 —— **本手册默认写的是写实系版**）

上面 9 块的**骨架三系通用**（板式 · 身份锚点 · 分区 · 调性 · 材质与脏 · 尺度 · 色板照写）；
**只有「8 布光」与「9 统一提质层」两块按系整体替换**，另有几句**必须删掉**。

| 块 | 写实系（本手册默认） | 描边系（`stylized-look.md` §二 §三） | 第三系（`style-library.md` §二 系三） |
|---|---|---|---|
| **8 布光** | 角色 / 道具：柔顶中性光 + 暖边光、几乎不产生投影；道具静物：单一顶光 + 一侧柔光 | **纯色或渐变底 + 平光**；光只负责**分色块**（亮面 / 中间调 / 暗面），不做真实衰减 | 由**工艺本身**决定光：定格＝小台灯式硬光（留压痕）· 水墨＝留白 · 像素＝不留光 |
| **9 量级句** | 器材行 + 痕迹行逐字粘 + 高光滚降 + 银盐颗粒 | **风格化量级句**（粗黑描边 / 平涂硬边 / 互补边光 / **色相与占比写死**） | **渲染方式句**（说清"怎么造出来的"）**+ 同时禁掉写实与描边两系** |
| **必须删的句** | — | ❌ `皮肤哑光，毛孔与胡茬清晰可见` ❌ `高光平滑滚降、渐进出白` ❌ `有机银盐颗粒簇` ❌ 器材行 | ❌ 同上 **+** ❌ `描边` `平涂色块` `赛璐璐` |
| **一致性锚点换成** | 量级一致 + 高光颗粒一致 | **描边一致 + 色块层级一致 + 做旧强度一致** | **工艺痕迹一致**（指纹 / 压痕 / 像素格 / 笔触） |
| **真实感去处** | **材质与使用痕迹**（毛孔 / 磨损 / 纤维） | 做旧划痕与网点（**不写毛孔**） | 工艺的物理证据（指纹 / 刀痕 / 纸边） |

**判据（一句话）**：把资产提示词给一个没看过画面的人——**他能说出"这是用哪套工艺、哪台机器做的"吗？** 说不出 → 量级句写错了系。

**跨系不变的三条**：`asset-consistency.md` 一·补 的三条硬规格**三系都成立**——
① 背景干净（写实＝纯中性灰 / 描边＝纯色或渐变底 / 第三系＝按工艺）；② **光照平到不出现硬投影**；
③ 场景 3/4 角度、能见两面墙。**只有第 ① 条的颜色与第 ② 条的光照表述要按系换词。**

> **为什么单列这张表**：写实系那三句"真实感台词"**正是描边系与第三系的禁用词**。写实片写顺手的人，
> 给风格化片写资产时会**条件反射地写上它们**——**结果整片资产掉回写实，与镜头端割裂**。

## 资产侧最容易写歪的三块

1. **布光（写错＝全片报废）**——把场景动机光写进角色资产图。**表现**：每一镜人像都像"贴上去的"。**修法**：资产用中性光，场景光只留给首帧版。
2. **材质与脏（写虚＝白出）**——`有些旧了`。**表现**：全新的塑料道具出现在用了二十年的房间里。**修法**：逐处写脏，位置 + 形态 + 尺寸三件齐。
3. **身份锚点（写判断＝没写）**——`眼神沧桑`。**表现**：每张脸都像，但**不是同一个人**。**修法**：全部换成可判的物理事实，词汇表冻结。
