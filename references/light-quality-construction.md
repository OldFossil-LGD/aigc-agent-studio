# 光质构造层（同一个「柔光」有五种造法）

> **何时读**：把方案包选定、要写「光」这一轴时。**读完回哪**：回 `camera-package-library.md` 填包的「光质」轴，再回 `quality-layer.md`。
>
> **为什么需要**：六轴里「光质」原来只有四个词（现场光 / 硬闪 / 棚光 / 屏幕光）——太粗。
> 模型读到"柔和的自然光"时，只会在"A 大平光"与"B 全黑"之间选；**它不知道柔光有构造差异**。
> 本篇把光质拆成**可写的构造**，让"柔"变成一个**有造法、有出处、有破绽**的东西。

> **总纲一句话**：**光不是亮度，是"从哪里来、经过什么、落在脸上什么形状"。**
> 写光的四个必答：**① 源在哪 ② 经过什么（柔化手段）③ 落在脸上是什么形状 ④ 破绽在哪（阴影、双影、眼神光）。**

> ## ★★ 先读这一条：本页的"造法"是给你的认知工具，不是写给模型的指令
>
> **本页 §一–§三 用剧组语言写（大源近置 / booklight / 灯阵并排 / 负补光 / 把灯挪近）。**
> **这些词的作用是让你分得清"柔"的构造差异 —— 它们不进提示词。**
>
> | 你看到的 | 它是什么 | 生成模型怎么看 | 提示词里该写什么 |
> |---|---|---|---|
> | `大源近置` `booklight` `灯阵` `负补光` | **你的认知工具**：帮你判断这块柔光"是哪一种"、破绽在哪 | **看不见**。模型不会去搭灯、不会挪灯，**只会画结果** | 写**结果**：光包裹感／过渡长短／影子有几组／眼神光什么形状 |
> | `光位 45°` `逆光` `眼平` `半张脸` | **画面可读的结果** | **看得见**：训练数据里 45° 侧光长什么样，模型学过 | **可以直接写**，这是结果不是动作 |
>
> **判据一句话**：写完一句光，问 **"模型是去'做'这件事，还是去'画'这个结果？"**
> —— 答"去做"（搭灯、挪灯、关灯、拨色温）→ **改写成结果**；答"去画"（什么地方亮、影子几组、过渡多长）→ **可直接写**。
>
> **正确示范就是本页 §四第 131 行**：写**结果**（脸被油灯般的光照着一小块），不写**器材**（加了一盏 650W）。
> **反面示范**：写"把灯挪近一点"——模型不会挪灯，它只会随机给你一种柔光。**你要写的是"光贴着皮肤包过来、影子几乎消失"。**

## 一、柔光的五种造法（这一节是核心）

同样是"柔光"，五种构造在脸上留下的东西完全不同。**选一种写，不要写"柔光"两个字就收手。**

> **读法**：前三列是**给你的判断依据**（怎么造 / 结果 / 破绽）；**第四列「提示词落地」才是能直接抄进提示词的句子。**
> 你**不需要**告诉模型"这是 booklight"，只需要抄第四列。

| 造法 | 怎么造（你的认知） | 落在脸上的样子（判断依据） | 破绽（判断依据） | **提示词落地（可直接抄）** |
|---|---|---|---|---|
| **① 大源近置**（big source, close） | 一块大的柔光布 / 反光板，**离脸很近** | 光包裹感强、明暗过渡极长、几乎没有投影 | 肤色会**偏暖、偏润**；人的表情会本能地放松｜眼微眯一下 | `一块大面积的柔光几乎贴着左侧脸包过来，明暗过渡从脸到肩拉得很长，脸上几乎找不到影子；光色调偏暖，皮肤表面被照得湿润` |
| **② booklight（书灯）** | 灯先打向一块反光板，**再经柔光布**折一次 | 极柔但有**方向性**；皮肤上仍保留结构 | 反光板的边缘可能漏出**第二条影子** | `光很柔，但方向明确——从人物左前方过来；皮肤的起伏仍看得见，不是被磨平；**墙上只有一条影子**` |
| **③ cove（环形／包覆光）** | 一圈灯管或一整面发光面**包住演员** | 几乎没有明暗差、脸像"没有影子" | **太平**——必须靠负补光重新找回对比，否则像证件照 | `四周的光把人物从两侧和上方同时包住，脸上几乎没有明暗差；**只有右侧下颌有一道窄窄的暗部**，皮肤纹理照样清楚`（**不写"整体明亮均匀"——那是 AI 默认值**） |
| **④ 灯阵（array）** | 多盏灯**紧密并排**，或加柔光纸把光束合并 | 明暗过渡连续、无断点 | 灯间距没排好 → **多重影子**（这是硬伤，见 §三） | `光从正前方大面积铺开，明暗过渡连续、没有断点；**墙上/身上只有一组方向一致的影子**` |
| **⑤ 反弹（bounce）** | 打向天花板 / 墙面 / ultrabounce，**靠环境回光** | 光像"从空间里来的"，没有明确单点 | 屋顶与墙面颜色会**污染光色**（白墙回白、木顶回暖） | `光看不出明确出处——像是从整个房间的顶部漫下来；**光色带着天花板的暖木色**，头顶最亮、往下慢慢暗` |

> **一句话判据**：写完光，问"**这块柔光是哪一种造的？**"——答不出，模型就会用"大平光"替你答。
> **★ 但答出来的那个名字不要写进提示词**：名字是给你自己听的，提示词里只落**第四列**的句子。

### ★ 一条反直觉纪律：**柔光 ≠ 低对比**

很多人以为"柔"就是"对比低"，于是一路柔下去，结果脸像证件照。
**专业的做法是：用柔光造脸，用负补光（negative fill）拿回对比。**

| 手段 | 做什么 | 结果 |
|---|---|---|
| 主光用柔（五种造法之一） | 让皮肤有过渡、不硬 | 脸立得住 |
| **负补光**：在暗侧放**黑色的减光板** | 把环境回光"吸走" | 对比回来，暗侧有浓度（**默认档＝保留纹理看得清；暗侧沉进黑里＝强分离档**，与 `lighting-philosophy.md` §一统一口径） |
| **逐级调暗**：从主光中心向外，光逐渐减弱 | 不靠"主光+辅光"两盏，而靠**一盏的梯度** | 过渡自然，没有"补光块"的痕迹 |

> **纪律**：**不写"主光 + 辅光"这个分法。** 写"一盏光的梯度"，或"柔光造脸、暗侧被压暗"的**结果句**（"负补光"是认知工具词，落提示词时译成"暗侧压暗 / 下颌线沉进暗里"的结果——见卷首对照表）。
> 写 key/fill 会得到**两个方向的光** → 脸上出现两块互相打架的亮区，这正是 AI 味的来源之一。

## 二、光的六个可写维度（写完五个造法后，用来把光写细）

| 维度 | 可写的值 | 写错的后果 |
|---|---|---|
| **① 源的个数** | 1 / 2 / 3 个（**超过三个就写不清了**） | 不写 → 模型默认"处处补光"；写了三个以上 → 影子方向乱 |
| **② 源的高度与角度** | 眼平 / 上方 45° / 低于眼（恐怖）/ 逆光 | 只写"侧光"→ 模型随机选高或低，影调完全不同 |
| **③ 柔化方式** | 上面五种之一 | 见 §一 |
| **④ 色温与出处** | 钨丝 3200K / 日光 5600K / 混合（窗光 + 台灯）（工业标称值） | 混合光不写清 → 肤色发脏 |
| **⑤ 落在脸上的形状** | **眼睛下方一小块** / 半张脸 / 只有轮廓 / 有一道横条（百叶窗） | 不写 → 光变成"均匀铺开"，失去构图 |
| **⑥ 破绽** | 双影 / 阴影边缘发虚或发硬 / 眼神光形状 / 光斑边缘发脏 | 不写 → 光是"完美的"，一眼假 |

### ★ 眼神光的形状（最容易被忽略、效果最直接的一条）

**眼神光的形状 = 光源的形状。** 观众会从眼睛里读出光源。所以写光时**顺手写眼神光**：

| 眼神光形状 | 说明光源是 | **提示词里怎么写** |
|---|---|---|
| 一个小圆点 | 一盏小的点光源（台灯、电视） | `眼睛里有一个小小的圆点反光` |
| 一竖条 | 竖着的柔光布 / 灯管 | `眼里的高光是一条竖细条` |
| **一横条** | 横向并排的灯阵，或**反弹形成的横向长条** | `两只眼睛里的高光都是同一条横向的细长条` |
| 一大块方形 | 窗户 | `左眼里有一块方形的窗形反光` |
| **没有眼神光** | 平光 / 光包得太死 —— **眼睛会死**（见 `performance-craft.md` 眼生命） | **不写**（缺省时模型常给死眼）；若确实是暗场，写 `画面极暗，眼里只有一点极弱的反光` |

> **纪律**：**光写得再好，眼神光不对就是假的。** 写光时最后补一句眼神光的形状。
> **★ 为什么这一列最好用**：眼神光的形状**不需要翻译**——它本身就是画面结果。**"一横条"直接就能写，模型画得出来。**

## 三、双影：柔光最硬的失败模式

**一个画面里出现两个方向不同的影子 = 立刻暴露是打的光。**

> **★ 这一节整张表都是"回去怎么改灯"——那是给现场的你。**
> **提示词里绝不能写"把灯并排紧靠"。** 你无法回到模型上一次生成里去挪灯，
> **你只能改写"下一次要它画什么"**。所以每一行都给两列：左边是**现场修法**（你的认知），右边是**提示词改法**（真正要执行的）。

| 症状 | 原因（你的判断） | 现场修法（你的认知，不进提示词） | **提示词改法（真正执行的一句）** |
|---|---|---|---|
| 墙上/脸上有两个影子 | 两盏灯**分开放**，各自投影 | 把灯**并排紧靠**（间距小于灯面尺寸）；或加柔光纸把光束**合并** | `光从一个方向来；墙上只有一条影子，边缘柔和` —— **把"两个灯"改写成"一个方向 + 一条影子"** |
| 鼻子下有一道横影 + 下巴一道影 | 灯位太高 + 还有一盏在更低处 | 统一到一个方向；低位那盏改为**负补光**（黑色板）而不是加光 | `光从上方偏左下来，鼻下一个短影；脸的下半部从侧面被压暗，下颌线在暗里` —— **把"加了一盏低灯"改写成"下半部被压暗"** |
| 多重影子在人身上移动 | 灯阵间距太大，人走动时影子交替出现 | 缩小间距；或改用**反弹**（无明确单点） | `人物转身时，影子始终保持在同一个方向；身上的明暗不随着动作交替跳变` |
| 眼神光里有两个亮点 | 同上 | 灯阵并排到眼神光合并成一条 | `两只眼睛里的高光都是**同一条横向的细长条**` |

> **判据**：**数影子。** 一个画面里**只允许一组方向一致的影子**。数出两组，回去改光。
> **★ 提示词版判据**：把"数影子"写成**要求**——在提示词里明写 `只有一组影子`，比写"柔和的光"有效得多，因为**影子数量是模型能直接画出来的结果**。

## 四、动机光（motivated light）：光必须"有出处"

**最高原则：光是可信的，不是漂亮的。** 每一盏光都要能回答"它从哪来"。

| 光的出处 | 怎么写 |
|---|---|
| 窗 | 窗光从左侧进来；光池落在桌面上、边缘发脏 |
| 台灯 / 油灯 | 一盏油灯在画面右侧，光只够照亮桌边一小块，**脸有一半是暗的** |
| 电视 / 屏幕 | 屏幕光从正面下方打上来、**色偏冷**、会随画面变化闪烁 |
| 街灯 / 霓虹 | 头顶街灯洒下一小块光，人物走到哪里、那块光就跟到哪里 |
| 车灯 | 车灯从侧后方扫过，**扫过时脸会短暂过曝** |
| 无出处（大平光） | ⛔ 不要写"整体明亮均匀"——那是 AI 默认值 |

### ★ 一条专业手法：**造一个"假动机"**

想给脸补光，但现场没有理由 → **不要直接加一盏灯**，而是**给画面里加一个光源理由**：
> 桌上放一盏没开的台灯，然后让台灯"亮着"给脸打光。

原话精神：**不希望观众看出"光在哪"，只希望观众觉得"像油画灯照着"。** 
→ 写的时候写**结果**（脸被油灯般的光照着一小块），而不是写**器材**（加了一盏 650W）。

## 五、与方案包对接：每个包的光质倾向

不同载体**天生只能配某几类光**。写光之前先看载体：

| 包 | 光质倾向 | 写不清就出事的地方 |
|---|---|---|
| P01 手机 · P06 网络摄像头 | **只有现场光与屏幕光** | 写了"柔美主光"→ 立刻假，因为手机没有灯 |
| P02 MiniDV · P03 VHS | **机顶小灯 / 现场光 / 闪光灯直闪** | 直闪会在墙上留一个**硬影**——这是它的特征，要写 |
| P04 监控 | **红外 / 固定顶光 / 自己的补光** | 写成"有氛围的光"→ 与载体矛盾 |
| P05 转播 | **多灯大平光、几乎没有暗部** | 这是"不好看但真实"的光，要敢写 |
| P07 S16 · P11 Super 8 | 现场光为主，**常常欠曝** | 写"曝光完美"→ 不像小机器 |
| P08 35mm · P09 65mm | 五种柔光造法都能用；**讲究动机** | 不写动机 → 大平光 |
| P12 三色带 | **棚内强光、大平光 + 硬侧光** | 这是它的时代特征，**要写"过度布光"** |
| P13 大画幅数字 | 什么光都能用 → **最需要靠光来救** | 不写光 → 一尘不染的大平光 |
| P14 变形宽银幕 | 逆光与点光源最好（炫光） | 不写逆光 → 浪费这一包的唯一优势 |
| P15 老玻璃 | 遇到亮处就发光、**怕眩光** | 写"抗眩光"→ 把老镜写成了现代镜 |
| P16 高速升格 | **必须大量补光** → 偏亮偏棚（落提示词写结果：**整体偏亮、光比小、影子淡**） | 不写 → 模型不知道要补光，动作会糊 |
| P17 虚拟制片 | **屏幕自己就是光**（打在演员身上） | 不写 → 背景与光脱节，人像贴上去的 |

## 六、可直接复制的成套句

### 1. 柔光 + 负补光（五种造法之「大源近置」）—— 写光写的是**画面上的结果**，不是布光动作

```
光位：一扇窗在人物左前方，窗光直接照进来；人物右侧不放任何补光，
画面右侧暗部的边界清晰、衰减快，看不到环境回光把暗处抬起；
明暗过渡从脸的左侧一直延伸到右侧，暗侧保留浓度但看得清纹理。
眼神光：左眼有一点窗形的方形反光。
```

### 2. 现场光（手机 / 监控这类"没有灯"的载体）

```
光位：光线全部来自现场——头顶的日光灯、墙上一块发绿的应急灯。
没有主光，脸是平的，下巴下面有一点影；右侧肩膀落在更暗处。
不许出现柔美的布光；画面里没有任何"摄影灯"的痕迹。
```

### 3. 逆光与妖光（变形宽银幕 / 老玻璃）

```
光位：主光在人物身后偏左，形成轮廓；人物正面没有补光、接近剪影但保留眼睛。
逆光经过画面左侧的一盏路灯时，拉出一道横向的暖色光条；
高光处形成一圈发光的 halation，边缘发暖、不裁成纯白。
眼神光：没有——眼睛在暗处，只有一点极弱的反光。
```

## 七、自检五问（写完光，逐条问）

1. **源在哪？** 能说出具体出处（窗 / 台灯 / 屏幕 / 街灯）吗？
2. **经过什么？** 这块柔光是五种造法里的哪一种？
3. **落在脸上什么形状？** 是"半张脸"还是"一小块"？——不许答"均匀"。
4. **破绽在哪？** 数影子：**只有一组方向一致的影子吗？** 双影就回去改。
5. **眼神光对吗？** 形状与光源一致吗？**没有眼神光 = 眼睛会死。**

> **零命中 ≠ 合格**：五问只是"没踩已知的坑"。

### ★ 第六问（AIGC 专属，前面五问都不覆盖）

6. **这句写的是"让它去做"还是"让它去画"？**
   - 若句子里出现 `挪灯 / 并排 / 加柔光纸 / 关掉一路 / 拨到 4200K / 上反光板` —— **这是动作，模型做不到**。
   - 改写：**同一个意思换成"光落在画面上的结果"**（影子几组、过渡多长、哪侧有浓度、眼神光什么形状）。
   - 对照：§一–§三每张表的最后一列，就是"结果写法"的现成句子。

> **为什么单独立这一问**：前五问只管"物理对不对"，**第六问管"模型听不听得懂"**。
