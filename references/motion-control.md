## 一、动作控制决策树（最重要的规则 · 动笔前必过）

> **硬约束：周期动作（走路 / 奔跑 / 负重位移 / 舞蹈 / 连续循环动作）禁止用纯文字提示词求解。**
>
> 已两次实测确认这是**能力边界**，不是措辞问题。控制动作靠的是**动作模板**（参考视频）或**端点锚点**（首尾帧），
> 文字只负责风格、场景与镜头。

| 优先级 | 路径 | 怎么做 | 适用 / 局限 |
|---|---|---|---|
| **① 首选** | **参考视频驱动**（MOTION_REF） | 手机拍 3–5 秒真人动作：**纯色背景、无遮挡、开防抖、只做 2–3 步**；用即梦 Seedance「@视频参考」或 Kling Motion Control（第三方入口名以平台现状为准，2026-09 核实）；提示词按下方**两步写法** | **成功率最高、截至 2026-09 的首选**（②可拆段后也能接长）。**局限：道具/重物接触会脱手**——模型算的是像素不是刚性约束 |
| **② 次选** | **首尾帧单步**（FLF_STEP） | 首帧＝站立预备姿，尾帧＝迈出落地姿；**单段 2–3 秒**；多步拆成多段（起步 / 迈一步 / 落定）；**切在抬脚或脚跟着地的瞬间** | 不需要参考片；只给两端，中间由模型猜，差异大时会变成"形变"而不是真步态 |
| **③ 规避** | 构图绕开"地面 + 双腿" | 低机位 + 前景遮挡（沙垄 / 门框 / 芦苇）、与主体同速跟拍、背影或剪影、浅景深虚化脚部、**从画外走入并停下**（只有 1–2 个接触事件） | 保留氛围与重量，不暴露解剖。**失败率与"可见地面参考线"成正比** |
| **④ 兜底** | 实拍 / 3D 预演 | 让实拍或 3D 出主体运动，AI 只做背景扩展、换风格、氛围层 | 核心叙事镜头的正确工程解 |

**决策树验收三问与回退（2026-09-30 补）**：选完路径后自问——① **这条路径的产出能过战斗矩阵 5/5 吗**（→ `production-ledger.md`）？② **失败时下一跳是哪条**（按 ①→②→③→④ 顺序逐级回退，**不跳档、不倒退重试已失败的档**）？③ **重试上限到了吗**——同一路径累计 8 次不过 → **换下一档**（→ `production-ledger.md` §四"改结构不换词"），不许在原路径无限重抽。

### ①·补 ★★ 参考视频的**第二种用法：整片的调度蓝本**（2026-09-13 补 · 火山方舟官方）

**上面 ① 是"一段动作"的参考；官方示例里还有更强的一种**——把**白模 / 素版参考视频**当作**整支片子的镜头语言蓝本**：

```
以白模参考视频 <video1> 作为整支视频唯一的运镜、镜头节奏、景别变化、主体运动轨迹和
镜头调度参考，严格保持白模视频的镜头顺序、机位变化、运动方式和节奏，
不改变镜头结构，不新增镜头，不改变主体运动逻辑。
结合各阶段关键帧参考图，生成一部 30 秒电影级 3D 动画短片，整体风格……
角色外形与各阶段的关键帧保持一致，不要改变角色形象。
```

**要点**
> **上块为火山方舟官方示例的逐字引用**（含"电影级"这类词）——引用是为了给证据。**本库自己写提示词时，仍照 `ai_smell_check.py` 的清空话词纪律执行**（"引用原文"与"本库处方"是两件事）。
- **锁的是"结构"**：镜头顺序 · 机位变化 · 运动方式 · 节奏 · 主体运动轨迹 · 调度 —— **一次锁六样**
- **配"各阶段关键帧参考图"**锁角色外形与风格（两条腿：结构靠视频，外观靠图）
- **必须显式写"不改变 / 不新增"**（`不改变镜头结构` · `不新增镜头` · `不改变主体运动逻辑`）
  → 这三句是**保持型否定**（有正面参照物），本库三类分诊**许可**（`quality-layer.md` §四）
- **官方示例是"一条提示词出 30 秒"** —— 说明**长秒数不是靠拼接，是靠"蓝本 + 关键帧"**

**独立第二源印证（B站 · 北京卫视跨年 AIGC 片幕后）**：
> *"用**线稿规划**先把**镜头骨架、调度、主次关系**锁死，再让 AI 填光影与材质，避免跑偏。"*

**两者是同一件事的两种形态**：**白模视频 / 线稿规划**。平台入口：**updream 的「预演台」3D 白模片场**（→ `updream-workflow.md`）。

**怎么嵌进本库流程**
```
站 2 可行性门 → 站 4 剧本 → ★ 用白模 / 线稿把整场（或整片）调度预演一遍
   → 预演视频当 @video 参考 + 各阶段关键帧当参考图 → 站 6 一条提示词出多镜
```
**判据**：**这场戏有 ≥3 次机位切换、且机位关系承载叙事** → 值得先做白模预演；只有一两个镜位的场面不值得。

### ① 路径的提示词写法：保留清单 + 1:1 转移句（两步，缺一不可）

只写"参考 @视频1 的动作"太弱——模型会把它**重新解释**，然后漂掉。分两步写：

**第一步 · 列保留清单**（明确写出要原样搬过来的东西）：
```
保留以下全部：动作、身体姿态、位移路径、节奏与停顿、表情变化，
以及摄影机的起始位置与完整运动轨迹。
```

**第二步 · 写唯一变化 + 锁定转移方式**：
```
从源素材 1:1 转移，不要重新解释。
唯一改变：[要改的那一项]。
```

> **一条反直觉的纪律**：**模型会自己补你没拍的物理**（风、倾斜、视差）——**这是卖点，不要压掉。** 不要写成"不要添加额外运动"。

**三条配套纪律**：

1. **分镜阶段就标注**哪些镜头需要参考视频，并明确告诉用户"需要一段 3–5 秒真人参考片"。
2. **重物/道具的接触**：用**环境反馈**（拖痕、扬尘、水面波纹）或**后期合成**兜底，或让重物大半被前景遮挡。
3. **参数边界**：**"运动幅度 / 运动强度"调高只放大位移，不修正动作正确性**——调高只会得到"更活跃的同一种滑步"。

**最差构图（务必避开）**：**侧向全身 + 清晰可见的地面参考线**。这正是我们前两次翻车的构图。

## 二、时间纪律（为什么单镜要短、切点要落在动作节点）

- **扩散模型在 1.5–2.5 秒后连贯性开始衰减**——动作会出现"走到一半忘了在走"的漂移。
- 因此：**单段控制在 2–3 秒**；需要更长就拆成多段。
- **切点落在动作节点上**：抬脚的瞬间、脚跟着地的瞬间、发力的一刻。
  在这些瞬间剪辑，接缝最容易被藏掉——四段两秒的小片段，读起来比一段四秒的连续动作可靠得多。

### ★ 补：**要延长的镜头，结尾不能"收"**（2026-09-13 补）

**延长（Extension）能接得上，前提是初条留了"方向性动量"。**

| 该写 | 不该写 |
|---|---|
| `持续向前移动的航拍，海岸线无尽延伸` | `球弹起来并停住` ← **完成性动作** |
| `跟拍角色持续行走` · `缓慢横移扫过山谷` | 一切"已经做完并落定"的描写 |

> **⚠️ 这与本库的「结尾留白」会冲突，必须分清**：
> - **结尾留白**追求"**收**"（余韵、不堆爆发）→ 用在**成片的最后一个镜头**
> - **可延续性**要求"**不断**"（动量）→ 用在**后面还要接的镜头**
>
> **判据**：**这一镜后面还要接东西吗？** 要接 → 结尾写"**仍在进行中**"；
> 是成片的收尾 → 才用留白。**两者写反了，要么接不上，要么片子收不住。**
> （官方同类提示：**Veo Extend 每次 +7s，但 4–5 次扩展后画质劣化**（2026-09 核实，以平台现状为准）→ 长片靠"蓝本 + 关键帧"优于靠反复延长。）

### ⚠️ 适用条件（避免与"分段镜"的两套时长规则对撞）

**上面这条只管一件事：单个动作的连续时长。**

两套规则说的不是同一个量，不要混：

| 概念 | 时长 | 说明 |
|---|---|---|
| **单动作连续段** | **2–3 秒**（**质量经验窗，优先遵守**——2026-09-30 分层） | 扩散模型的一致性衰减是经验边界；**平台硬上限按所用模型分档**（Seedance 2.0＝4–15s、2.5＝4–30s 等 → `sequence-craft.md` §8.3），两层不冲突：生成按模型档位投喂，成片单段仍取经验窗内 |
| **素材卷（一次生成）** | 可 8–15 秒 | 内部**含多个硬切**，不是让单个动作变长 |

> **一次可以生成得更长——它是"素材卷"，用来提供可被开采的密度，不是为了让单个连续动作变长。**
> **进入成片的连续片段仍必须 ≤3 秒。**

**只有当你走"分段镜"路线时才用 8–15 秒**——一条里装多个景别 / 机位，必须**写死镜数与切数**、
**每镜首词是景别**、**锚点句逐字复述**。→ 判路、镜序语法与完整模板见 `references/segmented-shot.md`。

## 三、动作与表演（基础规则）

### ★ 两级动作模型（先分清在写哪一级）

| 级别 | 管什么 | 形态 |
|---|---|---|
| **五段链** | **一个**动作的完整推演 | 准备 → 发力 → 接触 → 反作用 → 落定 |
| **拍序列** | **一串**动作的先后 | 有序动作串，见下 |

**动作永远不许用简写。** "他跳舞""他走过去"对模型等于什么都没说。

**逐拍写序列**——把动作拆成一串有序的、每拍都可执行的短动作：

> ❌ 他跳舞
> ✅ 点头两下 → 左右各一次肩滚 → 屈膝 → 响指 → 门前四分之一转身 → 收在拍一下耳罩，全程松快

> ✅ 装鞋进包 → 拉拉链 → 点头两下 → 起身

**判据**：如果这一串里某一拍**单独拿出来都看不清是什么动作**，说明还太抽象，继续拆。

- 动作五段链：准备（重心支撑）→ 发力（来源方向）→ 接触（点/时刻/材料）→ 反作用（位移/声尘）→ 落定（尾帧即下一镜输入）。
- 表演只选 2–3 个可见通道：视线 / 呼吸 / 停顿 / 重心 / 手部。情绪标签词全删，换可见信号。
- **静止要先过一道判断题**（不要再笼统说"静止是雷"）：

  > **这一镜里，静止本身在传达什么变化？**
  >
  > - **答得出来**（支配感、压迫感、等一个答案、从 A 变成 B 的那一口气）→ **保留静止**，并在提示词里**写清静止在传达什么**（`他不动，但下颌的线条一直紧着`——绷住的静 ≠ 松垮的静）。
  > - **答不出来**（只是"没想好让他干嘛"）→ 改成**小幅动作承担**：衣摆 / 呼吸起伏 / 重心微移 / 手指的一次收紧。

  允许的微动（眨眼、呼吸）+ 明确的排除项（不转头、不说话、不做手势）照旧要写。
- 动作超载降级六法：删装饰 → 合并结果 → 减角色 → 固定机位 → 拆镜 → 破坏交后期。

### 【人物表演】块（每镜必带 · 治"僵硬脸"）

> **先读 `character-depth.md` 的方法，再写这一段**——下面是**一个落地示例**，不是可照抄的模板。
> 换一个角色、换一种情绪，句子就该完全不同；照抄模板一样会写出"通用脸"。
>
> **分诊先行**：僵硬（没信息）→ 补信号；虚假（太整齐）→ 加延迟 / 半途修正 / 未完成 / 一处矛盾。
> **方法与训练 → `performance-craft.md`**（本文只给这一段的落地形态）。
> **某个情绪写不出形变 → 查 `performance-vocabulary.md` 第三节**（按情绪的肌肉 / 呼吸 / 眼神词表）；**眼睛必须单独写（眼生命）→ 同文件第二节**，不写就是死眼。

**人物僵硬、没有表情，只有两个原因**：①脸在画面里太小；②提示词只写了动作、没写**可见的表演信号**。
"她愣住了""她笑了"是**情绪标签**，模型无法执行——必须翻译成眉、眼、嘴、呼吸、重心的具体状态。
写之前先问三句：**他想让人看见什么？身体在哪背叛他？用哪里使劲克制？**

```
【人物表演】[姓名]的表演只给四个可见通道，全部写成具体的形变：
眉毛——[眉的状态：舒展 / 皱起 / 一高一低 / 上扬]；
眼睛——[眼睑开合程度 + 视线看向哪 + 视线何时移动]；
嘴与下颌——[嘴角方向 / 嘴唇开合 / 下颌是否收紧]；
呼吸与重心——[呼吸快慢深浅 + 重心往哪个方向偏]。
微动节奏不均匀：快一下、停一下、再动，不是匀速动画；
每两秒有一次自然的眨眼，视线有一次小的游移再回到目标；
表情从[起始状态]连续过渡到[结束状态]，全程连贯，不跳变。
```

三条配套纪律：

1. **脸要够大**——面部表演只在中近景、近景、特写里成立；全远景/大远景里人脸占不到画面比例，写再多表演也白写。**需要表情的镜头就给近景**（"把脆弱的东西拍大"）。
2. **情绪词→形变**：`愣住了` → `眼睛睁大到露出眼白，嘴唇微张不动，呼吸停住`；`笑了` → `嘴角先单侧上扬，再露出牙齿，眼睛眯成一条缝`。
3. **卡通/风格化片要夸张**：幅度比写实更大——眉毛抬得更高、眼睛可变形、嘴形更明确，否则在描边风格里等于没有表情。

### 被拖 / 被推物体的反馈链（物体不是平移的贴图）

| 反馈 | 怎么写 |
|---|---|
| **张力交替** | 她蹬地发力那一瞬布带绷紧、物体被拽一下；迈步间隙布带松开一点、物体往后顿一下 |
| **痕迹** | 物体在沙地上犁出**一道连续的沟/拖痕**（越靠近它越深），并把沙土向前推成一堆 |
| **摇晃** | 物体的机身随拖拽前后摇晃 |
| **受阻弹跳** | 偶尔有一条腿卡到小石块时弹跳起来再落下（**写成"偶尔"的一次变奏，不要写成定时事件**） |
| **节奏顿挫** | 整个运动是"拽—顿—拽—顿"，不是匀速滑行 |

**配套纪律**：负重动作**上半身与下半身要反着写**——腿在走、上半身后倾顶住拉力，肩膀一高一低。
只写"拖着走"三个字，模型一定给你原地跺脚。

### ⚠️ 不要用文字"教"模型走路

**实测翻车**：一条跟拍镜头里写了完整的步态分解（"右脚跟落地 → 左腿蹬离 → 下一步反过来"），
出片却是**12 帧里同一个弓步姿势在前后摇摆**——腿根本没交替。

两个根因，都很反直觉：

1. **文字分解动作＝给知识，不是给约束。** 模型读懂了，但没被驱动——
   它把"右脚跟落地→左腿蹬离"理解成**一张姿态说明图**，于是把人物固定在那张图的姿势上。
2. **跟拍本身会诱导"人不动、背景动"。** 摄影机与人物同速移动，画面里人物相对静止，
   模型很容易滑向"原地循环"——而原地循环里，腿不交替这个错误**在画面上无法被辨识**。

**如果坚持用文字做动作**（非周期动作、或只做一步时），只写"约束"不写"步骤"：

- ✅ `两条腿一步一步交替迈出，每迈一步都看得见脚从后向前的摆幅；一步大约半秒`
- ✅ `每走一步，骨盆与胸口在两条腿之间左右转移一次、身体随之下沉起伏一次`
- ❌ `右脚跟先落地 → 脚掌压平 → 左腿在后蹬离 → 下一步整个反过来`（变成分解图）

**必须补的三个量**：**步频**（一步约几秒）、**摆幅**（脚从后到前的可见位移）、
**重心转移**（骨盆与胸口左右换、每步一次下沉）——这三个缺任何一个，出来都是"原地摇摆"。

### ⚠️ 一个镜头里"景别与焦距必须全程不变"（**作用域限定**）

实测翻车：写了"固定机位"，出来前 1.5 秒是中近景、之后突然拉远成中全景——**一次景别突变**。

- 要写死：`镜内景别与焦距完全不变，画面不推近也不拉远，构图保持不变化`
- **不要写** `她慢慢变远` / `镜头渐渐拉开` —— 这类词会直接触发变焦
- 若人物横穿：写 `她横向移动，与摄影机的距离保持不变`

> **★ 作用域（2026-09-12 补 · 关键）**：这条管的是**一条之内不许自己变景别**，作用是**防止模型自由发挥**，
> **不是"禁止你在一条里安排多个景别"**。
>
> - **单机位镜**：整条生效。
> - **分段镜**：只在**每一镜内部**生效；**镜与镜之间就是要换景别与机位**（用镜号明确切）。
>
> → 想"一条里出多个景别"，正确做法是**分段镜**（`references/segmented-shot.md`），**不是删掉这条规则**。
> 这条规则在分段镜里仍然是镜内的护栏；删了它，镜内会自己漂。

## 四、摄影机运动块（要素清单已移出 → `camera-movement-library.md` 第二节）

**要素与写法去 `camera-movement-library.md`**：五要素（起始观察点 / 轨迹 / 速度 / 锁死项 / 停止结果）、六族全谱、四型句式、失败模式。
本节只留**这一段的稳定与作用域纪律**：

一镜只有一个主运动；"先推近再环绕"= 两个主运动，删一或拆镜（**分段镜里这条只约束每一镜内部**）。
焦段先写视觉效果（空间夸张/自然/压缩），毫米数辅助。
稳定五级：锁死 / 跟随 / 自然手持 / 重肩扛 / 故障抖动=失败（五级即此五项，第五项「故障抖动」为失败态，不作为可选项）。**五级可执行表（2026-09-30 就地补定义；`camera-movement-library.md` 单向指本处）**：

| 级 | 手感 | 可写锚词 |
|---|---|---|
| **锁死** | 完全平滑、无微颤 | `运动完全平滑，无微颤`（→ `motion-parameters.md` §6） |
| **跟随** | 主体画面位置恒定、背景在流 | `主体在画面里位置恒定，背景在流动`（→ `camera-movement-library.md` 跟随行） |
| **自然手持** | 极轻微高频抖 | `画面有约 0.5–1 毫米的细微抖动，频率约每秒 2 次`（→ `motion-parameters.md` §6） |
| **重肩扛** | 更大幅、更低频的沉重晃动 | `画面有明显的沉重晃动，幅度大、节奏不匀`（B 档经验句，无实测锚值） |
| **故障抖动** | **失败态，不作选项** | 属禁词（→ `shot-craft.md` 风险移除）；出现即重抽 |

**呼吸感要写全限定词**：`手持，全片保持极轻微、如呼吸般的机位浮动`——
"极轻微"和"如呼吸般"**两个词都必须有**，只写"手持"会被理解成剧烈摇晃。
（机械呼吸与反云台 → `cinematic-look.md`）

### ★ 补：**「静止区域」的画内锁定**（2026-09-13 补）

本库在这一段只写了"**锁死构图关系**"（画面外的稳定性），**还有一个画内手段**：

**运动笔刷（Motion Brush）的完整四步**
```
① 划定区域（涂抹；单个动态笔刷只能画一个连通区域）
② 画带箭头的轨迹：起点 → 路径 → 终点
   ★ 轨迹长度直接决定末帧位移量（画长了甩出去，画短了不到位）
③ 绑定结构化提示词（主体 + 动作 + 路径特征 + 约束）
④ ★★ 用「静态笔刷」涂抹「静止区域」——防能量泄露 / 背景漂移
```
- **多区域轨迹各自独立，但★不许交叉**（交叉会肢体错位或残影）
- **幅度要与部位强绑定**：`右臂小幅前摆，角度不超过 20°` **优于** `整体轻微晃动`
  （→ 与本库"物理六杠杆要写量级"同源；**但"微微/略微识别率仅 58%"这类数字属内容农场编造，不采**）
- **「静止区域」的意义**：把"不该动的东西"**显式锁住**。本库的"锁死构图"管的是**摄影机**，
  它管的是**画面内被误驱动的像素**——**两者互补，不是一回事**。
- **入口**：可灵「运动笔刷 / 静态笔刷」；Seedance 侧无同名入口，用"路径描述 + 静止区域声明"在提示词里做等价表达。
