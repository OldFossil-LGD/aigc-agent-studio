# 声音的叙事语法：**从"技术"到"戏"**

> **何时读**：想让声音**承担叙事**（而不只是"把画面配响"）时。
> **读完回哪**：**怎么设计**回 `sound-design-craft.md` · **怎么写进提示词**回 `sound-prompt-craft.md` · **怎么做完**回 `sound-post-pipeline.md`。
> **★ 本册的定位**：前面八册解决"**声音怎么来、怎么对、多大、按什么顺序**"；
> **本册解决"这一声为什么必须有"**——**它是唯一一册把声音当"剧作手段"来讲的。**

---

## §1 开篇那句话

> **Walter Murch（《现代启示录》《英国病人》声音设计）：**
> **"电影中最有表现力的片段，就是那些主观化的片段。"**

**推论（本册的立场）**：**声音最有力的用法不是"还原现实"，而是"让观众住进某个人的耳朵里"。**
**而"还原现实"（写实、干净、对得上）是入场券，不是目标。**

---

## §2 ★ 声画关系的五档（**从"贴合"到"反着来"**）

| 档 | 名字 | 做什么 | 什么时候用 |
|---|---|---|---|
| 1 | **同步** Synchronization | 声音与画面对齐（对口型是最明显的一例） | **默认，是基线** |
| 2 | **米老鼠化** Mickey-mousing | **音效逐拍匹配画面动作** | 喜剧、卡通、强调节奏；**写实片用多了会像广告** |
| 3 | **★ 对位** Counterpoint | **故意把声音与画面反着放** | **在暴力场景上放欢快流行歌 → 反讽与认知失调，比任何恐怖配乐都更令人不安** |
| 4 | **声音透视** Sound perspective | **音量与清晰度匹配视觉距离**（角色走远 → 更轻、**混响更多**） | 几乎每场；**这是"空间是否可信"的底线** |
| 5 | **★ 听点** Point-of-audition | **把整条音轨滤成角色的主观听觉**（爆炸后的耳鸣/闷住/只留下一个词） | **要观众进入角色的内部状态时** |

**★ 判据一句话**：**"这一场，我要观众站在画外看，还是站在某个人的耳朵里听？"**
——**前者用 1–4，后者用 5。而这一选择决定后面所有声音的设计。**

## §3 ★ 主观声：**三种做法，一种比一种深**

### 3.1 滤掉世界，留下一个东西（最早的范例）

**1929《Blackmail》（希区柯克，英国最早的长片有声片之一、也是他的首部有声片）**：
女孩以为自己杀了人，坐在餐桌前——**周围所有声音被压低，只有"刀（knife）"这个词在她脑中反复回响、成为她注意力的唯一焦点**；
**直到父亲一句"Alice, 切点面包"把她叫醒。**

**可复用的写法**：`环境与对白被压到几乎听不见 → 一个词（或一个声音）异常突出、带着回响 → 一句日常台词把角色拉回来`。
**★ 那个"拉回来的日常台词"是关键**——**没有它，观众不知道她回到了现实。**

### 3.2 画面说不出，声音来说（**声音成为角色本身**）

**《潜水钟与蝴蝶》**（主角全身瘫痪、只剩一只眼能动）：**主观声不只代表视点，更代表角色本身——在画面表现不到或无力表现的场景里，主人公以声音的形象出场。**
它的手法**逐条可学**：

| 它做了什么 | 效果 |
|---|---|
| 片头字幕音乐到了黑场，**空间感改变、加上长长的混响** | 从"非电影时空"落进**一个具体的有长混响的空间**——**故事要开始了** |
| **很近的心跳声：没有混响、没有反射，"仿佛来自头脑中"** | **把观众直接定位到"主观听点"** |
| 远处歌声：**巨大混响 + 多次反射的声染色** | 暗示来自**空荡荡的走廊** |
| **声像晃动、位置不明确、忽远忽近** | 不只是声场，还暗示**听的那个人正处在恍惚状态** |
| **画面省略了空间信息（大量虚焦、大特写），声音把空间补上** | **"与有限的画面空间相对照的，是声音空间的丰富"** |

**★ 这一条最值钱**：**当画面刻意"少给"时，声音可以"多给"**——**声画不必同步地"省"或"给"，两者可以互为补充。**

### 3.3 声画异步：**心内的独白**

**Béla Balázs** 的经典论述：
> **"电影声音在与画面异步时最有表现力... 异步声音不必自然，它的效果是象征性的，它通过意义而不是现实与画面相连。"**

**他举的例子**：一位士兵第一次遭遇炮火，丢下战友躲进弹坑。**特写他闭着的嘴——他的嘴确实是闭着的；
但我们听见他在说话。那是他心里的独白，我们紧张地听他默默对自己说什么。**
> **"如果他真的出声说出来，这场戏会无法忍受。"**

**★ 与画外音（voice-over）的区别**（Mary Ann Doane）：**内心独白展示的是画面无法接近的东西——角色的"内在生命"**。

**★ 落成可写的三条**：
```text
① 嘴不动，但有声音        → 心内独白（不是旁白，不是对白）
② 声音不必"来得合理"      → 它靠意义与画面相连，不靠现实
③ 一旦让它出声，戏就毁了  → 心里的声音不许"说出口"
```

## §4 ★ 无源之声（acousmatic）：**看不见声源的声音**

**定义**：**声源在画外、或根本没有可见的声源**。
**两个用法（刚好相反）**：
- **制造悬念**：画外的地板吱呀、没有可见说话者的声音 → **"是什么？在哪？"**——**把恐怖维持在最强的位置（未知）**；
- **扩展世界**：**声音把故事世界推到画框之外**——观众知道"这间屋子之外还有东西"。

**★ 判据一句话**：**"我让观众看见它，还是只让他们听见它？"**
**"看见"给的是确认，"只听见"给的是想象——后者更省，也更强。**

## §5 ★ 声音蒙太奇与叠化：**不着一词地传意**

- **声音蒙太奇（sound montage）**：**把多个声音并置产生意义**。
  例：**婴儿哭声 + 火车汽笛 + 走时声 → 传达焦虑，一句台词都不用。**
- **声音叠化（audio dissolve）**：**城市噪声渐变为鸟鸣 = 地点变了**；
  **★ 慢慢淡入静默 = 时间流逝，或"进入角色的内心世界"。**

**★ 三种最省力的叠化**（可直接写）：
```text
地点变：城市噪声 → 鸟鸣 / 室内底噪 → 室外风
时间变：同一环境床渐弱 → 渐强（配一次很轻的过渡）
内心化：环境与混响一起收 → 只留下心跳/呼吸/耳鸣
```

## §6 ★ 静默：**它是最贵的一件乐器**

**Britannica 的原话（意思）**：**声音技术的引入，让"静默"也能有戏剧效果——可以比言语或音乐都更有力。**
**音乐史那边同一条**（`music-craft.md` §4.2）：**静默是一件乐器**。

**★ 静默的四种用法**（**必须先有声音，静默才成立**）：

| 用法 | 怎么用 | 例子（参考） |
|---|---|---|
| **爆点前的空** | 把一切声音**在爆发前抽掉半秒** | 动作片；**比加音效更响** |
| **主观化的入口** | 世界的声音被"抽走"，进入角色的内部 | §3.1 的刀 |
| **强调一个孤立声** | 抽掉周围，让**一个声音**独自响 | 希区柯克《Torn Curtain》：**煤气嘶声主导全场（画面只剩抽搐的手）** |
| **可怕的收尾** | 不是安静，而是**"这一声太大/太密"** | 布列松《圣女贞德受审》：**火的噼啪声"和任何视觉特效一样可怖"** |

**★ 一条纪律**：**静默不是"没做声音"，是"把别的都拿掉"**——
**没有底噪与环境的静默，听起来是"漏了"；有底噪被抽掉的静默，听起来是"发生了什么"。**

**★ AI 平台落地注记**（生成期 vs 后期的分界）：
```text
① 亚秒级静默点（"爆发前抽掉半秒"）→ 后期时间线实现；写进单镜生成 prompt 强求落点必然漂移
② 听点滤波（闷住/耳鸣/只留一个词）→ 优先后期对整段加统一滤波；若逐镜生成，每镜须重复同一滤波描述并引用同一声音锚点
③ 静默段按声音方案选择是否保留生成音轨。sound=off 可用于明确无需原声的画面素材，所需环境床也可在后期独立铺设或按意图撤掉，验收最终音轨的静默落点与连续性
```

## §7 ★ 把"写实"当成一档，而不是默认

**先澄清一处字面张力**：**同步对齐（§2 档1）是技术基线，无需选择；而"写实风格"仍是一种需要主动设计的美学档位**——两者不矛盾。
**本册最实用的一张对照表**（把上面全部落成"什么时候按哪个开关"）：

| 这一场要什么 | 声音该怎么处理 |
|---|---|
| **真实感、纪实感** | **同步 + 透视**（该多远就多远，混响匹配空间） |
| **紧张 / 悬念** | **无源之声 + 静默**（不给他看见） |
| **进入角色内部** | **听点 + 主观声**（滤掉世界，留下一个东西） |
| **反讽 / 不安** | **声画对位**（画面上是 A，声音是它的反面） |
| **情绪推进、不着一词** | **声音蒙太奇 + 叠化** |
| **要"更狠"** | **先给足声音，再把它全抽走**（§6 第一行） |

**★ 判据一句话**：**"这一场，声音是在描述世界，还是在描述某个人怎么看世界？"**
**—— 答不上来，说明声音还是"配上去的"，不是"设计出来的"。**
