# 物理反馈（AI 不懂牛顿 · 必须用文字替它算 · 通用方法）

> **何时读**：写动作 / 负重 / 接触的物理之前。**读完回哪**：回到 `motion-control.md` 选动作路径。

> 第一性原理：视频模型是**去噪生成**，不是物理模拟。它学的是"动作的统计模样"，不是力。
> 所以**一切物理都得用文字显式算给它**——分量、方向、接触点、形变、谁先停谁后停。
> 这份文件是**思考清单**，不是逐字模板；每次按当前动作挑相关杠杆写。

## 一、六个物理杠杆（写完动作后，逐个过一遍）

| 杠杆 | 要回答的问题 | 浅的写法 | 深的写法 |
|---|---|---|---|
| **① 质量与重量** | 这东西多重？实心还是空壳？头重还是底重？ | 她拖着一个机器人 | 它比看起来重——铁壳里是实心配重，起步要**明显用力**，停下之后还会**往前溜**一点 |
| **② 力与来源** | 力从哪来、往哪去？是推、拉、砸还是掉？ | 她拉着走 | 力从**她的小腿和大腿**来，经布带传到机身——所以布带会绷紧、她的小腿肌肉会鼓出来 |
| **③ 摩擦与牵引** | 什么面接什么面？滑还是涩？ | 在沙地上走 | 沙地是**松的**：每一步都陷进一两厘米、拔出来时带起一小撮沙；铁腿在沙上打滑才会刮出沟 |
| **④ 惯性与动量** | 起步与停下的样子 | 她往前走 | 起步慢、越快越省力，**停下时上半身会多冲出去一点**再被拉回来 |
| **⑤ 接触点与碰撞** | 第一次碰在哪？之后呢？有没有穿模？ | 她拽着绳子 | 布带先是**勒进她手掌的虎口**、手掌被压出一条红痕；布带另一端系在机器人**颈部那圈铁环**上，铁环每次被拽都会**转半圈** |
| **⑥ 形变与材质响应** | 谁被压了、谁被拽长、谁被溅起来 | 机器人在被拖着 | 布带被拉得**绷直发硬**（不再下垂），机器人的外壳**没有形变**（是硬的），但它的**三条腿的关节在每次顿挫时会被压弯一点点** |

**写法提示**：六个杠杆不必每条都写，但**凡有支撑面接触承重的镜头，①③⑤（重量、摩擦、接触点）必备**——这三条缺一，画面立刻"飘"（悬空 / 无承重镜头按实际接触情况豁免）。

## 二、因果顺序：先因后果，链条要短

- **写因再写果**：`她的手先触到把手 → 手指合拢 → 再往外拉`，而不是"她拉开了抽屉"。
- **一次只算一小段**：一次生成里超过三四个物理交互，必然崩——**把链拆到多镜**，或者干脆把复杂的交互放到画外（只拍结果与反应）。
- **把"5 个交互"换成"1 个交互 + 4 个反应"**：反应的容忍度远高于交互。

## 三、动画十二法则里最有效的六条（直接决定"活不活"）

| 法则 | 一句话 | 提示词里的落法 |
|---|---|---|
| **挤压拉伸** | 受力会形变、体积守恒（压扁就变宽） | 软的东西被压会扁；硬的东西不变形但**受力点会震** |
| **预备动作** | 大动作之前先向反方向蓄力 | 举手前先沉肩；踹之前先收腿；转身前先低头 |
| **跟随与重叠** | 不是所有部分同时停 | **身体先停，头发/衣角/配饰后停；越重越滞后** |
| **慢进慢出** | 加速减速，不是匀速 | "起步慢、中段快、末段减速停住"——**匀速＝机械感** |
| **弧线** | 肢体走弧线不走直线 | 手臂挥动是弧线；抛出的东西走抛物线（机械臂例外） |
| **二级动作** | 支撑主动作的小动作 | 走路时手自然摆动、说话时手指的小动作——**但不能抢戏** |

## 四、二级动作**必须有因**（最容易翻车的一条）

头发、衣角、尘埃、蒸汽、树叶、水面——**只对它被写明的原因反应**：

- ✅ `风从左边窗缝进来，只带动窗帘的边缘和几缕碎发；家具和其他物体完全不动`
- ❌ `头发飘动、衣摆飞舞`（没有因）→ 得到**水下漂浮感**，全程像泡在液体里

**判断标准**：画面里每一样在动的东西，都能指出"它为什么在动"。

## 五、被接触面也要有反应

物体不是悬在真空里动的——**它碰到的那个面必须回应**：

| 接触面 | 该有的反应 |
|---|---|
| 沙 / 土 | 陷下去、扬起、堆成小堆、留下连续痕迹 |
| 木板 / 桌面 | 轻微的震、物件跳一下、灰尘被震起来 |
| 金属 | 碰击声的位置感 + 接触点的高光变化 |
| 水 / 湿面 | 飞溅、涟漪、湿痕扩散、倒影被打碎 |
| 布 / 软面 | 凹陷、回弹、褶皱走向改变 |

## 六、轻重对比法则（判断有没有"重量"的快捷键）

| | 轻的东西 | 重的东西 |
|---|---|---|
| 起步 | 快 | 慢、要蓄力 |
| 停下 | 立刻停 | 还会多冲一点、再被拉回来 |
| 被带动 | 反应快、幅度大 | 反应慢、滞后明显 |
| 二级动作 | 头发衣角马上飘 | 厚重布料几乎不动，只微微晃 |

**一句话检查**：把画面里最重的东西和最轻的东西各指出一个——如果两者动起来"一样轻快"，重量就没写出来。

## 七、禁区与对策（这些最容易崩，写之前先想）

| 高风险 | 为什么 | 对策 |
|---|---|---|
| 液体（倒水、泼、溅） | 流体模拟是长尾 | 只拍**结果**（已经满/已经湿），或大大缩短 |
| 人群 | 每个个体都要独立物理 | 用**一群人变成一团暗影**、只拍主体 |
| 碰撞 / 打击 | 接触帧极难 | **默认**：撞前切、撞后切，**不拍接触那一帧**（经典动作片做法）。**例外**：明确要子弹时间时，改用下方"冲击三锁" |
| 手与物体的精密交互 | 手指结构 + 接触点双重难点 | 简化动作、拉宽景别，或只拍**手影与结果** |
| 多个物体同时受力 | 依赖太多 | 拆镜，或只让一件东西受力、其余写"完全不动" |

## 八、自检五问（每镜出片前过一遍）

1. **力从哪来**？能指出来源吗（身体的哪一部分、哪个方向）？
2. **接触点在哪**？第一次碰在哪里，之后有没有穿模？
3. **什么是被压/被拽/被扬起来的**？画面里有没有"被影响的环境"？
4. **谁先停、谁后停**？有没有东西还在动，有没有东西已经停住？
5. **链条是不是太长**？超过三四个交互了吗——超了就拆镜。

**再加一条通用兜底句**（可放在提示词末尾，跨模型都有效）：
`全程保持自然的重量与惯性，物体不滑动、不穿模、不漂浮。`

### 冲击镜的"三锁"（只在明确要子弹时间时启用）

**默认仍按第七节**——不拍接触那一帧。**只有当你主动要"冻结在接触前一瞬、再切进去绕一圈"时**，用这三把锁：

| 锁 | 锁什么 |
|---|---|
| **姿态锁** | 上一镜尾帧 = 下一镜首帧的**身体与武器角度**，逐字一致 |
| **时间锁** | 慢动作**保持在接触前一瞬**；**破坏发生的那一刻才回实时**速度 |
| **材料锁** | 明确写出**哪个材料断**（哪一根、什么材质、从哪断） |

> 三者缺一，慢动作就会变成"整体放慢的糊镜头"，而不是"时间被拉长的瞬间"。

## 九、动作要"量化"，并且写出过渡（从 AI 视频一线实践提炼）

**只写动作名不够，要补三个量**：

| 量 | 写什么 | 例子 |
|---|---|---|
| **幅度** | 动多少 | 头转约二十度 / 手抬到肩高 / 退半步 |
| **速度** | 快慢与节奏 | 缓慢抬手 / 快速转头 / 先快后慢 |
| **力度** | 使劲程度 | 用力蹬地 / 轻轻放下 / 几乎不用力地搭上去 |

**动作之间要写过渡与承接**（否则每个动作都像独立切片）：

- ✅ `借着转身的惯性顺势抬手` · `从停顿状态自然过渡到举手` · `落手之后余劲带着肩膀晃了两下`
- 这正是"跟随与重叠"法则在文字上的落地——**上一个动作的余势，是下一个动作的起点**。

**优先低缓连续的小动作，规避高爆发**：
狂奔、大跳、剧烈翻滚、连续翻转，是模型的**长尾区**，几乎必崩。
要动感就换一种给法：**慢动作 + 幅度小 + 有重量**，动感交给剪辑与声音，不交给模型。

**一条反直觉的经验**：一个镜头里"动作越少、越大、越慢"，成功率越高；
动作多、快、密，出来的多半是糊的。**宁可拆成三镜，不要塞进一镜。**

### ★ 规模与变形：写"测量"，不写"强度"

想表达"巨大""戏剧性""剧烈"时，**不要用程度副词**（那是形容词，等于没写）。
改成**四要素测量**——**起点 → 路径 → 定时状态变化 → 终点画面**：

| 要素 | 写什么 | 例 |
|---|---|---|
| **起点** | 空间坐标 | 约 8 米外、3 米高处 |
| **路径** | 轨迹形状 | 划过半个圆弧 |
| **定时状态变化** | 完成所需时间 | 半秒以内完成 |
| **终点画面** | 落点 + 看向何处 | 停在约 4 米处、2 米高，面朝门口 |

**再加一个可见的行为比喻**（写在测量之外）：
> `像一件武器展开，不是魔法变身`

**自检**：**画不出这四样，这一镜不够格被诊断。** 说不清起点终点的变化，出片后也无从归因。
