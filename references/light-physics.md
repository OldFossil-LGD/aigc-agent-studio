## 一、光位谱：本库此前只写了名字，这份文件给角度

### 1.1 五个基础光位（角度是可执行的）

| 光位 | 主光位置（相对相机轴） | 高度（相对眼平线） | 脸上的标志 | 皮肤效果 |
|---|---|---|---|---|
| **正面平光** flat | **0°**（与镜头同轴） | 略高 | 几乎无阴影 | **最"磨皮"**——填平皱纹、抹掉毛孔、**四项细节全隐形**【待核】此数值回一手源前不要当唯一答案 |
| **蝴蝶光** butterfly | **0°**（同轴） | **30–45°上** | 鼻下一小块对称的蝶形影 | 强调颧骨，**对称、光洁**（美妆）【待核】此数值回一手源前不要当唯一答案 |
| **环形光** loop | **30–45°侧** | **15–30°上** | 鼻影偏向一侧、**但不与颊影相连** | **最通用、最自然**；有立体但不失柔和【待核】此数值回一手源前不要当唯一答案 |
| **伦勃朗光** Rembrandt | **45–60°侧** | **30–45°上** | **暗面颊上有一个三角亮块**（鼻影与颊影相连） | 立体、戏剧、**保留部分纹理**【待核】此数值回一手源前不要当唯一答案 |
| **分割光** split | **90°侧** | 眼平或略高 | 面孔中线一分为二 | **掠射角 → 纹理暴露最强**（"High texture reveals on the illuminated side due to the raking angle"）【待核】此数值回一手源前不要当唯一答案 |

**判据（怎么验对了）**：
- 环形光 → `鼻影朝嘴角方向走，但没有碰到脸侧的暗部`。
- 伦勃朗光 → `暗面颊上的亮三角，宽度不超过一只眼、长度不超过鼻子`。
- **越界判据**：环形光的鼻影一旦**碰到颊影**，就变成了伦勃朗光。
  → **提示词落地**：两者是**同一句的两种写法**，写哪句模型就画哪种——
  `鼻影朝向嘴角走，但还没碰到脸侧的暗部`（环形光）／`鼻影和脸颊上的阴影连在一起，暗面颊上只剩下一个三角亮块`（伦勃朗光）。
  **判据本身（鼻影碰没碰到颊影）就是画面结果，不需要翻译。**

### 1.1·补 平台给的"灯位预设"怎么对到这张表（2026-09-20 补）

**问题**：平台（LibTV 等）把主光位做成了**可选的下拉值**（官方口径 **24 种主光位 + 9 种轮廓光预设**；第三方口径为 **六档位置〔左/顶/右/前/底/后〕＋轮廓光开关＋六套预设**——**两说并存，未核**）。**UI 选一档 ≠ 提示词写清光位**：模型读的是提示词，不是界面。

**做法（三步，方向永远以本表为准）**：
1. **先在本表选光位**（五个基础光位之一或组合），把角度、高度、**脸上的标志**写进提示词——**这一步不看平台**；
2. **再去平台选最接近的一档**，只当作**渲染参数**；
3. **回读校验**：拿"脸上的标志"当验收判据（如伦勃朗光＝暗面颊上一个三角亮块），**平台选档与画面不符时，改的是提示词，不是判据**。

**一条反直觉提醒**：**多了 24 档不代表更准**——预设的命名与角度**各平台不同**，且**未核**；本表给的是**角度区间 + 可验证标志**，是唯一能跨平台搬的东西。

### 1.2 两条最值钱的光位结论

**① 顺侧光 → 显纹理；逆光 → 显透光；正面光 → 什么都看不见。**

| 要什么 | 光位 | 角度依据 |
|---|---|---|
| 毛孔／皱纹／肤质 | **45°–90° 侧光**（越接近 90° 越强） | **掠射角 + 硬光** → "accentuate the textures"，同时增加立体感【待核】此数值回一手源前不要当唯一答案 |
| 绒毛轮廓毛边 | **120–150° 背后**（轮廓光 / 边缘光） | `asperity scattering` 只在轮廓上发生【待核】此数值回一手源前不要当唯一答案 |
| 透彻的次表面散射 | **背后 / 侧逆** | 光必须从**背面**穿薄处 |
| 高光收成正确形状 | **斜角**（任何非正面） | 菲涅尔在掠射最强 |

**② "短光 vs 宽光"是全库里最被忽略、但改动最小、收益最大的一条。**

- **短光** short：亮面在**远离相机**的一侧 → **显瘦、强调颧骨**。
- **宽光** broad：亮面在**朝向相机**的一侧 → **显宽、显开放**。
- **它不是一个独立光位，是任何光位里的一个二选一开关。** → 提示词里值得加一句 `主光在远离镜头的那一侧`——**这一句不改变光质、不改色温、不加任何形容词，却直接改变脸的体积感。**

### 1.3 光位对身体：三个区域，三套写法

身体不是"放大的脸"。**身体有三个独立的光学区域**：

| 区域 | 特征 | 该写什么 |
|---|---|---|
| **锁骨／胸骨上窝** | 皮下薄、有骨性标志、易于积光 | `锁骨上窝积着一小片光`、`胸骨上的骨头把光顶出一道窄的亮边` |
| **肩／上臂** | 面积大、少毛孔、**有更明显的绒毛** | `肩头有一层细绒毛，逆光下勾出轮廓`（**身体绒毛比脸部更显形态**） |
| **手／指／腕** | 层多（关节、肌腱）、**背面薄** | `指缝挡光处透出橙红`、`腕内侧的青筋把皮肤顶起来` |

> **身体与脸的最大区别**：脸靠**骨骼的起伏**造型（眉弓／颧骨／下颌），身体靠**肌肉与骨性标志的边界**造型（锁骨／肩峰／肋骨）。**写身体不要写"轮廓光"了事，要写"光在哪个骨性标志上停住"。**

### 1.4 眼神光：光位在眼睛里留下的签名

**眼神光（catchlight）的形状 = 光源的形状**，这是光位唯一的"自证"。

| 光源 | 眼神光形状 | 位置（钟点方向） |
|---|---|---|
| 柔光箱 | 矩形 | 10 点 / 2 点【待核】此数值回一手源前不要当唯一答案 |
| 环形灯 | 圆环 | 居中的环 |
| 窗户 | 矩形（可能带窗格） | 偏向窗户侧 |
| 硬点光源 | 极小一点 | 随光位 |

**为什么这条重要**：**眼神光是画面里唯一能"证明灯在哪"的证据**。写了眼神光形状，等于给整场戏的光位上了锁——**观众和模型都由此确认光的空间位置**。这也是 `light-quality-construction.md` 把它单列一节的原因。

## 二、软硬光：物理定义（本库此前只教了"五种造法"，没给因）

### 2.1 决定软硬的唯一变量：**光源的"视在尺寸"**

> **软硬不看灯多大，看灯在主体眼里有多大。**

三个乘数：

| 因素 | 更软 | 更硬 |
|---|---|---|
| **光源物理尺寸 S** | 大 | 小 |
| **距离 d** | 近 | 远 |
| **散射材料厚度** | 厚 | 薄（或无） |

**两条量化的**：

```
角尺寸（从主体看光源）：   θ = 2 · arctan( S / (2·d_o) )
半影宽度（影子的软边）：   W_p = S · ( d_r − d_o ) / d_o
                            其中 d_o = 源到遮挡物，d_r = 源到承影面
```

**从半影公式读出的一条最重要的摄影事实**：
**当 d_r → d_o（承影面越靠近遮挡物），W_p → 0（影子越锐利）。** 这就是**"接触硬化"（contact hardening）**——**真实世界里没有"全软"的阴影**，任何柔光在物体接触处都会变锐。

> **这是本库最值得加的一条物理判据**：**看阴影与物体的接触处**。接触处锐利、离得越远越虚 → 真实柔光；**整条阴影边缘一样虚 → 不真实的"全软"阴影**（典型 AI 感）。这与 `tone-realism.md` §第一层 的"光的物理"直接对接，但**给了可测判据**。

### 2.2 下降（falloff）：柔光不会连背景一起洗白

```
点光源：  I = P / (4π·d²)          （平方反比，物理正确）
线光源：  I ∝ 1/d                  （细长灯管）
面光源：  I 几乎不随距离下降
```

**结论**：**柔光（大面源）近置 → 主体亮，背景暗得快 → 主体从背景里"分离"出来。**
**远置的柔光 → 主体和背景同亮 → 画面平。**
→ **提示词里"柔光"三个字不够。** 必须写**光在哪停**：`柔光只到人物身上，他背后的房间迅速暗下去`——这一句就同时表达了源大、源近、有分离。

### 2.3 光比与负补光：控制对比的两条相反路径

| 手段（你的认知） | 做的是 | 代价 | **提示词落地（可直接抄）** |
|---|---|---|---|
| **加正补光**（反光板／fill） | 抬暗部 → **降低对比** | **影子边缘不变软**，只是变浅；容易糊平 | `暗部被抬起来，脸上的阴影都很浅、边界发虚` |
| **加负补光**（黑旗／黑绒布） | 吸掉反弹光 → **提高对比** | 无代价，**本库推荐** | `暗侧完全没有补光，环境里的反弹光也被压掉；暗部保留浓度、但纹理照样清楚` |

> **★★ 这一列的差别要特别注意**：`加负补光` 是**动作**，模型做不到；`暗侧完全没有补光` 是**结果**，模型画得出来。
> **两者描述的是同一张画面** —— 这正是"与模型高效沟通"的核心手法：**把你的动作，翻译成它给出的结果。**
>
> **一条反直觉但也最实用的**：**你要"对比"，不是要"暗"。** 加负补光不是把暗部压黑，**是把"不该有的环境反弹光"拿走**——留下的暗部因此**干净、有结构**。
> **写成提示词时也守这条**：不要写"暗部很黑"，要写`暗部干净、有结构、纹理清楚`——**否则模型会给你一块死黑**。
>
> ⚠️ **与 `skin-realism.md` §1.4 是同一件事的两面**：那边说"换角度 + 加负补光，不要加正面光"；这里给的是**为什么正面光是最坏的选择**——它同时毁掉毛孔（掠射角的缺失）、SSS（无背后路径）、高光形状（非掠射角）、体积感（大面源远置 = 平）。**四条物理原因，一个动作全踩。**

## 三、色温：从"暖／冷"到开尔文标度（本库此前是空白）

### 3.1 标度表（可以直接写进提示词或用它反推）

| 开尔文 | 光源 | 观感 | 用在皮肤上 |
|---|---|---|---|
| **1500–1900K** | 烛光、火柴 | 深橙／琥珀 | 极暖，贴近拍会过红【待核】此数值回一手源前不要当唯一答案 |
| **2000–2700K** | 日出／日落、白炽灯泡 | 金黄 | **黄金时刻人像**【待核】此数值回一手源前不要当唯一答案 |
| **2700–3200K** | 钨丝灯、卤素 | 柔和的暖 | **室内人像的舒适区**【待核】此数值回一手源前不要当唯一答案 |
| **3500–4500K** | 荧光灯、中性 LED | 中性白 | 办公场所；**常带绿偏**【待核】此数值回一手源前不要当唯一答案 |
| **5000–5600K** | 正午日光、电子闪光 | 纯白 | **肤色基准线**【待核】此数值回一手源前不要当唯一答案 |
| **6000–6500K** | 阴天 | 冷白 | 清冷【待核】此数值回一手源前不要当唯一答案 |
| **7000–10000K** | 开阔阴影、蓝天 | 深冷蓝 | **冷、情绪化、月光感**【待核】此数值回一手源前不要当唯一答案 |

**三个锚点记住就够**：**钨丝 3200K ／ 日光闪灯 5600K ／ 阴影 8000K。【待核】此数值回一手源前不要当唯一答案**

### 3.2 影响肤色的三个可执行规律

**① 暖光抬红橙，冷光抽色。**
- **低 K（暖）**：红橙被抬起来 → **多数肤色显健康，但浅肤色／红血丝皮肤会显"发红发烫"**。
- **高 K（冷）**：深肤色被**去饱和**、带上灰蓝 → **深肤色最怕过冷的光**。
- **可靠起点：4500–5000K。** 这个区间对多种肤色都"宽容易读"，是**跨肤色最安全的基准**。【待核】此数值回一手源前不要当唯一答案

**② 混合色温 = 一张脸两种颜色，后期救不回来。**
最典型的场景：**窗户（5600K 日光）+ 室内灯（3200K 钨丝）** → 脸的一侧蓝、另一侧橙。

**遇到混合光，分两步：先决定**（这是你的取舍），**再改写**（这是给模型的指令）。

| 步骤 | 做什么 | 具体 |
|---|---|---|
| **第一步 · 决定** | **现场能解决就现场解决** | 把其中一路关掉／用变色灯把它拨到 4200K 左右去靠近另一路。**这是拍摄现场的做法，模型做不到。**【待核】此数值回一手源前不要当唯一答案 |
| **第二步 · 改写** | **模型面前无法"关灯"，只能"指定哪一路是主光"** | 不写"混合光"，**写清哪一路是主光 + 另一路只落在哪**（见下方写作纪律）。**这一步才是真正解决生成图的方法。** |

→ **写作纪律**：**一场戏里若要写"混合光"，必须写明"主光是哪一路"**，否则模型会随机分配两侧颜色。写法：`窗光（冷）是主光，屋内的台灯只作为暖色轮廓落在肩后，不照脸`。
> **★ 关键**：**别写"把两路的色温调一致"**——模型没有"调"这个动作。
> **要写的是"结果"**：`脸的一侧被窗光照成偏冷的白，另一侧完全落在阴影里，**脸上没有第二种颜色**`。

**③ 色温是"光的属性"，白平衡是"相机的补偿"——这是两件事。**
提示词描述的是**第一种**（光本身是什么颜色），不是第二种。**别写"白平衡 3200K"给生成模型**——那是拍摄参数，不是画面描述。**要写的是：`画面偏暖，皮肤呈橘黄色调，阴影里没有一丝蓝`。**

### 3.3 与动机光的关系（接 `light-quality-construction.md`）

色温是**动机光最便宜的"证物"**——**有出处**（`light-quality-construction.md` §四 动机光节的既有纪律）不光要写"光从哪来"，**还要写"那路光是多少 K"**：
- 窗边的演员 → `5600K 的冷日光从窗进来`。
- 台灯下的演员 → `2700–3200K 的暖黄光从台灯过来`。
**一个数字，把光源的可信度提高一个档次**——因为数字意味着**具体的灯具**，而"暖光"只意味着一个形容词。

## 四、十七条可复用规律（本文件的压缩版）

**世界观类**
1. **皮肤是半透明体，不是表面** —— 只写表面的提示词必然蜡像化。
2. **光选深度** —— 颜色是深度的函数，不是涂在表面的。
3. **角度决定看见什么** —— 比任何形容词都强大。

**皮肤类**
4. **高光在角质层（n≈1.55）【待核】此数值回一手源前不要当唯一答案，颜色在真皮** —— 两件事分开写。
5. **暗部偏暖是唯一的 SSS 证据** —— 冷灰暗部 = 没有皮下光。
6. **SSS 是边缘现象** —— 只在薄处 + 逆光出现；全脸提 SSS 会变成油亮。
7. **肤色越深，"表面"占的比重越大** —— 深肤色靠高光形状 + 暗部色相，不靠透光。
8. **毛孔是几何（坑 + 自阴影），不是贴图** —— 必须斜射光。
9. **T 区 4–5 倍于 U 区**【待核】此数值回一手源前不要当唯一答案 —— 全脸同密度 = 假。
10. **高光是两层（宽 + 窄）** —— "高光成片"的解药是**拆成两层**，不是调暗。
11. **油光只落 T 区，且要写"连续 vs 离散"**。

**光位类**
12. **顺侧光显纹理／逆光显透光／正面光什么都不显**。
13. **短光 vs 宽光是最小改动、最大收益的一句**。
14. **越接近 90°，纹理越暴露**。
15. **眼神光形状 = 光源形状** —— 画面里唯一的灯位证据。

**光质类**
16. **软硬 = 视在尺寸，不是物理尺寸**；**半影公式 W_p = S(d_r−d_o)/d_o**；**接触处必锐（contact hardening）**。
17. **色温三个锚点 3200／5600／8000K**，跨肤色安全区 **4500–5000K**。【待核】此数值回一手源前不要当唯一答案

## 五、常见误区清单（十四条，每条都带物理原因）

| # | 误区 | 为什么错（物理原因） |
|---|---|---|
| 1 | 皮肤"细腻／光滑"是好词 | 只描述表面 → 模型走不透光材质 → 蜡像。**空话词还占预算** |
| 2 | 加"不要油亮"来去油 | 否定句会**注入**该概念；且没给替代方案 |
| 3 | 全脸提 SSS／全脸透光 | **SSS 是边缘现象**，全脸提 = 全脸发亮 |
| 4 | 为了让皮肤"看得清"开大正面柔光 | **同时毁掉毛孔（掠射角）、SSS（背后路径）、高光形状（菲涅尔）、体积感（大源远置）四条** |
| 5 | 用一个大高光表达"皮肤有光泽" | 高光是**两层**的；单层大高光必然成片 |
| 6 | 把高光调暗来解决"成片" | 根因是**没分层**；调暗只是让片子更假（哑光死板） |
| 7 | 全脸同样毛孔／同样光泽 | 真实的分野是 **T/U 区 4–5 倍密度差**【待核】此数值回一手源前不要当唯一答案 |
| 8 | 写 `有黑头` | 看到的是**开口 + 皮脂丝**，不是黑点 |
| 9 | 湿发／湿皮肤写"反光" | 湿态是**高光连成面且形状被拉长**；"反光"太笼统 |
| 10 | 写"柔光"就以为万事大吉 | 柔光还有**造法、距离、光比**三个未定变量 |
| 11 | 阴影"全软" | 违反 **contact hardening** —— 真实阴影在接触处必锐 |
| 12 | 写"混合光"却不指明主光 | 模型会**随机分配**两侧颜色（脸一半蓝一半橙） |
| 13 | 给生成模型写"白平衡 XXXX K" | 那是**拍摄参数**，不是画面描述；应写"画面偏暖／阴影无蓝" |
| 14 | 指望模型自己做出耳廓透红 | Jensen 偶极子**已知低估前向散射**——**必须明写** |
