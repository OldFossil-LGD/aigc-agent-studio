## 五、局部编辑与重绘（改一只手 / 换一件衣服）

### 5.0 ★ 铁律：只有一处不对时，禁止重 roll

资产图（或任一已锁定的图）**只有一处不对**——发色偏了点、某个表情不对、手上多了件东西——**不许重跑整张**。

**必须走编辑模型局部改，并显式锁定画面其余部分不变。**

理由：这是省抽卡预算最多的一条纪律，也是"去 AI 塑料感"的关键——重 roll 是赌博，局部编辑是手术。

### 5.1 编辑会掉质量 → 双层合成止损

**每次走一遍编辑模型，整图都会变软**——这就是"AI 塑料感"的来源之一。修法不是写更好的提示词，是**加一层**：

```
上层 = 原始高保真渲染（保持不动）
下层 = 编辑后的版本
只在上层把「需要替换的区域」遮罩掉，让下层的新内容透出来
```

脸、皮肤、背景全部保持原始渲染，**编辑模型只碰到被遮罩的那一块**。

**典型用法**：
- **换脸保衣**：把图一的人换成图二的人，保留原本的服装 → 只遮罩脸部；
- **换标识**：只换 Logo 或文字，其余全部原样 → 只遮罩标识区。

> 与 `post-production.md` 的"Relight 是止损不是修复"同构，可并成一条通则：**能遮罩就不重跑；改局部就不改整体。**

### 5.2 局部重绘的参数与失败场景

- **mask 只画要改的**，并**向外多扩 8–16px**、**羽化 8–16px**。
- **denoise 分级**：改人物 0.4–0.6；大替换 0.6–0.8；换手换衣用低 denoise 保身份。
- 提示词**只描述新内容**，不要写"把 A 换成 B"。
- **失败场景**：mask 太小（模型无上下文猜错）· 硬边 mask（接缝露色温与纹理）·
  改整只手或大姿态（高 denoise 下脸与肢体崩）· **提示词与参考图抢控制权**（想改的越多，一致性越差）。

## 六、风格化（美漫描边 / 赛璐璐）的可靠做法

- **免训练先把风格跑稳**：用多参考图先跑 20–30 张锁定风格；
  或**两步法**——先出构图，再用编辑模型"过风格"（忠实度最高）。
- **可复用风格栈**（开源）：插画底座 + 风格 LoRA + 1–2 张风格锚图 + ControlNet(lineart/pose)。
- **赛璐璐防"渐变回潮"**：正面词 `cel shading, flat shading, hard shadow edges, two tone shading, thick clean outline`；
  负面词 `soft shading, gradient, airbrushed, subsurface scattering`；**hires denoise 0.2–0.3**（高了渐变就回来了）。
- **写实 → 目标风格**：**两步走最稳**——先锁人物基准图，再单独一步只改风格。
  **不要在同一次生成里同时换脸 + 换装 + 换景 + 换风格**。

## 七、常见错误（7 条）

1. **参考图混排**（脸图与全身/服装/细节拼一张）→ 人脸占比小 → ID 漂移。
2. **多视图塞一张** → 被识别为多个主体。
3. **参考图质量不足**（<1024²、强磨皮、极端光影、侧脸、遮挡）→ 特征不可用。
4. **风格参考污染身份**：一张图同时被当身份图与风格图 → 复制了它的光线 / 背景 / 色调。
5. **身份描述被打散改词**：`钴蓝色波波头` 改成 `蓝黑色短发` → 模型当成新角色。**冻结词汇表**。
6. **一次改太多变量**（脸 + 装 + 景 + 风格）→ 失败率陡增。
7. **风格词冲突**（几种风格求平均 → 怪物）或**多个风格参考互相抵消**。

## 八、资产一致性工作流

```
1 设计：写 40–70 字冻结身份块 + 单条风格句（各一份，永不改写）
2 建锚：生成单张中性正脸大头照（纯灰底、柔光），反复抽卡到满意 → 存为主参考图
3 扩面：需要时把三视/转身拆成多张独立图存储，不与身份图拼合；道具可给多角度
4 清场：场景图标 safe / risky / unnecessary，删掉 risky；场景另出反向 180° 一张
5 动测：角色跑四类（跨角度 / 跨景别 / 真实场次光 / 同框搭档）、场景跑三类，**同条件连跑 5 条 5/5 成立**才允许锁（→ `production-ledger.md` §二、§三）
6 锁定：多图参考（身份 1 张 + 场景 1 张，最需精准者置前），显式声明参考范围与不继承项
7 变体：先只改场景 → 再改服装 → 再改姿态 → 最后加复杂光影，逐次缩小单次变量
8 纠偏：局部重绘只改一处（禁重 roll）；每批留最像的一张，把最新最佳图回灌作新参考
9 复用：同系列固定同一模型、同 LoRA 权重、同风格词、同风格参数
10 验证：全尺寸对比锚图（别看缩略图）；保存提示词与参数作为一致性凭证
```

**★ 第 5 步"动测"判定标准（重要）**：**静态好看不算数。**
- 角色：**必须在视频里站得住**才算通过——暗场景里两张脸都陷进阴影 → 淘汰；亮场景里"才像一条真的片子" → 入选。
- 场景：**一张场景照可以很好看，但仍然过不了视频测试**（光在照片里 OK，动起来死板无生气）。
- **至少留 2 个 finalist**，不要"够好就收"——等真素材跑出来定胜负。
- **道具豁免动测**（"物件不是演员"），干净参考表即可，省成本。

**"在视频里站得住"到底看什么**——跑完 5 秒测试镜，**逐条勾，三条全勾才算过**：

- [ ] **脸没变**：5 秒里每一帧都是同一个人——不是"大部分帧像"。
- [ ] **身体没散**：手指数目、肢体位置、衣褶与穿帮在动的过程中**没有突变**。
- [ ] **光没漂**：人与场景的光方向、明暗关系全程一致（**没有"人亮了、场景没亮"**）。

**任一条没勾上 → 不是"多抽几次"**，是回第 1 步查变量（多数是身份块被改了词，或多视图被当成了参考素材）。

### ★ 动测的加强版：跑"一组"而不是"一条"，并量化（2026-09-13 补）

上面三条勾是**一条**测试镜的判据。**一条过得去可能是运气**——所以资产生效前要跑**一组**（战斗矩阵），并用**次数**而不是观感来放行：

| 对象 | 必须跑的四 / 三类测试 | 量化放行线 |
|---|---|---|
| **角色** | **T1 跨角度**（正 / 3/4 / 侧）· **T2 跨景别**（近景 + 中远景）· **T3 真实光**（用该角色**实际场次**的光，不是资产中性光）· **T4 同框**（与**每一个**会同框的搭档各一条二人镜） | **同一条件连跑 5 条，5/5 全成立**才算通过；**不许"4 条好就锁"** |
| **场景** | **S1 跨机位**（正反两机位）· **S2 带角色**（场景 + 主角同跑）· **S3 真实光**（该场时段与光源） | 同上 |
| **道具** | 豁免表演类测试，但**"与角色的尺度关系"要验** | — |

**T4 最容易漏**：出资产是**一个人一个人出的**，出场顺序上根本看不见"两人同时在场"。**做法**——出资产时先列**同框关系表**（谁和谁同场、谁和谁同框），按表逐对跑 T4；全片无同框的片 T4 记"**不适用**"，不记"通过"。理由：**同框是漂移最重的场合**，模型要在两个身份间分配注意力，还要防双胞胎（→ `updream-workflow.md` §七 第 6 条）。

**为什么是 5 条**：本库单镜基础预算是 2–4 次（`platform-matrix.md` §四），**验证成本必须低于它所保护的镜头成本**，否则纪律会被绕开。5 条足以暴露"偶然产物"，10 条会让验证本身吃掉预算。**用低分辨率、短时长、极简动作跑**——验的是身份与光影的稳定，不是表演。

**状态与放行门**：资产只有 **draft / locked** 两态（不设中间态；动作口径，完整生命周期见 `asset-standard.md` §9）；**一场戏开生成前，它涉及的每个资产都必须是 locked**，有一个是 draft 就整场不开工。状态机、台账与止损规则见 **`production-ledger.md`**。

> **金句：图便宜，视频生成不便宜。** 在资产层多花 30 分钟，省的是在错资产上烧掉整场戏的生成预算。
