- **边界**：**写六项**（`shot-craft-2.md:58–65` 表）：大气透视 / 体积光雾 / 光线穿透 / 高光处理 / 调色方向（**全片统一一次**，`shot-craft-2.md:64`）/ 颗粒（**全片统一**，`shot-craft-2.md:65`）。**不写**：① 后期工程规格（`:57` 一律不进提示词）；②「加颗粒 / 胶片颗粒」（`:62`、`shot-craft-2.md:65`）；③ `film grain` / `bright lights`（`shot-craft-2.md:69`）。**条数下限：库里未写明**（无数量要求）。段落版同名同序（`segmented-shot-part2.md:18–20`）。

## 三·补 ★ 内容归属与去重表（**每类内容只准有一个"定义块"** · 2026-09-17 立）

**为什么要有这张表**：实测一份合格稿（12 块齐、门禁零告警），仍然出现**同一信息写在两块**：
皮肤句同时出现在【人物与环境】与【光位与影调】· 颗粒同时出现在【后期特效】与【统一提质层】·
**动作链被【人物与环境】整条复述**（时间线里又写一遍）· "呼吸"在四块里各指一件事。
**判据（一句话）**：**一个信息只在一个块里"定义"；别的块只能"引用"，不得复述。**

| # | 内容 | **定义块（唯一）** | 其他块怎么处理 |
|---|---|---|---|
| 1 | **身份锚点**（疤 / 痣 / 压痕 / 发缝 / 咬肌 …） | **【人物与环境】** | 别处**不写**；要提就写"锚点句逐字复用" |
| 2 | **个体化三点**（面部结构 / 身体发型 / 行为痕迹） | **【人物与环境】** | 同上；**面部结构差异只写一处** |
| 3 | **皮肤**（哑光 / 毛孔 / 高光点 / 眼神光） | **【光位与影调】** | 【人物与环境】**不许写皮肤**（实测最常见的重复） |
| 4 | **微表情** | **分两半**：【人物与环境】写**基线 + 破口落在哪两处**；【时间线】写**什么时候开、什么时候收** | 别处的"脸"只许指代 |
| 5 | **静息微动**（重心 / 肩 / 手指） | **【人物与环境】** | 【时间线】只写**动作停下之后**的余韵 |
| 6 | **光源**（是什么灯、什么质地） | **【统一提质层】的"光有出处"行**（全片级） | 【光位与影调】写**本镜落在人身上的走向**（亮面/暗面/影子方向）；时间线·声音·过渡**只许指代**（"门缝那道光"） |
| 7 | **颗粒与胶片痕迹** | **"方向"归【后期特效】**（粗细分布 / 暗部粗中间调细）；**"量级与规格"归【统一提质层】的痕迹行** | 两块**不许写同一句**——各写自己那一半 |
| 8 | **动作链**（入画 / 两步 / 按住 / 回头 / 先…随后…最后） | **【时间线】** | 【人物与环境】**只写姿态与状态**（"他站在桌前，右手按在纸上"），**不复述过程** |
| 9 | **构图** | **【构图】写"起始构图"** | **【运镜】写"运动带来的变化与结尾落点"**——两块各写一半 |
| 10 | **画面手持浮动** | **【运镜】的"随动与浮动"**（原"随动与呼吸"↔ 与人物呼吸撞名，**改名**） | **人物呼吸**归【时间线】；**呼吸声**归【声音】——三者不许混用同一个词 |
| 11 | **道具与场景的外观、磨损** | **【人物与环境】**（逐处写脏 + 材质受光 + 磨损分布） | 构图 · 时间线 · 声音只写**功能**（"那张单子""杯子"），不重述外观 |
| 12 | **禁止项** | **【风险移除】＝内容类**（第二个人 / 字幕 / 现代物品 / 奔跑跳跃） | **【统一提质层】的"禁用"＝画质类**（过锐 / 油光 / 塑料皮肤 / 大平光）——**两类不许混放** |

## 三·补 ★ 不许写死的七个变量（**跨题材复制 ＝ 写死默认**）（2026-09-19 立）

**除它之外，下面七样必须逐片重选**；**跨题材原样复制，就是把某一道题的答案当成了所有题的答案**。

| # | 变量 | 它在哪一块 | 写死会怎样 |
|---|---|---|---|

**读不出，说明它是模板复制，不是针对这一题写的。**

**★ 与 `quality-layer.md` §二·补 的分工**：那边管「**同一部片内**，哪三样（胶片/印片/调制层）要按题材再调一次档」；
