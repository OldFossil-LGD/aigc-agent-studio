## 七、★★★ 平台审计后的修订（2026-09-23 · `审计A1_资产与环节清单` `i-bvghtfsgpyb5`）

> **★ 口径**：**本节与 §一 / §二 冲突处，一律以本节为准。**
> **它的总判断**：**主干（剧本→资产→故事板→首帧→镜头→合成→验收）不用推翻**；**但我把"资产完备度"当成了"每类必出全套"，导致【必出】标得过重**；**真正缺的不是更多资产，而是两个"轻量但关键"的动作**。

### 7.1 ★★ 两条"平台侧不成立"的硬纠正

| 我方原规定 | **平台审计结论** | **修订** |
|---|---|---|
| **角色三视图"正面格去头"**（幽灵人台 / 干净颈切） | **❌ 平台没有"去头正面格"这一标准用法；不建议**——**角色一致性恰恰依赖头部/面部**；去头**会丢失最关键的身份锚点**，且**容易被生成侧误读为异常构图**；**平台的角色 turnaround 模板是"正/侧/背"，各格都正常带头** | **改为「正/侧/背」带头三视图**；**面部一致性交给"定妆正面图"**；**"去头"仅在"只需锁定服装/轮廓"的特殊场合作可选变体**（不作默认） |
| **场景主锚点"必须正对中轴（单点透视），与成片机位一致"** | **❌ 作为硬规则不成立，且自相矛盾**——"正对中轴、单点透视"是**一种特定构图**，**不等于"与成片机位一致"**；**成片大多数叙事镜头是 3/4 或带轻微角度**，**正对中轴的正面图反而无法直接充当这些镜头的首帧** | **★ 修正为条件规则**：**主锚点出"与主力机位视角一致"的图**（主力机位通常**略带 3/4 的人眼视角**）；**是否单点透视取决于镜头设计，不得反向用它约束所有镜头**；**真正要锁的是：空间布局 · 主要道具位置 · 光线方向在各镜间一致**——**这比"是否正对中轴"重要得多**。<br>**★ 但《钥匙》全片确实正对中轴 → 对它而言"正对中轴"仍成立**（**这是"与主力机位一致"的特例，不是通用硬规则**） |
| （保留）空镜"不许出现人" | ✅ **对的**——场景锚点应保持纯净，便于复用、避免把错误人物烙进场景 | 保留 |

### 7.2 ★★ 两个"被低估、接近必出"的**动作**（不是图片资产）

| 动作 | 为什么 |
|---|---|
| **① 首帧 → 镜头的 `start_frame` 引用绑定** | **"首帧驱镜头"不会自动发生**：必须把首帧节点设为镜头的 **`start_frame_image_node`** 并在 prompt 里插桩；**只在文字里说"用上一张"不算** |
| **② 合成前的镜头/口径核对** | 核**镜头数量 · 时长合计＝总时长 · 画面方向与光线连续 · 是否需要转场**；**不做这两件最容易在成片时崩**（时长对不上 / 光线跳 / 镜头缺首帧） |

### 7.3 ★★ 三档必要性 · 平台重判（**替换 §一 的必要性列**）

**【真正必出】**
| 项 | 规格 |
|---|---|
| **① 剧本层：人物小传 + 可拍分镜/动作脚本** | **文本，不额外出图**；**脚本＝镜数/每镜动作/道具交互/时长，合计＝总时长** |
| **② 角色：正面定妆图 ×1** | 正面半身 · 中性光 · 中性底（**身份与面部基准**） |
| **③ 场景：主锚点 ×1** | **空镜 · 按"主力机位视角"** · 锁布局与主光方向（**不强制正对中轴**） |
| **④ 故事板：每镜 ×1** | **灰度 · 一镜一张 · 不拼版**（规划用；**不直接驱动生成**） |
| **⑤ 写实彩色首帧：每镜 ×1** | **引用 ②③（及道具锚点）**；**不得用灰度故事板替代** |
| **⑥ 镜头视频 · ⑦ 合成 · ⑧ 验收** | 流程必出 |

**【应降为条件出】（原标"必出"里可省的）**
| 项 | 降级条件 |
|---|---|
| **角色三视图** | **只在有背面/侧面/服装背面镜头时才出**；**默认三格不必**；若出，用**正/侧/背**（**不是**"正面/背面/胸以上特写"——**胸以上特写与正面格信息高度重复**，特写应在有特写镜时单独出） |
| **场景机位视图（3/4+反打+侧位）** | **由故事板/分镜点名才补，不批量预出**；**反打只在真有反切镜时才要**；"列不出 ≥3 个机位就不出图"**可保留为"不批量预出"的纪律，但不要为凑数而生造镜头** |
| **道具"4–5 视角"** | **降级**：**简单道具（杯/钥匙/手机）1 张干净主图够用**；**复杂或剧情看多面 → 3 视角即可，4–5 过剩**；**道具不需要照搬角色三视图** |

**【条件出 · 维持】**：**手持道具"握持面+接触面"**（手物交互占比大 / 接触面影响穿帮时）· **关键物证近距版**（有物证特写时才出；**价值＝避免从全景放大导致细节模糊或被重绘**）· 多角度板 / 平面图 / 十格设定板（**本题基本用不到**）
**【点名才出】**：风格展示板 · turnaround 三视图模板 · 多机位网格 / 25 格故事板大网格 · **帧预测（前/后推帧）** · 光线/色彩锚点图（**无单独强制类目**，通常由场景主锚点彩图 + 首帧承担）· 平面图（**不是标准必出**）
**【音频】**：**更准确的档位是"按成片是否要声音"的条件出**，**不是默认可有可无**——无对白片通常仍需环境声/氛围支撑写实感。

### 7.4 ★ 平台的标准图片量（**默认口径**）

> **角色 1 + 场景 1 + 道具 1（少量）+ 故事板 N + 首帧 N** —— **三视图 / 机位视图 / 多视角都不是默认项。**

### 7.5 ★ 顺序修订（**三处**）

1. **"人物小传"不是独立环节**，它是**剧本的子产物**；**① 阶段必须同时产出"可拍分镜/动作脚本"**（否则 ②–④ 的资产需求没有依据）；
2. **②③④（角色/场景/道具）没有强先后 → 可并行**（都只依赖剧本，彼此独立）——**我排成串行只是书写顺序，不应成为制作上的等待关系**；
3. **⑥首帧 → ⑦镜头之间要补一个显式动作**：**首帧作为镜头的 `start_frame` 被引用**（见 7.2）①。

**建议顺序**：`①剧本（含可拍分镜脚本）→〔并行：②角色 ③场景 ④道具，按条件出齐〕→ ⑤故事板 → ⑥写实彩色首帧 → ⑦镜头（引用首帧）→ ⑧合成 → ⑨验收`

### 7.6 ★ 并行 / 串行（**它给的分组**）

- **可并行**：**角色定妆 · 场景主锚点 · 道具主图可同批** ｜ 故事板各镜之间 ｜ 各镜写实首帧之间（各自引用锚点，锚点须已生效）｜ 各镜镜头视频之间（各自首帧须已生效，**同批不要互相引用**）；
- **必须串行**：剧本/分镜脚本 → 全部资产 ｜ 资产 → 故事板 ｜ 故事板 → 写实首帧 ｜ 写实首帧 → 镜头（`start_frame` 引用）｜ 全部镜头生效 → 合成 → 验收；
- **★ 允许一个"局部回环"**：**故事板完成后若发现资产缺口 → 回资产阶段补 → 再进首帧**；
- **纪律**：**被引用节点未生效，不运行引用它的下游节点；同批节点不得互相引用。**

### 7.7 ★ 它给的"真正不能省的资产"（第 15 问）

> **写实彩色首帧**（每镜一张，并作为 `start_frame` 真正驱动镜头）。

**理由（它的原话要点）**：**无对白写实短片里，信息几乎全部由画面承载**；**角色/场景/道具锚点最终都要通过首帧才能进入镜头**；**没有合格首帧，身份、光线、物证、氛围都无法稳定锁定，镜头合格率与成片连续性会直接崩**。**角色定妆和场景主锚点虽也极重要，但它们是"为首帧服务的输入"** → **若只能保一个直接决定成片的资产，保首帧。**

### 7.8 ⚠️ 一处待核差异（记录在案）

审计说"镜头**把该首帧设为 `start_frame_image_node`**，并在 prompt 中以**双花括号包裹 `node_key`** 的形式插桩"；
而我从**平台实物**（`关键帧S2_发现翻转`）读到的插桩写法是 **`{{Image 1}}` / `{{Image 2}}`（按参考图位次编号）**。
**→ 两者待核**：可能**两种都支持**（`{{node_key}}` 与 `{{Image N}}`），或**实物口径更新**。**从实物为准，但两种写法都保留备选。**

## 八、★★★ 用处与连线的审计修订（2026-09-23 · `审计A2_用处与连线` `i-35fb43uar9ab`）

> **它的总评**：**材料一（用处）方向全对**，需补**"状态变量 / 时间天气 / 交互面 / 尾帧不被首帧保证"**四处；**材料二（连线）没有反向或错对象的硬伤**，缺口是**【末帧约束】与【道具交互状态锚点】**，风险是**【三视图在正面特写的权重】与【色彩锚点图自带构图】**。

### 8.1 ★ 四处补"说浅/说漏"（补进 §五）

| 项 | **它补的** |
|---|---|
| **A1 人物小传** | **它还决定"可拍的【状态变量】"**——手部与皮肤痕迹 · 长期习惯造成的体态 · 此刻的疲惫/紧张等**"表演前状态"**。**跳过后果不只是"模板脸"，还有"脸对但人不对"**（妆面对、气质与经历不符） |
| **A2 定妆图** | **它是单一/少数角度，锁的是"面部身份与基础妆发"，不锁全身结构与所有角度 → 不能替代 A3** |
| **A3 三视图** | **锁的是【静态结构基线】，不锁"动作中的形变/衣褶规律"**（那是镜头阶段的事） |
| **B1 场景主锚点** | **还隐含锁定【时间与天气的连续性】**（同一时刻光、同一空气感）——**对单场景多镜尤其关键** |
| **B2 机位视图** | **不仅锁透视，还锁【该机位下的遮挡关系与前后景层次】**（哪个道具挡哪个、景深压缩） |
| **C1 道具主锚点** | **若道具会被手持/开合/翻转，单主锚点不够 → 需补【关键交互状态/关键面】** |
| **D1 故事板** | **还负责【镜头间的轴线/视线/方向连续性】与节奏分配**，不只是单镜明暗 |
| **★★ D2 首帧** | **★ 首帧钉死的是"起始状态"，它【不保证尾帧】！**——**若末态重要（放下物体、转身定格），需末帧约束或续写承接，不能默认首帧管全程** |

### 8.2 ★★ 该连没连的四项（**要补**）

1. **★ 末帧/尾帧约束缺显式产物**：对【收束镜头或关键接触定格】，应有 **"末帧关键帧 → 该镜头"**（`frames2video` 的**末帧位**），**否则动作终点无据**；
2. **★ 道具的"交互状态/关键面"锚点**：**凡有开合/翻转/手持的道具都应有对应近距/状态锚点**；
3. **连续性"状态变量"的文字复述要作强制项**（妆是否花了、衣袖是否卷起、物体是否已被移动——**每镜 prompt 复述**）；
4. **色彩/影调锚点图**（要**确保真的建了**）。

### 8.3 ★★ 两处"连了但要降级/净化"

1. **★ 三视图 → 含角色镜头**：**在【正面表情特写】里，三视图权重压到最低或不挂**——**它的平光/制图感会把写实特写拉平、拉硬**；**它最该出现在侧/背/全身/转身镜**；
2. **★ 色彩锚点图 → 每镜**：**必须是"影调/色彩基准"而非带具体构图的图**——**自带强构图/主体会让模型照搬构图、反而污染** → **用纯调色板式/中性画面的色板更安全**。

### 8.4 ★★ 四个"最易手滑连错"的点

1. **场景机位视图必须连到【对应机位】的镜头**——**不要一张机位视图 fan-out 到所有镜头**；
2. **承接尾帧必须是"时间上紧邻的下一镜"**——**不能跨镜引用**（S2 尾帧不能直接给 S4），**否则会把中间动作抹掉**；
3. **锁接触关系（S6 引用 S4）要引"接触成立的那一帧"，不是整段视频**——**否则会把 S4 的运动/镜头轨迹也带进 S6**。

### 8.5 ★★★ "不许连"纪律：三条都对，**补第 4 条 + 区分三视图与多角度板**

- ① 不拿上一镜传身份 → **保持严格**；
- ② 故事板不直接连镜头 → **保持严格**；
- ③ 设定板/多角度板/平面图不连 → **对，但★要区分**：**A3 三视图是【生产用结构锚点】→ 要连（按 8.3 ① 分级）**；**"多角度板/设定板/平面图"是【设计/排镜稿】→ 不连**；**别混为一类，否则会误把 A3 也摘掉**；
- **★ ④ 新增**：**任何【带具体构图 / 带文字 / 带网格 / 带标注】的图（设定板、平面图、分镜带字稿、九宫格）一律不进镜头 `left`**——**网格与文字一旦被模型当内容，会直接污染画面**。

### 8.6 ★ 连线目的的边界（**时长不归连线管**）

- **保风格 ＝ 第②类**（效果基准）· **保尺度 ＝ 第①类**（一致性）→ **都不另立**；
- **★ 保时长 —— 不属于连线目的**：**时长由"分镜时长表/时间预算"控制**，是**时间轴约束**，靠剪辑合成与每镜 `duration` 保证；**→ 不要为了"保时长"去造连线**。

### 8.7 ★★★ 扇出 与 "每 N 镜拉回"（**两层机制，叠加使用**）

- **扇出**解决**【引用拓扑】**；**"每 N 镜拉回"**解决**【漂移校正的节奏】**；
- **★ 最稳共存（三层）**：**① 拓扑层：始终 fan-out、所有镜头引用同一个锚点 key，绝不复制成 9 份（复制会产生 9 个漂移版本）② 校正层：每 N 镜 + 高风险镜（特写/物证/接触/转身）插入"首帧锁定/承接尾帧" ③ 文字层：每镜 prompt 复述当前关键状态**；
- **→ "每镜都挂锚点"是底线，"每 N 镜拉回"是额外保险，不是替代关系。**

### 8.8 ★★ 中转节点的两条硬危害（**为什么不能设**）

① **二次栅格化丢信息、降清晰度**；② **模型可能把拼接线/背景/版式当实体内容污染画面**。
**★ 唯一近似"中转"却可接受的是 D2 首帧**——**它是合法的"聚合产物"，因为它是经过写实化重绘的【创作环节】**；**区别：首帧产出新增信息，中转图只做拼接（不新增、只损耗）**。

### 8.9 ★★ "未生效不得进下游 left"的正确理解（**计划可占位、执行不许占位**）

- **可以在【账本/编排计划】里用占位符登记依赖**（先写好将来的 `node_key` 位置）；
- **但【不得在占位产物未生效时实际 run 下游】**；
- **★ 判断标准一句话**：**要 run 的节点，其 `left` 内所有引用必须已生效（有真实产物）**。

### 8.10 ★★ 非引用但保一致性的 **9 条手段**

1. **同一锚点复用同一 key**（不复制节点）；2. **文字复述**（每镜复述身份/服装/当前状态/站位/光线方向与色温——**引用给"看图依据"，文字给"该镜必须成立的状态"，互补，不能只挂图不写字**）；3. **首帧/尾帧锁定**（**必要时尾帧钉终点**）；4. **固定 seed / 模型与参数一致**（**★ seed 不是身份一致性的主手段，只作辅助**）；5. **统一的镜头与光线描述模板**（**避免同义词被模型理解成不同光**）；6. **状态变量表（连续性表）**（记每镜开始/结束时"妆发/衣物/物体位置/接触关系"）；7. **轴线/视线/方向规则**（**靠分镜与文字，不靠连线**）；8. **时间预算/时长表**；9. **审校回读**（**不合格即重建，避免把漂移产物当下游基准**）。

### 8.11 ★★★ 它给的"最容易被搞错的连线"

> **把"上一镜（视频/尾帧）"当成身份与样式的来源去喂下一镜**，而不是只让锚点传身份、尾帧仅传"末态连续性"。
> **一句话：身份永远走锚点（定妆/三视图/道具/场景），上一镜只负责"接动作末态"，绝不负责"我是谁、东西长什么样"。**
> **一旦反了，漂移会沿镜头链逐镜累积放大，且越到后面越救不回来。**

### 8.12 ★ 允许的"镜→镜"例外：**两个成立 + 一个窄边界**

1. **续写/承接** ✓（**只传"末态画面"，不传身份**）；2. **锁接触关系** ✓（**限定"接触成立的具体帧/状态"，不引用整段**）；3. **★ 新增（边界很窄）**：**同一动作被拆成多镜、机位切换但动作必须无缝时，允许用"动作交接帧"互引**（本质仍是尾帧/首帧承接）。
**→ 除此之外不建议再开口子**：**尤其不要为了"省一张锚点"而用镜→镜传身份/传道具样式**。

## 十一、★★★ 重大修正：「拉回」是**帧级动作**，不是连线动作（2026-09-23 · `R38` `i-fhhped9wgpv5`）

> **★ 修正根本性**：正册 §六 6.5 写的「拉回镜＝`left` 里重新含锚点的镜」**是错的**（那是 no-op）。
> **它的一句话**：**锚点一直在线上，漂移发生在帧里；拉回换的是首帧、断的是续链，不是重新连线。**

### 11.1 为什么原写法错（它确认了我的自查）
- 连线规则「场景主锚点 → 每一个镜头」「角色定妆图 → 每个含角色镜头」→ **每镜 `reference_nodes` 里始终带着锚点键** → **"把锚点重新挂回去"＝空操作**；
- 原写法**把两层混了**：**连线层**（`reference_nodes` 是否含锚点 → 一直含，无需拉回）vs **帧层**（`start_frame`/`continue_from` 用哪一帧 → **这才是会漂移、需要拉回之处**）。

### 11.2 ★ 正确表述与完整动作
> **拉回 ＝ 在首帧层「重新用锚点图/已确认干净帧锚定」＋「断开 `continue_from` 续链」。**
1. **`start_frame_image_node` 指向锚点图**（角色定妆图 / 场景主锚点彩图 / 上一张已确认无漂移关键帧）；
2. **不设置/清除 `continue_from`**（不继承长链尾帧）；
3. `reference_nodes` **照常挂满锚点**（本来就挂着，不动）。
**★ 两种影响的区分**：**受"锚点"影响＝保留（一致性来源）**；**受"上一镜尾帧/续链"影响＝切断（漂移来源）**。

### 11.3 ★ 操作六步 + 口诀
① **选拉回点** → ② **备首帧**（记下 `start_frame_image_node`）→ ③ **建视频节点**（首帧字段＝锚定帧 · **不设 `continue_from`** · `reference_nodes` 照常扇出 · prompt 插桩并写明三句为准）→ ④ **先不运行，人工核对** → ⑤ **审批后点火** → ⑥ **回读校验**（合格则以此镜尾帧为后续短链新起点，最多再链 N−1 镜后再拉；不合格在新节点重抽，**不在漂移链上将就**）。
**★ 口诀**：**换 `start_frame`、断 `continue_from`、`reference_nodes` 照旧挂满。**

### 11.4 ★★ "每 N 镜"的 N：四个判据
| 判据 | 内容 |
|---|---|
| **A 按链型给基线** | **纯视频续视频硬链 → N 取 2–3**（漂移最快）· **图生视频链（首帧来自图非上一镜尾帧）→ N 取 4–6** · **每镜都独立用锚点图出首帧、无续链 → 近似"每镜拉回"，N 概念弱化** |
| **B 按内容下调（硬覆盖）** | **出现高风险镜位（特写/物证/接触/转身/换装/换光/新道具/新角色入画）→ N 在该镜强制收窄为 1**（该镜即拉回点），不数格子 |
| **C 实测校准（主）** | **同套锚点跑测试链（连续 6 镜），逐镜回读比对相似度，找"首次跌破阈值"的镜号 m → 正式片取 N = m−1**（留一格余量）；不同景别/模型各跑一次 |
| **D 按模型稳定性** | **换模型/分辨率/风格后重新校准，N 不跨配置沿用** |
**★ 落地**：**以 C 为主 · A 给先验初值 · B 硬覆盖** → **"默认按实测间隔，高风险镜前必拉"**。
**★ 触发方式**：**计数上限（兜底）＋ 事件触发（优先，并清零计数器）→ 取"先到者"**。

### 11.5 ★ 长链漂移的三类可观测信号
1. **帧比对**（最直接）：抽每镜首/尾帧与角色、场景锚点做相似度（**人脸 embedding 余弦 · CLIP 图文相似度 · 色调直方图距离**）→ 阈值**用自己测试链标定**；
2. **续链结构字段回读**：`get_node_details` 查**是否仍带 `continue_from`、`start_frame` 指向锚点还是上一镜尾帧、`reference_nodes` 是否齐**——**连续多镜"首帧＝上一镜尾帧"即处硬链累积区**；
3. **生成内容回读**：`analyze_video` 看分段视觉描述，查发型/服装/道具/空间/色调是否偏移。
**★ 它如实说**：**当前没有"一致性自动评分"的一键机检**；**可落地路径＝抽帧 +（外部/自建）embedding 相似度 + 字段回读 + `analyze_video` 比对 → 组合成"超阈值即提示拉回"的检查点**；**高风险镜保留人眼复核**。

### 11.6 ★★ 色彩/影调锚点图：**默认不单独建**（消除我方口径不一）
- **默认不建**——影调由「**场景主锚点彩图 + 每镜首帧**」承担；**影调依附于具体场景的光源/材质/空间，单抽一张可能与实际光照冲突**；
- **需单独建**：**多场景/多时段但要统一调色** · **强风格化**（特定青橙/低饱和/复古胶片，场景图难稳定传递）· **跨模型/跨批次发现色调逐镜漂移明显**；
- **★ 若建，必须是"一张带代表性场景的影调图"，不是纯色板/中性灰板**（**纯色板只定义白平衡，模型无法据此把色调贴到画面**）；内容建议：最典型机位 + **角色皮肤（肤色基准）+ 中灰环境 + 主光源 + 目标 LUT 风格的成片感画面**，命名「影调锚点_全片统一」；
- **★ 条件规则（消除矛盾）**：**未建 → 每镜连场景主锚点彩图**；**建了 → 每镜再加连影调锚点键**，prompt 写明色调/对比度/光比以它为准。

### 11.7 ★★ 同节点重抽会漂，且有硬上限
- **两层原因**：① **采样随机性**——**重抽是"同一分布多次取样"，非单调逼近锚点；多抽不保证第 k 次更像**；② **版本/缓存因素**——模型版本/参考解析/seed 策略变化会**让分布本身移动**（表现"越抽越不对"）；
- **★ 若该镜在续链中，真正漂移源是上游尾帧** → **仅在本节点重抽治标不治本 → 应回最近拉回点重新锚定**；
- **★ 硬上限：同节点重抽 2–3 次**；超过仍不合格 → **问题在约束而非运气 → 升级**（加强/更换首帧锚定 · 把该镜改拉回镜 · 或细化 prompt 后在新节点重试）；**与异常规则一致：同一产物最多重建 3 次**。

### 11.8 ★ 它给的"最容易被误写的一条"
> 把「拉回」写成**连线动作**（"重新在 `reference_nodes`/`left` 里挂回锚点"），而它其实是**帧动作**。

### 11.9 ★ 与总策略的衔接（**正交，不矛盾**）
| 机制 | 解决 | 层级 |
|---|---|---|
| **扇出**（每镜挂场景+角色锚点） | 每镜都能看到锚点 | **横向空间约束** |
| **拉回**（每 N 镜/高风险镜前：换首帧 + 断续链） | 长链时间轴累积漂移 | **纵向时间重置** |

## 十二、★★★ 标准七层链与"资产按需裁定"（2026-09-23 平台 Agent 逐条裁定 · 新增）

> **裁定源**：`审计A4_层次与连线`（画布 库审计_1 · 节点 `i-27rxxvwnwqga`）→ 全文已落 `libtv-official-qa-part7.md` 口径之外，**本节为结论层**。

### 12.1 标准七层链：每层只引自己的直接上游
| 层 | 节点 | 引用谁 |
|---|---|---|
| ① 剧本 | `P1` | 无上游 |
| ② 分镜 | `P2` 总分镜表 | 引 `P1` |
| ② · 分 | `Dn` 各镜分镜卡 | 引 `P2` + **本镜入镜资产 A\***（`A1/A2/A3/A4` 中实际入镜的那些） |
| ③ 资产 | `A*` 主锚点 | 可引 `P1`/`P2` 作内容依据 |
| ③ · 派 | 派生视图（三视图/机位视图/近距版） | **引各自的主锚点** |
| ④ 故事板 | `Sn` | **引 `Dn`（本镜分镜卡）+ 该镜入镜资产** |
| ⑤ 首帧 | `Fn` | **引 `Sn`（排第一参考位）** + 本镜资产；`Dn` 可选（约束已随 `Sn` 传递时**不加**，避免重复信号） |
| ⑥ 镜头 | `Vn` | **引 `Fn`（首帧排第一）** + 本镜资产；`Dn` 可作文本约束 |
| ⑦ 合成 | `X1` | **引全部 `Vn`**（用 `video-clip` 节点；**接口传参不能替代引用边**） |

**★ 三条硬判断**：
1. **S 不直连 V**：镜头的视觉起点已由首帧承载；故事板再直连镜头＝跨层冗余，且会让模型同时收到"草图"与"精细首帧"两套构图信号 → **反而干扰**。
2. **同一资产被 D/S/F/V 四层引用不过载**：分层链路的标准形态，每层职责不同（分镜卡＝选角清单 · 故事板＝构图元素 · 首帧＝精修依据 · 镜头＝身份锁定）。**真正要防的过载是"单节点一次挂太多素材"** → 按镜裁剪，单节点参考图 **2–4 张**为宜。
3. **分镜卡（文本节点）引资产图有意义**：意义是**登记与锁定**（写死本镜资产清单、供审计核对、资产变更时可定位受影响分镜卡），**不是"喂给模型看图"** → 所以它既引 `P2`、也引本镜资产，两者用途不同不冲突。

### 12.2 ★★★ 资产数量＝**一致性需求驱动，不是层数驱动**
| 资产 | 主锚点 | 派生视图：**什么条件下才做** |
|---|---|---|
| **角色** | 定妆图（锁脸） | **三视图**：跨镜连续出现、有角度/服装一致性风险时**值得做**（锁体型/服装/发型；**不承担锁脸**） |
| **场景** | **平面图**（见 12.3） | **机位视图**：**与分镜机位一一对应**；机位差异大 → 2–3 张；**三镜同机位 → 只需 1 张，不为凑层数加** |
| **道具** | 主锚点（锁结构材质） | **近距版**：**仅当确有特写/近景镜头**才做；没有特写就是多余的 |

**★ 判据一句话**：**"镜头里不会以该视角/状态出现的视图，一律删。"**

### 12.3 ★★ 场景层口径：**平面图作主锚点，所有机位由它推得**（用户定案）
- **场景层最上游＝俯视正投影平面图**（无透视、无立体投影、无人物、不写机位）；家具位置/朝向/相互距离按比例准确，**把"核心情节位"（如抽屉拉开一指宽）在图面坐标上标出来**。
- **机位视图＝平面图在某机位下的透视落地**，`left` 引平面图；**每个机位一张**，与分镜表"机位"列一一对应。
- **理由**：平面图锁"空间关系"，机位视图锁"该机位下的空间+光位"；先有平面布局才不会出现"每张机位图各写一套房间"。**★ 它与 §7.3 的"空镜主锚点"不是二选一**：平面图在上游锁关系，空镜是某个机位的 view（`asset-standard.md` §5）。

### 12.4 15 秒 / 3 镜的**最小完备集**（小体量按需裁剪）
- 文本：`P1` 剧本 · `P2` 总分镜表 · `D1/D2/D3` 分镜卡；
- 资产：**角色定妆 1 张 + 场景平面图 1 张 +（有道具才）道具主锚点 1 张**；三视图/机位视图/近距版**全部按镜头实际需要触发，不预先配齐**；
- 画面链：每镜 `S`、`F` 各 1 张（共 3+3）→ `V1/V2/V3` → `X1`。

### 12.5 ★ 最容易被漏的一条边
**`Dn → Sn`（分镜卡→故事板）** —— 它是**新增"分镜层"后才出现**的边，改造旧链时最易漏。
**检查口诀**：**加一层，就必须补这一层到其直接下游的边。**
其余"该连没连"的边 → 见 `libtv-op-manual-part3.md` **§三十·30.4**。
