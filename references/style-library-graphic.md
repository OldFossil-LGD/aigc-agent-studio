# 风格库 · F 卷：平面与图形视觉体系（F01–F12）

> **何时读**：`style-library.md` 选取流程筛到「平面 / 图形 / 印刷」分类，或需要**片头字卡、海报、设计感强烈的画面**时。**读完回哪**：回 `style-library.md` 定案。

> 这一卷的共同点：**画面是一张被设计过的平面**——它们不假装有纵深，而是把"版面"当作画面本身。
> **最适合三种用途**：① 片头 / 片尾与转场字卡；② 海报与宣传物料；③ **刻意打破写实的段落**（人物被处理成拼贴/平面符号）。

---

### F01 · 瑞士国际主义 Swiss / International Typographic Style
**识别**：网格、无衬线、大量留白——秩序本身就是画面。
- **核心视觉**：**严格的对齐网格**、**无衬线字（Helvetica 一路）**左齐与不规则右边缘、极简的摄影（黑白或单色）与大面积留白
- **色彩光影**：**黑、白 + 一个信号色**（红最经典）；**平光**、无渐变、无纹理
- **构图材质**：**非对称平衡与网格分区**、字与图各占网格单元、留白是主动元素；纯净的哑光纸感
- **参考作品**：约瑟夫·米勒-布罗克曼的海报、《Neue Grafik》杂志、瑞士联邦铁路的视觉系统
- **适用场景**：片头字卡、机构与产品、冷静的现代场面
- **叙事氛围**：理性、克制、可信；适合制度、科学、现代性的题材
- **可写句式**：`瑞士国际主义风格，画面被看不见的对齐网格分区，主体只占一到两个网格单元、其余是大面积留白；无衬线字体左对齐；黑白加一个信号红；完全平光、无渐变无纹理；黑白摄影的清晰主体`
- **★ 质感与痕迹**：`网格 + 无衬线 + 大留白` · `摄影是黑白或高对比的` · `版面元素对齐到线`
- **★ 最容易被写歪成什么**：`装饰花纹` · `手写字体` · `多层特效`

### F02 · 后现代解构排印 Postmodern / Deconstructivist
**识别**：字被拆开揉皱后重新扔在纸上——但你知道它是故意的。
- **核心视觉**：**被拉伸、重叠、切割的字**、图层错位与重影、多处并置的混乱信息层次、碎片化的图像
- **色彩光影**：**撞色的荧光**（品红、荧光绿、亮橙）配黑白；**平面无光影**，靠图层叠加制造深度错觉
- **构图材质**：**刻意失衡的多焦点构图**、元素互相覆盖且"印刷错位"、密集到溢出的信息；复印与激光打印的粗糙颗粒
- **参考作品**：Emigre 杂志、Cranbrook 学派、大卫·卡森的版面设计
- **适用场景**：朋克与亚文化、音乐与艺术事件、精神失序的段落
- **叙事氛围**：嘈杂、反叛、信息过载；适合失序与躁动的场面
- **可写句式**：`后现代解构排印，字体被拉伸重叠与切割、图层之间有明显的印刷错位与重影；荧光撞色（品红、荧光绿）配黑白；多个信息块互相覆盖、构图刻意失衡；复印机与激光打印的粗糙颗粒`
- **★ 质感与痕迹**：`字被拆开、揉皱、错位、互相压` · `高对比黑白 + 一个刺眼的色` · `印刷的错版与叠印`
- **★ 最容易被写歪成什么**：`工整的网格` · `经典衬线排版` · `柔和的色彩`

### F03 · 日本极简平面 · 余白
**识别**：画面里只放了一样东西，其余全是空气。
- **核心视觉**：**一个主体占据极小面积**、**巨大而精确的余白**、细微的质感（纸、白瓷、木）
- **色彩光影**：**白、米白、灰 + 一抹淡色**（嫩绿、樱粉、藏青）；**均匀柔和的漫射光**，没有明显阴影
- **构图材质**：**极端不对称与偏置**、主体常贴在画面一角或压边；**纸纹、粗糙的陶土、和纸的纤维**
- **参考作品**：原研哉（无印良品）、田中一光的几何、《白》所代表的审美
- **适用场景**：产品与器具、安静的室内、片尾字卡、日常细节
- **叙事氛围**：空、静、克制的自信；最适合"少即是多"的段落
- **可写句式**：`日本极简平面，画面上只有一个很小的主体位于一角，其余是巨大的空白；白与米白的底色、只一抹淡色；均匀柔和的漫射光、几乎没有阴影；和纸的纤维与陶土的粗糙质感清晰可见`
- **★ 质感与痕迹**：`只放一样东西、其余是空气` · `大面留白 + 一处实的色块` · `纸的纹理与印刷的哑光`
- **★ 最容易被写歪成什么**：`元素堆叠` · `饱和多色` · `写实照片作底`

### F04 · 中国当代汉字海报
**识别**：汉字本身就是图形——笔画被撑满整个画面。
- **核心视觉**：**被放大到切出画面的汉字**（笔画切出画面）、**印章式的红块**、墨迹的飞白与枯笔、竖排的文字
- **色彩光影**：**红、黑、白 + 金**（中国设计的经典四色）；**平面无光影**，靠色块与笔触对比
- **构图材质**：**满版的字块与留白的对冲**、印章作为画面重心；宣纸的渗透与印刷的厚重墨色
- **参考作品**：中国当代海报设计（汉字排印的传统与现代融合）
- **适用场景**：片头字卡、文化题材、历史与家国
- **叙事氛围**：有力、庄重、文化的重量；适合中国题材的标题设计
- **可写句式**：`中国当代汉字海报，一个巨大的汉字被放大到笔画切出画面以外，有墨迹的飞白与枯笔；红色印章块作为画面重心；红、黑、白与金的配色；平面无光影、靠笔触与色块的对比；宣纸的渗透质感`
- **★ 质感与痕迹**：`汉字本身就是图形、被拆解与重组` · `朱红、墨黑、宣白` · `笔画的肌理与残缺`
- **★ 最容易被写歪成什么**：`西式无衬线` · `彩色渐变` · `图案装饰`

### F05 · 拼贴艺术 Collage
**识别**：不同来源的图片被剪开粘在一起，接缝明明白白。
- **核心视觉**：**可见的剪刀边缘**、不同材质与比例的图像拼合（旧杂志、照片、手绘）、胶带与水渍的痕迹
- **色彩光影**：**彼此不协调的色彩**并列（因为来自不同来源）、**每块图各自有光源**（因此整体光影是断裂的）
- **构图材质**：**重心失衡的堆叠**、撕纸与剪裁的毛边、**叠层的实影**（纸片投下的阴影）；纸张的厚度、胶带的反光、旧纸的发黄
- **参考作品**：汉娜·霍克的达达拼贴、约翰·哈特菲尔德的摄影蒙太奇、当代 zine 文化
- **适用场景**：记忆碎片、心理状态、档案与调查、反讽段落
- **叙事氛围**：断裂、拼凑、不安的幽默；**最适合表现"记忆不可靠"与信息断层**
- **可写句式**：`拼贴艺术，画面由来自不同来源的图像剪贴拼合、能看到清晰的剪刀边缘与撕纸毛边；各部分的光源方向不一致、色彩彼此不协调；纸片相互叠压并投下真实阴影；有胶带反光与旧纸发黄的痕迹；比例刻意失调`
- **★ 质感与痕迹**：`剪开的图粘在一起、接缝可见` · `材质冲突：报纸、照片、色纸` · `剪刀边与胶的痕迹`
- **★ 最容易被写歪成什么**：`无缝合成` · `统一色调` · `写实景深`

### F06 · 迷幻艺术 Psychedelic
**识别**：所有线条都在流动膨胀，颜色像被调错了。
- **核心视觉**：**流动的有机曲线**（气泡字、熔化的形）、**高频的重复纹样**（同心圆、波纹、格纹）、视觉眩晕的图案
- **色彩光影**：**荧光色的高饱和对撞**（紫配橙、绿配粉）、**渐变光晕**与发光边缘；无自然光、光像在皮肤下发出来
- **构图材质**：**中心放射或满版流动**、字体本身被液化、图形密度高；海报的丝网印墨与颗粒
- **参考作品**：60 年代旧金山音乐海报（Fillmore 风格）、维克多·莫斯科索、韦斯·威尔逊（Wes Wilson）式的当代迷幻设计
- **适用场景**：音乐、幻觉、药物的主观体验、狂欢段落
- **叙事氛围**：眩晕、狂喜、意识边界的溶解；适合非现实的主观体验
- **可写句式**：`迷幻艺术，所有线条呈流动的有机曲线、字体被液化膨胀；荧光色高饱和对撞（紫配橙、绿配粉）并带光晕；同心圆与波纹的高频重复纹样铺满画面；光像从形状内部发出、没有自然光源`
- **★ 质感与痕迹**：`线条流动膨胀、颜色像调错了` · `高饱和的补色对撞` · `字被拉伸成波浪`
- **★ 最容易被写歪成什么**：`克制的配色` · `直线几何` · `写实阴影`

### F07 · 涂鸦与街头艺术
**识别**：喷漆的边缘在墙上晕开，字迹挤在一起争抢位置。
- **核心视觉**：**喷漆的柔和喷边与滴流**、气泡字与立体字、多重覆盖的标签（tag）、模板镂印的硬边图形
- **色彩光影**：**高饱和的喷漆色**（亮红、黄、钴蓝、荧光绿）与**墙面的脏底**形成对比；夜里的街灯或白天的直射光
- **构图材质**：**墙面的水平展开**、字与图层层覆盖（新的压住旧的）、画面的边缘被切断；**粗糙混凝土、砖、锈铁、剥落的旧漆**
- **参考作品**：纽约地铁涂鸦、班克斯的模板涂鸦、巴西的 pixação
- **适用场景**：后巷、桥下、废弃建筑、都市边缘
- **叙事氛围**：反抗、被压抑的表达、都市的粗糙生命力；适合街头与青年题材
- **可写句式**：`街头涂鸦风格，喷漆形成的柔和喷边与向下滴流的痕迹；气泡字与多层覆盖的标签互相争夺墙面；高饱和的喷漆色（亮红、钴蓝、荧光绿）画在粗糙的混凝土与剥落的旧漆上；画面沿着墙面水平展开、边缘被切断`
- **★ 质感与痕迹**：`喷漆的晕边与滴流` · `一层盖一层的字与墙面纹理` · `被撕掉一角的旧海报`
- **★ 最容易被写歪成什么**：`干净的墙面` · `矢量字体` · `工整构图`

### F08 · 默片与复古电影字卡
**识别**：黑底白字，字体是画的，画面里有一圈胶片划痕。
- **核心视觉**：**手绘或雕版感的标题字**（衬线华饰）、**装饰性边框**（卷草、几何）、插画式的图解（手、心、箭头）
- **色彩光影**：**黑白或单色调**（可做棕褐/靛蓝的染色）；**轻微的闪动与曝光不均**、边缘发黑（暗角）
- **构图材质**：**居中的对称版式**、边框包裹、字与插画分层排列；**胶片的划痕、灰尘、帧抖动、可变形的片门**
- **参考作品**：默片的开场字幕卡、早期动画片头、默片风的当代致敬
- **适用场景**：片头片尾、章节分节、怀旧叙述、戏中戏
- **叙事氛围**：复古的庄重、剧场式的讲述；**是章节分隔最有效的视觉语言**
- **可写句式**：`默片字幕卡风格，黑底上手绘的华饰衬线字体居中排列，四周是装饰性的卷草边框；画面上有胶片的划痕、灰尘与暗角，边缘略有变形；轻微闪烁的曝光不均；下方有插画式的图解符号`
- **★ 质感与痕迹**：`黑底白字、字体是画出来的` · `胶片划痕与抖动、边缘发黑（暗角）` · `装饰性的花边框`
- **★ 最容易被写歪成什么**：`现代字体` · `彩色` · `高清锐利`

### F09 · 编辑设计 Editorial Grid
**识别**：像一本被摊开的杂志——栏、线、图、字各就各位。
- **核心视觉**：**分栏的版面与细分隔线**、大图跨越栏位、**导语与正文的层级**、页码与栏目名
- **色彩光影**：**克制的两到三色**（黑 + 一个品牌色 + 纸白）；照片是清晰写实的、版面是平的
- **构图材质**：**网格分区与非对称平衡**、图与文的咬合、页边与出血的处理；**纸张的哑光或反光涂布**
- **参考作品**：《Esquire》《The New York Times Magazine》的封面与内页、独立杂志
- **适用场景**：档案与调查、人物特写、时间线叙事、片中的文档与信件
- **叙事氛围**：权威、考据、条理化；适合需要"信息感"的段落
- **可写句式**：`杂志编辑设计，画面像摊开的杂志对页——分为两到三栏并有细的分隔线；一张大照片横跨两栏，旁边是导语与正文的层级；黑加一个品牌色配纸白；页码与栏目名在页角；纸张是哑光涂布`
- **★ 质感与痕迹**：`一本被摊开的杂志：分栏、图注、页边` · `衬线与无衬线混排` · `纸张的厚度与印刷网纹`
- **★ 最容易被写歪成什么**：`单页海报感` · `无网格的随意排布` · `数码感`

### F10 · 高对比双色印刷 Duotone / Risograph
**识别**：整张图只有两个颜色在互相错位。
- **核心视觉**：**整幅画面被压成两个色相**（如黑 + 荧光粉）、**套色错位的重影**、油墨的粗糙颗粒与不均匀
- **色彩光影**：**只有两个颜色**，所有明暗靠这两色的覆盖率表达；**无渐变**或只有网点造成的假渐变
- **构图材质**：**网点（halftone）构成的明暗**、油墨在纤维上晕开的毛边；**粗糙的再生纸**与油墨的哑光厚度
- **参考作品**：Risograph 独立出版、丝网印海报、双色印刷的唱片封面
- **适用场景**：海报、片头、档案感画面、低成本出版物的质感
- **叙事氛围**：独立、手工、克制的潮流感；**成本极低但辨识度极高**
- **可写句式**：`双色印刷风格，整幅画面只由两个色相构成（如黑与荧光粉），明暗全部靠这两色的网点覆盖率表达；套色有轻微错位形成重影；油墨在粗糙的再生纸上晕开、颗粒不均匀；没有渐变`
- **★ 质感与痕迹**：`整张图只有两个颜色在错位` · `网点与叠印的错版` · `颜色的边界是被套出来的`
- **★ 最容易被写歪成什么**：`彩色照片` · `渐变过渡` · `柔和的边`

### F11 · 手写手账与 Scrapbook
**识别**：胶带、便签、圆珠笔字，一个人的桌面被拍了下来。
- **核心视觉**：**手写的圆珠笔字**、**胶带与贴纸**、便签与拍立得、箭头与下划线、涂改的痕迹
- **色彩光影**：**温和的低饱和 + 一两处荧光贴纸**；**桌面台灯的暖光**或窗边的自然光、纸张的实影
- **构图材质**：**俯拍的桌面平面**、物件随意堆叠但有生活逻辑；**纸的纤维、胶带的反光、笔迹的压痕**
- **参考作品**：手账文化、调查员的线索墙、zine 中的个人记录
- **适用场景**：调查与推理、私人记忆、计划与推演、日常细节
- **叙事氛围**：私人、亲近、未加整理的真诚；适合"一个人的视角"
- **可写句式**：`手账拼贴，俯拍一张桌面——便签、拍立得与手写的圆珠笔字用胶带贴在纸面上；箭头、下划线与涂改痕迹清晰可见；桌灯的暖光让纸片投下真实阴影；温和的低饱和配色加一两处荧光贴纸`
- **★ 质感与痕迹**：`胶带、便签、圆珠笔字` · `剪纸边与贴歪的照片` · `纸的褶皱与钉书钉`
- **★ 最容易被写歪成什么**：`工整排版` · `印刷体` · `数码合成感`

### F12 · 工程蓝图与系统图
**识别**：一切都被画成了线框，还被标注了尺寸。
- **核心视觉**：**白色或青色的细线框**、**尺寸标注与引线**、剖面与爆炸图、网格与坐标、图例与编号
- **色彩光影**：**蓝底白线**（经典蓝图）或**黑底青线**（当代系统图）；**纯平面、无光影**，靠线的疏密表达层次
- **构图材质**：**多视图并置**（正视图 + 剖面 + 局部放大）、标注文字环绕主体；纸的折叠痕迹或屏幕的像素光
- **参考作品**：建筑蓝图、机械爆炸图、HUD 界面与科学示意图
- **适用场景**：技术说明、推演与规划、科幻的仪器界面、解构性的段落
- **叙事氛围**：精确、理性、可被分析的世界；**最适合"把事物拆开来看"的段落**
- **可写句式**：`工程蓝图风格，深蓝的底上是白色的细线框，主体以线框与剖面呈现；四周环绕尺寸标注、引线与编号；画面包含正视图与局部放大图的并置；完全平面、没有光影；纸上有折叠的痕迹`
- **★ 质感与痕迹**：`一切被画成线框并被标注` · `蓝底白线或黑底青线` · `尺寸线、剖面线、引线`
- **★ 最容易被写歪成什么**：`写实材质` · `照片纹理` · `装饰色`

## 本卷易混提示

| 易混对 | 一句话分辨 |
|---|---|
| 瑞士国际主义 / 编辑设计 | 瑞士是**网格 + 无衬线 + 大留白**（纯）；编辑设计是**分栏 + 图字咬合**（实用） |
| 后现代解构 / 拼贴 | 解构是**字被拆**（排印层面的混乱）；拼贴是**图被剪**（图像来源的混乱） |
| 高对比双色 / 波普 | 双色是**只有两个色相 + 套色错位**；波普是**多色 + 网格重复** |
| 迷幻 / 涂鸦 | 迷幻是**流动的曲线与光晕**；涂鸦是**喷漆的硬边字与墙面** |
| 蓝图 / 蓝图以外的线稿 | 蓝图的标志是**标注与引线**——没有标注就只是线稿 |
