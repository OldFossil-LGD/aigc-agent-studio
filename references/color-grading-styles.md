# 调色风格族谱（14 族：色相倾向 · 色彩构成 · 明暗与对比 · 场景 · 辨识要点 · 提示词落点）

## 一、日系清新（高调通透）

- **色相倾向**：**青蓝为底 + 暖橙肤色**——环境往青，人往暖
- **色彩构成**：**降橙/黄/绿饱和 + 提明度**；**绿色色相往青偏**（薄荷绿 / 抹茶色）；蓝原色降饱和（全图"灰一度"）；**整幅低饱和**
- **明暗与对比**：**高调 + 低反差 + 暗部发灰不坠底**；阴影大幅提亮；**高光压住但保留溢出边缘**（"过曝要亮，不要爆"）；**曲线暗部上提**（模拟胶片肩部压缩）
- **分离色调**：**高光加暖黄 / 阴影加青蓝**（模拟交叉冲洗的结构）
- **场景**：日常、校园、写真、旅行、治愈向
- **★ 辨识要点**：**看暗部**——**它是发灰发亮的，不是黑的**；**"色彩不是调得越多越好，而是减得越多越高级"**
- **提示词落点**：写在【后期特效】的"调色方向"行——`高调、低对比，暗部发灰不坠底；环境往青、人往暖橙；暖色只用一小块`；**不要**写"日系滤镜"（模型会给你糖水色）

## 二、复古港风 / 王家卫式（暖高光 + 绿阴影）

- **色相倾向**：**暖黄橙红（钨丝）压在暗底上 + 阴影带饱和的绿黄**——**冷暖对撞是本族签名**
- **色彩构成**：红色**偏橙红**且更沉（色相+12、饱和+25、明度−18）；绿色**偏墨绿**且更暗（色相−12、饱和−25、明度−30）——**"红更沉、绿更暗，撞在一起不发飘"**
- **明暗与对比**：**暗调打底**；**黑位不压死（lifted veil / Fade + Matte）**；**高光有红橙 halation 光晕**（灯与霓虹"出血"）
- **标志性结构**：**暖高光 vs 青绿阴影** + **颗粒**（Grain 20–25）+ **暗角**
- **场景**：夜街、走廊、车厢、茶餐厅、雨夜霓虹
- **★ 辨识要点**：**看阴影是不是绿的**——暖色高光谁都有，**阴影发绿黄才是这一族**；另有**抽帧（step printing）**的运动质感
- **★★ 最容易被写成"赛博朋克"（2026-09-15 实测踩坑，必读）**：这两族都爱**夜 + 雨 + 霓虹**，**但主次正好相反**——
  **港风＝"钨丝暖做主光 + 阴影带绿黄"，霓虹只是"点"**；
  **赛博朋克＝"霓虹自发光做主光 + 暗部被招牌照出彩色（泛蓝绿）"，湿地面反射是核心。**
  **★ 三条判据**（写之前逐条自问）：① **主光是谁**——暖的灯是主光，还是招牌是主光？② **暗部的色**——**绿黄（港风）还是蓝绿（赛博）**？③ **霓虹的量级**——**一两个霓虹字（港风）还是整条街的招牌墙（赛博）**？
  **★ 反例（我实际写错的那句）**：`整体低照度、大面积暗部被招牌光照出彩色`——**这一句本身就是赛博朋克的定义**；港风该写 `暖色的灯落在皮肤上，阴影里带绿黄`。
  **★ 抽帧也容易写废**：**不能写成"动作带拖影"这种属性**（会被当装饰），**要写成动作的词法**——`抬手抬到一半停一拍、再抬到帘子上`（**动作一顿一顿地走**）。
- **提示词落点**：`暗部沉下去但不到纯黑、暗部带一点绿黄；暖色的灯落在皮肤与招牌上，霓虹只是漏进来的一点`；**"红更沉绿更暗"要分别写**（别只写"港风"）

## 三、韩系清透（低对比 + 粉白肤）

- **色相倾向**：**偏粉或微冷**，整体干净
- **色彩构成**：**提红/橙明度 + 降黄饱和**（去黄气、肤色粉白）；背景降饱和且**不杂乱**
- **明暗与对比**：**低对比 + 高明度**；高光与白色色阶**大幅压低**保细节；阴影提亮（暗部柔和）
- **场景**：时尚、人像、都市白领、清新爱情
- **★ 辨识要点**：**肤色的明度高于环境**——脸比周围亮一档，但**皮肤不是发白死白，是有粉感的**；对比极低
- **提示词落点**：`肤色比环境亮一档、偏粉白；整体低对比、暗部柔和；背景干净不杂`；**别加重颗粒**（韩系加颗粒会显脏）

## 四、新中式 / 东方复古

- **色相倾向**：**青绿或暖黄的复古调**，含蓄
- **色彩构成**：绿往青偏并降饱和（清冷如国画）；红微移橙并降饱和（沉稳）；**低饱和**
- **明暗与对比**：**柔和灰阶**、降对比与清晰度；压低高光、提亮阴影 → **哑光感**；**高光加淡黄 / 阴影加青蓝**
- **场景**：人像、器物、庭院、茶与食物、年代向
- **★ 辨识要点**：**"哑"**——画面像蒙了一层纸；**绿色是"国画绿"不是"植物绿"**
- **提示词落点**：`整体偏哑光、光线过渡很软；绿色偏青、红偏沉；阴影带青蓝、高光带淡黄；轻微颗粒与暗角`

## 五、德味 · 徕卡（低饱和 + 厚暗部）

- **色相倾向**：**偏冷偏青**（白平衡总体准确但压冷）；**亮部偏暖、暗部偏冷（蓝绿）**
- **色彩构成**：**低饱和**（浓而不艳）；**红蓝浓郁**（尤其红）；色彩过渡"油润"
- **明暗与对比**：**压低亮部、明暗过渡平和；整体亮度偏低但对比不减**；暗部厚重**且有细节**（不黑作一团）
- **场景**：纪实、街头、弱光、人文、器物
- **★ 辨识要点**：**"浓而不艳 + 暗部有细节 + 一抹淡暗角"**；**明度偏低**是它的底，**亮丽的题材配不上它**
- **提示词落点**：`整体亮度偏低、对比不减；亮部略暖、暗部偏冷且有细节；低饱和，红蓝表现浓郁；轻微暗角`

## 六、德味 · 蔡司（冷峻通透）

- **色相倾向**：**偏蓝**
- **色彩构成**：色彩还原准确、**通透**
- **明暗与对比**：**高对比 + 高锐度**；焦内极锐、焦外柔和（**"刀锐奶化"**）
- **场景**：建筑、机械、产品、冷调风光
- **★ 辨识要点**：**与徕卡正好相反**——**徕卡是"低饱和厚暗部"，蔡司是"高对比高锐度偏蓝"**
- **提示词落点**：`画面通透、锐度高、色调偏蓝；暗部干脆不发灰`

## 七、青橙商业大片

- **色相倾向**：**青蓝（环境）+ 橙（肤色）**——**互补对撞**
- **色彩构成**：环境去饱和压向青，**皮肤保留橙**
- **明暗与对比**：高对比、深阴影
- **场景**：预告片、动作片、商业广告
- **★ 辨识要点**：**⚠️ 这是本库点名警告的一族**——`color-narrative.md`：**"青橙是训练数据里最'电影感'的配色，所以模型一听到'电影感'就给你青橙"**。**用它必须有理由**（否则它就是"AI 默认审美"）
- **提示词落点**：**能不用就不用**；要用就写具体方向（`环境压向青蓝、皮肤保持橙`），**且必须与"风格槽"和"调色方向"分开说**

## 八、胶片褪色（Fade + Matte）

- **色相倾向**：不限（**结构特征 > 色相特征**）
- **色彩构成**：**整体降饱和**、颜色"灰一度"
- **明暗与对比**：**黑位抬起来（Fade / Matte）**、白位降下来 → **两端都不触底**；低对比
- **场景**：回忆、青春、年代、文艺
- **★ 辨识要点**：**看两头**——**最黑处不是黑、最亮处不是白**；这就是"被时间泡过"
- **提示词落点**：`黑位抬起来、不到纯黑；白也不是纯白；整体灰一度`（**这一族可以叠在任何色相上**）

## 九、黑白高对比（与低调黑白两种）

- **色相倾向**：无（**全部靠灰阶**）
- **色彩构成**：——
- **明暗与对比**：**两个方向**——**① 高对比（硬光、黑到底）**＝战争 / 极简 / 力量；**② 低调灰阶（暗部有层次、不纯黑）**＝文艺 / 记忆 / 忧郁
- **场景**：按上面两个方向分
- **★ 辨识要点**：**看暗部有没有层次**——**"黑到底是狠，黑里有东西是沉"**
- **提示词落点**：**写清是哪一种**：`黑白，对比高、暗部压到接近纯黑` 或 `黑白，暗部保留层次、灰阶丰富`

## 十、韦斯·安德森粉彩

- **色相倾向**：**粉彩**（薄荷绿 / 粉红 / 芥末黄）+ **一个撞色**
- **色彩构成**：中高饱和、**平涂感**；色彩承担情绪
- **明暗与对比**：**平光、几乎没有戏剧性阴影**；整体明度高
- **场景**：对称构图、室内剖面、童年、怀旧
- **★ 辨识要点**：**平光 + 粉彩 + 绝对对称**三者齐了才是它；**只有粉彩没有对称＝不是**
- **提示词落点**：`平光、没有戏剧性阴影；粉彩色（薄荷绿/粉红/芥末黄）配一个撞色`

## 十一、赛博霓虹（青品红对撞）

- **色相倾向**：**青蓝 vs 品红/洋红**
- **色彩构成**：**高饱和的自发光**（霓虹招牌）
- **明暗与对比**：**低照度 + 大面积暗部泛蓝绿**；湿地面反射
- **场景**：雨夜街区、霓虹、未来都市
- **★ 辨识要点**：**光必须"自己会亮"**（自发光源）——**给它打个柔光箱就废了**
- **提示词落点**：`青蓝与品红在湿地面反射；霓虹是自发光；蒸汽与管道遮挡前景；暗部泛蓝绿`

## 十二、阳光年代（暖黄高光 + 低对比）

- **色相倾向**：**暖黄 / 金**
- **色彩构成**：中低饱和；绿色偏黄
- **明暗与对比**：**高光大量溢出**（光斑、逆光、眩光）；中低对比
- **场景**：夏日、青春、家庭影像、乡村
- **★ 辨识要点**：**光是"烫"的**——逆光与光斑是主要语汇
- **提示词落点**：`午后金色逆光；高光大量溢出、边缘有光晕；整体中低对比`

## 十三、冷调犯罪（蓝绿低照度）

- **色相倾向**：**青绿 / 黄绿的病态偏色**
- **色彩构成**：中低饱和；肤色被压灰
- **明暗与对比**：**极低照度 + 有来源的实用光**；高对比、暗部重
- **场景**：犯罪、侦探、惊悚、夜戏
- **★ 辨识要点**：**光源必须有来源**（显示器、台灯、逃生灯）——**没有来源的蓝绿就是廉价滤镜**
- **提示词落点**：`极低照度；光只来自有来源的实用光源（显示器/台灯/逃生灯）；暗部带青绿、肤色被压灰`

## 十四、荒野土色（去饱和土黄）

- **色相倾向**：**土黄 / 赭石 / 锈红 / 灰绿**
- **色彩构成**：**去饱和**；天空过曝成浅黄而**不是饱和蓝天**
- **明暗与对比**：**高对比硬光**（烈日长影）
- **场景**：西部、荒漠、战争、废土、灾难
- **★ 辨识要点**：**天空的颜色**——**蓝天一出现，这一族就破了**
- **提示词落点**：`土黄与赭石、锈红、灰绿；天空过曝成浅黄，不是饱和蓝天；硬光、长影；去饱和`

## ★ 可复用的调色方法（四条，跨族通用）

1. **先定影调，再动颜色**——**影调错了，颜色怎么调都不像**（日系那篇拆解讲得最清楚：**"高调 + 低反差 + 暗部发灰"没先搭对，后面的青调会挂在错误的明暗关系上**）。
2. **降饱和是最通用的手段**——**"色彩不是调得越多越好，而是减得越多越高级"**；**要"浓"就靠明度压低 + 降饱和对冲**（德味的做法），**不是靠加饱和**。
3. **分离色调（Split Tone）是"胶片感"的开关**：**高光加暖、阴影加冷**——这是模拟交叉冲洗，**几乎每种"有味道"的调色都在用它**。
4. **两端不触底**：**黑位抬一点、白位收一点**（Fade / Matte）——**"被时间泡过"的统一手法**，可叠在任何色相上。

**★ 一条纪律（本库自己的判据）**：**一族只写"色相 + 明暗基调 + 一个标志结构"，不要堆三个以上的形容词。**
**并且：调色方向必须与"印片方向"同向**（→ `film-stock-matching.md`：**高调低对比的戏配 2383 会打架**）。

## ★ 量级档：**"低饱和"这三个字不算写了**（2026-09-19 补）

**旧写法的病**：只写"**低饱和，阴影推向青绿，肤色保留暖棕**"——**没有量级，等于没写**（模型自己决定推多少）。
**补量级之后的写法**（**数字进不了提示词，但"量"必须用可感的方式写出来**——见下表右列）。

| 部位 | 业界常用量级（给人看） | **提示词里怎么写**（可感、不写数字） |
|---|---|---|
| **阴影** | 饱和 **10–20%** | "阴影里有一层很淡的青，**淡到要仔细看才认得出**" |
| **高光** | 饱和 **5–15%** | "高光**只比中性暖半档**，不是金色" |
| **★ 中调** | **5–10%，或不动** | "**中调基本不动**，肤色所在的那一段保持中性" |
| **整体强度** | **常用档 50–70%**（比全强度"高级"） | "整条调子**收着走**，不是一次性拉满" |
| **上限** | **超过 30% 饱和，"滤镜感"就明显** | "**不许出现明显的滤镜味**" |

**★ 三条纪律**（按调色流程的因果，**顺序不能反**）：
1. **先把画面调成"干净无聊"的，再风格化**——**在不平衡的画面上叠 look，是"糊"的原因**；
2. **中调尽量不动**——**中调直接影响肤色**，过量会让肤色崩；
3. **对比最后加**——**对比会放大饱和度**，先加对比，前面每个决定都会错。

## ★ 三条分离手段：**不是只有"青橙"一种分离**（2026-09-19 补）

**机制**：teal & orange 之所以成立，是因为**青是人体肤色橙的补色** → **在主体与环境之间造出最大对比** → 主体在复杂场景里更突出。
**但"分离"有三条路，色相只是其中一条**：

| 分离手段 | 怎么做 | 什么时候用它替掉青橙 |
|---|---|---|
| **色相分离** | 阴影推青、高光推橙（就是青橙） | **默认，但有"俗套"成本**（它现在读作"通用好莱坞大片"） |
| **★ 明度 / 景深分离** | **逆光 + 负补光 + 控制背景曝光**，把脸从墙上"抬"起来——**不动色轮** | **多数拍得漂亮的剧情片走的是这条**；纪实与文艺首选 |
| **邻近色（analogous）** | 整条调子待在**邻近色家族**里（琥珀→品红，或绿→青），**靠明度与景深制造分离** | 要"更独特、更不像 AI"时——**更难，但更不撞** |

**★ 一句话**：**"我要分离"≠"我要青橙"。** 先问**"这一场用什么分离最省、最贴题材"**。

## ★ 两道护栏与三句必写（2026-09-19 补）

**★ 分水岭**：**专业调色与滤镜的差别就一步——"背景变青，脸不变绿"。**
→ **提示词里必须有"肤色保护句"**：`肤色保持自然暖棕，不被环境色带偏`（本库既有写法，保留）。

**★ 两道护栏（审片时用，写稿时只写"结果"）**：
1. **脸上对肤色线**（示波器）——**所有肤色，不论族裔，都落在同一条斜线上**；
2. **★ 检查白色物体**——**白衬衫变青，是最快把调色做"廉价"的方式**；写稿时可加一句 `画面里的白仍是白`。

**★ 三句必写**（把"调色方向"写全的最小集）：
```text
① 哪个亮度段偏什么色（阴影 / 高光 各一句）
② 量级（用"很淡 / 只暖半档 / 中调不动"这类可感说法）
③ 肤色保护句（+ 可选：白物句）
```
**★ 不许进提示词的**：`LUT` / `节点` / `示波器` / 色号 / 饱和度百分比 / `Rec.709`——**模型不认这些**（分流表见 `color-pipeline.md` §7）。
