# 多镜序列：一场戏拆成多镜时怎么立住

**何时读**：要拍**一场戏**（≥2 镜的连续段落），而不只是单镜时。**读完回**：`studio-workflow.md` 第三步。
单镜的构图 / 镜头规格 / 运镜骨架 → `shot-craft.md`。本条只管**镜与镜之间**。

> 一句话：**多镜的成败不在单镜拍得多好，而在"上一镜告诉下一镜的东西"够不够。**
> 模型没有跨镜记忆，它只有当前帧。

---

## 一、拆镜前先写「序列总契约」（7 项）

总时长 / 精确镜头数量 / 序列目标 / 每镜叙事功能 / 切点规则 / 跨镜必须保持的资产与连续性 / 最终落点。

- 一场戏一镜一个叙事功能；一场塞"交代+打斗+反转"必须拆场。
- 链式首帧：同机位连续内容（纸面、桌面）后一镜用前一镜尾帧做首帧，剪辑严丝合缝。
- 切点五类型要写明：硬切（第几秒切在什么事件）/ 动作匹配切（哪一帧续接）/ 视线匹配 / 声音桥（来自哪镜、空间变没变）/ 遮挡切（遮挡物与方向）。
- 时长公式：总时长 = Σ各镜可读时间 + 切点预算 + 尾部停留。超载先减镜数，不是"快速闪过"。
- 画外声触发点只在**一个镜**里出现（反应镜），前镜保持无声——声音卡位错 = 反转失效。

## 二、≥3 镜时先做两件事（多镜能不能立住的最大预测因子）

**写 Shot 1 之前**先落两张小表，不是写完再补：

1. **主体登记表**：每个角色 / 关键道具 / 场景各一行——唯一标识 + 2–3 个稳定静态特征 + 对应参考素材编号。
   之后每一镜提到它时，**指代必须一致**，不许这镜叫"她"、下镜叫"女孩"。
2. **氛围锁**：全片一套色调与光源逻辑，写成一行贴死（如"全片低饱和青绿、单一窗光从画面左后"）。
   **色彩漂移会毁掉多镜剪辑**——不要在不同色调的氛围块之间混搭。

再出片时：**先出首镜与末镜锁定外观**，中间再补——中途"换了个主体"是情感类短片最常见的失败。

**★ 排镜顺序两条补充**：

- **Shot 1 默认取 wide establishing shot**（冷开场 / 延迟建立等例外须在总契约写明意图）——一张能把**全部人物与关键陈设**框进去的远景。
  不给 wide 做锚，之后硬切到近景就会把人物搬个位置。
- **结局倒着排**：先锁住**中间**的对话 / 对峙镜（它决定主体停在哪里、背景里有什么），再做 arrival，再做 exit。
  **"能开得走"才批准这个停法**——别把车停进两车之间。

## 三、★ 凡是几何问题，一律用图，不用文字

**判据**：

> 问自己：这句话是在描述**"长什么样"**，还是在描述**"在哪、多大、朝哪、谁挡谁"**？
> 后者一律不要用文字硬写，**画一张带标注的示意图**。

**症状**：同一个物件在每条 take 里大小和位置都不一样（人偶这条巨大、下条极小、每次跳到街面不同位置）。
这不是措辞问题——**文字解决不了空间问题**。

**做法**：

1. 在图像模型里画一张**示意图**——标出固定参照物（消防栓、门口、桌子），把主体**钉在它的一侧**、
   写明**相对人高几倍**、说明**是否在同一条线上**；
2. 再把这张图交给模型，让它**围绕地图重写提示词**；
3. 主角再用一个**物理锚点**钉住（"钉在左侧那棵树下"）。

| 几何问题 | 图的形式 |
|---|---|
| 主体在哪、多大、朝哪 | **带标注俯视图**（画格子 + 参照物 + 箭头） |
| 谁挡住谁 | 俯视图上标**视线与遮挡关系** |
| 运镜的起止位置 | 俯视图上标**摄影机起点→终点弧线** |
| 动作的路径 | 侧视图标**轨迹与接触点** |
| 光线方向 | 俯视图标**光源方位 + 人物朝向** |

**为什么图比字强**：文字描述空间时，模型要**先把文字解码成三维再摆位置**，每一步都在丢信息；
给图等于**直接给它坐标**。

**可以跨镜原样复用**——第 5 场直接把第 3 场那张**原封不动**贴回来当空间锚，
只需说明"这次他站在参照物右侧"。**一张地图跳过抽奖**（暴力抽 20 次捞几秒，烧预算而且几何还是松的）。

**纪律**：示意图**不进交付物**（属内部工作稿），但**可以跨镜、跨集复用**——是资产的一部分。

> **与 `storyboard-frame.md` 的边界**：黑白故事板是**灰度**、只锁结构与明暗、**明确禁止当图生视频首帧**；
> 布局地图是**另一张图**（可彩色、可带标注、只用于表达几何）。两者混用会踩单色锁死的坑。

## 四、★ 情绪连续性（第四层连续性）

连续性除了色调、光源、资产之外，还有**第四层：角色的情绪与生理状态**。

必须在提示词里**显式写出"他从上一场带过来的状态"**：`仍然红着眼、声音还在抖、没有笑`。

**关键结论**：**技术参数与情绪状态是两个独立的旋钮。**
情绪不对时，改的是**状态描述**，**完全不需要动运镜与光位参数**。

> 实测案例：只加了一句"他刚才哭过"，甩镜的参数一个字没改，表演就对了。

## 五、★ 一次生成里写死镜数与切数 → 见 `segmented-shot.md`

**分段镜（一条生成里装多个景别 / 机位）的完整方法**——判路、段落语法、镜数档位、
锚点逐字复述、转场词库、首帧策略、失败模式——**全部移到 `references/segmented-shot.md`**（一处定义，本文不复述）。

两条纪律留在这里（属于"多镜序列"层，与生成机制无关）：

- **写死镜数与切数**。对按顺序拼接的 N 个连续镜头单元，内部剪辑切点为 N−1。连续推拉或变焦保持同一镜头单元，段落式多画面的段间与段内切点按 `segmented-shot.md` §七分别统计。
- **时长分配（规划层）**：前几镜短促，**最后一镜最长，约占总时长一半，从容不迫**——**这是排镜表上的分配，不写进提示词**。

### 动作戏的"每镜一个信息职能"

打斗或大规模动作场，**每个机位必须提供不同的信息**，不能只是换个角度拍同一件事：

| 机位 | 提供的唯一信息 |
|---|---|
| 50mm 环绕 | 地理关系与被包围 |
| 24mm 低角度 | 质量与规模 |
| 85mm 特写 | 精度与反应 |
| 35mm 广角 | 波及范围 |

**静音自检**：把动作名词全部盖住，**只读机位计划**——如果每个机位提供的信息一样，
那只是"一个游戏视角切成几个装饰镜头"。

## 六、★ 按 beat 切生成单元

**问题**：一场戏整段扔给模型一次生成，中段一定会漂（模型记得住开头，记不住 8 秒后的方向）。

**做法**：切成**若干生成单元**，每个单元**不超过平台单次上限**，
且**单元结尾留一个"接口帧"**——一个**明确的、可被下一单元当作起始参考的画面状态**。

```
Beat 1 [生成] → 尾帧（接口帧）→ Beat 2 [以上一单元尾帧为起点] → …
```

**三条纪律**：

1. **切点切在"动作完成、情绪未落"处**——不要在动作中途切（观众会看出接缝）；也不要等情绪完全落地（会显得断）。
2. **接口帧必须是"能被描述的状态"**——位置明确、朝向明确、手上有明确东西。飘着的状态传不下去。
3. **接口帧同时是传递链的一环**——优先级是**实际生成的尾帧 > 静态图 > 文字**（与 `asset-consistency.md` 四·补一致）。

## 七、★ 一镜之内只允许一个速度例外

**速度例外** ＝ 这一镜里与"常规节奏"不同的那一下：突然的加速、一下子的急停、瞬间的升格。

**纪律**：**一镜只准一个。** 两个例外凑在一起 → 观众来不及读，反而"什么都没记住"。

| 例子 | 判断 |
|---|---|
| 平稳推轨 → 撞上瞬间切黑 | ✅ 一个例外（撞） |
| 平稳推轨 → 突然加速 → 撞上 → 升格 → 摇开 | ❌ 四个例外，全糊 |

**例外必须"被一个明确事件触发"**（撞击、出现、关门），不能平白无故变速——**无动机的变速看起来像卡顿**。

## 八、★ 景别体系与节奏分配（2026-09-13 补 · 治"中近景一家独大"）

### 8.1 九级景别（每级提供不同的信息）

| 景别 | 框到哪 | 提供的唯一信息 |
|---|---|---|
| 大远景 ELS | 人极小，环境是主体 | 地理、距离、孤独 |
| 远景 LS | 全身 + 大量环境 | 人在环境里的位置与体量 |
| 全景 FS | 全身，头顶脚底留边 | 身体姿态与站位 |
| 中景 MS | 腰部以上 | 上半身动作与手部关系 |
| 中近景 MCU | 胸口以上 | 表情 + 上身张力 |
| 近景 CU | 肩以上（脸） | 情绪 |
| 特写 | 一个身体局部充满画面（**脸 / 手 / 后颈都可**） | 一个生理细节 |
| 大特写 ECU | 眼 / 嘴 / 指节 / 扣 | **一个不可再分的生理事实** |
| 插入 / 细节 Insert | 与人无关的局部或物件 | 一个物理证据 |

**静音自检**：把景别盖住，只看"这镜提供了什么新信息"——**相邻两镜若信息一样，那只是"换个角度拍同一件事"**。

### 8.1b ★★★ 判据：景别由「画框装了什么」决定，**不由「这件事多重要」决定**（2026-09-14 补 · 实测误标后立）

**为什么单列**：8.1 只给了定义，**没给"怎么判自己写对没写对"**。
于是会犯一类错——**把"落点动作"当成"景别"**：写「收在中近景——**手停在枪套上，没有拔**」，
读起来像"画面只剩手"，**人和模型都会往特写想**。

**★ 一句话判据**：**把画框想象成剪刀——剪下去之后，框里还剩几张脸、几个物件？**
**"发生了什么"不改变景别；"框住了什么"才改变景别。**

| 画框里有什么 | 景别 | 谁在说话 |
|---|---|---|
| 手 + 枪套 + 一小段皮带（**脸出画**） | **特写 CU** | **手比人诚实**——生理层 |
| 手 + 枪套 **+ 帽檐 + 下半张脸 + 肩** | **中近景 MCU** | **他在忍**——克制层 |

**同一件动作（"手停在枪套上"）在两个景别里是两个意思**：
特写拍得到"手停下了"，**拍不到"他选择停下"**。**落点动作再重要，也不能反过来决定景别。**

**写作纪律（两条）**：
1. **景别行里必须点名画框边界**（"画面下缘收进枪套的下半截"／"帽檐横切过面部上三分之一"），
   **不要只写动作**——只写动作就等于把景别交给模型猜。
2. **收尾句把"画框内容"与"动作"分开写**：❌「收在中近景——手停在枪套上」
   ✅「收在中近景偏近——**画框里仍装着他的帽檐、下半张脸、肩膀和枪套下沿**，他的手停在枪套上，没有拔」。

**换景别的三条正当理由**（都不含"这件事很重要"）：
**① 信息密度变了**（脸不再提供新信息）· **② 距离关系变了**（人走远／尘遮）· **③ 叙事职能变了**（从"他在忍"变成"手在犹疑"）。


### 8.2 ★★ 占比硬线（任一条破了就是"单调"）

1. **单一景别不超过 35%**
2. **中景 + 中近景合计不超过 40%**
3. **停滞检测＝抓两种形态**：① **同级连切**；② **来回摆动**（a→b→c 中 a==c 且 b≠a，例：中景↔中近景↔中景）。**豁免：只查 ≥1.5 秒的镜头**（快段 0.5–0.8s 在 ECU/Insert 间交替是快切语法，速度本身已提供变化）。（**旧口径「相邻两镜景别跨度 ≥2 级」已由 `scripts/shotlist_lint.py` 实测推翻**——它会误报合法的单向渐进：大远景→远景→全景＝建立/收紧。）

| 片种 | 极远 | 中间 | 极近 |
|---|---|---|---|
| **西部 / 史诗 / 对峙** | **30–40%** | 30–40% | **20–35%** |
| 剧情 / 对话 | 10–15% | **50–60%** | 25–35% |
| 悬疑 / 惊悚 | 15–25% | 35–45% | **35–45%** |
| 动作 / 追逐 | 20–30% | 30–40% | **30–40%** |

> **单调的反面不是"快"，是"没有对比"。** 极远与极近的**跳变幅度**提供冲击——**不需要靠推拉摇移，也就绕开了 AI 最不稳的部分**。B07 西部片的原文即"**极限的远—近剪接**"。

### 8.3 ★★★ 时间尺度澄清：生成时长 ≠ 成片镜头长度（**这是本节最重要的一条**）

**一个反复出现的冲突**：库规（`shot-orchestration.md` §七）说"**AI 动作场单镜守 2–3 秒，压时长只会崩**"；
但快节奏段落观感上需要 **0.5–2 秒**的短镜。**这两条不冲突，说的是两件事**：

| | 该守多长 | 为什么 |
|---|---|---|
| **生成单元**（一次投喂） | 动作有效窗口 **2–3s**（投喂取 4s 档，余量供剪辑） | 单镜越短，模型定型与展开表演的时间越少 → 崩 |
| **成片镜头长度**（剪辑后） | 快段 **0.5–2 秒** | 这是**后期剪辑**的事，模型不参与 |

**关键事实**：**平台单次生成有下限**（Seedance 2.0 = `[4,15]`、2.5 = `[4,30]`、1.5 Pro = `[4,12]`）——**你无法"生成"一个 0.5 秒的镜头**。
所以快切只能靠：**生成 4 秒 → 剪辑时只取其中 0.5–1.5 秒**。

> **★★★ 每段时长下限（2026-09-14 实测翻车后补 —— 与"按段落写"配套的必算项）**
> **不写秒数 ≠ 不用算秒数。** 段落语法解决了"模型不知道这段演到哪"，**但没解决"每段摊到几秒"**。
> **动笔前必算：`每段秒数 = 总时长 ÷ 段数`。**
> - **< 2 秒 → ⛔ 不生成**（一段里塞不下一个完整动作弧）→ 减段数 / 加总时长 / 拆多次生成
> - **< 4 秒 → ⚠️ 只能放"停住 / 看一眼 / 一个微动"这类零动作段**（段＝分段镜段均；单条生成投喂仍守平台 4s 下限）
>
> **实测症状**：**5 秒写 5 镜 → 每镜 1 秒 → 整条看不懂，每镜都糊。**
> **模型收到 5 个"各自完成一段叙事"的镜、每镜只给 1 秒 → 每镜只演半口气，接起来就是五段糊片。**
> **这不是提示词不详细，是每镜的预算根本不够**——**加内容只会更烂，唯一修法是减镜数**。
> 档位表（已按 2 秒下限重算）→ `segmented-shot.md` §四。

**快段落地三件事**
1. **取 `t = 0.3–1.3 秒`，不要取中段** —— 库规：连贯性在约 2 秒后开始衰减，中段反而最容易漂；
   而"起手不成型"用**提示词**解决：写 `第一秒就是这个状态，之后保持不变`。
2. **插入镜当成"一张会轻微呼吸的照片"写，不是一段动作** —— 切断它不但不崩，而且正是要的效果。
3. **素材按 3× 备**（可用率 30–40%）；**快段镜数要克制**（约 7 镜已是上限——经验值，换模型需复测，再多该改结构而不是加镜头）。

**为什么快切仍然正当**：`direction-reasoning.md` 第 7 问——**快切不是风格，是叙事信息密度高时的必然结果**。
**快段的每一镜仍然只给一个信息**（§五 一镜一信息职能）；**快，是因为每秒塞了更多"新东西"，不是每镜塞了更多东西**。
→ **"库规防每镜塞太多"与"你要每秒给更多"必须同时遵守，两者互补而不是矛盾。**

### 8.4 ★ 叙事职能（**与景别正交**：同一景别可以是建立，也可以是反应）

**为什么单列一层**：景别管"**框多大**"，职能管"**为叙事干了什么**"。
两镜可以景别不同、职能相同——那仍是停滞（`shotlist_lint.py` 会抓"职能重复"）。
**排镜表最难填也最值钱的，是「这一镜的唯一信息」那一列；职能是它的上一层抽象。**

| 职能 | 它干什么 | 常见景别 | 填不出来的后果 |
|---|---|---|---|
| **建立** | 给地理 / 时间 / 人物关系，让观众知道"在哪、谁在" | 大远景 / 远景 / 全景 | 观众失去空间感，后面再紧也没用 |
| **推进** | 收紧、加速、加压（把观众往里带） | 中景 / 中近景 | 节奏起不来 |
| **揭示** | 给出此前不知道的信息（物件 / 细节 / 意图） | 特写 / 大特写 / 插入 | 叙事没有新信息，观众开始走神 |
| **反应** | 人物的反应：看 / 听 / 身体变化 / **不动** | 近景 / 特写 / 大特写 | 事件没有落点，变成"发生了但没人在乎" |
| **过渡** | 掩接缝、补时间、转场（跳切 / 插入） | 插入 / 环境 | 接缝会露 |
| **峰值** | 这一场的最高点 | 大特写 / 插入（**具体看内容**） | 必须有且**只有一个** |
| **收束** | 落点、余韵、离场 | 大远景 / 大特写 | 必须在**最后一镜** |

**三条硬规则**（`shotlist_lint.py` 会查）：
1. **相邻两镜职能不得重复** —— 景别换了但干的事一样，仍是停滞
2. **峰值唯一** —— 一场戏只该有一个最高点（纯过渡场豁免，仍守职能不重复）
3. **收束必须是最后一镜** —— 出现在中间说明后面还有东西没收

**★ 第四条：单镜不得过载**（`shotlist_lint.py` **检查 0c**）——**排镜表看不出的病**。
排镜表只能看到"镜2 = 中近景 / 5 秒 / 推进"，**看不出这一镜里塞了几件事**；
但**提示词的【时间线】里若出现切镜词**（`准备 / 接触 / 落定 / 触发`），
那就是**一镜里塞了整条动作弧**的铁证——**这些是段落与段落之间的词，写进单镜模型会读成"这里有好几个镜头"**。**单镜（非分段镜）的时间线只保留 `起始 / 主动作 / 反应与呼吸 / 定格` 四相**，这四个不是切镜词。
**改法：先过「拆镜开关」（→ `shot-craft.md` 的 ★★★ 节）**——**分镜版（＝单机位镜）能拆就拆**（拆出的新镜头＝**另一次独立生成**：通用 3 块照抄、专属 9 块重写，不许只改时间线）；
**只有在这一段本身就是一次生成、拆不了时**（＝**段落版（＝分段镜）**），才用**段内推进**的写法：**镜内推进写「他先…；随后…；最后…」**（→ `segmented-shot.md` §三）。
（工具另查：单镜 >8 秒时提醒"先考虑拆镜"，长镜本身不是罪，长镜里塞整条弧才是。）

**排镜表列建议**：`镜号 | 景别 | 机位与运动 | 时长 | 叙事职能 | 这一镜的唯一信息 | 声音/对白 | 转场 | 节奏说明`

> **★ 秒数只活在排镜表，不活在提示词（2026-09-14 口径改动）**
> **排镜表的「时长」列是规划用的**（节奏数学要靠它：景别占比 / 停滞检测 / 快切门禁）。
> **写进提示词的那一层不写秒数**——**按「段落 / 组合」写（段落A / 段落B / 段落C），⛔不写「镜几」，时间由模型自己分配**；
> 只有**首行的总时长**保留（那是平台硬约束）。**同一份秒数，规划时用、投喂时删。**
