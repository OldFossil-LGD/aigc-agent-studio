# 声音后期：**流程 · 中间产物 · 交付**（本库此前完全空白的一层）

> **何时读**：要真正做完一条片子的声音（不只是写提示词）、要安排声音的工作顺序、要给剪辑/混音交东西时。
> **读完回哪**：写词回 `sound-lexicon.md` · 写提示词回 `sound-prompt-craft.md` · 怎么做声回 `sound-design-craft.md` · 多大回 `mix-loudness.md`。
> **★ 为什么要有这一册**：前面几册解决"**怎么写、怎么做**"，本册解决"**按什么顺序做、每一步交出什么、什么绝对不能跳过**"——
> **这是"业余"与"成熟"之间真正的差别**。**站内语料在这一层是空的**（spotting / A-B-C 优先级 / 拟音工艺 / 后期阶段链 / 混响参数 全为 0 命中），故本册全部来自**专业影视声音**资料。

## §1 ★ 第一前提：**画面没锁定，声音不开工**

**画面锁定（picture lock）**＝时间、结构、内容都不再改。
**为什么是硬前提**：**所有工作都按帧位校准**——ADR 的切点、音效的落点、音乐的对位。
**开工后改画面 = 全部受影响轨道都要重剪。**

**★ 两条纪律**：
- **不接受没有签核锁定的 AAF/OMF**；
- **锁定要书面确认**（口头不算）。

**★ 验收交接物时跑一张清单**（缺失媒体是常见坑）：媒体是否齐全 → 时间码是否对得上 → 帧率是否一致 → 音频采样率是否 48 kHz → 有无离线文件。

## §2 ★ Spotting：**正式开工前的"点戏"**

**Spotting（点戏）**＝**对着锁定画面看一遍，把声音工作在图上标出来**。参与：声音总监 + 导演（+ 剪辑师 / 作曲）。
**★ Spotting for sound 要定六件事**（这是它的完整定义，照着问）：

| # | 问什么 | 产出 |
|---|---|---|
| 1 | **哪里有对白问题**？能不能清理，还是需要 **ADR**？要 ADR 的话——**哪个演员、多长、什么时候排队** | **ADR 清单** |
| 2 | **哪里有硬效/具象音效需求**，需要什么样的 | **硬效清单**（设计声统一归第 4 问，不在此重复建清单） |
| 3 | **哪里需要拟音**，需要什么 | **拟音 cue 表** |
| 4 | **是否需要"设计声"**（为这条片专门创造的声音） | 设计声清单 |
| 5 | **（for music）配乐放哪、源音乐放哪、电平该在哪一档** | 音乐对位表 |
| 6 | **★ 目标受众与规格是谁**——影院 / TV / 流媒体 / 广播 / 广告 | **交付规格**：立体声 / 5.1 / 全景声、响度目标、要不要 M&E |

> **★ 第 6 条最容易被忽略、后果最贵**：**每个渠道有自己的交付规格**——
> **规格没定就开始混，等于不知道自己在往哪儿混**（`mix-loudness.md` §1 的表就是为这一条服务的）。

## §3 ★ 九阶段链（含每一步的"交出什么"）

**中文专业团队版（九步）与英文版工作流表是同一件事的两种切法**，下面合并：

> **AI 生成流程注记（2026-09-30 补）**：AI 短片的声音**不走九阶段实拍工艺**——环境底噪与动作音效由平台音频节点直出（按「连续层 1 条 ＋ 点状事件层 1 条」分条），在合成阶段统一混入（→ `libtv-ignite-ops-fields.md` §3.2/§3.3）；本册九阶段适用于实拍或"实拍＋AI"混合工作流的后期。

| 阶段 | 谁做 | 交出什么 |
|---|---|---|
| **① 素材交接与首次看片** | 剪辑师 → 声音团队（AAF/OMF + QuickTime） | 口头/书面的创作方向；**先花时间把 AAF 里的杂音整理一遍**（剪辑时间线来的素材通常很脏） |
| **② 制定工作计划** | 后期声音制片 + 声音指导 | **后期声音制作时间计划单**（给制片与导演的行动指南） |
| **③ 声音剪辑/编辑** | 声音编辑（按**对白/环境/音效/拟音/音乐**分类） | 各类编辑成果；**每阶段成果都要经声音指导检查** |
| **④ 第二次声音预览** | 导演 + 制片 + 声音指导 | **导演的具体意见**（此时用立体声或以其为核心的 5.1/全景声 Bed 听） |
| **⑤ 补充素材** | 录音/拟音/ADR 组 | **ADR**（同期难修复的对白 / 旁白 / 送审改词）· **音效**（**大部分自己录，不是从库拿**）· **拟音** · **环境声重录** |
| **⑥ 环绕声/全景声工程分配** | 声音编辑 | 多声道工程（预算允许时优先全景声） |
| **⑦ 制定整体声音设计方案** | 声音指导 | **全片声音的大方向与调性 + 具体场景的处理策略 + 关键段落的编排 + 用声音讲的东西** |
| **⑧ 预混** | 预混师 + 导演 + 声音指导 | **分类预混**（对白/环境/音效拟音/音乐 各自内部先平衡）→ **分类配对** |
| **⑨ 终混** | 终混师 + 导演 | **最终母版** + **stems** + **M&E** |

**★ 英文版的关键差别（值得记）**：它把 **Spotting → Dialogue Edit → ADR → SFX Edit → Foley → Music Edit → Pre-Mix → Final Mix**。
其中 **Dialogue Edit 的产出被明确写成两样：干净的对话轨 + ADR 清单**——
**"对白编到哪里需要重录"是剪辑阶段的产物，不是录音阶段的话题。**

## §4 ★★ 声音表（spotting sheet / cue sheet）：**本册要你带走的那张表**

**这是整条流程的中间产物**——把"点子"变成"可执行清单"。**没有它就开始放音效＝按假设设计，不是按确认的意图设计**（这是官方错误表里的一条）。

**字段固定（一次一行，按时间码排）**：

```text
| 时间码 | 类别 | 具体声音 | 挂在哪 | 强度/情绪 | 备注 | 优先级 |
|---|---|---|---|---|---|---|
```

| 字段 | 写什么 | 例 |
|---|---|---|
| **时间码** | 起止 | `00:01:15–00:01:16` |
| **类别** | 对白 / 环境 / 硬效 / 拟音 / 设计声 / 音乐 | 拟音 |
| **具体声音** | **动作 + 表面/材质**（不许写"脚步声"三个字） | 皮鞋跟落在木地板 |
| **挂在哪** | **哪个人物 / 哪件物件** | 主角左脚，第二步 |
| **强度 / 情绪** | 重而怒？轻而玩？轻关还是摔门？ | 疲惫，脚跟先落 |
| **备注** | 特定细节 | 门铰链有一声吱呀；关门前有一次重呼吸 |
| **★ 优先级** | **A / B / C**（A＝非做不可；B＝很值得；C＝有预算再说） | A |

**★ 优先级为什么必须有**：**它让"做不完"变成"有取舍"**——
没有 A/B/C，交付末期会在"某个 C 级音效"和"对白的最后一轮打磨"之间随机分时间。

**★ 用法**：**先按类别统计行数**（这个数决定工期），**再看 A 级有多少**（这个数决定能不能按期）。

## §5 ★ 六步实操（个人 / 小团队版，**顺序不可换**）

### Step 1 · 建模板（**建一次，反复用**）

**母版轨道结构**（命名 + 色标）：
```text
Dialogue   Boom A/B · Lav A/B · Group · ADR
Foley      Footsteps · Props · Cloth
Backgrounds Atmos A/B
SFX        Hard · Cut · Design
Music      Score · Source
Aux 返回    Reverb Short · Reverb Long · Delay
```
**采样率跟随摄影机（几乎都是 48 kHz）· 至少 24-bit。**（AI 生成音频不经摄影机、无"跟随"对象——导入合成前仍按 §1 交接清单的 48 kHz 口径人工核一遍。）
**★ 为什么先建模板**：**每一部片重搭一次 = 把同一份时间浪费 N 次**，而且**命名方式不一致会让后面每一步都变慢**。

### Step 2 · 对白剪辑（**永远第一步**）

> **"对白是混音的主干——其他一切都围着它建。"**

要做的五件：**一致性剪辑**（挑最能用的那一条）· **每一刀都交叉淡化** · **每个空隙用 room tone 填** · **宽带 + 频谱降噪** · **刺耳处去齿音**。

### Step 3 · 音效与设计声（**逐场走，且顺序固定**）

```text
① 先放**硬效**  —— 每扇门、每个拟音不覆盖的脚步、每声枪响、每辆车
② 再放**设计声**—— whoosh / riser / 这条片专属的签名声
③ 最后铺**氛围**—— 铺在以上一切**下面**
```
**★ 顺序错了会怎样**：先铺氛围再放硬效，氛围会被硬效压着改，来回返工。

### Step 4 · 拟音（**对着画面在硬表面上表演**）

**脚步优先，布与道具次之。**
**"哪怕只过一遍拟音，人物身体的可信度都会完全不一样。"**（工艺细节见 `sound-design-craft.md` §7）

### Step 5 · 音乐剪辑

铺配乐 → **把提示点对到画面上**（音乐编辑的全部工作就是让作曲的小节落在对的击点上）→ 铺源音乐。
**★ 一条硬纪律**：**对白要与配乐对位检查——人声线永远不许撞旋律峰值。**

### Step 6 · 预混 → 终混

**顺序：先组内平衡（对白对对白、音效对音效），再组间平衡。**
**★ 先做组内**，是因为**组间不平衡往往只是组内不平衡的伪装**。

## §6 ★ 交付包：**stems 与 M&E**

| 件 | 是什么 | 为什么必须有 |
|---|---|---|
| **母版** | 最终复合声轨（立体声 / 5.1 / 7.1 / 全景声） | 正片用 |
| **stems** | 按元素分的子混音：**对白 DX · 音乐 MX · 音效 EFX**（实务上常再分 拟音 / 环境 / 设计声） | **让终混师能按组调整而不动单轨**；**也是 M&E 的来源** |
| **★ M&E** | **Music and Effects ——去掉对白的版本** | **国外配音版能干净剪入**；**这是所有发行公司的要求** |

**★ 两条实务提醒**：
1. **不是想需要，是"必须"**：**"光 M&E 这一项交付要求，就足以证明建 stems 的时间是值得的"**；
2. **M&E 要"全填充"**：**与同期对白轨绑在一起的音效与拟音，会随对白一起被去掉**——
   **要给国外版做高质量 M&E，这些必须替换**（这就是为什么流程里第⑤步要"自己录大部分音效"）。

## §7 ★★ 按阶段的常见错误表（**照抄级预防**）

| 阶段 | 常见错误 | 预防 |
|---|---|---|
| **交接** | **画面锁定前就开工** | **书面确认锁定；没有签核的 AAF 一律不收** |
| **交接** | 收了有**缺失媒体**的工程 | 跑 §1 的五点验收清单 |
| **对白剪辑** | **跳过 room tone 采集** | 向同期录音师索取；拿不到就**从生产音轨的空隙重建** |
| **ADR** | **动不动就排 ADR**，而不是先降噪 | **逐句按"可懂度"判断；先穷尽频谱修复与去混响类工具（如 iZotope RX）** |
| **声音设计** | **没有 spotting 笔记就放音效** | **先与导演点戏**——按确认的意图设计，不是按假设 |
| **预混** | **跳过 stems 直奔终混** | **永远建 stems**（光 M&E 就值这个时间） |
| **终混** | **增益结构差 → 输出削顶** | **轨 → 总线 → 主，全程一致的增益结构；每个阶段都看表** |
| **母版** | **把"真峰值合规"当成"响度合规"** | **一个文件可以过了真峰值限制、仍然不合响度规格**；用**专用响度分析器** |
| **交付** | **不做 QC 就交** | **QC 是强制的**：一次通听 + 响度表检查，**比重新交付省时间** |

**★ 一句话总纲**：**"后期声音里最贵的错误，几乎都能追溯到上游抄的近路——锁定前开工、跳过文件验收、忽略 room tone、终混前不建 stems。这些近路会一路往下传，最后花的时间永远比省的多。"**

## §8 ★ 现场同期（**现场不做，后期要花十倍**）

> **AI 生成流程注记**：AI 工作流没有现场同期——room tone 与垫底噪改用素材库或生成垫（见 `sound-design-craft.md` §8）；本节适用于实拍或"实拍+AI"混合工作流。

**同期录音师的三个任务**：**捕获干净对白 · 捕获野生音轨（wild tracks）· 为每个场景捕获 room tone**。
**★ 一条不可妥协的规则**：
> **每个场地至少录 30 秒 room tone，且剧组成员完全静止。**
> **"room tone 在现场是免费的，事后伪造非常贵。"**

**为什么**：**编辑用它填对白轨里的每一个空隙**——**没有它，每一刀都会"啪"一下露出来**（音频版的跳切）。

## §10 ★ 声音成熟度自查（**"业余 vs 成熟"的十条分界**）

- [ ] **画面对齐前不开工**（且有书面锁定）
- [ ] **spotting 做过**，六问都有答案，**交付规格已定**
- [ ] **对白先做**，且它是混音的主干
- [ ] **room tone 填满了所有空隙**（现场至少 30 秒/场地）
- [ ] **音效顺序**：硬效 → 设计声 → 氛围（氛围在底下）
- [ ] **拟音过了一遍**，脚步优先
- [ ] **对白与配乐做过对位检查**（人声不撞旋律峰值）
- [ ] **先组内平衡、再组间平衡**
- [ ] **建了 stems**，并输出了 **M&E**
- [ ] **交付前做了 QC**：通听 + 响度表 + 真峰值

**★ 判据一句话**：**这十条里做到 ≤5 条，说明问题不在"审美"，在"流程"。**
