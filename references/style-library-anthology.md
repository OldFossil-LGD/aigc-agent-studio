# 风格库 · G 卷：选集与混合媒介（G01–G15）

> **何时读**：`style-library.md` 选取流程落到「混合媒介 / 多风格 / 选集」这一路时；或用户说"要一部片里好几种风格""动画和实拍混着来""像那种一集一个画风的合集"时。
> **读完回哪**：回 `style-library.md` 定案，再按每条自带的**「量级」**行去对应文件。

> **本卷与 A–F 六卷的性质不同**：前六卷讲"**一种风格长什么样**"，本卷讲"**多种媒介怎么共存于一部片**"。
> 因此每条多一个字段——**「量级」**。混合媒介必须先说清**哪一层是拍的、哪一层是画的、哪一层是造的**；说不清，模型会把三层糊成一锅。
> 方法论来源：**多风格选集作品**（每段各有一套量级的合集形态）与**混合媒介动画**（2D 角色进 3D 环境、实拍叠手绘）。

---

### G01 · 选集式多风格（一段一个世界）
**识别**：一部片里，每一段各是一个世界。
- **核心视觉**：段落之间**量级整段更换**——上一段是照片写实、下一段是平涂描边、再下一段是工艺渲染；换段处有一个明显的转场标记
- **色彩光影**：**每段自成体系**（各段的调色与光照逻辑互不相通），但**段内绝对自洽**
- **构图材质**：段与段之间**画幅、画法、质感动词全部更换**；全片唯一的统一元素通常是**同一个主题，或同一条旁白**
- **参考作品**：多导演合集的动画选集（《爱，死亡和机器人》式的单元结构）、以"单元"组织的剧集
- **适用场景**：短篇合集、主题式作品、单元剧
- **叙事氛围**：每一次更换都像"翻页"；适合"用一个主题做多种讲述"
- **量级**：**多系并存**（每段各自选定）——必须过 `stylized-look.md` 第二节·补2 的**跨风格准入四条件**，做不到就回到一套量级
- **可写句式**：`【第 1 段 · 照片写实】用[方案包]拍摄……【第 2 段 · 平涂描边】整段切为手绘黑描边与两三级平涂色块、非照片写实……两段的画法完全不同，但都在讲同一个主题：[主题]；每一段风格不同、但共享一套镜头语法，段落之间有明确的换画风标记`
- **★ 质感与痕迹**：`每一段风格不同、但共享一套镜头语法` · `段落之间有明确的换画风标记` · `不同段落的人物保持同一身份锚`
- **★ 最容易被写歪成什么**：`几种画风糊在同一画格里` · `风格只在配色上变`

### G02 · 2D 角色 + 3D 环境（混合媒介）
**识别**：人在纸上，世界在三维里。
- **核心视觉**：**角色是手绘的**（线条有粗细变化、身体被压平），**环境是三维的**（真实透视、光与体积雾）；两者之间有一层看得见的"贴上去"的关系
- **色彩光影**：角色用**平涂与硬边阴影**，环境用**真实的衰减与体积光**；两组必须在同一个光源方向下
- **构图材质**：因为环境是立体的，**可以做真正的运镜**（推轨、环绕），拍出平面动画做不到的调度；角色边缘有淡淡的合成边缘
- **参考作品**：把 2D 角色放进三维场景的动画短片（近年多部选集作品的核心工艺）
- **适用场景**：奇幻、冒险、需要"贴地"的世界观
- **叙事氛围**：手绘的温情加立体的空间；适合"一个人在一个真实的世界里"
- **量级**：**混合**——角色的量级句照 `stylized-look.md`，环境的量级句照写实族；**两句都要写，并各加一句"各自保持体系"**
- **可写句式**：`2D 角色 + 3D 环境：角色是手绘的、有粗细变化的黑描边与两三级平涂色块、身体被压平；他所在的环境是三维渲染的、有真实的透视与体积雾；两者处在同一个光源方向下；摄影机可以做环绕与推轨；角色是平涂描边的 2D、环境是写实 3D，两层的光向必须一致`
- **★ 质感与痕迹**：`角色是平涂描边的 2D、环境是写实 3D` · `两层的光向必须一致` · `角色不产生写实的投影`
- **★ 最容易被写歪成什么**：`把角色也做写实` · `环境也平涂` · `两层的光不一致`

### G03 · 实拍 + 手绘叠加
**识别**：真实的人身上画着线。
- **核心视觉**：**实拍打底**，上面覆一层**手绘的线、色块或涂鸦**（轮廓线、速度线、记号、遮盖色块）；手绘**不完全对齐**实拍，有一点偏移才活
- **色彩光影**：实拍保留真实的曝光与景深，手绘层是**不透明的纯色**（黑线、荧光色、白块）
- **构图材质**：手绘层承担**强调与情绪**（心跳、痛、记忆），实拍层承担**事件的真实**；两层同时可见
- **参考作品**：在实拍上叠加动画的纪录片与音乐影像做法
- **适用场景**：心理状态、记忆、创伤、混合叙事
- **叙事氛围**：主观与客观叠在一起；适合"外在发生了什么 / 内在发生了什么"
- **量级**：**混合**——实拍层照 `camera-package-library.md` 选包；手绘层单独写一句"线条与色块为纯色手绘、不做真实光照"
- **可写句式**：`实拍打底（用[方案包]拍摄），画面上叠加一层手绘的线——[角色]的轮廓被黑线描过、呼吸的位置有手绘的记号；手绘层与实拍不完全对齐、有一点偏移；手绘只用纯色、不做光照`
- **★ 质感与痕迹**：`手绘元素贴在实拍上、边缘看得见` · `手绘的颜色比实拍更饱和` · `手绘会遮住画面的一部分`
- **★ 最容易被写歪成什么**：`把手绘融进实拍` · `全片都是手绘` · `无缝合成`

### G04 · 漫画分格与动效
**识别**：画面被切成格子，格子里的东西在动。
- **核心视觉**：**漫画分格结构**——粗细不一的格框、跨格的人物、格与格之间的间隙；格内的运动用**速度线、拟声词、重复的动作残影**表示
- **色彩光影**：**平涂加网点**；格与格可以各自是黑白或彩色
- **构图材质**：**排版本身就是画面语言**（格的大小等于节奏、整页一格等于高潮）；网点与印刷套印的偏移
- **参考作品**：把漫画分格直接做成动效的影像作品
- **适用场景**：动作、爆点、回忆、元叙事（角色知道自己在一本漫画里）
- **叙事氛围**：强调、节奏被打断、纸上世界的暴力
- **量级**：**描边系**（另加"排版层"）——格框与网点照 `stylized-look.md` 写
- **可写句式**：`漫画分格动效：画面被切成三格，格框是粗细不一的黑色手绘线；同一个动作在三格里被重复三次、一次比一次夸张；格内有速度线与拟声词；平涂色块加网点阴影`
- **★ 质感与痕迹**：`画面被分成格、格与格之间有边框` · `拟声词与速度线进画面` · `格内构图按漫画的读法排`
- **★ 最容易被写歪成什么**：`电影式的连续镜头` · `没有分格` · `写实景深`

### G05 · 抽帧运动（低帧率本身就是风格）
**识别**：动作一格一格地跳，像手翻书。
- **核心视觉**：**低帧率**让每一格都看得清——动作有台阶感、物体留下残留；常与高细节的画面配对（细节越多，抽帧越显得是有意为之）
- **色彩光影**：不限定；关键在**运动的时间感**，不在画法
- **构图材质**：**每一格都要当成一幅完整的画**来构图（因为观众会看清每一格）；运动模糊很少，取而代之的是**重复的残影**
- **参考作品**：以"每秒 8–12 格"处理动作的动画与混合媒介作品（**帧率注（2026-09-30 补）**：生成端无帧率参数可下发——"8–12 格"是**观感目标**，落提示词写画面特征：**台阶感的顿挫、重复残影、无运动模糊**）
- **适用场景**：爆点、仪式感、舞蹈、任何要"被看清"的动作
- **叙事氛围**：机械、仪式化、被放慢的暴力；适合"把动作拆开来看"
- **量级**：**不独立成系**——它是**运动处理层**，可叠在任何量级上（画法照所选系，只改帧率）
- **可写句式**：`动作以分段停顿的节奏呈现——动作有明显的台阶感、每一格都看得清；快速挥动的部分留下重复的残影而不是运动模糊；每一格都像一张完整的画；动作有跳顿与拖影、帧率不均匀，静止的部分仍然清晰`
- **★ 质感与痕迹**：`动作有跳顿与拖影、帧率不均匀` · `静止的部分仍然清晰` · `拖动方向与运动一致`
- **★ 最容易被写歪成什么**：`全程运动模糊` · `平滑插帧` · `慢动作`

### G06 · 游戏引擎实时渲染
**识别**：像游戏过场，但世界是真的在实时算。
- **核心视觉**：**体积雾与动态光照**、屏幕空间反射、次表面散射的皮肤、**略微塑料感**的表面（引擎的招牌）
- **色彩光影**：**高动态范围加强 bloom**、逆光的雾与光束、饱和的补色对撞；暗部有轻微发灰与噪点
- **构图材质**：**第三人称或过肩的运镜**、镜头跟随、场景里有可交互的道具暗示；材质的程序化重复
- **参考作品**：以实时引擎渲染整段影像的做法、以引擎画面作背景的虚拟制片
- **适用场景**：科幻、游戏世界观、赛博、动作
- **叙事氛围**：被计算出来的真实、技术性的自信；适合"这个世界随时可以被接管"
- **量级**：**第三系（工艺渲染）**——必须写渲染方式句：`由游戏引擎实时渲染的影像`
- **可写句式**：`由游戏引擎实时渲染：画面里有体积雾与动态光照、地面有屏幕空间反射；皮肤是次表面散射的、略微塑料；逆光处有 bloom 与可见光束；镜头是过肩跟随的第三人称视角`
- **★ 质感与痕迹**：`实时的光照与屏幕空间反射` · `边缘有锯齿与 LOD 切换的痕迹` · `贴图重复、远近精度不同`
- **★ 最容易被写歪成什么**：`离线渲染的完美感` · `手绘笔触` · `胶片颗粒`

### G07 · 屏幕生活（整部片都在屏幕里）
**识别**：故事发生在一块屏幕上。
- **核心视觉**：**画面本身就是一块屏幕**——聊天窗口、视频通话、监控分格、地图与浏览器标签；鼠标指针是唯一的"身体"
- **色彩光影**：**屏幕发的光**（冷白与蓝）是唯一光源；屏幕之外的房间沉在暗里、几乎看不见
- **构图材质**：**界面即构图**、窗口的位置与大小承担叙事；压缩块、像素化的头像、转动的加载圈
- **参考作品**：全片以电脑桌面构成的长片
- **适用场景**：当代、悬疑、异地关系、网络调查
- **叙事氛围**：被界面中介的亲密、焦虑、无处可逃的信息
- **量级**：与 **P06 网络摄像头**是天然一对——画面里的一切都走低端档
- **可写句式**：`整部片发生在一块屏幕上：画面是电脑桌面，开着聊天窗口与视频通话；唯一的光是屏幕发的冷白光；人物只是窗口里一个像素化的头像；屏幕外的房间沉在黑暗里；鼠标指针在移动；画面就是屏幕：界面、光标、消息，拍屏幕时的摩尔纹与反光`
- **★ 质感与痕迹**：`画面就是屏幕：界面、光标、消息` · `拍屏幕时的摩尔纹与反光` · `拍摄者的手与倒影`
- **★ 最容易被写歪成什么**：`全屏无边框的纯净界面` · `电影式运镜` · `写实场景`

### G08 · 多屏并置叙事
**识别**：画面被切成几块，同时看几个地方。
- **核心视觉**：**分屏**（二分、四分、不规则分割）、相邻屏之间有呼应或反差、时间可以不同步
- **色彩光影**：**每块屏可以有自己的色调**（用来区分地点或时间）；块与块之间常用一条硬边分隔
- **构图材质**：**分割线就是剪辑**、观众的视线在块之间跳；不同画质、不同画幅的素材并置造成的落差
- **参考作品**：以分屏构成长的对话与并行叙事段落
- **适用场景**：同时发生的事件、电话两端、监视与行动并置、对比
- **叙事氛围**：被同时发生的多件事压住、观众比人物知道得多
- **量级**：**多系并存**（每块屏照它自己的媒介写）——**块与块之间观感的落差是设计的一部分，不是穿帮**
- **可写句式**：`画面分成左右两块：左边是[地点 A]的室内、右边是[地点 B]的窗外；两块用一条硬边分隔、色调一冷一暖；镜头在两块之间硬切；两块里的动作不完全同步；几个画面同时在一屏里、各自推进，每格的尺寸与边框不同`
- **★ 质感与痕迹**：`几个画面同时在一屏里、各自推进` · `每格的尺寸与边框不同` · `视线在不同格之间跳`
- **★ 最容易被写歪成什么**：`单画面叙事` · `画中画的廉价特效` · `所有格完全同步`

### G09 · 生成痕迹作为风格
**识别**：不藏，就把生成器的痕迹当画风。
- **核心视觉**：**有意保留生成的特征**——形体在运动中轻微漂移、纹理中途改变、边缘像在溶解、不合逻辑但好看的细节增生；整体有一种"活的、正在变"的感觉
- **色彩光影**：**高饱和加泛光加轻微过曝**（这正是生成器的偏好），但**被有意收在同一个方向上**
- **构图材质**：**形体在运动中不稳定**、同一件东西上的质地会渐变（皮肤变陶、布变金属）；细节密度远高于真实
- **参考作品**：把生成器特征当作风格来用的实验影像
- **适用场景**：梦境、致幻、变形、意识流、超现实
- **叙事氛围**：世界不稳定、正在溶解或生长；适合"现实正在被改写"
- **量级**：**第三系（工艺渲染）**——必须写明这是**有意为之的风格**。**与"翻车"的区别只有一条**：这里的变化是**全片一致的方向**，不是随机崩坏
- **可写句式**：`画面有意保留生成的痕迹：形体在运动中轻微漂移、边缘像正在溶解；同一件东西上的质地从中途开始变化——皮肤渐渐变成陶土；细节增生得不合逻辑；全片保持同一个方向的变化`
- **★ 质感与痕迹**：`分辨率不一致的拼贴、边缘断裂` · `同一物体在不同区域长得不一样` · `像素级的糊与涂乱的边界`
- **★ 最容易被写歪成什么**：`干净统一的画面` · `把痕迹做成滤镜` · `全画面一致的糊`

### G10 · 剪影与影子戏
**识别**：只看得见黑，看不见人。
- **核心视觉**：**纯黑的剪影**、背景是唯一被照亮的东西（雾、幕布、落日、火）；面部与衣纹全部消失，只剩轮廓
- **色彩光影**：**逆光是唯一的光**——光在背景，主体全黑；常用暖橙或冷蓝的渐变底
- **构图材质**：**轮廓的形状就是全部**（姿态必须一眼读得懂）、影子投在墙上或幕布上；雾气让光可见
- **参考作品**：以剪影与影戏构成的动画与舞台段落
- **适用场景**：寓言、回忆、暴力、匿名的人、历史
- **叙事氛围**：匿名、命运、被光吞掉的人；适合"这不是某个人，是一类人"
- **量级**：**描边系（极端版）**——没有内部细节，只有外轮廓
- **可写句式**：`画面里只有剪影：所有人物都是纯黑的轮廓、看不出脸与衣服的细节；背景是唯一被照亮的东西——一片发亮的雾；逆光让雾气里的光变成可见的光束；轮廓的姿态清楚得一眼能读懂；人只剩轮廓、影子投在墙上，单一强光源造成硬边剪影`
- **★ 质感与痕迹**：`人只剩轮廓、影子投在墙上` · `单一强光源造成硬边剪影` · `道具与手在光与影之间`
- **★ 最容易被写歪成什么**：`看得清脸` · `多光源` · `写实肤色`

### G11 · 微缩模型加实拍
**识别**：世界是被做出来的，做得比人小。
- **核心视觉**：**看得见的模型痕迹**（接缝、涂装笔触、石膏与木料的质地）、微缩的比例感（景深与真实对不上）、合成边缘
- **色彩光影**：**小尺寸布景的灯**——灯泡相对模型比人还大、光衰减很快；火花与烟在微缩尺度下显得浓
- **构图材质**：**模型与实拍剪接**造成的尺度错乱；表面质感是漆与木，而不是真实材料
- **参考作品**：以微缩布景拍灾难与城市的传统做法、模型与真人同框的特技
- **适用场景**：灾难、城市全景、幻想世界、怀旧的特技感
- **叙事氛围**：手作的诚实、被造出来的世界；适合"这世界是假的，但情感是真的"
- **量级**：**第三系（工艺渲染）**——写明"这是微缩模型拍摄的"
- **可写句式**：`微缩模型拍摄：布景是手工做出来的，看得见接缝、涂装的笔触、木料与石膏的质地；光是小尺寸布景的灯、衰减很快；炸开的火与烟在微缩尺度下显得很浓；真人与模型剪接时尺度对不上`
- **★ 质感与痕迹**：`模型的接缝与涂装的不均` · `浅景深暴露模型尺度` · `实物与人同框时的比例感`
- **★ 最容易被写歪成什么**：`完美的 CG 场景` · `写实远景` · `无接缝的表面`

### G12 · 沙画与粉末
**识别**：一条线被手抹开，变成了别的东西。
- **核心视觉**：**沙或粉末在白底上**堆、抹、划；一个形象被抹掉之后在同一位置变成另一个形象；**手的痕迹**时常入画
- **色彩光影**：**只有沙的本色与背光的白**（或单色光）；明暗由沙的厚度决定，是真正的"物质明暗"
- **构图材质**：**连续变形**（一镜之内完成多次转化）、颗粒的堆积与散开；沙的粗细与漏沙画出的线条
- **参考作品**：以沙画完成的叙事短片与现场表演
- **适用场景**：起源、变迁、记忆的转化、神话
- **叙事氛围**：一切都在变形、留不住；适合"事物一个接一个变成另一个"
- **量级**：**第三系（工艺渲染）**——写"在背光的玻璃上以沙作画"
- **可写句式**：`沙画：在背光的玻璃上铺着沙；一只手把沙抹开，一个人形散成一座山；同一个位置上的形象连续变成另一个形象；明暗由沙的厚度决定；画面里只有沙的本色与背光的白`
- **★ 质感与痕迹**：`粉末的颗粒与堆积的边` · `手在画面上抹、留下指痕` · `正上方的均匀照明`
- **★ 最容易被写歪成什么**：`笔触式的绘画` · `颜料质感` · `侧光投影`

### G13 · 光绘与长曝光
**识别**：时间是画面的一部分。
- **核心视觉**：**光走过的轨迹**（线、圈、字）、运动的物体被拉成连续的光带、静止的部分清楚而运动的部分化开
- **色彩光影**：**暗环境里只有光源本身亮**、轨迹是饱和的彩色；背景近乎全黑，建筑只被光"描"出边缘
- **构图材质**：**曝光时间本身就是构图工具**（轨迹的形状决定画面）、光带与静止实体的叠加
- **参考作品**：以长曝光与光绘完成的影像与摄影
- **适用场景**：都市夜、速度、记忆的残留、抽象的情绪
- **叙事氛围**：时间的可见堆积、快速流逝；适合"这一刻被拉长了"
- **量级**：**写实系加曝光层**——按方案包选机身，再加一句曝光时间
- **可写句式**：`长曝光：摄影机的快门开着很久；街上经过的车变成连续的光带、行人的身体化开成半透明的拖影；站着不动的人与建筑是清楚的；背景近乎全黑，只有光走过的轨迹是饱和的；光的轨迹连续、背景是暗的，移动的人变成半透明残影`
- **★ 质感与痕迹**：`光的轨迹连续、背景是暗的` · `移动的人变成半透明残影` · `车灯拖成长线`
- **★ 最容易被写歪成什么**：`移动主体缺少预期拖影` · `日光下的场景` · `闪光灯冻结`

### G14 · 实物剧场（日常物件当角色）
**识别**：演员是一把勺子。
- **核心视觉**：**日常物件被赋予身体与情绪**——勺子弯腰、纽扣列队、纸片发抖；没有人的脸，情绪全靠姿态与节奏
- **色彩光影**：**桌上的一盏台灯**（或桌面自然光）是全部光源、投影清楚；材质的真实感保留
- **构图材质**：**俯视桌面**或低角度贴近物件、比例被放大成"人那么大"；物件本身的质地（木、瓷、布）是画面主角
- **参考作品**：以物件演剧的实验短片与定格做法
- **适用场景**：寓言、日常哲学、教育、温情段落
- **叙事氛围**：天真、轻、用最少的语言讲清一件事；适合"讲一个道理但不许说教"
- **量级**：**第三系（工艺渲染）**——写"以实物逐格拍摄"
- **可写句式**：`实物剧场：角色是一把汤勺与两粒纽扣，它们有姿态、有动作；摄影机放低到与桌面齐平、它们显得像人一样大；光源是桌上的一盏台灯、投影很清楚；材质的真实感保留；逐格拍摄；用日常物搭出场景、看得出是实物，人的手在场景外操作`
- **★ 质感与痕迹**：`用日常物搭出场景、看得出是实物` · `人的手在场景外操作` · `桌面高度的俯拍`
- **★ 最容易被写歪成什么**：`写实场景` · `CG 特效` · `抽离实物的抽象`

### G15 · 混合画幅（同一片里换画幅）
**识别**：画框本身在讲故事。
- **核心视觉**：**画幅随段落变化**——回忆用 1.37:1 或 4:3、现在用 2.39:1、某个时刻变成 9:16；变化处与时空切换同拍（**平台落地历史快照（2026-09-30 补，当前参数以现时 schema 为准）**：平台 `aspect_ratio` 枚举为 16:9 / 9:16 / 1:1 / 4:3 / 3:4 / 21:9 / adaptive，**2.39:1 / 1.37:1 非法值**——2.39:1 写 21:9、1.37:1 写 4:3 近似；且**单节点不能中途换画幅**，按段落分段生成、后期遮幅拼合）
- **色彩光影**：不限定；**每种画幅可以配自己的一套色彩工程**（年代画幅配年代调色）
- **构图材质**：**构图必须跟着重排**（横向画幅重左右、方形画幅重中心）；画框边缘成为信息——多出来或被截掉的边缘，就是"另一个时空"
- **参考作品**：用两三种画幅区分时空的长片（以不同画幅对应不同年代）
- **适用场景**：跨年代、回忆与现实交织、多个时空
- **叙事氛围**：被画框不断提醒的时空差、观众随时知道"这是哪一层"
- **量级**：**多系并存**——每种画幅各自选包与量级；**切换点必须有叙事上的触发**（同 `stylized-look.md` 第二节·补2 的条件 2）
- **可写句式**：`画幅随段落变化：现在的部分用 2.39:1、回忆的部分切为 4:3 并同时换成更粗的颗粒与偏黄的调子；切换与时空切换同拍；切换后构图重新排过——方形画幅里一切向中心收拢`
- **★ 质感与痕迹**：`画幅在一次剪辑里改变：宽变窄或变方` · `画幅变化对应时间或视角的切换` · `不同画幅并存于同一段落`
- **★ 最容易被写歪成什么**：`全程同一画幅` · `把黑边做成装饰` · `画幅随机变化`

## 易混对：一句话分辨（G 卷）

| 容易混的两条 | 一句话分辨 |
|---|---|
| G01 选集多风格 ↔ G15 混合画幅 | 选集换的是**整段量级**（画法都换了）；混合画幅换的是**画框**（画法可以不变） |
| G02 2D 角色+3D 环境 ↔ D13 三渲二 | 三渲二是**整个画面都是 3D**、只把明暗做成卡通；G02 是**角色真手绘、环境真三维**，两层材质不同 |
| G03 实拍+手绘 ↔ A33 欧普 / F06 迷幻 | 后两者**整幅都是画**；G03 是**实拍是真、手绘是加在上面的一层** |
| G05 抽帧 ↔ D16 油画动画 | D16 管**画法**（每一帧是厚涂）；G05 只管**帧率**，画法可以是任何系 |
| G09 生成痕迹 ↔ 一般意义上的"AI 崩坏" | 崩坏是**随机、方向不一**；G09 是**全片朝同一个方向变形**，是有意为之 |
| G10 剪影 ↔ A09 至上主义 | 至上主义**没有主体**（只有形状）；G10 **有主体、只是全黑**，姿态在讲故事 |
| G11 微缩模型 ↔ D10 定格动画 | 定格的对象是**黏土/偶**（材料本身是角色）；G11 的模型是**真的布景**，旁边可以有真人 |
| G12 沙画 ↔ D14 水彩绘本 | 水彩是**画上去的、留白是纸**；沙画是**一坨材料被抹开**，明暗来自厚度，且形象在连续变形 |
| G14 实物剧场 ↔ D17 剪纸与纸艺 | 剪纸是**纸被剪出人形**；G14 是**物件本身当人**（一把勺子不需要变成人） |
