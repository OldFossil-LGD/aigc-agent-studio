# 语料地图（12 板块：要什么词 → 去哪张表取）

> **何时读**：**写提示词时"知道该写什么、但想不出词"**的那一刻——先查这张图，别凭印象造句。**读完回哪**：回 `shot-craft.md` 填对应板块。
>
> **这份是什么**：**全库语料的索引与取词流程**。它**不重复任何词表**——只回答一句：**这个板块缺的是"词"还是"结构"？词在哪张表里？**
> **为什么单开一份**：库内此前是"**每个板块各写各的**"，**没有一处告诉你"语料在哪、怎么取"**——结果是每次都靠临场造句，写出来的词飘忽、且同一个意思在不同镜里用不同说法（同名不同词本身就是漂移源）。

---

## §0 先分清三类语料（**这是用这份图的唯一前提**）

**同一个"词库"里其实混着三种完全不同的东西**，混用会把提示词写坏：

| 类 | 是什么 | 给谁 | 例子 | 落进提示词吗 |
|---|---|---|---|---|
| **A 术语词** | 行业里有定义的**名词（含名词性短词组）**（可被执行的可见/可听之物） | **给模型** | `硬光` `半影` `碎高光` `房间底噪` `砾石上的脚步` | ✅ **直接写** |
| **B 可写句式** | 一整句**可直接粘进提示词**的句子 | **给模型** | `画面里只有一处光源，所有影子朝同一方向倒` | ✅ **整句粘** |
| **C 判断参数** | **角度 / 毫米 / % / Hz / 秒 / dB** 这类数字 | **给作者** | `嘴角上拉 30°` `瞳孔扩张 20–40%` `音乐 −28 dBFS` | ❌ **不写**——**数字进你的判断，句子进提示词** |

> **★ 这张图的三种用法，对应三类问题**：
> 1. **想不出词** → 去 A 类表（术语词）
> 2. **有话但不成句** → 去 B 类表（可写句式）
> 3. **判断不出"这是轻微还是过度"** → 去 C 类表（判断参数对表），**然后仍写句子**
>
> **判据一句话**：**划掉形容词后，剩下的应当是名词与动词**——剩下的若是数字，说明你抄了 C 类，该转成 A 类或 B 类。

## §2 补：构图法名词表（本库此前只有 4/17）

**写构图时，先点名字法，再写落点。** 名字法＝告诉模型"按哪种结构摆"，落点＝告诉它"主体具体在哪"——**两个都要，只写一个都会飘**。

| 法 | 一句话 | 什么时候用 |
|---|---|---|
| **三分法** | 主体压在横竖三分线的交点上 | 通用、最稳 |
| **中心对称** | 主体正中，两侧对称 | 秩序、压迫、仪式感、对峙 |
| **对角线** | 主体沿画面对角排布 | 动势、张力、不稳定 |
| **三角形构图** | 三股力量构成三角（人或物） | 三人关系、稳定中的倾斜 |
| **框架内框架**（框中框） | 用门／窗／洞把主体再框一层 | 隔离、窥视、被困 |
| **镜像构图** | 用镜面／水面复制主体或空间 | 分身、自省、双重性 |
| **S 形 / 曲线** | 主体或引导线走曲线 | 柔、流动、抒情 |
| **引导线** | 用线条把视线引向主体 | 纵深、方向感 |
| **前景遮挡** | 虚焦的前景压住画面一角 | 纵深、旁观视角 |
| **负空间 / 留白** | 主体偏向一侧，另一边空着 | 孤独、威胁感、呼吸 |
| **黄金分割 / 斐波那契** | 比三分法更偏的分割点 | 更松弛、更"不经设计" |
| **俯视 / 平视 / 仰视**（视角法） | 机位高度直接决定权力关系 | 与景别配合用 |
| **满构图 / 填充** | 主体塞满画面 | 压迫、亲密、失控 |

> **与 `shot-design.md` §2 十装置的对照（2026-09-30 补）**：**框中框＝装置「框中框」**、**负空间 / 留白＝装置「负空间」**、**三角形构图≈装置「三角调度」**——本表法名管"按什么结构摆"，装置管"这一镜在说什么"：**先选装置，再取对应法名落词**（同义异名以各册原文为准，不许混造第三套名）。

> **★ 一条纪律**：**构图法只能写一个**。写两个法名（"三分法 + 对角线"）＝模型自己挑一个，或两个都不执行。**要两个效果就出两条独立版本。**

## §3 补：姿态名词表（本库此前只有"体态四维度"，没有姿态名）

`character-depth.md` §三 给的是**判断维度**（怎么占空间 / 朝向 / 重心 / 静止质量），**没有可写进提示词的姿态名**。两者配合用：**先用维度想，再用姿态名写**。

| 站 | 坐 | 低姿态 | 倚靠与支撑 |
|---|---|---|---|
| 立正（绷） | 正襟危坐 | 蹲踞（蓄力） | 靠墙（肩与后脑贴墙） |
| 松站（重心偏一侧） | 塌腰坐 | 蹲坐（脚跟落地） | 倚门框 |
| 抱臂站 | 前倾坐（肘压膝） | 盘腿 | 搭在桌沿上 |
| 双手插袋 | 后仰坐（摊开） | 跪坐 | 撑着栏杆 |
| 背手站（收） | 盘腿坐 | 侧卧 | 把重量全交给椅背 |
| 垂手站（空） | 架腿坐 | 蜷缩（抱膝） | 趴在桌上 |
| 单脚承重 | 缩在椅子里 | 躺平（仰／侧） | 手肘支在窗台 |

**加三样才算"活"**（→ `character-realism.md` §四）：
- **重心在哪只脚上**；② **肩怎么挂**（抬／塌／一高一低）；③ **头与脊柱的关系**（头前引／下巴内收／后仰）。
> **纪律**：**每镜只写一个姿态名 + 三样细节**；一镜里换两次姿态＝该拆镜。

## §4 反例与三条纪律

| ❌ 常见写坏 | ✅ 改法 |
|---|---|
| 把 C 类数字写进提示词（`高光面积不超过指甲盖的 6%`） | 换成 A/B 类：`高光只是鼻尖与眉骨上的几小片，面积窄，且被毛孔打断` |
| 一次写三个构图法名 | **只留一个**；两个效果＝两条独立版本 |
| 一个板块的语料从别处"另造一套"（例：自己编运镜名） | **去 §1 那一栏的加粗文件里取**（同一概念一处定义） |
| 声音一次写十几二十个词 | 每类**≤5–8 个**（→ `sound-craft.md` §3.1） |
| 同一场里混两种声学空间 | **一场景一空间**（要两种＝拆场） |

## §5 来源与口径

**本文件（语料地图 · 三类语料的分法 · 12 板块索引 · 构图法名表 · 姿态名表）为 2026-09-15 本库自建**，动机：用户要求"围绕各个板块做语料扩充、并形成可复用的参考"。
**★ 检索与筛选过程（如实交代）**：检索了 GitHub 与公开网络上的同类"提示词语料库"——包括 `LingyiChen-AI/image-prompts`（movie-styles / **storyboard-prompts 500+** / camera-language / sound-design 诸卷，附 300+ 电影风格与 5000+ 分镜画面的原始表格）· `khanof89/awesome-video-prompts`（MIT，按场景分组的提示词**结构模板**）· `Emily2040/seedance-2.0` 的 `seedance-vocab-es`（450 条 / 20 类**双语影视词汇表**）· 各平台官方 cheatsheet（Pruna 等，按"光／风格／运镜／情绪"分区）。
**筛选结论与不采用的理由**：
- `LingyiChen-AI/image-prompts` **未声明 LICENSE** → 按 `sources-and-credits.md` 的纪律**只借鉴其"按板块分卷"的组织方法，不采用其任何词条**；
- `awesome-video-prompts` 是**提示词样例集**（结构模板），非词汇表，且与本库"整合式交付"的体例相反（它按"场景描述 + 运镜 + 风格 + 效果 + 时长"分行）→ **不采用**；
- 双语词汇表类的价值在**翻译等价**，本库是**纯中文**交付（E9）→ **不采用**；
- **本库已有的语料层覆盖面远大于这些仓库的可用部分**（关键词扫描：构图 13/17、大气 12/14、陈设 13/13、材质 15/16、光现象 13/14、色彩 11/13、运镜 13/14、转场 10/10、景别 14/14 均已覆盖）——**唯一真缺口是"声音词"（8/14 零命中）**，故本次**只新建 `sound-lexicon.md` 一处**，其余**补两张小表（构图法名 · 姿态名）+ 建这份索引**，**不做重复加装**（E20）。
**声音词的来源**见 `sound-lexicon.md` 末尾（LCC / Morphic / VideoProc / Pixflow / SoundSpool 的公开术语体系，**只提炼分类法与术语，未复制文本、未使用任何素材**）。
