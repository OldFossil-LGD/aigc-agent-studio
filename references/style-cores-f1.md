# 风格内核册 · F 卷（F01–F12）

> **何时读**：① 写完风格声明、要落「可写句式」之前；② 要判断"这条风格到底稳在哪"时。
> **读完回哪**：回 `style-library-*` 对应条目，把内核翻成可写句式。
>
> **本册是什么**：**每条风格「剥掉题材之后仍然成立」的那套语言**——由 `_refs/<编号>/` 里的**真实参考帧**逐图反推、
> 再交叉比对求交集得来（方法 → `reverse-prompt-method.md` §2 七层反推 · §6 三图比对）。
>
> **三条纪律**：① **内核一律来自真实像素**，每条标注用了哪几帧；没有图就不填。
> ② **内核是关系句、不是形容词**——判据：**换掉题材它还成立**。
> ③ **证据分级**：疑似宣传照 / 概念图 / 错片的帧**标注并剔除**，不作内核证据。
>
> **同系列**：本册即 F 卷唯一册（F01–F12）；邻卷 `style-cores-e2.md`（E 卷）· `style-cores-g1.md`（G 卷）（原行误指本册自指，2026-09-30 修正）

## F01 · 瑞士国际主义排印

**用帧**：`_refs/F01/` 01（纯文字排印｜非对称色块网格·整幅｜暖橙+米白）· 04（纯文字排印｜巨字出血裁切·暗底整幅｜冷黑紫+红+灰白）（可选帧偏少，6 张中本体仅此 2 张）

**视觉语言**：文字自己当图像——01 用一组大小错落、互相咬合的橙色矩形把版面切成非对称的格子，所有文字严格齐左、单一无衬线字族，层级只靠缩进与位置而不靠字号跳跃（**此为正文版面法则**；巨字号只作 04 那样的图像化封面元素，不入层级系统）；04 让 "der Film" 的巨字直接被底边裁切出血，灰白两色分词，红色小字信息带压在下方，网格不可见但秩序无所不在。两张一暖一冷共用同一套法则：无插画、无照片、无装饰线，色彩只作为平面色块出现且永远与信息结构对位。

**叙事气质**：它看待世界的方式是"信息应当被客观地组织"，与观看者的距离是冷静、平等、不加劝说——海报不表演，只交代。

**情绪基调**：上限是明快的理性秩序感（01 的橙色节奏近乎音乐拍点），下限是近乎刻板的克制。它从不做的是：不居中对齐、不加任何手写或有机形态、不让装饰先于信息半步。

**换题材测试**：换成产品目录、数据年报、网页版式或任何"以文字信息为主体"的题材，只要坚持非对称网格、单一无衬线、色块与信息对位，语言仍成立。

**★ 存疑（已剔除）**：02、03 为 [观察到] RIT 校报《News & Events》的整页翻拍（03 内恰有 Müller-Brockmann 到访讲学的新闻照片，但属报刊翻拍），05 为该新闻照片的单张放大（[观察到] 讲座现场照），07 为 [观察到] 暗红布面书封档案翻拍（索书号 HG 1628），四张均剔除。剔除后内核由 01、04 两张本体海报支撑，恰为暖/冷两极，证据链完整但偏薄。

## F07 · 涂鸦与街头艺术

**用帧**：`_refs/F07/` 02（图像主导｜字体特写｜单色黑白）· 05（混合·高架街景｜整幅远景｜暖黄）· 07（混合·车厢内景｜局部裁切｜暖红棕）

**视觉语言**：先把一个功能表面（车厢侧板、门板、墙面）整体认作画布并铺满，再用大弧度气泡字横撑出骨架，细密 tag 像霉斑一样糊进字缝与边角；字的面积永远大于任何具体形象，人只是被塞进字形旁边的过客。核心关系是"边界服从材质"——把手、车窗、门框、铆钉线一律不动，直接被字形包围或切断。

**叙事气质**：信息不是被送达的，是抢占地盘抢出来的；作者与观看者处在同一条街的水平线上，谈不上"展示"，只有"留名"，署名密度和字号大小就是话语权的刻度。

**情绪基调**：上限是松弛的炫耀（字形饱满圆润、互相叠压，像在笑），下限是资源匮乏的粗粝（单色胶片、逆光、无补光，颗粒粗到吃下细节）。它从不做的是精致打光、对称构图，也从不给字形留安全边距。

**换题材测试**：把车厢换成集装箱、货车箱体、仓库卷帘门、地下通道，甚至换成一段提交记录墙，这套"满铺字面 + 碎 tag 缝补 + 材质边界不改动"的语言照样成立。

**★ 存疑（已剔除）**：03 为现代地下通道彩色满墙涂鸦（灰绿冷调、瓷砖地、LED 照明、贴纸与签名混杂），[推断] 非 1970 年代纽约地铁系统、属现代照片，予以剔除；因此本组色调轴只剩"单色黑白"与"暖棕黄"两极。01、04、06、08 未剔除，均 [观察到] 1970 年代纽约地铁实景（04 可见 UTICA AV / LEXINGTON AV EXPRESS 站牌，05 可见高架桥与 1521/1776 车号），作为支撑帧保留。剔除 1 张，由 02、05、07 支撑内核。

**叙事气质**：它看待世界的方式是"在段落之间闭眼"——字卡是沉默年代的旁白替身，与观看者的距离是一声转场的提示，不解释、不寒暄。

## F09 · 编辑设计 Editorial Grid

**用帧**：`_refs/F09/` 05（图像主导·纯色圆盘衬底｜整幅｜暖橙）· 07（图像主导·无框散落物件｜整幅｜暖棕）· 08（混合·圆形徽章框＋书法卷轴｜整幅｜暖）

**视觉语言**：顶部一条跨栏刊头垄断绝对权重，中段插画可以漫出任何假想栏位、压住下缘文字，底边却始终收紧成一行齐中小字目录——三段的重心配比是固定的，只有中段被允许越界。留白不是背景而是被切出来的形状：插画要么坐进一个正圆或拱形色块，要么与白场直接硬碰硬，因此形象与纸面的关系永远是"贴上去的一整块"。

**叙事气质**：它把封面当成一次优先级的公开宣示——先报名号，再给图，最后才在底边小声列清单；与观看者的距离是沿街橱窗式的，先拦住脚步，再交代细节。

**情绪基调**：上限是节日般的饱满（正红、正橙、正黄一次性上满，双色 script 刊头与插画暖色互相应和），下限是克制的礼节（大面积白底、细线小字、底部目录只用一行）。**就本刊样本而言**，它不做居中对称的平衡版式、不把刊头缩小让位给画面、也不做满幅出血的图像（单刊样本立论，外推需再取样）。

**换题材测试**：把杂志封面换成演出海报、唱片封套、活动折页或网页首屏，这套"顶端绝对刊头＋中段越界图形＋底边细字清单"的骨架照样成立。

**★ 存疑（已剔除）**：8 张全为 The Elks Magazine（1929–1930）封面的整幅档案扫描，保留纸边与轻微暗角，无折痕、无图书馆标签，[观察到] 属印刷品本体，故剔除 0 张，内核由 05、07、08 三帧支撑、01–04、06 作旁证。需另记两点：参照物实为 The Elks 而非 Esquire，两者同属编辑设计传统但版式成熟度不同 [推断]；本组三轴只能取到单极——构图全为整幅、色调全落在暖区间（红/橙/棕/黄），无冷色与单色样本，"色调至少两极"一项在本组不可得。

## F12 · 工程蓝图与系统图

**用帧**：`_refs/F12/` 01（系统线图｜整幅｜单色普鲁士蓝）· 02（图像主导·浅调留白｜整幅｜单色浅蓝）· 04（图像主导·深调满幅｜局部式堆叠｜单色深蓝高对比）

**视觉语言**：全部明暗关系被压进单一色域——蓝是实底、白是留白，亮部靠"没上到蓝"得到而不是靠加白，于是任何题材都被压成同一种关系：白线或白影贴在蓝域上。制图的格网、引线、编号与照相得到的影调共用同一根细笔画，两者的差异只在笔画疏密，所以一张船体线图和一张花瓣照片会显得像同一个作者做的。

**叙事气质**：它把证据摆出来而不解释——编号、标注、比例挤在图面边缘，像旁注一样越出画面；与观看者的距离是技术交付式的，要求你俯身贴近、按编号去查，而不是被引导着看。

**情绪基调**：上限是冷静的权威（单色、零装饰、全幅被信息填满），下限是工业磨损（折痕、褪色、边缘毛口、曝光不匀的白斑）。它从不做多色、渐变与装饰花边，也从不给主体留一个聚焦中心——画面重心由信息密度决定，不由视觉趣味决定。

**换题材测试**：把船体换成机械装配、电路板、城市管网、流程框图，或把花瓣换成人脸、手掌、任意物件，这套"单色域＋反白线影＋边缘旁注＋手刷毛边"的语言照样成立。
