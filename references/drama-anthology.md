# 选集剧：三台引擎与结构手法（黑镜 · 爱死机 · 九号秘事）

> **何时读**：要做**选集**（每集独立、可任意顺序看）时；写**技术寓言 / 概念短片 / 单一地点反转剧**时；设计"系列识别度"时；写反转时。
> **读完回哪**：单集结构 → `drama-episode-structure.md`；引擎与季 → `drama-series.md`；创意落点 → `drama-plotcraft.md`；风格 → `style-library.md`。
> **适用**：剧本 / AIGC 写作。**NOT for** 技术文档 · 论文 · 新闻 · 公文（→ `writing-methods.md` §0）。
> **为什么单列这一册**：前几册的剧集方法是**为"连续剧"写的**（引擎、人物网、季形）。**选集没有延续的人物、没有季弧——它有另外一套约束与另外一套资产。** 而这三部恰好覆盖了选集的三种典型做法。

## §0 选集的三个门槛（先判它是不是选集）

| 判据 | 选集 | 不是选集 |
|---|---|---|
| **人物延续** | **不延续**（每集新角色、新场景、新设定） | 有固定主角团 |
| **观看顺序** | **任意顺序都能看**（本可乱序） | 顺序敏感 |
| **绑定装置** | 靠**一个装置/母题**把互不相干的集绑成"一部剧" | 靠人物与世界观绑定 |

**三种绑定装置**（这是选集唯一"必须现造"的东西，见 §1）：

| 装置类型 | 例 | 特点 |
|---|---|---|
| **主题装置** | 黑镜＝科技 | 一个**当代文化的侧面**（不是题材） |
| **数量/位置装置** | 九号＝"9" | 每集一个与"9"相关的东西——**可以毫无深意** |
| **隐藏道具** | 九号＝**一只黄铜野兔**（藏在每集布景里） | 主创原话：因为每集差异太大、本来没有东西连接它们，**所以放一个能藏在每个布景里的物件**；**它没有特殊含义** |

> **★ 关键教训**：**绑定装置不需要有含义，只需要可辨认。** "必须让彩蛋有意义"是把简单问题复杂化了——**观众要的是"我认出来了"的那一下。**

**与"限定剧"的区别**：限定剧是**一条完整的故事切成几集**（顺序敏感、人物延续）；选集是**几个完整故事共用一个招牌**。**别把限定剧当选集写，也别把选集当限定剧排。**

## §1 ★ 三台引擎对照表（**本册的骨架**）

| | **黑镜**（技术寓言） | **爱死机**（短片选集） | **九号秘事**（结构游戏） |
|---|---|---|---|
| **时长** | 多数一小时上下，早期约 45 分钟 | **6–21 分钟** | **约 30 分钟** |
| **体量** | 早期每季 3 集 → 被平台接手后 6 集 | 第 1 卷 18 集，后续每卷 8–10 集 | 单季 6 集上下，多年累积 |
| **绑定装置** | **主题**：当代科技的近未来后果 | **标题三词**（爱 / 死 / 机器人，每集至少连一个） | **"9" + 藏起来的野兔** |
| **单集引擎** | **一处技术改动 → 放大当代文化的一个侧面 → 反噬** | **一个概念 + 一个视觉方案**（多数改自已发表短篇） | **一个日常场景 → 一个反转**（单一地点、短剧形态） |
| **结尾策略** | 绝望 / 反讽 / 罕见的希望 | **结局重新定义前面的一切** | **反转**；**有时"没有反转"就是反转** |
| **失败模式** | 两套推测技术分两条线、结尾强行会合 | **"附了剧本的技术演示"**（技术强、情感空） | 反转不公平（回头看信息不全） |
| **AIGC 适配** | 高（近未来·室内·单人·可静态） | **最高**（短片 + 每集一个风格） | **最高**（单一地点 + 两三人） |

**三台引擎的共同点（选集的通则）**：
1. **每集自足**：一集里必须完成"建立→升级→结算"三件事，**不许把结算留给下一集**。
2. **单集必须只有一个"奇观点"**：一处技术、一个概念、或一次反转。**两个就会显得"什么都想要"。**
3. **冷开场即建立**：选集没有预热时间，**前 90 秒要交代"这是谁的什么处境"**。

## §2 黑镜引擎：技术寓言的六条纪律

**来源为该剧主创的公开访谈与公开整理**（见来源节）。这六条里，**前四条是可判定的**。

| # | 纪律 | 判据 / 反例 |
|---|---|---|
| **1** | **前提是"最坏情况的复合"**（把一件技术带来的最坏结果**再叠一层**） | 单一后果 = 不够黑镜；**叠一层** = 到了 |
| **2** | **每集只允许一处需要"暂时放下怀疑"** | 两处以上 → 观众开始算逻辑账（**弱集的病灶正是"两套推测技术分两条线、最后强行会合"**） |
| **3** | **技术必须加剧人物本身的性格问题**，不是凭空制造悲剧 | 反例：技术只是工具，人物随剧情需要改变性格 |
| **4** | **语境可以离奇，人物行为必须真实** | "他的处境古怪，但他的反应像个真人"是底线判据 |
| **5** | **讽刺的动作是"取当代现实的一个方面并放大"**——**它最强的时候是抵抗纯推测、基于已经存在的技术** | 越依赖"未来才有的东西"，越容易失手 |
| **6** | **不追新闻热点** | 理由很实用：**上映时它多半已经过时** |

**结尾三型（选一种，不要含糊）**：**绝望**（最常见）· **反讽**（他得到的东西正好是他失去的东西）· **罕见的希望**（"不是悲观主义者就不能给一点光——**只要主题不变**"）。（**"无反转"不是第四型**——它是 §5.3 的通用用法，判据在那里。）
**创作流程上的两条可借用**：**先想结尾**（主创自述：写出结局让过程变容易，即使结局后来改了）· **先写一份大纲再动笔**（前两季边写边想导致丢掉副线、反复重写）· **先发一页 treatment 拿反馈再写初稿**。

## §3 爱死机引擎：短片选集的生产法

| # | 方法 | 说明 |
|---|---|---|
| **1** | **标题即生成器** | 三个词（爱 / 死 / 机器人）——**每集至少连上其中一个**。这是"永不缺题"的一种机制：**三个词做排列组合 + 换类型** |
| **2** | **从已发表的短篇改编**（多数集） | 短篇是**现成的结构底座**：它已经解决了"如何在很短篇幅内成立"这件事；**改编时保留结构与概念，换视觉与地域** |
| **3** | **视觉方案由故事决定**，不是先选风格 | 主创的公开说法即"**让故事决定每一集怎么画**"；**反例**：先定"我们要一个 CG 大场面"，再往上贴剧本 |
| **4** | **容量纪律：用"一个处境"代替"一个人物"** | **角色深度是这种篇幅的常态性牺牲品**——主角常被单一特质定义。**解法是把人物写成"一个处境的化身"，情绪的投入靠观众对概念的兴趣** |
| **5** | **★ 好集的三个共享特征（直接当验收判据用）** | ① **清晰的情感内核** ② **视觉风格服务故事而不是展示技术** ③ **结局重新定义前面的一切** |
| **6** | **失败模式：技术上令人印象深刻但情感空洞**（"附了剧本的技术演示"） | 这是这一型的头号病，**且它不会自己暴露**——需要有人专门问"删掉画面还剩下什么" |

**一条反直觉的观察**（对本库的"风格先行"是个补充）：**实拍感最强的那些（写实 CG）反而常常最"临床"、有距离感；2D 与混合媒介的集更能打。** 推论：**"更真"不等于"更动人"**——这条与 `tone-realism.md` 的写实纪律**不冲突但要标明适用面**（写实层管"质感像不像真的"，选集这一层管"这一集该用哪种媒介"）。

## §4 九号秘事引擎：单一地点与反转

**血统**：源头是一次**单房间 bottle episode** 的尝试（受希区柯克《夺魂索》影响的实时、近似一镜到底的做法），成功后扩展为整部选集；致敬的是老式"电视短剧"节目（`Play for Today` / `Tales of the Unexpected` 那一类）。

| # | 方法 | 说明 |
|---|---|---|
| **1** | **每集实质是一出短剧**：**单一地点 + 极少人物 + 自足** | 成本最低、可控性最高；**部分集是实时的**（三十分钟就是剧中三十分钟） |
| **2** | **"极其平淡"的开场** | 几乎每集都**从日常琐事开场**，然后才露出黑暗——**这是把反转藏在明面上的办法** |
| **3** | **两台绑定装置 + 一个可无意义的彩蛋** | 每集与"9"相关的物件（宅子 / 化妆间 / **9 码的鞋**）+ 藏起来的野兔（**无含义**） |
| **4** | **反转的变奏：有时"没有反转"就是反转** | 主创原话是"总有让观众**踩空**的欲望"。**连续几集都反转，观众会开始防你**——所以需要一集不给 |
| **5** | **基调逐集变，唯一常量是"三种东西的合成"** | 行业评价的概括：**病态喜剧 + 尖刻的社会评论 + 真实的毛骨悚然**。**基调可以每集换，但这一"味道"不能换**（这就是它的识别度） |
| **6** | **形式集传统** | 无对白集 / 实时集 / 近似一镜到底集——**形式本身就是这一集的卖点** |
| **7** | **被要求"更黑暗"时，从一个被抛下的细节里长出一条暗线** | 这是它的一个真实工作法：**把一句顺口的台词（"他不洗澡了"）纺成一条支线**，而不是另加一个事件 |

## §5 ★ 反转的工程学（三剧共用的一块）

**本册对我库既有判据的升级**：`drama-genre-casebook.md` 已有"反转必须公平——回头看信息都在"。**本节补三件它没有的**：

**5.1 误导三技术**（反转成立必须先用掉至少一种）
| 技术 | 做法 | 例（结构示意） |
|---|---|---|
| **错误引导** | 放一个**明显可疑**的东西，让观众把注意力花在它身上 | 全片都在查那封信，真相在**信封上的邮戳** |
| **机制转移** | 让观众**以为这一集在玩 A 机制**（时间循环 / 记忆 / 双胞胎），真相是 B | 观众在数循环次数，其实循环是**另一个人也在数** |
| **语气掩护** | **用喜剧或日常的语气把关键信息明着说出来**——观众不会把它当线索 | 开场闲聊时报出的一个数字，最后是全部答案 |

**5.2 最小线索配额**：**每条反转至少留两条"重看时才成立"的线索**，且**其中至少一条在前 1/4**。
**判据**：把反转那一场遮住，让没看过的人只看前 3/4——**他能不能指出"这里有点不对"**？完全指不出 = 线索给少了；一眼看穿 = 藏得太浅。

**5.3 "没有反转"是一种合法选择**（九号的做法）：
- **用途**：**防止观众形成"我一定会被骗"的防御姿态**（连看三集都反转，第四集观众会开始预判）；
- **写法**：让**表面上的那个"该反转的位置"给出一个平淡的、真实的解释**，把力量放到**情绪**上；
- **判据**：这一集必须**在别处更狠**（更痛 / 更真），否则观众会觉得"这次没料到"变成"这次没写"。

## §6 选集独有的三个问题（连续剧没有）

| 问题 | 为什么难 | 处置 |
|---|---|---|
| **① 系列识别度** | 没有固定主角、没有固定世界 | **认得出的是"味道"不是"人物"**：一个可辨认的**基调合成**（如"病态喜剧 + 社会评论 + 毛骨悚然"）+ 一个**可辨认的装置**（主题词 / 数字 / 彩蛋） |
| **② 单集自足** | 观众可能只看这一集 | **每集要能单独当短片看**：建立、升级、结算都在这集里；**不许依赖"看过前面几集才懂"** |
| **③ 观众预期管理** | 上一集的类型会变成这一集的预期 | **主动换类型**：这一集是科幻，下一集可以是哥特或闹剧——**但换完必须给一个"这一集自己会交付什么"的信号**（前 90 秒的类型承诺） |

> **一条排集建议**（来自公开评论的共识）：**不要把最强的集全放在一头一尾**——选集观众会跳着看，**中段要留一个"意外强"的集**当口碑点。

## §7 AIGC 适配：为什么选集是最友好的形态

| 优势 | 与库内体系的关系 |
|---|---|
| **单集独立** | **每次试错只影响一集**——不像连续剧，一集崩了不牵连全局；交付粒度与 `script-module.md` 的"每集一套 M1–M12"天然对齐 |
| **单一地点 / 两三人** | 资产最小：**场景 1–3 个、角色 1–3 个**（见 M11 的资产清单口径） |
| **短片**（6–30 分钟） | 落在 `drama-scaling.md` 的"能直用模型"区间（起承转合 / 故事圈 / 序破急 / 七点） |
| **每集一个视觉方案** | 与 `style-library.md` 的选取流程咬合；**每集可按 `style-package-matching.md` 换包** |
| **技术寓言多为室内近景** | 绕开可行性门的高失败项（手 / 走路 / 多人 / 口型 / 画面内文字）（**对白密集型〔九号式〕例外：口型风险反而升高——关键台词走 TTS / 后期配音，勿让模型对口型**） |
| **屏幕界面（黑镜式）的落地法** | 屏幕信息**后期叠加**（剪辑期图形层 / 字幕轨），镜头拍**交互反应与空屏**——不让模型画 UI 文字 |

**⚠️ 选集的两条成本警告**：
1. **风格漂移是选集的固有风险**——**每换一集风格，一致性体系（`asset-consistency.md` / `character-continuity.md`）都要按集重建**，等于把"一部片的一致性工作量"乘以集数。**排集时把"同风格的集"放在一起做，是省一半工的办法。**
2. **不要用选集的旗号省编剧力**——单集越短，**结构与反转的压力越大**（爱死机的"角色深度常被牺牲"就是这个代价的明账）。**选集的省法是省资产，不是省结构。**

## §8 落在 M1–M12 的哪一块

| 选集专属项 | 落哪 |
|---|---|
| 绑定装置（主题词 / 数字 / 彩蛋） | **M1 抬头**（写在系列层，每集抄一次） |
| 单集"一处奇观点" | **M2 前提 + M4 容量单**（写明"本集只有一处技术/概念/反转"） |
| 前 90 秒的类型承诺 | **M5 第 1 拍 + M8 第一场** |
| 反转的线索配额（≥2 条，≥1 条在前 1/4） | **M5 骨架的"埋点行" + M12 诊断记录** |
| "没有反转"的决定 | **M12**（写明"本集不做反转，力量放在 ____"） |
| 单集场景与角色上限 | **M11 交接契约**（场景 ≤3 / 角色 ≤3） |
| **跨集复用**（2026-09-30 补，承接 §7 成本警告 1） | **风格包 / 布光 / 声音锚可跨集复用**（同风格集排在一起）；**角色 / 场景资产板按集重建**——两边分别记账，勿混 |

> 表外的生产环节（分镜数 / 投喂生成 / 合成 / 质检）不在本册——走 `run-sheet.md` 十站与 `production-ledger.md`；选集的特有项只有上表两行，其余与单片同流程。

## §9 自检清单（写完一集逐条问）

```text
① 这一集能单独当短片看吗（建立/升级/结算都在本集内）？
② 一处奇观点还是两处？（两处 → 砍一处）
③ 前 90 秒有没有交代"这是谁的什么处境"？有没有给出本集的类型承诺？
④ 绑定装置在哪（主题词 / 数字 / 彩蛋）？观众认得出这是本系列吗？
⑤ 技术（或概念）是否**加剧了人物本身的性格问题**，而不只是制造事件？
⑥ 人物行为在离奇处境里是否像真人？
⑦ 前提是不是"最坏情况的复合"？还是只叠了一层？
⑧ 结尾是哪一型（绝望 / 反讽 / 希望）？用了"无反转"的话，§5.3 的判据撑得住吗？
⑨ 反转有几条"重看才成立"的线索？其中至少一条在前 1/4 吗？
⑩ 用了误导三技术里的哪一种？还是靠信息不给？
⑪ 遮住反转那一场，前 3/4 能不能让人感到"有点不对"？
⑫ 如果这一集不做反转，它有没有在别处更狠？
⑬ 抽掉视觉/风格，这个故事还剩什么？（剩不下 → 是"技术演示"）
⑭ 本集的场景数 ≤3、角色数 ≤3 吗？（超出 → 与 AIGC 的经济性对不上）
```
