# 风格内核册 · E 卷（E01–E16）

> **何时读**：① 写完风格声明、要落「可写句式」之前；② 要判断"这条风格到底稳在哪"时。
> **读完回哪**：回 `style-library-*` 对应条目，把内核翻成可写句式。
>
> **本册是什么**：**每条风格「剥掉题材之后仍然成立」的那套语言**——由 `_refs/<编号>/` 里的**真实参考帧**逐图反推、
> 再交叉比对求交集得来（方法 → `reverse-prompt-method.md` §2 七层反推 · §6 三图比对）。
>
> **三条纪律**：① **内核一律来自真实像素**，每条标注用了哪几帧；没有图就不填。
> ② **内核是关系句、不是形容词**——判据：**换掉题材它还成立**。
> ③ **证据分级**：疑似宣传照 / 概念图 / 错片的帧**标注并剔除**，不作内核证据。
>
> **同系列其他册**：`style-cores-e1.md`（E01–E16） · `style-cores-e2.md`（E17–E18）

## E01 · 中国青绿山水

**用帧**：`_refs/E01/` 02（景物｜全幅·整卷装裱全貌｜暖赭绢底主导）· 06（景物｜长卷中段·群峰与村舍桥梁｜冷青绿主导）· 08（景物｜尾段局部·峰峦与木桥亭阁｜青绿与赭石并置，笔触与绢纹可辨）

**视觉语言**：以石青、石绿在赭黄绢底上叠出"峰尖—坡身—水岸"的三条横向带，色块按矿物颜料的自身重量分层，越冷越靠上、越暖越靠下，山体因此不靠受光塑形而靠色相分层成立。远近不由单点消失决定，而由"前山遮后山"的层叠遮挡加水面留白决定，同一横断面可以并存数条视平线。可迁移的核心是：任何形体先被压成一个可平涂的色块单元，再按色相分层横向堆叠，而非按光影体积排列。

**叙事气质**：世界是横向展开、可被无限续接的，观看者是缓慢移动的过客，画不设唯一入口也不设终局，目光沿绢面横移即完成观看。人物只是山水中极小的一笔，与树、桥、亭同为尺度刻度，不承担任何中心职能。

**情绪基调**：上限是辽阔而自足的静气——天地不因谁在场而改变；下限是无人称的清冷。[观察到] 它从不做的一件事，是使用单一光源或强明暗对比去制造戏剧性瞬间，也从不给任何局部以情绪化的高光。

**换题材测试**：换成城市天际线、工业管道、珊瑚礁、星系云带，或任意连续的景观剖面，只要坚持"色块分层 + 遮挡定远近 + 横向可续接 + 矿物色平涂"，这套语言照样成立。

**★ 存疑（已剔除）**：8 张均为无画框、无玻璃反光、无参观者的本体平扫 [观察到]，本目录 0 张展品照。01、02 是整卷全貌（极窄长，细节不可判读，仅用于确认全幅比例与装裱），07 为尾段题跋与印鉴区（含后人题跋文字，不作画面语言证据）[推断]。剔除这三张后，内核由 03、04、05、06、08 五张干净绢本扫描支撑。

## E02 · 中国工笔重彩

**用帧**：`_refs/E02/` 06（人物｜全幅·长卷平扫，横向动作序列最完整｜暖赭黄绢底）· 05（人物｜局部特写·捣练四人持杵｜棕褐底，中性偏暖，绢面剥落最清楚）· 07（人物｜局部·熨练五人组｜暖赭底上出现石青石绿冷色衣裙，绢纹与印鉴可见）

**视觉语言**：线是骨架，色是填充——所有形体先用匀细的铁线勾出闭合边界，再在边界内平涂矿物色，色不越线、线不被色吃掉，因此轮廓永远比体积先被读到。体积只用"同一色相的深浅两阶"表达：衣褶凹处加深一道、凸处留原绢色即算亮部，不设受光面。构图以"横向并列的等距人物组"为单位，人物之间靠道具（长绢、木杵、熨斗、方箱、火盆）搭出实体连接线，形成一列可读的动作序列而非一个中心场面；人物身高一致、视线互不交叉，画面因此极稳。

**叙事气质**：世界是被反复、均匀、可重复的手工劳动，观看者是站在略高平视位、与画中人保持约一臂距离的旁观者。它不邀请你进入，只邀请你逐段核对手势，时间在画中被处理成"工序"而非"情节"。

**情绪基调**：上限是从容、明亮、有秩序；下限是无声、无色情、无高潮的冷静。[观察到] 它从不做的一件事，是不使用投影与光源方向，也不给人物面部任何超出手势所需的表情强度。

**换题材测试**：换成现代流水线、手术室、实验室、厨房，或任何"多人 + 手工 + 序列动作"的题材，只要坚持"匀线闭形 + 平涂矿彩 + 同色两阶塑体积 + 横向等距并置"，语言仍成立。

**★ 存疑（已剔除）**：E02/04 是 1898 年《The Bombay Gazette》整版报纸，与《捣练图》完全无关，[观察到] 直接剔除为 [推断：无关图]。其余 01（整卷含题跋全貌，仅作比例参照）、02、03、05、06、07 均为无画框、无玻璃反光、无参观者的本体平扫，本目录 0 张展品照。剔除 04 后，内核由 02、03、05、06、07 五张支撑 [推断]。

## E03 · 敦煌壁画

**用帧**：`_refs/E03/` 01（纯纹样｜藻井与边饰满铺·无中心｜石绿与土红冷暖并置）· 02（人物｜千佛列像·网格重复式满铺｜土红暖底 + 石青石绿佛衣，冷暖并置）· 03（人物｜一佛二菩萨·单组中心式｜土黄暖棕底，裂缝与剥落清晰）

**视觉语言**：底色先被整片铺成一块土红或土黄的地仗，所有形象都"贴"在这块暖地上，因此画面从不存在天空、地面、远景这类空间层级，只有"底 + 形"两层关系。造型靠粗重轮廓线加单层平涂色块完成，体积只用一道外侧晕染带暗示，这道带不指向任何光源方向；佛衣、头光、背光被赋予逐格固定的矿物色序（石青—石绿—朱—白）并无限重复，重复本身即构成图案与节奏。可迁移的核心是：以"暖地仗 + 固定色序 + 可无限重复的单元 + 粗轮廓平涂"把任何题材转化为可满铺的纹样场。

**叙事气质**：世界是被秩序固定的、已成定局的世界，观看者被安置在仰视并沿墙横移的位置上——画不为观看设置焦点，而为环绕设置密度。它不讲述，只作在场的证明。

**情绪基调**：上限是沉着的庄严与时间压强，地仗的开裂、剥落与褪色都被当成画面自身的一部分；下限是近乎无人味的重复与静。[观察到] 它从不做的一件事，是不使用焦点透视与单一光源（因此没有投影逻辑），也不让任何单个形象超出"单元"规格去争夺视线。

**换题材测试**：换成星座图、芯片阵列、人群合影、商品陈列墙，或任何"同一单元无限重复并需要庄严感"的题材，只要坚持"暖地仗 + 固定色序 + 无中心满铺 + 粗轮廓平涂"，语言仍成立。

**★ 存疑（已剔除）**：E03/04 为壁画残块嵌在现代混凝土基座与木栏之间的陈列照（[观察到] 有外框、强阳光斜射），E03/05 带明显装裱边条、疑为嵌板或图册页翻转照（[观察到] 边条与摄影水印），两张均标 [推断：展品照，非本体]，不作内核证据；E03/06 是莫高窟外景（[观察到] 现代栏杆、地砖、蓝天沙砾），判为无关图直接剔除。另有两点未决：02 左下带摄影署名水印、03 右上带版号「1-1」，其"是否为图册或网页配图"**不可判定**，故 02、03 只作色调与绘制工艺的辅助证据，构图主证以 01 为准。若从严只认 01（及 02），第三帧不成立，但已满足"至少两张本体平扫描"的门槛，内核仍立 [推断]。

## E05 · 浮世绘

**用帧**：`_refs/E05/` 08（景物｜全幅平扫｜粉橘天空，暖极）· 02（景物｜全幅平扫｜冷灰天空、群青最饱和，冷极）· 07（景物｜全幅平扫｜米黄暖底、留白云形最明显，木版刀痕与套色错位相对可辨）

**视觉语言**：以一条明确的黑轮廓线把形体切成若干"色域块"，每块只上一次平色，块与块之间绝不做渐变过渡（指形体的色域块；天空的 bokashi 渐变除外）——层次感全部由色块的边缘形状承担，而不由明暗或大气透视承担。全画由一道对角动势统摄：巨浪自左上垂落，右侧浪谷与远方山体形成反向对压，所有纹理（浪花爪、飞沫点、船板格、水纹线）都是重复的短促笔触单元，按密度排列而非按光影排列。天空是唯一不参与造型的底色场，固定做成由暖到冷的平染渐变，用来给前景的纯色块让路。

**叙事气质**：世界是被高对比度瞬间定格的，观看者被安放在一个现实中不可能的位置——比浪高、比船近、与山齐平。它给观看者的距离是"惊险但安全"，允许你在灾难的一步之外把整个过程看完。

**情绪基调**：上限是雄浑、绷紧、几近失控的动势；下限是图案化的整齐与装饰性的冷静。[观察到] 它从不做的一件事，是不使用写实塑形——没有真正的体积、没有统一光源、没有透视消点，浪的危机也从不改变画面的秩序。

**换题材测试**：换成暴雨中的城市、赛车、雪崩、拥挤人群，或任何"强大自然力 vs. 微小承受者"的题材，只要坚持"黑轮廓线 + 纯平色块 + 对角动势 + 重复纹理单元 + 暖冷渐变天空"，语言仍成立。

**★ 存疑（已剔除）**：E05/03 是展馆悬挂照（[观察到] 可见挂线固定件、深色展墙、照明造成的反光），标 [推断：展品照，非本体]，不作证据。其余 01、02、04、05、06、07、08 均为无画框、无玻璃、无参观者的本体平扫，是同一图样的不同版次印次，其中 01 右下角带藏品编号，属馆藏片扫描。需说明：本目录 8 张全为同一图样整幅，**题材轴与构图轴无法拉开**，只能靠版次色差拉开色调两极，故选帧为 08（暖）／02（冷）／07（中偏暖）[推断]。

## E06 · 日本装饰屏风

**用帧**：`_refs/E06/` 04（景物｜全幅·金地大面积留白那只屏｜暖金主导）· 05（景物｜全幅·桥与栏杆横贯、带金襕表装｜金地之上群青与石绿，冷暖并置）· 07（材质与笔触特写｜金箔拼缝、叶尖湿笔停顿、落款与朱文圆印｜暖金）

**视觉语言**：金箔拼成的镜面底决定了全部语言——植物不是"长在地上"，而是"浮在金子上"，画面主动拒绝了地面线、天空和一切纵深，只剩"贴面的形 + 金底"这一层关系。花与叶被简化为可重复的"月牙—披针"符号，以极少的平色（群青、石绿、青绿）用湿笔一次性拉出，颜料的流痕与停顿本身就是造型边缘，绝无二次修饰。节奏靠"群—空—群"的水平疏密交替，再加一道折线（桥与栏杆）横穿来达成，全画没有焦点，也没有消点。

**叙事气质**：世界被压成装饰平面，它拒绝叙事、也拒绝被"看进去"。观看者被放在屏风正前方一臂余的固定位置——这是为房间、为墙面写的画，观看者不是进入者而是被包围者；时间也被取消，花不开不谢，永远停在同一个时刻。

**情绪基调**：上限是华丽而克制、富贵而不喧哗；下限是冷香与近乎无人味的静谧。[观察到] 它从不做的一件事，是不做明暗、不做透视、不做纵深，也不把花画成真实植物——形态一律服从笔画与平面分割。

**换题材测试**：换成枫叶、鹤群、几何条带、抽象色块，甚至城市招牌，只要坚持"贵金属底 + 拒绝地面线 + 符号化重复单元 + 流动性湿笔 + 群空交替的横向节奏"，语言仍成立。

**★ 存疑（已剔除）**：E06/01 为暗底双屏并置的展陈照（[观察到] 屏间缝隙与深色展墙），标 [推断：展品照，非本体]；02 与 03 是同一图像的重复下载，只计一张。其余 04、05、06、07、08 均为本体平扫，无画框玻璃、无参观者，其中 06、07 含金襕表装与木框边缘，属"带装裱的本体"而非展柜照。**不可判定**：本目录未说明各屏的对应关系，"04（无桥）与 05／08（有桥）是否同属一双、02／03／04 是否为同一只屏的不同扫描"，据现有画面无法判定，故本文只描述可见结构，不指认屏只编号 [推断]。

## E07 · 千利休茶室

**用帧**：`_refs/E07/` 02（景物｜室内一角·坐姿视高整幅｜暖褐木色+榻榻米草黄，窗外苔绿作冷极）· 06（景物｜床之间单元素特写｜低照度暗暖，土墙吸光）· 03（景物｜露地柴门与竹篱整幅｜阴天苔绿+土黄中性偏冷）（可选帧偏少，室内本体仅 02、06 两张）

**视觉语言**：世界里没有会反光的表面——土壁、木、纸、榻榻米全部以吸光方式呈现，光不从任何方向射来，而是被障子纸滤成无影的漫射（02、06 中明暗均来自物件自身的吸光深浅，而非画出的或打出的光）；空间被坐姿视高压低，室内外不靠窗洞相通而靠障子纸"过滤"，06 的床之间则把整个世界压缩成一壁土墙、一管花生、一幅字轴的三角关系。可迁移的核心是：以吸光材质+漫射无影光+坐姿低视高+障子式半透明分层，把任何题材做成"静观一隅"。

**叙事气质**：它看待世界的方式是删减到只剩一件值得看的东西为止，观看者被安置在跪坐的位置上，与物的距离是一臂之遥、必须凑近才能看全。

**情绪基调**：上限是佗寂中的郑重——暗不是死黑而是土与木在自己呼吸（06 的"洗心"字轴在微光里仍可读）；下限是近乎空的、无人气的静。它从不做的是：不设对称轴线、不给任何一件器物打方向光、不让室外景色完整地闯进来。

**换题材测试**：换成一碗茶、一把铁壶、一个人的低照度肖像，或任何"需要把世界删到一隅"的题材，只要坚持吸光材质、无影漫射、坐姿视高与一物一景的床之间式构图，语言仍成立。

**★ 存疑（已剔除）**：01 为茶室外观资料照但带 [观察到] 电线与修剪草坪的现代庭园环境、07 为 [观察到] 柏油路、电线与现代住宅包围下的茶室门户现场照，两张均作外观旁证不作内核证据；08 为 [观察到] 芬兰堡石砌要塞照，判无关图直接剔除。剔除后内核由 02、03、04、05、06 支撑，其中 02、06 为室内本体主证。
