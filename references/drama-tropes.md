# 套路与叙事模式库：已被验证有效的形状

> **何时读**：定了题材之后、选结构模型之前（**先认名，再谈变形**）；写不出冲突时（直接查 §4 的角色配置）；想"这部片凭什么不一样"时（查 §6 的三种用法）。
> **读完回哪**：创意手法 → `drama-plotcraft.md`；换算成秒 → `drama-scaling.md`；选骨架 → `drama-structure-models.md`。
> **定位**：本册是**素材库**——列出**文学与戏剧史上被反复验证有效的形状**，每条给：**引擎 / 情感承诺 / 适用档位 / 失效条件 / 怎么变形才不平庸**。

---

## §0 用法三条纪律

1. **套路是引擎，不是曲谱。** 引擎告诉你"靠什么转起来"，不告诉你"每一分钟发生什么"。
2. **先认名，再动手。** 说不出自己用的是哪一条套路 → 结构是飘的（`drama-plotcraft.md` §5 第 ⑨ 问）。
3. **★ 认名之后必须回答两问**：**我改了哪一条规则？观众最俗的预期是什么、我做了什么与它不同？** 答不出 → 只是复述套路（同 §5 第 ⑦⑩ 问）。

**三张经典清单的关系**（都在描述同一片天空，只是切法不同）：

| 清单 | 切的是 | 颗粒度 | 本册怎么用 |
|---|---|---|---|
| **Booker 7 种（+2）** | **情感结构**（故事走什么弧） | 最粗 | 定"整部片让人经历什么" |
| **Polti 36 种** | **角色配置**（谁对谁、为哪样东西） | 最细 | **写冲突时直接取**（每次一个三元组） |
| **Tobias 20 种** | **驱动力类型**（动作驱动 / 角色驱动） | 中 | 定"靠动作推还是靠变化推" |

## §1 Booker 七种（+2）：情感结构层

**来源**：Christopher Booker《The Seven Basic Plots: Why We Tell Stories》(2004，写作历时 34 年)。**他主张所有故事都落在这七种弧里**；书末又补了两种（**Rebellion** 与 **Mystery**）。**"七"这个数目最早由 Arthur Quiller-Couch 提出，Booker 是集大成者。**
**已知批评**（必须标注）：书后半部的荣格心理学论证被批评为"以理念压过证据"；但**前半部的情节归类本身被广泛使用**。**引用时按"归类工具"用，不按"心理学定律"用。**

| # | 情感结构 | 引擎 | 主角的弧 | 失效条件 |
|---|---|---|---|---|
| **1** | **斩妖除魔** | 有威胁者威胁共同体，主角与它对抗 | 从普通 → 胜利者 | 威胁**不可怕**（没有真正的代价）→ 退化为打斗 |
| **2** | **从穷到富** | 主角被低估 → 显露 → 失去 → 复得 | 从被忽视 → 被承认 | 只写"变富"不写**失去**那段 → 变成爽文 |
| **3** | **探寻** | 主角与同伴去取一件极重要的东西 | 从想得到 → 变得不同 | 目标物**不重要**（只为跑动而跑动）→ 变成旅游 |
| **4** | **远行与回归** | 进入陌生世界 → 受试 → 逃回 | 从熟悉 → 带着理解回来 | 世界**没有规则**（想怎么变就怎么变）→ 变成流水账 |
| **5** | **喜剧** | 误会与错认累积 → 澄清 → 结合 | 从混乱 → 和解 | 误会在中途就被澄清 → 后面无处可去 |
| **6** | **悲剧** | 主角的缺陷或大错 → 自毁 | 从光亮 → 坠落 | 缺陷**不是他自己造成的** → 变成受害者故事（同情错位） |
| **7** | **重生** | 主角被困住（魔咒 / 病 / 执念）→ 解脱 | 从封闭 → 复苏 | 解脱**不来自内在变化**（靠外力）→ 变成奇迹故事 |
| **+1** | **反抗** | 个体对系统，系统不因个人而改变 | 他不变（**平弧**），周围被他撬动 | 系统**被个人轻易改变** → 变成童话 |
| **+2** | **谜** | 一个待解的问题（侦探传统的源头） | 从不知 → 知 | 答案**不回扣已有的可见物** → 变成作弊（`drama-genre-casebook.md` §2） |

## §2 Tobias 二十种：驱动力层

**来源**：Ronald B. Tobias《20 Master Plots and How to Build Them》。**核心贡献是把二十种按"动作驱动 / 角色驱动"分家**，并要求作者**在动笔前就知道自己在写哪一类**——分家错了，比例就错（动作片里花一半篇幅写内心，两边都不讨好）。

**动作驱动（主角不必大幅改变；唯一例外＝探寻，见下）**

| # | 套路 | 引擎 | 关键件 |
|---|---|---|---|
| 1 | **探寻** | 找一个人 / 地 / 物 | **主角必须变**；目标物是"智慧"的载体；同伴不可省 |
| 2 | **冒险** | 行动本身 | 允许"为动而动"；改变较小 |
| 3 | **追逐** | 追与被追 | 需要**明确的追逐规则** + 一个不断收窄的场 |
| 4 | **营救** | 有人被抓 → 释放 | 主角 / 对手 / 受害者构成三角 |
| 5 | **逃脱** | 被关 → 逃 | 与营救互为镜像；可接一段追捕 |
| 6 | **复仇** | 受了冤 → 讨回 | 靠**道德义愤**取得认同；复仇者会越界 |
| 7 | **谜** | 先解出答案的是观众还是主角 | 允许"限时不解开就有后果" |

**角色驱动（主角必须改变）**

| # | 套路 | 引擎 | 判据 |
|---|---|---|---|
| 8 | **对抗** | 两个对等力量争同一样东西 | 零和；**开场要有一份"事前的秩序"** |
| 9 | **弱者** | 力量悬殊的竞赛 | 靠**执着**取胜；观众先要喜欢他 |
| 10 | **诱惑** | 拿了对他是损耗 | 战场在内部；**必须给"屈服"一个合理的声音** |
| 11 | **变形** | 身体或形态被改变 | 解脱来自**爱或代价**，不来自魔法 |
| 12 | **转变** | 被意外事件改变 | 有挫折；他学到的必须**在最后一拍用上** |
| 13 | **成长** | 长大 | 信念被挑战 → 换掉旧信念 → **付代价** |
| 14 | **爱情** | 找到彼此 | 必须**受试**（有障碍）；障碍不成立则无戏 |
| 15 | **禁忌之爱** | 打破一条社会规则 | **通常以悲剧收**（与"爱情"分家的关键） |
| 16 | **牺牲** | 他给出去的远多于常人 | 他**起初并没有打算牺牲** |
| 17 | **发现** | 他发现了大事 / 坏事 | 发现之后必须**做一个困难的选择** |
| 18 | **过度**（wretched excess） | 无节制 → 失控 | 主角通常是磁性的、压倒性的 |
| 19 | **上升** | 变得更好 | 与"下沉"同构，方向相反 |
| 20 | **下沉** | 变得更好之后变坏 | 要有一个**越界前的道德困境** |

> **★ 与本库的接口**：这张表的最大用处是**校准**——"我以为我在写 A，其实我在写 B"。**这类误判极常见**（公开教学案例：以为是"英雄拯救"，其实是"复仇"；以为是"爱情"，其实是"禁忌之爱"）。**校准发生在 M2（前提）与 M5（骨架）之间。**

## §3 Polti 三十六种：角色配置层（**写冲突时直接取**）

**来源**：Georges Polti《The Thirty-Six Dramatic Situations》，19 世纪末（**两说并存，取常见口径 1895 年**；另有 1868 年之说；**受威尼斯剧作家 Carlo Gozzi 的同数清单启发**）。Polti 自己的立场是：**"36"不是魔法数字，换个粒度也能列出别的数目。**
**★ 它的价值在形式**：每条 = **一组角色 + 一样被争的东西**。写一场戏缺冲突时，**从这张表里挑一条换上本片的材料**，比空想快得多。

|---|---|---|---|

| | 5 | 追捕 | 惩罚者 · 逃亡者 |
| **灾祸与对抗** | 6 | 灾祸 | 被击败的强者 · 胜利的敌人或信使 |
| | 7 | 受残酷或不幸摆布 | 不幸者 · 主人或不幸本身 |
| | 8 | 反抗 | 暴君 · 阴谋者 |
| | 9 | 壮举 | 大胆的领袖 · 目标 · 对手 |

## §4 套路 × 时长适配（**先看能在哪一档用**）

| 档位 | 能直用的 | 只取机制的 | 提示 |
|---|---|---|---|
| **15–30 秒** | Polti 单一情境（如 1 求告 / 2 救援 / 36 失去所爱）· Booker ⑥悲剧的一个切面 | 探寻 / 成长 / 重生（太长，只取"一个瞬间"） | **一条情境 + 一个转折 = 一个短片** |
| **60 秒** | Booker ④远行与回归（压成"进与出"）· ⑦重生（压成"困与解"）· Tobias 7 谜（取"最后一次揭示"） | 多数可折叠（斩妖除魔压成"威胁现形 → 对抗"两拍即可用） | 见 `drama-scaling.md` §2 折叠表 |
| **3–15 分钟** | Booker ②从穷到富 · ⑤喜剧 · Tobias 6 复仇 / 9 弱者 / 14 爱情 | 探寻（可保留完整：有同伴、有障碍） | 开始需要"副线" |
| **45 分钟单集** | 全部可用；每集取一条情境 + 一条角色线 | —— | 每幕末留卡点（模型 15） |
| **长片** | 全部直用；**一条主套路 + 一条变奏** | —— | 主套路与副线**互为变奏**是同源技巧 |

> **★ 表格的 AIGC 适用性（2026-09-30 补）**：本表只解决"**装得下**"（叙事容量）——**AI 生成媒介还有自己的失效条件**：单镜内角色位 ≥3–4 的情境（如 32 求告无门 / 33 错认）单镜直出高风险，需拆镜或用引用锚强化身份；"内在转变"类（重生 / 坠落）须首尾帧或前后两镜承载，文字单镜写不出转变（→ `motion-control.md` / `feasibility.md`）。

## §5 三种"用套路"的方式（**创意就藏在这里**）

| 方式 | 做法 | 付什么代价 | 什么时候用 |
|---|---|---|---|
| **① 直用** | 照套路走，靠**具体性**取胜（`drama-plotcraft.md` §3） | 必须极具体，否则一眼看穿 | 短片档主力；观众要的是"看这一版怎么处理" |
| **② 变形** | **只改一条规则**（目标物 / 尺度 / 空间 / 失败的定义） | 其余零件必须还认得出 | 默认方式 |
| **③ 反向** | 故意把套路翻过来（救援其实是加害；复仇其实是被设计） | **必须给出比套路更深的解释** | 慎用：**翻过来如果不解释，观众判定为"乱来"** |

**★ 反向的三条判据**（缺一条就退回变形）：
1. **有前文铺垫**——反向成立的前提是"回头看信息都在"（公平性，与反转同一判据）；
2. **有更深的解释**——翻过来的版本必须回答"那原来那个套路为什么会出现"；
3. **有代价**——翻过来之后，主角要更难受，不是更聪明。

## §6 东亚与中国侧的几个模式（**惯例层，标注可信度**）

本库已有的 **起承转合**（汉诗绝句结构）与 **序破急**（雅乐 → 能乐的速度结构）见 `drama-structure-models.md` §7。补三条**文学史常识级**的模式：

| 模式 | 机制 | 适用 |
|---|---|---|
| **章回体** | 以"回"为单位，**每回末留悬置**（"且听下回分解"） | 多集 / 系列：**每集末钩子的老祖宗** |
| **公案** | 案发 → 勘验 → 冤情 → 昭雪；**读者常比官差先知道真相** | 悬疑的东亚变体：**信息错位的另一种默认配置** |
| **才子佳人** | 相遇 → 阻隔（礼法 / 门第）→ 团圆 | 与 Tobias 的"爱情 / 禁忌之爱"同构，**阻隔的形状不同** |

**⚠️ 诚实标注**：这三条属**文学史常见归类**，中文剧本领域**没有像美国那样的单一权威格式／情节标准**（同 `script-format.md` 对中文档的标注）；本库**只取多源一致的机制描述，不引具体二手论断**。

## §7 什么时候**不许**用套路

| 情形 | 理由 |
|---|---|
| **题材本身很新**（真的没人见过） | 先用 `drama-plotcraft.md` §2.6 的约束生成想清"它凭什么新"，再套形状 |
| **你只想用它省事**（"这样写保险"） | 保底套路 + 无具体性 = **观众读到的第一件事就是"应付"** |
| **套路与命题冲突** | 命题优先（`direction-reasoning.md` §十：推导结果优先于默认值） |
| **反向但没有更深的解释** | 见 §5 的三条判据 |

## 来源与署名

- **Booker 七种基本情节（2004，34 年成书，736 页）+ 书末补的 Rebellion / Mystery**：Christopher Booker《The Seven Basic Plots: Why We Tell Stories》。**"七"的最早提出者为 Arthur Quiller-Couch**——两处均为公开评述与公开课程材料中的通行表述（FutureLearn 公开课材料 · 期刊书评 · 公开文学评论）。**已标注其心理学论证部分的公开批评**（书评指其荣格框架"以理念压过证据"），本库**只取其情节归类**。
- **Polti 三十六种戏剧情境（19 世纪末；常见口径 1895，另有 1868 之说；受 Gozzi 启发；Polti 自称"36 非魔法数字"）**：Georges Polti《Les Trente-Six Situations Dramatiques》，**全书已进入公有领域**；本库按其**角色配置三元组**逐条重写，**未复制原文表述**；36 条的完整性与编号经**多源交叉核对**（百科条目 · 公版全文站 · 书摘）后一致。
- **Tobias 二十种主情节 + 动作驱动／角色驱动分家 + "作者须在动笔前知道自己在写哪一类" + 探寻的完整写法**：Ronald B. Tobias《20 Master Plots and How to Build Them》，经多份公开读书笔记与教学资料交叉核对（含其"误认类型"的公开教学案例）。
- **"叙事只有两种"**（一个人去远行／一个陌生人来了）与 **Booker 理论的公开质疑**：公开文学评述。
- **中式三条模式（章回体 / 公案 / 才子佳人）**：**文学史常识级归类**，本库只取机制描述，**标注为惯例层**（理由同 `script-format.md` 的中文档标注）。
- **本库自建**：§0 三张清单的"切法"对照与三问纪律 · §1 每条的情感结构表与失效条件 · §2 两张驱动分表与"校准"用法 · §3 **按家族重排的 36 条角色配置表**（原书为线性编号，本库按引擎归族以便取用）· §4 套路 × 时长适配表 · §5 三种用法与**反向的三条判据** · §6 东亚三条与可信度标注 · §7 四条禁用情形。
- **不采用**：把任一张清单当作"万能配方"逐条填满（与 `direction-reasoning.md` §一 的判据冲突）；无许可证的社区类推库（如 TV Tropes）**只作线索、未取用其词条文本**。
