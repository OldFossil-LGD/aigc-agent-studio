# 剧作 → 提示词的转换层（**本层存在的唯一理由**）

> **何时读**：**动笔写任何提示词之前必读**；写完提示词自查时。
> **读完回哪**：回 `shot-craft.md` 填 12 块；回 `block-playbook.md` 逐块思考。
> **一句话**：**模型不认识"弧光、潜台词、主题、反转"这些词。这些概念必须先在作者脑子里变成结论，再落成可见物，才能进提示词。**

---

## §0 三种语料（与 `lexicon-map.md` §0 的三分类**同源，本层是它的剧作版**）

`lexicon-map.md` §0 已定：**术语词给模型 · 可写句式整句粘 · 判断参数只给作者**。剧作概念按同一把尺分三档：

| 档 | 是什么 | 进提示词吗 | 例 |
|---|---|---|---|
| **甲 · 可直写** | 本来就是可见/可听之物 | ✅ **直接写** | 距离、遮挡、朝向、开门、松手、背对镜头、镜中位置不同 |
| **乙 · 可翻译** | 是判断，但能**一对一**换成可见物 | ✅ **翻译后写** | 弧光 → 同构图两次 · 潜台词 → 答非所问的动作 · 权力关系 → 谁占画面中心 |
| **丙 · 不可写** | 是**作者的坐标系**，没有对应的可见物 | ❌ **一律不写** | 三幕、节拍、beat、turning point、premise、want/need、logline、伏笔、笑点（**悬念**的拆层见 §1——"信息结构＝丙 / 悬念感＝乙"两 层，此处的"悬念"指未拆层的概念整体） |

> **丙类的唯一去处**：**填进【4 本镜目的】与【12 过渡压力】的"思考"，不进提示词的"文字"。**
> **判据一句话**：**一个只看画面、不懂剧作的观众，能不能看出这个词？** 不能 → 它是丙类。
> **台词一行（2026-09-30 补）**：**台词＝甲类逐字写**（写定不改字）；确定台词配 TTS 的，视频 **sound 设 off**、音频节点在合成端混入（→ §7 台词与声音的平台分工）。

## §1 可写性分档表（**把这些词从提示词里赶出去**）

| 剧作概念 | 档 | 落点 |
|---|---|---|
| **人物弧光** | 乙 | 首尾**同一构图** + 他做的是相反的事 |
| **内在冲突 / 犹豫** | 乙 | 手伸出去又收回；物件被推回去一寸 |
| **潜台词** | 乙 | 回答上一个问题；把物件转向自己；说 A 做 B |
| **主题 / 命题** | **丙** | 只进【4 本镜目的】；由高潮的动作支付 |
| **三幕 / 节拍 / beat** | **丙** | 只进导演推理与节拍表 |
| **激励事件 / 催化** | 乙 | 一个**画面内的外力**（一封信落地、门被撞开、手机亮起） |
| **中点 / 转折点** | 乙 | **同一空间里的一样东西变了**（多/少/换位/变状态） |
| **悬念（拆两层）** | **信息结构＝丙 / 悬念感＝乙** | "谁知道什么"的配置只进思考（丙）；**悬念感落成可见动作**（乙）：看向画外、门口在画面外（写法见 §6） |
| **伏笔** | **丙** | 靠**物件在早期出现且被看见**实现；画面层只写"这个物件在，且在画面里" |
| **反转** | 乙 | **同一构图、第二次出现时少了一样东西** |
| **人物关系（亲密/断裂）** | 乙 | **同框 = 关系在；分开的单人镜 = 关系断**（`direction-reasoning.md` §六） |
| **权力关系** | 乙 | 谁占画面中心、谁被压到边缘、谁被前景遮挡 |
| **内心（他真正想要的）** | **丙** | 只进【4 本镜目的】；画面层给他**朝向那个东西的身体** |
| **节奏 / 能量** | 乙 | 镜长、光的变化幅度、环境声的密度（`direction-reasoning.md` §七） |
| **情绪（他很难过）** | 乙 | **情绪词必须翻译成形变**（`SKILL.md` 三步硬纪律 ②） |
| **笑点** | 乙 | 建立—回响：同一动作做三遍，第三遍变异 |
| **时代 / 社会阶层** | 乙 | 陈设、材质、磨损、颜色（进【7 人物与环境】） |
| **类型（这是恐怖片）** | **丙** | 只进选型与结构；画面层写具体威胁 |

|---|---|---|
| 他在犹豫 | **9 时间线** | `手伸到一半停住，指尖离桌面还有一寸，停了很久才收回去` |
| 他在隐瞒 | **9 时间线** | `他把那封信翻过来扣在桌上，先看窗外，再回答` |
| 他们关系断了 | **6 构图** | `两人分处画面两侧，中间隔着整张桌子的空位，各自只有单人镜` |
| 权力在他手里 | **6 构图** | `他正对镜头坐在画面中心，另一人被压到画面右缘，肩膀被前景切掉一半` |
| 他快要崩溃 | **5 镜头规格 + 10 摄影机** | `中近景，机位贴近面部高度，极缓的推近，全程不动` |

| 时间在流逝 | **8 光位与影调** | `窗格投在地上的影子从画面左缘移到右缘，屋内其他照明不变` |
| 环境在压迫他 | **7 人物与环境** | `天花板很低，横梁在画面上方压进三分之一，人物必须低头才能通过` |
| 转折发生了 | **9 时间线 + 7 人物与环境** | `桌上的碗从三个变成两个，位置没动` |
| 他改变了 | **6 构图 + 9 时间线** | `与开场完全相同的机位与构图，他把那扇门拉开了` |
| 他放弃了一个东西 | **9 时间线** | `他松手，东西落到地上，没有去捡，转身走出画面` |
| 他做了决定 | **12 过渡压力** | `他在这一镜的最后一个动作是抬脚向前；下一镜从他的脚落地开始` |
| 这是威胁 | **11 声音** | `门外传来金属摩擦声，由远及近，人声没有出现` |
| 危险在逼近 | **10 摄影机 + 11 声音** | `机位不动，画面内的物体开始轻微震动，低频噪声逐渐增大` |
| 他心里有事 | **9 时间线** | `他反复擦同一块已经很干净的玻璃，擦了三遍` |
| 他注意到了什么 | **9 时间线 + 12 过渡压力** | `他的视线从桌上移到门口，停住；下一镜从他的视线落点接上` |
| 他在说谎 | **11 声音 + 9 时间线** | `他说完没有停，立刻起身去关窗，背对镜头` |

**★ 三条使用纪律**：

1. **一块只装该块的事**——把"关系断了"写进【9 时间线】就会被读成一个动作，不会变成构图（→ `block-spec.md`）。
2. **句式只作参照，落笔必须重推**——照抄会产生"填空模板"（用户明令禁止）；句式的作用是告诉你**这句话长什么样**。
3. **同一意图不要在两块里重复写**——重复会被模型读成"要强调"，从而把它演成动作。

## §3 结构功能 → 该给什么镜（**节拍落地的最小映射**）

**用法**：节拍表定完之后（`script-craft.md`），逐拍查这一行，得到"这一拍该是什么镜"的**起点**；之后照常走 `shot-orchestration.md` 与 `direction-reasoning.md`。

| 拍的功能 | 镜的起点 | 为什么 |
|---|---|---|
| **建置 / 常态** | 固定机位 · 全景或中景 · 时间给够 | 常态需要"可比较的基准"，基准越稳，后面的变化越可读 |
| **裂缝出现** | 同机位不动，**画面内多一样或少一样东西** | 变化必须发生在**同一个坐标系**里才可读 |
| **催化** | 一个新元素**从画框外进入**（人或物） | 外力的"外来性"由画框边界表达 |
| **主动选择** | 他**朝一个方向走出画** | 方向＝动机，离开画框＝不可撤回 |
| **中点（假胜利）** | 稍高的机位 · 更开阔的构图 | 空间变开阔 ≈ 他以为自己赢了 |
| **中点（假失败）** | 稍低的机位 · 被前景挤压 | 空间被压缩 ≈ 他退无可退 |
| **谷底** | 最紧的景别或最空的构图（二选一，不要中间值） | 谷底要极端；中间值读不出情绪 |
| **支付 / 终局** | **回到建置的机位构图**，但内容相反 | 观众用"同一个框子里不同的东西"读出改变 |

> 表内"时间给够"等指**叙事时间预算**：**按台词字数＋动作节拍估秒**（中文 3.5–5 字/秒），秒数须落在所选模型时长档位内，**超容量拆镜**——秒数只进排镜表，不进提示词。

## §4 三种外化套路（**AI 短片的三把通用扳手**）

| 扳手 | 机制 | 可复制句式 |
|---|---|---|
| **物件** | 心理变化落在**一个物件的状态/位置**上 | `那只碗始终摆在桌角，位置从开场到结尾没有变过，只有碗里的东西从满到空` |
| **距离** | 关系变化落在**两人之间的空间**上 | `开场两人并排坐在同一张长椅上，结尾同一张长椅，中间空出一个人宽的位置` |
| **重复** | 改变落在**同一动作的第二次执行**上 | `同一个动作：他进门先摸一下墙上的开关。第二次做这个动作时，他没有摸到，因为开关的位置上是一个洞` |

**三条纪律**：

1. **一次只用一把扳手**（三把混用 = 观众抓不到主轴；**反转类的同机位复现属构图呼应，不算第二把扳手**——见 §6 反转例）。
2. **同一物件/位置/动作全片不许换说法**——措辞改写本身就是漂移源（`character-continuity.md` 的判据）。
3. **它必须能跨镜被认出来**——所以选择**外形最不容易漂的东西**（几何形状明确的物件 > 复杂人形）。

## §5 "模型能懂吗"——五问（**每写一句都过**）

```text
① 这句话描述的是一个可以被看见或听见的东西吗？（不是 → 删）
② 它是不是剧作术语？（是 → 丙类，赶出去）
③ 它有没有指向两个以上的动作？（有 → 拆句，一镜只许一个主动作）
④ 如果模型照着这句话自由发挥，最坏会做出什么？我能接受吗？（不能 → 补一句正面状态句，见 quality-layer.md §四）
⑤ 划掉全部形容词之后，剩下的是名词和动词吗？（不是 → 还有判断参数混在里面）
```

## §6 反例图鉴：术语直接进提示词的七种写法与改法

| ❌ 写进提示词 | 模型会做什么 | ✅ 改成 |
|---|---|---|
| `这场戏体现人物弧光` | 无事发生（不可执行） | 删；在【4 本镜目的】里写"这一镜他第一次主动伸手"，画面写动作 |
| `要有潜台词` | 无事发生 | `他回答的是上一个问题` |
| `体现主题：孤独` | 可能出现象征物滥用 | `画面里只有他一个人，两副碗筷只用了一副` |
| `这是全片的反转点` | 无事发生 | `与上一镜完全相同的机位，桌上的碗从三个变成两个` |
| `制造悬念` | 可能出现雾气、暗角等套路化处理 | `他抬头看向门口，门口在画面外` |
| `他陷入内心冲突` | 可能出现夸张表情 | `他站在原地不动，手先伸向左边，又收回，最后什么都没拿` |
| `节奏要快` | 可能出现抖动与模糊 | `三个画面：手抓门把、门开、门内空屋，每个画面都短` |
| `参考《××》的光` | **可能触发平台 IP 过滤** | 换成风格描述（光源、色温、明暗结构） |

- **"同框＝关系在 / 分开＝关系断"· "接近真相收紧、逃避给空间"· "认同谁镜头就架在谁肩上"**：`direction-reasoning.md`（**权威源，本文只引用**）。
- **"参考片名会被平台过滤"**：本库既有结论（`key-decisions.md` 三·明确不改：影片锚点不直写）。
- **"内心冲突外化到物件与空间关系"**：`key-decisions.md` C42（**本库自建立场 · Conventional · 未实测**）。
- **本库自建**：可写性**三档（甲乙丙）在剧作概念上的完整分档表** · §2 十七行翻译表（含"落在哪一块"）· §3 结构功能→镜的起点映射 · §4 三把扳手（物件/距离/重复）与三条纪律 · §5 五问 · §6 八条反例图鉴。
