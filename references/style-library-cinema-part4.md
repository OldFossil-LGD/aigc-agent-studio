# 风格库 · B 卷四：当代作者导演补编（B51–B60）

> **何时读**：`style-library.md` 筛到「电影」分类，而 B 卷三（B41–B50）里没有合适条目时。
> **读完回哪**：回 `style-library.md` 定案，再去 `camera-package-library.md` 选拍摄方案包。

### B51 · 是枝裕和（日本）
**识别**：家人的距离，用一扇门和一碗饭说清。
- **核心视觉**：**低机位固定镜**；人物常被门框、走廊分隔；**不介入的凝视**
- **色彩光影**：日常的自然光；室内偏暖；夏天有风扇与纱帘透进来的光
- **构图材质**：**生活物件在画面里占大位置**（饭桌、碗、洗衣机）；房间的层次
- **节奏**：**慢而从容**；一个吃饭的镜头可以很长；不追求戏剧高潮
- **声音**：环境声为主（水、风扇、脚步）；**配乐少**；沉默的相处
- **参考作品**：《步履不停》《小偷家族》《海街日记》
- **适用场景**：家庭、日常、亲情、离别、四季
- **可写句式**：`低机位固定在走廊一侧，人物被门框分隔在两个空间里；纱帘把夏天的光滤成一片白；桌上摆着饭菜；画面安静，只有风扇在转`
- **★ 质感与痕迹**：`固定中景、门框里的一家人` · `室内的自然光与饭桌的顶灯` · `日常物被完整交代：饭、衣服、拖鞋`
- **★ 最容易被写歪成什么**：`特写脸部` · `运镜强调` · `戏剧化配乐感`

### B52 · 李沧东（韩国）
**识别**：一个普通人被生活慢慢推入愤怒。
- **核心视觉**：**克制的中景**；摄影机保持礼貌的距离；暴力突然出现在日常里
- **色彩光影**：**自然的脏与脏的暖**；室内昏黄；阳光有时刺眼
- **构图材质**：人物常在门口、窗口、工地；**环境里有未完成的东西**（半建楼、塑料布）
- **节奏**：**前慢后快**——积累到某个点后节奏崩掉
- **声音**：日常噪声（车、工地、电视）；配乐极少
- **参考作品**：《燃烧》《诗》《绿洲》
- **适用场景**：阶级、愤怒、乡村、暴力
- **可写句式**：`人物站在未完工的楼里、身后是塑料布与钢筋；午后的光很硬、照得一侧脸发白；环境里全是生活的噪声`
- **★ 质感与痕迹**：`人物在空间里被挤住、门与墙做框` · `低照度的暖褐与青灰` · `长镜与沉默的等待`
- **★ 最容易被写歪成什么**：`手持` · `明快的光` · `快速剪辑`

### B53 · 洪常秀（韩国）
**识别**：喝了很多酒，说了很多话，第二天再来一次（略有不同）。
- **核心视觉**：**突然的数码变焦**（推上去再推回来）；摄影机随意但精准
- **色彩光影**：**日常、平、不修饰**；餐厅与街道的普通光；冬天偏灰
- **构图材质**：**对话场景的简单正反打**；画面朴素
- **节奏**：松散、生活化；**结构上做重复与变奏**（同一情境两次）
- **声音**：**对白是全部**；环境声真实；配乐常只有一首（重复使用）
- **参考作品**：《这时对那时错》《独自在夜晚的海边》《小说家的电影》
- **适用场景**：文艺圈的对话、酒桌、尴尬、冬天
- **可写句式**：`两个人坐在小馆子里说话，画面朴素、光是哪算哪；镜头忽然往上推近再推回来；桌上摆着酒瓶与剩菜；固定机位的长对话、突然的推近，白天室内的平光与真实的乱`
- **★ 质感与痕迹**：`固定机位的长对话、突然的推近` · `白天室内的平光与真实的乱` · `喝过酒的桌与烟`
- **★ 最容易被写歪成什么**：`精美构图` · `戏剧化光` · `配乐`

### B54 · 谢晋 / 第五代与第六代（中国）★合并条目
**识别**：土地与人的关系，比人更大。
- **核心视觉**：**大远景把人放进土地**（第五代）；或**手持贴近城市边缘人**（第六代）
- **色彩光影**：第五代是**浓烈的红与黄、强光**；第六代是**灰蓝的城镇与阴天**
- **构图材质**：黄土、高粱、红灯笼、砖墙；或破烂的街巷与拆迁
- **节奏**：第五代**仪式化的慢**；第六代**游荡式的松**
- **声音**：第五代是鼓、锣、人声呐喊；第六代是街声、流行歌、电视
- **参考作品**：《红高粱》《大红灯笼高高挂》《黄土地》（第五代）· 《小武》《站台》《苏州河》（第六代）
- **适用场景**：乡土、历史、民间仪式；或城镇青年、游荡、变迁
- **可写句式**：`巨大的远景里，一小队人走在黄土坡上、身影很小；阳光极强、把土地晒成一片金黄；画面边缘有一排红灯笼；家族与国家的两层空间：屋里与街上，饱和的红与灰、年画的色`
- **★ 质感与痕迹**：`家族与国家的两层空间：屋里与街上` · `饱和的红与灰、年画的色` · `对称的室内构图`
- **★ 最容易被写歪成什么**：`手持` · `冷调` · `极简构图`

### B55 · 杨德昌（中国台湾）
**识别**：一整个城市在同时出错。
- **核心视觉**：**中远景 + 玻璃反光**（人物被窗玻璃叠化）；**梳理过的群像调度**
- **色彩光影**：**都市的冷光**；办公室的荧光；夜里的车灯
- **构图材质**：玻璃、反光、百叶窗；**画框里常有两层空间**
- **节奏**：文学化的长段落；**大量平行的故事线**
- **声音**：**画外音/旁白**；都市噪声；配乐有古典与流行
- **参考作品**：《一一》《牯岭街少年杀人事件》《麻将》
- **适用场景**：都市中产、家庭、少年、时代
- **可写句式**：`摄影机隔着一层玻璃拍人物，玻璃上叠着街上的车灯反光；人物坐在办公室里、荧光灯是冷的；画面外还有另一组人在说话`
- **★ 质感与痕迹**：`玻璃与隔断把城市切成很多层` · `夜晚的霓虹与白日的灰` · `人物在人群里被挤散`
- **★ 最容易被写歪成什么**：`干净的都市` · `手持炫技` · `暖黄怀旧`

### B56 · 许鞍华（中国香港）
**识别**：普通人过日子的重量。
- **核心视觉**：**克制的写实**；摄影机不炫技；人物在真实的空间里
- **色彩光影**：自然的市井光；室内偏黄；港岛的湿与热
- **构图材质**：公屋、街市、楼梯、街边小摊；**生活物件的堆积**
- **节奏**：平实的日常节奏；**在平常处突然给出情感重量**
- **声音**：**市井环境声**（叫卖、电视、麻将）；配乐克制
- **参考作品**：《天水围的日与夜》《桃姐》《女人四十》
- **适用场景**：市井、家庭、老人、香港、日常
- **可写句式**：`公屋的走廊里，人物端着菜走过、身后是晾着的衣服；光从楼道窗子进来、是暖的；画面朴素、像纪录片；市井的空间：楼梯、摊位、公共走廊，自然光与实用光、真实的乱`
- **★ 质感与痕迹**：`市井的空间：楼梯、摊位、公共走廊` · `自然光与实用光、真实的乱` · `人物边走边说话`
- **★ 最容易被写歪成什么**：`对称构图` · `戏剧化光` · `极简陈设`

### B57 · 拉美魔幻现实（丰塞卡三人组）★体系条目
> 本条目覆盖 **费尔南多·梅里尔斯 / 卡蒂亚·隆德 / 沃尔特·塞勒斯** 之外的当代拉美魔幻现实倾向（含《上帝之城》式与《中央车站》式两极）。
**识别**：现实里突然长出神话。
- **核心视觉**：**两极**——要么手持街头的生猛（贫民窟），要么公路上的温情长镜（旅途）
- **色彩光影**：**热带的强光与浓色**（黄、橙、绿）；灰尘与汗水
- **构图材质**：山坡上的房子、晾衣绳、电线、市场；**人挤在画面里**
- **节奏**：**快切与长镜交替**——街头段落碎、路途段落长
- **声音**：**桑巴/波萨诺瓦/街头音乐**；人群的喧闹；广播与电视
- **参考作品**：《上帝之城》《中央车站》《摩托日记》
- **适用场景**：贫民区、公路、热带、群像
- **可写句式**：`山坡上密密层层的房子，电线把画面切成碎片；热带阳光极硬、把墙照成黄橙色；人群挤在画面里、都在同时做各自的事`
- **★ 质感与痕迹**：`现实里插进一件不可能的事、但光与质感都写实` · `饱和的暖色与潮湿的空气` · `时间被拖长`
- **★ 最容易被写歪成什么**：`奇幻特效` · `冷调` · `写实的光`

### B58 · 非洲当代电影（希萨柯 / 塞姆贝内 / 苏莱曼·西塞）★体系条目
**识别**：土地有自己的时间。
- **核心视觉**：**缓慢的凝视**；大量**静态的正面人像**；摄影机像在听
- **色彩光影**：**土地的暖褐与尘**；日落的橙；阴影很重
- **构图材质**：土墙、木门、布、水罐、牲畜；**村庄的空地**
- **节奏**：**极慢**——不急于推进；以仪式与日常为节奏单位
- **声音**：**人声与自然声**；鼓、歌、远处的人；配乐少
- **参考作品**：《廷巴克图》（希萨柯）《法蒂·金特》（塞姆贝内）·《叶莲》（苏莱曼·西塞）
  （**★ 2026-09-28 落库勘误**：本行原挂「《廷巴克图》（西塞）《法蒂·金特》（杜库雷）·《叶莲》（萨勒）」**三处导演归属全错**，按多源实证改挂（IMDB tt0276951 ／ 斯坦福 SearchWorks ／ 哈佛电影档案 ／ TMDB 一致）：**《廷巴克图》(Timbuktu, 2014)＝阿伯德拉马纳·希萨柯 ·《法蒂·金特》(Faat Kiné, 2001)＝奥斯曼·塞姆贝内 ·《叶莲》(Yeelen, 1987)＝苏莱曼·西塞**。）
  （**⚠️ 中文译名歧义提醒**：原挂名里的「西塞」同时可指 Souleymane Cissé 与 Sissako 的近译，**两位导演、两部名作全撞中文译名**——这正是当初挂错的根源。故本条一律标**全名**，写提示词时勿只写「西塞式」。）
- **适用场景**：村落、信仰、土地、历史
- **可写句式**：`固定机位正对一位坐着的人；土墙是暖褐色的、阴影很重；背景里有人慢慢走过；画面长时间不动、像在等什么；红土、烈日、尘土与塑料布，手持与贴近的人群`
- **★ 质感与痕迹**：`红土、烈日、尘土与塑料布` · `手持与贴近的人群` · `饱和的暖色与硬光`
- **★ 最容易被写歪成什么**：`风景明信片` · `干净的服装` · `柔光`

### B59 · 中东作者电影（帕纳西 / 法尔哈迪之外的阿巴斯系）
**识别**：真实与虚构之间只隔一层车窗。
- **核心视觉**：**车内长镜**（摄影机固定在仪表盘上拍对话）；**山路的远景**
- **色彩光影**：**黄土与橄榄绿**；阳光极强、把土地晒得发白
- **构图材质**：车窗框、土路、树（一棵孤树是常见意象）；建筑是土色的
- **节奏**：**慢**；大量在车里的对话；镜头很少切
- **声音**：**车声、风、谈话**；配乐极少或不用
- **参考作品**：《樱桃的滋味》《橄榄树下的情人》《出租车》（阿巴斯 / 帕纳西系）
- **适用场景**：乡间旅程、对话、生死讨论、山野
- **可写句式**：`摄影机固定在车内拍两个人说话；挡风玻璃外是黄土的山路；阳光把土地晒得发白；一棵孤树立在坡上`
- **★ 质感与痕迹**：`狭窄街巷与水泥建筑、人在门洞前` · `硬光与深影、几乎没有中间调` · `固定机位的长镜`
- **★ 最容易被写歪成什么**：`异国风情滤镜` · `手持` · `暖黄怀旧`

### B60 · 纪录片作者的剧情片（怀斯曼 / 王兵 / 赵亮）★体系条目
**识别**：不解释，只呈现。
- **核心视觉**：**无解说的长镜头**；摄影机耐心地等；**没有访谈头的段落式结构**
- **色彩光影**：**现场光，不修饰**；白炽灯与窗光；允许欠曝
- **构图材质**：**真实场所的杂乱**（车间、病房、街道、家）
- **节奏**：**段落式的长**；不剪出"故事高潮"
- **声音**：**纯环境声**、无配乐无旁白；机器与人声的密度
- **参考作品**：《铁西区》（王兵）《24 号城市》（怀斯曼系）《上访》（赵亮）
- **适用场景**：工厂、边缘人、社会现场、时代切片
- **可写句式**：`摄影机架在车间的角落里、长时间不动；灯光是顶上的白炽灯、把人的脸照得发黄；画面里工人在各做各的事、没有人看镜头；没有旁白，只有机器的声音；纪实式的自然光与现场声般的空间，真实人物的脸与不完美的构图`
- **★ 质感与痕迹**：`纪实式的自然光与现场声般的空间` · `真实人物的脸与不完美的构图` · `长时间的静止镜头`
- **★ 最容易被写歪成什么**：`精致构图` · `戏剧化配乐感` · `手持炫技`

## 易混对一句话分辨（本卷）

| 容易混 | 一句话分辨 |
|---|---|
| B41 法哈蒂 vs B51 是枝裕和 | 法哈蒂的摄影机**在争吵里往前挤**；是枝的摄影机**退到走廊里不动** |
| B42 锡兰 vs B59 阿巴斯 | 锡兰是**冬季室内的长夜对话**；阿巴斯是**夏季车里的山间旅程** |
| B43 考里斯马基 vs B53 洪常秀 | 考里斯马基**人不动、颜色浓**；洪常秀**人在说话、颜色平** |
| B45 瓜达尼诺 vs B50 詹金斯 | 瓜达尼诺是**白天的阳光与汗**；詹金斯是**夜里的霓虹与水** |
| B47 拉雷恩 vs B52 李沧东 | 拉雷恩的广角是**风格化的变形**；李沧东的中景是**克制的观察** |
| B48 达内兄弟 vs B42 锡兰 | 达内的摄影机**贴着人物后背走、跟随不切**；锡兰的长镜**几乎不动地停在原地** |
| B54 第五代 vs B58 非洲体系 | 第五代色彩是**浓烈饱和的仪式**；非洲体系是**暖褐尘土里的静观** |
| B55 杨德昌 vs B52 李沧东 | 杨德昌是**城市群像的多线并置**；李沧东是**单个人的愤怒线** |
| B60 纪录片作者 vs B56 许鞍华 | 两位都朴素；但 B60 **不写情节**、许鞍华有**完整的剧情弧** |
| B44 拉姆塞 vs B46 德尼 | 拉姆塞**声音先行、剪辑跳**；德尼**身体先行、段落整** |

## 来源与署名

- **本卷 20 条（B41–B60）的视觉特征、色彩、构图、节奏、声音五个字段**：基于公开影史资料、导演访谈、影评与学术论文的**要点重写**；技法名词（手持近景 / 长镜 / 单点透视 / 跳接 / 画外音先行等）为**影视公共知识**。
- **「节奏」与「声音」两个字段的读法**：Fiveable 导演风格分析公开课讲义 + Bordwell & Thompson 剪辑与声音理论（经公开论文转引），见 `director-system.md`。
- **参考作品仅作识别线索**，不写进提示词（见 `quality-layer.md` 第 4 条）；**未复制任何影评或论文原文**。
- **本卷导演的选择与分组（当代作者 / 亚洲 / 拉美 / 中东 / 非洲 / 纪录片作者）、易混对分辨**：本库自建。
