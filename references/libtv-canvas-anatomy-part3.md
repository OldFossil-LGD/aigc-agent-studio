## 十四、★★★ 提示词内容层的高价值写法（14 条，全部【实证】）

### 14.1 「节奏与信息检查」—— 管"观众看完要知道什么"

此前所有规律都在管**画面里出现什么**，这一条管**看完之后观众该知道什么**。

```
节奏与信息检查
这一段必须让观众在48秒内清楚接收四项信息：
零和五号已经确认三号位于富士山北麓地下八百米。
两人原本正在赶往日本营救三号。
…
```

⚠ 写 48 秒而本节点只演 22 秒 → **信息规格的作用域可以超出单个节点**。

### 14.2 「表演锁定」—— 约束情绪的成因，不是表情清单

```
**五号不能表现成不愿救普通人。他的痛苦来自"又一次来不及保护三号"，
  而不是任务选择上的道德犹豫。**
**雷达员负责喊出最紧急的即时信息，昆仑不重复雷达员已经说过的内容。**
```

★ 先排除错误表演，再指定情绪的**来源** → 防模型自作主张改人物动机
★ 第二条是**群戏必备的台词分工约束**

### 14.3 镜头标题 = 这镜的功能，不是画面描述

`｜合影尚未开始，血雾已经出现` · `｜差一步就爬上来` · `（全片最高光：子弹时间！）`

⚠ **默认推荐，不是硬门禁** —— 同一 owner 下也有纯 `镜头1` 无功能句的成功节点。

### 14.4 执行锁定写"因果必然性"，不是元素清单

> **父女必须先逃离玻璃。事故不是他们停留观看造成的，
> 而是结构失效速度超过人类逃生速度。**

七种类型：镜内切法 / 因果锁 / 道具物理链 / 人物决策锁 / 显隐时序锁 / 台词锁 / 反摆姿势锁

⭐ 两种此前没意识到的：
- **显隐时序锁**：`D18全程不出现五号，也不以声音、影子或屋顶剪影暗示五号所在位置`
  → 不只是"不给画面"，连**预告**都不许。防"提前露脸"的结构化写法
- **人物决策锁**：`东北大哥必须先跑过男孩，再经过短暂且可见的犹豫后主动折返`
  → 锁**决策的步骤与可见性**，而不只是结果

### 14.5 禁止项写"改成什么呈现方式"，不写"不要 X"

⛔`不许拍到怪兽` → ✅`本场不把它拍成可以辨认全貌的生物`

⭐ 最高级的写法是**给它一个物理上无法摆姿势的力学路径**：
`她不是用一把刀硬扛整只巨爪，而是借怪兽自身的下压力撬动关节角度。`

### 14.6 三条「剥夺式」写法（同一手法，三处实证）

模型最爱的表现 → 显式否定 → 立刻给替代解释。

- 动作：`怪兽不需要直接撞击玻璃。它逼近时推动的巨大水压，就足以让承压结构失效。`
- 音效：`不使用吸力声，不改变水流方向。`
- 视觉：`剑气不带彩色特效，纯粹是超高压空气导致的光学折射。`

### 14.7 主体规格块的否定式三段式

```
统一称为"<固定称呼>"，不使用<某分类>描述。            <- 锁称呼 + 锁分类
通过以下现象建立<属性>：<六条可拍摄的物理事件清单>。  <- 抽象词降解成现象
<主体>不需要<那个最戏剧化的动作>。                  <- 剥夺 + 替代机制
```

⭐ 第一条治的是**模型自行给主体归类**（造型漂移的头号源头）。

### 14.8 执行锁定要防「上一段的焦点被沿用」

> `镜头16开始时，终端已经收好，任何人都不再查看屏幕。`

⭐⭐ AI 有很强的倾向把上一段最出彩的道具延续下去，必须明说"它退场了"。

同族：
- `镜头15只拍机外急转，不回切机舱。`（防惯性切回室内）
- `起跳顺序锁定为：五号先跳，零随后跳。`（防 AI 爱做对称）
- `镜头17第0帧舱门已经完全开启。`（防重新演一遍开门）

### 14.9 升格镜必须防「变成静帧照片」

> `进入升格后仍保留轻微摄影机漂移，不变成完全静止的展示镜头。`

⭐ 把「帧率」从「焦段」里拆出来单列
⚠ **实测有节点写 1200fps 超升格但没写这句，仍然 status:2** → 这是好习惯不是门禁

⭐ **帧率之上还能控"哪一帧用哪种风格"**（全画布唯一一例）：
> `帧1/2（0.06s）：画面黑白负片反转` / `帧3（0.03s）：硬切为一帧铅笔素描风格画面`

→ **把"帧"当可控单位**，且每种风格占几帧都写死。

### 14.10 中英双写技法的真正机制（13 处实证）

`Sliding Tackle` / `Whip Pan Split` / `Jetpack Burst` / `Barrel Roll Free-fall`
`Flesh Knitting` / `Optical Distortion` / `Rigid Body Destruction`

⭐ **不是装饰，是给模型一套镜头语言词汇表**，专治"中文动作词有多种视觉解读"：

| 中文 | 必须靠术语 |
|---|---|
| 滑铲 | `Sliding Tackle`（美式橄榄球式低身滑行，不是摔倒） |
| 甩镜 | `Whip Pan Split`（"Split"暗示一镜内两人分向两端） |
| 二段跳 | `Jetpack Burst`（暗示有推进器，不是纯弹跳） |
| 自由落体翻转 | `Barrel Roll Free-fall`（桶滚是空翻，不是乱转） |

⚠ 这是某位 owner 的习惯，**不是平台门禁**，只在中英歧义确实存在处用。

### 14.11 多场景并置的三条全局规则（此前完全没有的一层）

色温隔离：
> `不同场景执行绝对的色温隔离（运输车的战术红/屏幕蓝，指挥室的全息青，拍卖会的奢华暖黄）。`

运动语言对照：
> `运输车内使用剧烈的手持抖动，指挥室与拍卖会使用绝对平滑的机械滑轨，形成"动与静"的暴烈反差。`

⭐⭐ **它不只是区分空间，而是用摄影机运动本身给人物分组**（慌张的平民 vs 冷静的权力方）
→ 这是在**用运镜做人物塑造**

统一符号（整批样本最高级的一条）：
> `无论观众处于何种环境，瞳孔/镜片中必须精确反射出战场的火光与残影。`

⭐ 不靠剪辑节奏，靠一个反复出现的物理细节。
⭐ 高明之处是落实在不同光学器件上：**眼镜镜片**（冷、精确）与
**威士忌杯弧面**（暖、扭曲）—— 同一件事，两个质感，不重复。

⭐ 闪切必须用同一事件统一：`四个不同空间的特写镜头随着同一次爆炸的光源同步切换`
⭐⭐ **最后一刀必须回到主线并兑现**：`白光填满所有画框！（完美衔接回主战场的下一记绝杀）`

### 14.12 摄影机换人格写法（全画布唯一一处）

> `这不是人类摄影师的手持跟拍，而是一种体量巨大、惯性沉重的水下运动。`

四层：
1. 否定人类属性
2. 三条反常识的运动参数（速度递增 / 方向异常稳定 / 只随水压轻微浮动）
3. 分层声场（人声压成遥远闷响 + 整座建筑在水下共振）
4. 显式剥离一个 AI 必加的音效（`不使用吸力声`）

### 14.13 其他细粒度

- **当某一镜违反全局规则，必须当场解释它为什么不违反**：
  `镜头17的稳定不是安全，而是怪兽自身巨大惯性带来的非人运动感。`
  （同段前 17 镜全声明"手持、不稳"，第 17 镜突然变稳 → 不解释模型会困惑）
- **屏幕内的影像也要遵守摄影机能力边界**：
  `新闻摄影机来不及跟上，画面发生一次慌乱甩动` → 治 AI 拍监控画面时的过分流畅感
- **形态机制要在全局块预先声明**：
  `五号的实体长枪…是他未开启神格时使用的实兵器；神格启动后才会显化为不完整的三尖两刃形态`
  → 同一道具写两态 + 指定切换条件
- **摄影机"跟不上"是表现物理惯性的手段**：
  `摄影机没有跟着机身同步旋转，而是迟半拍修正水平线` → 追逐机位若刚性同步，转弯完全不可见
- **道具当视线引导线**：
  `白鲸玩偶从气穴下方漂过。父亲顺着玩偶看见小艾正在更低处下沉。`
- **群众表演要防"一个接一个念完台词"**：
  `所有台词都作为抢话、喊话和残句出现，不允许群众一个接一个清楚说完台词。`
- **抽象感受要定义其来源**：
  `怪兽的压迫来自"无法测量"。` → 约束的是观众感受的成因
- **声音动态可以量化**：`环境声短暂降低约3分贝`
- **事件并行锁**：`撤离与袭击必须同时发生，避免变成角色站着等待通讯完成`
- **点名禁止 AI 最爱用的套路**：`不使用平稳转场` / `摄影机没有围绕人物旋转`
- **表演锁定也可写进单镜正文**（与独立块逐字同型，两处并存不冲突，后者是冗余保险）
- **灯光"三个参照物一起转"**：
  `水墙抵达后彻底放弃水平线，让人物、地面与水面共同滚转`
  → 不是"画面倾斜"，是三个参照物一起转 → 失重感才成立

## 十五、★★ 提示词该写多细：诚实结论（【实证】）

**同一画布里同时存在三种密度，全部 status:2 成功：**

1. 300–3000 字五层结构，12–15 张参考
2. 全文无焦段、无 `相机／焦段` 字段、无全局规格块，只有「时间区间标题 + 纯散文对白」
3. **只剩引用声明行，正文全空**

| 情况 | 怎么写 |
|---|---|
| 灾难奇观 / 动作段 | 焦段 + 构图 + 运镜三件套，**密度越高越稳** |
| 对白 / 喜剧 / 人物互动段 | 焦段写了也用不上，**直接写对白与动作** |

⭐⭐ **「每镜必写焦段/构图/运镜」是这批制作者在动作段的习惯，不是平台门禁。**

### ⭐ Midjourney 英文提示词 = 分层写法的通用形态

两个 `mj-v8.2` 节点是全画布仅有的英文提示词，十段结构：
题材主体 → 机位 → 形态清单 → 材质配色 → 文字要求 → 背景层次 → 光位 → 器材质感 → 禁项

⭐⭐⭐ **同一个人在同一画布上用中文写视频分镜、用英文写资产图，分层逻辑完全一致。**
→ **「分层写法」不是中文制作者的偏好，是这套方法的通用形态。**

英文禁项三个特点：
1. 全部用 `No X` 开头，不用 `Don't X`（更短的 token）
2. **禁项与正文元素一一对应**（正文写了 spaceship 就禁 no spaceships）
3. 带文化地理指认：`unmistakably mainland China` / `no Japanese or Korean signs`
