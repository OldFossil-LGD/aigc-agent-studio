# 剧本格式：好莱坞标准规格 + 中文适配档（**全库唯一权威源**）

> **何时读**：写剧本之前（定版式）；交付剧本之前（逐条自查）。
> **读完回哪**：内容层 → `script-craft.md`（七件交付物）· `drama-*` 十七册（剧作层）；容量的秒数轴 → `drama-scaling.md`。
> **定位**：本文件管**"纸面长什么样"**，不管"故事怎么讲"。**格式与内容互不替代**——格式正确救不了一个坏剧本，格式错误会让一个好剧本读不到第五页。

## §0 三条定律（为什么格式不是审美问题）

| 定律 | 含义 | 违反的代价 |
|---|---|---|
| **① 它是计时器** | Courier 12pt + 标准页边距 → **一页 ≈ 一分钟**。制片按页数做预算，副导演按页数排拍摄日 | 改了字体或页边距，这把行业的量尺就废了——**这是最不可协商的一条** |
| **② 它是解析协议** | 剧本是全剧组读得最多的文件：副导演从场景标题拆拍摄表、选角只看人物名与对白、外联扫场景标题里的地点 | 每个元素有固定缩进，每个部门才能一眼取走自己要的东西 |
| **③ 它是专业信号** | 代理公司与制片方每周筛几十个本子；**第一页格式正确 = "这人读过剧本"** | 格式错 = 反面结论，而且会**连带影响后面每一页的阅读态度** |

## §1 页面规格（英文标准档 · 五源一致）

| 项 | 规格 | 说明 |
|---|---|---|
| **纸张** | **US Letter 8.5″ × 11″**（美国境外接受 A4） | 页面数学依赖它 |
| **字体** | **Courier 12pt**（Courier Prime / Courier Final Draft 均可） | **等宽字体是量尺本身**；用 Times / 宋体 / Arial 一律判不合格 |
| **页边距** | **左 1.5″** · **右 1.0″** · **上 1.0″** · **下 1.0″** | 左宽半英寸是**留给装订夹**的；右可浮动约 ¼″，但保持接近 1″ |
| **对齐** | **左对齐、右端参差** | **绝不做两端对齐**——两端对齐会改变词距、破坏计时 |
| **行距** | 单倍行距 | 元素之间**空一行** |
| **每页行数** | **约 55 行** | 一页 ≈ 一分钟的来源 |
| **页码** | **右上角，距顶 0.5″，数字后加句点**（`23.`） | **第一页不编号**（标题页不计入） |
| **强调** | **基本不用粗体 / 斜体 / 下划线** | 需要强调时用 **AII CAPS**（声音、关键道具、人物首次出场） |

## §2 六大元素（位置表 + 写法 + 判据）

| # | 元素 | 英文位置 | 写法 | **判据（不合格长什么样）** |
|---|---|---|---|---|
| 1 | **场景标题（slugline）** | 左对齐 1.5″，独立一行，**全大写** | `INT. MOLLY'S DINER - NIGHT` · `EXT. BROOKLYN BRIDGE - DAY` · `INT./EXT. PARKED SEDAN - CONTINUOUS` | 语法是刚性的：**内外景 → 地点 → 连字符 → 时间**。时间通常只有 **DAY / NIGHT**，偶尔 DAWN / DUSK / CONTINUOUS（紧接上一场、无时间跳跃）/ LATER。**地点名必须前后一致**（`MOLLY'S DINER` 与 `THE DINER` 在制片眼里是两个景）。子空间用连字符链：`INT. MOLLY'S DINER - KITCHEN - NIGHT`。**换地点或跳时间就必须换标题——没有例外，场景数是靠它数的** |
| 2 | **动作（action）** | 左对齐，**通栏（1.5″–7.5″，约 6″ 宽）** | 现在时、主动语态、只写**拍得到与录得到**的东西 | 只写**能拍的**：不写心理、不写前史、不写气味。**段长 3–4 行以内**，然后留白——**整块密集描述是最典型的业余信号**。**第一次出场的角色名**、**关键音效**、**必须被注意的道具**用全大写 |
| 3 | **人物名（character cue）** | **约 3.7″**（3.7–4.2″），**全大写** | `RAY` · `SARAH` | 英文一般**只写名不写姓**；中文可写全名。**说话的人必须显式出现**——不要让读者猜谁在说 |
| 4 | **括号（parenthetical）** | **约 3.1″**，小写，**不加句点** | `(whispering)` · `(checking his watch)` | **1–4 词上限**；**只在"念法从上下文看不出来"时才用**。滥用括号是对演员与导演的冒犯——把动作写进动作行，不要塞进括号 |
| 5 | **对白（dialogue）** | **左 2.5″ → 右约 6.0″（约 3.5″ 宽）** | 句首大写、正常大小写 | **窄栏是为了按说话速度读**；对白不能通栏 |
| 6 | **转场（transition）** | **右对齐**，全大写，**带冒号** | `CUT TO:` · `DISSOLVE TO:` · `SMASH CUT TO:` · `MATCH CUT TO:` · `FADE TO BLACK:` | **现代剧本极少用转场**：换一场戏只需新场景标题（**切是默认的**）。转场只留给"这个转法本身有戏剧意义"的时刻。`FADE IN:` 在**开头、左对齐**；`FADE OUT.` 在**结尾、右对齐、以句点结束** |

## §3 一页正确的剧本长什么样（版式样板）

### 2.1 ★ 动作密度（**这一节防的是"把提纲当剧本交付"**）

**★ 先澄清一条最常被误用的规则**：本库的「中文 **3.5–5 字/秒**」是**对白与旁白**的语速预算——**它不约束动作行**。把动作行也按这个秒率去省，出来的就是**提纲**，不是剧本（2026-09-16 实测踩过：《代哭》初稿 15 分钟只写了约 900 字正文，通篇一段一行）。

| 项 | 标准 |
|---|---|
| **正文密度** | **每 1 分钟成片 ≈ 500–900 字正文**（含动作与对白）。<br>**< 400 字/分钟 = 提纲**（不合格）· **400–500 = 偏薄**（可交付但显空）· **≥ 500 = 合格** |
| **动作行与对白行的比例** | **动作是页面主体**，对白通常只占版面 1/3 左右（对白本身就只允许占总时长 1/3） |
| **单段的长度** | **3–4 行是常态，也是上限**——**不是"越短越好"**：整段压成一行，读起来是提词卡 |
| **一段该装什么** | 一个**可拍的动作单元**：谁在什么地方、做了什么、周围有什么在动。**空镜与静物也要写成段**，不要只写名词 |
| **什么时候允许极简** | **分镜表与排镜表**（那是工程层）；**剧本正文不行**——正文是给演员、美术、摄影读的 |

**判据一句话**：**把正文交给没看过梗概的人，他读一遍能不能复述出这场戏发生了什么、周围是什么样？** 不能 → 你写的是提纲。
**机器把关**：`scripts/script_lint.py` 会对 **≥ 600 秒**的稿子算「正文字数 ÷ 时长」，**低于 400 字/分钟判 FAIL**。

### 3.1 英文标准档样板

> **版式示意**：下面用等宽排版复原缩进关系；实际交付时按 §1 规格设定，不要用 Markdown 表格充当剧本。

```text
                                                            23.

INT. MOLLY'S DINER - NIGHT

The diner is empty except for RAY (60s), wiping the same spot
on the counter he has wiped for a decade.

The door CHIMES. Ray does not look up.

                                   RAY
                     We're closed.

She doesn't move.

                                   RAY (CONT'D)
                     I said we're closed.

                     (beat)
                     Sit down, then.

CUT TO:

INT. MOLLY'S DINER - KITCHEN - CONTINUOUS

Ray fills a cup he did not ask for.
```

**从这张样板里要读出五件事**：① 场景标题独立成行、全大写；② 动作通栏、现在时、短段；③ 人物名比动作缩进、比括号更靠右；④ 对白最窄；⑤ **同一场戏换到厨房时，标题写成新的一场**（`- CONTINUOUS` 表示紧接），不要在同一场里"走过去"。

### 3.2 ★ 中文适配档的样板（**以后交付默认长这样**）

```text
                                                              3.

内景 深夜便利店 - 夜

店内只剩一个客人。林默（32 岁）站在冷柜前，指间夹着一张没有递
出去的纸币。

冷柜的压缩机停了一下，又响起来。

　　　　　　　林默
　　　（没有回头）
　　　结账。

　　　　　　　店员
　　　这个不卖。

林默把纸币对折，再对折一次。

切至

外景 便利店门口 - 连续

林默站在台阶上，没有走。
```

**要点对照**：① 场景标题 `内景 地点 - 时间` **四要素齐**，第二步换到门外就**另起一场**（`连续` = 无时间跳跃）；② 场景标题与人物名**加粗**；③ 动作行只有可见与可听（"压缩机停了一下"是声音，可写；"他觉得难堪"不可写）；④ 人物名居中、对白居中留空、**对白不用引号**；⑤ 括号在人物名与对白之间、**四个字以内**；⑥ 转场 `切至` 只在这一处有意义时用（门外那一步的落点）。

## §4 特殊情形（十三种，全部要照写）

| 情形 | 写法 | 要点 |
|---|---|---|
| **画外音** | `SARAH (V.O.)` | 旁白 / 内心 / 电话另一头的声音。**不在场景里出现的人的说话** |
| **画外（同场）** | `JOHN (O.S.)` | 人在这一场的空间里，但**不在画面内**（隔壁房间喊话） |
| **画外（电视）** | `JOHN (O.C.)` | 与 O.S. 近似，电视行业更常用 |
| **接着说** | `RAY (CONT'D)` | 同一人**被动作行打断后**接着说，或**跨页续接** |
| **跨页续对白** | 对白未完处：`(MORE)`；下一页人物名后加 `(CONT'D)` | **只在被页边切断时才用**；不要为了好看滥用 |
| **时间压缩** | `MONTAGE - SARAH TRAINS` 居中起，逐行描述，`END MONTAGE` 居中收 | 每行一个画面、现在时；**不配乐不配音乐提示，只写画面** |
| **串场（不如蒙太奇快）** | 先写场景标题，再逐行列相关动作 | 用于同一场里的一组相关动作 |
| **平行剪辑** | `INTERCUT` 居中起，分别写两处场景标题，交替描述，`END INTERCUT` 收 | 电话对话的标准写法 |
| **闪回 / 梦境** | `FLASHBACK - INT. CHILDHOOD HOME - KITCHEN - DAY` … `END FLASHBACK` | **起止都要写明**，否则读者不知道何时回到现在 |
| **插入 / 强调局部** | `INSERT` 或 `CLOSE ON:` + 一行描述 | 用于一个必须被看见的细节（照片、签名、戒指） |
| **双栏对白** | 两人的对白**并排两列**（左一列、右一列） | 只用于**同时说话**（叠话、吵架）；**不是"快速来回"的意思**——来回仍是顺序写 |
| **画面内文字** | `TITLE CARD:` / `SUPERIMPOSE:` + 文字 | ⚠️ **本库提醒：画面内文字是 AIGC 的高失败项**，见 §8 |
| **手机短信** | `LISA (TEXT)` 当作对白写 | 无官方唯一写法；`(TEXT)` 最通用 |

## §5 标题页与页码

| 项 | 规则 |
|---|---|
| **标题** | **居中、全大写**（正式送审版常加引号） |
| **署名** | 标题下空四行 → `Written by` → 下一行作者名 |
| **联系信息** | 页面**左下**，最后一行距底边 1″ |
| **不加的东西** | 不需要写日期、版本号、公司抬头（越干净越好） |
| **页码** | 右上角 `23.`；**标题页与第一页都不编号** |

## §6 spec 剧本 vs 拍摄稿（**本库只用前者**）

| | **spec（投稿稿）** | **shooting script（拍摄稿）** |
|---|---|---|
| **场景号** | **不写** | 场景标题**左右两侧**各标一个编号 |
| **修订标记** | 无 | 修订页按**颜色轮次**（白 → 蓝 → 粉 → 黄 …）区分 |
| **锁定页** | 无 | 已拍部分锁页；新增用 **A / B 页** |
| **谁写** | 编剧 | 制片与编剧协作 |
| **本库口径** | ✅ **一律交付 spec 格式**（不带场景号、不带修订色） | ❌ 不产（除非用户明确要进组拍摄） |

> **判据**：**投稿稿的干净本身就是信号**。场景号与彩色修订页是制作工具，出现在投稿稿上会读出"这人不懂行"。

## §7 ★ 中文适配档（B 档 · **本库默认交付档**）

**为什么需要它**：好莱坞标准的物理量（Courier、55 行/页）**是为英文设计的**；中文交付必须把**结构**完整保留、把**载体**换掉。

| 项 | 英文标准 | **中文适配（本库默认）** |
|---|---|---|
| **字体** | Courier 12pt | **黑体或仿宋**（正式文档体例——⚠️ 仿宋并非等宽字体，英文档"等宽＝计时器"的逻辑在中文档不适用，时长口径见 §7.1）· 正文小四–五号 |
| **"全大写"** | ALL CAPS | **加粗**（场景标题 / 人物名 / 首次出场 / 关键音效 / 转场 / CONTINUED **全部加粗**） |
| **场景标题** | `INT. MOLLY'S DINER - NIGHT` | **`内景 报亭 - 日`**（或 `1. 内景 报亭 - 日`）；内外景、地点、连字符、时间**四项都要在** |
| **人物名** | 全大写、约 3.7″ | **居中、加粗**（或保持 3.7″ 缩进，二者择一并全片统一） |
| **对白** | 左 2.5″ → 6″ | **居中、两侧留空**，不同人物**另起一行** |
| **括号** | 约 3.1″，小写 | 同样**夹在人物名与对白之间**，**不超过 4 个词** |
| **转场** | 右对齐，全大写 | **右对齐 + 加粗**：`淡入` / `淡出` / `切至` / `叠化` |
| **页码 / 标题页** | 同 §1 / §5 | 同规则（标题页居中、联系信息左下、正文第一页不编号） |
| **标点** | 英文标点 | **全角中文标点**；对白**不用引号**（`人名：台词` 或居中块） |
| **行数换算** | 55 行 ≈ 1 分钟 | ⚠️ **中文没有"一页一分钟"**——页数估算失效 |

### ★ 7.1 中文档的时长口径（**必读，否则页数会说谎**）

**中国的"一页一分钟"不成立**：一是中文字形与 Courier 的等宽关系不成立，二是本库交付的短片由**秒数**驱动而不是页数驱动。**本库改用双轴**：

```text
时长（秒） ← 唯一硬输入 —— 来自 drama-scaling.md 的容量单
字数       ← 中文对白与旁白按 3.5–5 字/秒 折算（判据权威源：studio-workflow.md 第一步）
```

**页数只用来估"这份稿子有多长"，不用来估"片子有多长"。**

### 7.2 送审档（A 档 · 需明确要求才出）

**严格按 §1–§6 的英文规格写**（含英文 slugline 与全大写），用于电影节与海外投稿。**A 档与 B 档内容必须逐句同源**——**不许一次创作两个版本**（会漂）。要 A 档时：先定稿 B 档，再**机械转写**为 A 档。

## §8 ★ 与本库流程的接口（格式的每个字段去哪）

**剧本格式不是装饰，它是下游六个工序的取数口**：

| 剧本字段 | 流向 | 说明 |
|---|---|---|
| **场景标题** | **场景资产清单** | 每个不同标题 = 一个场景资产（→ `studio-workflow.md` 第二步）。**地点名不一致会直接造出多余资产** |
| **人物名** | **身份锚 / 角色资产** | 首次出场处是写"三点个体化"的位置（→ `character-sheet.md`） |
| **动作行** | **镜内容与物理反馈** | 动作行里**只写可见物**，与 12 板块的第 7 块同源（→ `shot-craft.md`） |
| **`(V.O.)` / `(O.S.)`** | **旁白音轨 / 声场** | **`(V.O.)` 是本库最划算的写法**——不吃口型（→ `drama-dialogue-craft.md` §10 旁白专项 · `sound-craft.md`） |
| **括号** | **表演提示** | ⚠️ **括号里的词不进提示词**（属判断语料）→ 必须翻译成形变（→ `drama-aigc-conversion.md`） |
| **转场** | **第 12 块"过渡压力"** | 剧本里写了什么转场，分镜就要在落点上兑现（→ `transition-library.md`） |
| **MONTAGE / INTERCUT** | **段落版（分段镜）的先声** | 蒙太奇天然是"一条里装多个画面"的写法（→ `segmented-shot.md`） |

**两条 AIGC 专属提醒**：

1. **格式 ≠ 可拍性**：剧本照标准写，但**镜头落地仍受可行性门约束**（手 / 走路 / 多人 / 口型 / 画面内文字）——**格式里合法的写法，在生成里可能仍是高危**（→ `feasibility.md`）。
2. **画面内文字**（`TITLE CARD` / `SUPERIMPOSE` / `(TEXT)`）在本库一律**约定后期覆盖**，不进生成提示词。

**剧本末尾仍按 `script-craft.md` 的三行硬事实收口**（`scene / open_state / close_state / hard_facts`）——那是剧本到分镜的接口，**格式文件不替代它**。

## §9 常见错误清单（英文档 / 中文档各一组）

**英文档**：❌ 非 Courier 字体 · ❌ 两端对齐 · ❌ 场景标题缩进（必须顶格） · ❌ 对白通栏 · ❌ 元素之间不留空行 · ❌ 页码错位或首页编号 · ❌ 写心理与前史 · ❌ 动作块超过 4 行 · ❌ 括号里塞动作 · ❌ 每场都写 `CUT TO:` · ❌ 大小写混乱（首次出场不大写、音效不大写）

**中文档**：❌ 用宋体细体正文（等宽感丢失） · ❌ 忘加粗场景标题 / 人物名 · ❌ 场景标题缺"内外景"或"时间" · ❌ 对白两侧不留空、与动作行同宽 · ❌ 标点中英混用 · ❌ 用页数估时长（§7.1） · ❌ 一次创作中英两版

## §10 交付前自查（**十条，逐条答"是"**）

```text
① 场景标题四要素齐（内外景 / 地点 / 连字符 / 时间）？换地点或跳时间就换标题？
② 地点名与人物名全片逐字一致（没有同义替换）？
③ 动作行现在是现在时、只写拍得到与录得到的东西？
④ 每个动作块 ≤4 行？
⑤ 首次出场的人员名、关键音效、必须被注意的道具都标记了？
⑥ 对白窄栏 / 居中留空，没通栏？
⑦ 括号只在念法不明确时用，且 ≤4 词？
⑧ 转场只在"转法本身有意义"时出现，且右对齐？
⑨ （V.O.）/（O.S.）/（CONT'D）/（MORE）用得对，没有为好看滥用？
⑩ 中文档：时长用秒与字数双轴算过，**没有用页数估片长**？
```

## 来源与署名

- **页面规格（Courier 12pt · US Letter · 左 1.5″/右 1″/上下 1″ · 约 55 行一页 · 一页≈一分钟 · 不做两端对齐 · 不编号首页）**：五源交叉一致——**FilmDaft《How to Format Screenplay Margins》** · **Laper《Screenplay Format: The Complete Industry Guide》** · **Celtx《Beginner's Guide to Script Structure》** · **NFI（Nashville Film Institute）剧本格式条目** · **ScreenWeaver《Screenplay Format: Rules, Margins & Examples》**。**数值经五源逐项比对后取一致值**；右页边距的 ±¼″ 浮动由两个来源明示，已按"接近 1″"表述。
- **元素位置与写法（场景标题语法 / 动作只写可拍之物与 ≤4 行 / 人物名 3.7″ / 括号 3.1″ 且 1–4 词 / 对白 2.5″→6″ / 转场右对齐且现代极少用）**：同上五源 + **EpicScribe《Industry-Standard Script Formatting Guide》**（`(V.O.)` / `(O.S.)` / `(O.C.)` / `(CONT'D)` / `DUAL DIALOGUE` / `MONTAGE` / `FLASHBACK` / `INTERCUT` / `TEXT` 的写法与用例）· **wikiHow《Write a Properly Formatted Screenplay》**（`(MORE)` 跨页续接、`INSERT` / `CLOSE ON`、蒙太奇的写法）· **No Film School《A Guide to Special Formatting Circumstances in Screenplays》**（`SERIES OF SCENES` · `SUPERIMPOSE` · 电话对话三种写法 · `(TEXT)`）· **Fiveable《Advanced Formatting Techniques》**（双栏对白用于**同时说话**、子标题、闪回与梦境的起止标记）。**本库只重写其规则，未复制任何原文。**
- **标题页与页码规则**：wikiHow（标题居中、空四行、`Written by`、联系信息左下距底 1″）+ FilmDaft / ScreenWeaver（页码右上、距顶 0.5″、数字后加句点、首页不编号）。
- **spec 剧本 vs 拍摄稿（场景号左右标注 · 修订页颜色轮次 · 锁定页与 A/B 页）**：**Laper《The Complete Industry Guide》** 与 **FilmDaft** 的公开表述；「本库只交付 spec 格式」为**本库口径**。
- **中文适配档（黑体 / 仿宋 · 加粗代替全大写 · `内景 地点 - 日` · 对白居中两侧留空 · 转场居右加粗 · CONTINUED 加粗 · 白卡纸封面与装订）**：来源为**中文编剧教学的公开整理**（中国电影资料馆考研剧本写作分析公开讲义 · 影视公司公开的剧本格式说明 · 公开的编剧培训文档），**属行业惯例层、非一手规范**——中文剧本格式没有像美国那样的单一权威标准，**故本档标注为"惯例"，且本库只取多源一致的部分**；其中"全长电影 120 页 / 共 7 场"一类数字**互相矛盾且明显有误，一律未采用**。
- **本库自建**：§0 三条定律的中文判据化 · §3 版式样板 · §7.1 **中文档时长口径改用"秒 + 字数"双轴**（**推翻"一页一分钟"在中文环境的适用性**） · §7.2 A 档与 B 档必须同源、A 档靠机械转写 · §8 **格式字段 → 下游六个工序的取数映射**（含两条 AIGC 专属提醒）· §9 两组错误清单 · §10 十条自查 · §11 空模板。
- **不采用**：把页数当作中文短片的时长估算（与本库容量纪律冲突，见 `drama-scaling.md`）· 各类生成器给出的"剧本分数"类工具（评分掩盖归因）。
