# 胶片与印片档位（选完包之后：这一部片取哪一档）

> **何时读**：选定方案包之后、**写统一提质层的「器材」行之前**。**读完回哪**：`quality-layer.md` §二 写块。
>
> **三份文件的分工（一条链，不要跳）**：
> 1. `camera-package-library.md` = **体系**（17 主包 + 17 补充包：画幅 / 机器 / 运动 —— **决定"这是谁拍的"**）
> 2. **本文 = 档**（胶片 × 印片 × 调制层 —— **决定"这一部片什么味道"**）
> 3. `cinematic-look.md` = **单品参数与特征**（片/机/镜/印片的逐条特征表）
>
> **★ 一句话分清"包"与"档"**：**包按"机制"划，档按"味道"分。**
> 画幅不同、机器不同、运动不同 → **那是新包**（所以 P07/P08/P09/P10/P11/P12 是六个包，不是六种味道）；
> 同一套机制里换片、换印片、换调制层 → **那不是新包，是换档**（P08 一个包就能拍出几十种味道）。
> **判据**：**要加的是档位，不是包** —— 34 个包已经覆盖机制；**瓶颈在"味道"的组织**。

## §0 两条先记死的纪律

**① 写画幅必须带「胶片 / 数字」，且型号不许省。**
`35mm` 单独写是**歧义**的——模型最常把它理解成 **35mm 画幅（全画幅数字机）**或 **35mm 焦段的镜头**，而不是"35mm 胶片"。
✅ `35mm **胶片**摄影机（ARRI 435 那一类片盒机）` · `全画幅**数字**机` · `Super 16mm 摄影机`
❌ `35mm 摄影机配定焦镜头`（可读成"一台 35mm 的画幅机"或"配一支 35mm 定焦"）
**同族对照**（本库的写法并不统一，已修）：P09 写 `65mm 胶片摄影机` ✓ · P07 写 `Super 16mm 摄影机` ✓（Super 自带消歧）· **P08 / P10 已补上"胶片"二字**。

**② 包定了不逐镜改；档定了也不逐镜改——但档必须"按风格与题材"选一次。**
（→ `quality-layer.md` §二：三行逐字复用；**"用哪一档"是本片级判断**。）

## §2 两种印片（决定最终的对比曲线与色彩响应）

| 印片 | 特征 | 判据一句话 |
|---|---|---|
| **Kodak 2383** | 对比高、暗部扎实并带青蓝、高光暖、怀旧浓郁 | **要"怀旧 / 浓郁 / 扎实"就用它**（年代戏、类型片、西部） |
| **Kodak 2393** | 比 2383 更现代：对比略低、高光更柔、青蓝更轻 | **不想要怀旧味时用它**（当代剧情、**高调低对比的文艺片**） |

> **★ 与风格的联动纪律**：**印片的对比方向必须与【后期特效】的"调色方向"一致**。
> 例：调色写了 `高调、低对比、几乎单色`，印片就不能是 2383 —— **那两个方向是相反的，模型会二选一或糊成一锅**。

## §3 ★ 十四风格族 → 推荐档（**这一节是本文的主产物**）

| 风格族 | 片 | 印片 | 调制层 | 一句话理由 |
|---|---|---|---|---|
| **① 电影史运动**（黑白 / 表现主义 / 黑色电影） | **Double-X**（黑白） | 2383 | 漫射黑 | 黑白片只在印片上做对比；黑位要实（2383 会给黑白片带轻微青暖染色；要纯中性黑白，在调色行去色罩） |
| **② 当代写实剧情**（家庭 / 职场 / 情感） | **250D**（日戏）· **500T**（夜戏） | **2393** | 无或极轻漫射白 | 不要怀旧味 —— 2393 就是为了"当代"存在的 |
| **③ 纪实现场** | **ETERNA 500T** | 2393 | 无 | ETERNA 的低饱和与平色调本身就是"纪实" |
| **④ 年代与回忆**（80s / 千禧 / 童年） | **Kodachrome 40** 或该年代的片 | 2383 | **漫射白** | 年代感来自载体的缺陷，漫射白给"被泡软的回忆" |
| **⑤ 恐怖与不安** | **Double-X**（黑白）· 或该包原片 | 2383 | 漫射黑 | 暗部要沉、干净处要少 |
| **⑥ 犯罪与黑色** | **500T**（夜戏） | **2383** | 漫射黑 | 低照度 + 单光源 + 面料反光，2383 的青蓝暗部正好 |
| **⑦ 战争与极端处境** | **Double-X** 或 250D | 2383 | **漂白层** | 去饱和 + 高对比 = 漂白的本职 |
| **⑧ 类型片质感**（西部 / 功夫 / 公路 / 歌舞 / 体育 / 法庭） | **250D**（日戏）· 歌舞片可 200T（细） | **2383** | 西部/公路 **漫射白** · 歌舞 **无** | 类型片的"招牌味道"多半来自浓郁的印片 |
| **⑨ 太空与近未来** | **500T**（舱内钨丝）或该包原片 | **2393** | 漫射黑 | 不要怀旧；舱内是实用光 |
| **⑩ 古装与东方** | **250D**（外景日光）· **200T**（殿内近景） | 2383（宫廷）· 2393（清冷） | 视朝代 | 木构的旧与克制的色，不要过艳 |
| **⑪ 摄影向**（人像 / 产品 / 汽车 / 时尚） | **Portra 400**（人像）· **Velvia 50**（风景静物） | 2393 | 无 | 这一类要"准"，不要印片味 |
| **⑫ 动画与工艺系** | **不用任何片与印片** | —— | —— | 这两系不用包（→ `style-library.md` §二）。**⚠️ 只管 F 卷 / A 卷平面几何组 / D 卷描边与工艺组 / G04 · G06 · G09 · G10 · G11 · G12 · G14** |
| **⑬ 画作转实拍（古典光影组）**（A14–A17 · A19 · A23–A29 · A34） | **Double-X**（黑白）· 或 **250D** | **2383** | **漫射黑** | 明暗对照靠印片的对比与扎实暗部落地；换 2393 会把暗部抬软、对照就散了 |
| **⑭ 混合媒介与机制条目**（G 卷 15 条 ＋ D20） | **按层取档**：实拍层照 ①–⑫ 对号入座 · G13 另加曝光层 | 同左 | G13 叠**曝光层** · G05 只改帧率（**不取档**） | **族⑫ 的"不用任何片与印片"只适用于 G04/G06/G09/G10/G11/G12/G14**；**G01/G02/G03/G07/G08/G13/G15** 有实拍层 → **照常取档**（G08 每块屏照自己的媒介写，即"按层取档"；2026-09-30 补挂，此前漏列 → `style-library-anthology.md` 各条「量级」行） |

> **读法**：**先按 §1 定片（判据＝光源色温 + 颗粒需要），再按 §2 定印片（判据＝要不要怀旧味），最后按族叠调制层。**
> **★ 别一次叠三层调制**：漫射 + 漂白 + 升降格同时上，等于把味道叠糊；**一层为主，最多两层**（**曝光层计入层数预算**——G13 实拍层最多再配一层其他调制）。
> **★ 族编号与 `style-package-matching.md` §1 是同一套**（十二族 → **十四族**，2026-09-17 补 ⑬⑭）：**先在那里定包，再回这里定档**——**包给机制，档给味道**。见到 **G 卷编号先问"哪一层是实的"**：有实拍层就照常取档，纯描边／纯工艺层才整条跳过本册。

## §4 五个最容易配错的（反直觉）

| # | 错配 | 为什么错 | 改成 |
|---|---|---|---|
| 1 | **钨丝片（500T）拍日光外景** | 钨丝平衡 3200K 拍 5500K 的日光 → 要加校正片才正常；**直接用会偏** | **日光戏用 250D**（本库实案：雪地日光戏配了 500T → 已改） |
| 2 | **高反差印片（2383）配高调低对比的戏** | 2383 的"对比高、暗部带青蓝"与"高调、低对比、几乎单色"**方向相反** | **2393**（对比略低、高光更柔、青蓝更轻） |
| 3 | **Velvia 50 拍人脸** | 原「用途」列就写了**"人物慎用——肤色会太艳"** | 人像用 **Portra 400** |
| 4 | **又写"加颗粒"** | **画幅颗粒档随包定**（65mm 极细 / 35mm 细 / 16mm 中 / Super 8 极粗），**片种颗粒随 §1 定**（同是 35mm 包：500T 粗、200T 最细）——两个变量在选完包与片后都已确定 | **删掉"加颗粒"**——不要再写第三个独立颗粒源；需要更粗就**换片种**（200T→500T）或**换包**（35mm→16mm） |
| 5 | **印片方向与调色方向打架** | 调色写"低对比"、印片写 2383 → 模型二选一或糊 | **先定调色方向，再挑与它同向的印片** |

## §5 自检四问

1. **画幅写了"胶片/数字"吗？型号在吗**？（`35mm 摄影机` 是歧义的）
2. **片与光源色温对上了吗**？（日光戏 → 250D；钨丝夜戏 → 500T/200T）
3. **印片的对比方向与调色方向一致吗**？
4. **调制层叠了几层**？（超过两层就是叠糊）
