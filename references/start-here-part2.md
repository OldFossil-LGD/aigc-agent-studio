## 四、第 3 步：拿分镜脚本（这是你最终要的东西）

**你会拿到什么**：**每镜两个板块**，两块分开给、各自可复制。

### 板块一 · 黑白故事板（一镜一张独立文件）

一张**纯黑白灰**的画格提示词，**一镜一张独立文件**——禁的是**一张画布里排 N 格**（要裁切才能拿到单镜、每格只剩 1/N 分辨率）；放行**一次请求出 N 张独立文件**（平台原生组图）。判据：**分画布禁，分文件放行**。

**它锁的是**：景别 / 机位 / 构图 / 人物位置 / 明暗结构 / 动作瞬间。

**你拿它去出图**，拿到一张黑白构图稿。

> ⚠️ **这张黑白图只是给你看构图的，不能直接当视频首帧**——灰度输入会把整片锁成单色。彩色首帧要用板块二重新出。

### 板块二 · 视频提示词（整段复制就能用）

一段**整合好的提示词**，层序固定，**整段复制粘贴进工具即可**，不用你自己拼。

**你的操作流程，逐镜重复**：

```
1 复制板块一  →  出黑白构图稿（看构图对不对）
2 复制板块二  →  出视频（用资产图 + 首帧）
3 出来的片子过一遍  →  合格就下一镜，不合格就贴回来让它修
```

**每镜重复这三下，直到拍完。**

> **想要"一条里换好几个景别、别老是缓推" → 直接说这一句就行。**
> 它会把这一镜写成**分段镜**：**一条 15 秒里装 3 个景别**（比如 全景 → 中景 → 特写），**按「段落」写（段落A / 段落B / 段落C）**，
> **每一段里先说清起始是什么景别、构图怎么摆，随后段内怎么变**——**不写"镜几"、也不写秒数**，**你只出一次视频**，不用生成三次再拼。
> 前提是这一镜满足：**同一场景、同一光线、人少（1–2 个）、动作简单**。
> 跨地点、跨时间、有对白口型、有走路奔跑的，仍然会拆成几镜——那不是省事，是给自己挖坑。

### 出片不合格怎么办（这是常态，不是你的问题）

**别自己重写提示词，也别自己加"不要 XX"。** 把片子贴回来说一句：

```
第 5 镜手崩了，我重抽了两次还是崩。
```

它会做三件事：
1. **先判是哪一层的问题**（资产？提示词？动作？平台？）——**不默认让你加重抽次数**；
2. 告诉你**该改哪一句 / 该换哪条路径**；
3. 如果是资产的问题，它会让你**回去补图**，而不是让你继续抽。

> **一条铁律**：**只有一处不对时，不要整镜重抽**——改那一个点（重打光 / 调色 / 换机位），比重生成整条便宜得多。

### 另一种情况更要注意：做出来了，但"不是你要的"

这和"崩了"不是一回事——崩了是技术失败；**这一种是没失败，但题材被削平了**（比如你要的是打斗戏，它给你的是一个站着喘气的情绪小品）。

**你只要说一句**：

```
这不是我要的。我要的是【把你要的那口气说出来】，你这版把【被删掉的那部分】删掉了。
```

它会做三件事：① 回头核**命题**（这片子到底在说什么）——多半是这一步没走或走偏了；② 核**这一镜有没有保留题材的核心动作**（"规避风险"不能变成"删掉动作"）；③ 重写，并把"改了什么、为什么"讲给你听。

> **判据你自己就能查**：**同行看完会不会问"这就完了"？** 会 → 就是削平了，直接说出来。

**✅ 交付信号**：所有镜头都过了（或你认可了），它会走交付流程，给后期与规格说明。

## 六、常见问题（照着答案说就行）

**Q：我完全不懂提示词，能直接用吗？**
能。你从头到尾不需要写一句提示词。所有提示词都由它给，你只负责**复制、粘贴、出图、贴回来**。

**Q：它给的东西太长，我要全读完吗？**
不用。**剧本读一遍**；资产看**清单**就够（提示词直接复制）；分镜**两块直接复制**。真正要你读的只有：可行性判断、资产清单、它给的"改法"。
**Q：我出的图和它说的不一样，要紧吗？**
不要紧，**以你实际出的图为准**。贴回来告诉它"实际是这样的"，它会按你的图调整分镜。

**Q：它说我的题材拍不了，怎么办？**
看它给的**分级**：如果是"建议改结构"，听它改；如果是"可以拍但成本高"，看你能不能接受它算的预算（它会折算成生成次数和钱）。**改结构永远比硬拍便宜。**

**Q：能中途换风格吗？**
**不能。** 一部片**只选一套量级**（写实 或 风格化），选定不改。资产图也不能跨风格复用。想换 = 从头来。

**Q：人物出来总是很假——油光光的、像打了蜡、皱纹看着不对，怎么办？**
**别自己加"不要油光""皮肤哑光"这类词**——那是形容词，库里早写过，说明问题不在词上。贴回来说 `人出来像打了蜡，脸上一片油光，高光整片，皱纹也不对`。它会先**诊断到哪一层**（油亮＝皮肤被当成不透光材质；高光成片＝毛孔被当噪声抹掉；皱纹假＝模型无解剖依据），**然后最可能让你改的不是词，是光**——毛孔、绒毛、次表面散射、高光分布在正面平光下全都看不见（→ `skin-realism.md`）。
想追问**为什么**：`skin-light-physics.md`（六层结构 / SSS 参数 / 穿透深度）+ `light-physics.md`（五个光位的精确角度 / 半影公式 / 色温标度 / 17 规律 / 14 误区）。**记得三句就够**：① 高光在角质层、颜色在真皮，**两件事要分开写**；② **SSS 是边缘现象**，只在耳廓/鼻翼/指缝这类薄处 + 逆光才出现，全脸写会变油亮；③ **软硬可调但接触处必锐**——阴影整条边一样虚就是假的。

**Q：它为什么老让我先跑个测试镜？**
因为**静态好看≠能交付**。"照片过关、视频测试淘汰"是反复出现的失败模式。**跑一组**（不是一条）是省你钱的。

**Q：我能不能自己改它给的提示词？**
可以，但不建议。它给的块是**整合过的**（人物→光位→时间线→运镜→禁止项都在里面），你删掉一段可能正好删掉防崩的关键句。**要改就说需求，让它改。**

**Q：一部片大概要花多久 / 多少钱？**
它会主动给你折算：**每镜 2–4 次生成**，**难镜 5–15 次**，**全片素材备 2–3 倍**，**后期占 60–70% 工作量**。它会把难点镜头单独折算成 credits / 钱，**你可以据此砍镜头**。
