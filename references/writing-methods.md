# 写作方法融合层（**适用范围：剧本 / AIGC 写作**）

> **何时读**：写剧本之前（选材与立意）；**卡在"有事没戏"**时；写完自检时；教/带别人写时。
> **读完回哪**：结构 → `drama-structure-models.md`；套路 → `drama-tropes.md`；创意手法 → `drama-plotcraft.md`；交付 → `script-module.md`。
> **定位**：本册是**从 GitHub 上的写作技能里检索、比对、融合出来的方法层**——不是书摘，是**可执行动作 + 判据 + 失效条件**。

## §2 融合 A · 从"想法"到"主控思想"（写之前，逼出唯一性）

**A1 · 前提是暴君——用它做推演，不是用它做标签。**
前提不是一句主题词，是**一条只能往一个方向走的铁轨**。推演链（五步，照走）：
```text
① 前提三段式：人物特质 ＋ 导致 ＋ 结局（「嫉妒摧毁自身与所爱」）
② 问"要证明它，人物必须是什么样的人" → 推出禁忌项（不能蠢、不能冷）
③ 问"什么处境能把这条前提逼到极限" → 推出必需条件（与钱有关 / 最爱的东西被威胁）
④ 顺着"最省"的路往下推，每推一步问"这一步会不会让前提走偏" → 走偏的选项直接砍
⑤ 推到"没有别的路可走"为止——那一步就是你的必要场景
```
**判据**：**能推出一个"不可替换的结算动作"——死亡 / 毁灭只是样态之一（也可以是当众认错、放弃抚养权、输掉决赛），前提才算活**。推不出来 = 前提是标签，不是铁轨。（2026-09-25 修正：旧表述"必须死去 / 必须被毁"误杀和解 / 治愈 / 体育类前提，且与本册 A3 理想主义型矛盾。）
**失效**：两个前提 = 两个方向（剧本会散）；**只许一个主前提**，副前提只能补充它。

**A2 · 主控思想 = 价值 + 原因。**
不写"关于孤独"，写**"孤独被承认之后才会消退，因为他终于允许别人看见他"**（价值＝孤独/被看见；原因＝他允许）。
**用法**：写在 M2；**它不许出现在台词里**，由高潮的动作结算。

**A3 · 三种主控思想，先选一种，再写结尾。**

| 型 | 句子形状 | 结尾的调子 | 本库例 |
|---|---|---|---|
| **理想主义** | "……因为主人公……"（上扬） | 得到 | 主流成长片 |
| **悲观主义** | "……因为这是人性的一部分" | 失去 | 《代哭》的底色 |
| **反讽主义（正）** | "对……的过分执着会摧毁你，但若及时看清并放弃执着，便得救赎" | 醒悟 | 救赎情节 |
| **反讽主义（负）** | "痴迷于执着追求欲望，然后毁灭自己" | 自毁 | 惩罚情节 |

**反讽最难写**，三条纪律：**一个动作同时是正与负** · **正负不能互相抵消**（否则观众读成"没态度"） · **必须有动机**，不能是模棱两可。

**A4 · 先写高潮，再反推。** 问两句话：**高潮带来了什么价值？主要原因是什么？** 答完，主控思想自己就浮出来了——**不要先定主题再硬写情节**。
**A5 · 思想 vs 反思想交替。** 序列之间**给交战双方同样的火力**（反派若是傻瓜，胜利没有价值）；但**全片只留一个答案**。
**A6 · 说教 = 把艺术当手术刀。** 检验：把台词里所有"讲道理"的句子删掉，故事是否照旧成立？成立 → 那些句子本来就不该在。

## §3 融合 B · 第三条轨道：渴望 vs 错误信念（**弧光的可建构版本**）

**为什么单列**：`drama-character-arc.md` 给了弧光的**类型**（A/B/C/D）与"一句话谎言"，但**没给建构步骤**。本节补的就是步骤——**它把"人物弧光"从判断变成可执行**。

**四步建构**：
```text
① 渴望：他想要什么——写到"闭眼能看见"的具体（不是"想被爱"，是"想让她把那句话再说一遍"）
② 为什么：这件东西对他意味着什么（一句话）
③ 错误信念：他坚信自己正确的那句话，因为在生命的某个时刻它曾经"对"过
   —— 不叫缺陷、不叫创伤：叫"曾经管用的结论"（「不麻烦别人，就没人能伤我」）
④ 原初场景：那个信念生根的瞬间——按第一人称、按时间顺序详写一页
   四问：进入前他旧信什么 / 为什么 / 这一场他要什么 / 他期望怎么实现
```
**三个转折场景**（必须写，不许省）：**每次离渴望只差一步，却因为错误信念而退缩**——**渴望与信念同时加强**。
**顿悟时刻**：结局不是"最后一幕的外部事件"，是**错误信念被打败、以新视野看世界的那一瞬**。**先写顿悟，再写最后一幕**。

**外部难题两测试**（两条都过才配当主线）：① 能升级到最后一页吗 ② 有没有倒计时/截止。
**内部两问**：① 它是否迫使人物反抗自己的错误信念 ② 情感伤害是否具体。

> **★ 与 AIGC 的接口**：**原初场景与三个转折场景不一定要拍**——它们是**写作工具**。落到 M8 时，只把它们的**结果**写成可拍之物（一个回避的动作、一个他不敢走的方向）。**判据：观众不需要知道原初场景，但必须感到它在起作用。**

## §4 融合 C · 主题、态度与风格（三条最容易被忽略的）

**C1 · 主题不变，态度变。** 主题定了就**永不改**；改的是**主角对它的态度**（开头是什么态度，结尾是什么态度）。
- **三问定主题**：主角想要什么？他在和什么斗争？主题词是哪一个（爱情 / 背叛 / 忠诚 / 成长 / 友谊 / 复仇 / 生存）？
- **主题试验台**：同一素材按六个不同主题各推一遍，**看哪个主题让人物最活**（工具，不是灵感）。
- **障碍 ≠ 对手**：**对手是那个"表现主题"的人**，纯粹的物理障碍不是对手。**这条能治"反派只是想毁世界"的病。**

**C2 · 风格由"人物性质 × 事件性质"的错配决定——不是先选风格。**
一个**迂酸可笑的喜剧性人物**，卷入一场**大悲剧**——**这就决定了全片风格："含泪的喜剧，微笑的悲剧"**。
- **自检**：各用一个词写下"主角的属性"和"事件的属性"；**两词相同 = 没有错配可用**，风格得另找依据（别硬贴"悲喜交融"）。
- **它与 A3 的关系**：错配是**反讽**的来源——这也是反讽钩子最好用的一种造法。

**C3 · 主题句先找"民间口头语"，再改写成人物的话。**
先有一句**流传在街头的话**（它自带真），把它**改成这个人物会说的句子**（它自带人）。
- **失效**：口头语与人物的语言层次差太远（文人角色说市井谚语）时**重写，不照搬**。
- **自检**：把改写后的句子**放回人物嘴里念一遍**——只有作者的声音、没有人物的声音 → 退回去。

## §5 融合 D · 中文戏剧工艺六诀（**本册新增的一整块**）

**来源提示**：本节方法出自中文编剧教学体系（陆军《编剧理论与技法》一系，经来源 1 的组织与转述）。**中文侧的工艺词（选材 / 立意 / 戏核 / 视角 / 板腔）此前在本库是空白**，故单列。

**D1 · 选材四忌四用**

| 四忌 | 四用 |
|---|---|
| **贪大求重**（题材大 ≠ 意义大；主人公觉悟高 ≠ 主题深——**流传的小戏珍品大都取材平常**）· **赶时髦**（一窝蜂题材"有一个与一千个价值一样"）· **缺乏戏剧性**（题材与体裁错位）· **容量不当**（把多幕的材料压成独幕，只剩干枯轮廓） | **用心选**——有感而发，选那个**几十年还留在心里**的东西 · **用身选**——写熟悉的；不熟就去泡现场（"新鲜于外，熟悉于内"）· **用眼选**——艺术发现（能不能看到这堆火**与别的火不同**）· **用戏选**——能入戏才选（冲突、动作、情感；短片再加"能不能拍"） |

**D2 · 六字诀：小 · 单纯 · 有戏核**
- **事件要小**：借一双靴、送一篮蛋、劝一回架——**"尖"字本身就是真理**。
- **情节要单纯**：**五分钟讲不清脉络的决不是好作品**。单纯 ≠ 单薄：**要把简单的事情复杂化**（讨西瓜 → 瓜秧 → 数瓜 → 瓜子）。
- **要有绝招**（杀手锏）：一场戏里那一处**别人想不出来的处理**。
- **★ 与本库容量的关系**：这三字诀在**任意时长**都成立——**片越长，越要靠"单纯"扛住，不是靠加线**。

**D3 · 开掘要深 = 立意（同素材，多想两步棋）**
- **四法**：**大环境，小故事**（把小故事放进时代背景考察，不要降格成个人恩怨）· **琢磨人物**（卡住时去琢磨一个**有特点的真人**）· **研究结尾**（立意的开掘过程就是不断研究结尾）· **象征的力量**。
- **三不等于**：**不拔高** · **不说教不图解**（"倾向应当从场面和情节中自然而然地流露"）· **不故作深沉**（删掉"好人坏人"标签戏仍成立，就别贴）。
- **表象真实 vs 本质真实**：历史/年代题材的开掘**不在官制、建筑、服饰、语言的复原**，而在**情感与人性状态的真实**。
  **判据**：**"能贯通古今的气场"——让人感到这段处境今天随时可能再发生。**

**D4 · 视角要新（同一题材，撞车不可怕）**
- 三种手法：**管窥**（写"看旗袍的姑娘"而不是"展销会全景"）· **聚焦**（同一事件靠性格不同写出不同的人）· **变形**（圣人被捕、活人讣告）。
- **判据**：**选那个"不正面写却尽得风流"的切口**。**忌**"哪里有戏往哪里挖"（那会散）。
- **与 AIGC 的接口**：视角选择同时是**成本选择**——"管窥"意味着更少的场景资产与更少的主体（→ `drama-scaling.md` §4）。

**D5 · 家乡层 vs 原乡层（本土题材尤其要过）**
靠方言笑料、土风土俗成立的是**家乡层**——**出了流行区域即失效**；靠"被代代告知的一组画面与声音"成立的是**原乡层**——**能打动没有那段经验的人**。
**自检**：**把全剧的方言笑料与风俗展示全部删掉，还剩下什么？** 剩不下 → 纯家乡层。

**D6 · 冲突要真（八病自检，逐条问）**
无社会意义 · **虚假** · 不准确 · 无戏剧特征（观点之争而非性格之争——**对问题的看法相同也可以冲突**）· 随意误会 · 避重就轻（半途转入陈套）· 虚晃一枪 · 缺乏张力。
**判据（别林斯基口吻）**：**双方都想占上风、都想刺痛对方性格的某一面、结果产生了新关系**——这才是戏。

## §6 融合 E · 戏核：抽掉它，戏还在吗

**定义**：在情节上**有延伸派生的生命力**、在冲突上**有抗衡激化的爆发力**、在内涵上**有穿透力**——**没有它构不成一个戏，没有它成不了"这一个"戏**。
（例：大学生故意摔碎另一只花瓶，再按阔太太的逻辑赔她三块钱。）

| 层 | 是什么 | 例 |
|---|---|---|
| **戏核** | **根**——抽掉就不成立 | 那个必须做的动作 / 必须成立的事 |
| **戏胆** | **枝**——起特殊作用的道具或关键情节 | 一把扇子 · 一封被改过的信 |
| **戏眼** | **叶**——关键人物或生动场面 | 让轿 · 一次当众的错认 |

**★ 唯一检验**：**抽掉它，戏是否还在？** 在 → 它只是枝叶。**并把"抽掉检验"写进 M12 的"最小改动"栏。**
**来源三处**：**日常细节**（丈夫的罚款 · 替小贩还的钱）· **人物心理的奥秘**（主人偷仆人的烟）· **想象世界**（把獾告上法庭 · 一磅肉）。
**承接**：`drama-plotcraft.md` 的"变量变形"落在这里就是**戏核的生成法**。

## §7 融合 F · AIGC 生产层（**只有这一节是"能不能拍"**）

**F1 · 生产标签语法**（可直写进剧本，交付时与后期对齐）

| 标签 | 用途 |
|---|---|
| `[VO]` | 旁白 / 内心（**不吃口型——本库最划算的写法**） |
| `[OS]` | 同场画外（人在空间里、不在画面内） |
| `[SFX]` | 必须被听见的现场音 |
| `[画面文字]` | **一律约定后期覆盖**（画面内文字是本库明列的高失败项） |
| `[连续性]` | 只交接"前文已建立、又容易在下游丢失"的状态 |
| `[转场]` | 转场方式（第 12 块"过渡压力"的兑现） |

**F2 · 场景编号的三档方言（**选一套，全片统一**）**

| 档 | 场景标题写法 | 用在哪 |
|---|---|---|
| **A 送审档** | `INT. LOCATION - NIGHT` | 海外投稿 |
| **B 中文工作档（默认）** | `内景 地点 - 日` | 本库默认（`script-format.md` §7） |
| **C 生产方言档** | `## EP001-SC001 内 · 地点 · 时间/天气` + 对白 `角色（表演提示）：台词` | **剧集/短剧流水线**（集号+场号便于下游引用；对白并行写） |

**F3 · "机关只在需要时上"（四条，防过度工程）**
**艰难选择**（两边价值都活着）· **证据边界**（先改变判断，再改变关系）· **精确死线**（先算动作容量，不要只写数字）· **有限单位**（次数/轮次/呼吸按"完成状态"计数）。
**纪律**：**输入没有以它为发动机时，一律不上机关**；**自检时如果剧本长出了输入没有要求的机关，撤掉机关，不要替它找理由。**

**F4 · 四条硬判据（可直接写进 M12 的自检栏）**

```text
① 阻力转向有可追溯的原因（事实 / 筹码 / 权限 / 代价 / 人物行动）——不能靠"对手忽然不反应了"
② 资源与外部反应必须来自输入或前文已建立——**不能替人物完成最难的戏剧行动**
③ 作者标签不能用来证明"镜头外从未发生某事"（标签只交接状态，不当证据）
④ 压缩时只保留会改变策略 / 关系 / 风险 / 结果的节点；无变化的场删掉或合并
```

**F5 · "去 AI 味"是定点修订，不是抹平个性。** 只修被点名的地方；**不因为"统一风格"把作者的语气磨掉**（→ `prompt-ops.md` 的空话词纪律仍适用）。

## §8 一页速查（融合后的十二条要点）

```text
① 前提推演以不可替换的结算动作为判据（见 A1），和解、放弃、认错与胜负也可完成结算
② 主控思想 = 价值 + 原因；只写在 M2，不进台词
③ 先选一种主义（理想/悲观/反讽正/反讽负），再写结尾
④ 先写高潮，再反推主题——不要先定主题硬写情节
⑤ 第三条轨道：渴望 × 错误信念；写原初场景 + 三个转折场景（工具，不必拍）
⑥ 顿悟先于最后一幕：结局是"错误信念被打败的那一瞬"
⑦ 主题不变，态度变；对手是"表现主题"的那个人，障碍不是
⑧ 风格 = 人物性质 × 事件性质的错配；两词相同就别硬贴
⑨ 主题句先找街头口头语，再改写成人物会说的话
⑩ 选材四忌四用 + 六字诀（小 / 单纯 / 有戏核）；五分钟讲不清的不要写
⑪ 戏核抽掉检验；冲突八病逐条过
⑫ 机关只在需要时上；自检长出机关就撤机关
```

## §10 六个可跑的融合动作（接 `drama-mastery.md` §2 的训练循环）

| # | 动作 | 20–40 分钟怎么做 | 判据 |
|---|---|---|---|
| **A** | **前提推演三跳** | 取一个前提三段式，照 A1 的五步往下推，**推三步** | 能推出一个**不可替换的"必须发生"** |
| **B** | **原初场景一页** | 给主角写那个信念生根的瞬间（第一人称、按时间顺序） | 写完你自己能说出"他为什么偏偏信了这句" |
| **C** | **顿悟先行** | 先写"错误信念被打败"的那一瞬，再倒推最后一幕 | 顿悟那一瞬**不靠台词**也成立 |
| **D** | **主题试验台** | 同一素材按三个不同主题各推一遍 | 选出**让人物最活**的那个，并说出另两个死在哪 |
| **E** | **戏核抽掉检验** | 抽掉自认的戏核，重读全片 | 戏**塌了**才算戏核；没塌 → 它是枝叶 |
| **F** | **冲突八病体检** | 逐条问自己的主线冲突 | 八条里命中 ≤1 |

## §11 门禁与自检接入

**可机器判的（已接）**：`script_lint.py` 已经覆盖 M8 版式、密度、语速、俗套黑名单、交接契约、诊断副作用栏——**本册的方法层不改门禁口径**。
**必须人工判的（写进 M12）**：
```text
① 前提推演：能推出"不可替换的一步"吗？
② 主控思想：价值 + 原因，两个成分都在吗？
③ 主义选型：理想 / 悲观 / 反讽（正 / 负），写出来了吗？
④ 错误信念：能写成他会真心相信的一句话吗？
⑤ 顿悟是否先于最后一幕？
⑥ 对手是不是"表现主题"的那个人（而不是障碍）？
⑦ 戏核抽掉检验：抽掉它，戏塌了吗？
⑧ 冲突八病：命中几条？
⑨ 机关四条：有没有上"输入没要求"的机关？
⑩ 适用范围自检：**这份作品是"被带进处境"，还是"准确拿到信息"？**
```
