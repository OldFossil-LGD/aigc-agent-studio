# 转场库：把两个画面接起来的十四种手法

> **何时读**：要"从这一镜进到下一镜""从这一镜进到下一镜"，或者觉得**切得太硬、太单调**的时候。
> **读完回哪**：段内的回到 `segmented-shot.md`（按段落填）；两镜之间的回 `shot-craft.md`（填过渡压力）。
>
> **分工**（三份文件不要互相抄）：
> - 本文 = **有哪些转场手法 / 各自长什么样 / 什么时候用 / 句式怎么写**（**转场词库在本文**）
> - `segmented-shot.md` 第六节 = 转场**写在提示词的什么位置**、默认硬切、两条护栏
> - `shot-craft.md` = 两镜之间的**过渡压力**与情绪连续性（**【过渡压力】块的写法**在这里）
> - `shot-craft.md` = 【进入下一镜的过渡压力】块的填写位置（**块里要填的转场「词」取自本文 `transition-library.md`**）

## 一、先分清两个层级（搞混就白写）

| | **A · 同镜内镜间转场** | **B · 跨镜剪辑点** |
|---|---|---|
| 发生在哪 | **一条生成里的两个镜之间** | 两条生成（两个镜）之间 |
| 谁执行 | **模型**，写在镜序里 | **首尾帧衔接**，或**后期剪辑** |
| 能做什么 | 只做**视觉可见的连续过渡**（糊、闪、遮、化） | 什么都能做，但**多数靠剪辑软件** |
| 典型手法 | 匹配切、甩镜、推穿、遮罩、白闪、墨染 | 硬切、叠化、划像、J-cut / L-cut |
| 写在哪 | **写在后面那一镜的开头** | 写在【过渡压力】块，或留给剪辑 |

> **两条护栏（只管 A）**：`画面无硬切，物体不凭空出现或消失。`
> 为什么必须有：平滑类转场最容易崩的两件事，就是模型**自作主张加一个硬切**，
> 或者**在过渡中把某样东西变没了**。硬切（B 层）不需要这两句。

**选择顺序**：**先问要不要转场**——同场景只换机位，**硬切最好**，别加戏。
转场是**叙事工具**，不是装饰；**它不推进叙事的时候，就是在烧预算。**

## 二、相似转场（Match Cut / 匹配剪辑）★

**定义**：上一镜**末尾画面的某个元素**，成为下一镜**开头画面的同一个元素**，
中间用"相似"把这层跳跃**缝起来**。观众读到的不是"切了"，而是"**这两件事是一回事**"。

**它的价值不在顺滑，在"意义"**——它是**隐喻**（这个＝那个）和**时空跳跃**（这里＝那里）的工具。

### 三种匹配（按可靠度排序）

| 匹配类型 | 怎么接 | 可靠度 | 例子 |
|---|---|---|---|
| **形状匹配** | 上一镜末尾的**轮廓/圆形/线条**，成为下一镜开头的同形状 | ★★★ **最稳** | 圆月 → 圆碗；铜钱 → 戒尺的圆头 |
| **动作匹配** | 同一个**运动的方向与速度**连续下去 | ★★☆ | 旋转的唱片 → 旋转的车轮（转向与转速一致） |
| **概念匹配** | 两者在**语义**上同类（不是视觉同类） | ★☆☆ 最险 | 捏碎核桃 → 捏碎一张纸 |

> **只做形状匹配，除非镜有余量。** 概念匹配最像导演手法，也最容易被模型理解错。

### 写法（三步）

1. **上一镜末尾**明写那个交接物的**形状、位置、大小、运动**：
   `画面最后停在[某物]，[形状描述]，占据画面中央约三分之一，[运动描述]`
2. **下一镜开头**用**同一个词、同一个形状**接上：
   `[同形状的新物]，同样位于画面中央约三分之一，[同样的运动]`
3. **命名交接物**——**这一步最容易被漏，但它是成败关键**：
   ✅ `一片正常大小的落叶飘进镜头，把画面完全遮黑`
   ❌ `有什么东西挡住了镜头`
   **说不出是哪片叶、哪个角，模型就会给你一个随机的东西。**

### 可复制模板

```
[全局：主体锚点句 + 场景陈设 + 时段与光源方向]

镜1：[景别]，画面最后停在[交接物A]，[形状]，位于画面中央约三分之一，[运动]；
摄影机[一个运动]。

镜2：匹配切——[交接物A]的[形状]成为这一镜的开头。
[景别]，[交接物B：同形状]，同样位于画面中央约三分之一，[同样的运动]；
[交接物B]缓慢展开，露出[新场景/新主体]；摄影机[一个运动]；
结尾停在[明确状态]。

恰好 2 个镜头与 1 个切点，不多不少，没有额外插入镜头。
全程保持不变：[量级与色调]、画幅、[光源方向与色温]。
匹配切以[交接物A]的形状为准，[交接物B]与它在画面中的位置、大小、朝向一致。
画面无硬切，物体不凭空出现或消失。
无配乐，只保留现场音：[列出 2–3 个关键环境音]。
```

## 三、动作转场（Action Match Cut / 动作接力）★

**定义**：**同一个动作**在两个（或多个）空间里**接着做完**——
上一镜里动作**没做完**，下一镜从**同一个姿势**继续。切口藏在**运动的动能**里，看不见缝。

> **与相似转场的区别**：相似转场匹配的是**形状**（静态元素）；
> 动作转场匹配的是**运动**（动态过程）。**动作转场天然更顺，形状转场天然更有隐喻。**

**它最值钱的地方**：让"换地点""换时间""换装"这种硬跳变得**像是同一次动作的延长线**。

### 切点落在哪（这条决定成败）

**切在动作的"可读峰值"上，不要等动作做完。**

> **❌ 错误**：角色完整地跳起来并落回地面 → 切 → 下一镜他已经在新地方站着
> ——动作做完了，切点暴露。
>
> **✅ 正确**：角色起跳，身体刚离地、四肢形态最清楚的那一帧 → 切 → 下一镜从同一姿势落下
> ——动能接着走。

**动作转场的三种形态**：

| 形态 | 怎么接 | 例子 |
|---|---|---|
| **接力** | 动作**出画**，下一镜**入画**接着做 | 上一镜跳起出框 → 下一镜从上方入框落下 |
| **换壳** | 同一个动作、同一个人，**环境换了** | 同一记挥拳，背景从巷子变成拳台 |
| **错位** | 同一动作由**不同的人/物**完成 | 他扔出的球 → 下一镜另一个孩子接住 |

### 可复制模板

```
[全局：主体锚点句 + 两处场景陈设 + 光源方向]

镜1：[景别]，[主体锚点句]开始[一个动作]，动作进行到[最清楚的姿势]；
摄影机[一个运动]；动作在此处**尚未完成**。

镜2：动作接力——从上一镜**同一个姿势**继续，[主体锚点句]完成[同一个动作的后半]；
背景已更换为[新场景]，[新场景的两个可见标志物]；摄影机[一个运动]；
结尾停在[明确状态]。

恰好 2 个镜头与 1 个切点，不多不少。
切点落在[动作]最清楚的那一帧上，切点两侧[主体锚点句]的姿势、朝向、运动方向连续一致。
全程保持不变：[量级与色调]、画幅、[服装]、[光源方向与色温]。
画面无硬切，物体不凭空出现或消失。
无配乐，只保留现场音：[列出 2–3 个关键环境音]。
```

> **验一条**：把切点前后各两帧截出来并排看——**姿势能不能接上**。
> 接不上就是动作转场没成立，回去把"最清楚的姿势"写具体（写清四肢位置，别写"跳起来"）。

## 四、其余十二种（速查表，含"让模型自选"兜底项）

| 转场 | 它到底做什么 | 稳 | 用在 | 句式 |
|---|---|---|---|---|
| **硬切** | 瞬时切换，什么都不做 | ★★★ | **同场景换机位（默认）** | `切至…` / `直切…` |
| **叠化** | 两画面同时存在并交叉溶解 | ★★★ | 时间流逝、回忆、梦境 | `叠化：前一画面逐渐淡去的同时，新画面逐渐浮现` |
| **淡入淡出** | 渐隐到纯黑/纯白，再渐显 | ★★★ | 段落起止、章节分隔 | `画面逐渐隐入黑色，停留约0.5秒，再逐渐显出` |
| **划像** | 一条边线扫过，把旧画面推走 | ★★☆ | 风格化、复古、双线对照 | `一条边缘自左向右扫过画面，旧画面被推走，新画面露出` |
| **甩镜转场** | 摄影机快速甩动，模糊接住切换 | ★★☆ | 能量延续、跨地点硬跳（见 `camera-movement-library.md` §4.2） | `摄影机急速向左甩动，全程运动模糊，模糊消散后已是[新场景]` |
| **推穿** | 摄影机推进一件深色物体（杯口/门洞/屏幕），黑场后穿出到新场景 | ★★☆ | 场景穿越、进入"里面" | `摄影机推入[深色物体]，画面被黑暗充满，随即从黑暗中推入[新场景]` |
| **缩放穿越** | 放大某个细节直到它**变成下一个世界** | ★★☆ | 尺度跳跃、由微观到宏观 | `摄影机放大[角色的瞳孔]，直到它充满画面，画面在瞳孔内部展开为[新场景]` |
| **遮罩擦除** | 一件前景物扫过镜头遮黑 → 露出新场景 | ★★☆ | 换场景（与遮挡切同源） | `[前景物]扫过镜头，画面完全变黑，物体移开后已是[新场景]` |
| **白闪** | 画面被强光充满，散开后换场 | ★★☆ | 强转折、撞击、耳光、失控 | `画面爆发为纯白强光，光散去后已是[新场景]` |
| **墨染** | 画面像墨滴入水一样散开 | ★☆☆ | **风格化片专用**（水墨/国风） | `画面像浓墨滴入水中一样散开，新画面从散开的墨迹中浮现` |
| **形态转变** | 主体自身融化重塑为另一个东西 | ★☆☆ | 角色变化、前后对比、超现实 | `[主体A]缓慢重塑变形，成为[主体B]，过渡过程中无硬切` |
| **让模型自选** | 只给情绪，让它挑机制 | ★★☆ | 只知情绪、不知机制时 | `从[硬切/遮罩/墨染/匹配切]里挑最适合这一段的一种` |

> **可靠度读法**：★★★ 基本不出错 ｜ ★★☆ 需要护栏 + 一次抽卡余量 ｜ ★☆☆ 风格化片专用，写实片慎用。
> **风格化片与写实片的差别**：墨染、形态转变在**风格化片**里成立，在**写实片**里会读成"特效感"。

## 五、声音转场（跨镜层，剪辑时用）

| 手法 | 定义 | 效果 |
|---|---|---|
| **J-cut**（声音先入） | 下一镜的声音**先于**画面出现 | 让人**期待**下一镜，转场不突兀 |
| **L-cut**（画面先入） | 上一镜的声音**延续到**下一镜画面上 | 让两镜**连成一个空间** |

**在我们这条路上**：J/L-cut 属于**后期剪辑**（`post-production.md`），
不要写进视频提示词——写实拍的"声音层"另见 `sound-craft.md`。

## 六、综合示例：五镜五转场（风格化短片）

同一场戏里**每镜换一种转场**，是练手最有效的写法。骨架如下（每镜都要带**主体锚点句**）：

```
[全局] 深夜，竹林客栈。水墨国风二维动画质感，边缘带墨线，冷月光压暖烛火。
[主体锚点句][角色锚点]，22岁剑客，眉峰锋利，高马尾，白袍黑边，桌上的剑鞘为黑色。
[禁止项] 无三维塑料感、无字幕水印。墨染效果只允许出现在最后一镜的那一声之后。

镜1：匹配切——圆月停在画面中央，月面渐暗，被一只同样圆的酒碗自上而下替换，
月光在酒面上反光；摄影机固定。
镜2：缩放穿越——剑客眼神转利，摄影机放大他的瞳孔直到它充满画面，
瞳孔内部展开为竹梢上一个刀身朝下扑来的身影；摄影机缓慢推进。
镜3：甩镜——随他拔剑的手臂向右急速甩动，全画面运动模糊；
模糊消散处，剑与匕首在半空相撞，溅出橙色火星；摄影机跟随手臂。
镜4：遮罩擦除——相撞的气浪掀动一片竹叶横过镜头，画面完全变黑；
叶片移开时已是地面高度，背景中对手倒地，前景中剑客正在收剑入鞘，背对镜头。
镜5：墨染——剑入鞘的"咔"声上，整幅画面散成黑白水墨并向四周晕开；
结尾停在画面完全散为黑白水墨的状态。

恰好 5 个镜头与 4 个切点，不多不少，没有额外插入镜头。
全程保持不变：[主体锚点句]、服装、剑鞘颜色、光源方向与色温、画幅。
画面无硬切，物体不凭空出现或消失。
无配乐，只保留现场音：竹叶擦响、剑与匕首相撞的一声脆响、剑入鞘的"咔"声。
```

> **这个例子的教学价值不在画面，在结构**：**每一镜都有明确的转场名 + 交接物**，
> 而**全局约束写在镜号之外**（才管全程）。这是分段镜 + 转场库的合体用法。

## 七、失败模式

| 症状 | 原因 | 修法 |
|---|---|---|
| **转场很花，叙事没动** | 用了炫技转场 | 同场景换机位**一律硬切**；转场只在推进叙事时用 |
| **交接处"跳"了一下** | 两个锚点帧差太远（颜色/高度/光向不同） | 让两侧**共享更多**：同色、同机位高度、同光向 |
| **物体凭空出现/消失** | 没写护栏 | 补 `画面无硬切，物体不凭空出现或消失` |
| **形状没对上，像两个不相关的镜头** | 交接物**没命名** | 把交接物写具体：`一片正常大小的落叶` 而不是 `什么东西` |
| **动作转场接不上** | 切点没落在动作的可读峰值 | 写清"最清楚的姿势"（四肢位置），让动作在切点处**尚未完成** |
| **匹配切变成了普通叠化** | 只写了"相似"，没写具体形状与位置 | 补 `位于画面中央约三分之一`、`与上一段在位置、大小、朝向一致` |
| **墨染/形态转变用错片种** | 写实片里用了风格化转场 | 写实片改用遮罩擦除或甩镜 |
| **模型自作主张多切了几刀** | 镜数与切点数没写死 | 全局约束里写 `恰好 N 个镜头与 N-1 个切点，不多不少` |
