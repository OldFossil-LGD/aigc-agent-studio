# 镜头调度与组接：一场戏该用哪几个镜、什么顺序、各多长

**何时读**：排分镜表的时候——尤其是**不知道开场怎么起、结尾怎么收、动作戏怎么切**的时候。
**读完回哪**：回 `studio-workflow.md` 第三步，把选好的镜头组合填进每镜的板块二。

> 一句话：**镜头不是画面，是信息单位。**
> 组接不是"把画面接起来"，是**决定观众在每一秒知道什么、不知道什么**。

> **★ 本篇不是起点，是校验清单。**
> 先走 `direction-reasoning.md` 的六问推导链（命题 → 人物 → 戏剧任务 → 冲突形状 → 能量），
> 推出这一场该是什么样之后，**再拿本篇校验有没有漏**。
> 反过来——拿着剧本查"这场属于哪一类、该用哪套配方"——出来的一定是**正确但空心**的东西：
> 类型是结果，不是原因。**因果在前，配方在后。**

**分工（五份文件各管一层，不要互相抄）**：

| 管什么 | 在哪 |
|---|---|
| **从主题与人物推导出镜头语言（先做这个）** | **`direction-reasoning.md`** |
| **选哪几个镜、什么顺序、多长、开场与结束（推导完之后校验）** | **本篇** |
| 一场戏的序列契约、几何用图、情绪连续性 | `sequence-craft.md` |
| 两镜之间的转场手法（12 种） | `transition-library.md` |
| 一条生成里装多景别（按段落分段） | `segmented-shot.md` |
| 单镜的构图与镜头规格（★ 排完镜逐镜过「**拆镜开关**」：画框 / 轴线换过没有？动作超过一个没有？命中就拆） | **`shot-craft.md`**（★★★ 节） |

## 一、五种镜头（一套最小词汇）

排镜之前手里只有这五个词，别多也别少：

| 镜头 | 装下什么 | 它的唯一职能 |
|---|---|---|
| **主镜头**（全景） | 全部人物与关键陈设 | 定地理关系，同时是保底镜 |
| **中景** | 腰部以上，或两个人 | 关系与体态 |
| **特写** | 一张脸 | 情绪落点 |
| **过肩** | 一个人肩后看向另一个 | 谁在听（不是谁在说） |
| **插入与切出** | 手、物件、环境细节 | 补信息，同时掩接缝 |

**两人对话的最少配置**（业界覆盖公式）：`1 主镜头 + 2 过肩 + 2 特写 + 若干插入` = **至少 5 镜**。
每多一个人加一镜；有剧情关键物件就补插入。

**只做"必须层"**：镜头分三等——**必须**（缺了这场剪不成）、**该有**（帮助节奏）、**可选**（有余量才拍）。
AI 场景**只做必须层**，可选层一律砍掉——每多一镜就是多一次抽卡与多一个漂移点。

## 二、四种拍法（这一场怎么拍完）

| 拍法 | 怎么拍 | 什么时候用 |
|---|---|---|
| **由远及近法** | 主镜头 → 中景 → 特写，逐层收紧，最后补艺术角度与插入 | **默认**；对白与情绪递进 |
| **主镜头法** | 先一条完整全景贯通全场，再补中近特 | 有把握的长对白；主镜头同时当首帧来源 |
| **重叠法** | 相邻两镜**重复一小段动作**，靠重叠接上；不需要主镜头，不要求整场重演 | **动作不能重复时**（爆炸、车毁、不可逆动作） |
| **一镜到底** | 全一场一条，靠调度撑，不打算补镜 | 短场、调度强；受平台单镜上限约束 |

**为什么"由远及近"是默认**：它每一步**只改取景与角度，其余元素保持不变**——
这正好是模型最能稳住的做法，与 `asset-consistency.md` 的"锁死块 + 镜头块"是同一原理。

## 三、★ 不同情景的镜头组合配方

这一节是本文件的主体。拿到一场戏，先判断它属于哪一类，再照行填：

| 情景 | 入场镜 | 中段推进 | 峰值 | 出场 |
|---|---|---|---|---|
| **两人对话** | 中景双人 | 过肩来回，逐轮收紧 | 关键决定落在**特写** | 拉回全景 |
| **动作 / 打斗** | 全景定方位 | 中景跟拍 + 特写穿插 | 撞击或落点的**大特写** | 硬切或定格 |
| **悬念** | **先紧**：特写、构图失衡 | 慢慢拉宽，**边宽边露** | 全景露出真正的威胁 | 切黑，或停在最后一张脸 |
| **揭示** | 关键细节的特写 | 退到中景，信息逐层给 | 全景或升起，全貌出来 | **停在人物反应上** |
| **追逐** | 全景定方位 | 追、逃、障碍三组短镜交替 | 大特写（脚 / 手 / 呼吸） | 硬切进下一场 |
| **独处** | 中景，人在环境里 | 推近到特写 | 最小的动作（手、眼） | 拉远，把人留在环境里 |
| **蒙太奇** | 按第一个节拍走，用相似形缝合 | 节奏驱动，不按叙事 | — | 末镜**呼应首镜** |

**★ 两条元规则（都是反直觉的，值得记住）**：

1. **动作序列朝峰值压缩**——越切越快、框得越紧；**悬念正相反**——起手紧，然后一路放宽去建恐惧。
   把这两类搞反，动作戏会散、悬念戏会泄气。
2. **景别的方向本身就是叙事**：由宽到近＝把观众拉进来；由近到宽＝把观众放开。
   "要不要推近"不是一个技术选择，**是一个关于观众距离的叙事选择**。

**经典五镜序列**（拿不准时用这个兜底）：主镜头 → 中景 → 过肩 → 特写 → 切出。

## 四、接得住：五条硬规则

镜头选对了，还要接得住。前四条本库已有专门定义，这里只给判据与指针；**第五条是本篇新加的**。

| 规则 | 判据 | 详处 |
|---|---|---|
| **180 度轴线** | 机位留在动作轴线同一侧；谁在左谁在右不许翻 | `character-continuity.md` 两条轴线纪律 |
| **视线匹配** | A 看画面右 → 切到 B 时 B 必须看画面左 | `sequence-craft.md` 切点五类型 |
| **动作接动作** | 在动作**进行到一半**时切，不在做完之后切 | `transition-library.md` 动作转场 |
| **方向连续** | 定了"从哪往哪走"，切点不许换边 | `character-continuity.md` |
| **★ 30 度规则** | 见下 | **本篇** |

### 30 度规则（同一主体连切两镜时用）

机位必须**至少转 30 度**，转得不够就会被读成**跳切**——观众会觉得"他瞬移了一下"。

- **角度和景别要同时变**。只转角度不够好，"全景 → 特写"一起变才最稳。**45 度是甜点**。
- 来不及量就用土办法：**往侧边迈两大步**，几乎总是够。
- 焦段也有门槛：视角不变时，**焦段变化不足 20 毫米**同样像跳切。
- **最狠的一条判据**（剪辑师 Walter Murch）：
  > "我们最难接受的是那种**既不细微又不彻底**的位移——比如从全身主镜头，切到一个把人从脚踝以上框起来的稍紧镜头。
  > 变化大到让人察觉'有东西变了'，却又小到不足以让人重新理解画面。"

→ **"变了但没变够"比"完全不变"更难看。** 排镜时逐对检查相邻两镜：要么差别够大，要么干脆别切。

**30 度和 180 度是两件事，要同时满足**：180 度管空间（别翻边），30 度管时间（别跳）。
正确做法是在轴线的**同一侧弧线上**移动至少 30 度。

## 五、开场镜头怎么选

先回答三问，再查表：

1. **观众第一秒最需要知道什么？**（这是哪儿 / 这是谁 / 有危险）
2. **这部片的第一印象该是"静"还是"动"？**
3. **结尾要呼应什么？**——开场一开就把呼应物埋下，结尾才有东西可收。

| 开场的叙事任务 | 用哪种起手 |
|---|---|
| 让观众知道"这是哪儿" | **定场远景**（信息一次性给足） |
| 让观众先认人，而不是先认地方 | **特写开场**（先给脸，后给环境） |
| 让人立刻紧张起来 | **先紧后宽**（起手特写，再拉开） |
| 让人立刻进入事件 | **中途开场**（动作进行到一半接进去） |
| 要交代时间跨度或前史 | **蒙太奇开场** |
| 需要解释，但画面难演 | 旁白开场（AI 片慎用，口型是高风险项） |
| 只想定调，不急着叙事 | **象征意象空镜** |
| 要建立"跟着他"的视角 | 追踪长镜或主观视角 |

> **与 `script-craft.md`「3 秒钩子」的分工**：钩子管的是**内容层**（演一件什么反常的事），
> 本篇管的是**镜头层**（用什么景别与机位去装它）。两者都要，前者定"演什么"，后者定"怎么框"。

## 六、结束镜头怎么选

**实证**：105 部电影里 **45 部**用"句号式"结尾——**这是默认，不是巧合**。

| 结束型 | 长什么样 | 什么时候用 |
|---|---|---|
| **句号式** | 摄影机退出去，人物变小，环境把他吞掉 | **默认**；余味、孤独、命运感 |
| **收束式** | 画面边缘收拢成一个圆，收在最后一张脸或一个物件上 | 复古、童话；像"合上书" |
| **蒙太奇式** | 一组短镜交代"后来" | 需要补完人物去向 |
| **★ 首尾呼应** | 末镜复制首镜的构图或物件，但状态已经变了 | **AI 短片最该用**——见下 |
| **最后一击** | 收在最后一下反转或惊吓上 | 惊悚 / 恐怖；前面必须有铺垫 |

**为什么推荐首尾呼应给 AI 短片**：每镜都是独立生成的，全片最缺的就是**整体感**。
而首尾呼应**只用一次构图复用**，就换来了"走完了一圈"的感觉——**性价比最高的一招**。
做法是：开场那镜的构图、机位、物件原样搬回来，只改变状态（人走了 / 灯灭了 / 位置空了）。

> **判据**：**结束镜的职责是把情绪落地，不是把信息说完。**
> 想再补一句说明，说明前面没演够——回去改前面，别在结尾加戏。
> 与"结尾留白"（`cheatsheet.md`）的关系：留白是内容层的克制，本篇是镜头层的选择。

## 七、★ 动作场面：镜头长度与节奏

**平均镜头长度的实测演进**：

| 年代 | 平均镜头长度 |
|---|---|
| 1930–1960 年代 | 8–11 秒 |
| 1980 年代 | 5–7 秒 |
| 现代动作片 | **短于 3 秒** |
| 极端值 | 《移魂都市》**1.8 秒** |

**节奏方向**：镜头**一路变短**建紧张（加速）；**一路变长**促沉思（减速）。
本库基线另有：短视频平均 1.8–2.2 秒、AI 单镜 2–3 秒为黄金（见 `post-production.md`）。

### ★ 一条 AI 特有的修正（别照搬真人的做法）

**真人快切靠"短"——把单镜压到一两秒。AI 不能这么干。**
每个镜都是独立生成，单镜越短，留给模型定型与展开表演的时间越少，崩得越厉害。

> **AI 动作场的正确做法：单镜守在 2–3 秒，靠"景别与机位的变化"造速度感，而不是靠缩短单镜。**（2–3 秒指**成片有效长度**；生成投喂取所用模型档位 ≥4s——平台单次生成下限 4s 见 `sequence-craft.md` §8.3——多余秒数供剪辑修剪。）本条只适用于**普通单镜**；`camera-movement-library.md` §4.3 的「三个分量 ≥5 秒」属**生成层**时长，与本条成片层口径分属两层、不冲突。【2026-09-30 复核：原「待确认项」（不可同时满足、原数值暂不改）按生成层/成片层分层后消除，撤销"暂不改"。】

也就是说：同样是"快"的观感，真人用**时长**换，AI 用**变化量**换。
四镜都是 2.5 秒、但景别从全景跳到大特写、机位每次都换边（仍在轴线同侧），
读起来比四镜 1 秒的碎切更紧张，而且**每一镜都还有足够的秒数让它立住**。

**可写句式**：`本场共 4 镜，每镜约 2.5 秒；景别依次为全景、中景、特写、大特写，机位每次换边但保持在动作轴线同一侧。`

## 八、★ 接不住时的三条补救（AI 专属）

两镜怎么都接不上，是 AI 分镜的常态。硬接一定是错的，用这三条：

**1. 插一个桥接镜**
中间加一个**中性小镜**——一只手、一个物件、一片环境、一个背影，1 到 1.5 秒就够（成片时长；从 4s+ 素材截取或用静帧节点，不单独生成）。
它的唯一作用是把两个不匹配的镜头**隔开**。观众读到的是"看了一眼别处"，读不到接缝。
> 什么时候用：两个镜的光线方向、人物位置或动作速度差太多，硬切一定会跳。

**2. 首末 3 秒规则**
瑕疵出现在镜头的**开头 3 秒或结尾 3 秒**，这一条就不要（剪掉，或重生成）。【2026-09-30 分层收口】本规则适用于 4s+ 生成素材修剪；成片短镜不依赖首尾修剪（原「待确认项」撤销）。
原因很简单：**剪辑点必然落在首尾**，瑕疵在首尾等于**把缺陷正好放在接缝上**。
中间 3 秒以后的小瑕疵反而可以留——它大概率会被剪掉或不被注意。

**3. 只在剪切点检查**
不要逐帧审全片。只把**前一条的末秒**与**后一条的首秒**并排摆在一起，查六项：

| 查什么 | 对不上的后果 |
|---|---|
| 注视方向 | 两个人看着不同地方，像各演各的 |
| 主体在画面里的位置 | 人物瞬间挪了位 |
| 手的位置 | 手凭空换了个姿势 |
| 运动方向 | 左往右接上右往左，读成"掉头" |
| 光线方向 | 光从左边变成右边，一秒穿帮 |
| 背景几何 | 墙角、门框对不上，空间塌了 |

六项里只要一项对不上，就插桥接镜，或者重生成后一条。

## 九、落地：一张排镜表

选定了组合，落成分镜之前先填这张表——**它比直接写提示词省事，因为错误在这一层改起来是免费的**。

```
【排镜表】第 [N] 场 · [情景类型] · 总时长 [X] 秒 · 共 [N] 镜（时长列＝成片有效长度；每镜生成投喂取所用模型档位整秒，默认 4–15s，余量供剪辑修剪）

开场镜：[类型] —— 理由：[观众第一秒需要知道什么]
收尾镜：[类型] —— 呼应：[开场埋下的哪个东西]

| 镜 | 景别 | 机位与角度 | 这一镜的唯一信息 | 时长 | 切点落在 |
|---|---|---|---|---|---|
| 1 | 主镜头 | 视平、正面 | 两人在同一空间，相距约两步 | 3.0s | 第一句说完 |
| 2 | 过肩 | A 肩后看向 B | B 在听，而且在躲 | 2.5s | B 抬眼的瞬间 |
| 3 | 特写 | B 正面，略仰 | B 的决定落在眼睛上 | 2.5s | 动作进行到一半 |
| 4 | 插入 | 俯拍桌面 | 那张纸被推了过去 | 1.5s | 手移出画面 |
| 5 | 全景 | 缓慢拉远 | 两人分开，空间变大 | 3.0s | — |

相邻两镜机位差均 ≥30 度、且都在轴线同侧：是
单镜均 ≥2 秒（动作场不靠压时长造速度）：是
```

**填完自查三问**：

1. **盖住"唯一信息"那一列再读**——如果两行说的是同一件事，删掉一行。
2. **相邻两镜的机位差够 30 度吗**？不够就往侧边迈两步，别硬切。
3. **每一镜都 ≥2 秒吗**（桥接镜除外，见 §八）？有短于 2 秒的，问自己是不是在照搬真人的快切。

> 表里"这一镜的唯一信息"是**最难填也最值钱**的一列：填不出具体信息，说明这一镜不该存在。

## 十、失败模式

| 症状 | 原因 | 修法 |
|---|---|---|
| 每个镜头都一样大，看得发困 | 没走由远及近，缺景别落差 | 按主镜头 → 中景 → 特写重排 |
| 切得飞快，却一点都不紧张 | 照搬真人做法，把 AI 单镜压太短 | 回到 2–3 秒，改靠景别与机位变化 |
| 两人对话像各说各的 | 缺过肩镜，视线没对上 | 补双向过肩；逐对查注视方向 |
| 一接就"跳" | 机位变化不足 30 度 | 往侧边两大步，同时换景别 |
| 变了又没变够，说不出哪里别扭 | 中了"既不细微又不彻底"的坑 | 要么差别够大，要么干脆别切 |
| 结尾散，不知道这片子在说什么 | 结束镜没选型 | 按第六节选一种；默认句号式 |
| 动作戏看不清谁打谁 | 只有中近景，缺地理全景 | 先用全景定方位，再进近景 |
| 两镜死活接不上 | 在硬接 | 插桥接镜，别硬来 |

## 来源与署名

- **Wikipedia《30-degree rule》**（CC BY-SA 4.0）：30 度规则与"20 毫米 / 30 度"的等价表述、轴向切作为例外、**Walter Murch《眨眼之间》关于"既不细微又不彻底"的位移判据**（引文经中文重述）。
- **visualfoodie.com（两篇）**：30 度与 180 度的分工对照（时间连续 vs 空间连续）、45 度为甜点、"往侧边两大步"的土办法、角度与景别同时变。
- **FilmDaft《What is Coverage in Film?》**：覆盖的定义、**四种拍法**（由远及近 / 主镜头法 / 重叠法 / 一镜到底 / 自由三遍法）。
- **StudyCalcHub《Storyboard Shot List》**：两人对话的覆盖公式（1 主镜头 + 2 过肩 + 2 特写 + n 插入）。
- **MindMapNote《Film Production and Cinematic Storytelling》**：覆盖三等分（必须 / 该有 / 可选）。
- **DrawStory.ai《Cinematic Shot Sequence in Storyboard》**：**按情景分类的镜头序列模式表**（对话 / 动作 / 悬念 / 揭示 / 蒙太奇的入场—推进—峰值—出场）、"动作朝峰值压缩、悬念反向放宽"的元规则、景别方向即叙事。
- **arXiv 2303.14491**（105 部电影结尾镜头实证）：**45 部用句号式结尾**这一数据；另参考 scriptarsenal、whatsafterthemovie 对收束式 / 蒙太奇式 / 首尾呼应 / 最后一击的归纳。
- **Bordwell《Intensified Continuity》**：平均镜头长度的年代演进（8–11 秒 → 5–7 秒 → 短于 3 秒；极端值 1.8 秒）与加速 / 减速节奏方向。
- **cliprise / domer / versely / soprompts**（AI 视频工作流）：**桥接镜**、**首末 3 秒规则**、**只在剪切点检查六项**、运动方向匹配、锁死块与镜头块分离。
- **本库自建**：五种镜头的中文化命名与"必须层"取舍、第三节"追逐 / 独处"两行配方、第七节"AI 快切靠变不靠短"的修正、第九节失败模式表。
