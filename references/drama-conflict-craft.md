# 冲突的工程：形状、过渡、出击点与动机工具箱

> **何时读**：戏"平"或"水"时；人物做出不像他的事时；冲突忽然跳级或原地打转时；要给动机补深度时。
> **读完回哪**：人物与弧光 → `drama-character-arc.md`；单集结构 → `drama-episode-structure.md`；诊断 → `drama-script-diagnosis.md`。
> **适用**：剧本 / AIGC 写作。**NOT for** 技术文档 · 论文 · 新闻 · 公文（→ `writing-methods.md` §0）。
> **本册补的是什么**：`drama-character-arc.md` 管**人物与对手是什么**；**本册管"冲突怎么动"**——四类形状、过渡、出击点、逐场规模、以及让动机深下去的心理学工具箱。**这一层此前全库为空。**

---

## §0 一句话：冲突不是"有没有"，是"什么形状"

**"天底下没有一个行动是无因无果独自发生的"**，而**"行动不比驱使它的因素更重要"**。
→ 所以诊断的第一步**永远不是"冲突够不够"，而是"这是什么形状"**。形状错了，加量只会更糟。

## §1 ★ 四类冲突（Egri · **本册的核心工具**）

| 型 | 特征 | 症状 | 处方 |
|---|---|---|---|
| **① 静止型** | 人物同型、无信念、无决定 | "你爱我吗"——"我不知道"**可以撑一个月**；风趣对话但不推进；两幕半全在点酒跳舞 | 给双方**各自一个不可让的立场** |
| **② 跳跃型** | **跳过步骤、做出不符性格的举动** | 看到一件旧西服就抢银行；删节版里反派**未经反驳**就变得善解人意 | **补过渡**（见 §2） |
| **③ 升级型** | **清晰前提 + 编排合理的三维人物 + 紧密对立统一**的产物 | 攻击 → 反击**必须比攻击更强烈** → 再攻击 →…… | 这是**最稳的入口之一**（④ 预示与 §4 危机—高潮—结果同样成立，只是更难写稳） |
| **④ 冲突的预示** | 对**后续必将发生的冲突的承诺** | 三分之二没有正面冲突，观众仍屏息 | 靠"意志坚定的人物本身"勾起期待 |

**★★ 一条一眼识别的判据**：
> **"一、二、三、四、五、六、七、八、九、十"＝升级型；"一、二……五、六……九、十"＝跳跃型。**
（把场景里的攻防逐句标号，**看台阶是不是连续的**——中间空档就是跳跃。）

**★ 诊断顺序（不可颠倒）**：冲突**放缓 / 突升 / 静止 / 跳跃**时——
**① 先查前提是否清晰** → **② 再查人物是否过弱** → **③ 是否停止成长** → **④ 三维是否完备**。
**先查前提**这一步最常被跳过：**九成的"冲突不动"，病在前提模糊**。

**从有道德到邪恶的七步**（角色偏移的刻度尺）：**有道德 → 受挫 → 犯错 → 不得体 → 违法乱纪 → 不道德 → 邪恶**。
**★ 判据**：**在第一、二步停留过久 = 静态**（人物不肯下滑，戏就不动）。

## §2 ★ 过渡："大自然从不跳跃"

**Egri 的原话**：**"大自然从不跳跃。"**
**九步链（照排）**：友情 → 失望 → 烦扰 → 恼怒 → 气愤 → 攻击 → 威胁 → 预谋 → 谋杀。
- **每两步之间仍有过渡**；**生活里可以瞬间发生，舞台上不能省略**。
- **★ 判据**：**缺少过渡，就使戏剧变成情节剧**（冷酷杀手忽然停下来扶盲人过马路）。
- **范例的机制**（一场争吵从恼怒到暴怒的逐句升级）：找一个**软肋** → 用一句话刺它 → 对方爆发（**这里出现一个"跳跃"**→ 补一句更日常的抱怨**把台阶接回来**）→ 猎犬转向新的目标 → 一句追问把场面推到高潮。
  **★ 关键技巧**：**跳跃发生之后，不许直接进高潮——中间垫一句"更小的事"**，台阶就接上了。

---

## §3 ★ 出击点（point of attack）

**定义**：**人物做出（或准备做出）重大决定的那个转折点**，事件恰在千钧一发。
**两条硬规则**：
1. **第一句台词就要引发冲突并交代动机**。
2. **从中间开始，绝不从起因开始**——哈姆雷特始于谋杀之后；《玩偶之家》从敲诈那一刻开始。
   **自检**：**把开场往前推三场（交代来历的那三场）删掉，故事还成立吗？** 成立 → 那三场来历本可删（开场太早，出击点应后移到"做决定那一刻"），或者那些场根本不是开场。（2026-09-25 修正方向：旧句"你的开场晚了"与《玩偶之家》从敲诈开始的原则相反。）

## §4 危机—高潮—结果（**逐场递进，规模必须递增**）

| 项 | 定义 | 判据 |
|---|---|---|
| **危机** | **决定性改变将至的不确定阶段** | "烟头点燃窗帘"仍属危机——**只要结果未定** |
| **高潮** | 这一场里决定性的那一刻 | **总比上一个高潮高** |
| **结果** | 新局面 | 它同时是**下一场的危机** |

**★ 一条极高的要求**：**"最短的一场戏也应包含三幕剧的所有元素。"**
**★ 另一条**：**戏剧的开场本身就是某个冲突的高潮**——你不是从头讲，是从**一场已经在烧的火**切进去。

**呈现纪律**：**冲突才是真正的呈现**。不许用"仆人介绍 / 宣读信件 / 打电话"交代；**停止呈现，人物就停止成长**。

## §5 冲突的层面与焦点（选一层，或叠三层）

| 体系 | 内容 |
|---|---|
| **麦基三层面** | **自我**（头脑 / 身体 / 情绪）· **个人关系** · **个人外**（社会机构 / 个体 / 环境）。**三层面同时转折＝复杂型；只有一层＝纠葛型** |
| **希克斯五种焦点** | **个人自身**（非影像化，慎用）· **人际**（最好用**封闭空间**，不让他逃）· **意外情况**（灾难本身无戏剧性，**真正的戏在其中的人际冲突**）· **社会**（必须**具体化**出代表群体的对手）· **利益相关**（最普遍可信：共同目标直接对抗） |
| **黑格尔三型**（中式转述） | **不自觉的行为**（家族性的、人人有份）· **有意识的行为**（他要动手）· **非直接的破坏**（他并不想，但他的存在就是伤害） |

**★ 性格冲突三形式**：**性格与环境** · **性格与性格** · **性格内部**。
**★ 一条反直觉的判据**：**看法不同会冲突，看法相同也会冲突**（两个都极聪明、都要赢的人，对同一件事看法一致，照样往死里斗）。
**★ 别林斯基的标准**：**双方都想占上风、都想刺痛对方性格的某一面、结果产生了新关系**——**这才算戏**。
**冲突要真三层**：**真实**（不虚假）· **有意义**（不无谓）· **戏剧性**（不是观点争论）。

## §6 ★ 冲突先落到"手上的活"，再落到思想（**中式工艺，极实用**）

**做法**：**第一次让主人公失败的事，必须是一个可演的"技术动作"**——人际取笑与思想层的动摇**跟在它后面**。
（范例：一部农村戏里，主人公第一次动摇是因为**把庄稼锄错了**，然后才是被同伴取笑，最后才是思想上的裂缝。）
**为什么**：**一上来就落到思想，观众只看见观点之争**。
**自检**：**动摇的第一场里，有没有一个"可演的失败动作"？**
**失效**：主人公若是行家里手（做这件事本来就该成），这条不成立——改用第二级（人际取笑）。**第二失效**：**对手与主角争的不再是同一物**（目标已错开）→ 冲突失效，回 §4 重锁目标。

## §7 ★ 动机的心理学工具箱（**给动机补深度用**）

### 7.1 三个人格层 → 三个角色位（最省事的用法）
**本我 = 坏人** · **自我 = 主角** · **超我 = 智者**。
**★ 找动机的一个快问**：**"这个角色的模范是谁？"** —— 答出来，就找到了他愿意奋战的理由。
**两条纪律**：**禁果线必须付代价** · **恐怖来自无力感与角色对调**（不是来自血腥）。

### 7.2 性心理阶段 → 给角色贴"本能特征"
- **口欲滞留**：抽烟＝**戏剧性间歇 + 内在冲突的信号**；成瘾＝**可克服的人性化障碍**。
- **肛门滞留 vs 排泄**：喜剧对偶——**控制者 vs 制造混乱者**。
- **性蕾期**：**武器就是身份象征**（剑 / 光剑 / 也可以是车船或计算机）。
- **★ 压抑得越久，释放越有力**（破坏 vs 非暴力、热情 vs 禁欲、反叛 vs 服从）；**反叛必须始于一次不公正，并升级到"不堪忍受的最后一件事"**。

### 7.3 防卫机制（**核心：角色自己不知道，观众看得见**）
| 机制 | 用法 |
|---|---|
| **压抑** | 几句台词、一个触碰就能宣泄 |
| **否认** | **真信＝悲剧；欺骗＝坏人**；用一次悲剧性失落揭开 |
| **升华** | 劳动热情、爱的力量，让不可信变得可信 |
| **退化** | 之后**接一场吐露秘密的安静场景** |
| **反向行为** | **嘴说不、眼睛说是**；想毁掉自己最爱的东西 |
| **错置** | 在角色之间制造推动剧情的裂痕 |
| **投射** | 父母把未竟的梦想投在儿女身上 |
| **孤立** | 孤独英雄**从荒野来回荒野去** |
| **说漏嘴** | **只用于表达情感** |

### 7.4 八阶段作弧模板（挑一个当骨架）
多疑的主角 → **信心的跳跃** · 易受骗者 → **学会说不** · 反叛者 → **夺回自主** · 罪恶感 → 推动力或障碍 · 弱势者 → **"他为何想赢、这与他的认同有何关系"**（**动机才是结构的支撑**）· 认同扩散 → **暂停期不可跳过**（"接受别人端来的身份"是危机）· **亲密＝让对方知道内心的秘密** · 中年二选一（传承或停滞）· 老年（圆满 or 绝望）。
**★ 三条可以直接用的**：
1. **没有信任就没有亲密**。
2. **第二幕末的"饱和时刻"应该是交心，而不是上床**。
3. **第三幕要让主角自己解决，不交给调停者**。

### 7.5 荣格四位一体（用于冲突设计）
**英雄（人格面具）必须遭遇并整合：阴影（坏人）· 智者（智慧老人/女神）· 爱的对象**。
- **阴霾的过去要"制约"**（不说唐人街发生了什么），**但一定要在某一点让角色面对它**。
- **爱的对象要"成全"英雄**；**母亲可同时是女神与女巫**；**蛇蝎美人 = 性 + 侵略合一**。
- **转变也可以发生在配角身上，并反作用于主角**。

### 7.6 阿德勒与罗洛·梅（两条收尾规则）
- **给每个英雄一个自卑情结**；**超级英雄 = 弱者与超人的双身份**；**成人片在关键时刻让最活跃的英雄失去行动能力**（增加张力）。
- **罗洛·梅：区分"解决"与"结局"**——解决是"发生了什么"，**结局是"接下来会怎样"，要让观众看到主角已经改变**。

### 7.7 两条铁律（不可破）
**① 片子必须始终维持自身的真实感；② 角色必须始终维持自我的真实感。**
**没有解释的突然改变，永远不被接受。**
**"要看情况"**：理论按角色在你剧本里的功能取用，**不套样板**。

## §8 诊断清单（冲突层，十四条）

```text
① 冲突是哪一型（静止 / 跳跃 / 升级 / 预示）？逐句标号，台阶连续吗？
② 前提清晰吗？（"冲突不动"九成病在这里，先查这一条）
③ 人物过弱吗？停止成长了吗？三维完备吗？
④ 从有道德到邪恶，人物走到第几步了？在前两步待太久了吗？
⑤ 每一个"跳跃"处补过渡了吗？跳跃之后有没有垫一句"更小的事"？
⑥ 出击点落在人物做重大决定的时刻吗？第一句台词引发冲突了吗？
⑦ 把开场前推三场删掉，故事还成立吗？
⑧ 每场的危机—高潮—结果比上一场大吗？最短的那场有三幕的全部元素吗？
⑨ 有没有用"仆人介绍 / 宣读信件 / 打电话"交代？（有 → 停止呈现了）
⑩ 冲突在哪个层面（自我 / 人际 / 社会 / 环境）？只叠了一层，还是三层同时转折？
⑪ 是性格之争还是观点之争？双方"都想刺痛对方性格的某一面"吗？
⑫ 第一次动摇落在"一个可演的失败动作"上，还是直接落到思想上？
⑬ 动机够深吗？"这个角色的模范是谁"答得出吗？有没有一处防卫机制在起作用？
⑭ 结尾区分了"解决"与"结局"吗？观众看到主角改变了吗？（没有 → 故事未完成）
```
