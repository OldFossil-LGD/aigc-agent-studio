# 声音语料库（环境床 / 拟音 / 硬效 / 人声 / 设计声 · 查词用）

> **何时读**：写第 11 块【声音】、或"这场戏该有哪些声音"卡住时。**读完回哪**：回 `sound-craft.md`（结构 / 配额 / 混音 / 同步的权威在那边）。
>
> **分工（**这是全库唯一一处分工，别互相抄**）**：
> - **本文 = 词**——**这个场景/这个材质/这个动作，具体能写哪些声音词**
> - `sound-craft.md` = **结构**（声音三层 / 七层表 / 配额 ≤5–8 个关键词 / 能量曲线 / 混音 / 同步 / 八个常见错误）
> - `expression-library.md` §0.2 = **呼吸与言语的时序**（言语前 0.2–0.5 秒等）
> - `transition-library.md` = **声音桥与跨场衔接**
>
> **为什么单开一份**：库内到处要求"**显式列出关键环境音**"，但此前**从没给过可查的声音词**——`sound-craft.md` 里只有 5 个英文拟声词（thud / crash / whoosh / hiss / zap），**没有中文词、也没有"什么材质发什么声"的对照**。

## §0 用法三条（照 `sound-craft.md` 的规矩落地）

1. **同步拟音与点效的挂靠公式**（→ `sound-craft.md` §三）：`在[可见动作]发生的确切时刻添加[声音]，保持[音量/风格]。`
   **适用边界**。同步点效对齐动作。画外声、环境床、主观声与设计声按声源、听点或叙事用途安排，见 `sound-narrative.md` §2–§4。
2. **配额**：**每类 ≤5–8 个关键词**（对白/旁白、现场音、环境床、音乐各算一类）。**本文是"候选池"，不是"一次全写"的清单**——从池里挑，挑够就停。
3. **★ 一个场景只讲一个声学空间**：混响必须统一（同场对白 / 音效 / 环境三者的空间感一致）。**"空旷回响"与"吸音闷响"不许写在同一条里**（→ `sound-craft.md` §3.1 互斥检查）。

## §1 环境床（atmos / room tone）——**最低音量，决定"这段是被放在真实世界里，还是被贴在一片寂静上"**

| 场景类 | 可写的声音词 |
|---|---|
| **室内通用** | 房间底噪 · 空气流动 · **荧光灯镇流器的嗡嗡** · 通风口的气流声 · 冰箱／空调压缩机的启停循环 · 老建筑的木结构轻微响动 · 水管的滴答 |
| **办公室 / 教室** | 键盘疏密不一的敲击 · 打印机起停 · 日光灯的细嗡 · 远处电话铃 · 中央空调的低频 · 走廊的脚步声由远及近 |
| **厨房 / 饭馆** | 抽油烟机的持续低吼 · 锅铲碰铁锅 · 油爆的细密噼啪 · 水龙头的水柱 · 碗碟轻碰 · 后厨排风扇 |
| **老屋 / 值班室** | 老钟的秒针 · 木地板随脚步的吱呀 · 台灯灯丝的微鸣 · 窗缝的漏风 · 隔壁的电视声**隔着墙** |
| **医院 / 走廊** | 推车轮子与地砖 · 输液架移动 · 门轴的低音 · 广播的模糊人声 · 仪器的规律提示音 |
| **街道 / 城市** | 车流（**远景要写成"一片连续的沙沙"，不是一辆一辆**）· 红绿灯行人提示音 · 卷帘门 · 远处刹车 · 电动车的电流声 · 井盖被压过 |
| **雨 / 风 / 雪** | 雨打在不同表面各不同（铁皮棚＝脆响 · 树叶＝沙沙 · 玻璃＝细密）· 屋檐的落水线 · 雨后的滴水 · 风的低吼与穿过缝隙的哨音 · 雪天特有的**吸音闷响**（雪是天然的吸音材料） |
| **自然** | 树叶摩擦 · 草叶拂动 · 鸟叫（**要远近有别**）· 虫鸣（昼夜不同）· 溪流 / 河水 / 浪拍岸 · 冰裂 |
| **工业 / 工地** | 机器低频 · 液压的嘶声 · 金属敲击的余响 · 电焊的爆裂 · 传送带的规律咔哒 · 塔吊的远响 |
| **交通载体内** | 车厢低频共振 · 轨道的规律接缝声 · 报站的模糊播报 · 轮胎过接缝 · 引擎的转速变化 |
| **夜 / 凌晨** | **声音要变少而不是变多**：只剩低频的隐约嗡声、偶尔一辆车、远处的犬吠、虫鸣、灯泡的电流声 |

> **★ 一句更好用的表述**：*环境声决定了一个片段是像**被放置在真实世界**中，还是像**被贴在一片寂静**上。*

## §2 拟音（foley）——**人身体与手边物件的声音，这一层是"人的质感"**

### 2.1 脚步：**先定表面，再定鞋**

**同一双鞋踩在不同表面上，声音完全不同——所以"脚步"必须先说表面。**

| 表面 | 声音特征 |
|---|---|
| 木地板 | 中空的共鸣、板材的轻微吱响 |
| 水泥 / 石砖 | 干、短、硬，带一点沙粒摩擦 |
| 瓷砖 / 大理石 | 高频反射、有尾音（走廊里更明显） |
| 地毯 | 几乎无声，只剩人自身的重心摩擦 |
| 沙 / 土 | 细密的挤压声、颗粒带起 |
| 碎石 / 砾石 | 脚步下的滑动与滚动 |
| 金属 / 铁皮（楼梯、船板） | 带余振的金属回响 |
| 积雪 | 短促的压缩声，雪下若有冰面则带脆裂 |
| 落叶 / 枯枝 | 干脆的碎裂 |
| 水 / 浅水 | 溅起与拖水的连续声 |

**鞋型也要定**：硬底皮鞋（清脆）· 运动鞋（闷而软）· 高跟（点状的顿音）· 皮靴（沉、有低频）· 光脚（几乎只剩肉与地面的粘滞）。

### 2.2 衣物与身体

布料的摩擦（棉＝哑、尼龙＝脆、羊毛＝粗）· 袖子蹭过桌面 · 拉链 · 纽扣碰到桌面 · 衣摆扫过门框 · 坐下时椅子受力的一声 · 起身时关节与呼吸 · **吞咽** · **鼻腔的呼吸声** · 翻身时床垫与床单。

### 2.3 道具触碰

拿起／放下的**两段**（先接触、再落定）· 杯子放回桌面（底与桌面的那一碰）· 门把手转动 · 抽屉滑轨 · 纸张翻动 · 笔尖落纸 · 火柴划燃 · 打火机开盖与合盖 · 布料上的手指摸索 · 钥匙串的金属碰撞 · 工具被放回工具箱。

> **★ 拟音的技法（可借来反推"该写什么声"）**：马蹄用椰子壳的一半 · 骨折用芹菜折断 · 关节响用核桃在皮袋里揉 · 躯体打击用湿麂皮 · 火焰用玻璃纸揉搓。
> **用法**：需要"某个动作该有什么声"时，先问"**实拍时拟音师会拿什么东西来配**"——那件东西的材质，就是你要写进提示词的词。

## §3 硬效（hard effect / spot FX）——**与画面动作严格同步的点状声**

| 材质 / 事件 | 可写的词 |
|---|---|
| **门** | 门轴的低音 · 门撞击门框 · 门锁的咔哒 · 弹簧门回位 · 铁门拖地的刮擦 · 卷帘门的链条 |
| **玻璃** | 轻碰的清脆 · 落地的碎裂（**先碎后落**，碎片在之后几拍才到）· 玻璃杯放下 · 玻璃被压出的应力声 |
| **金属** | 敲击的余振 · 金属拖地的尖响 · 弹簧 · 铁链 · 锁扣 · 刀背碰桌 · 空罐滚过地面 |
| **木** | 敲击的空响 · 断裂（先纤维撕裂、再断开）· 木板被压弯的吱声 · 木箱落地 |
| **纸 / 塑料** | 纸张的清脆 · 塑料袋的窸窣 · 塑料被压瘪 · 胶带撕开 |
| **水** | 倒水（**水柱声随容器形状变**）· 水滴入水面 · 水龙头关不严的滴答 · 泼水 · 水面被打破 |
| **软物** | 打击的闷响（无高频）· 布料裹住物体 · 身体落地的重音 |
| **枪械 / 机械** | 上膛 · 击发（**不要写"轰"就完，要写三段：击发的脆、低频的body、空间的尾巴**）· 弹壳落地 · 机械的规律运转 |

> **冲击声的三段结构**：**瞬时攻击（脆）＋ 中频本体（重量）＋ 低频与混响尾巴（尺度）**。
> **写法**：只写"一声巨响"是空的；写"**一声闷重的中频、紧跟一层低频的余振，随后是空间的短尾**"才可执行。

## §4 人声类（非对白）——**观众对这条最敏感，也最容易用过头**

| 类 | 可写的词 |
|---|---|
| **呼吸** | 鼻息 · 屏息后的急吸 · 长呼气 · 喘息 · 叹气 · 吸气被咽回去 |
| **喉部** | 吞咽 · 喉音 · 清嗓 · 干咳 · 压抑的哽咽 |
| **情绪音** | 笑（真笑的短促／假笑的干笑／憋笑／笑不出声的抽气）· 抽泣 · 呻吟 · 呻吟被咬住 · 低哼 |
| **人群（walla）** | **要写成"一片含混的人声"，不要写具体句子**：远处市集的人声墙 · 餐馆里含混的对话底噪 · 教室的窃窃私语 · 起哄 · 集体倒吸一口气 · 掌声（**先散后齐**） |
| **儿童与环境人声** | 小孩在远处玩 · 有人在隔壁唱歌 · 楼上拖动椅子 · 门外的交谈（**隔着门，字句不可辨**） |

**两条纪律**：① **具体台词之外的"人声"一律不可辨**（含混＝真实，听清字句＝假）；② **每场至多一处人声点缀**，过多会把对白挤没。

## §5 设计声与音乐元素（非现实声源，做节奏与情绪）

| 类型 | 它干什么 | 什么时候用 |
|---|---|---|
| **stinger（刺音）** | 短、锐、抓注意力的一击，常压在一个揭示或惊吓上 | 反转、惊吓、真相落地 |
| **riser（升音）** | 音高／能量向某一刻爬升 | 进入高潮、切换之前 |
| **whoosh（掠过）** | 有柔和起音与移动感的空气声，把视线从一处带到下一处 | 转场、快速移动的物体 |
| **drone（持续低音）** | 长时间不动的低频底，制造压迫与不安 | 悬念、心理恐怖、等待 |
| **pulse（脉冲）** | 有节律的短促声，替代音乐维持节奏 | 需要节奏但不能有配乐时 |
| **braam（金属低吼）** | 预告片式的重音质块 | 尺度与威压，慎用 |
| **sweetener（加甜层）** | 叠在已有声音上的额外层，使整体显得更大更具体 | 已经有一个声音、但"不够"，**不要重做一个**，加一层 |

> **★ 与 `sound-craft.md`「全片能量曲线」配套**：**最有效的动态是"对比"不是"强度"**——先稀后密、先低后高、**先耳语再咆哮再回到耳语**。

## §6 静默：**它是一件乐器**

- **静默是选择，不是遗漏**（《寂静之地》把静默做成主角；《2001》用纯静默让观众屏息；《老无所依》拿掉全片配乐，只留风、脚步与偶尔的枪声）。
- **可执行的写法**：`声音在这一拍全部撤掉，只剩现场的空气声` / `对白停下之后，环境床继续了半秒才切走`。
- **有意的绝对静音可以保留**。在其进出点检查接缝与爆音，淡化长度按素材试调（→ `sound-craft.md` §六）。

## §7 空间与混响词（**决定"多远、多大、什么壁面"**）

| 空间 | 一句话特征 |
|---|---|
| **空房间 / 空仓库** | 有尾巴的回响，脚步与说话都带余音 |
| **堆满东西的小房间** | 闷、短、几乎没有尾巴（软物吸音） |
| **楼梯间** | 竖直方向的多次回声、脚步层层叠加 |
| **瓷砖走廊 / 澡堂** | 高频反射强，声音发亮发硬 |
| **金属管道 / 船舱** | 带金属谐振的嗡鸣 |
| **室外开阔** | **没有回响**，声音散开得快，远处声"化开"成一片 |
| **树林 / 雪地** | 天然吸音，声音发闷、传不远 |
| **雨夜街道** | 湿路面反射高频，远处声被雨幕糊成一片 |
| **隔着墙 / 隔着一扇门** | 只剩低频与节奏，字句不可辨 |

**例（可直接改）：** `重靴缓慢踩在碎玻璃与砂砾上，仓库般的混响环境，颗粒粗粝、近距离录制`（此句来自 `sound-craft.md`，是**四要素齐**的写法：动作 + 材质 + 空间 + 距离）。

## §8 从画面取词的四步法（**可复用的取词流程**）

```
① 定空间   → 这是哪？室内还是室外？多大？什么壁面？      → §7 挑一个空间词
② 铺环境床 → 这个空间"什么都没发生"时有什么声？          → §1 挑 2–3 个（建议数；硬上限见配额）
③ 挂拟音   → 画面里每个人每个动作，他的身体碰到什么？      → §2 按"表面 × 鞋/材质"取
④ 点硬效   → 这一镜真正的事件是什么？                → §3 取一件，且只取一件
```

**可选收尾（不是第⑤步，二选一或都不要）**：**人声点缀**——本场要不要一处呼吸 / walla？**至多一处** → §4；**设计声或静默**——需要节奏与情绪 → §5 取一件；需要"更狠" → §6 用静默。

**自检三问**：
1. **同步点效对齐动作了吗，画外声与非写实声的声源关系或叙事用途明确吗？**
2. **混响统一吗？**（对白 / 音效 / 环境三者是不是同一个空间）
3. **有没有哪一类超过 5–8 个词？**（超了就是堆，不是写）

## 来源

**声音分类学（foley / atmos / room tone / hard effect / design effect / stinger / riser / whoosh / sweetener / transient / bed / diegetic 与 non-diegetic / spotting / sync）**：**LCC（London College of Film certificates）《Foley and Sound Effects》指南** · **Morphic《Sound effects glossary》** · **VideoProc《Sound Design: Everything You Need to Know》** · **Pixflow《Sound Design for Film》** · **SoundSpool《Foley, Atmosphere, and Impact Sounds》** ——**均只提炼术语体系与分类法，未复制文本**。
