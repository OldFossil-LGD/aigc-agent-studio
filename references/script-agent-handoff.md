# 剧本交接流程：**我方起手 → 平台 Agent 定稿**（2026-09-22 用户定）

> **规则来源**：用户原话「**这样以后我们在剧本的工作流程变为由你写大纲 决定题材 编写一份初稿 之后交给这个agent定稿**」。
> **读完回哪**：`run-sheet.md`（第一步 剧本）· `run-sheet-part2.md` **站 4**（分册路由）· `script-module.md`（M1–M12 交付契约）· `script-format.md`（版式）· `libtv-platform-watch.md` §十·补（实测依据）。
> **本册只管一件事**：**剧本的"谁写哪一段"**——内容判据仍在原册，本册不复述。

---

## 一、四步（**顺序固定，不许颠倒**）

| 步 | 谁 | 产出 | 关键判据 |
|---|---|---|---|
| **1 定题材** | **我方** | 题材 ＋ **一句话戏核（logline）** | **戏核必须我方先给**——实测：brief 只给"物件＋情绪＋结局"，平台会收敛到同一解法（题材惯性） |
| **2 写大纲** | **我方** | 主旨 · 情绪弧光 · 结构分段 · **钩子与伏笔的设计意图** · 每段功能 | 骨架按 `script-module.md` 的 M1–M12 |
| **3 出初稿** | **我方** | 完整分镜表初稿（镜序 / 时长 / 景别 / 情绪 / 光位影调 / 声音 / 动作） | 时长先自洽；声音守 **No BGM** |
| **4 定稿** | **平台 Agent**（`run_agent` · **`autoGenerate: false`**） | 定稿全文 | 见 §三 交付协议 · §四 边界 |

---

## 二、为什么这样分工（**实测依据，不是偏好**）

**它强的四项**（正好是"定稿"该做的事）：
- 结构完整 · **逐镜补运镜与机位** · **钩子/伏笔编号 ＋ 逐个写"埋设 → 回收"** · **情绪弧光显式分段**
- **实测结论**：这四项**比我们自己的分镜模板更规整** → 用来定稿是划算的。

**它弱的四项**（所以起手不能交给它）：
1. **戏核会收敛**：同题材重复既有解法（实测：与我们既有《钥匙》几乎同构——"犹豫 → 差点拿 → 松手 → 空镜留钥匙"）
2. **时长自述不实**：自称"总时长 32 秒"，逐镜加总却是 **35 秒**
3. **人物生理写错**：给女性角色写了"**喉结**"
4. **混入 BGM**："心跳般的低频鼓起"（与我方"分镜阶段 No BGM、声音后置"纪律冲突）

→ **一句话**：**起手（题材/戏核/大纲）必须我方做；收尾（打磨与补全）交给它；回来后的核对归我方。**

---

## 三、交付协议（**发给平台 Agent 时必须写全**）

1. `run_agent` · **`autoGenerate: false`**（守阶段闸：不点火、不生成任何媒体）
2. **投递方式**：建 image 节点但**不要 run**，节点名 **`Agent交付_剧本定稿_<题材>`**，**答案全文写进该节点的 `prompt`**
3. **锁定项（逐条写明，不许它动）**：题材 · 戏核 · 结局 · 镜数与总时长 · 无对白（若有）
4. **要它补的四项**：逐镜运镜与机位 · 钩子与伏笔编号并写"埋设 → 回收" · 情绪弧光分段 · 每镜可拍性（光位 / 声音 / 动作落到可执行）
5. **明确禁止**：不要向我提问 · 不要生成任何图片或视频 · **不要换题材、不要靠"加一个外部威胁"来制造冲突**（除非我方在戏核里明确要）

---

## 四、定稿回来后：我方**四项强制复核**（缺一不可）

| # | 复核什么 | 怎么查 | 实测踩过的坑 |
|---|---|---|---|
| 1 | **时长** | **逐镜加一遍**，与总时长自述对齐，再核对 brief 上限 | 自述 32s vs 加总 35s（超上限） |
| 2 | **人物生理** | 性别 / 年龄 / 身体特征**逐处**过一遍 | 女性角色写"喉结" |
| 3 | **声音** | 按"**分镜阶段 No BGM、声音后置独立制作**"改写 | 混入"心跳般的低频" |
| 4 | **锁定项未被篡改** | 与 §三 第 3 条锁定的五项**逐条 diff**：题材 · 戏核 · 结局 · 镜数与总时长 · 无对白 | 锁 5 项却只核 3 项时，题材 / 戏核 / 结局被改无从发现 |

**★ 四项都过 → 才许入 Script V2**：`create_script_v2` 建表（`assets` 表绑角色 / 场景 / 道具；**每镜必带 `durationSeconds`（1–15）**）；此后才进分镜与点火。
