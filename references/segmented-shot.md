# 分段镜：一条生成里装多个景别（**按「段落」写**）

> **何时读**：要让**一条生成**里出现**多个景别 / 多个机位**（而不是一条只出"缓推"）时。
> **读完回哪**：回 `shot-craft.md` 填板块二；或回 `studio-workflow.md` 第三步。
>
> **★ 2026-09-14 口径改动（当日第二次修正）**：**不用按秒数写，也⛔不用「镜几」写——
> 按「段落 / 组合」写（段落A / 段落B / 段落C），景别与构图在段内按时间线发生改动。**
> 总时长仍写在首行；**秒数不写进提示词**。**但"不写"≠"不算"——§四 的每段下限必须先算。**
>
> **分工**（不要互相抄）：
> - 本文 = **一条之内怎么分段**（段落语法 / 段数 / 共用块 / 段内变化块 / 首帧策略）
> - `shot-craft.md` = **一段之内怎么写**（五段协议 / 构图 / 镜头规格 / 声音七层）
> - `sequence-craft.md` = **段与段之间**怎么连（序列契约 / 几何用图 / 情绪连续性）
> - `motion-control.md` = **动作怎么走**（决策树 / 两级动作 / 时间纪律）

## 一、先判路：分段镜，还是拆镜

**两条路都能出多景别，成本结构完全不同。先判再写。**

| 条件 | 选 |
|---|---|
| **同一场景、同一光区**，只换机位 / 景别 | ✅ **分段镜** |
| 主体 ≤2 人，动作简单（坐下、转身、停手、看） | ✅ **分段镜** |
| 越轴（180° 换边）、跨地点、跨时间 | ⛔ 拆镜（连续性会被打散） |
| 需要精确到帧的节奏（卡点、卡音乐） | ⛔ 拆镜 |
| 对白 + 口型 | ⛔ 拆镜（口型窗口与切点会互相打架） |
| 走路 / 奔跑 / 打斗等周期动作 · 多人交互（≥3 人） | ⛔ 拆镜（见 `motion-control.md` 决策树） |

### 试错成本的算术（决定默认选哪边）

**分段镜：一次失败 ＝ 整条重抽；拆镜：一次失败 ＝ 只重抽那一镜。** → **稳镜可合，难镜必拆**：同场景同光、都简单的镜可合成一条；只要有**一**个难点（手部动作、走路、液体、多人），就把那一镜拆出来，其余合成——**不要为了省事把难镜塞进分段镜**（省下的是剪辑时间，赔上的是整条的可救性）。

## 二、为什么以前只出"缓推"（诊断）

历史模板把**摄影机段**写死成"**单一运镜 + 排除同族运镜**"、**景别**要求"全程不变"——**在 5 秒单机位模型上是对的，在 15 秒原生多镜平台上变成紧箍咒**，模型于是无论怎么写都只出**一条缓推**（不是模型不行，是提示词显式排除了它本可以做的事）。
**修法**：不删规则，只**加作用域**——单机位模式全文生效；分段镜模式**只在每一段内部生效，段与段之间解禁**。
> **★ 佐证（2026-09 核）**：Seedance 1.0 Pro 的旗舰能力官方就叫**「无缝多镜头叙事」**，官方示例用"**然后**"连接两镜、**不带时间戳**——与本库"按段落写、不写秒数"一致；**"多镜一条出"是平台给的，不是我们抢来的**（详见 `key-decisions.md` E31）。

## 三、段落语法（**按「段落」写，不写「镜几」、不写秒**）

> **★★★ 2026-09-14 用户定案（第二次修正，前两版都理解偏了）**：
> **"景别切换是对的。重要的是不要「镜几」，而是改成段落或组合。**
> **在段落内，有些模块是共用的，有些则按时间线发生改动**——
> **例如开始什么景别、构图怎么样、场景等，写详尽。就比如现在的 3 镜改为 3 段落或组合。"**

**为什么要改掉「镜几」**：`镜N` 带着**"剪辑点"的预设**——模型看到"镜2"容易理解成"**这里要切一刀**"，于是把**一个段落里的多个画面**也当成硬切；**「段落 / 组合」不带这个预设**：它说的是"**这一段里发生的事**"，**画面怎么切、构图上怎么变，都在段内按时间线写**。

**段落式结构，顺序固定**：

```
① 全局设定   —— 主体锚点 + 场景 + 时段光线 + 统一提质层（写一次，段内只复述不重写）
② 段落分段   —— 每段一个段落名（段落A / 段落B / 段落C）+ 段内按时间线写变化
③ 全局约束   —— 段落数 / 切换数 / 全程不变项 / 排除项 / 声音（放在段落外面，才管全程）
```

**「共用块」与「段内变化块」——这是段落式与镜序式最大的不同**（细则见 §七）：

| 类别 | 有哪些 | 怎么写 |
|---|---|---|
| **全局共用**（写一次） | 人物锚点句 · 场景陈设 · 时段与光 · 统一提质层 · 风险移除 | 写在**段落外面**，标"每一段逐字复用、不改字" |
| **段内共用**（本段各时刻不变） | 光位与影调 · 镜头规格 · 器材包 · 声音底 | 写在本段开头，**整段有效**，段内不再重复 |
| **★★ 段内按时间线变化**（**核心**） | **景别 · 构图 · 机位与运动 · 主体在画幅里的位置 · 画面内容** | **段内按「他先…；随后…；最后…」逐时点写** |

**每段必须写清"起始状态 → 结束状态"**（段落式的骨架）——例：`段落A（开始：远景，两人极小 → 结束：缓慢前推）`／`段落B（开始：中近景——帽檐横切过面部上三分之一 → 结束：中近景偏近——画面下缘收进枪套下半截，手停在枪套上，没有拔）`／`段落C（开始：远景，与A 同机位 → 结束：街对面空了，他仍没转头）`。

**★ 一段里可以有好几个景别**——**不要把"这一段的景别变化"拆成好几个「镜」去写**，而是在段内写"**先是什么画面、随后换成什么画面**"。
**判据：这一段的取景变化，是"同一个段落里换到另一个画面"，还是"跳到了另一个时间/空间去"？** 前者留在段内写，后者才开新段落。**段内时点用「先 / 随后 / 最后」，不用「镜几」也不用秒**：

```
段落B｜时间线（段内变化）（光位/影调等共用块写在段首，本行只写变化）：
他先是一条中近景——右手垂在身侧、掌背贴着枪套皮面，人整个是静的，构图偏画面右侧三分之一；
随后**取景换到**另一个机位——中近景偏近，机位略低、焦段收到[N]毫米，画框下缘收进枪套下半截（换景词，不是「切到」）；
最后收在中近景偏近——帽檐横切过面部上三分之一、手停在枪套上，没有拔，这个状态保持到这一段结束。
```

**纪律**：
- **段落名从 A 开始、连续、不跳**（A / B / C，或组合一 / 组合二）。**一段只写一件事** · **段数按动作可读性定，不按秒数定**。
- **光与声音不要写进段内的每一行**——本段共用的写在段首，全局的写进全局约束。
- **⛔ 全文不许出现「镜几」字样**——旧写法见 §八 对照表（那是"原表述"，只做对照，照抄会退回旧毛病）。

### ★★★ 段内的状态推进，不许借用切镜词汇（2026-09-14 实测后立）

> **病灶**：**段名是二元的**——「在段落B里」或「不在」。所以**「同一段里他先不动、随后眼睛动、最后手停住」**这件事若没有专门的词，人就会**顺手借用切镜的词**（`准备 → 接触 → 落定`）→ **模型读成"这是三个镜头"**。

| 要表达 | ⛔ 别用（**切镜词汇，一用就变多镜**） | ✅ 用（**同一段内的推进**） |
|---|---|---|
| 同一段内主体**状态随时间推进** | 准备 → 接触 → 落定 | **他先在…；随后…；最后…** |
| 同一段内**从不动到动** | 起始 / 触发 / 主动作 / 反应 | **起初…；接着…；收在…** |
| **段与段之间**的接继 | — | **准备 → 接触 → 落定**（**只在段名边界上**） |

**判据**：**"这句在描述一个动作的过程，还是两段的接继？"**——描述**过程** → 用"先…随后…最后…"；描述**接继** → 才用"准备/接触/落定"，**且必须跨在段名边界上**。**★★ 单镜（非分段镜）怎么办**：其时间线**只保留 `起始 / 主动作 / 反应与呼吸 / 定格` 四相**，`接触 / 落定 / 触发` 在单镜内同样禁写——**这三个词描述的是一条完整动作弧，一个镜装不下**。

**另一条同源禁令**：**段首的景别标签只描述起始帧**。写"中近景"却在段内让主体走远、或让尘把景别拉成远景——**起始锚点与后文打架，模型会自己选一个，多半选错**。**修法**：段内若真发生景别量级变化（人走远 / 尘遮 / 光变），**必须在时间线里显式写出**（这本来就是段落式要写的东西，见上）。

**第三条（2026-09-14 补）**：**景别行必须点名画框边界，不能只写动作**——`收在中近景——手停在枪套上` 会被读成特写；
**判据与两条正当理由见 `sequence-craft.md` §8.1b**（景别由"画框装了什么"决定，不由"这件事多重要"决定）。

## 四、档位（**先算每段几秒，再定段数**）

> **★★★ 不写秒数 ≠ 不用算秒数。** 段落语法解决了"模型不知道这段到哪结束"，**但没解决"每段摊到几秒"**。
> **实测翻车**：5 秒写 5 段 → 每段 1 秒 → **低于物理下限，每段都糊，接起来完全看不懂**。
> **动笔前必算：`每段秒数 = 总时长 ÷ 段数`；< 2 秒 → ⛔ 减段数 / 加总时长 / 拆多次生成。**

**★ "看不懂"的根因**：**5 秒 ÷ 5 段 = 1 秒/段**，低于 **2 秒的定型下限**。模型收到 5 个"各自完成一段叙事"的段、每段只给 1 秒 → **每段只演半口气，接起来就是五段糊片**。**不是提示词不详细，是每段预算不够。**

| 总时长 | 段数上限 | 每段秒数 | 说明（**秒数算完不写进提示词**） |
|---|---|---|---|
| **5 秒** | **2 段**（3 段是极限） | 2.5 / 1.7 秒 | ⛔ **5 段＝自杀**；2 段＝"建立 + 一个转折" |
| 8–10 秒 | **3–4 段** | 2.7–2.5 秒 | 叙事最舒服的档 |
| **15 秒** | **3 段**（最稳）；5 段是上限 | 5 / 3 秒 | 多一段就多一份糊的风险 |
| 30 秒 | **5–8 段** | 6–3.7 秒 | 节点**不超过 8 个** |
| 任何长度 | — | — | **段数按动作可读性定**，但**先过上面那条校验** |

**三档下限（引用 `sequence-craft.md` §8.3）**：平台单次生成下限 **4 秒**（2.0 = `[4,15]`、2.5 = `[4,30]`、1.5 Pro = `[4,12]`）· 单个动作镜定型下限 **2–3 秒** · 一段读清一件事 **≥2 秒**。**< 4 秒的段只能放"停住 / 看一眼 / 一个微动"这类零动作段。**

> **★★ 官方原句（Seedance 2.5 指南，2026-09 核）**：`Leave roughly 2–3 seconds for a visible action.` · **5 秒片 2–3 个节拍 · 8–10 秒片 3–5 个节拍 · 15 秒 3–5 镜最佳**（第三方佐证见 `key-decisions.md` E31）。
> **★ 按内容类型分档**（PenShot `neopen/story-shot-agent`，MIT）：快动作 1.5–2.5 · 对话与表情反应 2.5–4 · 环境交代 3–5 · 情感高潮 4–6。**先按内容定档再累加**——比平均分更准（平均分会让慢镜被压死、快镜被拖沓）。
> **对照口径（课程实测）**：8s = 5镜4切 / 10s = 4镜3切 / 12s = 7镜6切 / 13s = 3镜2切 / 15s = 4镜——**按新版已越界**（12s 7镜 = 每镜 1.7 秒），**"信息密度"不是豁免下限的理由**。

**为什么是 3 段**：多段的失败几乎都出在**段间一致性**上——段数越多，要复述的锚点越多、一致性衰减的暴露面越大。**3 段是"景别有变化"与"主体不变形"的平衡点。**
**景别弧线（四选一，别乱切）**：**递进**（全景→中近景→特写，情绪往里走，最常用）· **反打**（A 正面→B 过肩→A 特写，两人对话）· **揭示**（特写细节→中景→全景，先谜面后全貌）· **动作**（全景起→低角度发力→结果特写）。
> 同一个动作配不同景别，叙事层次完全不同：**"流泪"= 远景（孤独感）→ 中景（看见眼泪）→ 大特写（泪水与微表情）**。

## 五、★ 锚点逐字复述（多段一致性的唯一来源）

> **连续性来自重复，不来自每一段重新描述。**

先写一句**锚点短语**，含五样最小身份信息：**角色称谓 + 服装颜色 + 发型 + 核心道具 + 朝向**。然后**逐字复制到每一段**——不是"换个说法"，是**整句搬过去**。

**禁止近义词替换。** `铁锈红外套` 改成 `深橙色外套`，在模型那里不是同一个东西，是**重新设计了一次角色**。
同理：`搪瓷杯` 不许写成 `瓷杯`，`邮电工作服` 不许写成 `深蓝制服`。**场景陈设也只复述、不新写**（每段重描述场景 = 每段重建一次环境）。

**配套：全局不变项写一次，放在段落外面。**
`全程保持不变：同一个[角色锚点句]、同一件[服装]、[场景陈设]位置与数量不变、光源方向与色温不变、画幅与色调不变。`
> **稳版可加**：给每段标上对应参考图（`段落A人物参考图片1`），把"复述"升级成"锚定"。见第九节的稳版模板。

## 六、段间转场：只写在下一段的**开头**，且先说清是切还是接

**默认用硬切**——同场景只换机位时硬切最稳；炫技转场把预算烧在转场上，而它不推进叙事。**12 种手法全谱见 `transition-library.md`**；本节只管写法规则：
1. **转场写在后面那一段的开头**，不写在上一段末尾——写在末尾，模型会**提前开始过渡**。
2. **平滑类转场必须带护栏**（硬切不用）：`画面无硬切，物体不凭空出现或消失。`
3. **交接物必须命名**——`一片正常大小的落叶飘进画面遮住镜头` 强于 `有东西遮住镜头`。

## 七、★ 段内纪律（一段多画面，其余照旧）

**机制**。一段是一个叙事单元，可包含多个取景。段内可以断切换机位，也可以连续推拉或变焦。本模板的段间默认硬切，单个画面按选定的主运动推进。

**计数口径**。段落数、取景变化与剪辑切点分别登记。D 段的段间硬切为 D−1 次，全片切点数等于段间切点加各段内断切数。连续推拉或变焦造成的景别变化按连续运动登记，切点数为 0。
- **换画面怎么写**——每个画面**各自给**`景别 + 画框边界 + 机位与焦段`，按 **先 / 随后 / 最后** 逐时点排开。
- **★★ 换景词 vs 剪辑词**（全库唯一口径）：✅ **换景词**＝`画面变为` / `下一个画面是` / `取景换到`——说的是**画面里变成什么样**；⛔ **剪辑词**＝`切到` / `转到` / `镜头N`——说的是**剪辑动作**，会让模型去找硬切点、或以为你要另起一次生成。
- **换景别两条路**：① **断切式**（主路径）——直接换成另一个机位的画面；② **连续式**——同一机位内推近／拉远／变焦。**换画面＝换机位／换焦段，不占主运动名额**。
- **一个连续动作弧**——"**他先抬手，随后停住**"是**一个**动作的推演；**不要给它起"准备/接触/落定"这类名字，那是段间词汇**（→ §三）。
- **同族运镜排除**——写了推，就逐一排除拉/摇/移/环绕/变焦/俯仰（同 `shot-craft.md`）。

**★ 段内画面数下限（采用本模板时，切点按上述口径另算）**：**每段至少 2 个画面**（除非这一段本身就是「一个画面看完」的收尾段）——**整条视频的画面总数 ≥ 段数 + 1**。**算完数一遍：写出来只有 1 个画面 ＝ 不合格，回去改【★ 时间线】。** 【待确认项：平台「多镜序列 ≤8 镜」与本条下界 × §四「30 秒 5–8 段」相冲——30 秒档的段数上限可能要降到 4。】

> 核对每段各取景装了什么，并分别标明连续变景或断切。段间与段内的切点一起汇总。

## 八、旧规则改写对照（改了作用域，不是废掉）

| 旧规则（单机位模式，全文生效） | 分段镜模式下的写法 |
|---|---|
| 一镜一个主运动 | **一个画面**一个主运动；**段内换画面**与段与段之间都可以换 |
| 景别与焦距全程不变 | **画面内**焦距不变；**换画面就是换景别与机位**，要写出来 |
| 排除同族运镜（无拉出、无摇、无环绕） | **画面内**照旧排除；**换画面／跨段允许换**，且必须写明换成了哪个 |
| 单镜 ≤10 秒，超过就拆镜 | 单条可到平台上限（15s / 30s）；但**单个连续动作仍只装一件事** |
| 一镜一张黑白故事板 | 分段镜**每段一张**（各自独立文件，仍不拼版） |
| 结尾留白（用空位收） | **只有最后一段**写结尾落点；中间段末尾写**接口状态**（下一段的起点） |

**顺序**：先写**段数与景别弧线**，再写**每段的共用块与时间线**，最后写**全局约束**。
反过来写（先堆描述再切时间）必定糊。
