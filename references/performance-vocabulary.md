# 表演词表：情绪 → 可写的身体（查表用，不背）

> **何时读**：写【人物表演】块时**卡在"这个情绪怎么写"**——情绪词有了，但不知道写什么形变。
> **读完回哪**：回 `performance-craft.md`（方法）或直接填 `shot-craft.md` 的第 5 层。
>
> **分工**：`performance-craft.md` 管**为什么与怎么搭**（分诊 / 破假 / 时序 / 训练）；本文只管**"这个词该换成什么"**——一张表，查了就用。
> **★ 说到具体表情名字时（"苦涩的微笑""假装的微笑""微蔑视"这类）→ `expression-library.md`**（**96 条具名表情**：怎么做 / 用在哪）。**本文管笼统情绪，那边管具名表情；两边都只是参照，落地句式仍从当前角色推。**
> **纪律**：本文是**参照**不是**填空**。同一情绪在不同人身上写法不同——**先按 `character-depth.md` 想清楚他是谁，再来这张表找落点**。

## 一、铁律：一个笼统情绪词都不许留

**"惊讶""紧张""悲伤""生气"——这些词模型读不懂，必须分解到肌肉 / 呼吸 / 眼神 / 皮肤。**

而且**同一个笼统词有 3–5 种完全不同的物理实现**——写之前先选哪一款。以"惊讶"为例：

| 变体 | 写什么 |
|---|---|
| **轻度正面** | 眉毛轻微上扬 · 嘴唇微张 · 瞳孔扩张约 0.3 秒 · 一次柔和的鼻吸气 · 无多余动作 |
| **震惊** | 急促的口吸气 · 双眼睁大 · **身体瞬间冻结** · 一只手不自主抬到胸前 · 嘴唇张开但无声 |
| **不信** | 一次缓慢的眨眼 · 头部微侧 · 嘴唇收紧 · **只有一侧眉毛抬起** · 视线锁在触发源上 |
| **惊喜** | 眼睛点亮（眼神光强化）· **笑容逐步建立**（不是瞬间出现的完整笑容）· 双肩放松下沉 · 一次轻松的呼气 |

> **同样的四选一，适用于**：紧张 / 悲伤 / 愤怒 / 害怕 / 沉思 / 恋爱。
> **不确定选哪一款时，问用户"是哪种"**——比赌一个写法便宜。

## 二、眼生命（Eye Life）六条 · 每条带反例

**死眼是 AI 表演的头号破绽，这条不可选。** 每个有脸的镜头都要写：

| # | 规则 | 反例 → 正例 |
|---|---|---|
| **1** | **视线一直在动**：漂移、思考时闪开、扫一下细节再回来；**永远不在一个点上冻住** | ❌"他看着对方" → ✅"视线在对方的眼和嘴之间来回扫，偶尔落到身后那个门框上" |
| **2** | **眨眼真实、随状态变**：压力下快而密；控制时慢而稳；懵住时眨一下然后失焦 | ❌ 全程不眨 → ✅"他听完，很慢地眨了一次眼，然后才开口" |
| **3** | **眼神光是"活的"**：眼睛读起来**湿润、有光**，不是两个高光点贴上去 | 见 `tone-realism.md`——眼神光是**唯一**要写"亮"的地方 |
| **4** | **"不眨"是选择不是死板**：掠食者式的冷，眨眼少但要**慢而刻意** | ❌ 全程定格 → ✅"整个过程他一次都没眨眼——不是不能，是不肯" |
| **5** | **眼睛先于头**：视线比头转**早到**目标；**思想在说出之前先写在眼里** | ❌"他转过头看她" → ✅"眼睛先移过去，头才慢慢跟上" |
| **6** | **眼睛随节拍变**：眨眼频率、注视稳定度、眼神光温度都跟节拍走 | 情绪弧线里每一拍都要写眼的对应变化 |

## 三、按情绪的微节拍（写不出形变时直接抄这里）

### 愤怒 / 决心 / 暴怒
`咬肌（颊部）隔着皮肤可见地搏动 · 颈部颈动脉搏动可见 · 太阳穴血管浮起 · 鼻翼在重音词上扩张 · 瞳孔收缩（聚焦收紧）· 外眼角收紧（真张力，不是廉价的眯眼）· 高潮时刻不眨眼 · 眉骨与鼻翼上细小汗珠`
**配套身体**：重心偏高（胸、下巴）· 节奏快而碎 · 方肩 · 呼吸高而急

### 焦虑 / 紧张
`一次可见的喉结吞咽 · 台词前一次短促鼻吸 · 舔润干燥的下唇 · 下唇轻微内收 · 脸颊毛细血管泛红 · 关键词上瞳孔扩张 · ⚠️除非剧本明确要求，不哭`
**配套身体**：频繁自摸（脸 / 头发）· 语速碎、填充笑声 · 用眼睛请求许可 · 呼吸高而急

### 悲伤 / 脆弱（不流泪版）
`外眼角下垂 · 眼睛**湿润带眼神光但不流不淌不闪** · 眉头中央皱起 · 嘴唇轻微颤动 · 头部微微低垂`
**配套身体**：重心低（肩沉、含胸）· 节奏慢而省 · 抱臂低头 · 呼吸低而缓

### 控制 / 平静 / 优越
`呼吸平稳均匀（与对面紧张的人形成对比）· 手指与手臂放松 · 缓慢均匀的眨眼 · 下颌微抬 · Duchenne 微笑（眼角外侧出现细纹）——⚠️**逐步建立**，不是从完整笑容开始`
**配套身体**：头不动 · 动作慢 · 注视长 · 回答前先停 · 占地方。**最危险的人动得最少**

### 沉重 / 负重
`双肩下沉 · 头部微微下垂 · 深而缓慢的呼吸 · 声音更低更闷 · 回答时头轻侧 5–15°`

### 震惊 / 冻结
`镜头开始瞬间——身体冻结 0.3–0.5 秒，零移动 · 瞳孔在冻结瞬间扩张 · 嘴唇微张但无声 · 冻结**结束之后**才一次延迟的急促鼻吸 · 眼睛锁死在触发源上——不眨眼、不偏移`

### 压抑情绪（最难——物理抵抗）
`每一块面部肌肉都在对抗涌上来的东西 · 颧骨处咬肌缓慢收缩 · 喉结一次**延迟的、用力的**吞咽 · 眼眶积聚泪水使眼球泛光——**但泪不落下** · 一次缓慢、深、可控的吸气（胸腔可见起伏）· 下颌微抖一次，**立刻被收紧**`

## 四、台词前后节拍（每句台词拿三段）

| 段 | 写什么 |
|---|---|
| **台词前 Pre-line** | 第一个字之前发生什么：吞咽 / 吸气 / 舔唇 / 姿态变化 |
| **台词中 Mid-line** | 哪些词通过鼻翼、语调、瞳孔强调（**标出落在哪个词上**） |
| **台词后 Post-line** | **约 0.5 秒屏息，然后释放**（视线锁住对手 0.5 秒，再微微移开） |

**完整示例**：
```
台词前：一次短促鼻吸气，喉结一次吞咽。
台词："别再问我了。"——重音落在"再"，鼻翼在该词上扩张。
台词后：视线在对手身上锁住 0.5 秒，然后微微移开。
```

> **为什么值钱**：台词不是孤立的——**前后各有一拍**，戏才连得上。只写台词本身，就是"轮流念稿"。

## 五、表演量表（0–5，交付前自评）

| 分 | 状态 | 判据 |
|---|---|---|
| **0** | 人偶 | 台词到了，行为缺席 |
| **1** | 朗诵者 | "有表现力"的念白、指示式情绪、图解手势 |
| **2** | 勤勉 | 能猜出目标，但单战术、反应迟、空停顿 |
| **3** | 工匠 | 目标与节拍都在、听搭档、身体合理 |
| **4** | **活着** | 连续行为、**战术会换**、潜台词背离台词、**反应先于台词** |
| **5** | 磁石 | 4 分全部 + **悖论**：角色同时是不兼容的两样东西（两真相同在） |

**每个主角镜头瞄准 4+。自评 ≤2 → 发前重写，不要修。**

## 六、坏表演图鉴（15 条，症状 → 维修动作）

| # | 症状 | 提示词级修正 |
|---|---|---|
| 1 | **指示式**（做鬼脸 / mugging） | 把脸移出"表演任务"；写目标，并给手一个活计 |
| 2 | **演结果** | 只写角色**此刻知道的**，不写他不可能知道的 |
| 3 | **等 cue** | 写反应**始于搭档台词半句之前** |
| 4 | **单战术** | 标节拍；每个新节拍换一个战术动词 |
| 5 | **手势图解词义** | 手势要么**先于思想**、要么**与词矛盾**、要么没有 |
| 6 | **自由情绪** | 搭梯子：克制 → 崩；**情绪必须付出代价** |
| 7 | **身体不符传记** | 设身体档案：重心 / 节奏 / 磨损（→ `character-depth.md` §三·§四·四·补） |
| 8 | **言语太干净** | 碎屑化：打断 / 掉尾 / 重复 / 半截句 |
| 9 | **威胁有信号** | 威胁是平凡的；**暴力无预兆** |
| 10 | **群像完美同步** | 波状错开反应，强度各异 |
| 11 | **死停顿** | 用评估或活计填满——或删掉 |
| 12 | **情绪重置** | 状态有惯性；**尾巴带进下一拍** |
| 13 | **角色在评论情境** | 对情境**全信**；喜剧也死认真演 |
| 14 | **特写过载** | **镜越紧动越少**——只有眼与思想 |
| 15 | **死眼** | 完整套用本文第二节——**眼生命从不可选** |

## 七、虚焦听众也要活（群像错时）

焦点角色在焦内、其他人在虚焦时——**他们不是静止的**。必须写：

1. 头部与视线方向（他们看哪）
2. 肩与头的微动（**虚焦里也有生命**）
3. **对关键时刻的反应**（即使在虚焦中）
4. **明确时差**：`Roko 先转头；0.4 秒后 Rein；再 0.4 秒 Jax`

> **三人永远不会完美同步——总是错开 0.3–0.5 秒。** 同步 = 群演 = 立刻假。

## 八、角色表演主档案（常驻角色，一到两段、90–200 字——与 character-depth 母档篇幅口径统一）

每个常驻角色有一条主档案——**他怎么演的永久真相源**。**不是每镜写**，是写完在每镜里"重表达"。

**固定块顺序**：
```
角色表演：[姓名]。[年龄体格体态——身体是传记的文献]。[一句心理引擎]。
嗓音：……；关键身体习惯与抽搐：……（每个抽搐带触发条件）；步态：……（起个名字）。
However, when [情绪触发]，[转变]。
```

**六条规则**：

1. **只写可观察行为**——绝不写"他紧张"，写"发抖的下唇、沉重的吞咽"。
2. **每个抽搐带触发**——不是"他掰指节"，是"他**为假装有自信**而在闲聊时掰指节"。
3. **给步态起名**——"power-walk""老拳师的踱步""画廊漫步"。
4. **造面具 AND 裂缝**——每个档案至少一条 `However, when X…` 从句。
5. **至多一个软化对象**——合宜时，给脸一个（且仅一个）让它真正软下来的人或动物。
6. **不写服装、不写摄影机、不写颜色**——**表演段只驱动表演、脸、嗓音、动作**。

**改写到本镜的六条**：只写在场的角色 · 保留恒定核心 · 为本场重新表达 · **转变而非删除**（本场做不了的行为改写，不移除）· 一段流畅散文（无项目符号）· 用角色参考 tag 起头。

> **嗓音锁定，绝不改编**：表演段按场景重写，**嗓音永久不变**。有台词时把嗓音描述**逐字**粘进声音行。

## 九、两条最容易忘的

1. **状态，不是过渡。** 模型拍"**是何**"，不拍"**成为何**"。写角色**已在**动作中——半空中的拳、已经开口骂到一半——不要写"他开始打"的过程。
2. **反 AI 测试（交付前读一遍表演段问自己）**：
   > *这读起来像一份 AI 提示词模板，还是像一个看过演员排练的导演的笔记？*
   - **像模板** = 笼统形容词、对称动作、完美同步
   - **像导演笔记** = 具体肌肉名、不对称反应、时差错开、**有触发的习惯动作**
   **读起来像模板就重写。**

## 十、禁止的表演行为（黑名单）

| ❌ | 原因 |
|---|---|
| "就站在那里说话" | 总该有微动作 |
| 卡通式做鬼脸 / 过度夸张 | 破坏写实 |
| 用"眼睛看向天花板"表示思考 | 要**命名一个具体的视线方向** |
| 默认流泪 | 仅当剧本明确要求 |
| 多角色完美同步 | 总是错开时间 |
| 笼统的"看起来很紧张 / 很开心" | 必须分解为肌肉、呼吸、眼神 |
| "他是紧张的" | 写：颤抖的下唇、沉重的吞咽、口吸气 |
| **没有触发条件的习惯动作** | **每个习惯动作必须挂一个触发** |
