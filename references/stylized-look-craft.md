## §0 为什么要有这一册（它补的是哪一块空缺）

`style-library.md` §二 给系三定了**三条原则**（渲染方式句 / 停用前两套 / 禁止项排除两系），但**没给可逐字复用的量级句**——
而系二有 `stylized-look.md` 的完整量级句模板。**结果是：写系三每一次都得现编，而库自己说系三"最容易翻车，因为模型没有现成的量级可套，会自己掉回写实或描边"。**

**本册补的就是这一块**：十种工艺，每种给**六栏**，公共层（【统一提质层】那一块）可**逐字复制**。

### ★ 三件铁律（系三必须写齐，缺一件就掉回写实或描边）

| 件 | 判据 | 缺了会怎样 |
|---|---|---|
| **① 渲染方式句** | 说清"这是**怎么造出来的**"，不是"看起来像什么" | 模型给你一张"描了边 / 加了个滤镜的写实图" |
| **② 停用前两套** | **不写**胶片 · 机身 · 镜头（写实系那一段）；**不写**描边 · 平涂 · 粗黑轮廓线（描边系那一段） | 一个画面讲了三个拍摄故事 |
| **③ 禁止项排除两系** | `禁止：照片写实，真实皮肤毛孔，PBR 材质质感，胶片颗粒，光晕；美漫描边，赛璐璐平涂，粗黑轮廓线，平涂色块` | 掉回写实**或**掉回描边——**两条退路都要堵** |

> **判据一句话**：把提示词给一个没看过画面的人，**他能不能说出"这是用什么工艺做的"**？说不出 → 渲染方式句不够。

### ★ 用法（照这四步，别自己发明）

1. **先认工艺**（下表左列），**把该行的「渲染方式句」逐字粘进【统一提质层】**；
2. **把「色板写法」整段粘进【后期特效】的"调色方向"**（**系三同样会掉成单色棕，不是只有描边系会**）；
3. **把「两族排除句」整段粘进【风险移除 + 禁止出现】**；
4. **「运动特性」并进【时间线】**——**这一栏是系三最容易写错的地方**（见 §2 的共同教训）。

## 一、十种工艺（六栏速查）

> 每条格式：**材料签名 · 运动特性 · 光怎么处理 · 色板写法 · 两族排除句 · 失效症状**

### 1. 定格动画（黏土 · 木偶）
- **材料签名**：身体是黏土捏的、表面留着**手指按出来的浅坑**（一个挨着一个、大小不一样）；头发是毛毡、纤维翘着；接缝处看得见金属丝；衣服是布、边缘有剪过的毛边
- **★ 运动特性**：**动作不是逐帧平滑的**——写成"**分几小段完成，每一小段之后先停住、身体完全不动，再开始下一小段**"。**"逐格抖动"提示词做不到，留给后期降帧**（→ `post-production.md`）
- **光怎么处理**：**唯一的光**（布景灯）；小尺寸光源 → **影子方向一致、边缘清楚、光比可以很大**；**侧上方单一硬光源是唯一能让压痕显形的条件**（平光会把浅坑洗没）
- **色板写法**：**手工材料本色**——陶土棕与纸板褐约六成 · 毛毡灰与苔绿约三成 · 布景灯的暖橙不到一成；**禁止单色**
- **两族排除句**：`照片写实，真实皮肤毛孔，PBR 材质质感，胶片颗粒；美漫描边，赛璐璐平涂，粗黑轮廓线，光滑的塑料反光，完美的对称`
- **失效症状**：① 变成**光滑的 3D 渲染偶**（最常见）② 微缩尺度丢失 → **尺度靠"破绽"承担**：墙角露出的胶带 · 幕布边缘的纸板背面 · 椅腿下垫的折纸板

### 2. 微缩模型 + 实拍
- **材料签名**：**看得见的模型痕迹**——接缝、涂装笔触、木料与石膏的质地；**浅景深暴露模型尺度**
- **★ 运动特性**：主体动作要**少而硬**；爆炸/烟在微缩尺度下**显得更浓、更快**；**别让真人做精细动作**（尺度会崩）
- **光怎么处理**：**小尺寸布景的灯**——衰减很快，**近处一片亮、两步外就黑了**；这是一条很硬的尺度证据
- **色板写法**：模型的**涂装色**（比实物更平、更艳）；底色偏灰/偏褐；**禁止均匀满亮**
- **两族排除句**：`完美的 CG 场景，写实远景，无接缝的表面；平涂色块，粗黑描边`
- **失效症状**：变成**没有接缝的 CG 场景**——尺度与工艺一起丢

### 3. 沙画与粉末
- **材料签名**：**沙或粉末在白底上**堆、抹、划；**手的痕迹**时常入画；明暗由**沙的厚度**决定
- **★ 运动特性**：**抹与堆是单向过程**；**一个形象被抹掉之后，在同一位置连续变成另一个形象**（这是沙画的签名，不是硬切）
- **光怎么处理**：**背光**（沙的厚度决定透光量）或**正上方均匀照明**；**不要侧光投影**
- **色板写法**：**只有沙的本色与背光的白**；可加**一两种染色沙**（赭石 / 淡蓝）不到一成；**禁止多彩**
- **两族排除句**：`笔触式的绘画，颜料质感，油画厚涂；美漫描边，赛璐璐平涂，轮廓线`
- **失效症状**：被读成**"用笔画的抽象画"**——沙的颗粒与堆积的边没写出来

### 4. 剪纸与纸艺
- **材料签名**：**分层的纸片**（能看出厚度与边缘）；**关节式人物**（头/躯干/四肢分离）；**纸片投下的实影**；纸的边缘有毛茬
- **★ 运动特性**：**关节式**（部件各自转，不是软组织连续变形）；**平面分层各自移动**（前中后景各是一层纸）
- **光怎么处理**：**从侧后方打来** → 纸片投下实影、**纸边半透**
- **色板写法**：**有限的手工纸色**（彩色卡纸的有限色相）；**色块边界就是纸的裁切边**；禁止渐变
- **两族排除句**：`CG 的光滑感，写实毛孔，立体的软阴影；平涂无边界的色块，粗黑描边`
- **失效症状**：变成**"平面矢量插画"**——厚度、实影、毛边三样一起丢

### 5. 木刻与版画
- **材料签名**：**刀具刻出的直线组与排线**；**黑白二值为主、几乎没有中间调**；**套色错版偏移**（颜色没对齐）；纸张纤维与油墨不均
- **★ 运动特性**：**动势靠刻线的方向**（不是靠位移）；帧与帧之间**线条会"重刻"**——同一处排线方向可变，这是它的生命
- **光怎么处理**：**光只通过刻线的疏密表达**，没有渐变、没有方向光
- **色板写法**：**单色或双色套印**（黑 + 红/蓝）；**套色有轻微错版**；**禁止中间调与渐变**
- **两族排除句**：`平滑的渐变，写实光影，柔软的边；赛璐璐平涂，均匀色块`
- **失效症状**：被读成**"加了个黑白滤镜的照片"**——刀痕的顿挫没写出来

### 6. 油画动画
- **材料签名**：**可见的厚涂笔触**（颜料有立体感）；画布肌理贯穿整个画面；颜色边界**由笔触决定、不是轮廓线**
- **★ 运动特性**：**笔触随动作连续变形**——画面"始终在画"；**颜色在帧与帧之间跳动**（这正是它的味道，不是缺陷）
- **光怎么处理**：**光以颜色的明度层叠表达**，不用方向光与投影
- **色板写法**：**主观厚涂色**（可以比实物更艳、更脏）；**同一色相内部有笔触的明度台阶**；禁止数码渐变
- **两族排除句**：`平滑的插值动画，矢量感，照片纹理；赛璐璐平涂，粗黑描边`
- **失效症状**：被读成**"一张油画图在做平移"**——笔触没有跟着动

### 7. 水彩绘本
- **材料签名**：**湿边**（水痕的深色沉积线）；**留白**（未上色的纸白）；纸纹与铅笔草稿线
- **★ 运动特性**：**动作要少**（水彩经不起大幅位移）；**湿边在帧间缓慢洇开**是唯一被允许的连续变化
- **光怎么处理**：**白纸本身就是高光**；无阴影或只有极淡的色块暗示；**不要体积光**
- **色板写法**：**透明清亮的叠色**（能看到下层透出）；**大量留白**；可加赭石 / 花青一两处；禁止厚涂与复数层次
- **两族排除句**：`厚涂的油彩，数码渐变，锐利的轮廓；粗黑描边，平涂色块`
- **失效症状**：被读成**"柔光滤镜的照片"**——湿边与留白没写出来

### 8. 中国水墨
- **材料签名**：**墨在宣纸上晕开、边缘发毛**；**大面积留白**；**枯笔的飞白、笔断意连**
- **★ 运动特性**：**一笔成形、不描不改**；动作要有**书写性**（起笔—行笔—收笔）；**形象可以只出现一部分，剩下的交给留白**
- **光怎么处理**：**没有方向性光源**——光表现为**墨色的浓淡**
- **色板写法**：**黑白灰为主**（墨分五色）；可点**一两处淡彩**（赭石 / 花青）；**淡彩限于选定点染，排除高饱和满铺与均匀灰阶**
- **两族排除句**：`均匀的灰阶，未经选定的高饱和彩色，西方式的透视；照片写实，真实毛孔，PBR 材质`
- **失效症状**：被读成**"灰度照片"**或**"彩色水墨风插画"**——留白与墨晕都没写

### 9. 像素艺术（8/16-bit）
- **材料签名**：**可数的像素方块**（硬边、**无抗锯齿**）；**抖动（dithering）造成的纹理**；一格一格手绘的轮廓
- **★ 运动特性**：**位移必须按格跳，不许亚像素平滑**（这是像素的命）；**每隔一小段才换一次姿态，中间保持不动**（原"帧率感来自少于标准帧数的更新"含帧率术语，2026-09-30 按判据改写）
- **光怎么处理**：**光照只用色板换色**（同一色相的明度阶梯），**不做出真实的明暗**
- **色板写法**：**有限的十几色到几十色**；高饱和但**受限于色板**；**禁止平滑渐变与高清纹理**
- **两族排除句**：`平滑渐变，高清纹理，抗锯齿的边；照片写实，PBR 材质`
- **失效症状**：被读成**"低分辨率照片"**——方块不可数、边缘被抗锯齿

### 10. 低多边形（Low-poly）
- **材料签名**：**肉眼可见的多边形平面**（刻面感）；**没有纹理贴图**；形体被简化到几何体
- **★ 运动特性**：**面片翻转**，没有软组织连续变形；**棱边始终保持清楚**（一旦被圆滑就毁了）
- **光怎么处理**：**平面着色（flat shading）**——每个面一个色，**用色相变化代替明暗渐变**
- **色板写法**：低饱和柔和色**或**高饱和复古 3D 色，二选一；**按面分色**；禁止写实贴图
- **两族排除句**：`写实贴图，圆滑曲面，细节堆叠；粗黑描边，赛璐璐平涂`
- **失效症状**：被读成**"低模渲染效果"**——面被细分平滑了

## §2 ★ 十种工艺的共同教训：**"运动特性"这一栏最容易写错**

**十种工艺里有八种，"动作不是连续平滑的"。** 而视频模型的**默认行为恰好是帧间平滑**——写成"顿挫 / 跳格 / 抽帧"，
模型很可能理解成**卡顿或掉帧故障**（画质缺陷），而不是作画风格。

**所以本册统一采用一种写法**（源自 `expression-rhythm.md` §5）：

> **不写"帧率"，写"停多久"。**
> ❌ `作画是 3 格一拍、有跳格顿挫`（数字 + 帧率术语，模型读成掉帧）
> ✅ `动作分几小段完成，每一小段之后先停住、身体完全不动，再开始下一小段`
> **判据**：**把提示词里所有"帧 / 格 / 顿挫 / 抽帧"的词换成"停多久"的表述**（本册各工艺行的"帧与帧之间 / 帧间跳动"等措辞已按此口径读作"相邻两次更新之间"——2026-09-30 统一注）。

**并且**：**真正纯粹的逐格顿挫分两层（2026-09-30 分层表述）**——**(a) 分段停顿**（"停一拍再动"的节奏感）**提示词可以做**（见上两条写法）；**(b) 精确的逐格 / 均匀抽帧属于后期**（降帧 / 抽帧），提示词做不到（平台能力以复测为准）。
**该降级就降级**，别在提示词里反复加码（→ `post-production.md`）。

## §4 自检三问（系三交付前过一遍）

1. **渲染方式句够不够？**——给一个没看过画面的人，他能说出**"这是用什么工艺做的"**吗？
2. **两条退路都堵了吗？**——禁止项里**同时**有"照片写实 / PBR"**和**"美漫描边 / 赛璐璐平涂"吗？（只堵一条 = 掉回另一条）
3. **"运动特性"是按"停多久"写的吗？**——还有没有残留的"帧 / 格 / 顿挫"这类词？

## 来源与口径

**本册为 2026-09-15 本库自建**，动机：全面审计（`审计报告_aigc-film-studio_2026-09-15.md` 的 **O3 / N1**）查出——
**系三只有三条原则、没有可复用的量级句，而系二有完整模板**（`stylized-look.md` 第二节）。
**实测来源**：**同一天写 `D10 定格动画` 那条单镜时，【统一提质层】整块是我现编的**——这就是本册存在的理由。
**内容出处**：**十种工艺的「材料签名 / 光怎么处理 / 色板写法 / 失效症状」四栏，全部取自对应风格条目自身的
「核心视觉」「色彩光影」「★ 质感与痕迹」「★ 最容易被写歪成什么」四处**（`style-library-animation.md` 的 D11–D18 ·
`style-library-anthology.md` 的 G11/G12），**只是把它们重新组织成可复制的公共层，未新增库外参数**。
**本库自建的部分**：「运动特性」一栏 · **§2「停多久」的统一写法** · §3 的两类边界 · §4 自检三问 · §0 的三件铁律（三件原则取自 `style-library.md` §二）。
**★ 不做什么**：**不给"工艺 → 条目"的映射表**——系三条目各带自己的可写句式，本册只供**公共层**。
