## 5C. ★★★★ 禁项是"跑出来之后"才加的 —— 全画布最有价值的一条方法论

第一段「场景1」被重写了 **9 版，全部保留**。证据链：

**早期版**（`v-qwpYu9ikCE` / `v-UCF3Vm4LeK` / `v-jPcWkkyGv3`）镜头04 逐字写：

> 血雾深处，一只尺寸远超白鲸的**暗金色竖瞳短暂睁开**。

**后期版**（`v-oltUjvCNXM` / `v-qR2OuyJv9v` 等）在全局块新增「怪兽设定」，第一条就是：

> 统一称为"怪兽"，**不使用鳄鱼或爬行动物描述。**
> **不出现金色瞳孔，也不通过眼睛展示怪兽。**

⭐⭐⭐ **这就是"不可重新设计成 X、Y、Z"的来源 —— 它至少有一部分是事后补的禁令。**
跑出带金竖瞳的成片，下一版就把"金色瞳孔"写进禁项。

### 正确的工作流（我此前做错的）

```
✗ 我此前的做法：一次性凭想象堆禁项（不越轴、不摆姿势…）
✓ 正确做法：先跑一版基线 → 看哪里偏 → 把偏的那个具体元素写进全局禁项 → 跑下一版
```

⭐ 这与「同一段落多版本并存、改单一变量」是**同一套方法论的两面**：
保留多版不是为了择优重跑，而是**每一版都在给下一版补一条禁令**。

## 5D. ★★★★ 三条"剥夺式"写法（同一手法，三处实证）

**核心手法：模型最爱的那个表现 → 显式否定它 → 立刻给一个替代解释。**
比写"不要X"强得多，因为它不留空档。

### 一、剥夺动作

> **怪兽不需要直接撞击玻璃。它逼近时推动的巨大水压，就足以让承压结构失效。**

→ 省掉一整个重复的撞击镜头。

### 二、剥夺音效

> **不使用吸力声，不改变水流方向。**

→ 治 AI 的经典误判：怪兽张嘴 = 风吸声。
（⚠ 同段落另一版反而用了吸力 → 两个方向都试过，是主动取舍）

### 三、剥夺视觉惯例

> **剑气不带彩色特效，纯粹是超高压空气导致的光学折射与空间扭曲。**

→ 治 AI 看到"剑气"就默认发蓝光。

→ 可推广：`<效果>不带<视觉惯例>。它纯粹是<物理解释>。`

## 5E. ★★★★ 主体规格块的否定式三段式

```
统一称为"<固定称呼>"，不使用<某分类>描述。          ← 锁称呼 + 锁分类
通过以下现象建立<属性>：<六条可拍摄的物理事件清单>。    ← 抽象词降解成现象
<主体>不需要<那个最戏剧化的动作>。                    ← 剥夺 + 替代机制
```

⭐ 第一条治的是模型自行给主体归类（最常见的造型漂移源头）。
⭐ 第二条比"给一个对比物"更完整：**不是只给对比物，而是给一整套现象**。

## 5F. ★★★ 执行锁定里最容易被忽略的一类：防"上一段的焦点被沿用"

> **镜头16开始时，终端已经收好，任何人都不再查看屏幕。**

⭐⭐⭐ AI 有很强的倾向：把上一段最出彩的道具延续到下一段。
必须显式宣布"它退场了"。

同类还有：

| 禁令 | 防什么 |
|---|---|
| 镜头15只拍机外急转，不回切机舱 | 防模型惯性切回室内 |
| 起跳顺序锁定为：五号先跳，零随后跳 | 防两人同时跳（AI 爱做对称） |
| 镜头17第0帧舱门已经完全开启 | 防模型重新演一遍开门 |

→ 可推广：`<道具/界面>在第N镜开始时已<状态>，本节点不再<相关动作>`

## 5G. ★★★ 当某一镜违反全局规则，必须当场解释它为什么不违反

全画布最精细的一句：

> **镜头17的稳定不是安全，而是怪兽自身巨大惯性带来的非人运动感。**

同一段里前 17 镜都声明"手持、不稳"，第 17 镜突然变稳 → 模型会困惑。
所以必须**为这个反常写明理由**。

→ 可推广：`<某镜的反常表现>不是<常规解释>，而是<另一个具体原因>`

## 6. 全局块写什么

| 块 | 作用 | 原文句式 |
|---|---|---|
| 影像规格 | 器材层 | 画幅／帧率／快门／主摄影机／色调／摄影风格 |
| 空间锁定 | 方位层 | 见主册 §3 |
| 主体规格锁定 | 形态层 | `形态清单 + 什么条件下才看得到什么` |
| 不可重新设计成 X、Y、Z | 排除层 | 点名模型最可能替换成的错误造型 |
| 材质解算 | 光学层 | 逐物体点名材质 + 光学术语（Specular Highlight / Subsurface Scattering） |
| 环境逻辑 | 剥离层 | 主动剥掉模型爱加的东西 |
| 巨物迟滞感 | 物理层 | `肢体移动时，气流与风压会先于肉体抵达` |
| 节奏与信息检查 | 信息层 | `本段必须让观众在48秒内清楚接收四项信息：` |
| 声音底层 | 声场层 | 全局写一次，各镜只写变化 |

## 7. 尾部 `执行锁定`（12 块模板真正缺的东西）

**它锁的是因果必然性，不是元素清单。**

原文：

> **父女必须先逃离玻璃。事故不是他们停留观看造成的，而是结构失效速度超过人类逃生速度。**
> **男孩因为返回取玩具而脱离人群，发现巨尾前并不知道危险逼近。**

### 七种类型（`v-Jd6gomVuhr` 15 条实测）

镜内切法 · 因果锁 · 道具物理链 · 人物决策锁 · **显隐时序锁** · 台词锁 · **反摆姿势锁**

两条此前没意识到的：

- **显隐时序锁**：`D18全程不出现五号，也不以声音、影子或屋顶剪影暗示五号所在位置`
  → 不只是"不给画面"，连**预告**都不许。防"提前露脸"。
- **人物决策锁**：`必须先跑过男孩，再经过短暂且可见的犹豫后主动折返`
  → 锁**决策的步骤与可见性**，不只是结果。

**全片最重要单条约束**：`每次攻击必须看清发力、接触、后果` —— 每镜按秒数落实。

**关键动作链要写两遍**：正文块 + 执行锁定各一次（跨节点衔接锁同理）。

## 8. 禁止项写法（三条硬规则）

1. 不写"不要 X"这种空禁令 → 写"**改成什么呈现方式**"
   `不许拍到怪兽` → `本场不把它拍成可以辨认全貌的生物` / `以烟尘遮挡`
2. **禁项要指名到"这是哪一种常见套路的画面"**（禁套路，不是禁元素）
3. **反摆姿势**：`他没有停下来摆姿势` / `不加入静态英雄姿势` —— 每个"该帅"的时刻配一句

最高级的写法：**给它一个物理上无法摆姿势的力学路径**
`她不是用一把刀硬扛整只巨爪，而是借怪兽自身的下压力撬动关节角度。`

另有三条"禁止预摆位"的结构化写法：剪掉入场过程 / 钉死"第一次出现在这个视角里的那一刻" / 给力学路径。

另有：结尾三重禁止打包、`撞击瞬间白屏遮挡`、`无接触点的攻击`。

## 9. `节奏与信息检查` 块 —— 管"观众看完要知道什么"

此前所有规律都在管**画面里出现什么**，这一条管**看完之后观众该知道什么**。

```
节奏与信息检查
这一段必须让观众在48秒内清楚接收四项信息：
零和五号已经确认三号位于富士山北麓地下八百米。
…
```

写 48 秒而本节点只演 22 秒 → **信息规格的作用域可以超出单个节点**。

## 10. `表演锁定` 块 —— 约束情绪的成因

```
**五号不能表现成不愿救普通人。他的痛苦来自"又一次来不及保护三号"，而不是任务选择上的道德犹豫。**
**雷达员负责喊出最紧急的即时信息，昆仑不重复雷达员已经说过的内容。**
```

- 先**排除错误表演**，再**指定情绪的来源** → 防模型自作主张改人物动机。
- 微表演写"压低幅度的微表情 + 列举 2–3 个具体微动"，禁"夸张瞪眼／明显咬牙"。
- 方言配表演上限：`说话带自然四川口音，不使用播音腔` / `有幽默感但不说小品式金句`。
- 群演要定"质感坐标"，防止被演成电影群众。
