# 失败码与责任层（出片不合格时先读这里）

> **何时读**：生成结果不合格、要返工、想加负面词之前。
> **读完回哪**：按判定的责任层回到对应文档（资产 → `updream-workflow.md`；契约 → `shot-craft.md`；
> 动作 → `motion-control.md`；光影 → `tone-realism.md`；质感/量级/声音 → `quality-layer.md`；平台 → `updream-workflow.md`）。

---

## 一、先判责任层，再决定改什么

**出问题不要默认加负面词。** 按顺序判它属于哪一层：

```
资产层 → 镜头契约层 → 提示词层 → 动作层 → 平台适配层 → 安全降级 → 随机性 → 后期
```

| 责任层 | 典型症状 | 回哪修 |
|---|---|---|
| **资产层** | 人物长得不像、道具形态错、场景结构错 | 回去重出资产（`updream-workflow.md`） |
| **镜头契约层** | 主体位置错、多出人、该近景给了远景、越界 | 回去改分镜（`shot-craft.md`） |
| **提示词层** | 光影不对、质感不对、缺声音行、量级不统一 | 改提示词（`quality-layer.md` / `tone-realism.md`） |
| **动作层** | 步态不对、周期动作崩、僵硬脸、拖物无反馈 | → `motion-control.md` |
| **平台适配层** | 时长被截、被 IP 过滤拒稿、负向字段用法错 | → `quality-layer.md` 第四节、`updream-workflow.md` 第七节 |
| **安全降级** | 有产物但内容与 prompt 不一致（局部模糊/重绘/回避/偏移） | → 本册二·补（先查回执 safety 类提示，勿当随机质量问题重抽） |
| **随机性** | 前六层都没问题，只是这一条不好 | **重 roll 是工作流的一部分**，改 seed 重抽 |
| **后期** | 细节软、闪烁、色偏、颗粒不统一 | 后期解决，不要重生成 |

## 二、失败码速查

### 动作类（→ `motion-control.md`）

| 码 | 症状 | 修法 |
|---|---|---|
| **F01 · 周期动作崩** | 走路/奔跑/负重位移不自然、原地摇摆 | **不要再用文字解**——走 `motion-control.md` 的四路径决策树（首选参考视频驱动） |
| **F02 · 单腿重复** | 走路时同一只脚反复迈，像原地跺脚 | 改镜头类型 + 补步频/摆幅/重心转移三个量 |
| **F03 · 原地摇摆** | 12 帧里是同一个弓步在前后晃 | ①改镜头类型（正侧面固定 + 横穿）②或走 `motion-control.md` 四路径决策树（首选参考视频驱动） |
| **F04 · 跟拍变原地循环** | 摄影机与人物同速，人物相对静止 | 重点看步态的镜头不要跟拍 |
| **F05 · 越拍越不动** | 为了看清步态而放宽景别，结果腿变小更不动 | 服从"把脆弱的东西拍大"：遮挡脚，或把腿拍成近景 |
| **F06 · 拖拽物无反馈** | 被拖的物体像贴图平移 | 写反馈链：张力交替 / 一道连续拖痕 / 摇晃 / 顿挫 |
| **F07 · 无表情塑料脸** | 脸像固定面具 | 【人物表演】块（细节 → `performance-craft.md`）；需要表情的镜头给近景 |
| **F08 · 匀速机械动画** | 动作像线性插值 | 写"节奏不均匀" + 呼吸有深浅起伏 + 眨眼**间隔不等、偶尔连眨或停顿**（**不写固定秒数**——恒定节律本身就是 F08 同类病） |
| **F09 · 动作无重量** | 漂浮、无反作用 | 补动作五段链（准备→发力→接触→反作用→落定） |

### 镜头、连续性与画面异常类（→ `shot-craft.md`）

| 码 | 症状 | 修法 |
|---|---|---|
| **F10 · 景别突变** | **单机位镜**里前段中近景、后段自己拉远 | 写死"**镜内**景别与焦距完全不变"；删"慢慢变远""镜头渐渐拉开"。**注意**：分段镜里**按镜号跨镜换景别是设计，不是故障** |
| **F11 · 镜没切开**（分段镜） | 写了 3 个镜号，出来仍是一条连续缓推 | 镜号**另起一行**；每镜只留一个动作、一个运镜；写死"恰好 N 个镜头 N-1 个切点"（→ `segmented-shot.md`） |
| **F12 · 镜间换脸**（分段镜） | 切了，但人物到第二镜变成另一个人 | 锚点句**逐字复制**到每一镜；清掉全部近义替换（`铁锈红外套`≠`深橙色外套`） |
| **F13 · 中间镜景别没变**（分段镜） | 只有首尾两镜景别不同，中间那镜没换 | **每镜第一个词就是景别** |
| **F14 · 人数自增** | 多出人或重复角色 | "恰好 N 人各一次" + 禁倒影路人 |
| **F15 · 双胞胎** | 同画面出现两个一模一样的人 | 明确角色与参考图对应关系 + 加全局约束句（见 `updream-workflow.md` 第七节） |
| **F16 · 左右翻转** | 屏幕方向错 | 屏幕侧 + 解剖侧 + 鼻尖指向同写 |
| **F17 · 身份漂移** | 换脸换发型 | 查参考是否混入第二身份；参考改**大头照 + 全身照**；缩锚点句；同 seed 族 |
| **F18 · 状态回退** | 服装/伤势变化 | 引用状态版本 `@v00x` 写进保持项 |
| **F19 · 多主运镜** | 运镜乱跳 | **镜内**只留一个；跨镜要换运镜，就写明换成了哪个（或走分段镜） |
| **F20 · 口型污染** | 静止角色嘴动 | 只允许说话者在发声窗口有口型 |
| **F21 · 顺序变色翻车** | 指示灯逐盏变 | 拆两帧（前色/后色）硬切 + 继电器声 |
| **F22 · 字迹褪色崩坏** | 消失过程鬼畜 | 改雪光吞没，或两静帧叠化 |
| **F23 · 画面里冒出字幕** | 没要求却出现字幕 | 参考素材里的文字先清掉；横屏比竖屏概率低（见 `updream-workflow.md` 第七节） |

### 表演类（→ `performance-craft.md`）★ 2026-09-17 外部学习补

**八个"有名字"的坏表演**。**为什么要给失败起名字**：描述原则（"要真实"）**没法诊断**；
**有名字的失败可以直接对照成片认出来**——**"认得出是哪一种，才知道改哪一句"**。
（本册 F01–F23 本来就是这个形态；这八条是补进同一张清单。）

| 码 | 名字 | 症状（成片里长什么样） | 修法（改提示词） |
|---|---|---|---|
| **F24** | **快面具**（自动人偶） | 动作平滑、像排练过的编舞；**一切对称、过于干净** | **引入微不对称**：重心离掉一只脚、一侧肩塌下来、一只手比另一只慢半拍 |
| **F25** | **演员痒** | **脸把活全干完了，手和身体空着** | 把主动信号放进**身体**（一个抽搐、一个握持、一件正在做的活） |
| **F26** | **凝视陷阱** | 眼神**钉死**在一个方向不动 | 视线落到房间里的**一个点或一张脸**上；**眼睛要有变化**（不是静止的注视） |
| **F27** | **状态翻档** | 状态像**翻垃圾桶**一样一档跳到下一档，中间没有桥 | 用**一次持续的紧绷**做桥（不是两个状态的并置） |
| **F28** | **完美标记** | 每句台词都收得**干干净净、齐整向上** | **放开**：没说完的词、两句搭在一起、自己把自己打断 |
| **F29** | **反应迟到**（fracture latency） | **头在该转的词之后才转** | 把反应**挂到"正在到达的那个词"上**——重量落在拍上，不是拍后 |
| **F30** | **提线木偶转头** | **头转了，但背后没有引擎** | 写一个**驱动这次转头的目标**（他为什么现在转） |
| **F31** | **剪辑间全复位** | **每个切点都重启**，上一拍不留痕 | **余韵跨切**——一拍接一拍是连续的（与 `performance-craft.md`「未完成与余势」同源） |
| **F32** | **答非所写**（安全降级层） | 产物生成成功，但内容与 prompt 不一致——局部模糊 / 重绘 / 回避 / 偏移 | **不当随机质量问题重抽**——先查回执 safety 类提示，按本册二·补处置（改写越线表述 / 降低敏感度） |
| **F33** | **平台硬拒绝**（平台适配层） | 直接拒稿 / 审核拦截（IP 名、敏感内容、合规校验不过） | 按拦截原因改写表述（去 IP 名 / 换安全说法），**不改镜头结构** |
| **F34** | **参数失配**（平台适配层） | 时长被截、枚举越界、字段被拒（duration 不在模型档位等） | 以 `get_model` 当前 schema 取合法值重交（时长取模型档位整秒 → `libtv-official-qa-part3.md` R10.2） |

**★ 证据强度（`governance-law.md` L4·补2）**：**单源**（站点 273 份社区技能语料里仅 1 份含此命名体系）。
**仍采纳，走「机制可独立论证」门槛**：① **"给失败起名字"本来就是我们自己的做法**（F01–F23 就是本册自建的）；
② 这八条是**观察类**表述（`L6` 四证据之「观察」）——**看了片就能验证**，不依赖来源权威。
**状态按 L6 记为「拟订」**。

## 二·补 · ★★ 新增责任层："**安全降级**"（**答非所写 ≠ 随机质量差**）

**2026-09-21 平台口径新增的一层**：请求**没被拒、有产物**，但模型或后处理**主动把敏感风险弱化/改掉了**——**表现是"画面与 prompt 对不上"**。

**★ 判决规则（最核心）**：**有产物但"内容与 prompt 不一致"——这种"答非所写"往往是安全降级，而不是随机质量问题。**
**→ 所以：当"抽卡"反复抽不出你要的画面时，先怀疑它，而不是无脑加重抽次数。**

**六种降级表现**：① 自动模糊/打码（面部、身体部位、**文字、Logo、背景标识**）② **局部重绘/内容替换**（衣物被加上、伤口被抹平、手势/道具被替换、符号被改掉）③ **避免写实人脸**（偏 CG/卡通/雕塑感/过曝/逆光/背影/遮挡；**真人脸被泛化成不像具体真人**）④ 风格化偏移（写实暴力→油画/插画）⑤ 构图回避（自动拉远/转向/前景遮挡）⑥ 细节抑制（皮肤纹理/血液/武器细节被柔化）。

**五条识别证据**：① **有产物但内容与 prompt 不一致（最核心）**；② **回执/日志出现非致命安全提示词**——`safety` / `filtered` / `blurred` / `moderation` / `content adjustment` / `safe generation` / **`partial`**（**它不是 policy violation 那种硬错误，而是"已做安全处理"的提示**——**单凭 `partial` 不定罪**：个别平台它也指"部分内容未生成"，须与证据①④联合判断）；③ **状态成功（有输出可播放）但局部被处理**；④ **画面出现不自然的局部**（固定区域模糊、边缘重绘痕迹、衣物/光影与整体不一致、**脸部异常平滑或风格突变**＝后处理痕迹）；⑤ **对比同类非敏感 prompt**（同参数下唯独敏感题材被处理）。

| | 硬拒绝 | **安全降级** |
|---|---|---|
| 产物 | **无** | **有**（可播放/可查看） |
| 报错 | 政策/安全类硬错误 | **可能带非致命 safety 提示**（或什么都没有） |
| 节点状态 | **未生效/失败** | **成功**，只是局部被处理 |
| 正确动作 | **改内容 → 新建节点重提** | **若不可接受 → 调整措辞（更虚构、更非写实、去掉真人指向）后重新生成** |

**★ 纪律**：**不要试图绕过**（改拼写变体/谐音/隐写通常仍被拦、且可能触发更严格限制）——**要"改成本就合规的表达"**。

## 三、复测与停手规则

- **每次只改一个责任层**——同时改两层，就分不清是哪一层起的作用。
- **连续两批同一错误无改善 → 停手**：拆镜 / 降复杂度 / 转后期，**不要继续抽卡**。
- **重 roll 是工作流的一部分**：生成是抽样不是打印，前六层都干净时，重抽就是正确动作。
