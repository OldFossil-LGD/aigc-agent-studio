# LibTV 客户端硬限制与能力门（【REA静态】 · 2026-10-16）

**这一册只做一件事：把"平台让不让你做、上限是多少"的**客户端章**集中成一张表**，免得每条都现猜。
出处：`outputs/libtv_rea_20261014/58_客户端硬限制与能力门清单.md`。
> ⚠ **这是"客户端文案"证据，不是服务端契约**：**客户端拦不住的服务端仍可能拦**；
> **文案里没写的，也不代表没有**。当"已知上限"用。

## 一、★ 文件大小上限（逐条）

| 对象 | 上限 |
|---|---|
| **通用"单个文件"** | **20MB**（三种说法并存） |
| **图片** | **10MB** · **20MB** · **30MB**（**三条不同文案**） |
| **视频** | **50MB** |
| **音频** | **15MB** · **50MB**（两条） |
| **GLB 导入** | **100 MB** |
| **超分输入的整文件** | 超过 **10GB** 不支持 |

**★ 判据**：**同类对象存在多条不同数字**——**引用时必须连"哪条文案"一起说**，
**不能笼统写"图片上限 20MB"**（它们是不同功能各自的校验）。

## 二、★ 数量与规模上限

| 项 | 上限 |
|---|---|
| 单次下载数量 | **300 个** |
| 单画布"保护节点" | **30 个** |
| 分镜组内节点数 | **25 个**（且**只支持图片节点**） |
| 单次配置席位 | **200 个** |
| 素材库总量 | **2000 条** |
| **免费档任务并发** | **1 个** |
| 单模式同时运行 | **1 个**（其余可免费排队） |
| 描述主体长度（建议） | **100 字** |
| （GLB）浏览器内版本保留 | **30 天** |

⚠ **"并发 1 个"是"免费档任务并发"**，**与本库的"工具调用批 ≤5"不是一件事**，两条不可互推。

## 三、★ 分辨率 / 时长 / 格式门

- **像素面积**：`源视频像素面积超出 4K（3840×2160）上限`；
- **超分 / 去字幕**：`视频分辨率超过 2K` 不支持；
- **人声分离**：`视频时长超过 3 分钟` 不支持；
- 另有 **`视频大于15秒，暂不支持该功能`** 一条（**针对哪个功能，本轮未定位**）；
- **格式白名单（超分 / 去字幕）**：**`mp4 / flv / ts / avi / mov / wmv / mkv`**；
- **帧率**：`建议不超过原视频帧率的 4 倍`。

## 四、★ 流程门

- **样片有效期 7 天**：`样片已超过 7 天，无法生成正片`；
- **批量出视频前必须有分镜图**：`请先生成至少 1 张分镜图后再批量生成视频`；
- **某些分辨率下 10s 不可用**：`分辨率下不支持 10s 时长`；
- **能力门按"模型 / 模式"逐项开**：一族 `当前模型不支持 X` / `当前模式不支持 X`
  （如 `当前模型不支持 Director Studio` · `当前模式不支持预设运镜` · `当前模型或模式不支持智能续写`）。

## 五、★★ 能力门矩阵（"当前模型 / 模式不支持 X" · 逐字）

**模型门**：
`当前模型不支持 Director Studio` · `该模型不支持 Director Studio，取消关联 Director Studio 节点后可用` ·
`该模型不支持纯文字生成，需要连入素材` · `该模型不支持文生视频，请上传参考图片` ·
`该模型不支持当前连入的视频素材` · `该模型不支持当前连入的图片素材` · `该模型不支持当前连入的{types}素材` ·
`当前模型不支持已连接的媒体组合` · `当前连入的参数不支持该模型` · `当前模型不支持所选节点` ·
`当前模型不支持该素材作为参考` · `该模型暂不支持slash模式` · `当前模型暂不支持该能力` ·
`当前模型或模式不支持智能续写`

**模式门**：
`当前模式不支持人声分离` · `当前模式不支持预设运镜` · `当前模式不支持粘贴到时间轴` ·
`文件夹模式暂不支持优化` · `文件夹模式暂不支持一键优化`

**素材 / 参考约束**：
`视频暂不支持作为参考` · `暂不支持视频参考，请移除视频后重试` · `该资产不支持作为参考` ·
**`任务生成中，暂不支持替换参考图`** · `当前视频不支持剪辑` · `当前视频不支持 {displayName} 分辨率`

**其它门**：
**3D 导入支持高斯泼溅 `PLY` / `SPZ`**（`暂不支持该文件格式，支持 {formats}，及高斯泼溅 PLY / SPZ`）·
`当前骨骼不支持此通道` · `当前画布暂不支持接收动画视频` · `当前不支持添加到画布` ·
`当前节点不支持应用此提示词` · `该调整不支持预览，需要生成后生效` · `当前记录不支持删除` ·
`资产管理暂不支持移动端`

**账号类型门**：`课程暂不支持团队账号操作` ·
`团队版暂不支持课程兑换，请切换到个人账号进行课程兑换和查看` ·
`学院-AI跟练室暂不支持团队账号操作，请切换个人账号进行操作`

**→ 判据**：
1. **"模型"与"模式"是两个独立开关**（有一条文案同时点两者）；
2. **"不支持纯文字生成 / 文生视频"是"必须给素材"的硬前置**，不是建议；
3. **把视频塞进参考位会被拦**；**任务生成中不允许换参考图**（要等任务结束）；
4. **同一功能换个账号类型（团队 / 个人）可能直接不可用**——排障先问是哪个账号。

> **★ 更正**：本条白名单的键是 `seedanceImageFormatInvalid`——**它是 Seedance 专属门槛**，不是全局规则。
> **Seedance 的完整素材要求（宽高比 `(0.4,2.5)` · 尺寸 `(300,6000)` · 单图 <30MB · 时长 `2~15 秒`）见 `libtv-seedance.md`。**

## 六、★ 图片上传的格式白名单

```text
图片格式不支持（{format}），仅支持 jpeg、png、webp、bmp、tiff、gif、heic/heif
图片大于10M，不支持上传
图片大于50M，不支持上传
```

**格式白名单 7 类**：**`jpeg` · `png` · `webp` · `bmp` · `tiff` · `gif` · `heic/heif`**（**含 `tiff` 与 `heic/heif`**）。
**大小又添两个口径：`10M` / `50M`** —— 与 §一 的 **10 / 20 / 30MB** 并列成四组，
**再次印证"同对象多口径"，引用必须连文案一起引**。

## 七、边界

1. 全部为客户端**只读静态**证据；**未上传、未生成、未点火**；
2. **数值是否随账号档位/会员变化，未验证**（本批文案里"免费档并发"单列一条，说明档位确实会改文案）；
3. 本册只收**带数字与白名单**的那批；**"当前模型不支持 X"完整矩阵未展开**；
4. **服务端另有独立校验**，本册**不能当作"超过就一定会被拒"的完整依据**。
