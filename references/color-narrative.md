## 一、★ 青橙：为什么有效、为什么成了 AI 味、怎么用而不廉价

### 1.1 它为什么有效（四个原因，多源一致）

1. **青与橙在色轮上近乎正对**——互补色让**前景往前推、背景往后退**
2. ★ **肤色锚点**：**无论种族**，人的皮肤都落在橙色区间（浅杏 → 深褐）→ **把阴影推向青，脸就自动从背景里"跳"出来**
3. **数字中间片 + LUT 普及**——把过去要在暗房做几天的活，变成桌面一下午
4. **《变形金刚》（2007）之后成为行业速记**：**观众把这种对比读成"贵"**

### 1.2 ★ 为什么它变成了 AI 味（这一节解开本库一个关键矛盾）

`tone-realism.md` 说：**"暖橙主光 + 青蓝辅光对撞、高反差低调夜景"这类写法是标准答案 → 模型会执行成精修概念图 → 这就是 AI 味。**

**现在两边都说得通了**：

| 事实 | 推论 |
|---|---|
| 青橙是**训练数据里最"电影感"的配色** | 所以**模型一听到"电影感"就给你青橙** |
| 它在 AI 提示词里"**最可预测被解释**" | 你写它，**一定**得到它——**包括你不想它出现的那些场合** |
| 从 2007 到 2018 近乎无处不在 | **观众已经能一眼认出它** |

> **结论（本库关于色彩最重要的一条）**：
> **青橙在实拍里是有效的技巧，在 AIGC 里是模型的默认输出。**
> **区别在于"选择"与"默认"。** 你主动选它 → 它仍然有效；**模型替你选它 → 你就交出了控制权。**
> 所以**"反 AI 味"的操作，本质是"离开模型的默认审美区"**——而青橙正是那个默认区的正中心。

### 1.3 它会失败在哪

- **纪录片 · 婚礼 · 混合室内外光**（摄影机白平衡本来就不一致）
- **任何需要色彩感觉"诚实"的场合**
- ★ **它会抹平文化特异性**："拉各斯的街头市场和布鲁克林的 loft 在现实中不一样。把两者推过同一个青橙 LUT，它们读起来像同一个地方。"
  → **对 AIGC 创作者尤其致命**：如果你抱怨"我的片子看起来都一样"，**青橙就是原因之一**

### 1.4 要用而不廉价（可直接抄的四条）

1. **只推阴影到青，不推中间调**（保住脸的诚实）
2. **给橙色的饱和度设上限**——★ **皮肤应该变暖，不是发光**
3. **用量降到 50–70%**【待核】此数值回一手源前不要当唯一答案，优先用**滚降对比**的变体（★ 本条讲**青橙的用量减法**，与 §六 克制纪律的"主色占七成"是两件事，别混）
4. **只在动作段与音乐段落里用"冲"的版本**；文戏段落退回中性

## 二、色彩弧线（让颜色随故事走）

### 2.1 四个方向

| 方向 | 做法 | 例 |
|---|---|---|
| **成长** | 从苍白褪色 → 丰富多样的色相 | 成长类题材（获得自信 / 自由） |
| **衰败** | 逐渐融进沉闷的环境色 | 失去能动性的角色 |
| **反转** | **同一个颜色，剧情改变它的含义** | ★ **《寄生虫》**：绿 → 从"财富"读成"腐烂" |
| **渐进** | 随着理解发生，色板缓慢变暖 | ★ **《降临》**：早期去饱和冷调（蓝灰，像悲伤）→ 中后段**逐渐变暖**，让结尾落得更重 |

### 2.2 三个规划工具（都是**动手前**的事）

| 工具 | 是什么 | 对 AIGC 的用法 |
|---|---|---|
| **色彩脚本（Color Script）** | 把全片的色彩推进画成一张连续的图 | **在写分镜之前，先画一张只有色块的条带**——哪一场该是什么色，一眼看到全片的呼吸 |
| **情绪板（Mood Board）** | 收集视觉参考定调 | 与 `style-library.md` 的选取流程合并做 |
| **色彩圣经（Color Bible）** | 记录每场批准的色板 | 落到 `production-ledger.md` 的资产状态里（locked） |

### 2.3 ★ 一条极便宜的操作法

> **"给剧本里的每一场戏分配一个颜色——即使你最后不用它。"**

**为什么有效**：分配这个动作本身会逼你想清"这场戏的情绪是什么"；而**"最后不用"是自由的**——它把色彩从"必须用"变成"可选工具"。
**落到本库**：在 `direction-reasoning.md` 第 5 问（能量）之后，**加一句"这场的颜色是什么"**。

## 三、色彩心理的三条纪律（别踩）

### 纪律 1 · **色彩没有单一普世含义**

> 它的效果取决于**语境、文化、类型、光照，以及它与画面里其他每一个颜色的关系**。
> **这些联想并不跨文化通用**——红色的含义在西方与中国就不同。

**所以：不要写"红色代表危险"这种断言。** 见纪律 3。

### 纪律 2 · **看模式，不看孤立物件**

> **"一幅蓝窗帘很少能证明一个角色抑郁。"**
> **重复出现的**蓝色光照 + 蓝色服装 + 蓝色场景，绑在退缩的时刻上——那才是证据。

### 纪律 3 · ★ **"破格"比"含义"重要得多**

**《辛德勒的名单》的红衣女孩**是教科书案例，但它的机制**不是"红＝危险"**：

> **重要的不是"红意味着什么"，而是"一个元素打破既有色板时产生的视觉层级"。**
> 在大量黑白影像里出现一点红 → **她被标记为压倒性人群中的一个"个体"** → 让她后来的重现特别有分量。

**另一条同源的**：**《第六感》**里红色只在超自然出现时入画——"**大多数观众第一次看不会注意到**，但它全程积累不安"。
→ **隐蔽的色码 > 明显的色码。** 观众**说不出来但感觉得到**，才是色彩的最高用法。

**三条合起来是一条可执行纪律**：
> **先定"这个世界是什么色"（模式），再决定"在哪一刻让它破格"（事件）。**
> **破格点 = 你的叙事重音所在。** —— 这比给每个颜色配一个含义有用得多。

## 四、类型惯例与环境色（选色板的起点，不是答案）

**类型惯例**（与 `style-library-genre.md` C 卷的条目互补）：

| 类型 | 惯例配色 |
|---|---|
| 恐怖 | 高对比 + **去饱和** |
| 爱情喜剧 | 暖、亮 |
| 科幻 | 冷、未来感 |
| 年代剧 | 历史准确 |
| 动作 | 大胆、高能量 |
| 黑色电影 | **单色或低饱和** |
| 奇幻 | 鲜艳、异世界 |
| 纪录片 | 自然、写实 |

**环境色设计**：

| 环境 | 倾向 |
|---|---|
| 城市 | 更冷、更灰 |
| 乡村 | 更暖、土色 |
| 水下 | 蓝绿偏色 |
| 沙漠 | 暖沙色 |
| 森林 | 绿与土色 |
| 极地 / 雪 | 冷蓝白 |
| 未来 / 异世界 | **非常规组合** |

**两个天然的免费调色**（色温标度见 `light-physics.md`）：**黄金时刻**（低角度暖光 + 长影）· **蓝调时刻**（暮色冷调，饱和度天然的窗口）。
**天气也是色板**：阴天（天然柔光 + 低饱和）· 暴风雨（高对比 + 冷）· 晴天（高饱和 + 硬光）。

> **用法**：这一节是**起点**——先按惯例选，**再按 §二 的弧线去改它**。**只用惯例＝类型片的安全牌；用弧线改它＝有作者性。**

## 五、可抄的案例（带数值，可直接进情绪板）

> **hex 用法**：表内 hex 仅作**色彩方向参考**——写提示词时落地用**文字色描述＋参考图锚定**，hex 本身不进提示词正文。

| 片 | 色彩手法 | 具体 |
|---|---|---|

| **《布达佩斯大饭店》** | ★ **用色彩标记"时代"** | 1930s `#D4A5A5` `#9B59B6` `#F5D0C5`（暖金片基上的丰富粉彩）· 1960s 低饱和褪色（荣光消退）· 1980s 冷、机构化的灰蓝【待核】此数值回一手源前不要当唯一答案 |

| **《黑客帝国》** | **单色区分现实与虚拟** | 虚拟世界＝绿（老式显示器荧光色、人造压抑）· 现实＝偏蓝冷调（真实但残酷） |
| **《绿野仙踪》** | ★ **色彩弧线的原初案例** | 堪萨斯＝棕褐（沉闷、被困）→ 奥兹＝高饱和 Technicolor（可能性） |
| **《辛德勒的名单》** | ★ **破格** | 黑白世界里的一点红 → 个体被标记出来 |
| **《第六感》** | **隐蔽色码** | 红只在超自然在场时入画，多数观众第一次看不出 |
| **《寄生虫》** | **颜色含义反转** | 绿：财富 → 腐烂 |
| **《降临》** | **渐进暖化** | 蓝灰去饱和（像悲伤）→ 随理解变暖 |

| **芬奇作品** | **去饱和的恐惧** | 整体抽掉暖色 |
| **《狂人皮埃尔》** | **三角色** | 红黄蓝三原色、波普、新浪潮的叛逆 |

## 六、用色彩的三步（把三份色彩文件压成一条流程）

```
① 定模式 —— 这一部片的"世界的颜色"是什么？（`color-science.md` §二 六类配色里选一类）
             ↓ 同时定一条克制纪律：1 主色 + 1 对立色，主占七成
             ↓ **色板定稿后写成一段固定措辞**——每镜逐字粘、不改字（同 12 块【全片通用】纪律）；**另出一张色彩基准图作参考锚**——固定措辞＋同一张参考图双保险，同色板逐镜生成才不漂（2026-09-30 补）
② 定弧线 —— 它随故事往哪走？（§二：成长 / 衰败 / 反转 / 渐进）
             ↓ 用色彩脚本画一张只有色块的条带；给每场分配一个色（可以最后不用）
③ 定破格 —— 在哪一刻让颜色"破"？（§三 纪律 3）
             ↓ 那个点就是你的叙事重音 —— 一个元素打破既有色板，比给颜色配含义有力得多
```

**加两条检查**：
- **别落在模型的默认审美区**（§一）：如果这一版的色板和"任何一部好莱坞动作片"看不出区别，**那就是默认输出，不是你的选择**
- **校色在前、调色在后**（`color-science.md` §三）：先问"这张画面准不准"（曝光 / 白平衡 / 肤色），再问"这张画面有没有感觉"

## 来源与许可（2026-09-13 新建）

**本文为专项调研后的提炼 + 本库自建**，覆盖青橙溯源 / 色彩弧线 / 心理三条纪律 / 类型惯例 / 案例。来源：

- **dfirentals《Why Do Movies Look Orange and Teal?》**——本库青橙溯源的**主依据**：**黑色素只改变饱和度和明度、不改变色相，所以"皮肤已经坐在橙位上"**，要拉开人脸与背景就把背景推向补色（青到蓝绿）；**Technicolor 时代 Natalie Kalmus 1935 年《Color Consciousness》主张色彩是叙事语法、背景偏冷暗以突出面部**，1937 年 Max Factor 的 Pan-Cake（黄色化妆）配合当时的强蓝光——**"暖脸冷景"比青橙早八十年**；**Pleasantville（1998）为第一部全片数字扫描的长片**，**《逃狱三王》（2000，Deakins）为第一部全流程 DI 完成的长片**（把绿色推向黄、整片做过曝金）；**2010-03-14 Todd Miro 发文命名并抨击**（"Teal and Orange — Hollywood, Please Stop the Madness"）；**强片里配色有动机，弱片里是收工时随手丢上去的一个 LUT**。<https://www.dfirentals.com/news/why-do-movies-look-orange-and-teal-color-grading>
- **Filmit《Teal & Orange Explained》**——**《变形金刚》（2007）带火了现代激进版**；Resolve 与 LUT 让它可被复制成"省事的一套"；**不廉价的四条手法量化依据**：**强度回退到 50–70%**、**只推阴影不推中间调**（保住脸）、**在 HSL 二级里给橙色的饱和度设上限**（"皮肤要暖，不能发光"）、把强对比版留给动作与 MV；**它会毁掉记录感强的片种**（纪录片、婚礼、混合白平衡、文化特异性强的场景）。<https://filmit.io/blog/teal-and-orange-explained>
- **Free Electron Media《The use of Teal and Orange in Cinema》** · **BeverlyBoy《What is Teal-Orange Look?》**——对比色先声可追至 **Jack Cardiff《黑水仙》（1947）/《红菱艳》（1948）**；"**好莱坞默认值**"的批评与"补色张力最有效"的辩护双方口径。

**许可红线**：以上**一律只提炼机制与史实，未复制任何来源文本**；**影片名、年份、人名属事实性指称**。**评论性论断（"是懒人做法"）不采**——本库只取可验证的机制（补色对比、肤色线、强度回退），**不替用户的审美站队**。
