## 适用范围

按 SKILL.md 的共同边界与 `governance-law.md` L6/L8 使用本册及其配包、量级句、校准卡、内核与取图册。

- 当前用户锁定的媒介、参照用途、声音与镜头意图优先于库内默认建议。未声明媒介且存在多种合理解释时先确认，历史偏好按其原任务范围保留。
- 按段落、画幅或图层判断拍摄、绘制与工艺呈现。混合媒介逐层写清职责，再查 §二的单条路由。
- 配包、色板、磨损、描边、光质与运动句作为工艺候选，按选定参照和目标取用。缺陷痕迹只在目标需要时加入，身份锚点与成片光影分别按各自用途校验。
- 校准卡的方向性推导与历史容差需要本项目参照支持。条目覆盖数描述目录结构，平台能力与实际效果另取当前证据。
- 单帧仅支持可见的静态关系。运镜、剪辑、帧率、声音及全片从未发生某事的判断，需要相应时序媒体与覆盖范围。历史取图缺失时保留文字记录并标明尚未复核像素。
- 已剔除帧保留在历史记录中，当前推导须与有效证据清单对齐。换题材测试先作为创作假设，另有验证记录时再报告验证结果。
- 风格或方案变更后先核对现有资产的兼容性与受影响范围，再制定局部返工计划。生成依治理 L7 取得对应显式批准。

## 二、量级路由（选完风格立刻要做的判断）

> **历史用户偏好（2026-09-17）**。跨任务适用性待确认，当前任务依本册适用范围判断。原记录为「未声明特定风格或风格化镜头时走系一写实系」，下列配套要求保留为该历史流程的记录。
> 即：**风格化必须被显式声明**（一个风格编号 + 量级系，或在提示词里写明"风格：…"）才能走描边系 / 第三系；
> **没有声明时出现"描边 / 平涂 / 赛璐璐 / 纯色底 / 平光"这类词，就是跑偏**（`audit_prompt.py blocks` 会报 WARN）。
> **配套**：写实系要"往真实走"——**道具逐处写脏 ≥2 处（位置+形态+尺寸）· 场景写磨损分布 · 材质写受光响应**；
> 只写"有些旧了"＝出来是全新塑料（这也是 `--asset` 模式新加的三条检查）。


本库 **247 条**通过**三个量级系及混合路由**检索，选错系 = 提示词自相矛盾（"又想写实又想动漫"）。

### ★ 先过"三问定系"（判据只此一条，不要凭"感觉像不像电影"）
问自己一句：**"这一套观感，能不能只靠『摆真实的东西 + 布光 + 拍摄』得到？"**

| 回答 | 归系 | 一句话 |
|---|---|---|
| **能** | **系一 · 写实系** | **要"拍"** —— 选方案包 + 胶片档 |
| 不能，但它是**轮廓线 + 平涂色块**的图 | **系二 · 描边系** | **要"画"** —— 用描边与平涂的量级句 |
| 不能，且它是**某种材料或工艺做出来的** | **系三 · 工艺渲染系** | **要"造"** —— 说清"怎么造出来的" |

**★ 三条查表纪律（照这三条判，不照"感觉"判）**：

1. **A 卷按"识别核心靠什么"三分**：靠**光位与明暗** → 系一（这一组可以当实拍片拍）· 靠**轮廓线与色块** → 系二 · 靠**笔触与材料** → 系三。**同一幅画想拍成实拍就转系一、想保留画意就留在系三——系不是在给风格贴标签，是在选"拍还是画"。**
2. **C 卷的例外只有一条**：**C71–C75（商业人像 / 产品静物 / 汽车 / 战地纪实 / 街头纪实）虽在系一，但不选方案包** —— 按 `style-package-matching.md` §1 族⑪"**不选包，改选影棚灯具与现场光**"。**这五条写的是"一件东西 + 一个决定性打光"，配方案包会把现场感写没。**
3. **C01–C12 这十二条亚文化美学的系别是判过的、但不是唯一解**：**想拍成实拍就按系一写**（赛博朋克与废土本来就是实拍片种）· **想做平面图就按系二** · **要做图像合成才按系三**。**改系要改得说得出理由，且整片只用一套。**

### 系一 · 写实系 → 用 `tone-realism.md` + **`camera-package-library.md`**
**怎么写**：风格只写"构图语法 + 光位逻辑 + 色彩方向"；**器材必须先选一个方案包**（`camera-package-library.md`，17 包，一片一包），单品细节再查 `cinematic-look.md`。
**选包怎么落地**：原检索分组计 **157 条**（B 卷 60 + C 卷 78 + E 卷 5 + A 卷 13 + G 卷 1）；选完编号后去 `camera-package-quickref.md` §一 走**三问定档定包**（年代 → 光质 → 机器谁拿着）；**三问答不出不许挑默认包**，回 `equipment-selection.md` §六 第 ① 步重推。**其中 C71–C75 不走包**（见上面第 2 条）。

### 系二 · 描边系 → 用 `stylized-look.md`
**适用**：**F 卷全部 12 条** · A 卷的平面与几何组（A06 野兽派 / A07 立体主义 / A08 未来主义 / A09 至上主义与构成主义 / A10 风格派 / A11 包豪斯 / A12 装饰艺术 / A13 新艺术 / A20 波普 / A30 工艺美术运动 / A31 维也纳分离派 / A33 欧普 / A36 埃及 / A37 希腊陶绘 / A39 玛雅 / A40 插画黄金时代）· D 卷（D02 / D03 金田系 / D04 / D05 / D06 / D07 清线派 / D08 几何纹样 / D13 三渲二 / D19 极简线条 / D21 韩漫条漫）· **G 卷的 G04（漫画分格）与 G10（剪影）** · C10 合成器浪潮 · C17 孟菲斯。
**怎么写**：**写实系量级整段停用**，改用 `stylized-look.md` 的风格化量级句；**色彩必须写死色相与占比**（否则掉成棕褐单色）。

### 系三 · 第三系（工艺渲染系）→ 前两套都必须停用
**★ 这一系的公共层（可逐字复制的量级句）→ `stylized-look-craft.md`**（十种工艺 × 六栏：材料签名 · 运动特性 · 光怎么处理 · 色板写法 · 两族排除句 · 失效症状）。**写系三之前先翻它，别现编。**
**适用**：**E 卷的绘画与纹样载体（E01 青绿山水 / E02 工笔重彩 / E03 敦煌 / E04 年画 / E05 浮世绘 / E06 琳派 / E08 唐卡 / E09 波斯细密画 / E10 印度细密画 / E11 伊斯兰几何 / E12 拜占庭圣像 / E13 非洲蜡染 / E15 安第斯织纹）** · D 卷（D01 吉卜力手绘水彩背景 / D09 3D 长片 / D10 定格 / D11 像素 / D12 低多边形 / D14 水彩绘本 / D15 木刻 / D16 油画动画 / D17 剪纸纸艺 / D18 中国水墨动画）· A 卷的笔触与工艺组（A01–A05 · A18 拉斐尔前派 · A21 抽象表现 · A22 哥特彩窗 / A32 达达与现成品 / A35 素人艺术 / A38 罗马壁画）· **G 卷的 G06 游戏引擎 / G09 生成痕迹 / G11 微缩模型 / G12 沙画 / G14 实物剧场** · C09 蒸汽波。
**这三系最容易翻车**，因为模型没有现成的量级可套，会自己掉回写实或描边。**必须写齐三件**：

| 件 | 做法 | 例（D10 定格） |
|---|---|---|
| **① 渲染方式句** | 说清"这是**怎么造出来的**"，不是"看起来像什么" | `逐格拍摄的黏土定格动画，表面留有指纹与压痕` |
| **② 停用前两套** | 不写胶片/机身/镜头；不写描边/平涂 | 去掉 `ARRI` `Cooke` `描边` `平涂色块` |
| **③ 禁止项明确排除两系** | 禁止项里同时排除写实与描边 | `禁止：照片写实，真实毛孔，PBR 材质，胶片颗粒；禁止：美漫描边，赛璐璐平涂` |

> **判据**：把提示词给一个没看过画面的人，他能不能说出"这是用什么工艺做的"？不能 → 渲染方式句不够。

### 混合与多系并存 → G 卷 + D20，走单条路由（共 8 条）
**这 8 条不归入上面任何一系**：**D20 新海诚式**（写实背景层按系一的光效写、动画角色层按系二的描边写）· G01 / G08 / G15 是**多系并存**（各段各块各自选系）· G02 / G03 是**两层混合**（一层拍、一层画）· G05 是**运动处理层**（可叠在任何系上）· G07 跟着低端档走。
**判据**：**先答"哪一层是拍的、哪一层是画的、哪一层是造的"**——答不出，模型就会把几层糊成一锅。多系并存的准入条件见 `stylized-look.md` 第二节·补2 的四条件。

## 三、选取流程（五步 · 按当前任务执行）

1. **判叙事内核** —— 写下三个词：**情绪 + 题材 + 文化语境**。用 §五「按氛围反查」缩到 3–5 个候选。
2. **过可行性门** —— 按 `feasibility.md` 数镜头里的：手部动作 / 走路跑步 / 多人交互 / 剧烈动作 / 画面文字。**超过 3 项 → 优先选"信息密度低"的风格**（写实系、极简、侘寂、长镜类），避开 C 卷的高密度霓虹与 D 卷的复杂作画。
3. **查辨识度与滥用度** —— 本库**最容易被模型默认产出、也最不独特**的四个：`D09 3D 长片` · `C01 赛博朋克` · `A19 超现实主义` · `F06 迷幻`。选它们**必须有明确理由**，否则换同氛围的次热门（如恐惧优先 `C15 阈限空间` 而非 `C01`）。
4. **写风格声明（三行，进交付物）** —— ① 一句话风格 + 编号（如 `B10 王家卫式`）；② 量级路由（系一/二/三）；③ **三条一致性锚点**（全片不许变的三件事，如"抽帧拖影 / 霓虹绿红琥珀三色 / 玻璃与镜面分层"）。**写完才进资产阶段。**
5. **★ 取参照 + 校准（2026-09-15 补 · 写完声明之后立刻做，别等到交付前）** —— **① 去哪找参照**：按卷翻 **`style-sources-a.md`（美术史）· `style-sources-b.md` / `b2` / `b3`（电影与导演）· `style-sources-c1.md` / `c2`（类型与亚文化）· `style-sources-dg.md`（动画与混合媒介）· `style-sources-ef.md`（地域与平面）**——**每条给取图处 + 检索键 + 该截哪一类帧**；**② 怎么核像不像**：先翻定标页 **`style-cards-scale.md`（怎么量 · 容差表 · 实测示范）**，再翻 **校准卡七册 `style-cards-a.md`（美术史）· `style-cards-b.md`（B 卷详卡）· `style-cards-b2.md`（导演）· `style-cards-c.md`（C 卷）· `style-cards-c2.md`（C 续二/三）· `style-cards-df.md`（动画＋平面）· `style-cards-eg.md`（地域＋混合媒介）**——**先量参考帧、再量你出的图，把两组数填进卡的「参照 / 生成」**；**按容差表判**（色相 ±12° · 饱和 ±25% · 明度与对比 ±15%），**超了就先改风格层再写块**；**③ 要调"整片调色方向"时** → `color-grading-styles.md` 十四族先认族。

## 六、四条纪律（违反其中任一条，风格都会散）

1. **一片一套** —— 选定后不改（跨世界例外见 `stylized-look.md` §二·补2 的四条件）。**风格中途变化 = 观众读到的不是"风格"而是"不一致"。**
2. **风格必须写在资产之前** —— 资产的量级与材质由风格决定。**先出资产再定风格 = 资产全部重出。**
3. **风格服务叙事，不是装饰** —— 每个风格条目都给了「适用场景 / 叙事氛围」，**用之前先问：这个风格在替我讲什么？** 答不出就换。
4. **风格要落到"技法名词"** —— 只写"像王家卫"没用，要写 `抽帧拖影 / 霓虹绿红琥珀三色 / 玻璃与镜面分层`。**每条的可写句式就是干这个的。**
