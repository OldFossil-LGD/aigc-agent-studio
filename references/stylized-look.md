## 一、核心六条（美漫描边是怎么做出来的）

| 条 | 怎么写 | 反例（会掉回写实或塑料） |
|---|---|---|
| **1 黑色手绘描边** | 外轮廓是**粗细有变化的手绘黑线**，内部结构线更细更淡；转折处线更重 | 等宽描边、没有描边、只有物体边缘淡淡一圈 |
| **2 平涂 + 硬边明暗** | 明暗用**两到三级平涂色块**，明暗交界是**硬边**，不做过波 | 柔和渐变、真实光衰减、三点布光 |
| **3 手绘质感** | 阴影里有**交叉排线与网点**；表面有做旧划痕、掉漆、**印刷套印的轻微偏移** | 干净的数码渐变、塑料面、完美漆面 |
| **4 高饱和但受控** | 一个主色 + 一两个点缀色；用**脏色打底**（沙尘黄、铁锈红），不是纯净色 | 全画面高饱和、彩虹配色、干净色块分离 |
| **5 材质靠线条表达** | 金属＝锐利的直线与块状高光；布料＝折线；皮肤＝少量线条带过 | 真实材质反射、金属环境映照 |
| **6 光被简化** | 光只负责**分色块**（亮面 / 中间调 / 暗面），不做真实衰减、不做体积光与光晕 | volumetric god rays、bloom、halation |

## 二、风格化量级句（逐字复用 · 替代写实量级）

```
【统一提质层 · 描边分支】
渲染方式：全片统一为美漫描边风格，卡通渲染——
外轮廓是粗而明显的手绘黑色描边（外粗内细、转折处更重），内部结构线更细更淡；
明暗用两到三级平涂色块，明暗交界是硬边，不做照片式的柔和渐变与真实光衰减；
角色的轮廓上有一道明亮的边光（轮廓光），与身体的暗面形成很强的对比——
边光的颜色是[冷青蓝]、主光方向是[暖橙]，两个颜色在人物身上互补对照。

色彩（必须写死色相与占比，否则模型会掉成单一色调）：
这是一部彩色片，画面明亮、饱和度偏高，全部颜色只来自三个家族——
[主色：如暖沙色与铁锈色的环境色] 占画面约七成；
[对比色：如天空与阴影的冷紫灰蓝] 占约两成；
[点缀色：如机器人独眼的青色与霓虹的品红] 不到一成，只出现在发光体上。
禁止：整幅画面只有一种色调，棕褐色调，去饱和，旧照片感，黑白。

质感：阴影里带手绘的交叉排线与网点，表面有轻微划痕与掉漆（做旧要克制，不要糊成脏灰）。
禁用：照片写实，真实皮肤毛孔，PBR 材质质感，电影感调色与 LUT，柔和高光滚降，
halation 光晕，体积光与 god rays，均匀渐变的立体渲染，全画面过锐的数码质感，
同一张画面里混用写实与描边两种画法。
```

**为什么色彩必须写死**：只写"高饱和但受控"模型听不懂——它会顺着"做旧 + 脏色"一路推到**棕褐单色**，出来像老照片或水墨稿，这是最典型的翻车。必须给出**具体色相 + 明确占比 + 禁止单色**三件，且色相要放在锚点靠前的位置。

**三件让风格"立住"的东西**（缺一件就会滑向水墨稿或半写实）：

| 件 | 写法 | 缺了会怎样 |
|---|---|---|
| **粗黑描边** | "外轮廓粗而明显、外粗内细、转折处更重" | 只写"描边"，出来是细细一圈，像加了个滤镜 |
| **互补边光** | "轮廓上一道冷青蓝的边光，主光是暖橙" | 没有边光，人物就平贴在背景上，没有立体感 |
| **高饱和 + 写死占比** | 三个颜色家族 + 明确占比 + 禁止单色 | 掉成棕褐单色 / 旧照片感 |

**注意**：写实层里被禁的"动漫 / 卡通 / 二次元 / 漫剧感"，**在本层是必须出现的**——两套黑名单正好相反，这是判断有没有切对层的最快办法。

## 二·补 风格语法 > 风格外观（2026-09-11 补）

**问题**：只写"美漫感 / 像漫画"这类**外观词**，模型会给你一张"描了边的写实照片"——因为它不知道**漫画是靠哪些技法造出来的**。

**做法**：风格化提示词里，**技法名词的效力远高于形容词**。把"看起来像什么"翻译成"用哪几种画法画的"。

| 想要的观感 | 不要写（外观词） | 要写（语法·技法） |
|---|---|---|
| 美漫 | 美漫画风、漫画感 | **手绘黑描边**（外粗内细）+ **速度线**（动作方向的放射线）+ **网点**（阴影里的点阵）+ **拟声词框**（大写字块，可选） |
| 赛璐璐 | 日式动画感 | **三四级平涂色块 + 硬边明暗交界** + **色指定表**（每个角色一套固定色号） |
| 水彩 | 水墨风、水彩感 | **湿边晕染**（边缘有深色沉积线）+ **留白**（未上色的纸白）+ **笔触可见的排线** |
| 版画 | 木刻风 | **刀具刻痕的直线组** + **黑白二值为主、极少中间调** + **套色错版偏移** |

**自查**：把提示词里的**形容词全划掉**，剩下的还能不能指认"这是哪种画法"？不能 → 补技法名词。

**与板块二的边界**：黑白故事板**只锁构图与明暗结构**，**不写风格技法**（技法属于成片色彩层）。故事板画得越"通用"，越不干扰后面的风格切换。

## 二·补2 跨风格准入四条件（默认不放行，2026-09-11 补）

**默认纪律**：一部片**一套量级**（**第四节"切换纪律"**——原注"第二节末"系节号错写，2026-09-30 勘正）。但用户明确要求"片子里出现两个世界"（现实 ↔ 画中画 / 回忆套层 / 游戏内界面）时，按四条放行：

| 条件 | 判据 |
|---|---|
| **1 两个世界各有稳定量级** | 现实有写实量级句、画中世界有风格化量级句，**各自内部自洽**，不逐镜飘 |
| **2 切换点有物理触发** | 不是硬切风格，是**有一件事导致切换**（翻开画册 / 屏幕点亮 / 目光进入画框），观众看得见"门在哪" |
| **3 资产不跨世界复用** | 写实角色资产不进风格化世界，反之亦然（两侧各自出资产，允许同人不同画法） |
| **4 切换次数受控** | 全片 ≤3 次；每次切换要有叙事理由；频繁跳会增加观众理解成本 |

**做不到任一条 → 回到"一套量级"**。

## 三、按类型适配

| 类型 | 风格化下的写法 |
|---|---|
| **角色设定板** | 描边 + 平涂 + 表情表；皮肤**不写毛孔**，写"皮肤用少量手绘线条带过，明暗只有两三级色块"；六视角与表情表其余五官锁定 |
| **道具** | 写"描边清晰、平涂色块、边缘有掉漆与划痕的**边界线**"；不用摄影棚暗调布光，用**纯色或渐变底 + 平光** |
| **场景** | 写"背景是绘制的"；前中后景**用线条疏密与颜色明度分层**，远处颜色更平更浅；不做大气透视与体积雾 |
| **镜头** | 光影段只写"光从哪来、亮面在哪、暗面在哪"三件事；**不写光比数值与平方反比衰减**；后期段不写 bloom / halation，改"印刷做旧与轻微套印偏移" |

> **与 `block-playbook-asset.md` 的关系**：本节四类适配**替换的是那份手册的「8 布光」与「9 统一提质层」两块**（外加"必须删的句"）——
> **板式 / 身份锚点 / 分区 / 调性 / 材质与脏 / 尺度 / 色板七块骨架照写**，逐块思考与 12 条自查通用。
> **一句话**：那份手册默认写的是**写实系版**，本节的「分系替换表」是它的描边系列。

## 四、切换纪律

- 一部片**只选一套量级**：写实系或风格化系，选定不改（**唯一例外是二·补2 的"两个世界"四条件**——见第二节·补2）。
- **两套资产不能互换**：写实片的人物资产不能拿进风格化片，反之亦然（这是最常见的翻车点；"同人不同画法"＝**两侧各自出各自的资产**，不是同一资产跨系复用——2026-09-30 补说明）。
- 风格化系没有"高光滚降 / 颗粒簇"，取而代之的一致性要求是**描边一致 + 色块层级一致 + 做旧强度一致**（三条不对，观感立刻断）。
- 黑白故事板板块**不变**（本来就是灰度的）——它的职责是锁构图与明暗结构，与哪套量级无关。

## 五、自检五问（风格化版）

1. 全画面有没有统一的**手绘黑色描边**，粗细有变化？
2. 明暗是不是**硬边色块**（而不是柔和渐变或真实光衰减）？
3. 有没有**手绘排线 / 网点 / 做旧划痕**，还是干净得像 3D 渲染？
4. 有没有混进写实元素（真实毛孔、PBR 反射、电影感调色、光晕）？
5. **画面是彩色的吗？**——整幅只有一种色调／棕褐／旧照片感 = **首帧路径错了**（黑白故事板被直接当成了首帧），回 `storyboard-frame.md` 第四节。
