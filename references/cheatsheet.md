# 速查：最高频 55 条硬规则

> **何时读**：赶时间时先看这一页，再按需进对应文档。**读完回哪**：回到 `studio-workflow.md` 的第三步。
> 🟢 **第一次用 / 忘了怎么操作** → 先读 `start-here.md`（操作手册），本页是**规则速查**。
> 每条后面括号里是详细出处。

## 交付前必过

1. **提示词是工程型指令，不是文案型形容**——**空话词一律换成具体器材、动作、材质**（原词清单见下条指针）。**注意变体**：`电影质感` `大片感` `细腻` `高级感` 同样是空话，别以为禁了原词就安全（→ `prompt-ops.md` 空话词黑名单）。
2. **→ 交付前 10 项自查见 `steelman-protocol.md` 第 5 步**（未全过 = 不交付）——**那 10 项以第 5 步为唯一权威源，本页不复制**
3. **动笔前先走双向钢人论证**：正题 → 反题 → 交锋 → 合成留痕；反对意见写不到具体句子＝没想。（`steelman-protocol.md`）

## 量级与质感

4. **量级只写一套**：**写实族＝从 34 个方案包（主库 17 + 补充 17）里选定本片那一包**（把该包的「器材」行 + 「痕迹」行逐字粘上，见第 38 条），或描边族（美漫描边），一部片选定不换。**写实族不等于"固定用 ALEXA 35 + Cooke S4/i + 2383"那一套**——那是 2026-09-12 已废除的旧默认值。（`quality-layer.md` · `camera-package-library.md`）
5. **光有出处**：1–2 个有动机的光源，光先落在环境上，人物只接受它的一部分。
6. **曝光优先保护脸**，脸的另一侧不做补光、直接沉进黑。
7. **高光写行为不写亮度**：平滑滚降、渐进出白、不裁纯白、过曝处仍带暖色。禁"明亮 / 发光 / HDR"。
8. **颗粒写暗部成簇**（暗部粗、中间调细）。**禁写"film grain / 加颗粒"**。
9. **摄影机写呼吸感，两个限定词都要**：极轻微 + 如呼吸般。只写"手持"会被理解成剧烈摇晃。
10. **声音行必带**：无配乐、只留现场音，并**显式列出**关键环境音。
11. **结尾留白**：不堆对白、爆炸、强光、胜利姿势；用空位与克制意象收。
12. **角色 / 装备 / 服装各至少两处瑕疵**——完美＝假，且瑕疵兼作跨镜一致性锚点。

## 人物与动作

13. **情绪词必须翻译成形变**："她愣住了" → 眼睛睁大到露出眼白、嘴唇微张不动、呼吸停住。
14. **要表情就给近景**——大远景里脸占不到比例，写什么表演都白写。
15. **每镜只写 1–2 个关键动作，写透而不是堆砌**：深度不等于数量。
16. **先分诊再下药**：**僵硬＝没信息**（补可见信号）／**虚假＝太整齐**（加延迟、半途修正、未完成、一处矛盾）。**虚假的解法是"破"不是"加"**——加细节只会更假。（`performance-craft.md`）
17. **反应必须有延迟**（真人是"听见→理解→决定→动"，约 0.5–1 秒）；**动作不许都做完**（半途改主意、过头再修正）。这两条最能治"假"。
18. **眼睛必须写（眼生命）**——没写眼睛 = 一双死不动的玻璃珠眼，**这是最先被看出"是 AI"的地方**。视线一直在动 · 眨眼随状态变 · 眼神光要"活" · 眼睛比头先到。（`performance-vocabulary.md` 第二节）
19. **给角色一件"正在做的事"（活计）**，最强的重音是**停下手里的活**；**距离就是情绪**（越界或退开＝节拍变化）；地位靠"不动 + 慢 + 注视长"做出来，不靠形容词。（`performance-craft.md` 第三节·补）
20. **二级动作必须有因**——头发、衣角、尘埃只对写明的风反应；否则得到"水下漂浮感"。（`physical-feedback.md`）
21. **被接触面也要有反应**：沙要陷、水要溅、布要凹、桌面要震。
22. **周期动作（走路 / 奔跑 / 负重位移）禁止用纯文字求解**——走「参考视频驱动 → 首尾帧单步 → 构图规避 → 实拍兜底」。（`motion-control.md`）

## 镜头与平台

23. **一段一个主运动、一镜一个叙事功能**；"先推近再环绕"= 两个主运动，删一，或在**段边界**分开。
24. **运镜不要只会"推 / 横移 / 环绕"三个词**——先查**六族全谱**（位移 / 光学 / 旋转 / 环绕 / 高度 / 复合）再选。**位移与光学的判据是视差**：要写清"摄影机真的移动"+"近景物体掠过画框边缘"，否则模型给你光学变焦；**环绕必须写"是摄影机在绕，主体自身不转动"**；**狭窄空间（走廊 / 车内 / 电梯）禁环绕**，改侧跟或横移；**复合运镜最多 2–3 个分量，用"先…然后…"写顺序**，超过就改分段镜。（`camera-movement-library.md`）
25. **运镜五要素缺一不可**：起始观察点 / 运动轨迹 / 速度缓动 / 锁死项 + 按族排除 / 停止结果。**写不全＝无效运镜，模型会自己补一个最省事的——通常是缓推。**（`camera-movement-library.md` 第二节）
26. **转场是叙事工具，不是装饰**——同场景换机位**默认硬切**。**相似转场**（上一镜末尾的形状成为下一镜开头：圆月→圆碗）与**动作转场**（同一动作在两处接着做完，**切在动作的可读峰值上，不要等动作做完**）最值钱；**交接物必须命名**（`一片正常大小的落叶飘进镜头` 强于 `有东西遮住镜头`）；平滑类转场必带两条护栏：`画面无硬切，物体不凭空出现或消失`。（`transition-library.md`）
27. **镜内景别与焦距不变**；**不要写"慢慢变远""镜头渐渐拉开"**（会直接触发变焦）。**作用域**：这条只管"一条之内不许自己变景别"，**不是禁止你安排多个景别**。
28. **想一条里出多个景别 → 走分段镜，而不是删掉上一条**：**★ 先算 `总时长 ÷ 段数` ≥ 2 秒**（**< 2 秒直接砍段数**——5 秒 5 段＝每段 1 秒＝整条看不懂）· **按「段落 / 组合」写（`段落A：…；段落B：…`），⛔不写「镜几」、不写秒数**（**AI 自己会分配时间**）· **15 秒 3 段最稳** · **共用块写一次、段内变化块写进时间线**（**景别/构图在段内按"先…随后…最后…"改**）、**锚点句逐字复述到每一段**（禁近义词替换，`铁锈红外套`≠`深橙色外套`）、写死"恰好 N 个段落 N-1 个切换点"、全程不变项与排除项写在段落**之外**；段内仍按单机位纪律写。**总时长仍写在首行**。**交付前排镜表跑 `shotlist_lint.py --mode gen`。**（`segmented-shot.md`）
28b. **★★ 段内不许用切镜词汇**：**`准备 / 接触 / 落定 / 起始 / 触发` 是段与段之间的词**——写进单段，模型会读成"这是三个镜头"，出来就是**一段里塞了整段动作弧 + 起始景别与后文对不上**。**段内推进写"他先…；随后…；最后…"。** 另：**段首景别只描述起始帧**，段内真发生景别量级变化必须写进时间线。（`segmented-shot.md` §三）
28c. **★★★ 景别由"画框装了什么"决定，不由"这件事多重要"决定**：**判据＝把画框当剪刀，剪下去后框里还剩几张脸、几个物件？** 所以景别行**必须点名画框边界**——❌`中近景——手停在枪套上`（只写动作，读起来像特写）→ ✅`中近景——帽檐横切过面部上三分之一，画面下缘收进枪套的下半截`。**同一件动作在两个景别里是两个意思**（特写＝手比人诚实 / 中近景＝他在忍）。**换景别只有三条正当理由**：信息密度变了 · 距离关系变了 · 叙事职能变了——**"这件事很重要"不是理由**。（`sequence-craft.md` §8.1b）
29. **禁止项分三类**：**瑕疵**（手指、文字、模糊）用**肯定状态句**（"不要多余的手指"反而会注入）；**同族动作**（推/拉/摇/移/环绕/变焦）**必须逐一写排除**，否则模型在族内乱挑；**内容类别**（"不要像游戏""不要廉价特效"）**否定与状态句都无效**，只能改写成**"该拍什么"**。**不写 IP 名**（Seedance 系过滤激进，一个词可能拒整条）。（`quality-layer.md` 第四节）
30. **出片不合格先判责任层**（资产 / 契约 / 提示词 / 动作 / 平台 / 随机性 / 后期），**不默认加负面词**；连续两批同错无改善就停手。（`qa-failure-codes.md`）
31. **运镜速度要给量纲，不要只给形容词**："缓慢"是相对的——1 米上是挪，10 米上是敷衍。写 **`距离 + 用时`**（`推近约1.5米、用时2秒`）比只写 m/s 更稳。**速度尺**：凝滞 <0.2 ／ 缓推 0.3–0.8 ／ 常速跟随 1.2–1.5 ／ 快推 2–4 ／ 甩 >6 m/s。**复合运镜必须写速度差**（`升起慢、环绕快`），同速会糊成一坨。（`camera-movement-library.md` 第二节）
32. **材质有"力学"与"光学"两套词汇，只写一套不够**：重量/摩擦/惯性全写对，水照样像颜料、布照样像纸板。液体补**菲涅尔反射 + 焦散 + 表面张力**，织物补**各向异性反光**，接触处补**颜色溢出**（红漆桌面把淡红反到白瓷杯底）。（`tone-realism.md` 第三层）
33. **细节预算随景别缩放**：全景/远景只写整体肤色、轮廓、姿态、服装反光，**不写毛孔**；中景写手与衣物质地；**特写**才写毛孔、绒毛、眼下与唇纹。在远景里写毛孔＝**无效指令**，还会把构图拽成假特写。（`tone-realism.md`）
34. **一个画面只讲一个拍摄故事**：载体（手机随手拍 vs 电影级影棚主光）／光质（硬直闪 vs 柔和黄昏）／清晰度（运动模糊 vs 处处锐利）三条轴线，任一条打架都自相矛盾。要另一种观感就**出多条独立版本**，不塞进一条。（`quality-layer.md` 第 2 条）
35. **不完美只给一到两处**（单画框内可见口径；资产设定档的逐类预留见第 12 条）：一处是真实，三处以上就从"真照片"翻成"特效演示"。而且每一处都要**有因**（风、湿度、使用痕迹）。（`tone-realism.md` 第三层 · 剂量纪律）
36. **风格必须写在资产之前**：风格决定资产的**量级句、材质词、色彩占比**——先出图再定风格＝**全部重出**。出资产前先答三问：风格编号？属哪个**量级系**（写实／描边／**第三系工艺渲染**）？全片不许变的三条**一致性锚点**是什么？（`style-library.md`）
37. **风格要落到"技法名词"，不能只写名字**：写"像王家卫"没用——模型不知道那是什么意思；要写 `抽帧拖影 / 霓虹绿红琥珀三色 / 玻璃与镜面分层`。**第三系（3D长片 / 定格 / 像素 / 油画 / 剪纸 / 水墨）必须写"渲染方式句"，并同时停用写实与描边两套量级句**，否则模型会自己掉回写实。（`style-library.md` §二）
38. **写实系必须先选「拍摄方案包」，不许一套用到底**：主库 17 包（P01 手机 … P17 虚拟制片）+ 补充 17 包（P18–P34，见 `package-extended.md`），可整包用也可跨包组合，**一片一包、资产与镜头同包、痕迹至少写三项**。判据一句话：**"这是谁拍的、拿什么拍的、在什么条件下拍的"能答出唯一一个答案吗？**（`camera-package-library.md`）
39. **提升真实感最快的一档是「低端档」**：手机 / 家用 DV / VHS / 监控 / 转播 / 网络摄像头——**缺陷本身就是观众判真的依据**。写了"手机拍的"就必须把手机的痕迹写出来（边缘畸变、彩色噪声、高光硬裁），否则模型会用它的默认观感盖掉你写的机身。（`camera-package-library.md` §三）
40. **AI 味按"检测清单"反着查**：光源个数与阴影方向对得上 · 季节天气服装建筑互相印证 · 眨眼每 **2–10 秒**且眨眼时眼周肌肉联动 · 呼吸落在**短语之间** · 室外人声不带"录音棚般干净"。（`ai-artifact-control.md` §五·补）
41. **"太干净"本身就是破绽**：真实相机有像差、真实素材有噪声——一个本该在混乱现场的人却像杂志封面，就是红旗。选数字档时至少叠一层调制（黑色漫射滤镜 / 颗粒档 / 漂白效果）。（`camera-package-library.md` §四）
42. **排镜先判情景类型，别一上来就写提示词**：对话 / 动作 / 悬念 / 揭示 / 追逐 / 独处 / 蒙太奇各有配方（入场镜 → 推进 → 峰值 → 出场）。**动作朝峰值压缩**（越切越快、框得越紧），**悬念正相反**（起手紧，然后一路放宽）——**搞反就散**。每镜要能写出"**这一镜的唯一信息**"，写不出就说明这镜不该存在。（`shot-orchestration.md` 第三节）
43. **AI 动作场"靠变不靠短"**：真人快切靠压时长（现代动作片平均镜头已短于 3 秒），**AI 压时长只会崩**——单镜守 **2–3 秒**，靠**景别与机位的变化**造速度感。同时**相邻两镜机位差要 ≥30 度**且都在轴线同侧：**"变了但没变够"比"完全不变"更难看**。（`shot-orchestration.md` 第四、七节）
44. **两镜接不上别硬接**：插一个 1–1.5 秒的**桥接镜**（一只手 / 一个物件 / 一片环境 / 一个背影）把两个不匹配的镜头隔开；**瑕疵落在首末 3 秒的这条就不要**（剪辑点必然落在首尾）；检查时**只看剪切点**——把前一条末秒与后一条首秒并排，查注视方向、主体位置、手位、运动方向、光线、背景几何六项。（`shot-orchestration.md` 第八节）
45. **资产不是"看着像"就能用——要跑一组测试，且量化**：资产只有 **draft / locked** 两态。角色跑四类（**跨角度** 正/3-4侧/侧 · **跨景别** 近景+中远景 · **真实光** 用该场实际的光而不是资产中性光 · **同框** 与每个搭档各一条二人镜），场景跑三类（跨机位 / 带角色 / 真实光）；**同一条件连跑 5 条、5/5 全成立才锁，不许"4 条好就锁"**。**一场戏涉及任一资产还是 draft → 整场不开工。**（`production-ledger.md` 第二、三节）
46. **一镜超过 8 次还不过 → 改结构，不是改词**：1–3 次正常试错 · 4–5 次判责任层 · **6–8 次换实现路径**（单机位→分段镜、纯文字→参考视频/首尾帧）· **>8 次改结构**（拆镜 / 换机位 / 换景别 / 把功能移给相邻镜）。**禁止"再抽最后一次"。** 止损≠放弃意图——**意图守恒，手段可换**。（`production-ledger.md` 第四节）
47. **每次生成都记一行台账**：日期 / 镜号 / 资产版本 / 第几次 / **保留·淘汰·被过滤** / 淘汰原因（封闭枚举）/ 改了什么（**只写一个变量**）/ 花费。**"被过滤"（审核拒）与"淘汰"（质量差）必须分开记**——解决方向相反。连记 **30–40 行**后按**镜头类型**（不是全片平均）算命中率，用它替换 `platform-matrix.md` §四 的公开难度系数。（`production-ledger.md` 第六节）
48. **人物像 AI 时，先改光位再改词**：毛孔要**斜射光**才有影子、绒毛要**逆光**才显形、**次表面散射**要**逆光**才透红、高光要**斜角**才符合菲涅尔分布——**四样在正面平光下全部隐形**。所以"为了看清而开大正面柔光"会一次毁掉四项；正解是**换角度 + 加负补光（黑旗吸掉反弹光）**，不是加形容词，更不是加正面光。（`skin-realism.md` §1.4）
49. **三条皮肤缺陷的根因各不相同，别用同一个修法**：**油亮** ← 皮肤被当**不透光材质**（真实皮肤仅 6% 表面反射、94% 是次表面散射）→ 补 SSS 证据句（耳廓透红 / 暗部偏暖）；**高光成片** ← **去噪陷阱**（毛孔在 latent 里只占 1–3 像素，被当噪声抹掉，高光失去打断物）→ **把毛孔写回来**而不是写"高光小一点"；**皱纹假** ← 模型**无解剖依据** → 给走向。（`skin-realism.md` §一）
50. **皱纹是"走向"不是"数量"，且与其下肌肉收缩方向呈直角交叉**：额肌（抬眉）→ 额头**横行**；皱眉肌 → 眉间**垂直**；眼轮匝肌 → 外眼角**扇形放射**；口轮匝肌 → 口周**垂直**。**先定年龄再决定写不写**：20 岁只该有**动态细纹**（笑时才起），写静止深纹＝直接判废；**重力性皱纹 40 岁后**才明显。三个例外（表情纹与 Langer 张力线不同向）：**眉间、下唇、外眦**。（`skin-realism.md` §1.3）
51. **油光只许落在 T 区**：T 区（额/鼻/下巴）皮脂腺 **800–900/cm²**、毛孔粗大、有油光；U 区（两颊/眼周）稀疏、毛孔细小、**必须哑**。写"全脸油亮"是错的——**"不均匀"本身才真实**。同时补**绒毛**（逆光下轮廓的毛边），它是"人 vs 蜡像"的关键判据。（`skin-realism.md` §二）
52. **高光和颜色不在同一层——这是皮肤物理的总纲**：高光发生在**角质层（10–20 µm，n≈1.55）**，颜色与透光来自**真皮 3–5 层**。所以**"把高光做小做碎"和"把皮肤做透做暖"是两件互不相干的事**；模型把它们混算，正是"为了让皮肤透光而整张脸发亮"的源头。→ 提示词里**必须分开写**（高光句 / 透光句），不要合成一句"皮肤有光泽"。（`skin-light-physics.md` §一）
53. **暗部偏暖是"皮肤是半透明体"的唯一物理证据**：黑色素吸收是**幂律**（`μa_mel ∝ λ^(−3.33)`，**波长减半吸收升约 10 倍**）→ 蓝光被表皮截住，**只有红光能过真皮**。所以暗部里唯一还有能量的是**穿过真皮的红光**——**冷灰暗部 = 没有皮下光**。穿透深度量级：405–532 nm 仅 **~0.3 mm**、>980 nm 达 **~1.65 mm**。（`skin-light-physics.md` §一、§二）
54. **"柔光"三个字不够——软硬由视在尺寸决定，不是灯的物理尺寸**：`θ = 2·arctan(S/2d_o)`（角尺寸）、`W_p = S·(d_r−d_o)/d_o`（半影宽度）→ **由此得"接触处必锐"（contact hardening）**：`d_r→d_o` 时 `W_p→0`。**判据：看阴影与物体的接触处**——接触处锐、离得越远越虚 = 真实；**整条边一样虚 = 假的**。另：点 `1/d²` / 线 `1/d` / 面几乎不降 → **柔光近置才有主体与背景的分离**。（`skin-light-physics.md` §六）
55. **写给模型的每一句都要过一关："这是让它『去做』，还是让它『去画』？"** —— **动作它做不到，结果它画得出。** `挪灯 / 并排 / 加柔光纸 / 关掉一路 / 把 fill 开大 / 把毛孔写清楚` 都是**动作**（模型只会随机给你一张图）；对应的**结果**说法是 `光从一个方向来，墙上只有一条影子` / `暗侧完全没有补光，但纹理照样清楚`。**别写"把两路色温调一致"，要写"脸的一侧偏冷、另一侧完全落在阴影里，脸上没有第二种颜色"。** 注意：`光位 45°` `逆光` `半张脸` 是**结果**（模型学过），**可以直接写**——所以不是所有剧组语言都要删，**要删的只有"只有人能做、模型无法从画面结果理解"的那部分**。（`light-quality-construction.md` 卷首对照表 + 第七节第六问）
