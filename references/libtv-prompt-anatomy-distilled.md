## 0. 一句话总纲

**全局定规则 → 逐镜只写差异 → 末尾列因果锁定。**

这是实产的骨架，与技能库的「全片通用 3 块 + 本镜专属 9 块」**不是同一套**：
库规是逐镜自检清单，实产是分层写作，信息密度高得多且不重复。

## 1. 骨架模板（【实产】最常见形态）

```
{{Mixed N}} 语义名。              ← 引用声明行，一条一行，紧跟「不要背景音乐，不要字幕」

## 全局规格                      ← 画幅／帧率／快门／主摄影机／色调／摄影风格（全段只写一遍）
## 整体空间锁定                  ← ⭐ 越轴的唯一治法，见 §3
## 主体规格锁定 / 语言设定        ← 可选

1、风场与流体逻辑               ← 宏观设定用数字编号排序
2、光影与材质逻辑
3、摄像机运镜轨迹                ← ⭐ 箭头链先声明整段节奏，见 §4
4、正文：分镜执行动作

镜头N｜时间码—时间码｜秒数｜功能标题
  相机／焦段：
  构图／运镜：
  画面／表演：
  声音：（只在需要变化时写）

## 执行锁定                      ← 尾部清单，不逐镜重复
```

块名完全自由（已见十余种：执行锁定／执行重点／段落核心／怪兽规格锁定／空间尺度与声音锁定／影像规格／整体拍摄规格／环境逻辑）。**结构统一即可，块名随写随定。**

## 2. 引用声明行（铁律）

```
{{Mixed 2}} 怪兽。
{{Mixed 5}} 女上司昆仑。
不要背景音乐，不要字幕。
```

- `{{Mixed N}}` = `mixedListOrder` 里 1-indexed 的位置，不是数组下标。
- **N 必须等于该 key 在 `mixedListOrder` 里的 1-indexed 位置**；N 在文字里出现的先后顺序**不影响**（实测有跳号、`{{Mixed 11}}` 写在 `{{Mixed 10}}` 前面的成功节点）。
- 绝不靠"上次是几号"推算。每次 `leftEnsure` 之后先回读 `mixedListOrder`，再据此重编**全部** `{{Mixed N}}`。
- 加一条参考 → 后续序号**整体 +1**（两节点交叉实证）。
- 参考可以在列表里但不被引用（占位用法）。
- **插桩 + 有边 + 文字声明"本场不出现" = 合法**（为后续镜预埋）。
- **插桩但没有 `left` 边 = 真错误**。

## 3. 治越轴：`整体空间锁定` 块（本次深挖最高价值发现）

**越轴的根因不是"写错了左右"，是方位被交给每一镜重新发明。**
逐镜写"塔在右边" = 每镜各自决定一次 → 必然漂。
正确做法：在镜头表**之前**用独立块把方位一次性写死，镜头行只写变化。

原文（第四段 `v-eQHpWKVWnk`）：

```
## 整体空间锁定

- 海岸与怪兽始终位于画面左侧，西侧避难所在画面右侧。
- 所有群众统一向画面右侧撤离，避免灾难场面失去方向。
- 巨爪从左侧海面上方越过防波堤，再压向岸边建筑与撤离街道。
- 零从右侧逆着撤离人群冲入，形成明确的迎敌方向。
- 零保持正常人类身高，绝不能巨大化。画面重点正是她与巨爪之间近乎荒谬的体型差。
- 全段采用近距离灾难纪录片式手持。摄影机与群众一起逃跑，会被撞偏、遮挡、失焦，但必须迅速重新捕捉主体。
```

**三层结构：**

1. **锁死的**：主体**之间**的左右／前后关系 · 各自所属空间段 · **不可穿越**的移动路径
2. **可变的**：主体在**画面**里的绝对左右 —— 由机位方向决定，必须与"从哪个方向拍"一起声明
3. **必写的四样**：坐标系绑定（世界方位 ↔ 画面方位）→ 机位→画面左右映射表 → 互不穿插禁令 → 每镜 `构图` 里复述结论并注明拍摄方向

- **同机位正反打导致画面左右互换是正确行为，不是越轴。**
- 只写"某人在画面左侧"而不写"从哪个方向拍" → 模型只能猜 → 这才是越轴真正成因。
- **越轴更常见的成因是"走过去时穿过了对方"** → 必须锁移动路径（`不穿过零的前方`）。
- 两人**高速交错移动**时，静态锁不够用 → 加「换位轴」：指定画面中央物体作轴 + 两人分别从两侧通过 + 禁止直接跨轴切镜。

## 4. `摄像机运镜轨迹` 块（强烈推荐抄）

先给机位序列总览，再逐镜展开：

```
3、摄像机运镜轨迹
   【24mm极低背后仰拍（巨物降临的压迫）】
   ➔ 【Phantom 4K超升格（快-慢-快的极速流速折跃）】
   ➔ 【85mm极低贴地侧跟（底盘马步与发力点）】
   ➔ 【100mm微距（擦弹与自愈的死寂）】
   …
```

四个好处：

1. **机位序列一眼可读** —— 人工审阅不用逐镜读就知道这段怎么拍
2. **焦段与叙事职能绑定**（`擦弹与自愈的死寂`），不是孤立参数
3. **编号块强制分层**，消解 `「镜头N…」` 的歧义
4. 正文 `相机／焦段` 与轨迹块**逐项对应**，轨迹块是索引，正文是展开

## 5. 镜头行写法

### 5.1 标题 = 这镜的功能，不是画面描述

`｜合影尚未开始，血雾已经出现` · `｜差一步就爬上来` · `｜阴影吞没展区` ·
`镜头5｜…｜4.4秒（全片最高光：子弹时间与动能震荡！）`

这是**默认推荐，不是硬门禁** —— 同一 owner 下的成功节点里也见过纯 `镜头1` 无功能句。

### 5.2 相机的四要素

`机身型号 + 焦段 + 画框位置 + 运动方式`
`ARRI Alexa 65，14mm，超广角极低仰拍转剧烈物理震颤`
不写观感形容词。

### 5.3 摄影机当角色写

摄影机的**被动反应**也是内容：`会被撞偏、被水掀翻、短暂找不到人物，但必须迅速重新捕捉`。

### 5.4 景别由画框决定【库规】

必须点名画框边界（"帽檐横切过面部上三分之一"），只写动作等于把景别交给模型猜。

### 5.5 ⭐ 段落内最多四层嵌套

```
段落：场景7｜旧船坞·立体绞杀（02:53—03:19）
  └─ 阶段：【阶段三：TPS反重力跑酷 vs 六合大枪（双线高光）】
      └─ 镜头13｜03:03.5—03:04.5｜1.0秒｜拦、拿、扎！
          └─ 镜内子镜：【0.5秒】… / 【1.0秒】…
```

⭐ **【阶段N】是长段落的第二层**，实测用于 19 镜 / 26 秒的段落，把长段切成 4 个可独立审核的单元。
阶段标题写功能不写画面：`天降陨击与极速变阵`（阵型改变）· `双线高光`（剪辑归属）· `深渊自愈与绝望通讯`（信息传递段）。

→ **>15 镜的段落建议用阶段分组**，审片效率远高于逐镜。

### 5.6 ⭐ 招式名当镜头标题

`镜头13｜…｜拦、拿、扎！` —— 直接把武术拆招名当标题，既暗示了分解动作，又比"五号攻击"精确。

### 5.7 ⭐⭐ 中英双写技法的真正机制（13 处实证）

`Sliding Tackle` · `Whip Pan Split` · `Jetpack Burst` · `Barrel Roll Free-fall` · `Knee Slide` · `Flesh Knitting` · `Optical Distortion` · `Rigid Body Destruction`

⭐ **不是装饰，是给模型一套镜头语言词汇表**，且专治"中文动作词有多种视觉解读"：

| 中文能说清 | 必须靠术语 |
|---|---|
| 滑铲 | `Sliding Tackle`（美式橄榄球式低身滑行，不是摔倒） |
| 甩镜 | `Whip Pan Split`（"Split"暗示一镜内两人分向两端） |
| 二段跳 | `Jetpack Burst`（暗示有推进器，不是纯弹跳） |
| 自由落体翻转 | `Barrel Roll Free-fall`（桶滚是空翻，不是乱转） |

→ **⭐ 当一个中文动作词有多种视觉解读时，补一个英文专业术语把它钉死。**
比写三行中文描述更省字数、更有效。

⚠ 这是某位 owner 的习惯，**不是平台门禁**，建议只在中英歧义确实存在处使用。

## 5A. ★★★ 多场景并置的三条全局规则（此前完全没有的一层）

当一个段落里有 3 到 4 个不同空间（车厢 / 指挥室 / 拍卖会），
必须靠三件事让观众知道"这是同一时刻"。

### 规则一：色温隔离

> 不同场景执行**绝对的色温隔离**（运输车的战术红/屏幕蓝，指挥室的全息青，拍卖会的奢华暖黄）。

### 规则二：运动语言对照

> **运镜风格：** 运输车内使用剧烈的手持抖动，指挥室与拍卖会使用绝对平滑的机械滑轨，**形成"动与静"的暴烈反差**。

⭐⭐⭐ 第二条更狠。它不只是区分空间，而是用摄影机运动给人物分组：
混乱的（平民）与秩序的（权力方）。
**这是在用运镜做人物塑造。**

### 规则三：统一符号

> **无论观众处于何种环境，瞳孔/镜片中必须精确反射出战场的火光与残影。**

⭐⭐⭐ 整批样本里最高级的"统一符号"写法。
不靠剪辑节奏，靠一个反复出现的物理细节。
⭐ 高明之处：落实在不同光学器件上。眼镜镜片（冷、精确）与威士忌杯弧面（暖、扭曲）。
同一件事，两个质感，不重复。

→ 可推广：`无论<观众处于何种环境>，<某物理细节>必须精确反射出<主体>`

### 规则四：闪切要用同一事件统一

> 四个不同空间的特写镜头**随着同一次爆炸的光源同步切换**。

⭐ 没有这一句，四刀切就是四个无关镜头；有了这句，它是一个闪回。
⭐⭐⭐ **最后一刀必须回到主线并兑现**：`白光填满所有画框！（完美衔接回主战场的下一记绝杀）`
旁观者的闪切不是目的，**目的是让观众回到战场时情绪被抬到最高点**。

## 5B. ★★★ 剪辑术语直接写进提示词（全画布唯一一处，但最该抄的一条）

`动作匹配切` —— 把剪辑师的专业术语直接写给模型：

```
巨掌落下。

**动作匹配切——**

同一只巨掌，砸进指挥中心的立体全息战场。
```

**三步写法**：

1. 先写上一镜的末动作
2. **单独一行写出剪辑术语**
3. 写同一个动作在新场景里的落点（注意"同一只巨掌"这四个字保住了连续性）

⭐⭐⭐ **这一条直接解决了"video→video 连线被禁、只能靠文字对齐"的困境**：
既然必须靠文字，那就把文字写成剪辑术语，让模型按剪辑逻辑而非剧情逻辑理解。

同族术语：`亮度匹配剪辑` · `遮挡转场`。

### 配套：用遮挡代替硬切

> 两名士兵持枪巡过，深色战术装甲短暂遮住前景。
> 镜头穿过他们离开的空隙，落回壹号侧脸。

→ 可推广：`<前景物>经过并短暂遮挡 → 镜头穿过<空隙>落回<主体>`

### 配套：插入段结尾必须交还主线

`切回终端中的战斗画面，接船坞实景。`

**插入段拍完必须明说交还给谁。**
