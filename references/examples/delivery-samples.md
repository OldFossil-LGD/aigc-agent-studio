# 整合式交付样例（三步各一份）

> **何时读**：想知道"一份合格的交付长什么样"时。**读完回哪**：回到 `SKILL.md` 对应步骤。
> 下面用《保修期》（35 秒废土喜剧 · 美漫描边）做示例，均为**结构骨架 + 关键片段**，不是完整成品——
> 完整成品见工作区《测试片_美漫_剧本 / 资产提示词 / 分镜头脚本》。

## 样例一 · 剧本（一份文档，七件装订，不拆）

```
《保修期》· 35 秒 · 废土喜剧 · 美漫描边
一、主旨与 Logline      主旨：机器比你记得更久。Logline：拾荒少女把修了三个月的破机器人推进
                        "自动维修站"，投币后屏幕上写着——保修已过期三十年。
二、一句话梗概          以为买的是维修，其实买到的是三十年后第一次被"受理"。
三、人物                阿拾（17岁，外在目标=让 J-7 启动；内在需求=有人还记得她；致命缺陷=把铁皮当人）
                        J-7（三条腿维修机器人，只执行、且延迟半拍）
四、节拍表（精确到秒）   0–6 拖拽入场 / 6–12 投币 / 12–18 屏幕弹出"过期" / 18–24 愣住回头 /
                        24–30 抬脚踹 / 30–35 屏显"已受理"、掉出电池、独眼亮起
五、无对白版            拖拽 → 投币 → 加载 → 过期 → 愣 → 踹 → 冒烟 → 已受理 → 独眼亮（成立）
六、分场剧本            场1 · 废土路边 · 黄昏 · 外景（动作段 + 无台词）
七、台词清单            无台词；仅两处画面文字，后期贴图
```

**风格编号**：**D06 美漫金铅时代 · 网点与粗描边**（`style-library-animation.md`）→ **系二 · 描边系**，走 `stylized-look.md`。
⚠️ **描边系整段不写器材句**——不写 ARRI / Cooke / 胶片颗粒（`camera-package-quickref.md` §四 第 3 条）。
**这就是"风格编号决定后面所有环节"的样子**：选了 D06，就自动取消了整条写实器材链。

**要点**：一份文档、七件齐、不拆；节拍表必须精确到秒（后面分镜**按顺序推进**——秒数只活在节拍表与排镜表，不写进分镜提示词）。

## 样例二 · 资产（三类，每类一张/一组）

**① 角色设定板**（十区，一张）——骨架：

```
一张完整的角色设定板，超宽横版排布十个编号分区，分区之间用细白线分隔，浅灰白色干净背景；
全板统一光照：柔和的顶部平光，明暗只有两三级色块。

所有分区中是同一位17岁的废土拾荒少女：橙红色乱发在头顶扎成两个翘辫，护目镜推在额头上，
绿色的眼睛，脸颊一道旧疤，皮肤晒成麦色；灰色背心印着骷髅头图案，肩上一只手缝的护甲（边缘磨白），
右臂缠着红布，腰上挂着一把旧扳手；皮肤用少量手绘线条带过，不用写实毛孔。

分区1 主视觉 / 分区2 全身三视图 / 分区3 服装分层 / 分区4 色板（六列两行）
分区5 材质微距 / 分区6 细节插窗（四个小格）/ 分区7 面部特写 / 分区8 表情表（四个情绪）
分区9 发型细节 / 分区10 签名道具

所有分区中人物的脸、发型、服装、体型必须完全一致；分区标题留空，画面内不生成任何文字。
```

**② 道具**（一件一张）——骨架：多视角组合在同一底色上 + 逐处写脏 + **比例/颜色/磨损位置逐视角一致**，像博物馆档案的同一件藏品。

**③ 场景**（多角度设定板）——骨架：主视角 / 反打 / 侧向 / 顶部平面；**画面里不出现人**。

**要点**：三类都要带**统一提质层**；**资产类省略运动句**；出图顺序 **场景 → 光源 → 道具 → 角色 → 照片**；
本例风格 **D06（描边系）**，三类都**不带器材句**。
⚠️ 多视图设定板**只作设计稿**；出片参考要用**大头照 + 全身照**（官方口径）。

## 样例三 · 分镜（一镜两个板块）

> 本例风格 **D06 美漫金铅时代（系二 · 描边系）**——下面两块都**不含器材句**。
> **写实系**的分镜要长什么样（风格编号 → 三问 → 器材包号），见**样例五**。

**板块一 · 单镜黑白故事板**（节选）

```
一张黑白故事板画格，横版16比9，纯灰度，全画面只有黑、白、灰三种明度，一个镜头，
不拼版（一张画布只此一格；一次出 N 张独立文件不算拼版）。

画面内容：中近景——画框上缘切在她头顶翘辫之上、画面下缘收进投币口下半截，
左右各留一段暗部；少女的侧脸占画面左三分之一，她微微低头，视线落在画面中央偏右的投币口上；
一只手从画面前方伸出，拇指与食指捏着一枚旧硬币；画面里只有她一个人。

明暗结构：主光从画面右后方来，亮部落在她的侧脸轮廓、鼻梁与手背的一侧；
投币口凹槽深处全黑；她的脸的另一侧沉进中间调偏暗；明暗交界是一条柔和的过渡带，不是硬边；光比大约七比一。

构图：她在左三分之一、侧脸朝右；手与硬币在中央偏右；右侧留一段暗部负空间。
画格左下角留一条空白标签条，条内不生成文字。
```

**★ 2026-10-02 关闭【待确认项】** 上面「明暗交界是一条柔和的过渡带，不是硬边」改自 `storyboard-frame.md`（故事板提示词块）——
黑白故事板画的是**明暗结构块面**，铅笔炭笔叠出的灰度，交界应是有过渡的块面，不是矢量硬边。
**裁定（本例 D06 描边系）**：**故事板不走硬边**——故事板画的是**明暗结构块面**；硬边只对下面板块二的**成片**生效。**不需再改**。
⚠️ 下面板块二（美漫描边**成片**）写「暗面直接沉进硬边色块」是风格需要，**不受这条约束**。

**板块二 · 视频提示词**（12 块，层序固定）

```
分镜头脚本，单人单镜，时长6秒，画幅16比9，美漫描边风格。
风格标签：废土黄昏 | 美漫描边卡通渲染 | 高饱和彩色 | 粗黑描边 | 无配乐。

【全片通用 · 后期特效】—— 每一镜逐字复用，不改字
大气透视：远处的废土残骸随距离逐步损失对比与饱和，越远越被压成冷紫灰蓝；
体积感：落日斜射的光柱里浮尘清晰可见，地面浮起一层薄沙雾；
高光滚降：平滑渐进出白、不裁成纯白，过曝处仍带暖沙色，高反差边缘只有极轻的橙红光晕；
调色方向：暖沙色与铁锈色为主色，天空与阴影推到冷紫灰蓝，这是一部彩色片，不是单色调；
颗粒：暗部成簇、中间调细，颗粒随画面一起运动。

【全片通用 · 统一提质层】—— 每一镜逐字复用，不改字
量级：美漫金铅时代描边系——粗黑描边勾住外轮廓，内部只分两三级色块，不做写实渲染；
痕迹：描边粗细随轮廓转折变化、转角处带笔压；色块边缘有极轻的套色错位；网点底纹铺在中间调上；
运动：全片只保留极轻微、如呼吸般的机位浮动，没有甩动、没有变焦；
禁用：照片写实，真实皮肤毛孔，光线追踪，8K堆砌，全画面过锐，塑料皮肤，美颜磨皮，青橙滤镜感，大平光，概念图。

【全片通用 · 风险移除 + 禁止出现】—— 每一镜逐字复用，不改字
她的手始终做简单动作、手指不做手势，两只手各有五指、指节不扭曲；
画面里的字迹很小很糊、不可读，需要真字时后期贴。
禁止出现：第二个人，倒影里的人影，背景路人，字幕，水印，文字伪影，现代物品，LED灯，
均匀明亮布光，完美对称布光，镜头抖动，随机变焦，多个镜头运动，口型开合，说话，音乐，人声。

────── 以上三块全片通用，每一镜逐字复用、不改字；以下为本镜专属 ──────

【本镜目的】实质推进动作：让「投币」这件事在画面上真正做完。

【镜头规格】中近景——画框上缘切在她头顶翘辫之上，画面下缘收进投币口的下半截，左右两侧各留一段暗部；
球面镜头，等效约50毫米，光圈f/2.8（背景压成两三级色块、不抢主体），
机位高度平视，观察视角斜后方45度，机位距她约1.2米。

【构图】三分法：她的侧脸占画面左三分之一，投币口占中央偏右；
投币口的金属边框形成一条垂直引导线，把视线从她的手引向投币口；
右侧留出暗部负空间，留给后面亮起的那一小点光；前景右下角允许一块锈蚀铁皮以虚焦状态入画一角；
她的侧脸占画面高度约三分之二。

【人物与环境】17岁废土拾荒少女，橙红色乱发在头顶扎成两个翘辫，护目镜推在额头上，
绿色的眼睛，脸颊一道旧疤，皮肤晒成麦色；灰色背心印着骷髅头图案，肩上一只边缘磨白的手缝护甲，
右臂缠着起毛边的红布，腰上挂着一把掉漆的旧扳手。
她站在投币口前微微低头，右手拇指与食指捏着一枚边缘磨圆的旧硬币，指腹贴在币面上。
此刻她的脸：眉舒展；眼睑开合、视线落在投币口上；嘴角抿平、下颌微微收紧；呼吸浅、重心压在右脚。
画面里只有她一个人，投币口的光滑铁皮上没有第二个人影；场景里是一台剥漆的自动维修站机身、地上一层浮沙。

【光位与影调】画面里只有一处光源：画面右后方低角度的落日，暖橙色，从斜后方来；
光先落在维修站的铁皮上，她只接到它的一部分；亮面落在她的侧脸轮廓、鼻梁与手背的一侧，
暗面直接沉进硬边色块，不放补光；曝光优先保住她的侧脸；光比大约七比一；光柱里的浮尘清晰可见。

【时间线】
起始：她停在投币口前，捏着硬币的手悬在画面中央偏右，视线落在投币口上；
主动作：她把硬币推进缝隙，指腹离开币面、硬币带着一点重量滑进去，光滑的铁皮上滑过一道细窄的反光；
反应与呼吸：她的肩落下半寸，微动节奏不均匀——快一下、停一下、再动；眼睑自然开合一次、间隔长短不一；
视线有一次小的游移再回到投币口；下颌松开，呼吸变浅；
定格：手收回画面右侧，投币口里亮起一小点光，画面停在这个状态——无对白、无爆发、无强光。

【摄影机】机位架在固定位置，只保留极轻微、如呼吸般的机位浮动；
全程锁死不动的是构图关系——她的侧脸始终在左三分之一、投币口始终在中央偏右；
全程不推、不拉、不摇、不移、不环绕、不变焦；焦点始终锁定她的侧脸，全程不重新对焦；
结尾落点：她的手停在画面右侧，投币口里那一小点光保持亮着。

【声音】无配乐，只保留现场音：风、沙粒摩擦铁皮、硬币与铁皮相碰的一声；
硬币那一声落在币滑进缝隙的瞬间；全程没有人声。

【进入下一镜的过渡压力】动作匹配切——下一镜从「手收回画面右侧」的途中接；
视线落点：本镜结尾观众的视线停在画面中央偏右那一小点光上，下一镜的核心信息点就放在那里；
声音桥：硬币的相碰声延续进下一镜，空间不变；景别落差：下一镜跳到大特写。
```

**要点**：两块分开给、各自可复制；**顺序是先故事板后视频提示词**，两者人物位置与构图必须一致；
⚠️ **黑白故事板不能直接当图生视频首帧**（会把整片锁成单色）——彩图要按板块二重新出。

**下面几句是说给你听的，不进提示词**（围栏块里只留提示词本身，块内每一个字都会被喂给模型）：

- **12 块 = 全片通用 3 块 + 本镜专属 9 块**，全片三块**前置**并标「每一镜逐字复用、不改字」——
  复制时只改后半段，前半段一个字都别动。
- 【人物表演】【物理反馈】【结尾留白】**是思考清单，不是写作块**（`block-playbook.md` 的 15 块是思考清单）：
  表演并进【人物与环境】的「此刻她的脸」与【时间线】的「反应与呼吸」；物理反馈并进【时间线】的「主动作」；
  结尾留白并进「定格」与【摄影机】的「结尾落点」。**别把它们拉回成块，但也别丢。**
- **时间线不写秒数**——首行那个 6 秒是平台硬约束，是唯一保留的秒数，时间由模型自己分配；
  单镜只写 `起始 / 主动作 / 反应与呼吸 / 定格` 四相；若是分段镜，段内推进写「他先…；随后…；最后…」，
  ⛔ 不写 `准备 / 接触 / 落定 / 触发`。
- **瑕疵要照着写进句子**（旧疤、护甲边缘磨白、红布起毛边、扳手掉漆），不要写「+ 瑕疵各 ≥2 处」——
  那是思考残留，进了围栏就成了给模型的指令。
- **景别由「画框装了什么」决定**：写「上缘切在哪、下缘收进什么」，不写这件事有多重要。

## 样例四 · 广告向 12 镜骨架（30 秒）

**适用**：品牌广告 / 产品短片 / 15–30 秒投放素材。**不是叙事片的骨架**——广告的骨架是"钩住 → 建立 → 证明 → 记住"。

| # | 秒数 | 职能 | 镜头内容 |
|---|---|---|---|
| 1 | 0–2 | **钩子** | 一个反常画面 / 一个疑问（不是 logo，不是产品全貌） |
| 2 | 2–4 | 建立场景 | 谁、在哪、什么时间（**wide establishing**） |
| 3 | 4–7 | 引入主体 | 产品 / 服务**第一次露面**，但是局部（手部 / 一角） |
| 4 | 7–10 | 痛点 | 没有它会怎样（具体到一个可见的麻烦） |
| 5 | 10–13 | 转折 | 一个动作改变状态（拿出 / 打开 / 触碰） |
| 6 | 13–16 | **证明 A** | 功能可见（过程，不是结论） |
| 7 | 16–19 | **证明 B** | 结果可见（变化前后同框或紧接） |
| 8 | 19–22 | 人的反应 | 表情 / 姿态——**这一镜是情感落点，不能省** |
| 9 | 22–24 | 使用场景扩展 | 换个环境，说明"不只在这里能用" |
| 10 | 24–26 | 品牌曝光 | logo / 包装，**给足停留**（≥2 秒，别一闪而过） |
| 11 | 26–28 | 一句话 Slogan | 画面文字（**后期覆盖，不靠 AI 渲**） |
| 12 | 28–30 | 收｜留白 | 产品与场景的静态收尾，**不堆音乐高潮** |

**三条纪律**：

1. **第 1 镜绝不放 logo**——钩子必须先于品牌。
2. **证明镜（6/7）必须"看见过程"**——直接给结论（产品摆着好看）在广告里等于没证明。
3. **第 10 镜给足 2 秒**——品牌曝光是广告唯一不能省的镜头；压缩到 0.5 秒等于白投。

**为什么这张表可以留「秒数」列、可以说「第 N 镜」**：它是**排镜表 / 分镜骨架，不是提示词**——
秒数只活在排镜表（`scripts/shotlist_lint.py` 认 `SH\d+` 与「镜\d+」两种载体，排镜表的节奏数学靠这一列）。
**把这张骨架落成提示词时**，编号载体换成「段落 / 组合」（段落A / 段落B），并且**不写秒数**。

## 样例五 · 写实系完整链路（风格编号 → 三问 → 器材包号）

> 上面四个样例都是**描边系，不写器材句**，所以看不到器材包是怎么选出来的。
> 写实系必须走完这条链——这里给一条从头到尾的，**五步不可跳**。

**① 选风格** → `B04 黑色电影`（`style-library-cinema.md`）→ **系一 · 写实系**

**② 走三问**（`camera-package-quickref.md` §一）

| 问 | 答案从哪取 | 本例 | 落到 |
|---|---|---|---|
| ① 故事什么年代 | 调性四元组（`shot-craft.md` 第二节） | 1940 年代 | **胶片档** |
| ② 光什么性质 | **读 B04 条目的「色彩光影」一行**——黑白、极端低照度 | 暗调硬光 | **P08 / P10 / P04** |
| ③ 机器谁拿着 | 叙事氛围：宿命、凝视 | 架在那 | 固定 + 机械片门晃动 |
