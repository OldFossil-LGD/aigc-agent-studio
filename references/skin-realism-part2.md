## 四、处方表：症状 → 根因 → 改哪句

**这张表是本文件的主产物**。拿到"像 AI"的图，从症状找根因，按"改哪句"改**那一句**（不改别的，守单变量纪律）。

| 症状 | 根因 | 改哪句 | 别做什么 |
|---|---|---|---|
| **全脸油亮、蜡像** | ①把皮肤当不透光材质（无 SSS）②训练数据精修偏置 | **加 SSS 证据句**（耳廓透红 / 暗部偏暖）；**删掉** `皮肤细腻` `有光泽` 这类词 | ✗ 只加"不要油亮"——否定句无效（E2 第③类） |
| **哑光但死板（石膏感）** | 只有表面那 6%，没有内部 94% | **补次表面散射**；**补暗部偏暖** | ✗ 继续加"哑光"——会越加越死 |
| **高光是一整片镜面** | 毛孔被 denoising trap 抹掉 → 高光无打断物 | **把毛孔写回来**（且按区域写：鼻翼清、颧骨淡）；**把光改成斜角** | ✗ 只写"高光小一点"——治表 |
| **高光位置乱** | 平光下菲涅尔反射被平摊到全脸 | **改光位为斜射 / 侧光**；写 `亮面在[哪半张脸]` | ✗ 写"高光在鼻尖"——模型在平光下不听 |
| **看不到毛孔（怎么调都没有）** | **正面平光是主因** | **换斜射侧光**（不是加词） | ✗ 反复加强 `毛孔清晰可见`——平光下无效 |
| **看不到绒毛 / 边缘发硬** | 无逆光，绒毛不可见 | **加侧逆光或逆光轮廓** | ✗ 写"有绒毛"但不给逆光 |
| **皱纹乱走 / 不存在** | 模型无解剖依据，给平均脸 | **按 §1.3 的肌肉映射写走向**（垂直该肌肉）；**先定年龄** | ✗ 写"三道皱纹"——数量无效，走向才有效 |
| **年轻人显老** | 写了静止状态的深纹 | **改成动态细纹**：`笑时眼尾才起`；写 40 岁后才允许静态重力纹 | ✗ 给 20 岁写法令纹 |
| **有纹但脸是平的（僵硬）** | 皱纹与表情脱钩 | **把皱纹挂到一个正在发生的表情上** | ✗ 单独列出纹路清单 |
| **轮廓像剪纸贴上去** | 无绒毛 + 无次表面散射边缘 | **同时补**：逆光绒毛 + 耳廓透红 | ✗ 只补一样 |
| **磨皮感、像塑料（但不油）** | **只有反射层、没有肌理层**（皮沟网缺） | 补**区域分布**句（沟纹走向跟部位）＋ **局部对比**句（疤面 / 鼻头 vs 周围）；**"少给东西"比"多给"容易** | ✗ 反复加强 `皮肤纹理清晰`——**1K 级接不住**（→ `skin-light-physics.md` §七 的三档） |
| **老人显年轻 / 年轻人显老** | **沟纹方向写反**——"变乱"与"变模糊"是**两个相反方向** | 中年起是**变乱**（胶原排列杂乱）；老年末是**变模糊**（皮肤萎缩）；光老化是**革质＋色斑** | ✗ 只加皱纹——**肌理是比皱纹更底层的一条轴** |
| **疤痕看不见 / 像贴上去** | 没写"疤痕没有附属器"这条因果 | 写 `疤面比周围更平滑、反光更亮，边界清楚，疤上不长毛孔`；**并先用"高度"（高出/平/凹陷）把型定死** | ✗ 只写颜色——**高度比颜色有效得多** |
| **皮肤比环境亮两档** | 默认美颜光，与场景光源脱节 | **回 `tone-realism.md` 人物光影块**：光只来自画面内光源 | ✗ 加"自然一点" |

## 四·补 ★ 皱纹的"静息—牵拉两态"（2026-09-17 立 · 用户看片后指出）

**用户原话**：「嘴边那两条斜的皱纹虽然真实人物也有，但**真实人物只有在一些情绪下才会特别明显**」。
**病根**：§1.3 已写明"模型没有解剖学依据，只能靠平均脸"——**它的训练数据里带表情的照片占多数，于是把"最深的那一帧"当成了"常态"**，
结果**鼻唇沟像刻上去的**（S5 不合格表现第 3 条："有纹但表情是平的"）。

**判据（照 S5 用）**：**找到脸上每一道纹，问它垂直于哪块肌肉？那肌肉现在在动吗？**

| 类型（§1.3 四分类） | 静息时 | 牵拉时 | 写法 |
|---|---|---|---|
| **动力性**（眉间纵纹 / 额横纹 / 鱼尾纹 / 下睑褶 / **鼻唇沟的加深部分**） | **退回成一道很浅的印** | 加深 | **必须绑成因动作**：眉间纵纹↔眉内端下压 · 额横纹↔抬眉 · 鱼尾纹↔眼轮匝肌 · 鼻唇沟↔上唇上提／嘴角斜下 |
| **重力性 · 综合性**（上睑细密纹 · 下睑半月弧 · 颈部横纹 · **鼻唇沟的浅底**） | **可常驻，但必须写"浅"** | 变化不大 | **不写"深"**；写"很浅的影 / 几乎看不出边界" |

**三条纪律**：① **写强度（浅 / 加深），不写"有皱纹"**；② **每道动力性纹都要写出它的"退回状态"**；③ **全片不许把任何一道纹写成恒定的深沟**。
**机器口径**：出现动力性纹名而全文没有"静息 / 只在…时 / 退回 / 很浅"等**静息态证据** → `audit_prompt.py blocks` 报 WARN。

## 五、验证规程（改动前先量，别改完再猜）

**用户要求"经过验证后再修改"——本节就是"验证"的操作定义。**

按 `prompt-ops.md` §七 迭代闭环，但**皮肤专项要加两条专属步骤**（上面 S1–S6 六条判据就是打分量表）。

### 5.1 对照实验（改任何皮肤句之前必做）

**单变量，一次只改一处**。三条线并行出，各 5 条：

| 组 | 提示词 | 验什么 |
|---|---|---|
| **A 基线** | 当前写法（原样） | —— |
| **B 只加 SSS** | A + 次表面散射句（耳廓透红 / 暗部偏暖） | 蜡像感是否消失 |
| **C 只换光位** | A 的**词不动**，光位改斜射侧光（其他全不动） | 毛孔是否显形 |

**★ 为什么要拆成 B 和 C**：**B 验的是"词"，C 验的是"光"**。这两件事常被混在一起改，改完不知道该归功于谁。**分开跑，才知道你这套模型是"缺词"还是"缺光"。**

**评测方法**：6 条各打分，按 §三 的 S1–S6 判据逐条勾。**只看比例不看单条**（单条可能是运气）。

**判定**：
- B 组 S1/S3 变好 → **SSS 句有效，留下**
- C 组 S1 变好 → **光位才是最有效杠杆，写词优先级下调**
- 两组都无变化 → **问题在别处**（可能是模型能力上限 / 分辨率不够 / 景别太远），**不要在皮肤词上继续花预算**

### 5.2 双向用例（防止"改好了这个坏了那个"）

每改一次皮肤写法，**必须同时准备两条用例**：

| 用例 | 内容 | 期望 |
|---|---|---|
| **守正** | 一个"本来就该有油光"的镜（运动后 / 夏天 / 近火） | **不能被压成石膏**——该油的地方要有油 |
| **守负** | 一个"该干净"的镜（病中 / 冬天 / 暗调特写） | **不能被写出油亮** |

**为什么必须双向**：单向往"哑光"调，**一定会把该有油光的场景也压死**——这是最常见的一类"修完更假"。**两条同时过，才算改对了。**

### 5.3 记录与沉淀

- 每次改动记一行（对照哪两组、哪条判据变了、变多少）
- 失败样本**归档原因**，加进用例集
- 若发现某条写法在**你的模型 / 平台**上无效 → 写进 `platform-matrix.md` 的平台差异，**不要当通用规则**

## 来源

**成因（去噪陷阱 / latent 压缩 / 训练偏置）**：对扩散模型训练目标的通行解释，经多源交叉核对——`denoising trap` 与 VAE 8× 压缩下"单毛孔 ≈ 1–3 latent 像素"的表述来自 AI 肖像工作流的公开技术分析（bestprompt / imagera / looktara / sozee 等平台的公开方法论文章，**均只提炼机制、未复制文本**）；`像素级 L1/L2 损失倾向过平滑` 为深度学习通行结论（最小化像素平均差 → 推向统计均值 → 模糊与蜡感）。

**皮肤光学（SSS / 菲涅尔 / 分区）**：**6% 表面直接反射 / 94% 次表面散射**与"红通道散射最远"引自 **Chaos V-Ray《Subsurface scattering explained》** 与 **Wikipedia「Subsurface scattering」**（后者明确"红散射最广、绿次之、蓝极少"）；波长依赖与"skin mode 用更宽的红通道模糊核"引自 **Godot 4.5 官方材质文档说明**；**皮肤 IOR ≈ 1.38–1.45**、粗糙度分区（T 区更低）、各向异性引自 **Renderbus 瑞云渲染公开技术文章**；**T 区皮脂腺 800–900/cm²、面颊 500–700/cm²** 与"眼周颧骨内侧最少"引自公开皮肤科科普（经专家审阅）；**正向散射各向异性因子 g ≈ 0.9** 引自 **Hailuo 官方 SSS 指南**（其转引生物光子学的人体皮肤模型研究）。**"SSS 在平光下不可见、必须逆光或侧光"** 为上述多源的共同结论。**【口径提示】**本处的「T 区 800–900 / 面颊 500–700」是**皮脂腺绝对密度**（约 1.5 倍）；另一册 `skin-light-physics.md` §4.1 的「T 区是 U 区的 4–5 倍」是**相对倍数**，两者**不是同一量，不要互相推算**。**【待确认项】**两源口径不一，回一手源核实前先按「量级与量级关系」使用，不取单一数值当唯一答案。

**绒毛（vellus hair）与"人体 vs 蜡像"判据**：**LeGendre / Huynh / Wang / Debevec《Modeling Vellus Facial Hair from Asperity Scattering Silhouettes》（SIGGRAPH 2017，USC ICT）**——逆光下沿轮廓的 asperity scattering 是建模依据；"摄影中侧光 / 逆光才使绒毛可见"引自摄影与 3D 艺术的公开通行说明。**注意：本库只取"绒毛在逆光下可见、是区分活体与蜡像的关键"这一结论，未复制该论文的方法与数据。**

**皱纹解剖（本库此前零覆盖）**：**面部皱纹四分类**（直立性 / 动力性 / 重力性 / 综合性）与**各肌群对应的位置走向**、**"皱纹与肌收缩方向呈直角交叉"**、**出现年龄分期**（额纹起于青春、鱼尾纹 20 岁后、口周纹约 50 岁、重力性 40 岁后明显）——引自公开医学资料（**中国医药信息查询平台**经国家中医药管理局名词术语成果转化与规范推广项目审核的「皱纹」词条 · **面部老化**词条 · 《**美容局部解剖学**》与《**口腔颌面外科学**》的公开章节：朗格皮肤裂线走行、皱纹三类分法、"皱纹与其下肌肉收缩方向呈直角交叉"）。**三个例外部位**（眉间垂直 vs Langer 水平 / 下唇水平 vs Langer 垂直 / 外眦扇形 vs Langer 斜行）引自**口腔颌面外科学**公开章节，与 **DermNet《Skin tension lines》**（Langer 1861；Langer 线取自尸体、与活体 relaxed skin tension lines 在面部常呈直角）**互相印证**。
