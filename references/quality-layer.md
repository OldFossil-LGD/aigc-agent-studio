# 统一提质层（一切提示词的公共层 · 必带）

> **何时读**：交付任何类型提示词之前（每次必读）。**读完回哪**：回到 `SKILL.md` 交付规范。

> 目的：让**角色 / 道具 / 场景 / 镜头 / 批量任务**五类提示词共享同一套光度量级与质感行为。
> 以前只有镜头提示词带这套标准，导致资产图是人像棚拍味、镜头图是概念图滤镜味，合成时人物像贴上去的。
> **现在统一：任何含视觉成像的提示词交付，都要带本层（纯音频 / 纯文本类提示词不带）。**

## 一、为什么要统一（三件必须一致的事）

| 一致项 | 不一致的后果 |
|---|---|
| **同一套光度量级**（同一支摄影机 + 同一张印片） | 资产图与镜头图色温、对比、肤色不在一个世界 |
| **同一套高光与颗粒行为**（滚降 + 有机颗粒簇） | 有的图锐利干净、有的图脏，接在一起跳 |
| **同一套光的来源逻辑**（光有出处、曝光保脸） | 人物比环境亮两挡，像贴上去的 |

## 二、统一提质层（逐字复用块 · 镜头类完整版）

> **先选量级族**：本节的块是**写实族**（摄影机 + 镜头 + 印片）。若整片是**美漫描边 / 赛璐璐 / 卡通渲染**风格，换用 `stylized-look.md` 第二节的**描边族**量级句——**三族（写实 / 描边 / 工艺渲染）不能混用**，一部片只选一族（写实族禁"动漫/卡通"，描边族必须是卡通渲染，禁用词正好相反）。
> **★ 术语（2026-09-15 单轨化）**：**「描边族」＝ `style-library.md` §二的系二**（美漫描边 / 赛璐璐 / 卡通渲染）。**它不是"风格化的全部"**——**系三 工艺渲染族是第三套**（前两套都对它停用）。旧稿曾把这一族叫"风格化族"，**已全库改名，不再保留那个叫法**。

> **★ 写实族必须先选「拍摄方案包」**（2026-09-12 补）：下一个块的摄影与印片**不是写死的**——它要去 `camera-package-library.md` 的 **17 个主包**（P01 手机 … P17 虚拟制片）或 `package-extended.md` 的 **17 个补充包**（P18–P34 等 17 个：航拍 / FPV / 微距 / 鱼眼 / 移轴 / 宝丽来 / 红外 / 热成像 / 夜视 / 录屏 / 卫星 / 内窥 / CGI / AI 原生 / 延时——括注非穷举，完整清单见 `package-extended.md`）里选一个，把该包的**器材 / 痕迹 / 运动三行逐字粘进来**；**也允许跨包组合**（`equipment-selection.md` §三）。
> ⚠️ **选包链（五站，别跳；包本体一站含主包库与扩展包两文件）**：`equipment-selection.md`（六轴正交 · 怎么选）→ `style-package-matching.md`（族级判据与禁忌）→ **`camera-package-quickref.md`（速查；★ §三 三个可直接复制的成套句）**→ `camera-package-library.md` / `package-extended.md`（包本体）→ **`film-stock-matching.md`（取哪一档：片 / 印片 / 调制层）**。（2026-09-17 同步另一任务改动）
> **为什么**：以前这个位置写死了 `ALEXA 35 + Cooke S4/i + 2383`，结果 113 个风格、所有项目，器材观感全是一个样——**这是"不够真实、AI 味重"最直接的一个来源**。
> **纪律**：一片一包；**资产图与镜头图必须同一包**；痕迹至少写三项；**描边族与工艺渲染族不用任何包**（见 `style-library.md` §二）。**★ 例外与分层**：**G01／G15／G02／G03／G08／D20** 属"跨世界"条目——**每段／每画幅／每一层各自一包**，不是违反纪律（准入条件 → `stylized-look.md` §二·补2 四条件 · 族级落点 → `style-package-matching.md` §1 族⑭）。
> 拿不准选哪个 → 先按题材反查：纪实 `P07`、当代随手 `P01`、千禧回忆 `P02`、恐怖 `P04`、年代文艺 `P08`、史诗 `P09`、都市夜与科幻 `P14`。

**每镜（镜头类）提示词必带全块；资产类按第三节的适配表省略运动行**（`[ ]` 只替换本片与本镜专属内容）：

```
【统一提质层】
摄影与印片：[本片方案包 —— 把 camera-package-library.md 选定包的「器材」行逐字粘在这里]
全片只用这一包，不叠加其他器材、胶片或画幅体系。
光有出处：画面里只有一到两个有动机的光源（屏幕、台灯、窗、火、街灯），
光先落在环境上，人物只是接受它的一部分；曝光优先保护面部，
脸的另一侧不放任何补光，直接沉进背景的黑暗里。
痕迹：[把所选包的「痕迹」行逐字粘在这里 —— 至少三项]。
写实档的通用底线：高光平滑滚降、渐进出白，不裁成纯白，过曝处仍带暖色；
颗粒随曝光变化（暗部粗、中间调细），不是均匀叠加的数码噪点。
运动：[把所选包的「运动」行逐字粘在这里；底线是画面带轻微的机械片门晃动与手持呼吸，
从不完全静止，也绝不云台般稳定]。
禁用：漫剧感，概念图，全画面过锐，硬截断高光，高光裁成纯白，高饱和，
青橙滤镜感，大平光，完美三点光，处处补光，美颜磨皮，塑料皮肤，8K堆砌，光线追踪。
```

> **上面这个块里的 `[ ]` 是本片级替换**——它们在**整部片里保持同一个值**（一个包、一套痕迹），只有【风险移除】那块才逐镜替换。

**★★ 但"本片级不变"不等于"所有片都一样"**（2026-09-15 补 · 实案）：**包定下来之后，还有三样必须按"风格与题材"再调一次档**——**只把包的三行逐字粘进来是不够的**（那是"包的通用值"，不是"这一部片的档"）：

| 要调档的 | 去哪调 | 判据（一句话） |
|---|---|---|
| **胶片型号** | `cinematic-look.md` §三 胶片表的「用途」列 | **光的色温先定片**：日光戏用 **日光平衡（250D）**、钨丝夜戏用 **钨丝平衡（500T）**；**戏越亮、颗粒越要细**（高调日戏拿 500T 会脏） |
| **印片** | `cinematic-look.md` §四 印片表 | **要"怀旧浓郁"用 2383（对比高、暗部带青蓝）；不要怀旧味、要低对比柔高光用 2393** |
| **调制层** | `camera-package-library.md` §四（漫射白/黑 · 漂白 · 颗粒档 · 升降格） | **风格偏"柔/暖/怀旧"叠漫射白；偏"冷/硬/夜"叠漫射黑；题材极端叠漂白** |

**判据一句话**：**包的「运动」行基本可以直接用；「器材」行要按"年代 + 光源色温 + 明暗调性"换片换印片；「痕迹」行要按"风格要不要光晕、暗部偏暖还是偏冷"改写这几项。**
> **★ 这三样的具体档位表（九种片 × 两种印片 × 四个调制层 × **十四风格族**）→ `film-stock-matching.md`**——**包按"机制"划，档按"味道"分；要加的是档，不是包。**
**反例（本库实案）**：给一场**雪地反射的日光高调戏**配 `VISION3 500T（钨丝平衡）+ 柯达 2383 印片`——**两个都不对**：钨丝片在日光下要加校正片才正常，而 2383 的"对比高、暗部带青蓝"正与"低对比、几乎单色"打架。**换 250D + 2393 才是这一部片的档。**
→ **这就是"提质层看着没变"的根因**：三行是逐字复用的，**但"用哪一档"是本片级的判断**——**它随风格与题材走，不随镜头走。**
> 若题材是广告、动作、科幻这类"干净也行"的片种，也别偷懒用默认包——**干净不等于用同一台机器**：`P13` 干净、`P14` 也干净，但一个是平面、一个是变形。**在干净的包里换一个，观感立刻分开。**

【风险移除】不是禁止项，是**正文里的正面写法**（见第四节第 1 条）：

```
【风险移除】手部动作简单、不做手势，手始终落在[桌面/道具/键盘]上；
画面里的文字很小很糊、不可读，需要真字时后期贴。
```

## 二·补 ★ 提质层的三个混淆与一条禁令（2026-09-17 立 · 用户追问"提质层真的是电影感的真实吗"）

**结论先说**：**现在的提质层既不是"电影感"，也不全是"真实"——它把三样东西混装，其中两样不该在这里。**

| # | 混淆 | 事实 | 怎么改 |
|---|---|---|---|
| **①** | **型号 ＝ 电影感？** | **不是。** 型号只是**风格锚点**（触发训练数据里的印象），模型**不懂**它的宽容度曲线；**真正生效的是"译成效果"那句**。判据＝**把型号全部划掉，剩下那句还能不能说清"这部片看着像什么"** | **型号 ≤1 个，后面必须跟效果**；**括号里放效果、不放编号**（`Kodak VISION3 500T（5219）` 是反例） |
| **②** | **真实层 ＝ 成像层？** | **不是，两层目标不同。** **真实层＝材质/皮肤/接触阴影/物理行为**（**本镜级**——它随光位与本镜条件变，**所以归【光位与影调】与【人物与环境】**）；**成像层＝曝光/色彩/颗粒/光学/印片**（**全片级**——**所以归提质层**） | **皮肤句不许写进提质层**；**材质与接触阴影不许只在提质层出现** |
| **③** | **成像痕迹 ＝ 画面瑕疵？** | **不是，两类不共用一个额度。** **成像痕迹**（颗粒成簇/高光滚降/眩光/色散/片门晃动）是**全片级成像特征，库里要求至少三项**；**画面瑕疵**（污渍/掉漆/油光不均）是**画面内容，受 C22"只给一到两处"约束** | **别把成像痕迹当"瑕疵"去限数量**——限错了会把成像特征砍掉，画面反而变"干净得假" |

**★ 一条禁令（最要紧的一条）**：**跨作品不许复用同一套器材。**
> 库里已记录过这个坑（§二："以前写死了 ALEXA 35 + Cooke S4/i + 2383，结果 **113 个风格、所有项目，器材观感全是一个样——这是"不够真实、AI 味重"最直接的一个来源**"）。
> **纪律**：**每次开新片／新风格，必须重走选包链**（`equipment-selection.md` 六轴 → `camera-package-quickref.md` 三问／**§三 成套句可直接复制**），**把该包的三行逐字粘进来**；**胶片与印片档位去 `film-stock-matching.md` 取**；**同一个人连着做三条片，三条应该像三个不同摄影师拍的。**
> **自查**：**把最近三份稿子的"器材行"并排看**——如果一模一样，就是这条禁令被破了。

## 三、五类提示词的适配表（谁带哪几行；**逐块该想什么 → `block-playbook-asset.md`**）

| 类型 | 带哪些行 | 替换与省略 |
|---|---|---|
| **镜头提示词** | 全带（含运动句） | — |
| **角色设定板** | 方案包（器材 + 痕迹）+ 皮肤哑光句 | 光改为**资产中性光**（柔和顶中性光加暖边缘光），不用场景光；**省略运动句**；场景光版本只用于"首帧版"。**痕迹行要保留**，否则人像与镜头的观感对不上 |
| **道具设定图** | 方案包（器材 + 痕迹）+ 逐处写脏 + 接触阴影 | **省略运动句与皮肤句**；布光为摄影棚暗调（单一顶光加一侧柔光 + 深灰褐渐变背景） |
| **场景设定图** | 方案包（器材 + 痕迹）+ 光池衰减与死黑比例 | **省略运动句**；光按该空间的光源逻辑写，资产图里不出现人 |
| **批量任务文本** | 进【共享风格锚点】 | 共享锚点只放**方案包 + 中性光**（同包同痕迹，全批不许改）；运动句与人物光影块由各条各自带 |

## 四、两处必须一起改掉的旧写法（不改则前功尽弃）

### 1. 禁止项要**分三类**处理（2026-09-11 更正：补上"内容类别否定"这一类）

**这三类规则方向不同，混着用必犯错。**

#### 1·上游判据：一条否定句到底能不能写？（先过这条，再分下面三类）

平台自己的两份官方材料互相打架——一份说"绝不写否定"（`he's not crying` 会被读成 `crying`），
另一份（Prompt Bank）每条运镜都带一串排除。**别二选一，用这条判定规则把它们分开**：

> **被否定的那个概念，在提示词里是否已经有肯定替代项？**
>
> - **有替代项 → 排除句是"消歧"，安全。**（同族动作排除、参考范围声明属此类——"无摇移"的替代项是已写明的"推进"）
> - **没有替代项 → 它就是该概念的唯一来源，会被当成正提示。**（画面瑕疵、情绪、复杂状态属此类——必须改成肯定状态句或风险移除句）

这条规则比"按瑕疵 / 动作分桶"更上游，遇到新情况（如"不要屑他的脸转开"这类参考范围否定）也能归类。

#### 1a. 画面瑕疵 → 用**正面状态句**取代否定（这一类确实不能写否定）

**不要写否定句**——"不要多余的手指"反而会把手指注进引导。改为在正文里**移除风险**：

| ❌ 旧写法（禁止项） | ✅ 新写法（正文里的风险移除句） |
|---|---|
| 六根手指，融合的手指，畸形关节，悬空的手 | 他的手始终平放在桌面上，动作简单，不做手势 |
| 不要出现可读文字 | 画面里的文字很小很糊、不可读，真字后期贴 |
| 不要让第二个杯子出现 | 画面里只有这一只杯子 |
| 不要模糊 / no blur | **焦点咬住、纹理锐利**（英文原句：`tack sharp`） |
| 不要有人 / no people | **空无一人的荒野**（英文原句：`uninhabited landscape`） |
| 不要抖动 | **机位稳、只有极轻的呼吸浮动** |
| 不要过曝 | **高光平滑滚降、渐进到白，过曝处仍带暖色** |

**为什么必须改**（两条硬理由）：
① 实测：写下"不要六根手指"反而把手指数了进去。
② **在没有独立负向字段的平台上（字段有无按第四节 3 的路由表判断）**——所以"用否定句来排除"在机制上就不成立；只能靠"正面写清应该是什么"。

**注意区分**：脚本会标出块内的"不要/没有"，但**现象清单不算否定式动作句**——
`禁止出现：面部扭曲，多余手指，水印` 是**名词清单**（放负向字段用的），不是要改的对象；
`不要出现可读文字` 才是**命令式否定**，必须改。

禁止项里**删掉**手指/文字的否定词条，其他一致性条目（人数、换脸、左右翻转）保留。

#### 1b. ★ 同族动作 → **必须**写排除（这一类不写，模型就会在族内乱挑）

**这是 1a 的例外，而且方向相反。** 官方 Academy Prompt Bank 的**每一条**运镜提示词都带一串**同族动作排除**。原文样例：

```
no sideways travel, no dolly, no truck, no arc, no slide, no zoom, no tilt
```

**理由**：你写"缓慢推进"，模型把你没提的**同族动作**（拉、摇、移、环绕、变焦）当作可选项，于是镜头在族内摇摆、或混用两个动作。**列出同族并逐一排除，等于把动作锁定成唯一解。**

**判据（一句话）**：
> **瑕疵用正面句（1a），动作歧义用排除句（1b），内容类别改成"该拍什么"（1c）。**
> 1a 的毛病是"注入了不要的东西"；1b 的毛病是"没锁死，它自己挑一个"；1c 的毛病是"只拒绝类别、没给摄影机活儿干"。

官方口径也自洽：`write-a-good-prompt` 说"说你要什么"，同时明确承认 **"少量定向否定（no readable text / no plastic skin）在细节镜上有帮助"**——1b 就是那条被认可的例外。

**落地写法**（以推镜为例）：

```
摄影机：以每秒约0.08米直线缓慢推进共0.4米，全程无侧移、无拉出、无摇、无移、无环绕、无变焦、无俯仰，
稳定器跟随但保留极轻的人体呼吸浮动。
```

**执行顺序上有个坑**：脚本 `blocks` 子命令会把块内的"无/不要/没有"一律标 WARN。**1b 是故意的，属预期告警**，人工判读时按本节区分。

#### 1c. 内容类别否定 → 换成"该拍什么"（这一类最隐蔽，纯消耗）

"不要 CGI 感 / 不要像游戏 / 不要廉价特效 / 不要轻飘飘"——**反复写无效**，因为它**只拒绝一个类别、没告诉摄影机该拍什么**。

换成"这一镜该被拍到的东西"：

| ❌ 无效 | ✅ 替换成 |
|---|---|
| 不要像游戏 | **机位在哪、这一镜为何存在**（写清信息职能） |
| 不要廉价特效 | **该看到什么质感、什么碎屑、什么接触** |
| 不要轻飘飘 | **击中后什么弯了 / 停了 / 回弹了 / 飞出去了** |

> ⚠️ **这三类并存，各管一段，不要互相吞并**：
> **1a 瑕疵否定 → 改肯定状态句；1b 同族动作排除 → 必须写（消歧）；1c 内容类别否定 → 换成"该拍什么"。**
>
> 官方技术块里仍保留 `NO CGI. NON-IP.` 这类**风格与合规限定**——它们是限定句而非类别否定，不在此列。

### 2. 光度量级只写一套 —— 更上游的说法是「**一个画面只讲一个拍摄故事**」

一条提示词里**不能同时出现两套以上体系**——那会让模型的色彩与光学处理混成一锅，出来就是 AI 感。

| ❌ 堆砌（实测踩坑） | ✅ 收敛（一句话说完就收手） |
|---|---|
| 16毫米纪录片摄影机 + 柯达 VISION3 500T + 变形宽银幕 40mm | 用**本片方案包**那一套，一句话说完就收手（例 P13：`用 ARRI ALEXA 35 配 Cooke S4/i 拍摄，柯达 2383 印片收尾`） |

要换质感风格就**整片换一套**（例：纪实向换 Fujifilm ETERNA；年代回忆换 Kodachrome 40），不在同一部片里混。

**而且"两套体系"不只指器材。三条轴线任一条打架，都会自相矛盾**：

| 轴线 | 典型的自相矛盾写法 |
|---|---|
| **载体** | `手机随手拍的偷拍感` **＋** `电影级影棚主光、精修人像` |
| **光质** | `硬直闪的闪光灯正面光` **＋** `柔和的黄昏漫射光` |
| **清晰度** | `运动模糊、晃动的抓拍` **＋** `每一处都极度锐利、毛孔纤毫毕现` |

**判据一句话**：把提示词读一遍，问"**这是谁拍的、拿什么拍的、在什么条件下拍的**"——能答出**唯一一个答案**才合格。
想要另一种观感，**出多条独立版本**，不要把它们塞进同一条。

> 上面三轴是最容易打架的三条；**完整的是六轴**（载体 / 画幅 / 光质 / 清晰度 / 稳定度 / 色彩工程），见 `camera-package-library.md` §一。**六轴一次选定、整片不换**——这就是"方案包"。
> 这条与"写实向优先选手持/直播档"（→ `tone-realism.md` 第六层）是一对：**先选定一个拍摄故事，再把它讲到底**。

### 3. 禁止项按平台路由（同一句"禁止"，不同平台效果完全不同）

| 平台类型 | 怎么给禁止项 |
|---|---|
| **有独立负向字段**（Seedance / 即梦系、Kling、Veo、Hailuo、Wan、Pika 2.5） | 把规范预置**放进那个字段**；字段里只放**纯名词短语**（逗号分隔），**不要写"不要…/别…"的命令句**（Veo 与 Kling 会直接拒绝这类措辞） |
| **没有负向字段**（Sora、Runway Gen-4） | 折进**正向**描述里，写成显式的一行：`只保留原创角色，无标志、无字幕、无变形几何` |
| **Runway 特别注意** | 它对 `no X` 的措辞反应最差——**`no X` 可能把 X 召唤出来**。Runway 上只描述"应当出现的内容" |

规范负向预置（纯名词，可直接放负向字段）：

```
模糊，低分辨率，柔焦，水印，字幕，标志，面部扭曲，双眼不对称，多余手指，
畸形的手，融化变形的几何体，过饱和，塑料皮肤，光滑 CG 渲染感，游戏画面感，
3D 卡通感，动漫着色，扁平均匀的影棚光，完美无瑕的表面，画面闪烁，拖影，
生硬的硬切，死板的锁死机位
```

### 4. 不要写 IP 名（Seedance / 即梦系过滤最激进）

**具体作品名、角色名、演员名、游戏名，一律不写进要交给模型的提示词**——Seedance 系过滤很激进，
**一个被标记的词可能让整条提示词被拒**。

- ✅ 改写：`参考钢铁侠` → `原子朋克复古未来主义的红金配色战斗服`
- ✅ 改写：`像《铁西区》的光` → `工业纪实的灰绿色调，脏、低饱和、现场光`
- `tone-realism.md` / `cinematic-look.md` 里的**影片锚点表是给创作者看的内部参考**，
  **写进提示词之前必须先翻译成风格描述**。
