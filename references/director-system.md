# 导演体系化维度（读一位导演的六把尺子）

> **何时读**：选导演风格之前、或写完风格声明想补全时。**读完回哪**：回 `style-library-cinema.md` / `style-library-cinema-part2.md` / `style-library-cinema-part3.md` / `style-library-cinema-part4.md` 对应条目。
>
> **为什么需要**：现有导演条目给的是「核心视觉 / 色彩光影 / 构图材质」——**只覆盖了六个维度里的两个**。
> 结果：**风格"看起来像了"，但片子还是不对**——因为**节奏、声音、调度、母题**没跟上。
> "像某导演"从来不是画面对，是**六把尺子同时对**。

---

## 一、六把尺子（读导演的完整坐标系）

| # | 维度 | 具体问什么 | 落到提示词/分镜的哪一段 |
|---|---|---|---|
| **1** | **摄影** | 景别偏好？机位高低？画幅？明暗结构？调色冷还是暖？ | 人物环境段 + 光位影调段 |
| **2** | **剪辑节奏** | 平均镜头多长？快切还是长镜？切点落在哪？ | **镜头的时长与分镜数量**（容易被忽略！） |
| **3** | **声音观** | 音乐是画内还是画外？有没有旁白？对白是重叠还是留白？要不要**故意让声音与画面错位**？ | 声音行 + 结尾留白 |
| **4** | **场面调度** | 演员怎么占空间？是走位还是静止？群戏怎么摆？ | 人物位置与走位 → **方法本体见 `staging-craft.md`**（四变量 / 陪体五法 / 群像场型 / AIGC 降级顺序） |
| **5** | **表演指导** | 表演是外部行为还是内部情绪？克制还是外放？要不要"没演完"？ | 【人物表演】段 |
| **6** | **母题与原型** | 反复出现什么物件/意象/色彩？（水、镜子、时钟、食物）角色是哪种原型？ | 贯穿全片的一致性锚点 |

> **判据**：写完一位导演的风格，回问**"这六把我答了几把？"**
> **只答第 1 把 = 贴了滤镜**（本库既有纪律已警示过）；**答到 4–6 把才算"体系"**。

---

## 二、★ 最常被漏掉的是第 2 把：剪辑节奏

**风格不只写在画面里，也写在"一场戏有几个镜头、每镜多长"里。**

| 导演类型 | 镜头长度倾向 | 分镜策略 |
|---|---|---|
| **长镜派**（塔可夫斯基 / 阿彼察邦 / 侯孝贤 / 沟口 / 小津） | 一镜几十秒到几分钟 | **分镜要少**；一个动作不切；靠**时间本身**制造压力 |
| **快切派**（芬奇 / 苏联蒙太奇 / 今敏 / 盖·里奇） | 半秒到两三秒 | **分镜要多、要碎**；靠**节奏**制造压力 |
| **段落派**（王家卫 / 诺兰 / PTA） | 中等长度但**段落式组接** | 按**段落**而非单镜设计；段落内可长、段落间硬跳 |
| **一镜到底派**（冈萨雷斯·伊纳里图 / 门德斯） | 全片一个镜 | **分镜表就是调度表**；不写"切" |

> **纪律**：**写风格声明时，必须同时写"这一场大概几个镜头、每镜多长"。**
> 只写画面不写节奏 → 出来是"同一套画风的短视频"，不是这位导演。

---

## 三、第 3 把：声音观（本库已有 `sound-craft.md` 管"怎么录"，这里管"这位导演怎么听"）

| 声音策略 | 说明 | 代表倾向 |
|---|---|---|
| **旁白主导** | 人物对自己说话，台词不是给对面的人听的 | 王家卫式、黑色电影 |
| **画外音先行** | **声音比画面早到**（先说，后切到） | 悬念与预感 |
| **声音错位** | 画面安静但声音很满，或反之；**故意不同步** | 心理状态转变 |
| **环境声为主** | 几乎没有配乐，靠风、雨、脚步、机器声 | 纪实向、阿彼察邦 |
| **音乐母题** | 一首曲子反复出现，成为某个角色的"代表" | 王家卫式 |
| **静默** | 关键处**抽掉所有声音** | 冲击、失神、耳鸣 |

> **与既有纪律的接口**：本库已定"**结尾留白**"与"声音行"是每镜必备；本篇补的是**风格层面的声音选择**。

## 四、第 5 把：表演指导（与 `performance-craft.md` 对接）

| 表演倾向 | 怎么写 |
|---|---|
| **克制 / 内部** | 情绪全压在身体里；**只有手或下颌出卖他**；说话平、不动脸 |
| **外放 / 剧场** | 表情外显、动作大、**占满画面** |
| **未完成** | 动作**没做完**就切走；情绪**没到顶**就断 |
| **不整齐** | 反应有延迟、句子中间有停顿、动作有修正（见 E15） |

> **同一句台词在两位导演手里是两种拍法**：一位要"说完才切"，一位要"说到一半就切"。
> **所以风格声明里要写"切在哪"**——这是表演与剪辑的交叉点。

---

## 五、第 6 把：母题与原型（让全片"是一个人的作品"）

**母题是跨镜一致性的精神版锚点**：一个反复出现的物件或意象，会让观众潜意识觉得"这是同一部片"。

| 母题类型 | 例子 | 落地做法 |
|---|---|---|
| **物件母题** | 一只杯子、一台机器、一个时钟 | 写进 `asset-consistency.md` 的**子地标**，单独出资产 |
| **意象母题** | 水、镜子、雾、霓虹、食物 | 在风格声明里写"每场戏至少出现一次" |
| **色彩母题** | 某个只属于一部片的色 | 进**一致性锚点**，全片不许变 |
| **角色原型** | 反英雄、沉默的旁观者、被环境碾过的人 | 进角色主档案（`character-depth.md`） |

> **判据**：**把全片的镜头打乱顺序看，还能认出是同一部片吗？** 能 → 母题在起作用。

## 六、怎么用：写风格声明的六行模板

```
1 摄影：<景别与机位倾向> · <画幅> · <明暗结构> · <调色>
2 节奏：本场约 <N> 个镜头，<长镜/快切/段落>；切点落在 <哪里>（**秒数不写进提示词，由模型自己分配**）
3 声音：<旁白/环境声/音乐母题/静默>；关键处 <留白或错位>
4 调度：演员 <走位/静止>；群戏 <怎么摆>
5 表演：<克制/外放>；动作 <做完/未做完>；情绪 <到顶/截断>
6 母题：<反复出现的物件或意象>；每场至少一次
```

> **注意**：**这六行是给分镜用的"导演说明书"，不是交给模型的提示词**——不要整段粘进提示词。
> 它可以放**块外**或作为你自己的规划；最终提示词仍按 `quality-layer.md` 的两板块格式。

## 来源与署名

- **六把尺子框架为本库自建**（摄影 / 剪辑节奏 / 声音观 / 场面调度 / 表演指导 / 母题与原型），Fiveable《Analyzing directorial style and recurring themes》公开课讲义仅作启发，要点重写。
- **剪辑四维（图形 / 节奏 / 空间 / 时间）与"声音的可调维度（节奏 / 保真度 / 空间 / 时间）"**：Bordwell & Thompson 的剪辑与声音理论（经公开论文转引），本库整理为**可写的选择表**。
- **"声音与画面错位代表心理状态转变""旁白代替反应镜头""音乐母题代表某个角色"**：香港浸会大学公开学位论文《Modernist aesthetics in the films of Wong Kar-wai》中的分析（要点重写，未复制原文）。
- **六行风格声明模板、"只答第 1 把 = 贴了滤镜"判据、与既有文件的分工表**：本库自建。
