## 五、三个可直接复制的句式（跨片通用，来自公开实战写法）

### 1. 参考素材的「只取风格、不取内容」逐字前缀

带参考图做风格迁移时，**逐字粘贴这一句**放在指令最前（比"inherit 风格 exclude 内容"这种抽象说法有效得多，而且它明确承认"多张图就混"）：

```
只取输入图像的视觉渲染风格与调色（有多张图时把它们的风格混合）；
不要使用输入图像中的角色、文字、标志或物体，除非下面的指令明确要求。
只使用它的渲染风格，然后按用户的指令执行：
```

判准一句话：**把参考图只当"风格捐赠者"，绝不复制其中的人、文字、logo 或物体。**

### 2. 描边族的 STYLE 串固定结尾

整片走风格化（美漫描边 / 赛璐璐 / 卡通渲染）时，**风格描述写一次，然后逐字粘进每一镜**，并**以此串结尾**（防止模型滑回照片写实）：

```
非照片写实，手绘插画感，不是照片，不是实拍，不要真实感
```

> 此串属**有肯定替代（"手绘插画感"）的消歧否定**，符合第四节 1 上游判据，**不适用 1a 的"禁否定"规则**——别把它删成只剩正面词，那会松掉风格锚。

风格串本身要**逗号分隔、每一项一个决策**，不堆形容词。例：

```
平涂二维矢量动画，粗而干净的外轮廓线，纯色实心平涂不渐变，
无阴影层次，无渐变过渡
```

### 3. 视频段五行模板（风格化 / 解说类可直接套）

一行一个决策，没有一句废话；**STYLE 那一行逐字重复，别改**：

```
【第 N 段】
风格参考：严格匹配所附参考图，精确复刻它的观感：[STYLE 串 逐字重复]。
        下面每一个元素都用完全相同的风格渲染。
景：  [场景 + 一个清晰动作]
动：  [运镜与动画行为——缓推 / 漂移 / 尺度冲击 / 硬对比切换]
声：  [只留环境音效或音乐——没有人声、对白、旁白]
负向：[色彩漂移，照片写实，3D 渲染，口型，字幕，画面文字，标志，水印]
```

三条配套纪律：① **同一份 STYLE 串粘进每一镜**；② **画内音频只有同期声**，角色不说话、不做口型；③ **一镜只给一个清晰动作**。

## 六、自检六问（任何提示词交付前过一遍）

0. **「这是谁拍的、拿什么拍的、在什么条件下拍的」能答出唯一一个答案吗？**——答不出就是没选方案包，模型会替你挑一个最省事、最上镜的。见 `camera-package-library.md` §一。
   - **0a.** **本片档落了吗**（片/印片/调制层按题材再调一次 → `film-stock-matching.md`）；**0b.** **有专名吗**（作品/角色/演员/品牌 → 送模型前翻译成风格描述，见第四节 4）。
1. 画面里**能找到光的出处**吗？——找不到就是假光。
2. 高光是**滚降**的还是硬截断的？有没有"过曝处仍带暖色"？
3. 颗粒写的是**所选包的那种**吗（银盐成簇／磁带噪点／手机彩色噪声／老镜头的低对比），还是含混地写了"加颗粒"？
4. **画面瑕疵**是不是被写成了**正面状态句**（而不是"不要…"）？
5. **动作**有没有列出**同族并逐一排除**（写了推镜，就排除拉/摇/移/环绕/变焦）？

六问全过，才叫"统一提质层已带"。**第 0 问最上游**——它不过，后面五问全对也还是个人人都在用的通用观感。第 4、5 问是一对**方向相反**的检查：第 4 问查"有没有多写否定"，第 5 问查"有没有少写排除"。
