# 人物调度：主体 · 陪体 · 群像

> **何时读**：写分镜之前（定"谁在哪、谁动谁静、谁清谁虚"）；同一场戏**反复抽卡但关系讲不清**时；**两个人以上同框**时。
> **读完回哪**：几何与布局地图 → `sequence-craft.md` §三；选镜与顺序 → `shot-orchestration.md`；镜头运动 → `camera-movement-library.md`；资产与机位 → `asset-prompt-spec.md`；动作控制 → `motion-control.md`。
> **分工（**别串**）**：`sequence-craft.md` 管**"这一场怎么拆成镜"**；`shot-orchestration.md` 管**"选哪几个镜、什么顺序"**；**本册管"镜内的人怎么摆、怎么动、谁主谁陪"**。
> **★ 加一本**：**"这一镜有没有设计感"→ `shot-design.md`**（十个设计装置 / 直白→有设计四条改法 / 全片视觉母题）——**本册管"人之间的关系语法"，那边管"画框怎么被设计"。**
> **★ 为什么单列**：库里此前**`陪体` 零命中**，`调度` 只有"导演四问的第 4 问"与"白模/线稿锁调度"两处——**而它是"关系讲不清"的第一病根**。

## §0 一句话地基

**调度 = 演员调度 + 摄影机调度的统一处理**（mise-en-scène 的原义，从舞台进入电影后扩为两者合一）。
**依据不是"好看"，是剧本给出的**人物性格与人物关系**。
> **★ 判据**：**把这一镜的调度画成俯视图，你能不能指着它说出"这两个人现在是什么关系"？** 说不出 → 这一镜的调度是**摆pose**，不是调度。

**本册的主轴**：**位置就是关系，距离就是亲疏，高低就是权力，朝向就是同盟。**

## §1 ★ 调度的四个变量（调度语法的四个"词"）

| 变量 | 写什么 | 它说什么 |
|---|---|---|
| **① 方位** | 谁在谁的**哪一侧**（左/右/前/后）、面向何方 | **阵营与对立**（对角＝对立，同侧＝同盟） |
| **② 距离** | 之间多远（用**身体部位或步数**写，不用"适中"） | **亲疏**：贴身＝侵入；一臂＝对质；一桌之隔＝谈判；跨空间＝疏离 |
| **③ 高低** | 站 / 坐 / 蹲 / 倚 / 台阶上下 | **权力**（**但不是绝对规则，见下**） |
| **④ 朝向与视线** | 对视 / 同向 / 背向 / 错开（看别处） | **关系状态**：对视＝交锋或被吸引；同向＝并肩；背向＝断裂；**错开＝有话不说** |

**★ 三条纪律**：
1. **四个变量一次只改一个**——改两个，观众读不出"变的是什么"。
2. **变量的改变就是情节**（他从站着到坐下＝让位或夺权；两人从对面到并肩＝和解）。
3. **★ 高低不是绝对规则**：同一个"略高于眼平"的机位，在两种上下文里可以给出相反效果——**给一个将死之人，它是"支配环境"；给一个失势之人，它是"被环境支配"**。**判据**：问"这一镜我要说谁占上风"，再看**高低 + 居中/偏置 + 景深**三件合起来指向谁（单看高度必错）。

## §2 主体调度：两法 + 一个选择

**两种表现主体**：
| 法 | 做法 | 什么时候用 |
|---|---|---|
| **直接表现** | 给主体**最大面积 / 最佳照明 / 最醒目位置** | 要让观众"一目了然看他" |
| **间接表现** | 用**远景**，主体面积不大，**靠环境烘托与气氛渲染**来强调 | 要表现"他与这个环境的关系"（不是他的脸） |

**★ 位移 vs 静止（最常卡住的一个选择）**：
```text
他要"变"        → 让他位移（走近 / 退开 / 穿过画面 / 从后景走到前景）
他要"扛"        → 让他静止，让摄影机动（推 / 移 / 绕）
他要"被压住"    → 让他静止，让别人从他前面走过（遮挡＝打断）
```
**三条配套**：
- **纵深调度**：让主体**沿纵深移动**（由远而近 / 由近而远）——**前后移动比左右横移更能表现变化**（透视变化本身就是"力气"）。
- **重复调度**：同一走位在片中**复现两次**（首尾镜像、母题），第二次观众会自动对比——**这是调度层最省的"母题"工具**。
- **进场 / 退场只在情节需要时发生**，并推动冲突；不要用"支开一个人"的方式清场。

## §3 ★ 陪体调度（**用户点名的重点 · 库内此前为零**）

### 3.1 陪体的四种职能（先定职能，再定位置）
| 职能 | 它做什么 | 例（结构示意） |
|---|---|---|
| **呼应** | 与主体做**同一件事的变奏**（他也低头 / 也看向门外） | 强化主体的处境 |
| **对比** | 在**同一画面里做相反的事**（他在笑，主体在忍） | 让主体的情绪被"测"出来 |
| **环境** | 提供**世界与人数的证明**（这个空间里有别人在生活） | 一镜说完"这是哪里" |
| **尺度** | 当**参照物**（人在门框里的高度、队伍的长度） | 让空间可被度量 |

**★ 判据**：**每写一个陪体，先说出它是上面哪一种**——说不出来的陪体就是"填画面"，删掉。

### 3.2 空间处理五法（**按 AIGC 友好度从高到低排**）
| # | 法 | 做法 | 效果 | AI 友好度 |
|---|---|---|---|---|
| 1 | **后景虚焦** | 陪体在后景，**不在焦平面** | 世界在场但不抢 | **最高** |
| 2 | **前景遮挡** | 陪体/物件在前景**虚糊地框住主体** | 层次与窥视感 | **最高** |
| 3 | **群体化** | 陪体**不区分个体**（一片人、一群影） | 环境证明 | 高（**但人数别逐个数**） |
| 4 | **边缘切出** | 只入画**一半**身子或侧影 | 画外有人的暗示 | 中 |
| 5 | **★ 陪体先出、主体后出** | 先给陪体（他正看向画框之外），**镜头拉开/摇起后主体才出现** | **悬念 + 关系**；**且陪体的身份在主体出现后自动降为陪体** | 中（要一次运动）· 仅视频（依赖镜头运动的时间轴，静帧无从"后出"） |

**★ 第 5 法值得单记**：它是**"用调度做悬念"最省的写法**——先给一个**看着画面外的反应**，再揭示他在看什么。**主体与陪体的身份可以在同一个镜头内互换**（先出现的人群起初是主体，花车出现后成为陪体）。

### 3.3 ★ 不喧宾夺主的三条硬规则（**每条都可判**）
```text
① 陪体不朝镜头（破第四面墙的错觉，观众会去看他）
② 陪体不与主体争焦点或亮度（不在焦平面里、不在最亮处、不穿与主体冲突的强色）
③ 陪体不做与主体竞争的动作——**一个陪体只给"一件事"**（一个动作或一个状态）
```
**★ 陪体的"一件事"原则**：陪体需要的是**一个可判的状态**（他在擦杯子 / 他背对镜头站着），**不是一段表演**。给两件事，观众就开始看他。

### 3.4 前景与后景的纪律（两条，来自构图传统）
- **前景**：安排**没有一定之规**（可置边缘、可布满画面），**但必须以"烘托、陪衬主体"为前提**——**不能分割、破坏画面**。（例：雨幕、烟雾可以做满画面前景；一根横穿画面的杆子就只是障碍。）
- **后景**：**影调与色调必须与主体形成对比，避免与主体相近或雷同**；**简化背景、线形简洁**——背景越干净，主体越突出。

## §4 群像调度（三人以上）

| 项 | 做法 | 判据 |
|---|---|---|
| **场型** | 先选一个**几何场型**：三角 / 圆桌 / 一字排开 / 两面相对 / 半环 | **场型就是权力图**——说出这个场型在说什么 |
| **不平均原则** | **绝不等距排列**（等距＝没有关系） | 静帧里任意两人的间距都该不同 |
| **高低分工** | 谁站、谁坐、谁倚——**同一张桌上不要人人同姿态** | 姿态重复＝群像糊 |
| **视线挂法** | **每个人的视线都必须落在一个明确对象上**（人 / 物 / 画外） | 有一个人"看空" → 那一块画面浪费 |
| **★ 谁在动** | **一次只让一个人动**，其余保持 | 多人同时主动作 → 失败率显著升高（后景的环境性微动不算"主动作"）；观众也不知道该看谁 |
| **群像的"主"** | 群像里**仍要有一个视觉主体**（最亮 / 最清 / 最居中或最靠前） | 找不到主体 → 这一镜没有信息 |

## §5 调度与景别 / 焦点 / 机位的接口

| 调度决定 | 传导到哪 |
|---|---|
| **主体在画框里的水平位置与占比** | → **景别**（同一场景，人的占比变了，景别就变了） |
| **主体在纵深里的哪个平面** | → **焦平面**（前景/中景/后景＝三个可切焦的层） |
| **陪体的清晰度** | → **景深与焦点**（虚焦是最省的"降级"手段） |
| **谁更靠前、谁更高** | → **机位高度与俯仰**（但要注意 §1 的反例） |
| **镜内"主陪互换"** | → **焦点转移**（在一镜之内改主陪关系，比切两个镜头更高级，也更贵） |
| **主体的被动程度** | → **摄影机是否运动**（见 §2 的选择表） |

**★ 一句话**：**调度是"关系"，镜头是"读法"。** 先定关系，再选读法；反过来做，就会拍出"好看但说不出在讲什么"的镜头。

## §6 ★ AIGC 适配：调度是模型最脆的地方（**落地纪律**）

**已核实的前提（A 档）**：图像模型的官方短板里明列 **"精确空间定位"**——**所以调度不能写成坐标，只能写成关系**。

### 6.1 写法：关系词，不是坐标
```text
✅ 她在画面右侧三分之一处，他站在她左后方约一步，两人相距约一臂，都朝同一方向看
✅ 他背对镜头站在前景，只入画右肩与后脑；她在中景的桌边坐着，面向画面左
❌ 精确坐标、网格、角度数值分配、箭头指向
```
**★ 判据**：**"这句话是给一个摄影助理看的，还是给一个懂中文的画师看的？"** 后者才写得对。

**★ 补：方向必须"标注参照系"**（2026-09-17 外部学习后补 · **一手源**）
**写"左/右/前/后"时，必须在同一句里说清它是"谁的左"**——即**屏幕相对**（`画面左` / `画面右` / `入画右肩`）还是**角色相对**（`他自己的右边` / `她的左侧`）。
**理由（原文）**：`she turns to her OWN right` 不等于 `screen-left`；**未标注的方向，约一半概率会反转**（`cinema-director-v3` §SLOT 6 原话：
> "Screen-relative and character-relative direction are always labelled… **unlabelled direction inverts about half the time.**"）
**★ 二选一，并在整条稿里保持一致**：本库既有写法默认走**屏幕相对**（`画面左/画面右`），**沿用**；只有当"角色自己的左右"在剧情上有意义时（他往自己受伤的那条腿一侧倒）才写**角色相对**，且必须带"他自己的"。
**★ 人物与机位分处两侧时**（正反打 / 过肩），**必须标**——这是反转最高发处。
**★ 判据一句话**：**把"左/右"圈出来，每一项都能答出"相对于谁"吗？** 答不出 → 补参照系。
**机器口径**：`audit_prompt.py blocks` 对「出现左/右方向词、却没有任何参照系标注」报 WARN。
> **★ 证据强度 = 多源（2026-09-17 全量验证）**：273 份有正文的社区技能里，**30 份**含"屏幕相对/角色相对"这类参照系标注 → **真实但非主流**（L6：记为「拟订」）。

**★ 补二 · 运动中的主体要留 `lead room`（前导留白），不是 `trail room`**（2026-09-17 地毯式搜索后补）

**规则**：画面里**有运动方向**时（车在开、人在走、球在飞），**在运动方向的前方**留白，
**不是在后面**——**眼睛要跟着运动往前看，留白是给它"去"的地方**。
```
❌ 车靠画面右侧、头朝右开（右边只剩一点点 = trail room）→ 车"撞墙"
✅ 车放在 X 约 30–55%、运动指向画面 100% 那一侧 → 前方留出 lead room
```
**★ 判据一句话**：**"它要往哪去，就把空间留到哪一边。"**
**★ 与 §6.1 的关系**：方向**标注参照系**解决"会不会反"，**lead room** 解决**反了之后画面还成不成立**——
两条一起写：**写明运动指向（屏幕/角色相对) + 在指向那一侧留白**。
> **证据强度**：**单源**（273 份语料里 3 份，`1%`）。**走「机制可独立论证」门槛**：
> 这是**视觉动线**的既有构图原理（本册 §2 主体调度同族），不依赖来源权威。**按 L6 记「拟订」**。
> **来源**：`banana-pro-director-3-0`（"always leave lead room in the direction of motion — never trail room"）。

### 6.2 ★ 数量降级顺序（**按顺序试，不要跳**）
```text
① 先减数量：能一个人拍完的不放两个人（陪体可以先不入画）
② 再降清晰度：陪体进后景虚焦 / 转成剪影 / 只留局部
③ 最后才靠提示词约束：把"谁在哪、谁虚谁清、谁动谁静"写成一句关系句
```
**为什么是这个顺序**：前两级是**结构性降压**（删掉模型要算的东西），第三级是**语言层降压**（模型要读懂）。**语言层最贵、最不可靠**——先做便宜的。

### 6.3 五条硬纪律
```text
① 一次只给一个主动作（多主体同时动 = 必崩）
② 主体动 → 陪体静；陪体动 → 主体静（**绝不让两边同时做复杂动作**）
③ 走位拆成"起点帧 + 终点帧"（两个文件），中间交给模型或剪辑；不在提示词里描述轨迹
④ 镜内不做穿越调度（穿人、绕桌、交叉换位）——**交给剪辑**（单人且首尾帧锚得住的可试一次生成）
⑤ 优先级：**能拍 > 关系清楚 > 好看**（好看排最后，因为它是前两件的副产品）
```
**★ 陪体的"保险写法"**（关系复杂时的兜底）：**剪影 / 背影 / 局部 / 虚焦**——四种任选，**都不吃面部一致性**，也不吃多主体关系。

### 6.4 三个可视化工作件（**调度的图纸，与库内既有件咬合**）
| 件 | 内容 | 与谁咬合 |
|---|---|---|
| **布局地图** | 俯视几何：人、家具、门、机位 | `sequence-craft.md` §三（**几何问题一律用图**）——**同一张图，本册再加"人"这一层** |
| **站位表** | 逐镜：谁 / 在哪 / 朝哪 / 什么姿态 / 谁动谁静 | 写进 12 块的《人物与环境》与《构图》 |
| **视线图** | 谁看谁（含画外对象） | 机位与正反打（`sequence-craft.md`） |
**★ 与场景资产的接口**：**机位清单来自场景资产**（`asset-prompt-spec.md` §2.3），**人物位置来自本册的站位表**——**两者合起来才是这一镜的调度**。

## §7 自检（三组，共十七条）

```text
【主体】
① 画成俯视图，能说出这两个人是什么关系吗？
② 四个变量（方位/距离/高低/朝向）这一镜动的是哪一个？只动了一个吗？
③ 他是"变"、"扛"还是"被压住"？调度的选择与这三者之一对得上吗？
④ 有没有用"高低"这个单变量就断定权力？（**要高低 + 居中/偏置 + 景深三件合起来看**）
⑤ 有没有一次"重复调度"（与前面某镜同走位）来当母题？
⑥ 进出场是情节需要，还是为了支开人？

【陪体】
⑦ 每个陪体答得出职能吗（呼应 / 对比 / 环境 / 尺度）？
⑧ 用的是五法里的哪一种？**首选的两种（后景虚焦 / 前景遮挡）排在最前吗**？
⑨ 三条硬规则过了吗（不朝镜头 / 不争焦点亮度 / 只做一件事）？
⑩ 陪体给的是"一个状态"，还是一段表演？（后者的第二种删掉）
⑪ 前景烘托主体而没有分割画面吗？后景的影调与主体形成对比了吗？
⑫ 关系太复杂时，有没有改用保险写法（剪影 / 背影 / 局部 / 虚焦）？

【群像】
⑬ 场型是什么？它在说什么？
⑭ 有没有等距排列？（有 → 改成不平均）
⑮ 每个人的视线都落在明确对象上了吗？
⑯ 是不是**一次只有一个人在动**？
⑰ 群像里找得到一个视觉主体吗？
```

## §8 常见误区

| # | 误区 | 后果 | 修法 |
|---|---|---|---|
| 1 | **把调度当"站位"填**（只写"两人分坐桌两侧"） | 关系讲不清，抽卡永远差一点 | 四个变量至少写两个 |
| 2 | **高低即权力**（机械套用） | 反例一出就翻车 | 高低 + 居中/偏置 + 景深一起看 |
| 3 | **陪体越多越丰富** | 注意力被分走，且 AI 先崩 | 陪体"一件事"原则 + 五法降级 |
| 4 | **群像等距排列** | 画面像合影，没有关系 | 不平均原则 |
| 5 | **多人同时动** | 观众不知道看谁；模型必崩 | 一次一个人动 |
| 6 | **用坐标写调度** | 模型读不懂（官方明列短板） | 换成关系词 |
| 7 | **先想好看再想关系** | 出来是"好看的废镜头" | 顺序：能拍 → 关系清楚 → 好看 |
