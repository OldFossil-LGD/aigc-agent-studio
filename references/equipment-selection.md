# 器材与材质的选择逻辑（选包的方法）

> **何时读**：**选器材之前**——在 `camera-package-library.md` **之前**读这一份。
> **分工**：本文 = **怎么选**（判断链 · 六轴 · 组合规则 · 真实度尺）；`camera-package-library.md` = **有哪些**（17 包 · 三档位 · 调制层 · 反查表）；`package-extended.md` = **补充 17 包**（航拍 / FPV / 穿戴式 / 超长焦 / 微距 / 鱼眼 / 移轴 / 宝丽来 / 红外 / 热成像 / 夜视 / 录屏 / 卫星 / 内窥 / CGI / AI 原生 / 延时）。
> **本文不重复包的清单**，只给选择的方法。

---

## 一、先说清四个结构性问题（这一份就是为了解决它们）

### 问题 1 · 包被做成了"不可分的整体"，于是"要 A 的光学 + B 的机位"做不到

实测：要「变形宽银幕的横向眩光」＋「固定机位」——**找不到这样的包**，因为 P14 的运动行写死"缓慢横移或跟拍"，只能二选一。
**根因**：把六轴里**本来独立**的几轴（载体 / 清晰度·光学 / 稳定度）捆成了一个不可分的整包。

### 问题 2 · "默认包"给了偷懒一个正当的理由

P13 被标为"降为数字档默认包" → 三问答不出时**直接用它** → 于是"113 个风格、所有项目器材观感全是一个样"。
**2026-09-12 那次改造把「写死一套」改成了「默认一套」，但没有根治偷懒。**
**实测代价**：给"验证皮肤真实"的人物特写选包时直接用了 P13——而 P13 自述"**最容易显假**"，且配套纪律要求"用数字档必须叠一层调制"，两条都没遵守。

### 问题 3 · 反查表在做"场景类型 → 器材"的错误映射

"恐怖 → P04 监控"——但**恐怖不一定在监控下**：可能在 1980 年代的家庭录像带里（P03）、也可能在梦境的柔光里（P15）。
**"场景类型"不等于"记录方式"。** 同一个厨房可以有五种记录方式：手机（家人随手拍）／监控（被盯着）／35mm（回忆）／老镜（母亲的味道）／DV（千禧年）。

### 问题 4 · 缺一个可排序的"真实度"维度

三档位是按**年代**分的，不是按**真实度**分的。而"极度写实该用什么"这个问题，**答案不在"哪一档"，在"真实感由谁承担"**。

## 二、六轴是正交的：包只是它们的预设组合

> `camera-package-library.md` §一 已经定义了**六轴**（载体 / 画幅 / 光质 / 清晰度 / 稳定度 / 色彩工程），原句是「"谁拍的"不是修辞，它一次性决定六件事——**六轴一次选定、整片不换，这就是方案包**」（"整片不换"的纪律另见其 §七 纪律 1「一片一包」）。
> **本文不另造轴制**，只补一条它没有明说的性质：**这六轴互相独立，包只是它们的预设组合。**

| 六轴（沿用它 §一 的定义） | 在"包"里被绑定成什么 | 能不能跨包取 |
|---|---|---|
| **载体**（手机 / 家用机 / 转播 / 胶片 / 数字 / 虚拟棚） | 包的核心 | ⚠️ **只能取一个**（不许"又用 16mm 又用手机"） |
| **画幅** | 随包（P07=1.66:1、P14=2.39:1…） | ✅ 可换，**但颗粒尺度随之变** |
| **光质** | **包不管光**（光由命题与光位决定） | ✅ **本来就独立** |
| **清晰度** | 随包（老镜软 / 数字锐） | ✅ **可与载体拆开**——"数字机身＋老镜"（P15）就是这么来的 |
| **稳定度** | 随包的「运动」行（P14=缓慢横移、P04=完全固定） | ✅ ★ **最该拆开的一轴**——"要变形镜的眩光＋要固定机位"是正当需求，**现行设计把它堵死了** |
| **色彩工程** | 随包（印片模拟 / 磁带色偏 / 直出） | ✅ 可叠调制层 |

**★ 所以"包"的正确理解是**：**一个包＝六轴的一组经过验证的预设值**。它省事、不容易出错，**但它不是边界**。

**★ 再补一层「真实度调节」**（六轴之上的**总量控制**，不是第七轴）：
六轴决定"**是什么**"，真实度调节决定"**痕迹给多少**"——见 §五。

## 三、跨包组合规则

| 允许 | 说明 |
|---|---|
| ✅ **六轴跨包取** | 例：载体取 35mm 胶片（来自 P08）＋ 清晰度取变形镜（来自 P14）＋ 稳定度取完全固定（来自 P04）。**这是正当的，也是被"整包锁定"堵死的部分。** |
| ✅ **真实度调节叠在任何组合上** | 调制层本来就不单独成包（`camera-package-library.md` §四） |
| ⚠️ **组合后必须自检四轴是否讲同一个"拍摄故事"** | `quality-layer.md` 第 2 条：载体／光质／清晰度三条轴线任一条打架都自相矛盾。**判据：把组合读一遍，问"这是谁拍的、拿什么拍的、在什么条件下拍的"，能答出唯一一个答案吗？** |
| ❌ **不许叠两个载体** | "又用 16mm 又用手机"＝两个记录介质，不成立。**A 轴只能一个值。** |

**跨包组合的例子（正当的）**：

```
载体　　　　：35mm 胶片（银盐颗粒成簇）
清晰度·光学：变形宽银幕镜头（横向视野、椭圆焦外）
稳定度　　　：完全固定（机位不动）
→ 组合后讲的故事："一台架着的胶片摄影机，从街对面远远看着一个人"
→ 唯一答案 ✓ 成立
```

**反例（打架的）**：

```
载体：手机（边缘畸变、彩色噪声）
光：电影级影棚主光、精修人像
→ "手机随手拍"与"影棚主光"是两个故事 → ✗ 
```

> **★ 与「一片一包」的分界（2026-09-17 补）**：上面这条**管的是"一个画面里不许出现两个拍摄故事"**——它**不是**"一部片只能有一个包"的加强版。
> **"跨世界"条目允许整片出现多套包**：**G01 选集式多风格 · G15 混合画幅 · G02 · G03 · G08 · D20**——
> **那不是混包，是每一段／每一画幅／每一层各自成片**；**但每一个画面内部仍然只有一个拍摄故事**（本页 §三 的规则对每一段各自成立）。
> 两种做法的区别只有一条判据：**故事讲的是"一部片"还是"几部片拼成的合集"**。

## 四、默认器材怎么处理

**取消"默认包"这个身份。** 理由：默认包的存在会让"三问答不出"变成"直接用默认"，而这正是观感趋同的机制。

| 原表述 | 改为 |
|---|---|
| P13「**数字档默认包**」 | 「**数字档的起点之一**」——并且 **用它必须叠一层调制**（`ai-artifact-control.md` 自检第 8 条：**"太干净"本身就是破绽**） |
| P08「**胶片档的默认包**」 | 「**胶片档最不容易出错的起点**」——保留（它的痕迹行最稳），但**不是"答不出就用它"** |
| 「三问答完仍拿不准 → 用 P08 35mm」 | 「三问答不出 → **回到 §六 第一步问"真实感由谁承担"**，再按**六轴**组合。**已无"默认包"可挑**」 |

**兜底怎么做才对**：不是挑一个包，而是**给六轴各一个最保守的取值**——（轴名与 §二 的六轴**同一套**，不另立名）

```
载体    ：35mm 胶片（痕迹最稳、最不容易显假）
画幅    ：16:9，或**有首帧时留 `adaptive`**（自适应，官方默认）；艺术意图写法与落地映射见 `platform-matrix.md` §7.4
光质    ：以场景动机光为准，不额外加柔光风格
清晰度  ：现代定焦（不引入额外光学性格）
稳定度  ：稳定器（可控，不引入不稳）
色彩工程：标准胶片模拟收尾，不加 LUT 感
```

## 五、材质与场景的匹配原则

### 原则 1 · 场景决定"光"，不决定"器材"

**器材由"谁在看、用什么看"决定**（叙事视角），不由场景类型决定。
反查表的正确读法是「**氛围词 → 常见搭配**」，**不是「场景类型 → 唯一器材」**。

### 原则 2 · ★ 材质的真实感，需要"载体的噪声结构"来支撑

**这是最实用、也最容易被忽略的一条。**

| 材质的真实感靠什么 | 谁来承担 |
|---|---|
| 皮肤的**毛孔** | **光位**（斜射）——与包无关 |
| 皮肤的**绒毛 / 次表面散射** | **光位**（逆光）——与包无关 |
| 皮肤的**高光不像塑料** | ★ **载体的噪声结构**——**一个"干净到无噪点"的载体，会让光滑的皮肤看起来像塑料** |
| 布料 / 金属 / 水的响应 | 光学性格 + 光位 |

**推论（很重要）**：
> **越干净的载体，越不利于"人物真实"。** 因为皮肤的真实感有一半来自"有东西打断它的完美"——胶片成簇的银盐颗粒、老镜的 halation、或一层黑 Pro-Mist。

### 原则 3 · 载体的固有特征 ≠ "刻意的瑕疵"（两条纪律不冲突）

`camera-package-library.md` 说"低端档是提升真实感最快的一档"（缺陷＝判真依据）；
`tone-realism.md` 说"不完美只给一到两处，三处以上从真照片翻成特效演示"。

**这两条不矛盾，因为它们说的是两样东西**：

| | 载体固有特征 | 刻意的瑕疵 |
|---|---|---|
| 例 | 噪点、颗粒、畸变、片门晃动、halation | 墙上一个歪的相框、桌上一处缺口、杯壁一道水痕 |
| 范围 | **全局一致**（整片都是这个载体的特征） | **单处点缀**（一到两处） |
| 是否占"不完美配额" | **不占**——它是"这个世界用什么拍的"的证明 | **占**——它是"这个空间是活的"的证明 |

**所以：载体的痕迹该写足（至少三项），刻意瑕疵要克制（一到两处）。**

## 六、不同真实度需求下的选用依据

### 第一步（最上游）· 定"真实感由谁承担"

**问：观众判断"这是真的"，靠什么？**

| 真实感来源 | 落在六轴的哪一轴 | 典型载体 |
|---|---|---|
| **器材的缺陷** | **载体**（低端档） | 手机 · 监控 · DV · VHS · 转播 |
| **介质的物理** | **载体**（胶片档） | 35mm · 16mm · Super 8 · 65mm |
| **镜头的光学性格** | **清晰度**（老镜 / 变形镜） | 数字机身＋老镜 · 变形宽银幕 |
| **大画幅的浅景深与宽容度** | **载体**（数字大画幅） | P13 那一类 —— ⚠️ **最容易显假**，因为它**没有打断完美的东西** |

> **★ 走这张表之前先答一问："这是一层，还是几层？"**（2026-09-17 补）
> 若风格编号落在 **G 卷（G01 选集式多风格 · G02 2D＋3D · G03 实拍叠手绘 · G07 屏幕生活 · G13 光绘 · G15 混合画幅）或 D20 新海诚式**，
> **器材只解决"拍的"那一层**——**先答"哪一层是拍的、哪一层是画的、哪一层是造的"，再对"拍的那一层"走本节六轴**；
> **多系并存（G01 / G15）时每段／每一画幅各走一遍**，准入条件见 `stylized-look.md` §二·补2 的四条件。
> **判据**：答不出"哪一层是拍的"，就不要选包——否则会把两层写进同一句器材里，模型只能二选一或糊成一锅。
> 族级落点（谁配哪类包、哪些是禁忌）→ **`style-package-matching.md` §1 族⑭**。

### 第二步 · 按需求选（对照表）

| 你要的真实度 | 真实感由谁承担 | 载体走法 | 必须避开的陷阱 |
|---|---|---|---|
| **器材真实**（像随手拍的） | 缺陷 | 低端档 | 写了"手机拍的"却**没写手机的痕迹** → 模型会用它的默认观感盖掉你写的机身 |
| **介质真实**（要胶片味） | 介质物理 | 胶片档 | **颗粒档与画幅联动**（65mm 极细／35mm 细／16mm 中／S8 极粗）——选了包就定了，**不许另写"加颗粒"**（会得到均匀数码噪点） |
| **光学真实**（要老镜味） | 镜头性格 | 数字＋老镜 | **不许写"抗眩光""边缘清晰"**——那是把老镜写成现代镜，等于白选（老镜是"在选用像差，不是修正像差"） |
| ★ **人物真实**（皮肤＋表演） | **光位（能否看见）＋ 载体的噪声结构（是否显塑料）** | **胶片 / 老镜 / 或数字＋一层调制** | ★ **最干净的数字机最不利**——它没有东西打断皮肤的完美 |
| **绝对干净**（广告质感） | 大画幅浅景深 | P13 那一类 | **必须叠一层调制**（黑 Pro-Mist／漂白／颗粒档），否则就是在赌"干净本身不显假" |
| **被记录**（监控／直播感） | 视角的机械性 | P04/P05/P06 | 画面内的文字（时间码／台标）→ **约定后期贴**，不要指望生成 |

### ★ 对"追求人物高度真实的 AIGC 电影"的答案

**真实感的承担者是两样，不是一样：**

1. **光位**——决定"能不能看见"。毛孔要斜射、绒毛与 SSS 要逆光、高光要斜角。**四样在正面平光下全隐形**（`skin-realism.md` §1.4）
2. **载体的噪声结构**——决定"像不像塑料"。**没有任何噪声的干净画面，会把皮肤的光滑推向塑料**

**组合结论**：

```
载体　　　　：35mm 胶片 —— 银盐颗粒成簇，正好是皮肤该有的噪声结构
　　　　　　　或 数字机身＋老镜 —— halation 让高光化开，是真实胶片上皮肤高光的行为
　　　　　　　或 数字大画幅＋黑 Pro-Mist —— 只在有光处发光、不抬黑位
清晰度·光学：现代定焦或老镜 —— 老镜的边缘软与低对比进一步掩护毛孔的丢失
稳定度　　　：看叙事 —— 固定＝凝视，手持＝目击，与载体/清晰度独立
真实度调节　：介质物理，或受控调制
```

**明确不该做的事**：**不要因为"它最干净、最现代"就选数字大画幅默认那一套**。对"人物高度真实"这个目标，**干净是负债，不是资产。**

## 七、判断链（四步，按顺序走）

```
① 定真实感的承担者 —— 观众靠什么判真？（器材缺陷 / 介质物理 / 镜头性格 / 大画幅浅景深）
                       ↑ 这一步最上游，此前完全缺失；跳过它就会退回默认包
② 定载体         —— 谁在看、用什么在看？（六轴的「载体」）
③ 定清晰度·光学  —— 要不要变形 / 老镜 / 锐利？（六轴的「清晰度」）
④ 定稳定度       —— 固定 / 手持 / 稳定？（六轴的「稳定度」，与 ②③ 独立）

然后：光质（由命题与光位定）· 画幅与色彩工程（随载体，可叠调制）
最后：自检六轴是否讲同一个"拍摄故事"
```

**"三问答不出"的意思是**：这个题材没有明显的年代、光、视角特征。**此时不要挑默认包**——回到第 ① 步，从"真实感由谁承担"重新推。

## 八、三个自检

**自检 1 · 六字问**（`quality-layer.md` 质检六问第 0 问的原句）：
> "**这是谁拍的、拿什么拍的、在什么条件下拍的**" —— **能答出唯一一个答案吗？**

**自检 2 · 三行核一致性**（这一步针对"逐字粘包"的常见错）：
> 粘一个包的**痕迹行**之前，**必须同时核它的「器材」行与「运动」行是否与所选风格/命题一致**。
> **只粘痕迹行、不核运动行，是实测踩过的坑**（同一份提示词里出现"横移"与"推近"两个互相打架的运镜）。

**自检 3 · 干净审计**：
> 这一版的载体是"干净"的那一类吗？是 → **叠调制了吗**？没叠 → **补上，或者换一个自带噪声的载体。**
