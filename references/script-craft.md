## Gate Check（先过这关再写）

一句话说清"这剧本讲什么"。说不清 = 素材没组织好，先不写。

## 倒推法搭骨架

从结局倒推 → 第二动作点 → 第一动作点 → 干扰事件。每问一次："主角怎么到达这里？"

> **★ 这是"七点结构"的简化版**（Dan Wells 传统：钩子必须是结局的反面 · 两个 pinch 是反派施压 · 中点是"从反应转为行动"）——想换成别的形状（故事圈 8 步 / 起承转合 / 序破急）之前先去 `drama-structure-models.md` §9 决策树对一次；**不要拿最熟的那个套上去**。

## 容量先行（**排节拍之前必须做**）

**先量容量，再排节拍。** 60 秒 ÷ 每拍至少 8–12 秒 = **拍数上限 4–6**；反转通常 1 次；场景 ≤3（AI 建议）；台词总量 ≤60–80 字。**超了要换模型，不是删拍**（→ `drama-scaling.md`，附容量单模板）。

## 短片形态纪律

- 主角 ≤3、场景 ≤5、单起承转合、只讲一件事
- 只保留 1 条主线 + 1 次反转
- 后半部必须有威胁递增段，不能靠单次冲突撑结局（防头重脚轻）
- 高反差结尾 = 最佳记忆点
- 选材优先视觉驱动：AIGC 生成上限由剧本的"可视化程度"决定

## 节拍表模板

60 秒版（按比例缩放）：

| 时间 | 說明 |
|---|---|
| 0:00–0:04 | 开场画面：一镜定调，人物+环境反差，信息满载 |
| 0:04–0:11 | 主题呈现：暗示核心议题 |
| 0:11–0:18 | 铺垫：建立日常与人物缺陷 |
| 0:18–0:26 | 推动：主角被迫行动 |
| 0:26–0:34 | 第二幕衔接点：世界倒转（反转/意外） |
| 0:34–0:42 | 中点：目标升级或回头 |
| 0:42–0:50 | 坏蛋逼近 + 灵魂暗夜：威胁递增到最低谷 |
| 0:50–0:56 | 结局：孤注一掷 + 行动/牺牲 |
| 0:56–1:00 | 终场画面：与开场呼应，主题落地，留白 |

90 秒版可按本表等比放大，节拍一个不少；**3 分钟及以上不得等比套用**——"每拍 8–12 秒"的容量算式会先爆（180 秒 ÷ 9 拍 = 每拍 20 秒），**先回 `drama-scaling.md` 量容量重排拍数，再回来填秒**。

> **★ 本表是 30–60 秒档的唯一权威模板**（秒数是唯一允许写秒数的层）。**表外的档位**（15 秒 / 5 分钟 / 竖屏单集）与**长片模型往短片折叠的规则**在 `drama-scaling.md`——**先在那里量容量，再回这里填秒**。15 拍表在 60 秒里按比例摊会退化成"每 4 秒换一次情绪"，**不可直用**（`drama-structure-models.md` §4）。

## 分场剧本格式（**权威源：`script-format.md`**）

**★ 2026-09-16 起：正式交付的剧本一律按 `script-format.md` 的好莱坞标准规格写**——六大元素与位置表 · 特殊情形十种（`(V.O.)` / `(O.S.)` / `(CONT'D)` / `MORE` / `MONTAGE` / `INTERCUT` / `FLASHBACK` / `INSERT` / 双栏对白 / 画面内文字）· 标题页与页码 · spec 与拍摄稿之分 · **中文适配档（默认交付档）** · 十条自查 · 空模板。
**下面这套简版格式仍有效，但只作"内部工作稿 / 快速草稿"用**——它没有场景标题四要素、（V.O.）/（O.S.）扩展与转场位，**直接交付会被读出业余**。

| | 简版（本节 · 内部草稿） | **标准档（`script-format.md` · 交付）** |
|---|---|---|
| 场景标题 | `1 教室 日 内景` | **`内景 教室 - 日`**（内外景 / 地点 / 连字符 / 时间**四要素**，且**换地点跳时间就换标题**） |
| 说话人 | `人名：台词` | **人物名居中加粗 + 对白居中两侧留空**；念法不明确时**加括号（≤4 词）** |
| 扩展 | 无 | **`（画外音）` / `（画外）` / `（接着说）`** 必须写——**（画外音）是本库最划算的写法（不吃口型）** |
| 转场 | 无 | **右对齐加粗**（淡入 / 淡出 / 切至 / 叠化），**只在转法本身有意义时写** |
| 时长口径 | 秒 | 秒 + 字数双轴（**中文不能用"一页一分钟"**） |

```text
1 教室 日 内景          ← 场景号 + 时间 + 地点 + 内外景
　　（动作段落，句首空两格）
李老师：同学们……      ← 人名 + 冒号 + 台词，不用引号
　　（括号只放简短动作名词，禁止"（愤怒地）"式情绪形容词）
　　（场景之间空一行）
```

## 剧本 → 分镜的接口（写在剧本末尾）

每场三行硬事实，给分镜直接引用：

```text
scene SC03 · 叙事功能：一场只干一件事
open_state  : 可画出来的起始状态（位置/朝向/道具/持续声）

hard_facts  : 恰好人数、唯一道具、逐字台词、禁止出现的东西
```

## 短视频留人三件套（retention · 2026-09-11 补）

30–60 秒短片与长片**不是同一套叙事经济**：长片可以慢慢铺垫，短片**前 3 秒决定成败**。三件必须在前 15 秒内交代清：

| 件 | 位置 | 做什么 | 写不好会怎样 |
|---|---|---|---|
| **① 3 秒 hook** | 开场 0–3 秒 | 用一个**具体到能看见的画面**抓住人——一个反常动作、一个不该出现的东西、一张脸的特写。**不要**风景空镜起手、不要字幕起手 | 观众划走，后面全白拍 |
| **② open loop** | 3–15 秒内 | 抛出一个**未闭合的问题**（他为什么站在这？箱子里是什么？），让观众为了答案留下来 | 观众知道"要看什么"但没有"要等什么" |
| **③ 未答问题** | 结尾 | 收束主问题时，**留一个轻的次要问题不答**（让片子在观众脑子里多活一会儿）。**不是**没交代清楚——是**故意不答**，且观众知道是故意的 | 全答完 = 看完就忘；全不答 = 没看懂 |

**三条纪律**：

1. **hook 必须进第一个镜头的第一个动作**——不能"先建立环境再出 hook"。如果剧本第一镜是空镜，把它删掉或把 hook 前移。
2. **open loop 与 hook 不是一回事**：hook 是"值得看"，loop 是"值得等"。
3. **未答问题 ≠ 烂尾**：主动留白与没拍完的区别是——**主线必须闭合**，留白的只能是一个**意识到、被看见过、但不解答**的次要线索。

**钩子菜单**（① 的招法库——原则在上面，**具体怎么下手**在这里）：

**一条只用一招，最多叠两招**。叠到三招就糊成"什么都想要"。

| 招 | 怎么下手 | 适合 |
|---|---|---|
| **反常动作** | 去做一件"不该这样做"的事：徒手攥住滚烫的杯子 | 通用 |
| **不该在的东西** | 画面对了，但多了一样不该在那儿的东西 | 悬念、惊悚 |
| **脸的极端特写** | 只给眼睛或嘴、不给全脸——**先给"人"，再给"谁"** | 情绪片 |
| **睁眼 / 锁定视线** | 前提是有人在闭眼或垂眼，再让他睁开、直视 | 最本能的一招 |
| **尺度错位** | 把寻常物当宏大风景拍（布纹当山脊、水珠当星球），**先不给参照物** | 视觉系 |
| **静一拍再爆响** | 前 1.2 秒彻底静，第 1.3 秒一记声音 + 画面同步落 | 冲击型 |
| **颜色突变** | 冷灰打底，0.6 秒整体翻成暖金或霓虹 | 时尚、MV |
| **高速入画** | 主体带速度**从画面边缘进**，不从中间出现 | 动作、追逐 |
| **焦点甩移** | 前后都清楚，1 秒内把焦点甩到前景或背景 | 信息揭示 |
| **局部 → 揭示** | 先给局部，再拉开露出背后的体量 | 史诗、收尾 |

**两条配套纪律**：

1. **钩子落在第一个镜头的第一个动作上**——不是"先给环境再给钩子"。第一镜若是空镜，删掉它。
2. **钩子只负责"值得看"，不负责"讲清楚"**——交代留给第 2–3 秒。**把说明塞进钩子，钩子就死了。**

> 招法整理自 `beshuaxian/higgsfield-seedance2-jineng`（GitHub 821★，**无许可证，仅提炼未复制其文本**）的 2 秒钩子技法表，已按本库语言体系重写并压缩。

**与可行性门的顺序**：先过 `feasibility.md` 的可行性门（能不能拍），再排 retention（排得好看不好看）。**顺序反了会为镜头刁钻而选到拍不出来的东西**。

## 验收清单（精简 12 项）

概念有"点" · 主角内外目标明确 · 有强大反对力量 · 主角有变化 · 激励事件驱动足够 · 每场都有功能 · 晚进早出 · 大高潮值得期待 · 开篇抓人 · 为视觉惊艳留空间 · 台词有个性 · 四问：是否必需/能更好/能看见/做得到

## 交付格式

七件是内容功能清单，按 `script-module.md` 的交付档位收纳到同一个文档。内容包括主旨 + Logline / 梗概 / 人物 / 节拍表 / 无对白版 / 分场剧本 / 台词清单（**主旨与 Logline 合算一件**，与 `studio-workflow.md` 第一步同口径）。不拆文件、不拆层。**其中"分场剧本"这一件的版式一律按 `script-format.md`**（好莱坞标准 + 中文适配档 + 空模板 + 十条自查）。
**★「人物」这一件的写法与推导（八字段 · 句架库 · 痕迹词表 · 到提示词的映射）→ `character-sheet.md`**——**小传是给你自己推的，交付物里只放"可见物"那一层**。

### ★ 交付前跑 `script_lint.py`——**先判模式，再跑**（2026-09-18 实测踩到）

```text
python3 scripts/script_lint.py <剧本.md> --mode full    # L2 完整版，十二模块
python3 scripts/script_lint.py <剧本.md> --level L1     # 日常标准交付，十模块
python3 scripts/script_lint.py <剧本.md> --level L0     # 显式标注的可拍最小版，七模块
python3 scripts/script_lint.py <剧本.md> --mode body    # 只发 M8 正文：不查模块齐备
```

**★ 用错模式会得到完全相反的结论**——实测：把一份**单场正文**按默认 `full` 跑，
门禁报 **"模块缺失：未检出任何 M1–M12 模块标记" FAIL**，
而它其实**只是一场戏，本来就该用 `body`**。**同一份文件换模式后：退出码 0、全过。**
> **判据一句话**：**"我这次交的是整本，还是只交正文？"** 答不出就别跑——**跑错模式比不跑更糟**（会让你去修一个不存在的问题）。
> **另一条**：**读退出码别接在管道后面**（`cmd | tail` 读到的是 `tail` 的码，会看到假的"全过"）；
> **退出码 3 ＝ "没扫到东西"≠ 通过**（例：`ai_smell_check` 对纯剧本返回 SKIP）。
