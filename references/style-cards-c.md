# 风格校准卡 · C 卷（C01–C21）＋ C 卷续（C22–C41）· 41 条

> **答的是"我这一版偏了哪一项"**：四项色彩指标 + 光位 + 景深 + 构图 + 质感；末行留「参照 / 生成」两组数。
> **与取图册分工**：`style-sources-c1.md` 答"**去哪找参照**"，本册答"**怎么核像不像**"。**先看色相与饱和**。
> **★ 指标为方向性推导**（依据公开的类型片与美学运动研究），**非实测值**；**你的实测优先**。
> **★ 定标与容差 → `style-cards-scale.md`**：卡上给"低 / 中 / 高"是**方向**，**判偏要回那一页量数**——先量参考帧、再量你出的图，按容差表（色相 ±12° · 饱和 ±25% · 明度与对比 ±15%）看差多少。
> **★ 亚文化条目（C04 / C09 / C10 / C11 / C12 / C14 / C15 / C17 等设计运动与合成美学条目）没有"电影光位"** —— 卡上给的是**它的光源逻辑与介质**（名单与卷尾「来源与口径」节一致）。
> **★ 时序词与静帧卡（2026-09-30）**：卡上标 **[动态]** 的描述（频闪 / 呼吸 / 推移 / 追光换色 / 逐段变化）是**视频层特征**——静帧校准只取它的**单帧截面**（如"频闪"取荧光灯均匀冷绿的单帧），动态本身不进单帧判偏。
