实测（2026-09-22）：`sha256("https://mcp.liblib.tv")` = `fcbfe4701a68c606…`，**与文件里的 `fcbfe470…::LibTV` 精确命中**；带上 `/mcp`（`adbfd813…`）、尾斜杠（`58c69f25…`）或裸名（`4bc6bc73…`）**均不命中**。命中即证明宿主**已按 origin 建立批准白名单** → 「未批准」这一层可排除。

## 十六、五条常见误判（都踩过）

- **无头探 `POST https://mcp.liblib.tv/mcp` 得 401，不能当「授权失效」的证据**——无头请求本就带不上令牌。
- **`mcp.json` 里没有某条目 ≠ 未登记**——先证明该文件"本来应该收这类条目"再下结论。
- **`everConnected` / `enabled` / `userDisabled` 三表里没有 ≠ `headerOverrides` 该缺**——三表不做 `custom-mcp:` 前缀项的登记（对照：`custom-mcp:ardot` 有 headerOverride，三表皆无）。

## 十八、★ 阶段闸（挂载恢复后仍有效）

### §十九· · 三、掉线事故的真实修复路径（2026-10-02 实测结案）

**核心发现：原 marketplace 目录**从未消失**，**只是**在 `config.toml` 里**没被注册**。

| 假设 | 事实 |
|---|---|
| 插件被删了 | 缓存 `plugins\cache\libtv\libtv\1.0.0` 完好，**marketplace 目录 `.tmp\marketplaces\libtv` 也完好** |
| 网络所以不行 | GitHub 连不上（连接 github.com 443 失败），但**无需网络**：本地目录本身就是来源 |
| 必须手写 config | **不必——用官方 CLI，格式由它自己写** |

**正确修复路径（两条命令，官方 CLI）**：

```
codex plugin marketplace add <HOME>\.codex\.tmp\marketplaces\libtv
codex plugin add libtv@libtv
```

**为什么不手写 config.toml**：现有两个 marketplace 都带 `\\?\` 前缀的**本地路径形式**，手写易写成普通路径而导致**路径等价性失配**；而 CLI 会写出**与其他两个一致的格式**。
（实测：CLI 写出的是 `source = '\\?\<HOME>\.codex\.tmp\marketplaces\libtv'`，与 `openai-bundled` 逐字同形。）

**修完后的验收三步（三条独立证据，不用单一指标定性**：

1. `codex plugin list` → `libtv@libtv  installed, enabled`
2. `config.toml` 里 `[marketplaces.libtv]` 与 `[plugins."libtv@libtv"] enabled = true` 都在
3. `python3 scripts/libtv_orchestrate.py preflight` → 三层全绿、rc=0

**★ 一个必须知道的限制**：**MCP 服务器在任务启动时加载**。当前任务里 `ListMcpResources(libtv)` 仍报 `unknown MCP server`——**这不是修复失败，是「当前任务里加载的是任务启动时的插件快照」**。
**必须新开一个任务（或重启应用）才能拿到 MCP 工具面**。

**安全要点**：改配置前先备份 `config.toml`（本次备份在 `config.toml.bak-20261002-163720`）。

### §十九·四、CLI 会话过期时，**哪些只读命令还能用**（2026-10-16 实测）

**背景**：`libtv` CLI 的登录会话会过期（`account list` 报 `code: 401 未登录`）。
**过期后不等于什么都读不到**——**实测 11 条 `read_only` 命令，5 条照常、6 条被拦**
（清单：`outputs/libtv_rea_20261014/logged_out_readonly_inventory_20261016.json`）：

| **还能用（5）** | **被拦（6）** |
|---|---|
| `help` · `model search` · `model <name>` · `project list`（**返回空**）· `image shortcut list` | `account info` · `account list` · `node list` · `group list` · `workspace list` · `project <uuid>` |

**★ 判据**：**"会话过期"不是"读通道全灭"**——
**模型面（`model search` / `model <name>`）与 Slash 目录（`image shortcut list`）仍可读**；
**画布面（`node` / `group` / `workspace` / `project <uuid>`）才需要登录。**
**★ 用法**：**需要只读取数又没登录时，先用 `model search` / `model <name>` / `image shortcut list`**，
**别一上来就判"读不了"。**
**★ `project list` 的坑**：**它 `exit=0`，但返回 `{"projectMetaList": null, "total": 0}`**——
**"能跑"不等于"有数据"。**
