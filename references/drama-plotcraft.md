# 剧情设计的创意层：创意落在哪里、怎么落

> **何时读**：**命题与人物都定了、但还是"能拍但没意思"的时候**；写节拍之前（先想清"这故事凭什么是它"）；交付前做创意自检。
> **读完回哪**：套路素材 → `drama-tropes.md`；落到结构 → `drama-structure-models.md`；落到交付 → `script-module.md` 的 M1–M12。
> **定位**：本册补的是**全库此前唯一没建的那一层**——前几册管"结构不散、格式不乱"，本册管**"凭什么值得看"**。

---

## §0 三条前提（先认账，否则往下全是空话）

| # | 前提 | 推论 |
|---|---|---|
| **1** | **不要求突破人类已有经验** → 创意的正确形式是**选择与组合**，不是发明 | 目标从"想出没人想过的"改为"**在已验证的套路里做出别人没做出的那个组合**" |
| **2** | **创意必须落在剧情设计上才有意义** | 一个好句子不是创意，一个**只在此时此地才成立的处境**才是。**结构即修辞**：你怎么排列事件，就是你怎么说这件事 |
| **3** | **"有意思"必须能被判**，否则永远争不出结果 | 本册每条手法都带**失效条件**；§5 给十条可判自检；`key-decisions.md` 给可证伪的验收判据 |

> **一句话**：套路不是创意的敌人，**没选择的套路才是**。全世界只有两种故事（"一个人去远行"／"一个陌生人来了"），而写得好的人**赢在他选了哪一对具体**。

## §1 创意的四种来源（按性价比排序）

| 来源 | 是什么 | 为什么有效 | 训练动作（→ `drama-mastery.md` §3） |
|---|---|---|---|
| **① 具体性** | 把抽象处境换成**只有这个世界才有的物 / 规矩 / 数字 / 动作** | 具体 = 信息量；抽象 = 观众已经见过一百次 | 具体性替换（10 组） |
| **② 前提的非显而易见** | 命题本身反常识（反过来不成立） | 它决定天花板：**结构补不上前提的平庸** | 一句话前提 ×10 |
| **③ 组合** | 把 A 的**引擎**装进 B 的**材料** | 新意来自交叉点，不来自原创 | 强制关联（两领域各取一个） |
| **④ 变量变形** | 在已验套路上**只改一条规则** | 套路保证可读，改一条保证意外 | 套路变形 + 反向改写 |

**★ 性价比排序不是随意的**：**事实上一部"有意思"的片，多数情况下靠 ① 与 ②**——③④ 是锦上添花，而且**滥用会让片子显得在"玩结构"**（观众感到被耍）。

## §2 六种创意手法（**落在剧情设计上**，逐个给机制 / 落法 / 失效）

### 2.1 信息错位——谁在什么时候知道什么

**机制**：悬念不来自事件，来自**观众与角色的信息差**（三种配置，`drama-genre-casebook.md` §2 已定）。创意落点在**"错位"**：把默认配置拧一格。

| 拧法 | 做法 | 例（结构示意） |
|---|---|---|
| **把"观众知道"延后** | 让观众比角色更晚知道 → 从揪心变**惊讶** | 全片以为他在等人，最后发现**他才是被等的人** |
| **把"角色知道"提前** | 角色知道而观众不知 → 从谜题变**不安** | 他每一步都做对了，但观众不知道他为什么笑 |
| **让信息本身错位** | 交代的**不是内容，是态度** | 两个人一直在谈天气，观众看懂的是"他们在分手" |

**落法三步**：① 写下这一场**谁知道什么**（列两栏）→ ② 决定**错位在哪一刻合拢** → ③ 把合拢那一刻放在**最后 1/5**（早合拢就成了说明书）。
**失效**：错位没有合拢点 = 观众觉得"没交代"；合拢两次 = 观众觉得被耍。

### 2.2 因果倒置——先给结果，再给原因

**机制**：把"因为 A 所以 B"改成"**B 已经发生，我们看着他怎么一步步走到 B**"。
**落法**：① 用**第一镜就是结果**开场（他已经在收拾行李）→ ② 全片回答"为什么"→ ③ 原因揭示的那一刻，**不解释、只给一个之前出现过的物**。
**判据**：观众在第 2 遍看时，**前 1/3 的每个动作都变了一个意思**。
**失效**：结果不够反常（"他失恋了"）→ 观众没有"为什么"的驱动力，只剩等待。

### 2.3 视角偏移——换一个人站

**机制**：同一事件，叙述者的选择就是作者的判断。
**四种偏移**（按难度递增）：**旁观者**（路人视角看主角的悲剧）· **对手**（反派视角，他的正当性）· **物件/空间**（全片机位永不离这一间屋）· **叙述者不可靠**（他讲的是他需要的版本）。
**落法**：从 `drama-character-arc.md` §6 的四职能里**把主角挪出去一格**——让"镜子"当叙述者。
**失效**：偏移没有代价。**换了叙述者却讲同一件事 = 只是换了个说法，不是创意**；必须让**信息本身**因为他站的位置而不同。

### 2.4 代价错位——代价换一个面

**机制**：剧情设计里最有创意的一格是**代价的形状**。
**三种错位**：① 他失去的不是**他想要的**，而是**他一直没在意的那件**（观众比他先发现）② 代价**早付、晚显**（前面付了，后面才知道付了什么）③ 代价由**别人**付（他赢了，代价是他不知道的那个人在承担）。
**判据**：结尾的代价**能被一个画面指出来**（不是"他从此很痛苦"）。
**失效**：代价错位但不改行为 = 只是悲惨，不是创意。

### 2.5 规则变异——只改一条

**机制**：取一个已验证的套路，**只改一条规则**，其余全部照旧。
**落法**：把套路的变量列出来（谁、要什么、为什么不能得到、要多久、在哪），**只拧其中一个**：
- 换**目标物**（找的不是宝物，是**一句道歉**）
- 换**时间尺度**（一整个旅程压进**一顿饭**）
- 换**空间**（把远征放在**一张桌子两侧**）
- 换**失败的定义**（失败的代价不是死，是**被记住**）
**判据**：**其余零件都还认得出是那个套路**——全改了就不是变异，是另起一个故事。
**失效**：改的那条与命题无关 → 变成花招。

### 2.6 约束生成——限制就是创意

**机制**：**约束越具体，解越独特**。空手让你想"有意思的故事"，你想不出来；给你"一间屋、两个人、不许有人起身"，你能想出十个。
**五种可直用约束**：**一场景** · **无对白** · **只有一件道具** · **只允许一个动作** · **全程只有一个光源**。
**落法**：从约束反推命题（而不是先有命题再找约束）——**约束是选题工具，不是省事工具**。
**失效**：约束只是省钱借口（"省得做场景"）→ 观众感到局促而不是紧张。

## §3 具体性引擎（**本册最高性价比的一节**）

**原理**：抽象词是**已被压缩过的公共资产**，它省了你的力，也带走了你的信息量。**具体物是唯一不会被别的情境复用的东西**。

### 3.1 转换表（抽象 → 只属于这个世界的具体）

| 抽象（别写） | 具体（写这个） | 为什么更强 |
|---|---|---|
| 他很穷 | 他数完零钱把最后一枚硬币放回口袋，转身走路 | 贫穷变成**一个可拍的动作**，且带出了他的算计 |
| 她很孤独 | 她给外卖员备注"不用打电话，放门口，敲一下就行" | 孤独变成**一条规矩**，观众自己听出回声 |
| 他在等一个不会来的人 | 他每天买两瓶水，一瓶放到第二天倒掉 | 等待变成**可累积的物证** |
| 关系很好 | 他知道对方**只吃左边那半**的橘子 | 亲密变成**只有他们知道的知识** |
| 职场压迫 | 会议室的椅子比人头少一把，谁站着说话谁说得最快 | 压迫变成**空间规则** |
| 时间流逝 | 同一条街上，招牌从三层换成六层 | 时间变成**可数的物** |
| 内疚 | 他把家里的钟都调慢了两分钟 | 情绪变成**一条习惯** |
| 决裂 | 两人分处一张长桌两侧，中间那把椅子没人坐 | 关系变成**几何** |
| 权力 | 他坐着，别人站着；他先动筷子，别人才能动 | 权力变成**流程** |
| 恐惧 | 他先摸一下门锁，再摸一下门锁，第三次才进门 | 恐惧变成**节律** |

### 3.2 三条纪律

1. **一个抽象词只许出现一次**，第二处必须换成一个物。**同一处只能落一个具体物**（堆三个就互相稀释）。
2. **具体物必须能被复用**：全片至少出现两次，第二次要**变了状态**（`drama-aigc-conversion.md` §4 的三把扳手）。
3. **具体物必须只有这个世界有**——判据：**把它换到另一部片里还成立吗？** 成立 → 它还太通用，回去再拧一格。

## §4 俗套黑名单（三档，**判据是"能不能被替换掉"**）

**分档标准**：**致命** = 观众一看见就知道你放弃了；**高危** = 可以用但必须变形；**可救** = 加一个条件就成立。

| 档 | 清单 | 处理 |
|---|---|---|
| **致命（一用就烂）** | 醒来发现都是梦 · 其实早就死了 · 一切都是幻觉 · 突然下雨映心情 · 车祸造成失忆 · 绝症推动和解 · 最后打字幕解释 · 靠旁白总结主题 · 反派临死前讲动机 · 结尾问"你幸福吗" | **原则上删**（默认档）；要保留同类功能，换 §2 的任一手法，并在 M12 写明加了什么条件——与下方使用纪律对齐：致命档不是绝对禁止表，是"默认删、留要付全价"的表 |
| **高危（必须变形）** | 主角手机响了然后接电话 · 镜子里的人突然不同步 · 门被风吹开 · 停电 · 电脑屏幕上的监控画面 · 一个人对着墓碑说话 · 翻开旧相册 · 站在雨里 · 天台边沿 · 医院走廊 | **加一条规则变异**（2.5）：换目标物 / 换尺度 / 换空间 |
| **可救（加条件）** | 双胞胎 · 失忆 · 假死 · 时空循环 · 回到过去改一次 · 遗书 · 匿名信 · 忽然的门铃 | 加**代价错位**（2.4）或**视角偏移**（2.3）——同一条套路，代价换一个面就活了 |

**★ 一条使用纪律**：**黑名单不是禁止表，是"必须付代价才能用"的表**。用了就要在 M12 诊断记录里写明**"我加了什么条件"**——没写就当作没加。

## §5 创意自检十问（**交付前逐条答，答不出就回炉**）

```text
① 这个故事的专有名词全删掉之后，还剩什么？（剩不下东西 → 只是个设定）
② 换个主角，故事还成立吗？（成立 → 主角不是必需的）
③ 观众大约在第几分钟能猜到结局？能猜到就不能只靠结局（要靠过程的信息错位）
④ 主角在哪一刻做了"违背自己"的事？（没有 → 没有弧光，`drama-character-arc.md` §3）
⑤ 代价能被一个画面指出来吗？（不能 → 代价还是抽象的）
⑥ 全片有没有一个"只有这个世界才有"的具体物？（没有 → 通用件，谁都能用）
⑦ 这个题材最俗的处理是什么？我做了什么与它不同？（答不出"最俗版本" → 没想清）
⑧ 有没有一个时刻，观众比角色多知道一件事？（没有 → 没有悬念结构）
⑨ 我这次用的是哪一条已经被验证的套路？（说不出名字 → 结构是飘的）
⑩ 我改的那一条变量是什么？（说不出 → 只是复述了套路）
```

**判据**：**十问里 ⑥⑦⑨⑩ 四问是硬门槛**——这四问答不出，说明这部片**目前只是"结构齐全"**，不是"有意思"。

## 来源与署名

- **信息错位的三种配置（观众知道 / 角色知道 / 都不知道）**：类型教学通行表述——**惊悚片"生死在于信息控制"**（见 `drama-genre-casebook.md` §2 与其来源）；本册扩展为 §2.1 的三种"拧法"与"合拢点"规则。
- **叙事本质是"排列事件以产生情感与观点"（结构即修辞）**：Robert McKee《Story》通行表述（"structure is the selection and arrangement of events to create specific emotional and intellectual effects"），**只重写机制、未复制原文**。
- **"创作限制"（creative limitation：约束催生创意）**：McKee 一系的通行表述（本书"结构与背景"章的核心概念）；本册把它落成 §2.6 的五种可直用约束。**注：此前全库 grep 确认 `创作限制 / 限制原理` 零覆盖**，故本册为首次落库。
- **"全世界只有两种故事（一个人去远行／一个陌生人来了）"**：文学批评中广泛引用的概括（公开评述中常引 Quiller-Couch 一系的说法），属**惯例层**；Booker 七种基本情节与本册的呼应见 `drama-tropes.md`。
- **本库自建**：§1 四种来源的性价比排序 · §2 六种手法的机制 / 三步落法 / 失效条件 · **§3 具体性引擎与十组转换表** · **§4 三档俗套黑名单** · §5 创意自检十问（含"四问硬门槛"）。
- **诚实标注（变更记录）**：本册是 2026-09-16 用户挑战「**你确定你现在能到达能生成出有意思的剧本了吗**」之后的**补层**——此前全库逐词 grep 确认 `发想 / 头脑风暴 / 发散 / SCAMPER / 强制关联 / 俗套 / cliché / 意外性 / 新颖 / 新意 / 巧思 / 反常识` **全部 0 命中**，即"创意层"从未被建。**本册仍属惯例层：它的每条手法都还没有对照实验数据**，验收判据见 `key-decisions.md` 的 E38。
