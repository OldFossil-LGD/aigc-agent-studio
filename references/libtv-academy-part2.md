## 十、脚本节点（课 08）——批量产出的主干道

**定位**：从"基础脚本工具"升级为"**分镜故事板脚本工具**"。全链路：剧本拆解 → 角色/场景/道具资产提取 → 分镜脚本调整 → 批量生成分镜图 → 批量生成视频片段。适合**流水漫、AI 短剧、动画短片、故事分镜**。

**三项升级**：**资产化**（风格/角色/场景/道具与脚本绑定、可被提示词引用）· **可编辑**（每行、每字段、每资产可改并同步更新提示词；分镜可增删与调序）· **可批量**（自由选生成范围、生成类型、批量执行的模型类型）。

### 四步流程

1. **添加脚本节点**：双击画布或底部「+」选「脚本 new」；也可先把剧本文本放进文本节点，再从节点拉线选「脚本 new」。前置输入可以是剧本文本，或角色/场景/风格等参考图。
2. **生成分镜故事板**：把参考文本/图片节点连进脚本节点（或直接输入剧本）→ 选拆解模型，**官方推荐 CVLM5.5 或 GVLM 3.1** → 生成。产出：提取关键角色/场景/道具、把剧本拆成结构化分镜并整理每个分镜的画面信息、为后续生图生视频准备基础提示词。
3. **细化编辑** ★ **官方明确不建议直接批量生成**（会放大错误），分三步：
   - **确认镜头信息**：每行可增删、调序、标色；单元格可单独编辑；**输入 `@` 唤起资产卡片**。
   - **确认资产信息**：点「准备资产」进资产管理界面，按提示上传或生成参考图。资产＝特定人物/场景/道具的设定信息，用于提升一致性与稳定性。
   - **合成最终提示词**：点「待生成提示词」，按分镜画面内容、资产关联、整体风格合成。★ 此处提示词会进入下一环节生成器，**不满意可在生成器确认环节手动修改，不建议在此处改**。
4. **批量生成分镜图 / 视频**
   - 先选镜头与模型 → 点「确认并创建生成器组」，得到**填充了提示词、资产连线、对应参数的生成器组**；点单个生成器可查看/编辑详情（微调提示词、调整单分镜参数）。
   - 再点「**整组执行**」批量生成。
   - ★ **信息流向是"脚本 → 生成器组"，在下游生成器内改信息不会影响上游脚本节点。**
   - ★ **暂不支持分镜图直接转视频**；可**手动连接参考分镜图与视频生成器**以提升准确度。视频生成完成后可继续把片段合成为完整视频。

## 十一、3D 导演台（课 09）——"文字说不清"时的构图参考

**性质**：一个**轻量级 3D 构图节点**，在独立 3D 空间里用"摆积木"方式搭故事空间，靠**多视角截图**产出**模型能准确理解的构图参考**。

**入口**：双击画布空白处新建「导演台」节点 → 点「打开导演台」。

### 基础四步

1. **添加模型**：人体素模 / 基础几何模型 / 群众阵列 / 本地上传四种。左侧栏＝3D 空间元素清单（删除、重命名、打组/解组、隐藏/显示）；右侧栏＝所选对象属性（3D 场景、角色、人体素模、元素、摄像机）。
2. **调整站位**：三种模式 —— **移动 `V`** / **旋转 `R`** / **缩放体积 `S`**（**按住 `Shift` 等比缩放**）。选中模型可在「右侧栏-属性」调模型颜色。
3. **调整机位与截图**：
   - **机位视角**：鼠标移动相机调位置，实时预览机位内容。
   - **导演视角**：自由调视角，点底部「截图」会**自动基于当前视角新增拍摄机位后截图**。
   - **摄像机调节**：机位视角下，右侧栏「摄像机属性-**FOV**」调焦距；「摄像机属性-**注视目标**」绑定到某个角色可让镜头**自动跟随**。
4. **发送参考图**：底部工具栏相机图标「截图」。截图可有各种比例；右侧栏「摄像机」可查看所有截图，不满意可删除；满意的**发送到画布作为参考图**参与后续生成。

### 进阶

- **角色姿势控制**：选中角色 → 右侧栏「姿势」，用预设姿势或精细调各关节。
- **全景图设置**：本地上传 / 生成历史 / AI 生成获得全景图，让角色模型"身临其境"。
- **角色运动轨迹**：选中角色 → 下方「动画时间轴」选轨道 → 「绘制轨道」，或右侧「运动轨迹」。可选直线/圆形/矩形路径模板或手绘。时间轴**自动记录关键帧**，「新增轨道」可让多角色分别移动。左下「播放」或**空格**预览 → 「**导出视频到画布**」作后续生视频参考。适合短剧走位、漫剧调度、电商广告人物展示。
- **摄像机运镜轨迹**：选中机位 → 「动画时间轴」显示轨道 → 「绘制轨道」或右侧「运动轨迹」；预设运镜有**推近、拉远、横移、环绕、升镜、俯冲**。系统**自动生成运镜路径、机位高度、注视目标和关键帧**，也可指定注视角色/物体或手动指定目标点。空格预览 → 「导出视频到画布」。
- **「镜头+路径」一键跟随**：选中机位 → 右侧「属性-**跟随目标**」选角色，调**跟随距离、摄像机高度、拍摄角度、镜头范围**。播放后角色沿自己路径运动，摄像机保持距离与高度跟随。
  ★ **官方注意事项**：**角色运动轨迹与摄像机运镜轨迹不是同一条线**；角色路径可贴地，**但摄像机不能直接复制角色的贴地路径**；一键跟随本质是"打成镜头组"，由系统自动维护摄像机与角色之间的距离、高度和注视关系。

### 快捷键

模式：移动 `V` · 旋转 `R` · 缩放 `S` · 网格吸附 `X`

视角：俯视 `T` · 正面 `Y` · 重置视角 `Q`

基础：打组 `Ctrl+G` · 解组 `Ctrl+Shift+G` · 撤销 `Ctrl+Z` · 删除 `Delete`

### Blender 插件

可直接录制界面上的 3D 白模视频或截取画面，一键发送到 LibTV，无需反复下载上传。下载地址：`https://kol.liblib.tv/blender`

## 十二、Seedance 功能介绍（课 10）

### Seedance 2.5

- **一键直出 5 分钟成片**，完成度极高，**支持查看过程片段、画布剪辑**等精细化调优。
- **使用入口**：新建节点生成器 → 选「**5 分钟超长视频**」。

### 真人素材审核标准

- 正常的个人、原创影视角色素材，**通过合规校验后即可正常使用**。
- **版权内容、明星、公众人物**类素材**严格限制，通常会被拦截**。
- 通过新增的「**人像授权**」能力，可将通过检测的人物设定**加入角色库随时复用**。

### 真人素材使用场景

- **AI 演员出镜**、**虚拟主播讲解**（官方例："把 @视频1 中播报的男生换成 @图片1 中的女生"）、**数字分身创作**（需对角色完成**人脸授权**，创建为数字分身后可作为角色创建视频）。

### 合规校验（两条路径）

1. **常规素材校验**
   - **单素材**：上传或生成素材后点「**Seedance 2.0 合规校验**」，等待审核完成即可用 Seedance 2.0 生成写实真人视频；**校验通过后有专属标识**。
   - **多素材批量**：视频生成器中选 Seedance 2.0 模型 → 点顶部「角色库」进素材库 → **批量上传核验**，支持本地上传/历史图库，支持**音频、视频和图像**。
2. **真人人像授权**：视频节点中的角色库 → 选「真人资产录入」或「真人人像」→ **手机扫码，真人完成识别检测授权**，授权完成后角色创建（**创建时注意填写文件名称**）→ 在创建好的真人文件夹中上传对应真人的不同妆造图或三视图。
   ★ 后台会比对图片与真人：**同一人则审核成功**，图片上方有合规标记；**不是同一人，或图片中出现多人，则审核不通过**，该图仍无法用于生视频。可创建多个真人资产文件夹，**记得写清文件夹名称**便于查找。

### Seedance 2.0 专属提示词优化

- 作用：按官方优化改写为 **Seedance 2.0 更容易执行的结构化提示词**，降低"模型不听指令"的概率。**适合多角色的复杂场景**；**视频时长较短时可能无法完全执行优化后的扩充提示词，需适度选择**。
- ★ **仅在 seedance2.0 系列模型生效。**
- 入口：视频节点下方 → 模型选 **seedance2.0** → **提示词输入框下方**可见。
- 流程：①输入提示词完成创作 → ②点提示词优化按钮 → ③优化完成后**再次点击按钮**查看优化后提示词 → 点「**填充到输入框**」。
