# 皮肤与人物光影真实感（成因 · 解剖依据 · 判据）

> **何时读**：生成的人物"像 AI"——油亮、蜡像、高光错、褶皱假时；写任何近景 / 特写的人物光影段之前；**要写"肌理"（皮沟 / 皮纹）或疤痕时，先读 `skin-light-physics.md` §五–§七**（那里是解剖与可达成边界，本文只给判据与处方）。**读完回哪**：回 `tone-realism.md` 的「人物光影与皮肤」节（模板在那里），本文件只给**成因与判据**，不给第二份模板。

## 为什么单开一份

`tone-realism.md` 第二层已经写清了"该写什么"（哑光 / 碎高光 / 不对称 / 六选一状态）。**但那层全是现象描述，没有一处回答"为什么模型会错"和"怎么判它错了"**——于是两个后果：

1. **写不对症**：知道要写"哑光"，但不知道油脂感来自**模型把皮肤当不透光材质**，于是只在形容词上打转（"不要油亮"），模型照样油。
2. **验不了**：用户拿到"像 AI"的图，无法判断是哪一层出的问题、改哪一句能好。

本文件补这两块。**规则手册（怎么写）仍在 `tone-realism.md`；这里是诊断手册（为什么错 / 怎么判）。**

## 一、三条缺陷的成因（逐条定根因）

### 1.1 油脂感：模型把皮肤当成了"不透光的均匀材质"

**根因不是"写少了哑光"，是模型缺了一层物理。**

真实皮肤的反射约 **只有 6% 来自表面直接反射，94% 来自次表面散射（SSS）**。光进入表皮 → 在真皮的胶原纤维、血管、黑色素之间多次散射 → 从**另一个点**射出，带出暖色。这层"光进了皮肤又出来的"过程，才是活体皮肤那种柔润感的来源。

AI 默认把皮肤渲染成**不透光表面**——光只在表面弹一下。数学上等价于塑料或石膏：

| 层 | 真实皮肤 | 模型默认 |
|---|---|---|
| 表面薄反射 | 一层薄薄的油膜反光 | **整块都在这层** |
| 真皮次表面散射 | 光透进去、散开、带暖色出来 | **零** |
| 暗部偏暖 | 暗部被皮下血色染暖 | 暗部纯灰/纯黑 |

**三条可操作推论**：

1. **写"哑光"只能压住表面那 6%，治不了 94%。** 必须**同时给出次表面散射的证据句**，否则压完还是"塑料哑光"（死的、闷的、像石膏）。
2. **SSS 在正面平光下看不见**——它是"逆光 / 侧光才显形"的现象。所以光位不改，写再多 SSS 词也无用（见 §1.4）。
3. **SSS 不是全脸均匀的**：鼻梁骨近表面 → 散射弱；耳廓、鼻翼、脸颊肉厚 → 散射强；耳垂逆光透红是最强证据。**一句"全脸次表面散射"是错的**，要写**哪些部位透、哪些部位不透**。**【场景限定】脸颊要分薄厚：脸颊薄区（颧骨下缘、鼻翼侧）可写透光；脸颊大面积不写透光——大面积透光＝蜡像感**（与 `skin-light-physics.md` §3.3 同一口径）。

**次表面散射的写法（三条，按场景选一条，不要堆）**：

| 场景 | 写法 |
|---|---|
| 逆光 / 侧逆光 | `逆光从耳后打过来，耳廓边缘透出一圈红，鼻翼侧面有一点点透光` |
| 正侧光 | `侧光照到的那半个脸颊有一层薄薄的暖红从皮肤里透出来，不是打上去的`（**只写在脸颊薄区：颧骨下缘、鼻翼侧；脸颊大面积不写透光——大面积透光＝蜡像感**） |
| 环境暗、无逆光 | `暗部不是灰的，下巴底下和脖子窝里有一层很淡的暖色，像皮肤自己的颜色` |

### 1.2 高光：模型的"去噪本能"把碎高光抹成了镜面

**根因是架构级的，不是提示词级的。**

主流模型是**去噪**生成的。它被训练十几亿步，任务是**从噪声里恢复图像**。问题在于：

> **真实的皮肤微结构（毛孔、绒毛、极细的肤色变化）在数学上和噪声几乎一样**——高频、低幅、不规则。

再加上 VAE 通常做 **8 倍压缩**：在 latent 空间里，**一个毛孔大概只占 1–3 个像素**。解码器面对这么小的信号，必须猜"这是细节还是噪点"——**默认猜噪点，抹掉**。

这就是行内说的 **denoising trap（去噪陷阱）**。三个后果：

| 后果 | 表现 |
|---|---|
| 毛孔被抹平 | 高光失去打断它的东西 → **变成一整片光滑镜面** |
| 绒毛被抹平 | 轮廓失去毛边 → **边缘像剪纸贴上去** |
| 肤色变化被抹平 | 各部分反射率趋同 → **高光位置跟着乱**（因为模型没有区域差异的依据） |

**所以"高光面积过大"的根子不在高光，在毛孔。** 写"高光小一点"是治表；**写毛孔、写绒毛、写区域肤色差，把打断高光的东西还给模型**，才是治本。

**第二条根因：训练数据的偏置。** 互联网上流传最多的肖像照是**精修过的**——磨皮、美白、调色。模型学到"好皮肤＝光滑无孔"。所以写 `皮肤细腻有光泽` `完美皮肤` 这类词，是在**主动激活这个偏置**（→ `prompt-ops.md` 空话词黑名单）。

**第三条根因：菲涅尔效应被忽略。** 真实的皮肤反射率**随视角变化**——正面看反射弱，斜着看反射强。所以：

- **正面 / 平光** → 全脸反射均匀 → **一片死板油的观感**
- **侧面 / 斜角** → 反射集中在凸起边缘（鼻尖、颧骨顶、眉骨）→ **高光自然集中成小点**

**这解释了"高光位置错"的机制**：模型在平光下把反射平摊到整张脸。**解法是给斜角光，不是写"高光在鼻尖"。**

### 1.3 皮肤褶皱：模型没有解剖学依据，只能靠"平均脸"

> **★ 口径警示（2026-09-17 用户定案）：以下两张表是"验收判读"用的解剖知识，纹名禁入 prompt。**
> 不要写"鼻唇沟（法令纹）/ 额纹 / 鱼尾纹 / 川字纹"这类纹名——一提名字，模型就调用训练里"深沟"的统计印象，**越提越深**。
> **年龄改由结构承载**（鬓角白发 / 发际线后退 / 颌线 / 眼下凹陷 / 颈部）；**光位用正面平光**（皱纹是微立体结构，沟里没有影子，视觉上就不成立）。

**这是三缺陷里唯一"库里零覆盖"的。**

模型不知道皱纹长在哪。它的训练数据里，皱纹是"随机的细线"，于是它会：
- 抹掉不该抹的（年轻人脸上的动态细纹）
- 画出不存在的（额头正中竖纹、脸颊胡乱折线）
- 位置与走向荒谬（皱纹横穿鼻梁、眼下折成方格）

**真实皱纹是有解剖规律的**，分四类（来源见文件末）：

| 类型 | 成因 | 出现位置与走向 | 出现年龄 |
|---|---|---|---|
| **直立性皱折线** | 先天即有，皮肤过多 / 局部弯折 | 面颈后侧与前外侧，**横向**，仅 1–3 条 | 出生即有，随年龄变明显 |
| **动力性皱折线** | **表情肌反复牵拉** | 见下方分区表 | 随表情习惯，20 岁后起 |
| **重力性皱折线** | 皮肤松弛 + 重力 | 上睑细密纹、下睑"半月弧"、鼻颏沟外后多条弧纹、颈部 | **40 岁后**才明显 |
| **综合性皱折线** | 多因叠加 | 鼻唇沟（法令纹）等 | 随老化加深 |

**★ 一条贯穿全表的规律（这是模型最不懂的一条）**：

> **皱纹与其下方肌肉的收缩方向呈直角交叉。**
> 肌肉收得越勤，皱纹越深、方向越垂直于该肌肉。

按肌肉分组（**这是可执行的映射表**）：

| 表情肌 | 反复收缩时 | 皱纹位置 | 走向 |
|---|---|---|---|
| **额肌**（抬眉） | 抬眉 / 惊讶 | 额部，从颞窝前缘横跨到对侧 | **横行**（额纹 / 抬头纹） |
| **皱眉肌** | 皱眉 / 用力 / 疼痛 | 眉间，沿鼻侧上行到前额中下区 | **垂直**（眉间纵纹 / 川字纹） |
| **眼轮匝肌**（眼部） | 眯眼 / 笑 | 眼外眦（外眼角）起 | **放射状 / 扇形**，向外下延伸到颧弓（鱼尾纹） |
| **口轮匝肌** | 抿嘴 / 撅嘴 | 上唇先出现，后及下唇 | **垂直**，数目深浅无规律（口周纵纹） |
| **鼻根肌** | —— | 鼻根 | **短横纹**，1–3 条，不规则 |

**三个例外（Langer 张力线与表情纹不同向的地方，模型最爱画错）**：

| 部位 | 表情纹 | Langer 张力线 |
|---|---|---|
| **眉间** | 垂直 | **水平** |
| **下唇** | 水平 | **垂直** |
| **外眦** | 扇形放射 | **斜行** |

**三条可执行纪律**：

1. **先定年龄，再决定写不写皱纹。** 20 岁的人**不该有静止状态的深纹**——只该有**动态细纹**（笑的时候眼尾才起的那几条，笑完平复）。**写 20 岁的人有法令纹 = 直接判废。**
2. **皱纹必须依附于一个正在发生的表情。** 写"额头三道横纹"是死的；写"他一抬眉，额头横着绷起三道，眉一放下就淡了"是活的——**这同时解决了"褶皱不符合现实"和"人物僵硬"两个问题**。
3. **皱纹是"走向"不是"数量"。** 写"三道"没用，模型会给三道乱线；写"从外眼角向外下扇形散开、与眼角垂直"模型才知道往哪画。

### 1.4 三条缺陷的共同放大器：光位

**这是最反直觉、也最省事的一条。**

> **所有皮肤细节都在正面平光下隐形。**

- 毛孔是**微小的立体结构**——需要**斜射光**才能在开口里投出影子。平光下，光直直照进去，毛孔没有影子 → **视觉上不存在**。
- 绒毛（vellus hair）靠**边缘光 / 逆光**才显形（"asperity scattering"）——平光下完全不可见。
- 次表面散射靠**逆光 / 侧逆光**才显形——平光下无透光路径。
- 高光的**正确分布**靠**斜角**才成立（菲涅尔）。

**所以：换光位比改形容词有效得多。**

| 你要的 | 光位处方 |
|---|---|
| 看见毛孔 | **斜射侧光**（不是正面） |
| 看见绒毛 / 轮廓毛边 | **逆光或侧逆光**（背后有光源） |
| 看见次表面散射 | **逆光**（耳廓透红） |
| 高光成小点 | **斜角 + 有动机的单一硬光源**（不是大面积柔光箱正打） |

**与库内已有的连接**：`light-quality-construction.md` §「柔光 ≠ 低对比」——**主光用柔、用负补光（黑旗 / 黑绒布吸掉反弹光）拿回对比，而不是把 fill 开大**。这条正是本节的光位解法：**柔光负责"造脸"，负补光负责"留出暗面"，斜角负责"显形微结构"**。

> ⚠️ **一个常见误操作**：为了让皮肤"看得清"而**开大正面柔光**。这恰恰**同时毁掉毛孔、绒毛、SSS、和高光分布**四样。**正确的加法是"换角度 + 加负补光"，不是"加正面光"。**

## 二、皮肤细节的区域表（模型最易均质化的地方）

模型给的是**一张均匀的脸**——全脸同一反射率、同一毛孔密度。真实的脸**分区**：

| 区域 | 皮脂腺密度（每 cm²） | 毛孔 | 反射 | 该写什么 |
|---|---|---|---|---|
| **T 区**（额 / 鼻 / 鼻翼 / 下巴） | **800–900**（最密） | **粗大** | **有油光** | `额头与鼻梁有一层薄油光，毛孔在这个区域清楚可见` |
| **U 区**（两颊 / 眼周 / 太阳穴） | 稀疏（数百以下） | **细小** | **哑光** | `两颊是哑光的，毛孔几乎看不见，只有一层细绒毛` |
| 眼周 / 颧骨内侧 | 最少 | 最细 | 干燥 | `眼周皮肤最薄，有一点干纹，不许上高光` |

**两条可执行纪律**：

1. **油光只许落在 T 区。** 写 `全脸油亮` 是错的；写 `油光只在额头和鼻梁，两颊还是哑的` 才对——**"不均匀"本身就是真实感的来源**。
2. **毛孔密度必须与区域挂钩。** 一句 `毛孔清晰可见` 会让模型给全脸同样的毛孔 → 假。要写 `鼻翼两侧的毛孔看得清，颧骨上就淡得多`。

**★ 肌理（皮沟网）是同一套分区逻辑的另一层**（2026-09-16 补）：T/U 区讲的是**毛孔与油光**；**皮沟讲的是"走向"**——面部最深最复杂、四肢伸侧平行、掌跖成涡、指纹终生不变。**两者要分别写，不能互相代替。**（解剖与区域表 → `skin-light-physics.md` §五）

**第三样必须写的东西：绒毛（vellus hair）。** 极短极细（< 2mm）、几乎无色，**覆盖全脸**。它是**区分"人"与"蜡像"的关键**——因为它给轮廓一圈毛边，让皮肤边界不像刀切。**只在逆光 / 侧逆光下可见**，写法：

```
轮廓边缘有一圈极细的绒毛，逆光下每一根都挑出一丝亮边
```

## 三、可测判据（"像 AI 吗"怎么判，不靠感觉）

`ai-artifact-control.md` 九条是"生成后逐条查"的总表。**皮肤专项需要更可测的判据**——下面 S1–S6 六条，每条都能用一个具体动作验。

| # | 判据 | 怎么验（可执行动作） | 不合格 |
|---|---|---|---|
| **S1** | **高光面积 ≤ 指甲盖，且高光里有纹理** | 放大到 200% 看鼻尖 / 额头 / 颧骨顶 | 一整片光滑镜面（仍不合格）。**高光区若放大可见皮肤纹理，加分；不可见不判不合格**——模型在 VAE 压缩下做不出毛孔级细节，承诺"清楚可见"是给自己设一个过不了的门。→ 物理层见 `skin-light-physics.md`（毛孔可兑现的上限） |
| **S2** | **T 区与 U 区反射不同** | 用灰度模式看整张脸——**亮度分布是否有区域差** | 全脸一个亮度 / 全脸都油 |
| **S3** | **暗部不是灰的，是暖的** | 看下巴底下、脖子窝、耳后 | 暗部纯灰或纯黑（缺 SSS） |
| **S4** | **轮廓有毛边（绒毛）** | 看逆光处的人物轮廓边缘 | 边缘像剪纸贴上背景 |
| **S5** | **皱纹的走向与表情一致** | 找到脸上每一道纹，问"**它垂直于哪块肌肉？那肌肉在动吗？**" | 纹路乱走 / 有纹但表情是平的 / 20 岁的人有静止深纹 |
| **S6** | **肌理的走向与「年龄 / 部位」相符**（2026-09-16 补） | 问三句：**这张脸的沟纹是"清晰有规律"、"变乱"、还是"变模糊"？它所在的部位该是平行还是成网？**（面部最深最复杂 · 四肢伸侧平行 · 掌跖成涡） | 年轻人的沟纹是糊的 / 老人的沟纹走向整齐 / 四肢长了面部的沟纹——**方向写反 = 年龄写反** |

**用法**：生成后逐条过，**中 2 条以上 = 这一镜的皮肤层不合格，按 §4 的处方改，不是重抽。**

### 三·补 ★ 写实天花板：**写实永远不把脸写丑**（2026-09-17 外部学习后补 · **一手源**）

**这条是本册的总边界，先于下面所有判据**——因为本册通篇在讲"要毛孔、要不对称、要缺陷"，**很容易被执行成"把脸写难看"**。

**原则（原文）**：**"写实永远不让一张脸变丑；当哑光写实与好看冲突时，往好看解。"**
（`Realism never makes a face look ugly. Where matte-realism and flattering conflict, resolve toward flattering.` —— `cinema-director-v3` §SLOT 16）

**★ 与 §一 的关系（最容易搞混的一处）**：本册对治的是 **① 油腻感 ② 镜面高光 ③ 平均脸的塑料感**——
**它要的是"真"，不是"糟"**。所以：

| 要做 | 不要做（≠ 上面的反面） |
|---|---|
| **零油光**（额头 / 鼻梁 / 颧骨顶 / 锁骨） | ❌ **不是磨皮**——磨皮正是 §1.2 的根因（模型的去噪本能） |
| **真毛孔**（细而均匀） | ❌ 不是**放大 / 粗糙化**毛孔 |
| **自然不对称**（凡人都有） | ❌ 不是**明显歪斜 / 缺陷脸** |
| **绒毛 / 唇面 / 次表面吸收**（质感） | ❌ 不是**加重痘、斑、疤** |
