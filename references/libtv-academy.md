## 三、工作流（课 01）——本库最该内化的一课

**连线方向 ＝ 上下游关系**，"定向传递信息"。

### 搭法（官方范例：参考生图 → 图转视频）

1. 参考图上传：选中画布上要参考的图片，**从右侧拉线新建「图片节点」**，参考图自动进新节点生成器。
2. 角色设定接入：准备好的角色设定填进**文本节点**，连到上一步新节点（＝作为生成器提示词的一部分）。
3. 图像生成：在图像生成器输入需求（如"参考图1的画面风格，生成一张图片"），选模型/比例/张数/画质，生成落在当前节点。★ 不想要这么多文字节点，可把设定直接写进图片节点输入框；**LibTV 保留图片生成的全部痕迹，可随时返回查看**。
4. 视频生成：从生成好的图片**右侧拉线新建「视频节点」**，该图自动作参考，再补动态提示词，选模型/比例/个数/画质/**时长**，生成。

### 打组与工作流

- **打组**：右键拖动多选节点 → 右键打组；快捷键 `Ctrl / Cmd + G`。打组后可整体移动或整体执行。
- **创建工作流**：已打组的工作流 →「添加到工具箱」，后续在下方栏「工具箱」调用。
- **★ 限制（两处都要记）**：**分镜表不支持打组；分镜表不支持创建工作流。**

### 资产管理

- 右键节点 →「保存到我的资产」，填名称/位置/标签分类。
- 画布左下角「资产管理」可看当前画布全部节点 ＋ 你拥有的全部资产；点资产看来源与生成信息，或添加回画布复用。

### 智能引用 AutoLink

- 前提：图片/视频节点**已连上**用作参考的上游节点（即节点内已有参考内容输入）。
- 输入提示词时，若其中有与参考图相关的关键词，系统**自动在对应位置预置引用标签**。
- 触发条件：提示词与图片/视频/音频**节点名称一致或相似**；或按 **图片1、2、3** 这类数字顺序描述。
- 确认：`点击` 或 `Tab` 确认单次引用，**`Shift+Tab` 全部引用**；继续打字或点击别处＝忽略引用。确认后标签引用对象**支持切换**。

## 四、Slash 预设（课 02）——输入框打 `/` 或点生成器下方「预设」

无需额外提示词，自动执行成套操作。多数能力支持「文本」/「文本+图片」/「图片」三种输入。

| 预设 | 作用 |
|---|---|
| **多机位九宫格** | 基于已有图片生成多路取景画面，配「宫格」切分对比取景 |
| **剧情推演四宫格** | 一次生成四段连贯画面，分镜排布叙事段落 |
| **25 宫格连贯分镜** | 高密度连续画面，铺展完整连贯镜头序列 |
| **电影级光影矫正** | 优化明暗光影质感，一键院线级氛围 |
| **角色三视图生成** | 正/侧/背标准视图，供角色建模与设计参考 |
| **画面推演-3 秒后** | 基于当前画面顺延推演预判 3 秒后动态 |
| **画面推演-5 秒前** | 反向回溯，还原 5 秒前的前置状态 |
| **角色设定图** | 标准角色立绘设定，定格风格造型细节 |
| **故事板** | 把 **10–15 秒**剧情整理成可直接用于视频生成的连续分镜（拆人物表演/动作/镜头语言/衔接）；适配短剧、漫剧、广告片前期 |
| **调度故事板** | 同上，但带**动作、视线、运镜与衔接提示**的手绘分镜，补人物走位与机位调度 |

**人像调节专项**（分两块）

- **质感调节**：在生成器「人像质感调节」右侧选项按钮设置**人景融合、光影融合、皮肤、纹理、锐度**。四个官方档位：**降低 AI 感**（过度磨皮/塑料皮肤/五官边缘过硬/纹理过假）；**优化人像质感**（保留自然肤质、毛发细节、真实面部层次）；**提升人景融合**（色温/清晰度/边缘过渡自然，减少"贴上去"感）；**优化光影融合**（按场景光源调脸与身体光影，与背景一致）。
- **情绪调节**：入口在**已有内容的图片节点上方工具栏**「人像质感调节-情绪调节」。**多人图中可选指定人物，但单次仅能改一人表情。** 点右侧点位板自然精确改表情，**除表情外其余与原图一致**。

## 五、图片节点工具（课 03）——工具栏在图片节点顶部，选中已有内容的节点才弹出

### 全景 720°

- 入口：节点顶部菜单栏「全景」，或节点下方预设「720°全景」。可加额外参考图与提示词。
- 能力：拖动鼠标全方位浏览；**视角截图**（当前或预设角度，可作后续参考）；**构图参考线**；**重置视角**。
- ★ 官方坦承的失效场景：生成**空旷、无明确物体做参考的户外场景**（草原、沙漠、大海）时全景特征可能不明显。闭合处有缝、空间轻微扭曲**无法完全避免**，但对后续作参考生成影响不大；可截图后用图片模型**二次修复**。

### 多角度

- 视角设置：**三维网格坐标球**（拖相机图标或用坐标球周围四个箭头）或**数值滑块**。
- **提示词**开关：可额外加词优化视角；官方例："极度特写镜头，广角镜头，边缘带有鱼眼畸变效果"。
- **预设视角**：一键加载对应相机参数，直接生成。

### 打光

- **三维坐标球**调打光角度；**主光与轮廓光都需手动开启**。
- ★ **硬约束**：轮廓光开启后，**主光不能设在轮廓光背光点范围内**，否则轮廓光失效。
- **亮度**：滑块**变成蓝色才表示生效**；10% 暗调氛围，100% 过曝。
- **颜色**：调色板选色控主光源颜色；默认无色值，点开出调色板。
- **智能模式**（需手动开启）：走**提示词**（如"让画面拥有《赛博朋克2077》同款打光方式和画面质感"、"让画面氛围变得更加绝望、压抑"）或走**参考图**（上传打光参考图，无需提示词）。
- **打光预设**：官方 6 种，点击加载参数后直接生成。

### 图像基础编辑（「高清」下拉）

高清放大（**5 种模式**：通用、低分辨率、3D 动画、高保真、文本优化）· 扩图（可自定分辨率与张数）· 重绘（画笔涂抹＋提示词修改）· 擦除（画笔框选擦除）· 抠图（自动去背景留主体）· 裁剪。

### 宫格切分

点「宫格」选份数 → 点对应宫格**选中并批量导出、自动打组**；可拖分界线自定义分割线位置与比例。

### 标注

涂鸦笔或框选圈区域＋加文字，**标注信息会保存，可直接让 AI 按标注生成图像**。★ 官方建议：删除/修改画面内容时，提示词加 **"修后不可以留下任何标注痕迹"**。

### 旋转与镜像

输入旋转角度或鼠标拖动旋转，任意角度旋转与镜像翻转。

### 分镜组（专用"打组"）

- **快捷键**：`Command + Option + G`（Mac） / `Ctrl + Alt + G`（Windows）。
- **三条创建路径**：①框选多张图片节点 →「打组」→「合并分镜组」（按数量自动生成宫格布局）；②普通组（含图片节点）→「转分镜组」；③「宫格切分」完成后→「创建分镜组」。
- **工具栏功能**：比例切换 · 宫格数量（**减少宫格时多余图像自动解组排到右侧**）· 拼接（合并为一张大图；**组内图像宽度不足时导出被强制放大而非自动高清**）· 序号（右下角显示）· 清空（**移除组内所有图像节点及连线，谨慎使用**）· 转普通组 · 解组 · 右键常规操作。

## 六、视频节点工具（课 04）——入口在视频节点「上方工具栏」

| 功能 | 入口 | 要点 |
|---|---|---|
| **视频高清** | 工具栏「高清」 | 单个视频高清放大＋帧率提升；**「慢放倍数」控制慢动作，数值越高越慢** |
| **片段重拍** | 工具栏「片段重拍」 | 时间轴选一个或多个片段，用文字描述每段要改什么，**局部重绘** |
| **智能续写** | 「片段重拍」下拉 →「智能续写」 | 时间轴自由选续写起点＋后续描述，**可加新的参考图/视频**；在延续原片人物、场景、风格基础上续写 |
| **逐帧拉片** | 工具栏「逐帧拉片」 | 从**叙事分镜、运镜动态、音频配乐**多维分析，拆成可复用创作要素 |
| **片段截取** | 「逐帧拉片」下拉 →「片段截取」 | ★ **限制：时长 ≤10 分钟、分辨率 ≤1080p、格式 Mp4** |
| **深度动作捕捉** | 「逐帧拉片」下拉 →「深度动作捕捉」 | 选分辨率→提取→深度信息视频**以节点形式落在画布**作下游参考；**动作/运镜参考不再受原风格元素干扰，更稳定** |
| **音视频分离** | 工具栏「音视频分离」 | 拆成无声视频节点＋独立音频节点 |
| **人声/背景音分离** | 「音视频分离」下拉 →「人声提取」/「背景音提取」 | 分离干净人声或背景声 |

**片段截取快捷键**：移动选区 `←/→`（长度不变、位置左右移）· 扩展/搜索选区 `↑/↓`（**0.1s** 单位）· 精确模式 `Shift`（**0.01s** 单位）· 设出点入点 **`I`/`O`**。

**智能剪辑（4 种预设）**

- **讲解视频**：输入参考音色、文稿或一句话主题，无需出镜生成讲解视频。
- **批量广告**：输入产品信息与目标场景，一次直出多条带货视频。
- **口播视频**：自动去口水词与停顿，加人物画中画、高亮文字动效、转场、字幕。
- **素材混剪**：多素材自动卡点、视觉聚焦剪辑。

## 七、音频节点（课 05）

- **音频截取**（工具栏「截取」）、**音频变速**（「变速」）。
- **智能/自定义切分**（「智能切分/自定义切分」）：智能切分按歌词与节拍自动切；自定义用文字表述需求，官方例："**截取0-3s，在8s处断开，删除10-12秒。**"
- **音色克隆**
  - 使用：新建音频节点 → 模型选 **Minimax Speech** → 高级设置 →「切换音色」→「我的音色」。
  - 克隆：右下角「切换音色」→「我的音色-克隆新音色」。
  - ★ 朗读建议：**安静环境、清晰、语速适中，尽量读 115s 以上**；**朗读时带入情绪**，克隆出的音色会带该情绪。
  - 生成后先用短文本试听，重点检查：与原音色相似度、是否清晰无杂音糊音爆音、语速是否稳定、听感自然、情绪表达是否到位。
  - ★ **创建音色后 7 天内未使用会被 MiniMax 官方 api 清除 → 建议创建完立刻使用一次，即可永久保存。**

## 八、图像生成器进阶（课 06）

| 功能 | 入口 | 要点 |
|---|---|---|
| **元素标记** | 生成器「标记」→ 沉浸模式（`Esc` 退出） | 在画布**任意图片**上点要提取的元素，系统**自动识别并命名**、框出并**自动引用进生成器**；完善提示词后生成 |
| **风格模板** | 生成器「风格」→ 风格库 | 分类浏览＋关键词搜索（摄影写真/电商营销/动漫游戏等），点风格**标签自动填入生成器** |
| **镜头聚焦** | 生成器「聚焦」→ 沉浸模式（`Esc` 退出） | 单图上框选→生成该画面**细节特写分镜**；可加提示词优化表情/动作/角度 |
| **摄像机控制** | 图片节点**右下角镜头图标** | 设相机型号、镜头、焦距、光圈；**「摄像机」会自动引用进生成器** |

- **风格模板适用模型（UI 口径）**：General Image pro、General Image V2、Seedream5.0 lite、Seedream4.5、Z-image Turbo、Seedream4.0 等。
- **自定义风格模板**：加 **5–20 张同风格图**学风格，发布为模板后快捷调用；前往 `https://www.liblib.art/ai-tool/upload-template` 上传，**审核发布后**在风格库搜索调用。适用模型：General Image Pro / V2、Seedream5.0 lite、Seedream4.5 等。
- **官方示例**（General Image V2）：提示词"专业人像摄影，一个美丽的中国女孩…黑色无袖上衣，长发披肩，头顶戴黑色墨镜，面带微笑。背景是沿海大道，天气晴朗。"；相机 **Sony Venic**、镜头 **Helios**；三组参数依次为 焦距125mm/光圈 f11、焦距125mm/光圈 f4、焦距35mm/光圈 f4。

## 九、视频生成器进阶（课 07）

### 视频主体库（★ UI 口径：**目前适用模型为 Kling O3**）

1. 右键图片或视频节点 →「创建主体」。
2. 补全主体视图：**用图片可上传多张；用视频仅支持单段视频**；可用「智能补全」生成其他视角图。
3. 补全**名称、音色、描述**。音色可用本地上传或历史生成的音频/视频自动生成。★ **描述不只作备注，会被系统自动拼接到提示词中参与生成**；可用「智能生成」一键填充。
4. 使用：视频节点点「主体」→ 选主题 → 输入提示词 → 生成。

### 运镜

- **官方预设**：视频节点「运镜」→ 预设库，点预设后补提示词生成；悬停点「★」收藏，存入「我的收藏」。
- **自定义运镜**：「自定义」输入运镜提示词并保存复用。
- ★ **三条官方提醒**：①**运镜必须与提示词里已有的画面描述相适应**，否则冲突失效（例："高空航拍"会与画面里"近距离、特写"冲突）；②预设提示词**普遍宽泛**，不同模型表现可能不一，画面复杂或主体动作幅度大时运镜效果不佳；③在预设之外**额外补"镜头与主体、环境的关系描述"，用"首先、然后、最后"有序描述**，有助于模型处理效果提升。
