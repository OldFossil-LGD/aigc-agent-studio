# 音效设计：**方法**（不是词表）

> **何时读**：要设计一个"画面里没有的声音"、要让声音有远近、要把一堆音效分层而不糊成一团时。
> **读完回哪**：**取词**回 `sound-lexicon.md`（那边是词表，本册是方法）· **配额与能量曲线**回 `sound-craft.md`。
> **★ 单一权威源**：**词表在 `sound-lexicon.md`，方法在本册**——两边不许互相复述。

---

## §1 ★ 频率分工表（**本册核心表**）

**每一种声音在频谱上"住哪一间"，决定了它能不能被听见、要不要让路。**

| 层 | 作用 | 典型声 | **它的频段** |
|---|---|---|---|
| **环境层** ambience | 造气氛、给"世界存在感" | 风、室内底噪、远处车流、环境循环 | **20–500 Hz（低中）** |
| **拟音层** foley / diegetic | **把动作按在物理现实里** | 脚步、门轴、物件触碰、衣物摩擦 | **200–8000 Hz（中高）** |
| **界面/交互层** UI | 给反馈、引导注意 | 点击、提示音 | **1000–12000 Hz（高）** |
| **音乐层** score | 情绪叙事与节奏 | 音乐、动态主题、张力提示 | 全频 **20–20000 Hz** |
| **签名/冲击层** impact | 制造记忆点与强调 | 爆炸、特殊能力、揭示、转场 | 全频 + **超低** |

**★ 具体到单个声（可直接用）**：
- **枪声的冲击力在 80–120 Hz**（低频）；
- **金属碰撞的清脆感靠 8–12 kHz**（高频）。
  → **反推的用法**：想"更重"就往下加，想"更脆/更亮"就往上加；**两头都加，中间就空了**。

**★ 频率心理（三条）**：
- **超低（sub-bass）→ 力量、危险、重量、不祥**；
- **中频 → 人声与日常信息所在，"接地"且直接**；
- **高频 → 闪光、空气感、紧张、刺耳**（用过头就是"刺"）。

> **来源**：站点社区技能 `sound-design-basics`（一手，含上面这张表）；`muhou.net` 影视音效解析（枪声/金属频段）；
> `wavstock.com` 电影声音设计指南（频率心理三条）。**三源互不矛盾**，**记「拟订」**。

## §2 ★ 分层法：一个"声音"从来不是一个文件

**判据一句话**：**"这个声音，我叠了几层？"答"一层"＝大概率业余。**

**示例（未来飞船降落，五层）**：
```text
① 低频轰鸣   → 重量与力量
② 金属呻吟   → 机械受力
③ 风声/空气位移 → 运动
④ 高频啸叫   → 引擎能量
⑤ 轻微电流嗡鸣 → "有技术在里面"
```
每层**单独处理**，再混成一个整体。

**★ 起手式（三件套，任何"设计声"都能用）**：
**一个低频（重量）＋ 一个中频（材质）＋ 一个瞬态（攻击）**。
**瞬态（transient）是声音的"起初那一下"，它决定冲击力与清晰度**——**没有瞬态，声音就是"糊"的**。

> **★ 与"三层规划"的区别**：`sound-craft.md` §三 讲的是**全片要规划三层（环境/拟音/硬效）**；
> 本册讲的是**单个声音内部要叠多层**。**两个"层"不是一回事，别混。**

## §3 ★ 建场顺序（**从零搭一场戏的声音**）

**照这个顺序走，不要跳**：

```text
⓪ 先标静默位 → 这一拍要不要"什么都不响"？（静默是选择不是遗漏，见 `sound-lexicon.md` §6）
① 先铺环境床（room tone / ambience）
   → 它决定"这场戏在哪"，且它在所有东西底下；没有它，对白一停就是"数字静音"，耳朵立刻觉得假
② 再加同步硬效与拟音（与画面动作严格对齐）
   → 脚步按表面与步态配（硬跟走瓷砖 ≠ 软底走地毯），门是"把手 + 铰链 + 一记低沉的合体"
③ 最后把三者送进同一个混响，让它们共享空间
   → 滚掉环境床一点高频，让它退到前景之后；
     对白进来时把 room tone 自动降一点，让字清楚
```

**★ 判据一句话**：**"这三个声音，是在同一个房间里发生的吗？"**
干声丢进混响走廊＝一眼假；**共享混响＝它们才在同一个地方**。

**★ 前景/中景/背景三层摆位**：点效放**前景**（贴着听者）· 环境放**中景** · 远声放**背景**；
**用混响与延迟制造纵深**（洞穴里的拟音混响多于小厨房）。

## §4 四个"让声音活起来"的手段

| 手段 | 怎么做 | 什么时候用 |
|---|---|---|
| **自动化**（最实用） | **音量**（渐强/骤降）· **滤波**（低通缓开＝"清晰起来/浮出来"）· **效果**（混响干湿扫、延迟反馈爬升） | 静态声音显得死；**"浮出来"用滤波比用音量更高级** |
| **侧链压缩** | 用一个声音把另一个压下去（**音乐在对白下让路**） | 音乐与人声抢位置时（`sound-craft.md` §五 有阈值/比率/起音/释放的具体值） |
| **音高操纵** | **降调 → 加重、威胁**；**升调 → 紧迫、空灵**；极端降调＋拉伸＝"非人化" | 例：一记钟声降调拉长＝鬼魅般的持续音 |
| **音色操纵** | 失真 / 饱和 / 合唱 / 镶边 / 相位 → **改谐波内容**；颗粒合成 → 破碎重组 | 想让熟悉的声音"变陌生但仍认得出"时 |

**★ Riser（上行音）与转场**：**电影感的"要有大事了"靠的是"爬升 → 交付一击"**。
爬升的手法：音高上行 / 力度渐强 / 滤波缓开 / 节奏加密（**选一到两个，不要全上**）。

## §5 心理声学三件（**看不见但有效**）

1. **次声（< 20 Hz）**——人耳听不见但**身体能感觉**。加一条不规则脉冲的次声，**有研究报告称可诱发不安感，效果因人而异**。→ **恐怖/不安场景的底层手段**（**边界**：手机 / 笔记本扬声器与普通耳机基本不回放 <20Hz——消费级播放链路上该效果对多数观众不存在，只当创作意图，不计入可验收的声音层）。
2. **谢巴德音（Shepard tone）＋ 滴答**——制造"**持续升高却不落地**"的紧张感（《敦刻尔克》就是把谢巴德音效与时钟滴答结合）。
3. **动态范围本身是情绪**——**爆炸可到 115 dB SPL，细语只有 30 dB**；**巨大的音量落差要"不让人难受"而保留动态余量**。
   → **反过来的纪律：不要把整场都推满**——**都响＝没有重点**。

## §6 ★ 八个常见错误（**逐条可查**）

| # | 错误 | 为什么错 | 修 |
|---|---|---|---|
| 1 | **忘了 room tone** | 音效之间的**真数字静音**，耳朵一听就知道不对；底床还能藏剪辑点 | 全场铺一条连续环境床 |
| 2 | **什么都满音量** | 都响＝没有重点，且对白被淹 | 先决定"这段该听什么"，其余全部退后 |
| 3 | **声音不共享空间** | 干声丢进混响走廊 = 假 | 匹配混响与 EQ，让它们住进同一个房间 |
| 4 | **只用一个库素材** | 同一个 whoosh/impact 到处都是，会被认出来 | **叠加 + 变调 + 组合**（§2 的分层法） |
| 5 | **在错的系统上混** | 笔记本小喇叭听不见低频轰鸣与刺耳高频 | 监听/耳机，且**至少换一个设备回听** |
| 6 | **脱离画面设计** | 单独听很惊艳，放进那一秒完全不对 | **永远对着画面工作** |
| 7 | **音色分层同频打架** | 多层都住同一频段 → 糊成一团 | 按 §1 分工表**给每层指派频段** |
| 8 | **从头到尾一个响度** | 没有"安静"就没有"爆发" | 写能量曲线（`sound-craft.md` §3.2） |

**★ 时间预期（防"以为很快"）**：**一分钟精修的电影声音，可能是数小时的选材、对齐、分层与混音。**

## §7 ★ 拟音工艺：**怎么把它录出来**（2026-09-18 补）

> **适用边界**：本章与下一章（ADR）是**实拍 / 传统后期工艺**的背景知识——用来理解"好声音长什么样"、并反推音效提示词怎么写；AI 工作流里的对应做法（生成音效 / TTS 重配 / 分离清理）见 `sound-craft.md` §八与 `audio-tools.md`，画布里没有"录拟音"入口。

**拟音（Foley）＝ 对着画面表演并录制**——脚步、衣动、道具、身体接触。
**它替换的是"同期麦克风抓不干净的那层身体声"**。做对了它让画面**住人**；做错了它听起来**像贴上去的一段表演**。

### 7.1 ★ 道具替换表（**专业拟音师用厨房和花园的东西**）

| 画面上的声音 | 用什么替 | 怎么用 |
|---|---|---|
| **雪地脚步** | 布袋里的玉米粉 | 跟着画面节奏按与放 |
| **碎石脚步** | 浅盘里的碎石 | 穿合适的鞋原地走 |
| **草地脚步** | 新鲜卷心菜叶 | 在砧板上扭与压 |
| **骨折** | **芹菜杆** | 靠近麦克风掰断 |
| **关节响** | 皮袋里的核桃 | 用力挤 |
| **身体倒地** | 大书落在地毯上 | 从 6 英寸高落下以匹配冲击 |
| **布料移动** | 皮手套互搓 | 贴近麦克风搓 |
| **火噼啪** | 揉皱的蜡纸 | 慢慢揉 |
| **滴水** | 湿麂皮布 | 对着碗按节奏挤 |
| **马蹄** | **半个椰子壳** | 在硬表面上敲出疾驰节奏 |
| **打拳冲击** | 湿毛巾拍地 | 为瞬态而脆 |
| **门吱呀** | 吱呀的铰链或皮带 | 慢慢拉出那声吱呀 |
| **玻璃碎** | 金属盘里的碎冰 | 倒下去并散开 |
| **泥里走** | 硬表面上的湿海绵 | 按压并拉出吸吮声 |

> **★ 这条表真正的价值不是"照抄"，而是让你相信"任何声音都做得出来"**——
> 后面遇到表里没有的，**问"这声音的物理本质是什么"**（脆？黏？重？），再去厨房找。

### 7.2 ★ 脚步的三个维度（**录制前先定"谁在走"**）

| 维度 | 重的人 | 轻的人 |
|---|---|---|
| **重量** | 落地更平更硬、低频更多、接触时间更长 | 更软更亮，**多用脚尖** |
| **鞋** | **硬皮鞋＝清脆咔哒**；**橡胶运动鞋＝钝的噗**；**赤脚＝软拍、几乎没有高频** | 同左 |
| **意图** | 自信的阔步 / 紧张的碎步 / 狂奔——**节奏与压力都不同** | 同左 |

**★ 关键纪律**：**把这三个维度在录制前定好，让它驱动每一个选择**——
**做对了，后期几乎不需要 EQ 和变调；做错了，后期怎么修都像另一个人。**
**★ 拟音是一种表演，不是录音。** **"演那个情绪，而不只是对时序"**——这一步区分了可信的拟音与"节拍器一样的同一声响"。

### 7.3 ★ 录制：**脚步永远录"干"的**

- **不要在反射空间录**——房间自己的混响会被烤进去，**之后无法把角色重新定位到别处**；**空间留到后期加**；
- **麦位**：**大振膜电容（U87 / C414 一类）在动作上方 30–50 cm、心形指向**——
  太近会夸大表面质感，太远会收进太多房间反射；**衣动与道具**用小振膜电容或 SM7B 这类动圈（更亲密、更收敛）；
- **要有一个"坑区"放多种地面**（混凝土 / 碎石 / 木 / 地毯 / 大理石 / 泥 / 沙）——
  **表面选择是每次拟音的第一个创作决定**（既匹配画面，也决定麦克风收上来的共振）；
- **每一类元素单独一轨**（脚步 / 衣 / 道具），**每个 cue 用时间码与场次命名**；
- **录 3–5 遍**，每遍换一点视角（留选择）。

### 7.4 ★ 同步容差与回听

> **同步拟音先对齐画面接触与声音瞬态**，再按听点、帧率与交付要求回听。原 **2 帧**保留为本库试调参考。
> 原“比 2 帧更紧显得机械”与“全行业通用”的断言撤回，册内未给出支持这两条判断的可复核标准。
> 有意的画外声、声画异步与对位按 `sound-narrative.md` 的方案安排。

→ **推论**：**同步是帧级的活**，不是"大概对上"。**画面里物件落下的那一下，瞬态就该落在那一帧。**

### 7.5 分层（让一次冲击有深度）

```text
① 瞬态层（锐利的攻击）—— 那一下"啪"
② 体层（重量）—— 闷响
③ 低频层 —— 超低冲击
④ 尾/混响层 —— 空间
```
**★ 脚步的分层**：**脚跟撞击（主闷响）＋ 擦/趾（起身与移动的小质感）**；
**再叠一层表面质感**（碎石咯吱 / 叶子沙沙）——**这一叠就能把同一个角色"搬"到新环境**。

### 7.6 干净剪辑（**这一步决定"专业感"**）

- **topping and tailing**：切掉每条 clip 前后的静音与噪声；
- **★ 每一条 clip 都加几毫秒的淡入淡出**——**这是防爆音与咔哒的最佳防线**；
- **降噪要"温柔"**：**过度降噪会把生命抽走，剩下又薄又假**——目标是"让它沉进混音里听不见"，不是"消灭干净"。

### 7.7 拟音常见错误

| 错误 | 为什么错 | 修 |
|---|---|---|
| **在"活"的房间里录** | 房间混响被烤进去，**后面无法重新定位** | 录干；空间后期加 |
| **只有一层** | 单层听起来薄、假 | §7.5 四层 |
| **不对着画面表演** | 变成"配一段脚步声"而不是拟音 | **对着画面演**，按 §7.4 的项目同步要求校 |
| **一个 take 到底** | 没有选项，也就没有性格 | 录 3–5 遍，每遍换视角 |

## §8 ★ 对白剪辑与 ADR（**先修，再补**）

### 8.1 ★ ADR 的边界（**最重要的一条**）

> **ADR 是用来处理"这一句根本没法用"的工具**（完全漏录 / 需要改词 / 现场出了大问题）。
> **它不是用来补救"拍的时候没注意声音"的工具。**
> —— 同理：**"不要用 ADR 替代好的同期声。"**

**★ 上 ADR 之前的顺序（不可跳）**：
```text
① 先试清理：iZotope RX 的频谱修复 / 降噪 / 去混响，能救回"惊人地差"的素材
② 逐句按**可懂度**判断（不是按"听着别扭"）
③ 穷尽清理手段之后，才排 ADR
```

### 8.2 ADR 的录法五条

1. **安静空间**（衣柜挂满被子就够）——**目标是干掉回声、录成"干"的**；
2. **★ 匹配麦克风**：同期用枪麦就用枪麦；同期用领夹就**用领夹或摆成模仿领夹视角的枪麦**——**一致性决定能不能混为一轨**；
3. **小段循环**：**不要整段重来**，**逐句对着画面**——这是拿到"活的"而不是"机器人"表演的关键；
4. **★ 追情绪，不只是追口型**：
   > **"完美同步但情绪平的 ADR，比略松但情绪真实更糟。"**
5. **加回 room tone**：**这是让它自然坐进音轨的"看不见的胶水"**——不加，每一刀都会像音频版的跳切；
   **（现场每个场地至少录 30 秒 room tone——`sound-post-pipeline.md` §8）**

### 8.3 对白剪辑要做的五件

**一致性剪辑**（挑最能用的那一条）· **每一刀交叉淡化** · **每个空隙用 room tone 填** · **宽带 + 频谱降噪** · **刺耳处去齿音**。
> **★ 顺序纪律**：**对白永远第一步**——**"对白是混音的主干，其他一切都围着它建。"**（`sound-post-pipeline.md` §5 Step 2）
