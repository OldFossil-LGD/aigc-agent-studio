# 人物与弧光：从三维到弧光的完整链条

> **何时读**：建人物、建对手、建班底时；人物"平"或"做出不像他做的事"时；设计弧光时；诊断"情节剧感"时。
> **读完回哪**：冲突的运动机制与动机工具箱 → `drama-conflict-craft.md`；表演层 → `character-depth.md`；档案八字段 → `character-sheet.md`；一致性 → `character-continuity.md`。
> **分工**：**本册管"这个人是什么、他往哪变、对手凭什么配得上他"**（剧作设计）· `character-sheet.md` 管"经历怎么落成可写的可见物"（档案）· `character-depth.md` 管"此刻脸上身上怎么动"（表演）· `direction-reasoning.md` 管"这条线推出什么机位景别"（镜头）· `character-continuity.md` 管"全片五条线不漂"（跨镜追踪）。

---

## §0 一句话地基：人物创造情节，不是相反

**换掉一个人物，情节就换了。** 哈姆雷特换罗密欧，朱丽叶已经嫁给帕里斯；"哈姆雷特犹豫时，罗密欧正在行动"。
**俄狄浦斯若不暴躁，不会杀陌生人；不固执，不会追查；不诚实，不会自刺双目。**
→ **判据**：**把主角换成另一个性格的人，故事还成立吗？** 成立 → 他是"功能位"，不是人物。

## §1 三维（Egri）：三组必须问过的问题

| 维 | 问什么 | 它决定 |
|---|---|---|
| **生理** | 性别年龄体态外表缺陷遗传 | 他能做什么、不能做什么 |
| **社会** | 阶层职业教育家庭宗教种族地位政治娱乐 | 他"该"做什么（社会规训），也是他反抗的对象 |
| **心理** | 两性生活与道德标准 · **个人前提与目标** · 挫折与重大失望 · 性情 · 情结 · 内外向 · 能力品质 | 他会怎么选 |

**四条**：① **心理是前两者的产物**——同一结论必须能被两维以上支持；② **作者须知道，但不必写进剧本**——**经由行动传达**；③ "乏味 / 脸谱化 / 千篇一律"**都源于缺维度**；④ **人物＝生理条件与环境影响之总和**，且**一切都是变化的**（正题外部要求 / 反题人物欲望 / 合题结局），并**证明"为什么一定是她"**（排除所有其他可能）。

> **补一维（2026-09-30）· 声音形象**：语速 / 句长 / 口头禅——台词侧的个体锚；写剧本时落在台词清单，生成时对接 `sound-craft.md` 的声线母档（TTS 同写规则见该册）。

## §2 ★ 编排与对立统一（**决定"戏有没有张力"**）

**编排（orchestration）**：**人物之间必须彼此对立**——性情、思想、语言都能分开。
- 全是恶霸 = 只有鼓点的交响乐。
- **必须知道每个人物的"具体类别"**："坏"到底是**说谎者**还是**杀人凶手**？"雨"是**毛毛雨**还是**狂风暴雨**？——**类别不明，人物就糊**。
- 编排好了，**言辞自动就有差异**（专横／顺从、严谨／撒谎、责无旁贷／毫无责任心）。
- **单字性情词**（中式工艺，可直接用）：给每个角色写**一个字的性情词**（烈／恨／愚／狡／戆／侠／忠／智／贤／怜），**再看他张口第一句是否落实了它**——两部结构同型的戏能靠"启口便烈、启口便恨"彻底分开。
  **自检**：写不出单字词 → 这个角色还没定型（功能性过场人物不必）。

**对立统一（unity of opposites）**：**真正的对立不可能妥协。**
- 双方必须被**爱情 / 家庭 / 合同 / 秘密 / 怀疑**紧密绑定，**只有一方的主要特性"消亡"才能打破**。
- **缺乏动机的犯罪 = 只有对立，没有统一**；**合理的动机才能把对立建立起统一**（与讨厌的继父同住，因为怀疑他杀了父亲；把财富分给孩子后自己无法生存）。
- **对手与主使人物必须一样强大、意志同样坚定**，且**不仅个性冲突，意愿也必须分歧**。

## §3 维与太阳系（麦基）

- **维 = 矛盾**：深层性格之内（负疚沉重的野心），或**人物塑造与深层性格之间**（魅力四射的小偷）。**必须连贯一致**——**"好人踢一次猫"不算维**。
- **反面教材**：把爱好堆成清单（金融＋霹雳舞＋空手道＋萨克斯）＝**平板怪癖清单**。
- **主人公必须最多维**，否则**"善之中心"偏移**（反派比主角多维 → 全片哑炮）。
- **太阳系**：**主人公是太阳，配角是行星，小角色是卫星**；配角的存在**完全为刻画主人公的维**；**小角色只给一个特征**——**加了维，就必须再出现**（**群像 / 多主角剧的例外**：退化为**轨道交点图**——每条线各有维，交点处互为催化，"唯一的太阳"不成立）。
- **三诀窍**：为演员留余地（**AI 流程中对象错位：改为给模型留一致性余地**——锚点句与参考素材留出可复现的余地）· **热爱你的所有人物，尤其坏人** · **人物就是自知**（"如果我是这个人物"的那个诚实回答总是对的）。

## §4 主角（五条硬规格 + 两件工具）

| # | 规格 | 判据 |
|---|---|---|
| 1 | **有比生命更重要的欲望，且正处在紧要关头** | 说不出来 → 观众不会跟 |
| 2 | **移情（像我）绝对必要；同情（可爱）可有可无** | 麦克白靠"良心"取得移情，他并不讨人喜欢 |
| 3 | **能力可信 + 至少一次机会 + 追求到背景与类型的极限** | 他办不到的事，观众会走神 |
| 4 | **主动推进而非被动应答**（可以问，但剧情不能靠"等答案"推动）；**救猫咪**：出场做一件让人喜欢他的事 | 全靠问问题与等待 → 主角在等别人推动 |
| 5 | **风险测试："他得不到，将失去什么？"** 答"回到正常" → **这个故事不值得讲** | —— |

**Egri 的补充**：**没有意志薄弱的人物，只有没找准临界点的作者**——图书管理员三十年后一句玩笑杀人；**"每一个活物都有能力做任何事，只要压力足够巨大"**（在其生理 / 心理条件内——§1 的"生理"维就是这条的边界：生理条件做不到的事，压力再大也不成立）。**主使人物成长幅度较小**（戏开始前他已做完决定，只剩最后几步）。

**两件工具**：
- **逐一否定法（选主角用）**：列出这个题材里**所有现成的主角类型**，各写一条否定理由，**剩下那个才是本题材特有的主角**（否"义民领袖"——个性不独特；否"清官"——必落窠臼；否"有史可考的官吏"——难展示主题；剩下"罢考鸣冤的秀才"）。
  **自检**：**写不出三条否定，说明你还没看清这个题材与同类题材的区别。**（真人传记类只有一个可能主角时不适用。）
- **女性主角十阶段弧**（逐段可拍）：与母性角色分离 → 遇男性智者 → **斩三怪兽**（双头龙＝工作与孩子；食人魔暴君＝外在公司与内心"不惜代价"；甲胄骑士＝"会有男人来解决一切"的幻象）→ 识破"女超人"幻象 → 对国王说不、也对自己说不 → 遇病痛中的母亲 → 与"野蛮女人"再结合 → 祖母蜘蛛医治母女分裂 → 慈爱的内在男人 → 职场与家庭双圆满。**目标是平衡，不是"死在神圣里"。**（**适用面限定（2026-09-30 补）**：十阶段弧与 §6 弧光四型分属**成长过程的分步拆解**与**结局形态分类**两个抽象层——十阶段弧是**可选的分步工具**，不必与四型逐段对表。）

## §5 ★ 对手（**七条，全部可判定**）

| # | 规格 | 来源与判据 |
|---|---|---|
| **1** | **对抗力量必须配得上主角**——"主人公及其故事的智慧魅力与情感魄力，必须与对抗力量相适应" | 对抗力量是**各种力量的总和**，不只是坏蛋；**激励事件当刻，主人公应该是"战败狗"** |
| **2** | **★ 负面进展四层** | **正面 → 相反价值**（不公平）**→ 矛盾价值**（非正义）**→ 负面之负面**（**貌似正面的负面**：假装爱的恨、自欺并相信、貌似英勇的怯懦、貌似自由的奴役）。**"其他一切相等时，一部作品的伟大在于作者对负面的处理。"** 故事虚弱 → **先构筑负面之墙** |
| **3** | **对手必须更强、资源更多**；**对手的故事早已在进行，主角是闯入者** | 主角的准备**必然失败**，最后只剩他自己 |
| **4** | **报应必须等同罪过**，且**最好死在主角手中、方式要有戏剧性**；**英雄必须亲手打败坏人**——由警察或旁人解决 = **阴影未整合**（**道德论证型结局例外**：可由**代价 / 揭示**代替肉身击败，见 §9 道德论证的可反驳性） | 想留续集就留一扇门 |
| **5** | **给每个坏人一个"过度补偿背后的自卑"** | 观众的情绪会从嫌恶转为**怜悯与嫌恶的混合**；坏人的三种写法：戴面具的纯阴影 / 温和面具下的第二自我（医生·伯爵·旅店管理员→施虐者）/ 黑色英雄（好人面具＋暴力方法） |
| **6** | **每个主要角色有弧光；反派自身不经历弧光，但可被逐层揭示** | 反派是**同一人的正反两面**；揭示层级可递进而反派内在不变；反派**略强于主角**，其"维"不得超主角 |
| **7** | **障碍 ≠ 对手**：**对手是"表现主题"的那个人** | 纯物理障碍不是对手；对手的**目标必须与主题相关** |

**★ 给对手一把"刀"（中式：艺术加减法）**：加强对手、减弱主人公的有利因素。
- 对手手执**剔肉尖刀**；给对手**三把刀**（美色 · 弱者的哀求 · 情感自杀的威胁）；让主人公**去年输过他**。

**★ 对手配置的三种失误（诊断用）**：

| 失误 | 症状 | 修法 |
|---|---|---|
| **先天不足** | 对手不斗自垮（开后门的老婆＋儿子出事故） | 让对手**理直气壮**（儿子残疾却搞科研盈利数万） |
| **后天不良** | 对手咄咄逼人，刚交手就掉转枪头（弃儿原来是相亲姑娘的私生子） | 重设对手的目标 |
| **人为折腾** | 对手不存在，却让主人公死去活来 | 立真对手，或改成悲剧 |

**★ 最强的对手往往是自己**：哈姆雷特的对手不只是暴君，**更是自己性格的弱点**；一个人一台戏也能成立（从性格内部找对手）。
**★ 不许请"祥云"**：**对手过分强大时，不许用"上级电话 / 公文 / 视察"把一切化解**——"戏不够神仙凑"曾扼杀整整一个时代。**判据**：若对手战胜主人公**本质地反映了生活真实**，**就写悲剧**。

## §6 弧光：四型 + 三条发动机 + 一条幅度

**四型（选型决定可拍性）**：

| 型 | 定义 | AI 可拍性 | 外化手法 |
|---|---|---|---|
| **A 正向** | 放弃谎言，得到真正需要的 | 中 | 首尾**同构图**，他做相反的事 |
| **B 负向（堕落）** | 更紧地抓住谎言 | **高** | 同一动作做三次，一次比一次更狠 |
| **C 平弧** | 他不变，世界被他撬动 | **最高** | 别人的反应证明；主角只需保持一致 |
| **D 幻灭** | 看清真相，代价是失去幻想 | 高 | 一个揭示性的可见证据 |

> **跨镜呼应的落地方式（2026-09-30 补）**：本表"首尾同构图""同一动作做三次"等手法**跨镜必须经引用节点 / 首尾帧显式传入**（构图锚图、动作截帧 → 作下镜首帧参考）——**文字不构成跨镜记忆**，只写"和开头一样"模型不会复现。

**三条发动机**：
1. **种子必须在第一句台词或第一个动作里**（"不用找钱了" · 偷吃一块马卡龙）。
2. **错误连锁：每一个错都由前一个错生出来**，不是并列的四个错。
3. **麦基弧光五步**：铺陈人物塑造 → **选择揭示真相** → 内外冲突对照 → **压力递增、选择更难** → 高潮时人性被改变。
   **★ 推论**：**改事件就是改人物；改人物必须再造结构。**

**★ 一条幅度判据（动摇型人物专用，极准）**：
> **"他若完全不动摇，便没有悲剧；他若动摇到底，便成了否定人物。"**
**动摇是结构必需品**：既是悲剧的发动机，又必须**留有回头的余地**。
**自检**：**他每一次退让之后，观众是否还愿意等他回来？**（这条管的不是主角自己，而是**被主角牵动、替观众承受怀疑的那个人**。）

**★ 结局 ≠ 解决**：**解决**＝"发生了什么"；**结局**＝"接下来会怎样"——**让观众看到主角已经改变**。若无人改变，故事就没有完成。

## §7 压力下的选择 = 唯一能证明"他是谁"的东西

**人物塑造 vs 人物真相**：外貌职业说话方式是塑造；**真相只在他做选择的那一刻（尤其在压力下）暴露**——"他选故他在"。
**揭示原则**：**主要人物的内心绝不能和外表一样**。
**三条操作判据**：① **选择必须是两难，不是善恶**（两选项都要付代价）——善恶对立的选择不揭示人物；② **选择必须不可逆**；③ **结果必须立即可见**（一个动作、一个物件状态、一个位置改变）。

## §8 关系网：四职能 + 四位一体

**四职能**（可兼任）：**主角** · **对手/阻力** · **镜子**（让主角看见自己）· **触发者**（把他推过不敢越的线）。
**四位一体（荣格）**：**英雄 · 阴影 · 智者 · 爱的对象**——**三者各自都要在剧本里有对应人物或象征，且各自都改变了主角**（缺一个，弧光就少一条腿）。
**阿德勒四型作班底**：英雄（有益）/ 盟友（逃避）/ 坏人（统治）/ 帮凶（接受）。
**唯一判据**：**每比较一对角色，就要对主角做一次新的区分**——两个配角只差"一个好人一个坏人"＝**功能重复**，删一个。

---

## §9 道德论证：故事底下那句话

**由高潮的执行方式说出，不由台词说出**；**必须可被反驳**；**短片里只能是"一次支付的行动"**（他松手 / 没松手 / 换了一条路），不是一段领悟。
**两条纪律**：**命题不许被说出口**（说出来戏就变说教）· **主题不变，变的是主角对它的态度**。

## §10 短片的三条压缩法（心理活动一律外化）

| 心理状态 | 不要写 | 写成 |
|---|---|---|
| **犹豫** | 他犹豫很久 | 手伸出去又收回；杯子被推回去一寸 |
| **隐瞒** | 他在隐瞒 | 他回答的是**上一个问题**；把东西转向自己 |
| **关系断裂** | 他们关系不好了 | 两人**不再同框**；同一张桌中间空出一个人的位置 |
| **改变** | 他终于改变了 | 做**开场做过的那件事**，用相反的方式 |

**判据**：删掉这句心理描写，**只看画面能不能推出它**？能 → 它本来就不该进提示词。

## §11 自检（十四条，逐条答）

```text
① 把主角换成另一个性格的人，故事还成立吗？
② 三维填了吗？每个人物的"具体类别"是什么？（"坏"是说谎者还是杀人凶手）
③ 每人一个单字性情词？第一句台词落实了吗？两个人物同型吗？（同型 → 合并或删）
④ 主角有比生命更重要的欲望、处在紧要关头吗？是他自己行动还是只做反动作？
⑤ 风险测试：他得不到会失去什么？（答"回到正常" → 不值得讲）
⑥ 主角与对手被什么绑定而无法妥协？对手比他强吗？对手的目标与主题相关吗？
⑦ 负面进展到第几层了？敢不敢走到"负面之负面"？
⑧ 反派够坏吗？有过度补偿背后的自卑吗？报应等同罪过吗？是主角亲手打败的吗？
⑨ 有没有请"祥云"？如果对手本该赢，敢不敢写悲剧？
⑩ 弧光型是哪一个？种子在第一句台词里吗？错误是连锁的吗？
⑪ 动摇型：他每次退让后，观众还愿意等他回来吗？
⑫ 四位一体齐了吗（阴影/智者/爱的对象都改变了主角）？
⑬ 人物说得出"为什么"吗？还是只有形容词？
⑭ 结局 ≠ 解决：观众能看到"接下来他的生命将不同"吗？
```
