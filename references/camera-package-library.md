## 一、根本判据：器材回答的是"这是谁拍的"

动笔前先答一个问题：

> **这是谁拍的？拿什么拍的？在什么条件下拍的？**

三个问题必须能答出**唯一一个答案**。答不出，模型就替你答——**它永远选"高饱和 + 浅景深 + 云台般稳定 + 处处补光"**，因为那是训练数据里最像"大片"的样子，也就是最重的 AI 味。

"谁拍的"不是修辞，它一次性决定六件事——**六轴一次选定、整片不换，这就是方案包**：

| 六轴 | 决定什么 | 写错的后果 |
|---|---|---|
| **载体** | 手机 / 家用机 / 转播机 / 胶片机 / 数字电影机 / 虚拟棚 | 载体与画面观感打架（写"偷拍"却给了影棚主光） |
| **画幅** | 4:3 / 1.37 / 1.66 / 1.85 / 2.39 / 9:16（**艺术意图写法**，照写没问题）——**落地**按 `platform-matrix.md` §7.4：平台固定值只有 `16:9 / 4:3 / 1:1 / 3:4 / 9:16 / 21:9`，另有 **`adaptive` 自适应**（图生视频默认，按首帧比例取**最接近值**）。故 `2.39 → 21:9`、`1.85 / 1.66 / 1.37 → 16:9`；**有首帧时直接留 adaptive 即可** | 画幅是年代的指纹，错了年代就散 |
| **光质** | 现场光 / 硬闪 / 棚光 / 屏幕光 / 柔光（**五种造法**） | 光与载体不匹配 |
| **清晰度** | 锐到刺眼 / 边缘崩掉 / 整体发软 | 太干净是最常见的破绽 |
| **稳定度** | 固定 / 手持 / 轨道 / 片门晃动 | 写"稳定"会得到云台感，那是假的 |
| **色彩工程** | 直出 / 印片模拟 / 漂白 / 磁带色偏 | 时代与质感对不上 |

## 二、三个档位（选包先选档）

| 档 | 包 | 真实感从哪里来 | 什么时候用 |
|---|---|---|---|
| **低端档** | P01–P06 | **器材不够好带来的缺陷**（噪点、过硬的高光、畸变、不稳） | 当代题材、纪实、社交媒体、目击、恐怖（监控） |
| **胶片档** | P07–P12 | **介质自身的物理**（颗粒、宽容度、片门、划痕） | 年代戏、文艺、传记、任何要"影调浓"的题材 |
| **数字档** | P13–P17 | **镜头的光学性格**（老玻璃的柔、变形的眩光、大画幅的浅景深） | 现代类型片、广告、科幻、动作 |

> **反直觉但最关键的一条**：**"不够真实"往往不是器材不够好，而是器材太统一、太干净。**
> 低端档是**提升真实感最快的一档**——它们自带"不完美"，而不完美正是判定真假的依据。

## 三、十七个方案包

### 低端档（P01–P06）

#### P01 · 手机随手拍
- **拍摄故事**：一个人掏出手机，随手录下眼前正在发生的事。
- **器材**：现代手机主摄（等效 26mm，固定光圈）· 机内直出，不套胶片模拟 · 画幅 4:3 或 9:16 竖屏
- **痕迹**：景深很大（前后都清楚）、画面边缘轻微桶形畸变、暗部有彩色噪声、高光直接硬裁成白没有过渡、皮肤被算法抹过却保不住纹理、夜里手抖会糊
- **运动**：手持不稳、走路时上下颠、数码变焦是一跳一跳的
- **适用**：当代题材、偶然目击、偷拍视角、社交媒体语境；反"摆拍"最有效

#### P02 · 家庭 DV / MiniDV（2000 年代）
- **拍摄故事**：家里买了台摄像机，谁拿着谁拍。
- **器材**：2000 年代家用 CCD 摄像机 · 电动变焦镜头（等效 40–400mm）· 磁带记录 · 画幅 4:3
- **痕迹**：宽容度低——亮处直接爆成一块白、暗处死黑；可见彩色噪点；高反差边缘有紫绿彩边；颜色偏品红；整体比现在"糊"；**强光会拖出垂直的淡条纹（smear）、高光周围晕开一块（blooming）**；拍细密条纹（百叶窗、格纹）时出现锯齿或摩尔纹；**机器发热后暗部会冒出稀疏白点**
- **运动**：手持抖动 + 数码变焦推拉，偶尔自动对焦拉风箱
- **适用**：家庭录像、千禧年回忆、伪纪录片

> CCD 的专属破绽（**smear 垂直拖尾 / blooming 高光扩散 / moire 细纹锯齿 / 热噪白点**）与写法见 `carrier-artifacts.md` §一。

#### P03 · VHS 录像带
- **拍摄故事**：一台录像机在录电视，或者一盘放久了的带子。
- **器材**：模拟磁带（VHS），亮度与色度分离记录 · 画幅 4:3
- **痕迹**：分辨率低、**强色向相邻区域渗出去（红色最明显）**、颜色左右错位、强色块顶部无色而下沿被染、高对比边缘有彩色镶边、横向条带噪声滚动、画面整体垂直抖动、色调偏品红发脏
- **运动**：轻微水平抖晃与行同步不稳
- **适用**：80–90 年代、模拟恐怖、失落的影像

> **红色最能触发这一包的招牌痕迹**；五条机理（出血 / 下垂 / 彩虹边 / 点蠕动 / 条带）见 `carrier-artifacts.md` §二。

#### P04 · 监控 / 行车记录仪
- **拍摄故事**：一个固定在墙角的摄像头，没人管它。
- **器材**：固定安装的安防摄像头 · 超广角（等效 2.8mm）· 红外补光 · 低码率压缩 · 画幅 4:3 或 16:9
- **痕迹**：广角畸变把直线拉弯、对比极高、红外夜视是灰白的、动作有拖尾、暗部出现压缩块、时间码叠在角落（★ 时间码 AI 直出必画成乱码/错位——后期贴）
- **运动**：机位完全固定；只有画面里的人动
- **适用**：恐怖、犯罪、悬疑；"看不到全貌"的压迫感

#### P05 · 直播 / 现场转播
- **拍摄故事**：转播车里的导播正在切机位。
- **器材**：多台 ENG 转播摄像机 · 长焦电动变焦 · 电子感强 · 画幅 16:9
- **痕迹**：亮而偏冷、锐化过度、几乎没有浅景深（前后都实）、高光是电子感的纯白、颜色准但不美
- **运动**：机位之间硬切、平滑的推拉与摇摄（跟着导播走）
- **适用**：体育、庭审、突发新闻、真人秀；"这是真的在发生"

#### P06 · 网络摄像头 / 视频通话
- **拍摄故事**：一个人坐在电脑前，跟你视频。
- **器材**：笔记本内置摄像头（等效 24mm，固定对焦）· 画幅 16:9
- **痕迹**：低照度噪点、压缩块、正面无立体感（光只来自屏幕）、脸被广角推近变形、背景里可能有屏幕反光
- **运动**：固定；只有人动
- **适用**：当代、异地、监控式亲密、恐怖（对方身后有什么）

### 胶片档（P07–P12）

#### P07 · Super 16mm 手持纪实
- **拍摄故事**：一台小机器扛在肩上，跟着人走。
- **器材**：Super 16mm 摄影机（Aaton / ARRI SR 系）· 变焦或定焦 · Kodak VISION3 7219（500T）· 画幅 1.66:1
- **痕迹**：颗粒明显且随曝光变化、宽容度高（亮暗都保得住）、景深大（背景不容易虚）、画面有片门晃动与轻微划痕毛絮、色温可以故意不平衡
- **运动**：手持，有重量，呼吸感明显
- **适用**：纪实、低成本剧情、传记、街头

#### P08 · 35mm 胶片剧情
- **拍摄故事**：一部正常预算的剧情片，用胶片拍。
- **器材**：**35mm 胶片摄影机**（ARRI 435 / Panavision 那一类片盒机）· 定焦 · Kodak VISION3 500T · 柯达 2383 印片收尾 · 画幅 1.85:1 或 2.39:1
- **痕迹**：暗部有成簇的有机银盐颗粒（粗）、中间调细；高光平滑滚降、过曝处仍带暖色；高反差边缘有红橙光晕；暗部带一点青蓝
- **运动**：机械片门晃动，稳定器上仍有呼吸
- **适用**：年代戏、文艺、剧情长片；**胶片档最不容易出错的起点**（起点≠默认包——默认包身份已取消，"三问答不出"不自动用它，见 `equipment-selection.md` §四）

#### P09 · 65mm 大画幅史诗
- **拍摄故事**：一台巨大的摄影机架在轨道上，拍一片风景。
- **器材**：65mm 胶片摄影机（或 IMAX 规格）· 大画幅定焦 · 低速胶片 · 画幅 1.43:1 或 2.2:1
- **痕迹**：颗粒极细（底片面积大、放大率低）、影调极密、层次多、景深很浅（要收光圈才勉强够）、暗部几乎不塌
- **运动**：轨道与摇臂，慢而稳；景物的位移看得出来
- **适用**：史诗、自然、战争全景、仪式

#### P10 · 16mm 黑白高颗粒
- **拍摄故事**：一台旧机器，装黑白胶片。
- **器材**：**16mm 胶片摄影机** · 定焦 · 高感黑白负片 · 画幅 1.37:1
- **痕迹**：颗粒粗得像沙、对比高、灰阶不到十级、高光容易糊成一片白、有划痕与毛絮；**颗粒是"动"的、在画面上爬，并且吃掉细节**；暗部发浑、黑位**微微抬起**不是纯黑
- **运动**：手持或三脚架都可以
- **适用**：战争、极端处境、记忆、贫穷；黑白天然取消了"好看"这条退路

> **★ 胶片包通用原则：细节与颗粒"一起失去"**——不许在锐利的画面上盖颗粒，眼睛能看出只做了一半。见 `carrier-artifacts.md` §三。

#### P11 · Super 8mm 家庭影像
- **拍摄故事**：爷爷在 1978 年的院子里按下快门。
- **器材**：Super 8 家用摄影机 · 固定镜头 · 彩色反转片 · 画幅 4:3
- **痕迹**：颗粒极大、暗角明显、色彩不稳（偏黄或偏红）、曝光在镜头内波动、画面整体发软；**反差被压缩得很窄**（反转片没有宽容度）；**细节几乎全部溶进颗粒里**
- **运动**：手持抖动、片门跳动让画面上下晃、对焦常不准
- **适用**：家庭记忆、年代闪回、私人影像、失落的过去

#### P12 · 三色带工艺（1930–50 制片厂彩色）
- **拍摄故事**：黄金时代的制片厂，用三色带工艺拍的彩色片。
- **器材**：三色带摄影机（或数字模拟该工艺）· 定焦 · 强光棚 · 画幅 1.37:1
- **痕迹**：原色极饱和（红尤其浓、像颜料）、对比高、影调浓稠、黑很实、肤色偏暖橙；布光是棚内大平光加硬侧光
- **运动**：轨道与摇臂，工整，不手持
- **适用**：黄金时代、歌舞、童话、彩色的幻梦

### 数字档（P13–P17）

#### P13 · 大画幅数字 + 现代定焦
- **拍摄故事**：一台现代数字电影机配最好的定焦，拍得很干净。
- **器材**：ARRI ALEXA 35 / Sony VENICE 2 · Cooke S4/i 或 Master Prime · 数字底 · 柯达 2383 印片模拟收尾 · 画幅 2.39:1
- **痕迹**：宽容度高（17 挡）、自然肤色、干净、景深很浅、几乎无噪点——**正因为它最干净，也最容易显假**，必须靠光和刻意的缺陷来救（见 §四 调制层）
- **运动**：稳定器或轨道，可控
- **适用**：现代类型片、广告、剧情；**这是原先把全库写死的那一套**。⚠️ **它不再是"默认包"**——只是数字档的起点之一，**且用它必须叠一层调制**（`ai-artifact-control.md` 自检第 8 条："太干净"本身就是破绽）

#### P14 · 变形宽银幕
- **拍摄故事**：一台装了变形镜头的机器，站在街对面远远看着一个人。
- **器材**：ARRI Alexa Mini LF · 变形宽银幕镜头（40 / 50 / 75mm）· 数字底 · 画幅 2.39:1（横向挤压后展开）
- **痕迹**：水平椭圆焦外、横向蓝紫眩光（拉成光条）、轻微横向色散、景深很浅、画面轻微桶形畸变、逆光时眩光明显
- **运动**：缓慢横移或跟拍
- **适用**：都市夜、科幻、孤独、暴力美学；"远远看着一个人"

> **★ 这一包真正的价值不在眩光，在"距离"**（2026-09-12 深研修正）：
> 变形镜**用长焦的焦距，给到广角的横向视野**——所以拍同一个构图，**摄影机可以站得比球面镜近一倍**。
> **近一倍的距离，观众是能感觉到的**：脸的立体感、演员的呼吸、身体与镜头的空间关系全都变了。
> 所以写这一包时，**不要只写"椭圆焦外 + 光条"那套表面特征**，要写**距离**：
> `摄影机离人物很近，几乎贴到身前；人物从画面里"凸"出来，与背景分离得很干净`。
> **横向光条的色偏可以按品牌写**：Panavision 偏暖琥珀 · ARRI Signature 更冷更中性 · Hawk 是 1980–90 年代那种蓝条。

#### P15 · 老玻璃（古董镜头）
- **拍摄故事**：一台现代机身，前面拧了一枚 1960 年代的镜头。
- **器材**：现代数字机身 · 老镜（Cooke Panchro / Super Baltar / Helios 44 等）· 画幅 2.39:1 或 1.85:1
- **痕迹**：中心清楚、画面边缘明显发软并崩掉、对比低、发暖、抗眩光差（一点光就糊成一片）、部分镜头会旋焦（背景转圈）、焦点有呼吸；**遇到亮处会"发光"**——老的单层或早期多层镀膜挡不住内部反射，于是出现**大面积的纱状眩光、彩色的鬼影、高光周围一圈发光的 halation**
- **运动**：手持或轨道；焦点比现代镜头难保
- **适用**：怀旧、私密、年代、梦境；"有脾气的玻璃"

> **★ 方法论（一句话，本轮从一线实践里提炼）**：
> 摄影指导选老镜，是**"在选用像差，而不是修正像差"**（choosing to use the aberrations, not correct for them）。
> 所以写老镜**不许写"抗眩光""边缘清晰"**——那是把老镜写成了现代镜，等于白选。
> **要主动把缺陷写成正向特征**：`边缘的软是刻意的；炫光就是这一包的底色`。
> **另一条工程提醒**：老镜**组内个体差异大**——所以「一片一包」不只是风格纪律，也是**连贯性纪律**：混用不同镜头组，剪辑时看得出不一致。

#### P16 · 高速升格
- **拍摄故事**：一台高速摄影机，把一瞬间拉成好几秒。
- **器材**：高速数字摄影机（1000fps 级）· 大光圈定焦 · 需要强光 · 画幅 1.85:1
- **痕迹**：运动被拉慢——水花悬停、尘埃漂浮、发丝停在空中；景深很浅；因为要大量补光，画面常偏亮偏棚
- **运动**：极慢，几乎静止地"流过"
- **适用**：广告、爆点、诗意的瞬间、暴力的瞬间

#### P17 · 虚拟制片 LED 棚
- **拍摄故事**：演员站在一圈 LED 巨幕里，背景是实时渲染出来的。
- **器材**：数字电影机 · 定焦 · LED 巨幕实时背景 · 画幅 2.39:1
- **痕迹**：**背景的光真实地打在演员身上**（这是它最大的价值）；屏幕边缘可能有摩尔纹与轻微色偏；屏幕自身亮度有限，暗部背景会发灰；景深自然
- **运动**：与实拍无异
- **适用**：科幻、环境不可能实拍的题材、大场景

## 四、四个调制层（叠加在任意包上，不单独成包）

| 调制层 | 怎么写 | 什么时候加 |
|---|---|---|
| **漫射滤镜** | 白（Pro-Mist / Glimmerglass）→ 到处发光、抬黑位、乳白；**黑（Black Pro-Mist）→ 只在有光处发光、黑位不抬** | 写实夜戏选**黑**；1980 年代梦幻感选白。细节见 `cinematic-look.md` 第四节 |
| **漂白效果** | `类似漂白：高对比、整体去饱和，只有皮肤保留一点暖色` | 战争、极端处境、冷酷题材 |
| **颗粒强度档** | 无 / 细 / 中 / 粗——**与画幅联动**：65mm 极细 · 35mm 细 · 16mm 中 · Super 8 极粗 | 选了包就自动确定；**不要另写"加颗粒"** |
| **升降格 / 抽帧 / 曝光层** | 升降格＝升格拉慢、降格加速（**必须写帧率意图**`把这一秒拉成四秒`）；**抽帧**＝按低帧率拍或生成（完整写法 → `style-library-anthology.md` G05）；**曝光层**＝长曝光与光绘（G13：在所选方案包上再加一句曝光时间） | 只有叙事需要时才加；**抽帧与升降格不叠同一镜** |

> **★ 选完包之后：怎么挑、怎么抄、别踩什么坑 → `camera-package-quickref.md`**（三问定档定包 · 氛围词直查表 · 三套可直接复制的成套句 · 五条纪律与失败模式）。**2026-09-17 拆卷**：原册顶格 300 行，本册从此只承载"有哪些包"（判据／档位／17 包／调制层），现 **216 行 / 余 84**。
