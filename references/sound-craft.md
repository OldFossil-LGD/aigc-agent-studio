### 一·补 ★ 声线母档：**声线也要上锚点**（2026-09-17 外部学习补）

**缺口**：本库把**脸**（身份锚点句）与**物**（统一提质层）都锁成了逐字复用的固定文本——**唯独声线没锁**。
后果实测过：同一个角色**每场戏的嗓音都不一样**（同一条声线描述，模型每次给出来的音色都在飘）。

**规则**：**每个说话的角色一份声线母档，写一次，之后每次他开口就逐字粘进【声音】块，永不重写。**走平台 TTS 时，**声线母档＋当句台词一并写入 TTS 节点 prompt**（平台要求逐字台词与音色/语气同写，→ `libtv-official-qa-part6.md`）。

**★ 模板**：
```
[年龄]岁的[地域/职业]。
[音色；音域范围（耳语—满声）]。
[语速与说话方式]；受压时[声音在哪里破 —— 断层线在哪]。
```

**★ 三条纪律**：
1. **与台词绑在一起贴**：说话者的声线描述紧跟他的那句台词，**不要放在块首笼统列**——不绑，模型会张冠李戴。
2. **逐字复用、不许近义替换**（与身份锚点句同规：`沙哑` ≠ `粗哑`，换词＝换声）。
3. **别只写情绪标签**：`愤怒地说` 只给了情绪，没给音色；**音色先定，情绪后加**。

```
❌ 只给情绪：他愤怒地说："把门关上。"
✅ 声线 + 台词：他的声线——低、干、语速慢，受压时尾音会往上飘。
   他的台词，只此一句："把门关上。"
```
> **证据强度（`governance-law.md` L4·补2）**：**弱多源**（273 份语料里 4 份含 `timbre / vocal passport` 类做法）。
> **机制可独立论证**：**与"身份锚点句逐字复用"是同一条铁律**——模型没有记忆，凡是要跨镜稳定的东西都得固定成文本。
> **状态按 L6 记为「拟订」**。**来源**：`acting-skill` §8（一手，原件见 `outputs/higgsfield_skills_原件/`）。
> **机检**：`audit_prompt.py blocks` 对「【声音】块里有台词、却没有声线描述」报 WARN。

## 二、口型同步

**两条路线，别混着用**：

| 路线 | 什么时候用 |
|---|---|
| **生成时带口型**（即梦 / Seedance、可灵、Runway、Sora） | 台词短、正脸、单人、场景可控——一次成片省管线 |
| **先生成画面再后期对口型**（可灵对口型、Sync.so、Hedra、LatentSync） | 已有画面要换台词、多语配音、台词较长 |

**中文口型的失败根因**：闭唇音 `b/p/m`、卷舌 `zh/ch/sh/r`、儿化与轻声超出默认模型；
默认参数易"张嘴滞后"。
**修法**（以下两组参数仅适用于外部对口型工具——LatentSync / Sync.so 类；本平台生成节点不暴露）：开音素级对齐；口型延迟补偿 **−60 ~ −90ms**；唇动幅度 **0.65–0.78**；强制闭口帧插值；
音频先降噪、16kHz、峰值 −3 ~ −12dB、句尾留 0.3s 静音（本行为外部预处理规格，平台无对应入口）。
**不支持**：侧脸 >30°、遮挡、动物、插画。

### 二·补 生成时带口型的写法（2026-09-13 补 · 多源一致）

**四条配套指令（可直接抄进提示词）**
```
natural lip sync to the exact spoken line        ← 按确切台词同步
speaker faces camera for the line                ← 说这句时面向镜头
mouth movement matches the words without exaggerated expression   ← 口型匹配、表情不夸张
no extra speech after the quoted line            ← 台词之后不再说话
```

**对白写法（公式）**
```
Speaker: [谁]. Line: [确切台词]. Delivery: [语气 / 语速 / 情绪]. Timing: [什么时候开始说].
```
- **台词照写进提示词**是平台官方示例的做法（可灵官方示例：`who says, "Forget the crazy diets…"`）
- 本库既有的**语速停顿标注**（`低声哽咽+缓慢："……"`）保留 —— **只写台词不标语速停顿，口型必翻车**

**★ 台词预算（先算，再写）**
- 英文 **≈130–150 词/分钟** → **8 秒内 ≤15–20 词**（含自然停顿）
- 中文沿用本库算法：**3.5–5 字/秒**（`studio-workflow.md` 第一步判据）→ **字数 ÷ 5 ≤ 镜时长**
- **一句一镜**；一镜两句话＝直接超预算

**★ 景别是口型的第一调节旋钮**：**特写对口型时机压力最大，中景 / 中近景更宽容**。
台词稍长时 **先换景别（近景 → 中景），再考虑拆镜**（→ `feasibility.md` 复核表）。

**⚠️ 不采的说法**：某来源称"**绝对禁止引号**，引号会触发视觉文字渲染导致字幕"。
**不采**——可灵官方示例与多份教程**都在用引号**，且其"机制解释"属伪技术话术。
**可采的低成本做法**：**显式写一句"无字幕 / no subtitles"**（无害，且能压画面内文字）。

## 三、音效（分镜阶段就要规划三层）

> **★ 要写具体声音词（环境床 / 拟音 / 硬效 / 人声 / 设计声 / 空间混响）→ `sound-lexicon.md`。** 本节管**结构与配额**（哪一层该在、每层写多少），那份管**词**（这个词叫什么）；**取词流程与其四步法也在那边**。

| 层 | 内容 | 音量定位 |
|---|---|---|
| **① 环境底噪**（room tone / atmos） | 每场必做，场景的"空气" | 最低 |
| **② 拟音**（foley） | 脚步、衣物、道具触碰 | 中 |
| **③ 场外事件声**（off-screen） | 门响、远处车、雷、金属声 | 按需点缀 |

**提示词公式**：`[主体/动作] + [材质/表面] + [环境/声学] + [情绪]`

**★ 同步拟音与点效的挂靠公式（2026-09-13 补 · 多源一致）**
```
在[可见动作]发生的确切时刻添加[声音]，保持[音量/风格]。
```
> **适用边界**。本公式用于需要与可见动作同步的拟音和点效。画外事件、环境床、主观声与设计声按声源、听点或叙事职能安排，见 `sound-narrative.md` §2–§4。
> 例：`在产品瓶盖合上的确切时刻添加轻柔的点击声，保持微妙且真实`
> **自查**。同步点效是否对齐对应动作，画外声与非写实声是否有明确的声源关系或叙事用途。

**★ 环境声的作用（一句更好用的表述）**：
> *"环境声决定了一个片段是像**被放置在真实世界**中，还是像**被贴在一片寂静**上。"*
→ 与本库"室外人声必须带环境底噪"同向，但这句更能说明"为什么必须有"。

```
重靴缓慢踩在碎玻璃与砂砾上，仓库般的混响环境，颗粒粗粝、近距离录制
```

- 用**拟声词**（thud / crash / whoosh / hiss / zap）；指定时长（短促一击 vs 长延音）；
  可加负向（`no music, no talking`）。
- **复杂音效要分层生成再叠**：低频 boom + 中频 crack + 高频 sizzle。
- 工具：ElevenLabs SFX、Stable Audio 2、即梦 3.5 Pro（自动识别画面音与远近声场）——工具版本以 `audio-tools.md` 核验日为准。

### 3.1 ★ 声音行的配额与互斥检查（分镜阶段就查）

分镜的"声音行"要像图层一样**分类给出**，且遵守两条配额：

| 类别 | 写什么 | 配额 |
|---|---|---|
| 对白 / 旁白 | 逐字锁定 | — |
| 现场音（拟音） | 脚步、衣物、道具触碰 | 每类 **≤5–8 个关键词** |
| 环境床（atmos） | 房间底噪、远处城市、风雨 | 同上 |
| 音乐 | 按当前声音方案写明配乐、音乐驱动或无配乐 | — |

**两条硬规则**：
1. **每类不超过 5–8 个关键词**——太多会互相稀释，模型抓不住主次。
2. **不得自相矛盾**——写了"安静"就别再写"嘈杂"；同一镜里不能既"空旷回响"又"吸音闷响"。

> 这与我们已有的"声音七层"是**互补**关系：七层管**结构**（哪一层该在），配额管**密度**（每层写多少）；**上面"三层"＝七层中现场声维度（环境底噪 / 拟音 / 场外声）的子分层**。

### 3.2 ★ 全片能量曲线（写节拍表时就画）

声音与情绪要有**弧线**，不是每镜都给满。可用一个粗略的能量值标法：

```
开场 2–3  →  铺垫 5–6  →  蓄势 7  →  高潮 8–9  →  收束 9–10（**收束 9–10 仅限高潮式结尾**；常规结尾按"先收后放"回落，见下两条）
```

**最有效的动态技巧是对比，不是强度**：
- 先稀后密 · 先慢后快 · 先低后高；
- **"先耳语、再咆哮、再回到耳语"**——从亲密到全力再到脆弱，是最稳的一张情绪地图；
- **静默是一件乐器**——留白的位置比塞满更有效。

> 配合"结尾留白"使用：整片要有"先收后放"，最后一镜的克制才立得住。

## 四、配乐

- **能力**：Suno v5/v5.5（长 prompt、8 分钟、可出分轨）、Stable Audio 2（纯器乐、训练数据可商用）、ElevenLabs Music（授权最干净）、Lyria。（**工具版本核验日 2026-09；现行版本以 `audio-tools.md` 为准**——版本号会过期，能力类别不会。）
- **写法**：结构标签 `[Intro][Verse][Chorus][Outro]`；五要素＝**风格 + 情绪 + 节奏 + 乐器 + 场景**；
  可加 `[bpm-90][key-C-minor]` + instrumental + 负向。
- **实操**：先写**情绪地图**，按段落分别生成（不要一次整首），**生成 2–3 倍长度**留剪辑余量；
  先锁画面再用工具把音乐拉伸 / 缩短对位。
- **对白需要清晰时**，按素材回听调整音乐让位，原 **−28 ~ −24 dBFS** 保留为混音试调参考。音乐驱动路线可先锁音乐再排画面，逐拍或非逐拍剪辑依当前节奏意图决定。
- **无配乐候选**。写实纪实、对白驱动剧情、社会议题、恐怖悬念与日常切片可评估以环境音或静默承载。题材名称不自动决定配乐取舍，明确要求的音乐须保留。

## 五、混音与音频后期

- **三层平衡**：对白最响（峰值 −12 ~ −6 dBFS）→ 音效点缀 → 音乐垫底
  （有人声时 −28 ~ −24，无人声时 −16 ~ −12 dBFS）。（**以下 dBFS / 侧链 / EQ 数值均在外部 DAW / 剪辑工具执行；本平台合成只有线性 0–1 音量与峰值限幅，无这些入口**）
- **侧链闪避**：阈值 −20dB / 比率 4:1 / 起音 10ms / 释放 200ms（剪映的"自动闪避"＝一键版）。
- **EQ**：音乐在 2–5kHz 削 3–6dB 给人声让位；人声 2–4kHz 提；整体高通 80–100Hz 去轰鸣。
- **工具**：剪映（人声分离 / 降噪 / 响度统一 / 自动闪避）、达芬奇（AI Audio Assistant 自动铺三层、
  Dialogue Matcher 统一多段对白音色与房间感、Voice Isolation、Music Extender、Remove Silence）。

## 六、视听同步（决定成不成立）

- **声音先行**：**分路线说**——后期对口型路线，口型由音频驱动，先锁定对白与节奏再生成/剪画面；生成时带口型路线（§二），台词逐字写进提示词、音画联合一次成。**不许把"只能由音频驱动"说成全称**。
- **J-cut**（下一场的声音先入，制造期待）· **L-cut**（上一场声音延续到新画面，留余韵）。
- **声音桥**：三段不同的画面配一条**不间断**的风声，就能焊成一个连续世界。
- **跨剪辑点检查波形接缝**，需要连续时做适合该素材的淡化。原 0.2–0.5 秒作为试调参考，有意静默按叙事方案保留。
- **反转 / 惊吓点**先定揭示关系。需要同步冲击时按项目容差对齐，原 ±2 帧作为试调参考。有意的 J-cut、对位或提前提示按叙事方案回听，避免非预期泄露。

## 七、AI 短片声音的 8 个常见错误

1. **配乐盖过对白**（第一号错误）——对白播放时下调音乐。
2. **没有环境底噪**，场景"真空感"——真实世界从不安静。
3. **音效与动作错位 / 缺失**（脚步晚到）——逐帧对齐。
4. **音效太干净 / 太通用**（免费 whoosh 与爆炸包）——分层加材质与混响。
5. **混响不统一**——同场对白 / 音效 / 环境的混响不一致，立刻暴露"拼接感"。
6. **口型与语音不同步**或情绪不符（中文闭唇音缺失、张嘴滞后）。
7. **音频硬起硬停**、出现 click / pop——缺 0.2–0.5 秒微淡。
8. **克隆未授权 / 未加 AI 标识**——合规风险。

## 八、声音工作流（剧本 → 成片）

```
1 剧本期：做【声音七层表】——每场标：环境底噪 / 拟音 / 场外声 / 对白情绪 / 音乐情绪 / 静默点 / 声音桥
2 定音色：自有或已授权音色；写带情绪的台词
3 生成对白：逐句生成（便于插停顿与重生成），锁 timing
4 画面与口型：按选定的音画联合或后期对口型路线，依项目同步要求逐帧验证
5 音效分层：环境底噪 → 拟音 → 场外事件声，叠加并微淡入出
6 配乐：先情绪地图 → 分段生成 → 拉伸对位 → 决定留白（甚至全片无配乐）（**BGM 作为独立音轨在合成阶段经 audio_list 统一叠加**；不需要画面原声时 video_volume=0）
7 粗混：对白为锚 → 音乐闪避 → 音效点缀 → 降噪 → **响度统一**（**按交付渠道对表**：网络/YouTube −14 LUFS、广播 EBU R128 −23、北美 −24 —— 详见 `mix-loudness.md` §1；**−14 是播放参考、不是通用制作目标**）
8 复核：耳机 + 手机扬声器 + 闭眼听连续性 + 跨场混响一致性；加 AI 合成标识
```
