## 一、八条跨来源共识（多源独立重复 → 可信度最高）

| # | 共识 | 落地要求 |
|---|---|---|
| 1 | **关键帧先行**：先用便宜的文生图定下每镜画面，确认一致再转视频 | 必须有"故事板/关键帧 → 镜头"两层；**先出全部静态图再批量转视频** |
| 2 | **角色三视图 / Model Sheet 是工业必备**（非可选项） | 角色资产至少"定妆 + 多角度"；**任何"三视图多余"的说法都要外部佐证才采信** |
| 3 | **参考图全程复用**：从第一镜用到最后一镜 | 主锚点必须挂到 S/F/V |
| 4 | **首帧→尾帧→下一镜首帧的链式承接**是跨镜连续最强手段 | 连戏片必做；**★ 但链式超过 3 段会代际退化 → 每 3 段插一次 upscale** |
| 5 | **固定角色/场景描述块，逐字复制到每个 prompt** | **"改写＝漂移最大原因"**；每个 prompt 粘贴同一块，不要重打 |
| 6 | **最后必有一道统一调色**（抹平拼接感，**这一步不靠 AI**） | 合成步要有**跨镜色彩一致性**环节，不是可选 |
| 7 | **渐进承诺**：先用便宜方式测故事/风格，再逐步加投入 | **先跑 3 张测试风格与一致性，再批量扩** |
| 8 | **节点图要简单、有主脊**："复杂图不是技能徽章，是负债" | 收敛扇出；删死节点；两个节点干同一事 → 删一个 |

## 二、三处外部内部的分歧（按片情裁，没有唯一答案）

| 争点 | A 方 | B 方 |
|---|---|---|
| **资产要不要进镜头层** | **要**：按镜头选对应角度参考图作 `start-frame reference`，身份锁最死 | **不必**：镜头层优先靠首帧继承，只在身份漂移时补母锚点 |
| **一镜几帧** | **首+尾成对**（Wan FLF2V / LTX-2 双帧锚定） | **一镜一帧**（k 默认 1） |
| **长序列怎么拼** | **链式承接**（尾帧→首帧） | **硬切**（短片最干净、风险最低） |

## 三、★★ 最易被双方同时漏掉的 6 个环节

| # | 环节 | 说明 |
|---|---|---|
| 1 | **统一调色 / 跨镜色彩一致性** | 两个独立来源强调"最后一定有一道调色，且**不靠 AI**"——只做拼接不做调色，拼接感抹不掉 |
| 2 | **可逐字复制的"角色/场景描述块"** | 4 源一致：**改写描述是漂移最大原因**；只写"引用某锚点"不够 |
| 3 | **代际退化防治** | 尾帧链式**每 3 段插一次 upscale** |
| 4 | **参考图角度槽位要填满，须含 3/4 后视** | 只给正面 → 模型猜不到侧面与后脑 |
| 5 | **文件命名规范** | 工业源："跳过技术规划是后期混乱的最大单一原因" |
| 6 | **"先跑 3 张再批量"的试错纪律** | 一次性跑全部分镜＝高废片率 |

## 四、节点图本体判据（Nuke/Fusion 哲学 · 可直接用来体检任何图）

- **DAG（有向无环）**：边＝数据流，**必须能拓扑排序**；出现环＝图错了。
- **★ B-spine 主脊**：**"能指着一条竖线说'这就是这个镜头'，图才算结构成立"**——否则就是侧向面条。
- **Lens logic**：按真实镜头深度顺序叠（前景→中景→背景）；**不要靠 holdout 硬拗层级**。
- **DRY**：同一 matte/同一信息**不重复造多次**；**一个权威源 → 多个消费者**。
- **★ 复杂度是负债**：节点越多 → 隐藏依赖越多 / 越易引入重复调色与死支线 / 交接越脆。
- **非破坏性 + 可审计谱系**：节点图的价值是**保留从输入到成片的变换谱系**（＝我方"账本为正本 + 引用边"的同源思想）。

## 五、工业三阶段 → AI 短片映射

| 工业阶段 | 工业步骤 | AI 短片对应 |
|---|---|---|
| **Pre** | 故事/概念 → **角色设计 + Model Sheet** → **Storyboard** → **Animatic** → 技术规划与**文件命名规范** | 剧本 → 内容锚点(+派生) → 分镜条目 → 故事板 → 账本文件 |
| **Production** | **Layout（机位/路径/灯光）** → 资产/建模 → 绑定 → **关键姿势→中间画** → 灯光/VFX → 渲染 | 场景平面图→机位视图 → 关键帧 → 镜头视频 |
| **Post** | **合成（节点式）** → 声音设计 → **调色** → 终检输出 | X1 合成 → 声音节点 → **调色（常被漏）** → 交付验收 |

**★ 渐进承诺**：整套工业流程的方向是**"从便宜的规划与测试，走向越来越贵的成品"**——顺序反了（先做贵的）＝返工。

## 七、使用纪律

1. **对表优先**：平台 Agent 的每条结论，先查本节有无**外部多源佐证**；**无佐证且与外部冲突的，不采信**。
2. **区分"他那层的限制"与"平台的限制"**：他说"做不到"时，先问**是工具面限制还是能力限制**。
3. **分歧项按片情裁**：见 §二，两派都合法时按"本片是否需要跨镜连续/是否需要身份硬锁"来选。
4. **重点查 §三 六个漏项**——它们是"多源共识 + 极易漏"，每支片交付前逐条过。
